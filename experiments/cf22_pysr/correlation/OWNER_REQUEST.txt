## 2. Не нужно искать отдельный закон для каждого порядка масок

Вот точное сокращение всей этой иерархии.

Обозначим через

\[
A(P)=\#\{a:\ a\text{ хороший},\ q_a\le P\}
\]

**число усилителей**, а через

\[
A_P(N)=\#\{a:\ a\text{ хороший},\ q_a\le P,\ (a,N)=1\}
\]

— число усилителей, **взаимно простых** с \(N\). Все степени простых в \(a\) считаются отдельно.

Для настоящих коэффициентов

\[
c_n=\frac{\mu(n)}{\sqrt L}W(q_n/L)
\]

введём два средних одной и той же парной фазы:

\[
T_\rho(n,m)=
\frac1{S_\rho}
\sum_{u^{(6)}}\rho(q_u/U)
\chi_n(u)^{\varepsilon_\chi}
\overline{\chi_m(u)^{\varepsilon_\chi}},
\]

\[
T_H(n,m)=
\frac1{N_H}
\sum_{0<q_w\le2H}
\chi_n(w)^{\varepsilon_\chi}
\overline{\chi_m(w)^{\varepsilon_\chi}}.
\]

Здесь **\(S_\rho\)** — масса физических строк, **\(N_H\)** — число всех сырых строк. Это именно два усреднения из вашего вычислителя. Нули характеров сохраняются. 

Тогда для любой бесквадратной маски \(d\):

\[
\boxed{
h(d)=
\mu(d)
\sum_{\substack{n\ne m\\d\mid\operatorname{rad}(nm)}}
c_n\overline{c_m}\,T_\rho(n,m).
}
\tag{1}
\]

**Почему:** коэффициент одной пары в обращении Мёбиуса равен

\[
\sum_{e\mid d}\mu(d/e)\mathbf1_{(nm,e)=1}
=
\prod_{\mathfrak p\mid d}
\left(\mathbf1_{\mathfrak p\nmid nm}-1\right)
=
\mu(d)\mathbf1_{d\mid\operatorname{rad}(nm)}.
\]

Это конечное **включение–исключение**, а не статистическая гипотеза. Общая формула обращения Мёбиуса стандартна; здесь её применение к простым идеалам видно непосредственно из произведения. [DLMF](https://dlmf.nist.gov/27.5?utm_source=chatgpt.com)

Теперь суммируем **все** порядки:

\[
\sum_{d\mid\operatorname{rad}(N)}
\mu(d)A(P/q_d)=A_P(N).
\]

Следовательно, полная исходная величина равна

\[
\boxed{
\frac{\mathcal C}{A(P)S_\rho}
=
\Re\sum_{n\ne m}
c_n\overline{c_m}
\left[
\frac{A_P(nm)}{A(P)}T_\rho(n,m)-T_H(n,m)
\right].
}
\tag{2}
\]

**Всё смешанное взаимодействие уже внутри точного счётчика \(A_P(nm)\).** В том числе ваши \(+0.1500132009\). Среднее не потеряно, исходная диагональ уже удалена ровно один раз.

Цена преобразования — **ноль**: только конечные равенства.

Но важно: **(2) не уменьшает сумму. Она убирает необходимость придумывать самостоятельный закон для каждого порядка масок.**

## 4. Есть часть задачи, которую масочные поправки вообще не видят

Назовём колонку **\(P\)-грубой**, если у её индекса нет простого идеального делителя нормы \(\le P\).
