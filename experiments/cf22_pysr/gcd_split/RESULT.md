# Полная C: разбиение по общему идеальному делителю

2026-10-20. FINITE_PANEL_ONLY. Новых исходных сумм и PySR fits:0.

Выбрано одно разбиение с параметром G. Для каждой сохранённой неупорядоченной
пары i<j берём её ПОЛНЫЙ подписанный вклад D_ij и норму идеального общего
делителя g_ij=N(gcd(n_i,n_j)). Это не gcd целых норм: сопряжённые простые
идеалы могут иметь одинаковые нормы, оставаясь различными.

    M_G = sum_(g_ij≤G) D_ij,
    R_G = sum_(g_ij>G) D_ij,
    C = M_G + R_G.

«Основная часть» и «остаток» здесь — имена двух точных частей; вычисление
не доказывает, что одна аналитически легче другой. Каждый D_ij уже содержит
все усилительные маски и вычитание сырого среднего. RR, RA и AA сохраняются
в обеих частях. Исходная диагональ обратно не добавляется.

Проверены G=1,7,13,19,31 на всех20 конфигурациях. При G=1 основная часть
содержит пары взаимно простых идеалов, остаток — пары с общим простым делителем.
Порог выбран по арифметическому признаку, не по знаку вклада.

## Какой параметр помогает

G=1 даёт ясную первую математическую развилку: взаимно простые пары против
пар с общим простым делителем. На U64/P13 в основной части остаётся11.18660
из полной12.48124; основной положительный вклад этим разбиением не исчезает.
На U96/P13 остаток, напротив, уменьшает основную часть на2.36952.

Пока НЕ найден оптимальный G для доказательства. Минимизировать только |R_G|
некорректно: достаточно перенести все пары в M_G, чтобы получить R_G=0 и
M_G=C — исходная трудность вернётся целиком. На U64 G19 именно так и происходит.

Положительная часть x_+=max(x,0) — стоимость, если при оплате отдельной части
мы отказываемся использовать её отрицательный знак. Как в денежном балансе:
оплачивать расходы, не учитывая возврат денег, может оказаться дороже.
Диагностика потери компенсации:

    J_G=(M_G)_+ + (R_G)_+ − (C)_+ ≥0.

    M_G + R_G = C          → исходный подписанный баланс
    (M_G)+ + (R_G)+         → цена отказа от отрицательных вкладов частей
    разница J_G            → потерянная компенсация

На U96/P13 G1 такая цена около2.36952; на U48/P49 G7 около10.67788.
Она не является неизбежной ценой любого доказательства: направленная оценка
может сохранять отрицательный вклад. J_G — диагностический показатель,
а не новая мажоранта с улучшенным CF22-показателем.

## Следующий математический вопрос

Первый кандидат — сохранить G=1 как точное выделение взаимно простых пар и
искать оценку их полной физико-сырой разности на настоящих коэффициентах.
Одновременно нужен верхний бюджет R_1, без заранее назначенного знака.
Выделение общего делителя само по себе не поставляет ни одной из этих оценок.

Для дальнейшей оптимизации G=G(U) нужны доказанные бюджеты обеих частей с
явной зависимостью от G, причём их сумма должна улучшать исходный длинный
бюджет. Если раздельная оплата уничтожает нужную компенсацию, требуется
совместная оценка M_G+R_G с сохранёнными взаимодействиями. Текущая панель
показывает эту опасность, но не выбирает асимптотически верный G(U).

Все неединичные P в этой панели заданы вне исходного расписания. Наблюдения
не переносятся автоматически в режим длинных периодов CF22. Общий профильный
квантор и высотные потери здесь не проверялись. CF22 остаётся открытой.
