# Отсечение коэффициентов на сохранённой полной C

Дата: 2026-10-20. Область: только сохранённая конечная панель20 конфигураций
(10 числовых сценариев, две сопряжённые ориентации). Исходные значения C не
пересчитывались и не менялись. Все RR, RA, AA включены. CF22 не улучшена.

## Что проверяем

Для каждой строки используем фактические сохранённые U,P,L и полную C.
S=P U^(1/6)L^(5/6). Семейство конвертов:

    C ≤ alpha P U + kappa S U^(−delta), alpha,kappa≥0.

Эквивалентно q=C/S ≤ alpha (U/L)^(5/6)+kappa U^(−delta).
Коэффициенты конверта не изменяют исходную C. Для диапазона параметров максимум
правой части достигается при alpha+, kappa+, delta−, так как U>1.
Если нижняя граница интервала C выше верхней границы этого максимума хотя бы
в одной строке, весь диапазон отвергнут как конверт ВСЕЙ данной панели.

## Два конкретных отсечённых диапазона

| alpha | kappa | delta | Строка-свидетель | Нижний запас нарушения в единицах C |
|---|---|---|---|---|
| [0,0.01] | [0,0.019] | [0,0.01] | U64, Pproduction, ориентация+1 | >0.04988 |
| [0,0.01] | [0,0.003] | [0,0.01] | U64, P13, ориентация+1 | >0.24459 |

Это замкнутые диапазоны, включая границы. Каждый вариант внутри них нарушает
условие в указанной строке. Второй диапазон вложен в первый; его отдельный
свидетель показывает эффект именно на неединичной конфигурации.
Диапазоны выбраны после осмотра данных как простые иллюстрации, не как слепой
прогноз. Доказательность конечного опровержения от этого не зависит.

В первом случае C≈2.83848605, максимум конверта<2.78859754.
Во втором C≈12.48124162, максимум конверта≤12.236643835.
Независимый проверяющий с обычными рациональными дробями подтверждает строгий
запас; для него даже не требуется Arb. Он сверху ограничивает шестой корень
в S рациональным числом, проверяя результат точным возведением в степень.
Для delta≥0 использует U^(−delta)≤1. Полные рациональные числа сохранены.

## Что здесь делают смешанные вклады

На U64/P13 подписанный баланс:

    RR       +2.289643268113
    RA      +10.370283579123
    AA       −0.178685229776
    C       +12.481241617461

Это как общий денежный баланс: статьи могут иметь разные знаки, но сравниваем
с потолком только итог после сложения всех статей.

    RR + RA + AA → полная C → сравнение с максимальным конвертом диапазона
                                     ↓ строго выше
                              весь диапазон исключён

Если незаконно убрать RA, получится около2.11096. Эта величина даже меньше
одного alpha PU=8.32 в верхнем углу второго диапазона и не выявляет нарушения
там. Поэтому сохранение перекрёстного члена здесь меняет результат проверки.
Это диагностическое сравнение, не предложение заменить полную C.
RA — перекрёстные взаимодействия колонок. Не путать их со смешанными
масками усилителя p*pbar: последние впервые появились в строке P49. Эта строка
тоже включена целиком, но её отрицательная C не исключает неотрицательный конверт.

## Как читать границу параметров

Для заданных alpha,delta необходимое условие на kappa:

    kappa ≥ max(0, max_i (C_i−alpha P_i U_i)/(S_i U_i^(−delta))).

В result.json граница вычисляется интервально; её нижняя оценка пригодна для
опровержения меньших kappa. Равенство округлённому числу не является строгим
контрпримером. Проверка диапазона работает по исходным интервалам.

Самое сильное ограничение среди выбранных малых alpha даёт U64/Pproduction,
где усилитель единичный. Среди неединичных строк — U64/P13. Эти два результата
показаны раздельно, чтобы не скрыть разницу режимов.

При alpha=0.01 получены следующие границы (округлены для чтения;
для сертификатов используются полные интервалы):

| delta | Необходимая kappa на всей панели, примерно | На неединичной части, примерно |
|---|---|---|
| 0 | 0.01945392418 | 0.00318735260 |
| 0.005 | 0.01986269248 | 0.00325432565 |
| 0.01 | 0.02028004987 | 0.00332270595 |

При alpha≤0.01 эти ограничения не ослабевают. Отрицательные строки, включая
U48/P49 со всеми смешанными масками, остаются в проверке, но не ограничивают
неотрицательную правую часть.

## Проверка выполнения

Основной Arb-запуск: PASS_FINITE_PANEL_ONLY, все20 строк, оба узких диапазона
REFUTED_ON_PANEL. Контрольный широкий диапазон alpha,kappa∈[0,0.1],
delta∈[0,0.01] получил NOT_REFUTED_ON_PANEL. Проверяющий не объявляет весь этот
диапазон допустимым: в нём, например, есть нулевой конверт, который нарушается.

8 целевых тестов прошли: подмена C, потеря перекрёстного вклада, обратный порядок
концов интервала, некорректная область коэффициентов, граничное перекрытие,
монотонность по delta и полный результат панели. Независимый обзор после
исправления входных проверок — без существенных замечаний.

Отдельный verify_rational.py подтвердил два отсечения без Arb и без импорта
основного вычислителя. Источники и результаты закреплены контрольными суммами.
Сырые суммы не пересчитывались; PySR не запускался; новые зависимости не ставились.

## Что результат НЕ утверждает

Неединичные P7/P13/P49 заданы независимо от производственного расписания.
Их опровержение относится к контракту на этой панели. Даже строки Pproduction
не опровергают eventual-оценку с неизвестным началом U0 или неизвестными
неограниченными константами. Мы не исключили положительный степенной выигрыш.

NOT_REFUTED_ON_PANEL означает лишь отсутствие сертификата опровержения целого
диапазона: внутри него могут находиться и плохие кандидаты. Это не доказанная
мажоранта, не статус CANNOT_IMPROVE и не свидетельство оптимальности.
Исследуется фиксированный профиль и высота, без скрытого добавления потерь.
Общая CF22 требует полного исходного квантора и отдельной арифметической оценки.
