# Literature Ingestion (Markdown)

Drop markdown-converted papers here. The qmd collection points to this folder.

Suggested structure:

```
literature/
  Weil1952/
    README.md
    Weil1952.md
  Guinand1948/
    README.md
    Guinand1948.md
```

Each subfolder should include a short README with citation metadata (author, year, source URL, sha256 of original PDF).
