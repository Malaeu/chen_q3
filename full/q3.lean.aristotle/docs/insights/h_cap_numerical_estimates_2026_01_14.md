### Техника для n≥3

```

```

**Доказательство:** Нужно показать `4π²(log n)² ≥ 10·log n`.
Для n≥3: `log n ≥ 1`, поэтому `4π²(log n) ≥ 4π² ≈ 39.5 > 10`. ✓

**Следствие:**
```
Λ(n)/√n · exp(-4π²(log n)²) ≤ log(n)/√n · n⁻¹⁰ = log(n)/n^{10.5}
```
