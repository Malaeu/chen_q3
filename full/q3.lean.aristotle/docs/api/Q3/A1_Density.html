    Main Theorem A1' #

    source
    theorem Q3.A1.A1_density (K : ℝ) (hK : K > 0) (f : ℝ → ℝ) :
    f ∈ C_even_nonneg K → ∀ ε > 0, ∃ g ∈ Fejer_heat_cone K, ∀ x ∈ Set.Icc (-K) K, |f x - g x| < ε

    Theorem A1' (Local Density): The Fejér×heat cone is dense in C⁺_even([-K,K]) in the uniform norm.

    This is a key approximation theorem: any even nonnegative continuous function on a compact interval can be uniformly approximated by finite sums of Fejér×heat atoms.

    Proof: Follows from axiom A1_density_axiom (combination of Fejér's theorem and heat kernel approximation identity).
