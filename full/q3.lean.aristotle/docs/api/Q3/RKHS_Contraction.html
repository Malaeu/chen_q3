                      theorem Q3.RKHS.RKHS_contraction (K : ℝ) (hK : K ≥ 1) :
                      ∃ t > 0, ∃ ρ < 1, ∀ (S : Finset ℕ), (∀ n ∈ S, n ∈ Q3.Nodes K) → have T_P := fun (i j : { x : ℕ // x ∈ S }) => √(Q3.w_RKHS ↑i) * √(Q3.w_RKHS ↑j) * Real.exp (-(Q3.xi_n ↑i - Q3.xi_n ↑j) ^ 2 / (4 * t)); ‖LinearMap.toContinuousLinearMap (Matrix.toEuclideanLin T_P)‖ ≤ ρ

                      Main RKHS Theorem: ‖T_P‖ ≤ ρ_K < 1 for appropriate t

                      For any K ≥ 1, there exists t > 0 such that ‖T_P K t‖ < 1.

                      More precisely, for t ≥ t_min(K, η) with small η: ‖T_P‖ ≤ w_max + √w_max · η < 1

                      Since w_max = 2/e ≈ 0.7358 and √w_max ≈ 0.858, choosing η small enough gives contraction.
