### 5.3 Почему выделен `h1_po3_route_ladder_2026_04_19.md`

Это не инсайт в смысле остальных 164 файлов, это **карта маршрута**: называет лестницу
`PO3-shell.2…6 → PO3-rig.1/.2 → PO3-tail.1/.2 → PO3-cauchy.1/.2 → PO3-square.1/.2 → H2^f
→ H3^f → H4^f → RH`, объявляет `PO3-square.2` «настоящей стеной» с четырьмя критериями
и определяет язык `A_k`/`B_k` со стороны преобразования, используемый ниже по течению.
Единственный файл инсайтов, цитируемый **трижды** из `docs/INSIGHTS.md` (строки 430, 9339,
10764) и дважды из `oracle_questions/BY_ADDRESS.md` (строки 28, 82) — то есть он источник
словаря, делающий адреса оракула (`PO3-rig.1a`, `PO3-square.2d3`) читаемыми.
Именно поэтому он в группе оракула, а не отдельно: без него адресные строки `BY_ADDRESS.md` непрозрачны.

**Основание частично в силе, но крепление неверное.**

- *В силе:* `ACTIVE/PHASE_MONITOR.md` (коммит 2026-08-06) всё ещё несёт

  `INSIGHTS.md:420-435` всё ещё ссылается на этот файл как на дом языка маршрута `A_k/B_k`.

  (`finite-anchor / absolute no-escape … inside PO3-square.2d`) — `killed`.
