# Хуки — копии для переноса на второе тело

Эти файлы живут в работе по пути `~/.claude/hooks/` и подключаются через
`~/.claude/settings.json`. В репозитории они лежат **копией**, чтобы механизм можно было
поставить на Mac-теле, а не собирать заново.

Канонические версии находятся в этом каталоге репозитория. Установка на конкретном
хосте выполняется в локальный каталог hooks из его пользовательской конфигурации;
абсолютный путь хоста в версионируемые файлы не записывается.

---

## `q3-toolbelt.sh` — пояс с инструментами, `SessionStart`

Печатает при старте каждой сессии, **без чьего-либо действия**: доступные инструменты с
одной командой каждый, счётчики базы, объём литобзора, ветку, очередь к Прошке — и
предупреждает про мониторы, лгущие о своём статусе.

Зачем: в контекст без действия попадают только `CLAUDE.md`, память и вывод
`SessionStart`-хуков. Всё остальное надо пойти и взять, а «не забудь пойти» умирает —
проверено трижды за 6–7 августа.

Молчит вне репозитория Q3 (проверяет, что `$PWD` внутри дерева). Время работы ~0.1 с.

**Подключение** — в `~/.claude/settings.json`, в массив `hooks.SessionStart[0].hooks`:

```json
{ "type": "command", "command": "bash ~/.claude/hooks/q3-toolbelt.sh" }
```

**На Mac поправить путь `REPO`** в начале скрипта — он захардкожен на Linux-дерево.

## `unicode-guard.py` — защита от невидимых закладок, `PostToolUse`

Ловит спрятанные Unicode-каналы в выводе инструментов **до того, как их прочитает модель**:
tag-блок `U+E0000..E007F`, вариационные селекторы (байты в эмодзи), bidi-перевороты
(Trojan Source), zero-width. Декодирует полезную нагрузку, **переписывает вывод** через
`updatedToolOutput`, ставит видимый маркер `⟦HIDDEN-…⟧`, и говорит модели, что
расшифрованное — недоверенные данные, никогда не инструкция.

С 2026-08-07 пишет журнал: `~/.claude/logs/unicode-guard.jsonl` — время, инструмент, канал,
источник (URL или путь), расшифрованная закладка.

```bash
jq -r '[.ts,.tool,.summary,.source] | @tsv' ~/.claude/logs/unicode-guard.jsonl
jq -r '.categories[]' ~/.claude/logs/unicode-guard.jsonl | sort | uniq -c
```

**Подключение** — в `hooks.PostToolUse` с matcher `Read|WebFetch|WebSearch|Task|mcp__`:

```json
{ "matcher": "Read|WebFetch|WebSearch|Task|mcp__",
  "hooks": [{ "type": "command",
              "command": "python3 ~/.claude/hooks/unicode-guard.py" }] }
```

Fail-open: любая внутренняя ошибка → выход 0 с пустым выводом, чтобы баг сканера не ломал
инструменты. `GUARD_REPORT_ONLY=1` — только сообщать, не переписывать. `GUARD_DEBUG=1` —
ошибки в stderr.

## Что ещё нужно на втором теле, кроме хуков

| | |
|---|---|
| `./ask.sh <термин>` | один вход по шести хранилищам; лежит в корне репозитория, работает как есть |
| `./paper.sh <arxiv\|doi>` | PDF + метаданные + bib + Zotero + строка реестра; нужен `~/.api_keys` с `ZOTERO_API_KEY`, `ZOTERO_LIBRARY_ID`, `ZOTERO_LIBRARY_TYPE` |
| `./specs_docs/session_start.sh` | состояние сессии, выходит с 1 при противоречиях источников |

Первые два зависят только от репозитория и Python; `paper.sh` дополнительно от ключей
Zotero.
