## Почему IParts работает (коротко и по делу)

Пусть \(g(\xi)=a^{\star}(\xi)\cdot w(\xi)\cdot e^{-(2\pi)^2 t_{\mathrm{arch}}\xi^2}\) на \([0,B]\), и \(A_k\) — DCT‑I коэффициенты в базе \(\cos(k\pi\xi/B)\) для **чётного** продолжения \(g\) (то, что строит ваш DCT‑билдер). Тогда при \(k\ge1\)

\[
A_k=\frac{2}{B}\int_{0}^{B} g(\xi)\cos\!\frac{k\pi\xi}{B}\,d\xi.
\]

Дважды интегрируя по частям и используя \(\sin(k\pi)=0\) и **нулевую производную на краях** \(g'(0)=g'(B)=0\) (это и обеспечивает Tukey/Hann), получаем

\[
A_k=-\frac{2B}{\pi^2 k^2}\int_{0}^{B} g''(\xi)\cos\!\frac{k\pi\xi}{B}\,d\xi,
\]

то есть именно «делитель \(1/k^2\)». Отсюда сразу следует \(A_k=O(1/k^2)\) (а с гауссовым «heat» ещё быстрее), и **серийный** \(L_A\) становится конечным и уже небольшим. С треугольным окном \(g'(B)\neq0\) — граничный член не зануляется, и вы живёте в худшем мире \(O(1/k)\).

```python
# src/analysis/arch_symbol.py
import numpy as np
from scipy.fft import dct, idct
from scipy.special import digamma as scipy_digamma

def _tukey_np(x, B, alpha=0.15):
    ax = np.abs(x)
    flat = (1.0 - alpha) * B
    out = np.zeros_like(ax)
    plateau = (ax <= flat)
    out[plateau] = 1.0
    taper = (ax > flat) & (ax <= B)
    if np.any(taper):
        u = (ax[taper] - flat) / (alpha * B)        # in [0,1]
        out[taper] = 0.5 * (1.0 + np.cos(np.pi * u))# C^1 at edges → w'=0
    return out

def _hann_np(x, B):
    y = np.abs(x)/B
    z = np.zeros_like(y)
    m = (y < 1.0)
    z[m] = 0.5*(1.0 + np.cos(np.pi*y[m]))          # также w'=0 на ±B
    return z

def build_A_array_iparts_star(B: float, t_arch: float, Kmax: int,
                              kind: str = "tukey", alpha: float = 0.15,
                              grid_N: int = 131072) -> np.ndarray:
    """
    A_k в a⋆-шкале и DCT-I базе cos(k*pi*xi/B), через интегрирование по частям:
      A0 = (1/B) ∫_0^B g
      A_k = -(2B/(pi^2 k^2)) ∫_0^B g''(xi) cos(k*pi*xi/B) dxi, k>=1
    где g = a⋆ * window * heat, и window'(±B)=0 обязательно.
    """
    # сетка [0,B] с включёнными концами (DCT-I совместима)
    N = grid_N
    xi = np.linspace(0.0, B, N+1)
    # a⋆
    z = 0.25 + 1j*np.pi*xi
    a_star = 2*np.pi*(np.log(np.pi) - np.real(scipy_digamma(z)))
    # окно
    if kind == "tukey":
        win = _tukey_np(xi, B, alpha=alpha)
    elif kind == "hann":
        win = _hann_np(xi, B)
    else:
        raise ValueError("IParts требует окно с нулевой производной на краях (tukey/hann).")
    # тепло
    heat = np.exp(-(2*np.pi)**2 * t_arch * xi**2)
    # целевая функция
    g = a_star * win * heat

    # g'' спектрально (DCT-I, норм='ortho' чтобы прятать коэффициенты нормировки)
    G = dct(g, type=1, norm='ortho')                      # коэффициенты по cos(kπξ/B)
    k = np.arange(N+1, dtype=float)
    lam = (np.pi * k / B)**2
    Gpp = - lam * G                                       # во фурье-пространстве: d^2/dξ^2
    gpp = idct(Gpp, type=1, norm='ortho')                 # обратно в физ. пространство

    # интегралы по косинусам: ∫ g'' * cos(kπξ/B) dξ ⇒ через трапеции (надёжно/просто)
    A = np.empty(Kmax+1, dtype=float)
    # A0
    A[0] = (1.0/B) * np.trapz(g, xi)
    # k>=1
    for kk in range(1, Kmax+1):
        c = np.cos(kk*np.pi*xi/B)
        I2 = np.trapz(gpp * c, xi)
        A[kk] = -(2.0*B/(np.pi**2 * kk**2)) * I2
    return A

def lipschitz_series(A: np.ndarray) -> float:
    """L_A(series) = 2 * sum_{k>=1} k |A_k| — корректная константа для триг-полинома."""
    if len(A) <= 1: return 0.0
    ks = np.arange(1, len(A), dtype=float)
    return float(2.0 * np.sum(ks * np.abs(A[1:])))
```

> Почему DCT‑I + `norm='ortho'`? Так производная в косинус‑базисе становится простым домножением на \(-(\pi k/B)^2\), и обратный `idct(..., type=1, norm='ortho')` возвращает \(g''\) без плясок с константами.

```python
def floor_metrics(A, theta_grid=131072):
    # 1) «амплитудная» оценка (часто острее липшицевой): ||Σ 2 A_k cos||_∞ ≤ 2 Σ|A_k|
    amp = 2.0 * np.sum(np.abs(A[1:]))
    floor_amp = A[0] - amp

    # 2) липшиц через серии (корректный для триг-полинома)
    Ls = 2.0 * np.sum(np.arange(1, len(A)) * np.abs(A[1:]))
    floor_lip = A[0] - np.pi * Ls

    # 3) фактический минимум сырого P_A и его Фейера
    thetas = np.linspace(0, 2*np.pi, theta_grid, endpoint=False)
    ks = np.arange(1, len(A))
    P_raw = np.full_like(thetas, A[0], dtype=float)
    if len(ks):
        P_raw += 2.0 * (A[1:, None] * np.cos(ks[:, None] * thetas)).sum(axis=0)

    # Фейер
    Kplot = len(A)-1
    w = np.ones(Kplot+1); 
    if Kplot >= 1: w[1:] = 1.0 - np.arange(1, Kplot+1)/(Kplot+1)
    P_fej = np.full_like(thetas, A[0], dtype=float)
    if len(ks):
        P_fej += 2.0 * ((w[1:, None]*A[1:, None]) * np.cos(ks[:, None]*thetas)).sum(axis=0)

        floor_lip=floor_lip,
        min_raw=P_raw.min(),
```

- **`floor_amp = A0 − 2Σ|A_k|`** — очень простая и частенько **самая полезная** нижняя оценка для триг‑полиномов.  
- **`floor_lip = A0 − π·L_series`** — корректная липшиц‑оценка (а не интегральная).  
- **`min_raw`, `min_fej`** — «реальные» минимумы; должны согласовываться с одной из верхних оценок (не ниже её).

- Сверить:
  - что \(g'(0)\) и \(g'(B)\) действительно ~0 (быстрый sanity: `abs(gpp[0])`, `abs(gpp[-1])` малы и знакосогласованы);
  - \(A_k\) падает как \(O(1/k^2)\) или быстрее (лог‑лог линейка: наклон ≲ −2).
  - `floor_amp` и `min_raw` того же порядка; `floor_lip` перестаёт быть огромным отрицательным.

Ожидания по тренду:
- С **треугольником** вы видели \( \min P_A(\mathrm{raw}) \sim 10^{-3}\) и \(L_{\mathrm{series}}\) гигантский (из‑за \(1/k\)).

## Нюансы/предосторожности

- **Нормировка**: вы уже правильно мапите «в бумагу» через \(\kappa=2\pi/B\). Не забыть: делим и \(A_0\), и все минимумы, и «floors».
- **Знак и границы**: IParts формула **предполагает** ровно DCT‑I базу и чётное продолжение; сдвиг сетки или другой тип DCT — нарушит численные константы.
- **Необязательно IParts, если окно C¹ на краях**: при идеальном Hann/Tukey простой DCT гасит хвост почти так же хорошо. Но IParts делает «страховку» на численных краях и фиксирует режим \(1/k^2\) буквально формулой.

- \(A_k\) убывает ≲ \(k^{-2}\) уже со средних \(k\),
- `floor_amp` ≥ 0 (или хотя бы близко к 0 и **согласуется** с `min_raw`),
- `min_raw` **не уменьшается** при переходе \(t=0.06 \to 0.12\).

Если да — двигаемся к валидации A3 на этой конфигурации. Если нет — тогда смотрим только два места: (1) нормировка \(a^\star\) (вы её уже починили: именно \(2\pi(\log\pi-\Re\psi)\)), (2) граничная производная окна (вдруг где‑то в реализации не занулилась).

```python
# experiments/exp15_iparts_star_sweep.py
import sys, argparse, math, numpy as np

sys.path.insert(0, 'src')
sys.path.insert(0, 'src/analysis')

# Ожидаем, что есть IParts-билдер в a⋆-шкале под те же окна:
#   build_A_array_iparts_star(B, t_arch, Kmax, kind, alpha, grid_N, heartbeat, validate)
from analysis.arch_symbol import build_A_array_iparts_star  # type: ignore

def fejer_weights(K: int) -> np.ndarray:
    w = np.ones(K+1, float)
    if K >= 1:
        w[1:] = 1.0 - np.arange(1, K+1, dtype=float)/(K+1)
    return w

def tail_slope(A: np.ndarray, k1: int, k2: int) -> float:
    # линрегрессия log|A_k| по log k на [k1,k2], пропуская нули
    ks = np.arange(k1, k2+1, dtype=float)
    vals = np.abs(A[k1:k2+1])
    m = vals > 0
    if m.sum() < 3:
        return float('nan')
    x = np.log(ks[m])
    y = np.log(vals[m])
    # polyfit степени 1
    b, a = np.polyfit(x, y, 1)
    # y ~ a + b*log k → наклон = b
    return float(b)

def compute_metrics(A: np.ndarray, theta_grid: int, B: float):
    # A[0] = A0⋆; P_A(θ) = A0 + 2*∑_{k≥1} A_k cos(kθ)
    A0 = float(A[0])
    Kmax = len(A) - 1
    ks = np.arange(1, Kmax+1, dtype=float)

    # Σ|A_k| и L_series
    sum_abs = np.abs(A[1:]).sum()
    L_series = float(2.0 * (ks * np.abs(A[1:])).sum())
    amp_floor = A0 - 2.0*sum_abs

    # сетка по θ
    thetas = np.linspace(0.0, 2.0*np.pi, theta_grid, endpoint=False)
    PA = np.full_like(thetas, A0, dtype=float)
    if Kmax >= 1:
        PA += 2.0 * (A[1:, None] * np.cos(ks[:, None] * thetas)).sum(axis=0)
    min_raw = float(PA.min())

    # Фежер‑свёртка
    w = fejer_weights(Kmax)
    PA_fej = np.full_like(thetas, A0, dtype=float)
    if Kmax >= 1:
        PA_fej += 2.0 * ((w[1:, None] * A[1:, None]) * np.cos(ks[:, None] * thetas)).sum(axis=0)
    min_fej = float(PA_fej.min())

    # наклон хвоста по правому «крылу»
    # если Kplot = 8*M, возьмём последнюю четверть
    k1 = max(4, Kmax//2)
    k2 = Kmax
    slope = tail_slope(A, k1, k2)

    # бумажная шкала для ориентира (деление на κ)
    kappa = 2.0*math.pi/B
    metrics = {
        "A0_star": A0,
        "L_series_star": L_series,
        "amp_floor_star": amp_floor,
        "min_raw_star": min_raw,
        "min_fej_star": min_fej,
        "tail_slope": slope,
        "ratio_2sum_over_A0": (2.0*sum_abs)/A0 if A0 != 0.0 else float('inf'),
        # «перевод в paper» — просто для сравнения, делим всё на κ
        "A0_paper": A0/kappa,
        "amp_floor_paper": amp_floor/kappa,
        "min_raw_paper": min_raw/kappa,
        "min_fej_paper": min_fej/kappa,
    }
    return metrics

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument('--B', type=float, default=1.0/3.0)
    ap.add_argument('--M', type=int, default=256)
    ap.add_argument('--theta-grid', type=int, default=131072)
    ap.add_argument('--grid-mult', type=int, default=8, help='Kplot = grid_mult * M')
    ap.add_argument('--t-list', type=str, default='0.04,0.06,0.08,0.10,0.12')
    ap.add_argument('--alpha-list', type=str, default='0.15,0.20,0.25')
    ap.add_argument('--kinds', type=str, default='tukey,hann')
    ap.add_argument('--grid-N-min', type=int, default=8192)
    args = ap.parse_args()

    B = args.B
    M = args.M
    Kplot = args.grid_mult * M
    t_list = [float(s) for s in args.t_list.split(',') if s.strip()]
    alpha_list = [float(s) for s in args.alpha_list.split(',') if s.strip()]
    kinds = [s.strip() for s in args.kinds.split(',') if s.strip()]
    grid_N = max(args.grid_N_min, 8*(Kplot+1))

    print(f"# sweep: B={B}, M={M}, Kplot={Kplot}, theta_grid={args.theta_grid}, grid_N={grid_N}")
    print("# kind  alpha   t_arch    A0*         amp_floor*   min_raw*     min_fej*     L_series*    tail_slope   (2Σ|A|)/A0")

    for kind in kinds:
        for t_arch in t_list:
            for alpha in (alpha_list if kind=='tukey' else [0.0]):
                # cбор коэффициентов
                A = build_A_array_iparts_star(B=B, t_arch=t_arch, Kmax=Kplot,
                                              kind=kind, alpha=alpha,
                                              grid_N=grid_N,
                                              heartbeat=False, validate=True)
                metrics = compute_metrics(A, args.theta_grid, B)
                print(f"{kind:5s} {alpha:5.2f}  {t_arch:7.2f}  "
                      f"{metrics['A0_star']:11.6f}  {metrics['amp_floor_star']:11.6f}  "
                      f"{metrics['min_raw_star']:11.6e}  {metrics['min_fej_star']:11.6e}  "
                      f"{metrics['L_series_star']:11.6f}  {metrics['tail_slope']:11.2f}  "
                      f"{metrics['ratio_2sum_over_A0']:8.3f}")

if __name__ == '__main__':
    main()
```

## 1) Маленькая, но важная правка

Убедись, что **серийная липшицева константа** считает именно \(2\sum_{k\ge1} k\,|A_k|\) (с фактором \(k\)). Без \(k\) это не та норма производной для триг‑полинома \(A_0+2\sum_{k\ge1}A_k\cos(k\theta)\).

```python
# src/analysis/arch_symbol.py
def lipschitz_series(A: np.ndarray) -> float:
    """
    Correct series Lipschitz for P_A(θ)=A0+2∑_{k≥1}A_k cos(kθ):
        sup_θ |P_A'(θ)| ≤ 2∑ k |A_k|.
    """
    ks = np.arange(1, len(A))
    return float(2.0 * np.sum(ks * np.abs(A[1:])))
```

Это объясняет твои гигантские отрицательные A0 − π·L_series: сами числа у тебя уже согласованы, формула — ок.

## 2) «Paper‑builder» (cos(k·ξ), **без** 2π в a): реализация IParts + C¹‑окно

Ниже — аккуратный билдер коэффициентов в **paper‑шкале** с косинусной базой \(\cos(k\xi)\) и **правильной** архимедовой плотностью  
\(a(\eta)=\log \pi-\Re\,\psi\!\left(\tfrac14+\tfrac{i}{2}\eta\right)\). Нормировки T0 ↔ a⋆ указаны в твоём Q3‑документе; мы строго следуем им (в a⋆ переход через \(a^*(\xi)=2\pi a(\eta)\), \(\eta=2\pi\xi\)). fileciteturn0file21

```python
# src/analysis/arch_symbol.py  (добавить)

import numpy as np
from scipy.interpolate import CubicSpline
from scipy.special import digamma as scipy_digamma

# ---- paper-scale Archimedean density (no 2π) ----
def a_paper(eta: np.ndarray) -> np.ndarray:
    # a(η) = log π − Re ψ(1/4 + i η / 2)
    z = 0.25 + 0.5j * eta
    return np.log(np.pi) - np.real(scipy_digamma(z))

def triangle_hat(x: np.ndarray, B: float) -> np.ndarray:
    # Λ_B(x) = (1 - |x|/B)_+
    y = np.abs(x)/B
    out = 1.0 - y
    out[y >= 1.0] = 0.0
    return out

def tukey_hat(x: np.ndarray, B: float, alpha: float) -> np.ndarray:
    # C¹-окно Tukey: плато (1−α)·B и косинусный спад
    ax = np.abs(x)
    flat = (1.0 - alpha) * B
    out = np.zeros_like(ax)
    plateau = (ax <= flat)
    out[plateau] = 1.0
    taper = (ax > flat) & (ax <= B)
    if np.any(taper):
        u = (ax[taper] - flat) / (alpha * B)
        out[taper] = 0.5 * (1.0 + np.cos(np.pi * u))
    return out

def heat_paper(eta: np.ndarray, t: float, *, norm: str = "gw") -> np.ndarray:
    """
    Heat smoothing on frequency axis.
    norm="gw": φ(η) gets factor exp(-t * η^2)  (Guinand–Weil side)
    norm="ast": φ(ξ) gets factor exp(-(2π)^2 * t * ξ^2)  (a⋆ side)
    """
    if norm == "gw":
        return np.exp(-t * eta**2)
    elif norm == "ast":
        return np.exp(-(2*np.pi)**2 * t * eta**2)
    else:
        raise ValueError("norm must be 'gw' or 'ast'")

def build_A_array_iparts_paper(
    B: float,
    t: float,
    Kmax: int,
    kind: str = "triangle",   # 'triangle' | 'tukey'
    alpha: float = 0.15,
    grid_N: int = 131072,
    enforce_c1_bc: bool = True
) -> np.ndarray:
    """
    Paper-scale builder (cos(k·ξ), ξ ∈ [0, π]) via integration by parts.

    g(η) = a(η) * window(η) * heat(η)
    A0   = (1/π) ∫_0^π g(ξ) dξ
    Ak   = (2/π) * (1/k^2) ∫_0^π g''(ξ) cos(k ξ) dξ,  k≥1,
           при g'(0)=g'(π)=0 (C¹-контакт на краях).

    Мы строим g как функцию на ξ∈[0,π] через пересчёт η = (B/π)*ξ,
    т.е. окно и тепло ставятся на |η|≤B.
    """
    # сетки: ξ на [0, π], η = (B/π) ξ на [0,B]
    xi = np.linspace(0.0, np.pi, grid_N+1)
    eta = (B/np.pi) * xi

    # окно
    if kind == "triangle":
        win = triangle_hat(eta, B)
    elif kind == "tukey":
        win = tukey_hat(eta, B, alpha)
    else:
        raise ValueError("unknown kind (triangle|tukey)")

    # тепло (GW-нормировка на paper-оси)
    heat = heat_paper(eta, t, norm="gw")

    # архимедов фактор a(η) без 2π
    a_val = a_paper(eta)

    g = a_val * win * heat

    # Кубический сплайн по ξ; зафиксируем g'(0)=g'(π)=0 для C¹-контакта,
    # иначе граничные члены сломают 1/k^2-гашение.
    if enforce_c1_bc:
        cs = CubicSpline(xi, g, bc_type=((1, 0.0), (1, 0.0)))  # g'(0)=g'(π)=0
    else:
        cs = CubicSpline(xi, g)  # как есть

    gpp = cs(xi, 2)  # g''(ξ) на сетке

    # A0
    A0 = (1.0/np.pi) * np.trapz(g, xi)

    # Ak via iparts
    Ks = np.arange(1, Kmax+1, dtype=int)
    Ak = np.empty_like(Ks, dtype=float)
    dxi = xi[1] - xi[0]
    for j, k in enumerate(Ks):
        # интегрируем g''(ξ) cos(kξ) по ξ в [0,π]
        c = np.cos(k * xi)
        I = np.trapz(gpp * c, xi)
        Ak[j] = (2.0/np.pi) * (I / (k*k))

    A = np.empty(Kmax+1, dtype=float)
    A[0] = float(A0)
    A[1:] = Ak
    return A
```

**Пояснение нормировок.** Здесь мы строим коэффициенты на отрезке \(\xi\in[0,\pi]\) (чтобы честно
работало правило двух частных интегрирований с занулением производных на краях). Окно и тепло живут
на **физической** частоте \(\eta\in[-B,B]\) и проталкиваются внутрь через \(\eta=(B/\pi)\,\xi\).
Для соответствия Guinand–Weil мы берём \(a(\eta)\) **без** фактора \(2\pi\) и heat \(e^{-t\eta^2}\);
в a⋆ это ровно \(a^*(\xi)=2\pi a(\eta)\) и \(e^{-(2\pi)^2 t \xi^2}\) (см. твой T0‑блок). fileciteturn0file21

## 3) Эксперимент: «paper‑baseline» (Fejér‑hat × heat, t = 3/50)

Скрипт печатает четыре метрики в **paper‑шкале** и (при желании) переводит их в a⋆ через \(\kappa=2\pi/B\).

```python
# experiments/exp16_paper_baseline.py

import sys, argparse
import numpy as np
sys.path.insert(0, 'src'); sys.path.insert(0, 'src/analysis')
from analysis.arch_symbol import (
    build_A_array_iparts_paper, tukey_hat, triangle_hat,
    heat_paper, a_paper, lipschitz_series
)

def fejer_weights(K: int) -> np.ndarray:
    w = np.ones(K+1, dtype=float)
    if K >= 1:
        w[1:K+1] = 1.0 - np.arange(1, K+1, dtype=float) / (K + 1)
    return w

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument('--B', type=float, default=1/3)          # ширина в η
    ap.add_argument('--t', type=float, default=3.0/50.0)     # paper baseline
    ap.add_argument('--kind', type=str, default='triangle', choices=['triangle','tukey'])
    ap.add_argument('--alpha', type=float, default=0.15)
    ap.add_argument('--M', type=int, default=256)
    ap.add_argument('--theta-grid', type=int, default=131072)
    ap.add_argument('--kplot-mult', type=int, default=8)
    ap.add_argument('--report-astar', action='store_true')
    args = ap.parse_args()

    K_plot = args.kplot_mult * args.M
    A = build_A_array_iparts_paper(B=args.B, t=args.t, Kmax=K_plot,
                                   kind=args.kind, alpha=args.alpha,
                                   grid_N=max(4096, 8*(K_plot+1)))

    # минимумы (paper-шкала)
    thetas = np.linspace(0.0, 2*np.pi, args.theta_grid, endpoint=False)
    ks = np.arange(1, len(A))
    P_raw = np.full_like(thetas, A[0], dtype=float)
    if len(ks):
        P_raw += 2.0 * (A[1:, None] * np.cos(ks[:, None] * thetas)).sum(axis=0)

    w = fejer_weights(K_plot)
    P_fej = np.full_like(thetas, A[0], dtype=float)
    if len(ks):
        P_fej += 2.0 * ((w[1:, None] * A[1:, None]) * np.cos(ks[:, None] * thetas)).sum(axis=0)

    amp_floor = A[0] - 2.0 * np.sum(np.abs(A[1:]))
    Lser = lipschitz_series(A)

    kappa = 2*np.pi/args.B

    print(f"B={args.B}, kind={args.kind}, t={args.t}")
    print(f"A0_paper={A[0]:.9f}")
    print(f"amp_floor_paper={amp_floor:.9f}")
    print(f"min P_A(raw)_paper={P_raw.min():.9f}")
    print(f"min P_A^Fej_paper={P_fej.min():.9f}")
    print(f"L_series_paper={Lser:.9f}   A0_paper - π L_series_paper = {A[0]-np.pi*Lser:.9f}")
    if args.report-astar:
        print(f"(a⋆) multiply by κ={kappa:.9f}:  A0*={A[0]*kappa:.9f}, "
              f"amp_floor*={amp_floor*kappa:.9f}, min_raw*={P_raw.min()*kappa:.9f}, "
              f"min_fej*={P_fej.min()*kappa:.9f}")

if __name__ == '__main__':
    main()
```

## 1) Что именно утверждаем (быстрый путь)

Для фиксированных параметров профиля и размера матрицы \(M\) мы строим
\[
G(\theta)=P_A^{\text{Fej}}(\theta)-S_M(\theta),\qquad \theta\in[-\pi,\pi),
\]
и задаём его **косинусным рядом**
\[
G(\theta)=\widehat g_0+2\sum_{k=1}^{K_c}\widehat g_k\cos(k\theta),
\]
так что **Toeplitz** \(T_M[G]=(\widehat g_{i-j})_{i,j=0}^{M-1}\) является эрмитовой матрицей. По стандартному факту (Герглотц–Бохнер/Фежер–Рис): если \(G(\theta)\ge 0\) на всём \([-\pi,\pi]\), то все конечные усечки \(T_M[G]\succeq 0\).

Мы сертифицируем неотрицательность \(G\) **по сетке** с Липшиц‑коррекцией:
\[
\delta_{\text{cert}}
=\min_{\theta\in \Theta_Q}G(\theta)\;-\;\frac{\pi}{Q}\,L_G,
\quad
L_G:=\sup_{\theta}|G'(\theta)|
\le 2\sum_{k=1}^{K_c}k\,|\widehat g_k|.
\]
Здесь \(\Theta_Q=\{2\pi j/Q\}_{j=0}^{Q-1}\).
Если \(\delta_{\text{cert}}>0\), то \(G(\theta)\ge \delta_{\text{cert}}>0\) на всём круге, а значит \(T_M[G]\s \,0\).

## 3) Мини‑валидатор (что делает проверяющий)

Любой проверяющий (без твоего кода) должен уметь:

1) Прочитать JSON и восстановить \(G(\theta)\) **на сетке** \(\Theta_Q\) из \(\widehat g_k\):

2) Взять минимум по сетке \(m=\min_{\Theta_Q}G\).

3) Посчитать \(L=2\sum_{k=1}^{K_c}k|\widehat g_k|\) и \(\delta=m-(\pi/Q)L\).

4) Сверить, что `delta_cert` из файла совпадает (с допуском численной точности) и \(\delta>0\).

5) (Опционально) убедиться, что построенный **Toeplitz** из \(\widehat g_k\) действительно PSD (например, проверить, что все собственные значения \(T_M[G]\) неотрицательны с запасом \(\ge \delta_{\text{cert}}/2\); это не требуется логически, но приятно для sanity‑check).

## 4) Интервальный режим (надёжная версия)

Если захочешь «железобетон»:

- Храни \(\widehat g_k\) как интервалы \([a_k^{-},a_k^{+}]\) (MPFI/Arb), а не как float.  
- Тогда
  \[
  L_{\text{upper}}\;=\;2\sum_{k\ge1}k\cdot\max\{|a_k^{-}|,|a_k^{+}|\},

  а для каждого узла \(\theta_j\) считаете интервальное значение \(G(\theta_j)\); берёте минимум **нижних** концов \(m_{\text{lower}}\).
