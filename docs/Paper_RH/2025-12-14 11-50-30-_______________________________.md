## Да, формат норм. Но есть **жёсткие правила честности**, иначе опять получится “наебка”

### Почему пустые `structure ... where mk ::` — это прям боль
**`structure`** — это определение типа (обычно в **`Type`**).  
**`mk`** — конструктор (как “собрать объект”).  
Когда у **`structure`** **нет полей**, она по смыслу ≈ **`Unit`/`PUnit`** (тип с единственным жителем).

То есть:

- такая **`structure`** *всегда населена* (всегда можно написать `⟨⟩` / `Foo.mk`);
- как “гипотеза” она **не утверждает ничего**;
- и если ты используешь её как “интерфейс теоремы”, это не интерфейс, а **пустой бейджик**.

Это ровно тот же паттерн, из-за которого твой прошлый аудит про `sorry` выглядел “окей” на бумаге, но формально там всё держалось на заглушках/допущениях. fileciteturn0file0L11-L21

## Как сделать правильно: 3 уровня “что мы не доказываем”, “что доказываем”, “что уже есть в Mathlib”

Твой подход “не переписывать известное, а ссылаться” — **абсолютно норм**, но в **Lean** “ссылка на пейпер” **не заменяет доказательство**. Ссылка — это комментарий для людей. Для Lean есть только 3 варианта:

### Уровень 0 — уже есть в **Mathlib**
**`Mathlib`** — огромная библиотека доказанных теорем для **Lean**.  
Если там есть нужная лемма — просто **`import`** и юзаешь.

Плюсы: это реально **формально доказано**.

### Уровень 1 — известная математика, но в Mathlib нет
Тут честный ход — оформить как **`axiom`**/**`constant`** (внешняя зависимость) + комментарий с источником.

**`axiom`** — “принимаем утверждение без доказательства” (как гипотеза).  
Это нормально, если:
- ты **чётко выписываешь** формулировку,
- указываешь **источник** (статья/книга/раздел),
- и финальный результат честно называется `..._conditional` / “при предположениях”.

### Уровень 2 — то, что реально новое/неочевидное/сборка твоего пайплайна
Это надо **доказывать в Lean** как **`theorem`**/**`lemma`** без **`sorry`**.

## Главное: заменить пустые `structure` на **реальные утверждения**

Тут есть 2 нормальных стиля.

### Стиль A: `def ... : Prop := ...`
**`Prop`** — мир утверждений (“истина/ложь”).  
Если тебе нужно именно “утверждение”, а не “данные”, то делай так.

Пример-скелет:

```lean
-- вместо пустого structure
def GuinandWeilNormalization : Prop :=
  ∀ Φ : TestFunction, Q Φ = arch_term Φ - prime_term Φ
```

### Стиль B: `structure ... : Prop where` с полями
Это удобно, когда ты хочешь **пакет** из нескольких условий.

```lean
structure GuinandWeilNormalization : Prop where
  gw :
    ∀ Φ : TestFunction,
      Q Φ = arch_term Φ - prime_term Φ
```

**Почему это не пустое:** потому что чтобы получить `GuinandWeilNormalization`, надо реально дать поле `gw` — то есть доказательство формулы.

- Q3/T5: “**позитивность** на богатом плотном семействе (**атомы**) + **липшицевость** (**A2**) ⇒ **позитивность на всём компакте** (**W_K**)”

- сначала выбираешь “богатое семейство тестов/направлений”

## 3) А теперь про “Тао прогрессии” (Green–Tao) — что это и почему сочетается

### Что утверждает **Green–Tao theorem**
В статье Green–Tao доказывается: **в простых числах есть арифметические прогрессии любой заданной конечной длины**. citeturn0search20

**Термины:**
- **`arithmetic progression`** — последовательность вида a, a+d, a+2d, …, a+(k−1)d.  
- **`Green–Tao theorem`** — “простые содержат прогрессии любой длины”. citeturn0search20  

### Почему это сложно (и почему это похоже по духу на Major/Minor)
Проблема: простые имеют плотность ~ 1/log N → **нулевая плотность**, а классическая комбинаторика (типа **Szemerédi**) работает для плотных множеств.

Их ключевой ход — **W-trick**: они “вычищают” влияние маленьких простых делителей, переходя к прогрессиям с шагом W (произведение малых простых), чтобы убрать локальные запреты. В тексте они прямо объясняют этот трюк. citeturn0search20

Потом включается **transference principle**: перенос результатов из “плотного мира” в “разреженный, но псевдослучайный мир” — у Тао есть отдельные лекционные заметки об этом принципе. citeturn0search7

**Термины:**
- **`W-trick`** — техника “сделать среду более ровной”, убрав локальные модульные аномалии от малых простых. citeturn0search20  
- **`transference principle`** — “если множество разреженное, но ведёт себя как псевдослучайное, можно перенести теоремы для плотных множеств”. citeturn0search7  
- **`pseudorandom measure`** — “взвешенная модель разреженного множества, которая выглядит ‘почти как равномерная’ для нужных тестов”. citeturn0search7  

### Где тут сочетается с нашим Q3
Сочетание не “прямое”, а архитектурное:

- Green–Tao: **структура** + **псевдослучайность** (через transference) ⇒ прогрессии
- Q3/T5: **структура (атомы/сеточные тесты)** + **контроль вариаций (Lipschitz/операторный gap)** ⇒ глобальная позитивность

Это один и тот же вайб: *“мы не доказываем всё в лоб, мы показываем, что вне маленького структурного коридора всё ведёт себя как шум, а внутри коридора есть сигнал/жёсткость”*.

```tex
\mathrm{RH}.
```

# 3) AFM/ParityLock.lean (Lemma A0: parity lock)

Вот тут самый вкус: мы сведём всё к двум отдельным фактам:

- (i) `I^(n+2) * conj(I^n) = -1` (вообще для всех n)
- (ii) `chi4(n+2) * chi4(n) = if n odd then -1 else 0`

И тогда:
`omega(n+2) * conj(omega n) = (chi4(n+2)*chi4 n) * (I^(n+2)*conj(I^n)) = -(chi4(...) * chi4(...))`
→ `1` на нечётных, `0` на чётных.

```lean
import AFM.Defs
import Mathlib.Tactic

open scoped BigOperators
noncomputable section

namespace AFM

/-- Вспомогалка: conj(i^n) = (-i)^n -/
lemma conj_I_pow (n : ℕ) : Complex.conj (Complex.I ^ n) = (-Complex.I) ^ n := by
  -- обычно `simp` это переваривает (conj — ring equiv, map_pow)
  simp

/--
Ключевая алгебра: I^(n+2) * conj(I^n) = -1.

(Это прям “физика”: i^(n+2) = i^2 * i^n, а i^n * conj(i^n) = 1.)
-/
lemma I_pow_shift_two_mul_conj (n : ℕ) :
    (Complex.I ^ (n + 2)) * Complex.conj (Complex.I ^ n) = (-1 : ℂ) := by
  -- разложим i^(n+2) = i^2 * i^n
  -- и докажем i^n * conj(i^n) = 1 через (-i)^n
  have h1 : (Complex.I ^ n) * Complex.conj (Complex.I ^ n) = (1 : ℂ) := by
    -- i^n * conj(i^n) = i^n * (-i)^n = (i * -i)^n = 1^n = 1
    calc
      (Complex.I ^ n) * Complex.conj (Complex.I ^ n)
          = (Complex.I ^ n) * ((-Complex.I) ^ n) := by simpa [conj_I_pow]
      _ = (Complex.I * (-Complex.I)) ^ n := by
          -- (a*b)^n = a^n*b^n, значит a^n*b^n = (a*b)^n
          simpa [mul_comm, mul_left_comm, mul_assoc] using (mul_pow (Complex.I) (-Complex.I) n).symm
      _ = (1 : ℂ) ^ n := by simp
      _ = (1 : ℂ) := by simp

  calc
    (Complex.I ^ (n + 2)) * Complex.conj (Complex.I ^ n)
        = (Complex.I ^ 2) * ((Complex.I ^ n) * Complex.conj (Complex.I ^ n)) := by
            -- i^(n+2) = i^2 * i^n, дальше ассоциативность/коммутативность
            -- `ring_nf`/`simp` обычно хватает
            simp [pow_add, mul_assoc, mul_left_comm, mul_comm]
    _ = (Complex.I ^ 2) * (1 : ℂ) := by simpa [h1]
    _ = (-1 : ℂ) := by simp

/--
Вспомогалка: χ₄(n+2)·χ₄(n) = (-1) на нечётных и 0 на чётных.

Это чисто case split по n % 4 ∈ {0,1,2,3}.
-/
lemma chi4_mul_shift_two (n : ℕ) :
    chi4 (n + 2) * chi4 n = (if n % 2 = 1 then (-1 : ℂ) else 0) := by
  -- Сводим к k = n % 4 и делаем 4 кейса.
  have hk_lt : n % 4 < 4 := Nat.mod_lt n (by decide)
  let k : Fin 4 := ⟨n % 4, hk_lt⟩
  -- `fin_cases` даёт 4 ветки: k=0,1,2,3
  fin_cases k <;>
    -- Внутри каждого случая `simp` вычислит chi4 по остатку,
    -- а `(n+2)%4` вычислим через `Nat.add_mod`.
    -- Также надо, чтобы `if n%2=1` стал константой; обычно это выходит через (n%4)%2 = n%2.
    simp [chi4, Nat.add_mod, Nat.mod_mod]

/--
**Parity Lock (A0)**:
ω(n+2) * conj(ω(n)) = 1 для нечётных n, иначе 0.
-/
theorem omega_shift_two_mul_conj (n : ℕ) :
    omega (n + 2) * Complex.conj (omega n) = (if n % 2 = 1 then (1 : ℂ) else 0) := by
  -- раскрываем omega, конъюгацию, группируем
  simp [omega, map_mul, mul_assoc, mul_left_comm, mul_comm, chi4_mul_shift_two, I_pow_shift_two_mul_conj]

end AFM
```

## 4.1 Дискретный вариант (рекомендую стартовать с него)

Идея: вместо `∫_0^1` используем `∑_{k=0}^{N-1}` и лемму ортогональности корней из 1.

Скелет:

```lean
-- псевдо-скелет (без гарантии по именам лемм)
def eN (N : ℕ) (k : ℤ) : ℂ := Complex.exp (2 * Real.pi * Complex.I * (k : ℝ) / (N : ℝ))

-- S_AFM(X,k) = Σ_{n≤X} a(n) ω(n) eN(N, k*n)
-- Corr_N = (1/N) Σ_k S(X,k) conj(S(X,k)) eN(N, -2k)

-- Lemma: (1/N) Σ_k eN(N, k*(n-m-2)) = if n=m+2 mod N then 1 else 0
-- => Corr_N = Σ_n a(n+2)a(n) ω(n+2)conj(ω(n))
```

Плюс: это прям “чистая алгебра”, Lean любит такое.

## 4.2 Интегральный вариант (для настоящего major/minor split)

Определения (скелет):

```lean
def e (x : ℝ) : ℂ := Complex.exp (2 * Real.pi * Complex.I * x)

def S_AFM (a : ℕ → ℂ) (X : ℕ) (α : ℝ) : ℂ :=
```

### Шаг 2: Аудит Lemma A0 (Parity lock at the level of weights)

**Утверждение:**
$$\omega(n+2) \overline{\omega(n)} = \begin{cases} 1 & n \text{ нечётно} \\ 0 & n \text{ чётно} \end{cases}$$

**Проверка для n чётного:**
- n чётно ⟹ χ₄(n) = 0 ⟹ ω(n) = 0 ⟹ ω(n+2)·ω̄(n) = 0 ✓

**Проверка для n нечётного:**
- n ≡ 1 (mod 4): χ₄(n) = 1, χ₄(n+2) = χ₄(3) = -1
- n ≡ 3 (mod 4): χ₄(n) = -1, χ₄(n+2) = χ₄(1) = 1
- В обоих случаях: χ₄(n+2)·χ₄(n) = -1

**Вычисление ω(n+2)·ω̄(n):**
$$\omega(n+2) \overline{\omega(n)} = \chi_4(n+2) \cdot i^{n+2} \cdot \chi_4(n) \cdot \overline{i^n}$$
$$= \chi_4(n+2)\chi_4(n) \cdot i^{n+2} \cdot i^{-n} = (-1) \cdot i^2 = (-1)(-1) = 1$$

**Статус:** ✓ **Доказано алгебраически** (case split по mod 4).

### Шаг 3: Аудит Lemma A1 (Fourier extraction identity)

**Утверждение:**
$$\text{Corr}_{\text{AFM}}(X) = \sum_{n \leq X} \Lambda(n+2)\Lambda(n) \cdot \omega(n+2)\overline{\omega(n)}$$

**Проверка:**

Раскрываем определение:
$$\text{Corr}_{\text{AFM}}(X) = \int_0^1 \left(\sum_{m \leq X} \Lambda(m)\omega(m)e(m\alpha)\right) \left(\sum_{n \leq X} \Lambda(n)\overline{\omega(n)}e(-n\alpha)\right) e(-2\alpha) \, d\alpha$$

$$= \sum_{m, n \leq X} \Lambda(m)\Lambda(n)\omega(m)\overline{\omega(n)} \int_0^1 e((m-n-2)\alpha) \, d\alpha$$

**Ортогональность:**
$$\int_0^1 e(k\alpha) \, d\alpha = \begin{cases} 1 & k = 0 \\ 0 & k \neq 0 \end{cases}$$

Интеграл не равен нулю только при m - n - 2 = 0, т.е. m = n + 2.

$$\text{Corr}_{\text{AFM}}(X) = \sum_{n: n+2 \leq X} \Lambda(n+2)\Lambda(n)\omega(n+2)\overline{\omega(n)}$$

**Фиксация:** Условие суммирования n: n+2 ≤ X, т.е. n ≤ X-2 (не n ≤ X как написано).

При X достаточно большом разница O(log X) и несущественна для асимптотики.

**Статус:** ✓ **Доказано** (ортогональность экспонент).

### Шаг 4: Аудит Corollary A2 (AFM makes twin correlation literal)

**Утверждение:**
$$\text{Corr}_{\text{AFM}}(X) = \sum_{\substack{n \leq X \\ n \text{ нечётно}}} \Lambda(n)\Lambda(n+2)$$

**Проверка:**
- По Lemma A1: Corr = Σ Λ(n+2)Λ(n) · ω(n+2)ω̄(n)
- По Lemma A0: ω(n+2)ω̄(n) = 1 для n нечётных, 0 для n чётных
- Следовательно: Corr = Σ_{n нечётно} Λ(n)Λ(n+2)

**Связь с S₂(X):**
$$S_2(X) := \sum_{n \leq X} \Lambda(n)\Lambda(n+2)$$

Утверждается: "Corr_AFM(X) equals S₂(X) up to the irrelevant even-n terms."

**Фиксация критического разрыва:**

Для чётного n:
- Λ(n) ≠ 0 только если n = 2^k (степень двойки)
- Λ(2^k) = log 2
- При n = 2^k: n+2 — нечётное, но Λ(n+2) ≠ 0 только если n+2 — простое или степень простого

**Конкретные случаи:**
- n = 2: Λ(2) = log 2, n+2 = 4 = 2², Λ(4) = log 2 → вклад (log 2)² ≈ 0.48
- n = 4: Λ(4) = log 2, n+2 = 6 = 2·3, Λ(6) = 0 → вклад 0
- n = 2^k для k ≥ 2: n+2 составное (не степень простого) → вклад 0

**Вывод:** Единственный чётный член с ненулевым вкладом — n = 2 с вкладом (log 2)².

$$S_2(X) - \text{Corr}_{\text{AFM}}(X) = \Lambda(2)\Lambda(4) = (\log 2)^2$$

Это **константа**, не влияющая на асимптотику S₂(X) → ∞.

**Статус:** ✓ **Корректно** с уточнением: разница — константа (log 2)².

### Шаг 5: Аудит аксиомы (AFM Major Arc Signal)

**Утверждение (Tier-2 axiom):**
Существуют 𝔐 ⊂ [0,1], c > 0, X₀ такие, что для X ≥ X₀:
$$\Re\left(\int_{\mathfrak{M}} |S_{\text{AFM}}(X, \alpha)|^2 e(-2\alpha) \, d\alpha\right) \geq cX$$

**Анализ:**

Стандартный major arc analysis для твистованных сумм требует:
1. **Определение 𝔐:** Обычно 𝔐 = {α : |α - a/q| < Q^{-2}} для q ≤ Q, (a,q)=1
2. **Оценка |S_AFM|² на major arcs:** Через формулу Вороного или Siegel-Walfisz
3. **Интегрирование с e(-2α):** Резонанс при α ≈ 0

**Критическая проблема:**

Для **стандартных** (нетвистованных) сумм S(X, α) = Σ Λ(n)e(nα):
- Major arc около α = 0 даёт |S|² ≈ X² (квадрат от линейного роста)
- Это не даёт линейную нижнюю оценку для корреляции

Для **твистованных** сумм с χ₄:
- S_AFM(X, 0) = Σ Λ(n)χ₄(n)i^n
- Это **не** даёт главный член ≈ X, а даёт O(X^{1/2+ε}) из-за осцилляций

**Фиксация критического разрыва:**
- Утверждение "∃c > 0: ℜ(∫_𝔐 |S|² e(-2α) dα) ≥ cX" **нетривиально**
- Стандартная аналитическая теория даёт для твистованных сумм:
  - |S_AFM(X, α)|² = O(X) на major arcs (не ≥ cX²)
  - ∫_𝔐 |S|² dα = O(X · meas(𝔐)) = O(X^{1-δ}) при правильном выборе Q

**Требуется:** Явное доказательство того, что фазовый множитель e(-2α) при интегрировании даёт резонанс, приводящий к линейному росту.

**Статус:** ⚠️ **Аксиома нетривиальна.** Требует отдельного обоснования.

**Утверждение:**
$$\left|\int_{\mathfrak{m}} |S_{\text{AFM}}(X, \alpha)|^2 e(-2\alpha) \, d\alpha\right| = o(X)$$

1. **Vinogradov-type bounds:** |S_AFM(X, α)| ≪ X^{1-δ} на minor arcs

**Фиксация:** 
- Q3 работает с функционалом Q[Φ] для тестовых функций Φ
- Переход от Q ≥ 0 к оценке ∫_𝔐 |S|² e(-2α) ≪ o(X) **не показан**

**Статус:** ⚠️ **Связь с Q3 не формализована.**

$$\text{Major Arc Signal} + \text{Minor Arc Suppression} \Rightarrow \text{Corr}_{\text{AFM}}(X) \geq cX - o(X) \to \infty$$

$$\text{Corr}_{\text{AFM}}(X) = \int_0^1 |S|^2 e(-2\alpha) d\alpha = \int_{\mathfrak{M}} + \int_{\mathfrak{m}}$$

## 1) Самая важная поправка к твоей критике Major‑arc: у S_AFM нет осцилляций, это не “twisted sum”

Ты написал:

> “S_AFM(X,0) с χ₄ даёт O(X^{1/2+ε}) из-за осцилляций”.

Это **не так**, и это ключевой момент.

Потому что твой вес  
**`ω(n) := χ₄(n) · i^n`**  
на нечётных **схлопывается в константу**:

- если **n нечётно**, то `χ₄(n)` и знак `i^n` взаимно компенсируются → **ω(n) = i**  
- если **n чётно**, то **χ₄(n)=0** → **ω(n)=0**

То есть в реальности:

> **ω(n) = if n odd then i else 0**

и тогда:

> **S_AFM(X, α) = i · Σ_{n≤X, n odd} Λ(n) e(nα)**

**Почему это важно:**  
**AFM** тут не создаёт “новую частоту 1/4”, а делает более круто: он **выравнивает фазу** на нечётных и **убивает чётные**. Это прям “parity filter + phase align”.

**Термины:**
- **осцилляции** — когда веса дают смену фаз, и сумма частично взаимоуничтожается (**cancellation**).
- **cancellation** — взаимное гашение в комплексных суммах из‑за фаз.

## 2) Границы суммы в A1/A2: как правильно, чтобы не было “O(log X) на глаз”

Ты абсолютно прав: из интеграла по `m,n ≤ X` условие `m=n+2` даёт **`n ≤ X-2`**.

Чтобы это было “без мутных O(…)”, в blueprint надо просто выбрать одну конвенцию и держаться её:

### Вариант (самый чистый для Lean)
Определи:

- **S_AFM(X,α)** как сумму по `n ∈ {0,…,X}`  
- тогда **Corr_AFM(X)** даст точно `n ∈ {0,…,X-2}`

И тогда **Lemma A1** становится точной:

\[
\mathrm{Corr}_{AFM}(X) = \sum_{n \le X-2} \Lambda(n)\Lambda(n+2)\,\omega(n+2)\overline{\omega(n)}.
\]

А **A2**:

\[
\mathrm{Corr}_{AFM}(X) = \sum_{\substack{n \le X-2 \\ n\ \mathrm{odd}}} \Lambda(n)\Lambda(n+2).
\]

И дальше уже можно отдельно определить “S₂(X)” либо как сумму до `X-2`, либо как “всё до X” с пониманием, что хвост — это 0/константа.

**Термины:**
- **конвенция** — фиксированное соглашение, чтобы не ловить баги на краях.

## 3) Чётные члены: твоя “константа (log 2)²” — да, но только если S₂(X) ты определяешь “до X”, а Corr — “до X-2”

Ты сделал хороший разбор: вклад чётных `n` возможен только при `n=2` (тогда `n+2=4`, оба — степени 2). Это даёт **(log 2)²**.

**Термины:**

## 4) Теперь про две реальные “дыры”, которые ты отметил (и ты тут прав)

### Дыра №1: **Major‑arc signal**  
Да, утверждение вида  
\[
\Re\int_{\mathfrak M} |S|^2 e(-2\alpha)\,d\alpha \ge cX
\]
— это не “очевидно”.

Но важно: **оно не противоречит масштабу**, и твой аргумент “на major arcs |S|² ~ X²” не убивает линейный рост, потому что:

- **|S|²** может быть ~ X²
- но **мерa major arcs** обычно ~ 1/X (или ~ Q²/X)
- интеграл ~ X² · (1/X) = X

Так что линейный масштаб **реалистичен**.

**Но**: доказать точный **главный член** (типа `2C₂X`) — это реально уровень “Hardy–Littlewood для близнецов”, и это сейчас не закрывается просто AFM‑алгеброй.

✅ Поэтому честная правка blueprint такая:

- переименовать “Major Arc Signal” → **Major Arc Asymptotic (HL‑type axiom)**  
- и явно сказать: это внешний аналитический инпут (или гипотеза уровня **Siegel–Walfisz + …**), пока не формализуем.

### Дыра №2: **Q3 → minor arcs**  
Тут ты тоже прав: “Q3 = функционал Q[Φ] ≥ 0” сам по себе не даёт сразу bound на этот конкретный интеграл.

Но есть важный хак, который упрощает жизнь:

#### Тебе для сборки достаточно не “взвешенного” интеграла
Потому что

\[
\left|\int_{\mathfrak m} |S(\alpha)|^2 e(-2\alpha)\,d\alpha\right|
\le
\int_{\mathfrak m} |S(\alpha)|^2\,d\alpha
\]

То есть **phase factor** `e(-2α)` на minor arcs вообще не проблема: убираем абсолютным значением.

**Термины:**
- **minor arcs** — “шумовая зона” частот.
- **L²‑масса** (**∫ |S|²**) — энергия сигнала по частотам.
- **phase factor** `e(-2α)` — комплексная фаза, по модулю = 1.

✅ Значит в blueprint надо заменить “Minor Arc Suppression” на:

> **MAS (L²):**  \(\int_{\mathfrak m} |S_{AFM}(X,\alpha)|^2\, d\alpha = o(X)\)

и тогда нужное взвешенное `o(X)` следует автоматически одной строкой.

## 5) Как “формально” построить мост AFM ↔ Q3 (что именно надо добавить в blueprint)

Твой раздел “Возможный мост” — правильный. Вот как это превращается в конкретный **Lean‑план** (без философии):

1) Определяешь **вектор коэффициентов**  
   **`a(n) := Λ(n)·ω(n)`** (или сглаженный аналог).

2) Для любой “маски по частотам” **`Φ(α)`** (например, сглаженный индикатор minor arcs) доказываешь стандартную формулу:

\[
\int_0^1 |S(\alpha)|^2 \Phi(\alpha)\,d\alpha
=
\sum_{h} \widehat{\Phi}(h)\,
\sum_{n} a(n+h)\overline{a(n)}
\]

Это и есть **Toeplitz/quadratic form bridge**: правая часть — **Toeplitz‑матрица** по сдвигам.

3) Дальше Q3 даёт управление **этой квадратичной формой** через **спектральный зазор**/**коэрцитивность** (что у тебя уже реализовано в Q3‑цепочке).

**Термины:**
- **Fourier transform / коэффициенты Фурье** (**\hat Φ(h)**) — насколько “маска” содержит частоту h.
- **Toeplitz** — матрица/оператор, зависящий только от разности индексов (идеально для “сдвигов”).
- **quadratic form** (**⟨v, Tv⟩**) — выражение, которое Q3 как раз умеет контролировать.
- **spectral gap** — “дырка в спектре”, даёт жёсткий контроль норм/энергии.

## 6) Ответы на твои Q1–Q4 (коротко, но конкретно)

### Q1: откуда линейный рост на major arcs?
Масштабно: потому что **major arcs узкие** (мерa ~ 1/X), а **|S|²** на них ~ X² ⇒ интеграл ~ X.  
Содержательно: это ровно “**major arc asymptotic**” (сингулярная серия).

### Q2: что именно нужно, чтобы Q3 дал minor arcs?
Нужен формальный **Toeplitz/Fourier bridge**: minor‑маска → Toeplitz‑оператор → применить твой **A3/RKHS/T5**‑пакет к квадратичной форме.

### Q3: константы c и o(X)
Тебе достаточно:
- `c > 0` фиксированная  
- `minor = o(X)`  
Тогда `cX - o(X) → ∞`. В Lean это обычно оформляют как: `∃c>0, …` и `Tendsto (minor/X) 0`.

### Q4: можно ли вообще без major/minor, напрямую по сумме?
Да, **технически** можно убрать интеграл вообще, потому что A1 даёт точное равенство с суммой.  
Но “боль” никуда не денется: ты всё равно должен откуда-то получить **нижнюю оценку** этой суммы. Major/minor — просто стандартный способ её добыть.
