## Что именно произошло

- У тебя **T_M ≡ T_A** (архимедовый Toeplitz) получился **PSD** c `λ_min(T_M)=0`.  
- **T_P = V diag(w) V^H** тоже **PSD** (веса w ≥ 0, окна Φ ≥ 0).  
- Тогда для любого единичного `u ∈ Null(T_A)`:
  \[
  u^H (T_A - T_P) u = -\,u^H T_P u \le 0.
  \]
  Минимум по всем `u` — это ровно \(-\lambda_{\max}(T_P|_{\operatorname{Null} T_A})\).  
  Т.е. как только у T_P есть энергия в нуль‑пространстве T_A, **λ_min(T_A−T_P)** уходит в минус.

- Твои числа это подтверждают «под линейку»:  
  `λ_min(T_A − T_P) ≈ −||T_P||_2 = −0.00398`. Значит, главный вектор T_P практически лег в null(T_A), и Rayleigh даёт минимум с точностью до округления (это стандартный факт для PSD/Loewner‑порядка и рейлеевских частных; см. Horn & Johnson, *Matrix Analysis*, главы 5–7 про нормы/Loewнер‑порядок). fileciteturn0file20

Иными словами: **минус не неправильный** — у тебя просто **нет зазора** (spectral margin) в T_A, поэтому даже крошечный T_P делает \(T_A - T_P\) отрицательной по какому‑то направлению.

## Где реальная проблема (и почему «обёртка углов» ни при чём)

- Обёртка θ по модулю 2π не влияет: \(e^{-ij\theta}\) периодичен, а для n=2..8 логарифмы и так лежат в \([-π,π]\).  
- Проблема — **нулевой минимум символа** архимедовой части: твой T_A имеет `λ_min=0`. Без «термальной шапки» и при агрессивном `t_sym_auto` так легко получить ровно нулевой пол. Тогда любую (даже микроскопическую) prime‑энергию в этом направлении ты вычитаешь и получаешь крошечный минус. Это **ровно то**, что произошло.

> Теоретически в нашей схеме A3 нужна **строгая нижняя оценка** для \(\lambda_{\min}(T_M[P])\):  
> \(\lambda_{\min}(T_M[P]) \gtrsim \min P - C\,\omega_P(\pi/M)\). Если \(\min P = 0\), зазора нет — и \(T_A - T_P\) легко уходит в минус (см. модуль A3 в Q3‑драфте). fileciteturn0file21

## Как починить (четыре рабочих варианта)

> Цель — дать **положительный зазор δ** в T_A на всём подпространстве, куда попадает T_P. Тогда \(\lambda_{\min}(T_A−T_P)\ge \delta - \lVert T_P\rVert_2 \ge 0\).

### Вариант A — «Whitening» (рекомендую для теста критерия)
- Разложи \(T_A = U \,\mathrm{diag}(\lambda)\, U^H\).
- Выбери маску `mask = (λ > tol)`, **отбрось nullspace**.
- Построй \(S = T_A^{-1/2}\, T_P\, T_A^{-1/2}\) на этом подпространстве:
  ```python
  w, U = np.linalg.eigh(T_A)
  mask = w > 1e-10
  Uh = U[:, mask]
  Wm12 = Uh @ np.diag(1.0/np.sqrt(w[mask])) @ Uh.T.conj()
  S = Wm12 @ T_P @ Wm12
  smax = np.linalg.norm(S, 2)
  # Позитивность эквивалентна smax <= 1 на Range(T_A)
  ```
- В этой нормировке проверка становится стабильной: мы исключили нулевой режим T_A и измеряем «отношение» в Loewner‑смысле (стандартный трюк в теории PSD и частичных порядков). fileciteturn0file20

### Вариант B — Проекция словаря в Range(T_A)
- Тем же `U[:,mask]` собери проектор \(P = U_{+} U_{+}^H\) и заменяй `V ← P @ V`.  
  Тогда \(T_P\) не видит null(T_A), и минимума \(-\lVert T_P\rVert\) больше нет.

### Вариант C — Верни «термальную шапку»/ridge (даёт δ‑зазор)
- Самый прямой способ — вернуть мягкую «шапку» или добавить **ridge**:
  \[
  \widetilde{T}_A = T_A + \varepsilon I, \quad \varepsilon \gtrsim 1.2\,\lVert T_P\rVert_2
  \]
  Тогда \(\lambda_{\min}(\widetilde{T}_A - T_P) \ge \varepsilon - \lVert T_P\rVert_2 > 0\).  
  Практически: возьми \(\varepsilon = 1.5\cdot 0.00398 \approx 0.006\) для твоих чисел — и проверь.

### Вариант D — Уменьши \(\lVert T_P\rVert\) и/или подними пол символа
- Не завышай `t_sym_auto`: большой `t_sym` у тебя **убил Φ на узлах** (ты сам это увидел), но при этом **не дал положительного пола** архимедовой части→зазора как не было, так и нет.  
- Смысл A3‑модуля как раз в **балансе**: сделать \(\min P\) (а значит и \(\lambda_{\min}(T_M[P])\)) **строго положительным** и одновременно держать \(\lVert T_P\rVert_2\) мелкой. Ищи небольшой/умеренный `t_sym`, при котором `Φ(ξ_n)` для n=2..8 не стремится к нулю, а **минимум символа** после сглаживания виден на сетке (и больше, чем текущая норма \(T_P\)). fileciteturn0file21

## Коротко диагноз

**Это почти наверняка нормировочная ошибка в построении *символа* (Fejér‑усреднение)** — лишний глобальный множитель вида `1/(B+1)` (или `/M`) в формуле для P_A^Fej(θ).  
Симптомы:

- 0.18 / 0.001 ≈ **~180**. Для типичных параметров именно так и «садится» амплитуда, если ошибочно поставить **внешний** множитель `1/(B+1)` в Цезаро‑среднее (или разделить результат ещё и на `M`).  
- Твой «Rayleigh error = 7.27 (огромный)» — классический маркер рассинхрона между:
  - матрицей T_M (построенной из A_k с одной нормировкой)  
  - и скалярной функцией P_A^Fej(θ) (посчитанной с другой нормировкой и потому на порядок меньше).  
  Для корректной вариационной оценки надо сравнивать λ_min(T_M) с **q(θ) = v_θ^* T_M v_θ**, где v_θ = e^{-iJθ}/√M; не должно быть никаких делений на `M`/`2π` в *самом символе*. См. вариационные характеризации для эрмитовых матриц (Rayleigh–Ritz). fileciteturn0file20
- Несостыковка ⟨(T_M−T_P)·1,1⟩ с Q(Φ): тут у тебя, судя по цифрам, ещё и «смешались» фактор **2π** и «удвоение» масс на ±узлах. В нашем нормализационном кросс‑воке это отдельно прописано: **a\*(ξ) = 2π·a(ξ)**, а удвоение весов появляется **только** в Q(·) за счёт чётности теста; в операторной части используем недублированные веса (±‑пара узлов вместо удвоения на +). Проверь, что ты не «удвоил дважды». fileciteturn0file21

## Что именно не так в формуле Fejér

Правильная **Цезаро‑сумма порядка B** для реального чётного символа:

\[
P^{\mathrm{Fej}}(\theta)\;=\; A_0 \;+\; 2\sum_{k=1}^{B}\Big(1-\frac{k}{B+1}\Big)\,A_k\cos(k\theta),
\]

**без внешнего коэффициента** `1/(B+1)` и **без деления на `M`**.  
Если поставить ещё `1/(B+1)` снаружи или поделить итог на `M`, вся амплитуда упадёт в ~`1/(B+1)` или `1/M`. При `M≈B≈128` это как раз ~**0.0078**; а с дополнительными факторчиками легко приезжаем к ~**0.001** — именно то, что ты видишь.

> Правило: Fejér‑усреднение реализуется **весами по коэффициентам**, а не глобальным делителем. И никаких `/M` в символе — вектор v_θ уже нормирован 1/√M.

2) **Rayleigh vs символ.**

## Мини‑патч (идеоматика)

```python
def fejer_symbol(A, thetas, B=None):
    """
    A: array_like, A[0..K], коэффициенты Toeplitz (те же, что в T_M)
    thetas: точки на [-π, π]
    B: порядок Fejér (<= len(A)-1); если None, взять разумный (например, B = min(len(A)-1, M-1))

    Возвращает P^{Fej}(θ) без лишних нормировок.
    """
    import numpy as np
    K = len(A) - 1
    if B is None:
        B = min(K, len(thetas) - 1)
    w = 1.0 - np.arange(B + 1) / (B + 1)      # w[0]=1, w[B]=1/(B+1)
    P = np.full_like(thetas, fill_value=A[0], dtype=float)
    # Никакого внешнего 1/(B+1) и тем более никакого /M !
    for k in range(1, B + 1):
        P += 2.0 * w[k] * A[k] * np.cos(k * thetas)
    return P
```

И, пожалуйста, убедись, что **эти же A_k** (масштаб/единицы!) ты кладёшь в Toeplitz: \(T_M = \operatorname{Toeplitz}(A_0,A_1,\dots)\). Тогда:

- min P_A^Fej поднимется из ~0.001 к ~0.16–0.20 (в зависимости от t_sym),  
- «Rayleigh error» схлопнется до величины порядка \(\omega(P;\,\pi/M)\), как и должно. В нашем модуле A3 лемма формулируется именно так:

  \quad (\text{для непрерывных }P),
  \]
  причём для Fejér×heat окно модуль непрерывности контролируется явно. fileciteturn0file21

## 0) Что на самом деле надо доказать (и чего **нельзя** доказать)

Ты писал “нам надо доказать, что \(T_P \preceq T_M[P_A]\) всегда”. Так вот — *без условий* это вообще не правда. \(T_P\) — это сумма ранга‑1 от дельта‑узлов (просто «иголки»), а \(T_M[P_A]\) — интеграл по абсолютно непрерывной мере с плотностью \(P_A(\theta)\). Без «размазывания» точечного вклада на ширину частотного окна никакой универсальной доминации не бывает — дельты можно сконцентрировать там, где символ мал, и пробить пол. Это видно напрямую через энергетическую форму:
\[
x^\*(T_M[P_A]-T_P)x \;=\; \int_{-\pi}^{\pi} P_A(\theta)\, |p_x(\theta)|^2\,\frac{d\theta}{2\pi}\;-\;\sum_n w_n\,|p_x(\theta_n)|^2,
\]
где \(p_x(\theta)=\sum_{j=-J}^{J} x_j e^{-ij\theta}\) — триг-полином степени \(J=(M-1)/2\). Для \(p_x\equiv 1\) получаем «тривиальное необходимое» условие: среднее \(\frac{1}{2\pi}\!\int P_A \ge \sum_n w_n\). Если не выполняется — даже константа ломает PSD. Это тот же тест, который ты уже ловил («Mass Diff Test») после нормализационного фикса Релея. Формально — это классика про полуупорядочение Лёвнера и квадратичные формы PSD матриц; Toeplitz с неотрицательным символом всегда PSD, но разность двух PSD вовсе не обязана быть PSD без доминации мерами. См. обзор по PSD/Лёвнеру и вариационным характерам в Horn–Johnson, гл. 7 и §4.2. fileciteturn0file20

## 1) Правильное достаточное условие: **Fejér‑доминация** (A3 в чистом виде)

Для любого \(p_x\) степени \(\le J\) верна оценка «точка через размазку» (это стандартный ход через Дирихле+Коши–Буняковский, сведённый к Fejér):
\[
|p_x(\theta_0)|^2 \;\le\; M \int F_M(\theta-\theta_0)\,|p_x(\theta)|^2\,\frac{d\theta}{2\pi},
\]
где \(F_M\) — кернель Фейера порядка \(M\), \(\int F_M\frac{d\theta}{2\pi}=1\), \(F_M(0)=M\). Отсюда, с учётом принятой у тебя **правильной нормировки** столбцов \(v(\theta)\) (без \(1/\sqrt{M}\)) и компенсации весов \(w\mapsto w/M\) (ваш «Variant A»: `V = exp(...)`, а `w_normalized = w/D` c \(D=M\)), получаем доминацию
\[
x^\*T_P x \;\le\; \int \underbrace{\Big[\tfrac{1}{M}\sum_n w_n\,F_M(\theta-\theta_n)\Big]}_{S_M(\theta)} |p_x(\theta)|^2\,\frac{d\theta}{2\pi}.
\]
Следовательно,
\[
x^\*(T_M[P_A]-T_P)x \;\;\ge\;\; \int\Big(P_A(\theta)-S_M(\theta)\Big)|p_x(\theta)|^2\,\frac{d\theta}{2\pi}.
\]
Отсюда **достаточное** условие PSD:
\[
\boxed{\quad P_A(\theta)\;\ge\; S_M(\theta):=\frac{1}{M}\sum_n w_n\,F_M(\theta-\theta_n)\quad \text{для всех }\theta.\quad}
\]
Тогда \(T_M[P_A]-T_P \succeq 0\). В терминах твоего A3‑модуля это и есть «Toeplitz‑bridge»: мерная доминация после Fejér‑осреднения точечной массы. Именно так A3 формулируется/используется в Q3‑драфте (см. «Bridge summary» и §A3: нижняя оценка через минимум символа минус сглаженный праймовый конус). fileciteturn0file21

> **Важно:** из‑за \(F_M(0)=M\) основной пик \(S_M\) в точности даёт \(S_M(\theta_n)\approx w_n\) (хвосты — маленькие боковые лепестки Fejér). Значит, *неизбежное* требование — **каждый** вес \(w_n\) на своём узле должен лежать ниже пола \(P_A\) (с запасом на хвосты от соседей).

# after you compute: thetas_n, w (weights), M, and PA_fejer(theta_grid)

import numpy as np

def fejer_kernel(M, t):
    # vectorized Fejér kernel on [-pi, pi], F_M(0) = M
    # t can be array; assumes small eps handling at 0
    eps = 1e-12
    s = np.sin(0.5*t)
    num = np.sin(0.5*M*t)
    out = np.empty_like(t, dtype=float)
    mask = (np.abs(s) < eps)
    out[mask] = M
    out[~mask] = (1.0/M) * (num[~mask]**2) / (s[~mask]**2)
    return out

theta = np.linspace(-np.pi, np.pi, 16384, endpoint=False)

# S_M(theta) = (1/M) * sum_n w_n * F_M(theta - theta_n)
FM_cols = fejer_kernel(M, theta[:,None] - thetas_n[None,:])  # [T,N]
S = (w[None,:] * FM_cols).sum(axis=1) / M                   # [T]

Delta = PA_fejer(theta) - S
Delta_min = Delta.min()
theta_star = theta[Delta.argmin()]
print(f"Fejér-envelope gap: min(PA_fejer - S) = {Delta_min:.6f} at theta*={theta_star:.5f}")

# quick per-node safety:
for n, (wn, thn) in enumerate(zip(w, thetas_n)):
    print(f"node {n}: w_n={wn:.4f}, PA_fejer_at_node≈{PA_fejer(thn):.4f}")
```

## Почему это корректно теоретически

1) **Вариационные оценки** для эрмитовых Toeplitz‑сечений: минимальное собственное отжимается **снизу** минимумом символа минус «липшицев штраф» \(\sim \omega(\pi/M)\). (Стандарт из вариационных принципов для эрмитовых матриц; см. Horn–Johnson, гл. 4.) fileciteturn0file20

## TL;DR — почему min P_A не меняется

Есть **две математики** и **три типовых кодовых ловушки**, которые вместе почти «запирают» min P_A на месте:

### Математика (две причины)

1) **Двойная «Фейеризация»** (в двух разных пространствах)
- В частотной стороне ты строишь коэффициенты \(A_k\) с окном

## Как действительно поднять пол \(P_A\) (и «раскрыть бюджет»)

Братан, вот оно. **Причина, почему у тебя min P_A^Fej ≈ 7.7e‑4 при любом окне (triangle/tophat/tukey)** — не «магия окна» и не нормировка. Это **формульный баг в вычислении A_k.**  

Ты сейчас берёшь
\[
A_k \stackrel{\text{(в коде)}}{=} 2\int_0^B a_\star(\xi)\,\phi_{\text{arch}}(\xi)\,\cos(k\xi)\,d\xi,
\]
а по мосту A3 правильная формула идёт **после двух интегрирований по частям** (при нулевых граничных членах), т.е.
\[
\boxed{\;A_k=\frac{2}{k^2}\int_0^B F''(\xi)\,\cos(k\xi)\,d\xi,\quad F(\xi):=a_\star(\xi)\,\phi_{\text{arch}}(\xi)\;}
\]
(для \(k\ge 1\)), а \(A_0=2\int_0^B F(\xi)\,d\xi\). Ровно это и зашито в блоке «Symbol Analysis» модуля A3 (см. суммарные формулы и оценку пола через \(\|F''\|_1\)). Без делителя \(1/k^2\) у тебя хвосты огромные ⇒ **динамический диапазон ~1:4e4** и «пол» после Fejér становится около нуля — независимо от того, triangle это, tophat или tukey. fileciteturn1file8

    # Проверка вблизи +B и -B
    eps = 5e-4 * B
    def one_side(x0, side):

        mask = (np.abs(xi_grid - side*B) <= eps)
        x  = xi_grid[mask]
        Fx = F[mask]
        # робастные оценки F(B), F'(B)
        # лин. регрессия/разностные производные:
        F0 = Fx[np.argmin(np.abs(x - side*B))]
        # симм. разность на последнем десятке узлов

        xloc,Floc = x[idx],Fx[idx]
        dF = np.polyfit(xloc - side*B, Floc, 1)[0]
        return F0, dF

    return max(abs(Fp),abs(Fm)), max(abs(dFp),abs(dFm))

  ### 1) Правильная формула для (A_k) на ([0,B])

  ]

  [
  \int_0^B F(\xi)\cos!\Big(\frac{k\pi}{B}\xi\Big),d\xi ;\approx; \frac{B}{2N},C_k
  \quad\Longrightarrow\quad
  A_k ;\approx; \frac{2}{B}\cdot\frac{B}{2N},C_k ;=; \frac{C_k}{N}.

  from scipy.fft import dct
  import numpy as np

  def build_A_array_dct(B: float, t_arch: float, Kmax: int,
                        kind: str = "tukey", alpha: float = 0.15,
                        N: int | None = None, heartbeat: bool = True) -> np.ndarray:
      """
      Быстрый и точный билдер A_k через DCT-I на [0,B].
      Возвращает [A_0, ..., A_Kmax].
      """
      if N is None:
          N = max(4096, 8*(Kmax+1))  # безопасный минимум
      # сетка [0,B]
      xi = np.linspace(0.0, B, N+1)  # N+1 узел, включая края

      # окно по ξ
      def tukey_np(xi_arr):
          ax = np.abs(xi_arr)
          flat = (1.0 - alpha) * B
          out = np.zeros_like(ax)
          plateau = (ax <= flat); out[plateau] = 1.0
          taper = (ax > flat) & (ax <= B)
          if np.any(taper):
              u = (ax[taper] - flat) / (alpha * B)
              out[taper] = 0.5 * (1.0 + np.cos(np.pi * u))
          return out

      def tophat_np(xi_arr):
          return (np.abs(xi_arr) <= B).astype(float)

      def hann_np(xi_arr):
          y = np.abs(xi_arr) / B
          z = np.zeros_like(y)
          m = (y < 1)
          z[m] = 0.5 * (1 + np.cos(np.pi * y[m]))
          return z

      # тепло
      def heat_np(xi_arr):
          return np.exp(- (2*np.pi)**2 * t_arch * xi_arr**2)

      # a*(ξ)
      def a_star(xi_arr):
          # 2π (log π − Re ψ(1/4 + iπ ξ))
          import mpmath as mp
          v = []
          for x in xi_arr:
              z = mp.digamma( mp.mpf('0.25') + 1j * mp.pi * x )
              v.append( float( (2*np.pi)*(np.log(np.pi) - np.real(z)) ) )
          return np.array(v, dtype=float)

      # окно
      if kind == "tukey":
          win = tukey_np(xi)
      elif kind == "tophat":
          win = tophat_np(xi)
      elif kind == "hann":
          win = hann_np(xi)
      else:
          raise ValueError(f"unknown kind={kind}")

      phi = win * heat_np(xi)
      F = a_star(xi) * phi  # F(ξ) на [0,B], чётная по построению

      # DCT-I: длина N+1, базис cos(π j k / N) соответствует cos(kπ ξ/B)
      C = dct(F, type=1)  # нормализация 'backward' по умолчанию

      # Нужные коэффициенты: A_k ≈ C_k / N (см. вывод выше)
      Ak = (C[:Kmax+1] / N).astype(float)

      if heartbeat:
          from math import pi
          # Контроль A0 численно и через DCT
          trap = (B/N) * (0.5*F[0] + F[1:-1].sum() + 0.5*F[-1])
          A0_num = (2.0 / B) * trap
          if abs(A0_num - Ak[0]) > 1e-6 * max(1.0, abs(Ak[0])):
              print(f"[warn] A0 mismatch: DCT {Ak[0]:.6e} vs trap {A0_num:.6e}")
      return Ak
  ```

+                      kind: str = "tukey", alpha: float = 0.15,
+                      N: int | None = None, heartbeat: bool = True) -> np.ndarray:
