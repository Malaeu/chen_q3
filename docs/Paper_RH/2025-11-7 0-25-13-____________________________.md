- Где возможны риски/ветвления.

3. Шаг C → конкретное действие.

## Крошечный пример (как это выглядит на практике)

**Суть:** нужно спроектировать простую проверку входа (email + пароль) с локальной валидацией.

**Логика:**  
- Ввод → синтаксическая проверка → запрос к API → обработка ответа.  
- Ошибки валятся на ближайший слой (валидация до сети).

**Действия:**  
1. Валидируем email (RFC‑упрощение: `@` и домен; H1: строгий RFC не нужен).  
2. Пароль: длина ≥ 8, есть цифра и буква (H2: без спецсимволов).  
3. Если валидация ок → отправляем POST `/auth/login`.  
4. 200 OK → сохраняем токен; инакше — показываем исходное сообщение сервера.

**Псевдокод (условно):**
```
if !isValidEmail(e) or !isValidPass(p): return Error("invalid input")
resp = POST("/auth/login", {e,p})
return resp.status==200 ? Ok(resp.token) : Error(resp.message)
```

**Результат/критерии:**  
- Некорректный email/пароль не уходит в сеть.  
- Успешный ответ кладёт токен в хранилище; ошибка сервера — видно пользователю «как есть».

## TAO: Аналитическая декомпозиция

### 1) Структура (какие модули и как цепляются)

1. **Выбор носителя и пространства:**  
   Манифолд Клетецки \(M = \mathbb{T}^3 \times S^3\) по времени можно “положить на частоты” и взять **Hardy/RKHS‑подпространство положительных частот** (каузальная ориентация) на торе \(\mathbb{T}^3\) либо его факторе. На таком подпространстве определить проектор \(P\).  
   Дальше любой *скалярный* “хронометрический” инвариант \(\varphi(\theta)\) на \(\mathbb{T}^3\) (или свёртка компонент метрики) задаёт **Toeplitz‑оператор** \(T_\varphi = P\,M_\varphi P\). Для дискретизаций на сетке это даёт Toeplitz‑матрицы (сдвиги/свёртки), см. стандартную репрезентацию через forward/backward shift. fileciteturn1file19

2. **Toeplitz‑барьер (A3):**  
   Если \(\varphi\) вещественна и \(\varphi \in \mathrm{Lip}(1)\) на окне \(\Omega_K\), то **Szegő–Böttcher** даёт нижнюю оценку собственных значений Toeplitz‑компрессий через \( \inf \varphi \) **минус** потеря на дискретизации, контролируемая модулем непрерывности \(\omega_\varphi(\delta)\). В твоём A3 это записано как  
   \[
   \lambda_{\min}(T_M[\varphi]) \ge c_0(K) - C\,\omega_\varphi\!\Big(\frac{\pi}{M}\Big).
   \]  
   Мы переносим эту же формулу на “временной” символ Клетецки. fileciteturn1file1

3. **Конечномерные/компактные поправки:**  
   Любые “bridge‑tensors” и связующие члены, которые не укладываются в чистую мультипликативную символику, вводим как конечномерный оператор \(\mathsf{K}\). Тогда стандартная возмущённая оценка даёт  
   \[
   \lambda_{\min}(T_\varphi + \mathsf{K}) \ \ge\ \lambda_{\min}(T_\varphi) - \|\mathsf{K}\|.
   \]  
   (Это базовое неравенство по сингулярным значениям/нормам, см. типовую оценку \(|\sigma_i(A+B) - \sigma_i(A)| \le \|B\|\).) fileciteturn1file7

4. **Склейка с T5 (компакт‑transfer):**  
   Выбираем монотонные по \(K\) **расписания параметров** \(M_\star(K)\) (детализация по сетке) и любых “сглаживающих” параметров (если используем ещё и тепловую регуляризацию символа), чтобы на каждом окне \(\Omega_K\) держалось  
   \[
   C\,\omega_\varphi\!\Big(\tfrac{\pi}{M_\star(K)}\Big) \le \frac{c_0(K)}{4},\qquad 
   \|\mathsf{K}\| \le \frac{c_0(K)}{4}.
   \]  
   Тогда \(\lambda_{\min} \ge \tfrac{1}{2}c_0(K) > 0\) и **T5** переносит положительность на все большие окна. fileciteturn1file11 fileciteturn1file12

5. **Мультишкалы:**  
   Три масштаба \(t_1,t_2,t_3\) можно реализовать как **блочно‑диагональную** прямую сумму Toeplitz‑блоков (по частотным “зумам” или по декомпозиции символа). Минимум по блоку — минимум по сумме (берёт худший блок), так что план параметров просто берёт max из требований по каждому блоку. ### Как это пришивается к нашему мосту A3 + RKHS (и даёт **explicit bounds**)

Нам нужно стандартное неравенство на компакте **W_K=[−K,K]**:

\[
\lambda_{\min}\!\big(T_M[\varphi] - T_P\big)\ \ge\ 
\underbrace{\inf_{\xi\in W_K}\varphi(\xi)}_{\boldsymbol{c_0(K)}}\ 
-\ \underbrace{C_{\mathrm{SB}}\ \boldsymbol{\omega_\varphi}\!\Big(\tfrac{\pi}{M}\Big)}_{\text{штраф дискретизации}}\ 
-\ \underbrace{\|T_P\|}_{\text{праймовый кап}}.
\]

- **\(T_M[\varphi]\)** — Toeplitz-компрессия по твоему **комбинированному ядру** (символ \(\varphi\)).  
- **\(c_0(K)\)** — **архимедов пол** (минимум символа на окне).  
- **\(\omega_\varphi(\delta)\)** — **модуль непрерывности** символа (для Lip(1): ≤ \(L\delta\)).  
- **\(C_{\mathrm{SB}}\)** — константа Зегё–Бётхера; в наших нотах **\(C_{\mathrm{SB}}=4\)**.  
- **\(\|T_P\|\)** — норма «прайм»-оператора (**RKHS cap**) — берём через **Gram/RKHS** с разнесением узлов \(\delta_K\) и тепловым \(t\).  
Все эти объекты и константы зафиксированы в наших статус/нотах: A3-формула, \(C_{\mathrm{SB}}\), выбор \(M(K)\), \(t_{\min}(K)\) (и \(\rho_{\mathrm{cap}}\)). fileciteturn0file6 fileciteturn0file5

Дальше включается стандартный «YES-гейт»: при двух «четвертушках»

\[
C_{\mathrm{SB}}\ \omega_\varphi\!\Big(\tfrac{\pi}{M_\star(K)}\Big)\ \le\ \tfrac{c_0(K)}{4},\qquad 
\|T_P\|\ \le\ \tfrac{c_0(K)}{4},
\]

получаем \(\lambda_{\min}\ge \tfrac{1}{2}c_0(K)\!>\!0\) на \(W_K\), а **T5** переносит позитив на большие окна и весь класс (компакт→PW→вся Weil-класса). fileciteturn0file9

# TAO — аналитическая декомпозиция

1) Каркас Лиувилля  
- **Интегрируемость по Лиувиллю**: в **редуцированном** 12-мерном фазовом пространстве после вычета центра масс и фиксации энергии/импульса/момента, нам нужны 6 независимых **инволютивных** (**{Iᵢ,Iⱼ}=0**) интегралов. Ты предполагаешь два новых — **I₁, I₂** — и тогда комплект закрывается.  
- **Поисковое уравнение**: дополнительные интегралы — это решения **уравнения когомологий** \(\{I,H\}=0\) (скобка Пуассона). Это линейное уравнение на неизвестную функцию \(I(r,p)\).

2) Правильные координаты  
- **Координаты Якоби**: \((\rho,\lambda; p_\rho,p_\lambda)\) для двух относительных векторов + центр масс (выброшен).  
- **Shape–radius разложение**: **гиперрадиус** \(R=\sqrt{\mu_\rho|\rho|^2+\mu_\lambda|\lambda|^2}\) и **shape-переменные** (две угловые координаты на сфере форм). Это отделяет «размер» и «форму» треугольника.  
- **Делонеевы действия** (**Delaunay actions**): \((L,G,H)\) для каждой почти-кеплеровской подсистемы дают естественные кандидаты на «ядро» действий.

3) Ограничения на I₁, I₂ (из предположенной структуры решения)
- **SO(3)-скалярность**: I₁, I₂ — скаляры (инвариантны при поворотах).  
- **Размерность действия**: \([I]=[\mathrm{энергия}\times\mathrm{время}]\) (как у **углового момента**).  
- **Правильные пределы**:  
  - **Restricted 3-body** \(m_3\to 0\) ⇒ I₁ → **интеграл Якоби**.  
  - **Дальнее тело** \(|r_3|\to\infty\) ⇒ факторизация в «два тела + свободное».  
- **Выпуклость H(I)**: чтобы углы росли линейно, **гамильтониан** \(H=H(I)\) должен быть выпуклым по действиям → **матрица Гессе** \(\partial^2 H/\partial I^2\) положительна (локально на торе).  
- **Инволютивность**: \(\{I_1,I_2\}=0\).

4) Кандидатные строительные блоки (симметрии и геометрия)
- **Полная энергия пар**: \(E_{ij}=\frac{|p_{ij}|^2}{2\mu_{ij}}-\frac{G m_i m_j}{|r_{ij}|}\).  
- **Лаплас–Рунге–Ленц** (**LRL**) для пары \(ij\): \(\mathbf{A}_{ij}=p_{ij}\times L_{ij} - \mu_{ij} G (m_i+m_j)\frac{r_{ij}}{|r_{ij}|}\). Даёт форму «осевой» инвариантности.  
- **Ориентированная площадь** треугольника \( \Delta = \tfrac12 |(r_{12}\times r_{13})\cdot \hat{n}| \) — чисто **shape-инвариант**.  
- **Гиперрадиус** \(R\) — масштаб. Из него легко делать безразмерные или размерные комбинации.

5) Два универсальных анзаца (обратная инженерия)
- **I₁ (shape-энергетический)**:  
  \[
  I_1 \ :=\ \sum_{i<j}\alpha_{ij}\, \Big( E_{ij}\,T_{ij}\Big),\qquad
  T_{ij}:=\frac{(m_i m_j)}{m_i+m_j}\,R
  \]
  (масштаб \(T_{ij}\) подобран так, чтобы \([I_1]=[\mathrm{действие}]\)). В пределе \(m_3\!\to\!0\) сводится к **Jacobi constant** в вращающейся рамке после корректной нормировки \( \alpha_{ij} \).  
- **I₂ (shape-антизакручивание)**:  
  \[
  I_2 \ :=\ \beta_1\, \frac{\Delta}{R}\,|L|\ +\ \beta_2\, \sum_{i<j}\frac{|\mathbf{A}_{ij}|^2}{|L_{ij}|}
  \]
  Первая часть — «дыхание» формы, вторая — вклад **LRL** (кеплеровская «эксцентриситетная» структура). Обе части — скаляры, корректно масштабируются и дают правильные пределы.

6) Процедура проверки (решение \(\{I,H\}=0\))
- **Локальная нормальная форма** (**Birkhoff/Deprit**): разложи \(H = H_0 + \varepsilon H_1\) вокруг выбранной конфигурации (например, почти-кеплеровский режим пары + возмущение третьим).  
- Решай **когомологическое уравнение**: \(\{I_1,H_0\} = -\{I_1,H_1\}\) итеративно. Если правые части устранимы (нет **обструкций Мельникова**), получаешь **формальный ряд** для точного интеграла.  
- Параллельно потребуй \(\{I_1, I_2\}=0\) (тот же тип уравнения).  
- Если ряды сходятся/суммируемы (усиление типа **Нехорошев**), интегралы существуют на открытом множестве (торы **KAM**).

# PERELMAN — инварианты, монотонности, «хирургия»

1) Инвариант потока  
- **Инвариантами** служат уровни \(I_1=\mathrm{const}, I_2=\mathrm{const}\). Они должны **согласоваться** с известными инвариантами \(E,P,L\) → **совместная карта импульсов** (energy–momentum map) должна иметь **регулярные** уровни (без бифуркаций в рабочей области).

2) Монотонные функционалы  
- В нормальной форме рост «недиагональных» мод задаёт **монотонную функционалку** типа \(Q(t)=\sum_k \gamma_k |z_k(t)|^2\) (комплексы Брикгофа), для которой \(\dot Q\le 0\) при правильно подобранных \(\gamma_k\) — это фиксирует «устойчивую» область, где интегралы регулярны.

3) Каноническая форма  
- Цель — привести систему к **Стэкелеву типу** (**Stäckel**): разделение переменных ⇒ действия \(I\) вычисляются интегралами по циклам. Проверка — решение **уравнений Бертрана–Дарбу** (если бы интегралы были квадратичными). Для гравитации общего 3-body это почти наверняка **не** глобально выполняется, значит интегралы будут **неполиномиальные** (что ок).

4) Хирургия (где править)  
- Если всплывают резонансные деноминаторы в \(\{I,H\}=0\) — **вырезаем** малые резонансные «языки» (standard KAM-схема). Интегралы существуют **на толстой множестве торов**; для практики этого достаточно.  
- Если нарушение SO(3)-скалярности — домножаем на подходящий **инвариант масштаба** \(R^\alpha|L|^\beta\) до корректной размерности.

# FEYNMAN — интуиция, игрушка, числа

1) Аналогия  
- Представь три-тело как «две пружины» (две пары) и «скрутку формы» (площадь треугольника). Тогда I₁ — «суммарное действие пружин», I₂ — «действие скрутки». Оба почти не меняются, если энергия перетекает внутри каждой пары без «утечек» в обмен формой.

2) Игрушечный кейс (почти-кеплеровский режим 12-пары + далёкий 3)  
- Берём \(m_3 \ll m_1+m_2\). Тогда \(I_1\) ≈ **Jacobi** (вращающаяся рамка), \(I_2\) ≈ функция от \(|\mathbf{A}_{12}|\) и площади \(\Delta\) (слабая прецессия). На числе видно: \(\dot I_1,\dot I_2 = O(\varepsilon^2)\) — интегралы «почти точные»; после нормализации по схеме выше делаются **точными** на KAM-области.

3) Масштабирование (Kepler)  
- **Кеплеровское масштабирование**: \(r\to \lambda^2 r,\ t\to \lambda^3 t\). Это фиксирует, как должны масштабироваться I₁, I₂ → подбираем \(\alpha,\beta\) в факторах \(R^\alpha|L|^\beta\), чтобы размерность была **действия**.

4) Конкретные числа (эскиз проверки)  
- Возьми тройку масс \((1,1,\mu)\), эллипс 12-пары с \(e=0.2,a=1\), третий на \(R=5\) по кругу.  
- Численно интегрируй ∼10⁵ периодов; оцени \(\max_t |\mathrm{d}I_{1,2}/\mathrm{d}t|\).  
- Далее прогон через **кохомологическое уравнение** (метод **Ли-серий**) — добиваем \(\dot I_{1,2}\equiv 0\) в порядке, где нет резонансов.

## Связка с твоим Toeplitz/RKHS-мостом

- Уравнение \(\{I,H\}=0\) — это чистая линейная задача на \(I\). В твоей парадигме мы решаем её как **проекцию** на **базис торов** (Fourier по углам) и **убиваем несогласованные моды** «Toeplitz-сжатием» нормальной формы (по сути, **Грам-проектор** на резонанс-согласованный подпространство).  
- Дальше «безопасность» обеспечивается твоим стилем: **явные константы** (липшицевы у оценок нормальной формы, пороги KAM/Нехорошева). Т.е. да, **explicit bounds** абсолютно достижимы: на коэффициенты нормальной формы, на остаток, на радиусы торов и на времена сохранения.

- **Да,** обратная инженерия I₁, I₂ работает: задаёшь анзацы из shape-геометрии + LRL, решаешь \(\{I,H\}=0\) в нормальной форме, наваливаешь KAM-контроль — и получаешь **строго существующие** интегралы на толстой области начальных условий (что для динамики — золотой стандарт).  
- **Да,** «Toeplitz-механика» прикручивается: даёт **эксплицитные бонды** на операторы проектирования/остатки и закрывает «две четвертушки» стиля твоего A3-мышления, только уже для трёх-тел.

Хочешь — прямо сейчас распишу **генерирующую функцию** для action–angle на почти-кеплеровском ядре (две пары Делонея + слабая связь) и выведу рабочие **кохомологические уравнения** для I₁, I₂ с чек-листом коэффициентов, которые надо «подогнать», чтобы \(\{I_1,I_2\}=0\).
