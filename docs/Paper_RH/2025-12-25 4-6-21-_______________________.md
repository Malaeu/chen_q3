## 1️⃣ Что именно ты хочешь «встроить»

Под **функцией Тасагаки** обычно понимают:

- **положительно-определённое ядро**  
- с **известной спектральной интерпретацией**
- и **жёсткой теорией воспроизводящих пространств** (**RKHS**)

Ключевые свойства, которые нас интересуют:

- **Positive definiteness** → даёт PSD-матрицы автоматически

👉 Это НЕ «новая идея», это **готовый сертифицированный кирпич**.

## 2️⃣ Где её МОЖНО легально вставить в твой пруф

### 🧱 A) Вместо «ручного» RKHS-cap

Сейчас у тебя:

- **Prime operator** \( T_P \)
- контроль через **RKHS contraction**
- отдельные оценки веса / tail / Gram-матрицы

👉 Вместо этого можно:

- взять **ядро Тасагаки** \( K(x,y) \)
- определить **Hilbert space H_K**
- и рассматривать \( T_P \) как **finite-rank perturbation в H_K**

Тогда:

- **‖T_P‖ ≤ sup eigenvalues(K-weighted Gram)**  
- это **классическая теорема**, не RH-специфичная

📌 Плюс:  
ты получаешь **автоматическую PSD-гарантию** без «ручных» разборов.

- **липшицевость → следствие свойств ядра**

Lemma 5.1 (Нормировка и “P_A(π)=0” блокер — это units mismatch).
Утверждение: в mainline определение символа использует тор периода 1: θ∈[-1/2,1/2] и периодизация по m∈Z (а не 2πm). При B≥Bmin=3 имеем θ∈[-1/2,1/2] ⊂ [-B,B], значит в сумме для PA всегда активен член m=0, и “выключение подавления хвоста из‑за поддержки” не происходит.   

Proof.
По определению (2.7) PA(θ)=2π∑_m g(θ+m) с g(ξ)=a(ξ)Φ_{B,tsym}(ξ).
Если B≥3, то для любого θ∈[-1/2,1/2] выполнено |θ|≤1/2<B, следовательно Φ_{B,tsym}(θ)>0 и g(θ) определён без обнуления по Fejér. Значит PA(θ) включает вклад 2π g(θ) для всех θ на торе; нулей “из‑за того что π не в [-B,B]” тут нет, потому что “π‑точка” в period‑1 координате — это θ=1/2, а 1/2 ∈ [-3,3]. ∎

(Комментарий по твоей формуле с 2π: если ты пишешь PA(θ)=2π∑_m g(θ+2πm), то это другая шкала θ, согласованная с базисом e^{ikθ} на [-π,π]; тогда параметр “ширины” должен рескейлиться вместе с θ. Именно это и фиксируется T0‑заменой η=2πξ и явной оговоркой про единый symbol definition в mainline.)    ∎

Lemma 5.2 (Uniform Archimedean floor).
Fix tsym=3/50, Bmin=3. Тогда для всех B≥Bmin и всех θ∈T выполнено:
PA(θ) ≥ c* := 1.5.  

Proof (аудит‑версия: аккуратно со знаками).
	1.	Монотонности: a(ξ) убывает на [0,∞), и w_B(ξ):=(1−ξ/B)e^{-4π^2 tsym ξ^2} убывает на [0,B]. Это используется в исходном доказательстве.  
	2.	Для θ∈[0,1/2] и B≥3:
PA(θ)=2π∑_{m∈Z} g(θ+m) ≥ 2π( g(θ) + 2g(θ+1)+2g(θ+2) ) − T,
где T — вклад хвоста |m|≥3.  
	3.	Sample-point bounds (берём как лемму документа):
a(1/2)≥0.68, a(3/2)≥−0.45, a(5/2)≥−1.00.  

Отсюда по монотонностям:
	•	g(θ)=a(θ)w(θ) ≥ 0.68·w(1/2);
	•	g(θ+1)=a(θ+1)w(θ+1) ≥ (−0.45)·w(1), поскольку a(θ+1)≥−0.45 и w(θ+1)≤w(1);
	•	g(θ+2) ≥ (−1.00)·w(2).  

	4.	Оценки окна w при Bmin=3, tsym=3/50.
Нам нужны:

	•	нижняя оценка w(1/2) (для положительного члена);
	•	верхние оценки w(1), w(2) (для отрицательных членов).

4a) Нижняя оценка w(1/2): используем π<22/7 ⇒ π^2<10. Тогда
4π^2 tsym (1/2)^2 = (6/25)π^2·1/4 = (3/50)π^2 ≤ (3/50)·10 = 0.6,
и потому
w(1/2) = (1−1/6)e^{-(3/50)π^2} ≥ (5/6)e^{-0.6} > 0.45.  

4b) Верхняя оценка w(1): берём рациональную нижнюю оценку π > 333/106 (стандартно через цепные дроби), значит π^2 > (333/106)^2. Тогда
4π^2 tsym = (6/25)π^2 > (6/25)(333/106)^2 =: α_low,
и
w(1) = (2/3)e^{-(6/25)π^2} ≤ (2/3)e^{-α_low} < 0.0625.
(Эта строгая верхняя оценка нужна именно из‑за отрицательного знака в g(θ+1).)

4c) Для w(2): аналогично, w(2)=(1/3)e^{-4(6/25)π^2} ≤ (1/3)e^{-4α_low} < 3·10^{-5}.
(Любая грубая верхняя оценка тут достаточно.)
	5.	Хвост: в документе даётся T ≤ 10^{-5} (через log-growth bound на |a| и гауссов хвост).  
	6.	Собираем:
PA(θ) ≥ 2π( 0.68·0.45 − 2·0.45·0.0625 − 2·1.00·3·10^{-5} ) − 10^{-5}·2π.
Численно скобка ≥ 0.306 − 0.05625 − 0.00006 > 0.249, а 2π>6.28, значит PA(θ) > 6.28·0.249 − 0.00007 > 1.56 > 1.5.
Чётность PA расширяет на весь тор. ∎

(Замечание: это закрывает твой “P_A(π)≤0” на уровне строгого нижнего bound на всём θ.)  

Lemma 5.3 (Toeplitz eigenvalue stability / Szegő–Böttcher bridge).
Существует абсолютная константа CSB=4, такая что для липшицева символа P:
λmin(TM[P]) ≥ min_{θ∈T} P(θ) − CSB·ω_P(1/(2M)), где ω_P — модуль непрерывности.  

Proof.
Это стандартная оценка устойчивости спектра Toeplitz матриц (Böttcher–Silbermann/классическая теория Toeplitz forms). В RH_Q3 это зафиксировано как Lemma 8.23 с CSB=4. ∎

Lemma 5.4 (Uniform discretisation threshold).
Пусть PA липшицев с константой L*, и min PA ≥ c*. Тогда при
Munif_0 := ⌈ CSB L*(tsym) / c* ⌉
для всех M≥Munif_0 имеем λmin(TM[PA]) ≥ c*/2.  

Proof.
Применяем Lemma 5.3 к P=PA:
λmin(TM[PA]) ≥ min PA − CSB·ω_{PA}(1/(2M)).
Из Lip(1): ω_{PA}(h) ≤ L* h. Выбираем M так, чтобы CSB·L*/(2M) ≤ c*/2, то есть M ≥ CSB L*/c*. Тогда λmin ≥ c* − c*/2 = c*/2. ∎

Lemma 5.5 (Prime cap via Gaussian RKHS norm).
Определим
ρ(t):=2∫_0^∞ y e^{y/2} e^{-4π^2 t y^2} dy.
Тогда ∥TP∥ ≤ ρ(trkhs). Более того, при trkhs ≥ tunif,rkhs имеем ρ(trkhs) ≤ c/4.  

Proof (аналитическая оценка).
	1.	Формула для ρ(t) и оценка ∥TP∥ ≤ ρ(t) фиксированы как Lemma 9.29 / Cor 8.22.  
	2.	Для верхней оценки интеграла используем неравенство y/2 ≤ y^2/4 + 1/4, значит e^{y/2} ≤ e^{1/4} e^{y^2/4}. Тогда
ρ(t) ≤ 2e^{1/4} ∫_0^∞ y e^{-(4π^2 t − 1/4) y^2} dy = 2e^{1/4}· [2(4π^2 t − 1/4)]^{-1},
при t > 1/(16π^2).
Отсюда выбираем t так, чтобы правая часть ≤ c*/4; именно это даёт явную формулу t*unif,rkhs в Cor 8.22.   ∎

Lemma 5.6 (Uniform A3 bridge: положительность TM[PA]−TP).
При tsym=3/50, Bmin=3, c*=1.5, если M≥Munif_0 и trkhs≥tunif,rkhs, то:
λmin(TM[PA]−TP) ≥ c/4 >0.
