# Одна формула стены — сводка ~65 батчей Прошке (13.08–29.10.2026)

Запрос владельца 29.10: «15 батчей — вокруг чего всё крутилось, во что упирается, нужны ли нули;
выведи одну формулу». Фактически батчей около 65. Метод: пять агентов-чтецов (только чтение), по одной форме на батч
(вопрос / доказано / убито / атом с локатором / нужны ли нули). Девять опорных цитат наблюдатель сверил сам
(раздел 6). DIAGNOSTIC; PX_RH_CLAIM: NOT_MADE. Связанный обзор: `docs/G3_OVERVIEW_2026-10-29.md`.

## 1. Формула

Точное тождество окна (батч LEAKAGE, 04.09, `routeB_bus/proshka/PROSHKA_VERDICT_GOAL058_WINDOW_WEIL_IDENTITY_AND_LEAKAGE_MECHANISM_2026-09-04.md:43`, `:360-382`;
статус CONFIRMED, чётный сектор, кратности учтены, ряд сходится абсолютно):

```
   ⟨v, K v⟩   =   Σ   F_v(z)²          сумма по всем z, где ζ(1/2 + i z) = 0
   ────────       ──────────────
   левая часть:    правая часть:
   матрица CCM,    нули дзеты
   считается из
   простых чисел
   и Γ-функции,
   БЕЗ нулей
```

Это формула явных сумм Вейля на окне. Слева — то, что мы умеем считать. Справа — нули.

- Если все z вещественны (RH), каждое слагаемое F_v(z)² ≥ 0, и левая часть неотрицательна.
- Если есть z вне прямой, слагаемые от пары z, z̄ дают 2·Re F_v(z)², и это может быть отрицательно.
  Прошка: «the zero-side pairing is indefinite off RH» (LEAKAGE:99-103).

**Отсюда круг.** Любой знак, который мы хотим доказать для левой части, по этому тождеству равен знаку правой.
А знак правой задают положения нулей. Доказать знак слева «только из простых» значит неявно доказать,
где лежат нули.

## 3. Что доказано без нулей и что это даёт

Агенты нашли проверяемые куски, которые не используют нули. Ни один не является открытым атомом,
который был бы и без нулей, и не равносилен RH.

- Сторона трала: асимптотика вытянутых функций (Satz 9 / Фукс), «RH_EQUIVALENT_INPUT_USED: false»
  (G3_RATE_FLOOR_SOURCE_RERANK_2026-08-30:81). Трал сходится к явному пределу без нулей. Сторона дна так не сказана нигде.
- Верхняя оценка T² (SATURATION 10.09, независимо проверена). Даёт верх, не знак.
- Положительность на коротких окнах с одним простым 2 (PROFILES, GAUGE, SCALARFLOOR). Конечные классы, до RH не дотягивают.
- Перельмановский ход уже сделан: SCREW 08.09 показал монотонную по окну величину λ_a (λ_b ≤ λ_a)
  с дихотомией λ_∞ = 0 (RH) или −∞ (не RH). Монотонность есть, но предел снова равносилен RH.

## 4. Вывод наблюдателя

1. Все ~65 батчей — разные координаты левой части одной формулы раздела 1. Каждый раз нужный знак слева
   равен знаку суммы по нулям справа.
2. Маршрут B (G1 + G3 + Гурвиц) не сокращает задачу: G3 с любой положительной скоростью уже даёт полосу без нулей,
   а G3 на всей полосе — это RH.
3. Единственное место, где круг не доказан, — G1 (чётность дна). Но G1 сама по себе RH не даёт: без G3 крыша не стоит.

## 5. Что дальше (выбор наблюдателя)

Кандидат: перестать вести маршрут B как путь к доказательству. Оставить его как точный словарь
(«знак слева = положения нулей справа») и проверочный стенд. Новые батчи давать только под вход,
который приходит извне этой формулы: свежий чужой инструмент, который даёт знак суммы Σ_z F_v(z)² без её вычисления
(правило Уильямса, память `williams-method-fresh-foreign-tool`). Вероятность, что это верный ход для цели владельца: 0.75.
- ЕСЛИ_A (владелец согласен): аудит полки на чужие инструменты 2024–2026, которые дают знак квадратичной формы
  на бесконечном семействе без спектра (положительные операторы, полуопределённое программирование, теория де Бранжа).
- ЕСЛИ_B (владелец хочет добить G1): один батч Прошке «есть ли для нечётного блока тождество вида раздела 1,
  и сводится ли сравнение секторов к нулям». Цена 20+ минут, ожидаемая польза низкая: G1 без G3 до RH не доводит.
