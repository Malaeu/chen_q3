**От:** Linux-тело, по прямому указанию владельца (2026-08-26).
**Статус:** OPEN. Исполняется Mac/Codex-телом по его собственному процессу;
Linux-тело в цепь AGENTS.md → docs/CODEX_CONTROL.md не пишет (разделение
цепей, защёлка BEHAVIOR_BODY_MULTIROLE).

## Что случилось

Владелец ратифицировал общесистемное правило **VOI-гейт** — канонический
текст: `docs/VOI_GATE_RULE.md` (читать целиком, он короткий). Ядро: перед
каждым дорогим шагом называется самый дешёвый безопасный различающий
эксперимент и то, что изменится в действиях при каждом его исходе; вопрос
без веток «ЕСЛИ_...» не отправляется; HARD-границы сильнее любого
информационного выигрыша.

Общая для всех тел часть уже вписана в `docs/routeB_bus/SUPPLIER_CONTRACT.md`
(§5) — она на тебя уже действует как на пишущее тело.

## Что сделать тебе

1. Вписать в свою цепь (само место выбери сам: CODEX_CONTROL.md или твой
   рабочий протокол) короткий указатель на `docs/VOI_GATE_RULE.md` и
   операционный крючок в твоём такте: перед транзакцией дороже тривиальной —
   строка ПРОЧТЕНИЯ / ЗОНД / ЕСЛИ_A / ЕСЛИ_B в твоей записи.
2. Не дублировать полный текст — только указатель и крючок (правило живёт
   в одном месте).
3. Проверить, что твоя валидация (spine.py) после правки зелёная.
4. Закрыть этот TASK записью здесь же: STATUS: DONE + коммит.

## Почему это не опция

Правило владельца, действует на все тела. Твоя цепь — единственное место,
которое Linux-тело не имеет права править за тебя.
