# Конечная модель: знак доказан из геометрии

Объём результата — PAPER. Гипотеза Римана над числами не доказана.
Одна собственная попытка, ноль запросов Прошке.

Для любого ненулевого вещественного чётного тригонометрического многочлена
степени g доказана эквивалентность: H2 неотрицательна на всех конечных
комплексных векторах тогда и только тогда, когда все его комплексные нули
имеют вещественную координату theta. Случай g=0, кратные корни и весь
бесконечный нулевой блок учтены.

V допускает оба точных представления: форму Безу после преобразования Кэли
с множителем1/4 и ограничение формы Кастельнуово–Севери на явные соответствия
D_x. Для кривой над конечным полем знак второй формы следует из теоремы
Ходжа об индексе. Расположение нулей не используется как посылка. Полный
смешанный член и положительный резерв вместе образуют одну отрицательную
самопересекаемость примитивного класса.
