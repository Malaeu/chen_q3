# Ремонт инструментов и граф исходников Q3 — 20.10.2026

Статус: операционный ремонт; RH/SP/CF22 не закрыты. Исходный аудит до ремонта:
[TOOL_AUDIT_2026-10-20.md](TOOL_AUDIT_2026-10-20.md).

## Что исправлено

- `ask.sh`: пустые массивы совместимы с Bash 3.2; по умолчанию используется
  репозиторный Python с PyYAML во всех вызовах, явно заданный PYTHON сохраняет приоритет.
  Для lexical qmd search задан min-score=0: старый общий порог 0.2 скрывал
  архив CF22, найденный самим qmd со score 0.09. Порог vector search не менялся.
- Семантический корпус включает NEXT, PAPER_CHAIN, архив CF22, текущие CCM
  target/compression/transfer документы, заключения и RESULT экспериментов.
- `phase_end.py`: грязное дерево требует явные `--scope`; чужие файлы и staging
  сохраняются. Генераторы вне scope пропускаются. Остаточные чужие изменения
  блокируют pull/push после локального scoped commit. `--dry-run` не пишет,
  не запускает Lean и сеть. В общем файле с чужой вставкой нужен выборочный
  staging: scope файла включает весь файл. Статистика названа текстовой/ledger.
- Лексический depgraph сохраняет координаты после комментариев и явно объявляет,
  что не является графом зависимостей ядра Lean.
- `scripts/q3_graphify_source.py` строит локальный направленный граф всех tracked
  `.lean`, `.tex`, `.md`: импорты, literal input/include и документные ссылки.
  Хэши, dirty-состояние, исторические пути, внешние модули и ошибки разбора
  сохраняются отдельно. Исходные файлы не изменяются.

## Как повторять

Из корня репозитория, с новым каталогом для каждого снимка:

```sh
.venv/bin/python scripts/q3_graphify_source.py --out /tmp/q3-source-snapshot
graphify cluster-only /tmp/q3-source-snapshot --graph /tmp/q3-source-snapshot/graph.json --no-label --no-viz
.venv/bin/python orchestrator/spine.py --refresh --reason semantic-index-refresh
./ask.sh --defer-external 'CF22 PySR'
```

Graphify 0.9.92 установлен локально. Обычный `extract` не разбирает Lean/TeX
и может вызвать внешний LLM для прозы. Здесь используется только локальный
адаптер и `cluster-only --no-label`: платные/API вызовы не требуются.
Исходный graph.json сохраняет все вхождения рёбер; Graphify анализирует проекцию
на пары узлов. Его отчёт лежит в `<snapshot>/graphify-out/`.
Старый чужой `graphify-out/` в репозитории не изменён.

## Что граф может и чего не устанавливает

Это SOURCE_REFERENCE_GRAPH_NOT_PROOF_DEPENDENCY_GRAPH. Отсутствие ссылки не
доказывает отсутствие математического аргумента; наличие импорта не доказывает,
что его теорема использована. Изолированный архив не является бесполезной веткой.
Внешний Mathlib не является потерянным локальным модулем. Ссылки на файлы иных
типов и неподдержанные конструкции отдельно отмечаются, а не считаются дырой.

Реальная проверка `bash scripts/q3_check.sh Q3/Proofs/RouteB/Goal058DirectGroundZeroEscape.lean`
прошла. Для `Q3.RouteB.rh_of_real_zero_family_tendsto_centeredXi` Lean сообщил
только `propext, Classical.choice, Quot.sound`. Но теорема принимает F, вещественность
нулей каждого F_k, entire и локально равномерную сходимость к centeredXi.
Эти входы не построены этим запуском: зелёная условная крыша не закрывает RH.
Сборка предупредила о локально изменённой зависимости UnicodeBasic; это не
проверка чистого клона/Comparator. Существующий q3_check сканирует добавленные
аксиомы только в unstaged diff; отдельный kernel target необходим независимо
от текстового счётчика.

Следующий математический потребитель остаётся в NEXT: исходная односторонняя
оценка `2 Re Tr(F W F* Z)` для фактического W и всех r. Ремонт инструментов
не заменяет эту оценку очередным тождеством или красивым графом.
