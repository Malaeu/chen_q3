# Решётка Эйлера: какое свойство обеспечивает переход

Date: 2026-09-16. Source base: `2d61be8509a7f7fe84e6ffc62d2201d231d92df6`.
STATUS: INDEPENDENTLY_REVIEWED_EXPLANATORY_RESEARCH_NOTE_ONLY; exact review in the accompanying certificate.
Это запись принципа пользователя и аудит известного механизма, не новый
результат о знаке V, не выбор производственного узла и не доказательство RH.

## 1. Держать перед глазами

> В каждом предложенном переходе назвать конкретное свойство простых,
> которое работает, и точное утверждение, которое оно заставляет выполняться.

Если шаг — общая аналитическая лемма, честно указывать: специфическое свойство
простых здесь не используется. Затем показать, почему именно наш полный
источник удовлетворяет её гипотезам. Это разрешает общие методы и запрещает
выдавать сохранение названия источника за использование его арифметики.

Короткая запись перед применением:

    свойство источника → точный вывод → область действия → непокрытый переход

Перенос должен сохранять нормировку, границы, смешанные члены и квантор по
всем конечным комплексным семействам. Если свойство сохраняется у уже
проверенной отрицательной модели, само по себе оно не доказывает нужный знак.

## 2. Три разных факта Эйлера

Базельское равенство: sum_(n>=1) 1/n² = π²/6. В Euler Archive работа E41
датирована написанием 1735 и публикацией 1740. Это одно значение функции.

Произведение синуса [S1]:

    sin(πz)/(πz) = product_(n>=1) (1-z²/n²).

Здесь целые ±n — известные нули синуса. Сравнение коэффициентов z² даёт
Базельское равенство. Локальная равномерная сходимость произведения позволяет
сравнивать коэффициенты; она следует из sum 1/n² < infinity, без знания суммы.
Нули синуса не являются нетривиальными нулями ζ.

Произведение по простым [S2]:

    ζ(s) = product_p (1-p^(-s))^(-1),       Re s > 1.

Работающее свойство: единственность разложения натурального числа на простые.
При раскрытии геометрических рядов каждое натуральное число учитывается
ровно один раз; абсолютная сходимость разрешает перегруппировку. При s=2:

    product_p (1-p^(-2))^(-1) = sum_n 1/n² = π²/6.

Это точная связь мультипликативного устройства простых и целочисленного
спектра. Сами простые, как и log p, не образуют равноотстоящую решётку.
Произведение не переносится в критическую полосу как сходящееся произведение.

След простых можно выписать ещё точнее, дифференцируя логарифм при Re s>1:

    -ζ'(s)/ζ(s) = sum_p sum_(k>=1) (log p) exp(-s k log p).

Получается преобразование положительной атомарной меры с атомами k log p
и весом log p. После мероморфного продолжения левая часть имеет полюсы
в нулях ζ; это точная связь, но положительность меры в области сходимости
сама по себе не локализует все полюсы продолжения.

Euler product не уникален для ζ: Dirichlet L-функции также имеют его, с
множителями (1-χ(p)p^(-s))^(-1) [S3]. Поэтому фраза «только у ζ есть Euler
product» неверна. Нужны точные множители и доказанное следствие их структуры.

## 3. Где эта решётка уже есть в нашем полном источнике

Это повторное использование известного результата, а не новая находка.
Исходный отчёт [P1], B1, фиксирует

    T = sum_(n>=1) G_n/(π n²),   G_n independent Gamma(shape=2, scale=1),
    Φ(X) = exp(5X/2) r(exp(2X)),  f = Φ/||Φ||_2,

где r — плотность T. Для четырёх независимых стандартных вещественных
броуновских мостов на [0,1] точное равенство законов имеет вид

    T =_law (π/2) sum_(j=1)^4 integral_0^1 B_j(t)² dt.

Ковариационное ядро моста min(s,t)-st — обратный оператор к -d²/dt² с
нулевыми значениями на обоих концах. Его собственные функции
sqrt(2) sin(nπt), собственные числа 1/(π²n²) [S4, §2.1].

Проверка нормировки: по Parseval integral B_j² = sum_n Z_jn²/(π²n²),
Z_jn независимы N(0,1). Полусумма четырёх квадратов имеет Gamma(2,1),
поэтому множитель π/2 даёт в точности G_n/(π n²). Также
E T = (2/π) sum 1/n² = π/3. Последнее равенство — только среднее,
не информация о знаке полной V.

Таким образом π² уже находится в спектре нашего точного представления.
Само присутствие символа π зависит от нормировки координат; значимы весь
спектр, масштаб и условия на границе. Здесь используется целочисленный
спектр, а не новое свойство простых.

## 4. Когда π² действительно гарантирует неотрицательность

Точный учебный механизм, отдельно от V: для комплексной функции
u in H_0^1(0,1), то есть с квадратично интегрируемой производной и нулевыми
значениями на обоих концах, положим

    E[u] = integral_0^1 |u'|²,       N[u] = integral_0^1 |u|².

Разложение u = sum a_n sqrt(2) sin(nπt) даёт

    E[u] = sum π²n² |a_n|² >= π² sum |a_n|² = π² N[u].

Рядовая формула энергии сначала проверяется на конечных суммах, затем
переходит на H_0^1 по плотности. Поэтому для вещественного λ

    E[u] - λ N[u] >= 0 для всех u   iff   λ <= π².

Необходимость проверяется u=sin(πt). Это полное доказательство модельного
критерия; при λ>π² модель отрицательна несмотря на наличие той же решётки.
Это НЕ отрицательный свидетель для нашей V.

На языке деформации закреплённого на концах отрезка: E — нормированная
энергия изменения профиля, N — его квадратная величина. π² задаёт минимум
энергии на единицу величины. Это называют спектральным зазором.
На отрезке длины L коэффициент равен (π/L)². Без нужных граничных условий
постоянная функция может иметь E=0 и N>0; тогда такой оценки нет.

Броуновские траектории сами почти наверное не лежат в H_0^1: в их sine
разложении формальная энергия равна sum Z_n² и бесконечна. Нельзя применять
эту детерминированную оценку к B_j как к функции конечной энергии. Нужен
отдельно построенный образ наших сигналов с доказанной конечной энергией.
Равным образом интервал [0,1] нельзя заменить исходной полуосью по X без
нового точного переноса веса, области определения и границы.

## 5. Один конкретный вопрос переноса, без нового обещания RH

Для исходного ядра

    V_f(x,y) = integral_0^infinity (2X+x+y) f(X+x)f(X+y) dX,
    V[c] = sum_(i,j) conjugate(c_i) V_f(x_i,x_j)c_j,

не предъявлено отображление c -> u_c in H_0^1(0,1), построенное независимо
от предполагаемой положительности V, с доказанным сравнением

    V[c] >= a E[u_c] - b N[u_c],   a>=0, b<=aπ²,

для всех допустимых конечных комплексных семейств. Такое сравнение было бы
достаточным, но пока является требованием, а не полученным результатом.
Все поправки, веса и границы обязаны быть оплачены в самом сравнении.
Нельзя взять неизвестный положительный квадратный корень V и назвать его
независимо построенным u_c.

Прежний [P1] уже содержит положительную вспомогательную форму и отказ
конкретного вложения в V. Само возвращение к Brownian/Poincare не снимает
этого отказа. Следующий содержательный шаг возможен при явном новом
отображении с иным, проверяемым равенством или сравнением; повторение
известной положительности вспомогательного объекта таким шагом не является.

Постоянное слагаемое C также не решает задачу: V[tc]=|t|²V[c]. Если была бы
отрицательная строка c, любое фиксированное V[tc]+C стало бы отрицательным
при достаточно большом |t|. Поэтому π² может работать как доказанный
коэффициент сравнения энергий, но не как свободно добавленное число.

Результат аудита: правило записано; конкретный механизм π² объяснён;
его наличие в полном источнике проверено по известному представлению.
Новая оценка полной V не получена. Нового запроса Прошке и нового goal нет;
счётчики прежних попыток, production HOLD и пауза пустого polling сохранены.
