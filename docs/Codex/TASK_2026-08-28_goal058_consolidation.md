Источник: `docs/routeB_bus/LINUX_R1_PHASE0_ADDENDUM_L2_GAUGE_GOAL058_2026-08-28.md:32`.
Это `sum_k v_k * kappa_k(0) = L * v_0`, то есть частный случай (b) при `j = 0`.

### (b) Тождество полюсной строки

    kappa_m(2 pi j / L) = (-1)^j * L * e_j

Источник: `docs/routeB_bus/LINUX_CENTRAL_WINDOW_GRAPH_RESOLVENT_MASS_PREFLIGHT_GOAL058_2026-08-28.md:27,33`.
В ядре уже есть диагональный вход:

    proposition59PoleKernel L j (proposition59Pole L j) = L * cos(j pi) = (-1)^j * L.

**Проверь первым делом, что именно закреплено** — только диагональный вход или
вся строка. Если только вход, недостающее — зануление вне диагонали. Скажи
явно, что было и что ты добавил.

### (c) Замкнутая форма нормы полюсной строки

    ||kappa(z)||^2 = L^2 * sinh(L * Im z) / (L * Im z),   предел L^2 при Im z = 0.

Источники: `LINUX_CLOSEOUT_CENTRAL_WINDOW_PROGRAM_GOAL058_2026-08-28.md:48`,
`LINUX_GRAPH_TEST_VECTOR_L2_ENVELOPE_PREFLIGHT_GOAL058_2026-08-28.md:88`.
Устранимая особенность в нуле формулируется как предел или через
`Real.sinh x / x` с отдельным разбором `x = 0` — на твой выбор, но разбор
должен быть явным, не спрятанным в `simp`.

### (d) Потолок гладкой ориентированной массы

**Осторожно: мой заголовок «ровно `6/pi`» БЫЛ НЕВЕРЕН и отозван.** Точное
значение модели —

    (2/pi) * (1 - r) * (3 - 2 r),   r = m^{-1/2},

и оно **строго меньше** `6/pi` при каждом конечном `m`; `6/pi` — супремум по
семейству, не значение. Источник отзыва:
`LINUX_ORIENTED_STIELTJES_DISCRIMINATOR_GOAL058_2026-08-28.md:34-38`.

В ядро несёшь только элементарное: для `r` в `(0,1]` величина
`(2/pi)(1-r)(3-2r)` не превосходит `6/pi`, и она убывает по `r`. **Не пиши
равенства с `6/pi`.** Утверждение о том, что это масса гладкой части
источника, остаётся прозой: разница между моделью и фактическим источником
не закрыта.

### (e) Поляризованное тождество Вольтерра–Дюамеля

    K(w) = sum_k (alpha_k + beta_k * w) * exp(2 pi i k w),
    alpha_k = omega_k / (pi * i),   beta_k = 2 * conj(x_k) * q_k,
    sum_k omega_k = 0   (нулевая масса).

Источник: `docs/routeB_bus/LINUX_VOLTERRA_HILBERT_ARE_ONE_INSTRUMENT_GOAL058_2026-08-27.md`,

### (f) Ориентированное тождество одного функционала

    Psi = <sigma_m, J>,   J = G + t*B,   sigma_m = mu_W02^raw - R_*(mu_arch + mu_prime).

Источник: `docs/routeB_bus/LINUX_ORIENTED_FULL_VOLTERRA_SOURCE_RATE_PREFLIGHT_GOAL058_2026-08-28.md`,

**Отдельное предупреждение.** Это тождество у меня подтверждено численно, до
