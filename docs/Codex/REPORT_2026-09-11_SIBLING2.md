# Оба конечных тождества и непрерывный перенос доказаны

Объём результата — PAPER, одна попытка, ноль запросов Прошке.
Знак исходной формы Вейля и гипотеза Римана остаются недоказанными.

Подтверждены для всех g, включая кратные корни:

    q^{-(i+j)/2} C(Gamma_i,Gamma_j)=p_{|i-j|},
    V(x,y)=sum_{t,s>=0}phi(x+t)phi(y+s)p_{|t-s|}.

В активном блоке матрица коэффициентов треугольная с ненулевой диагональю:
её образ содержит весь нужный конечный блок. Поэтому обратная импликация
тоже доказана. До вывода о нулях используются алгебраические суммы p_k;
положительная мера на окружности появляется только после доказательства.

Непрерывный результат с исходной нормировкой f=Phi/||Phi||2:

    k_x(t)=1_{t>=0}f(x+t),
    V_f(x,y)=B(k_x,k_y)
            =int_{t,s>=0}f(x+t)f(y+s)W(t-s)dt ds.

Последняя запись — действие явно определённого распределения. Доказаны
допустимость обрезков, граничный скачок, сходимость всех хвостов и точные
множители. Использованы SL6, SL10, SL12 и единственность преобразования
Фурье; сумма по нулям и предположение об их расположении не понадобились.

Два возражения к совету:

- «Not Bezout» неверно: S5 даёт явное обратимое преобразование к форме Безу.
  Геометрическое представление этому не противоречит.
- Отождествление с сжатием Сонина из arXiv:2006.13771 не установлено.
  Статья рассматривает архимедово место и ограниченный носитель; p3,
  Theorem1/(4) требует отдельного зануления при0, а (5) сохраняет
  поправку −c|g_hat(0)|²,13<c<17. Удаление двух полюсных направлений
  не оплачивает эту дополнительную поправку и все простые.
