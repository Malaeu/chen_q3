## 4. Выполненный билинейный вход: все простые с нормировкой по логарифму

### 4.1. Сначала полная формула с простыми степенями

**[ABSTRACT; PAPER].** На хороших идеалах определим \(\Lambda(\mathfrak p^j)=\log q_{\mathfrak p}\) при каждом j≥1 и ноль на остальных идеалах. Имеем точное тождество
\[
 \mu(n)\log q_n=-(\mu*\Lambda)(n).
 \tag{SI.13}
\]
Оно проверяется коэффициентно на каждом простом: коэффициент \(\log q_{\mathfrak p}\) справа равен \(-\sum_{j=1}^{v_{\mathfrak p}(n)}\mu(n/\mathfrak p^j)\), что есть \(v_{\mathfrak p}(n)\mu(n)\). Это утверждение включает несвободные от квадратов n.

На поздней поддержке \(\alpha L>1\) положим
\[
 W_L^\dagger(y)=\frac{\log L}{\log L+\log y}W(y).
 \tag{SI.14}
\]
Полный исходный полином поэтому равен
\[
 M(a,u;W)=-\frac1{\sqrt L}
 \sum_{\mathfrak p\ \mathrm{good}}\sum_{j\ge1}\sum_m
 \frac{\log q_{\mathfrak p}}{\log L}\mu(m)
 \psi_u(\mathfrak p)^j\psi_u(m)
 1_{(a,\mathfrak p m)=1}
 W_L^\dagger(q_{\mathfrak p}^j q_m/L).
 \tag{SI.15}
\]
Суммы конечны по исходному окну. **Условие \((\mathfrak p,m)=1\) в (SI.15) не стоит.** Например, при n=\(\mathfrak p^2\) члены j=1,2 дают \(-[\mu(\mathfrak p)+1]\log q_{\mathfrak p}=0\). Удаление j=2 оставляет \(+\log q_{\mathfrak p}\); введение взаимной простоты в полную сумму оставляет \(-\log q_{\mathfrak p}\). Оба изменения неверны.

Формула (SI.15) сама по себе не оценивает M. Она фиксирует, какие степени и пересечения обязан сохранить логарифмический вход. Для оценочного шага далее используется **уже оплаченный** \(R_{\rm sf}\), с полным возвратом к (SI.15) и к исходному R в §7.

 r_Y(n)\psi_u(n)1_{(n,a)=1}V(q_n/L).
\]
При \(q_{\mathfrak p}>Y\) это именно старый \(V_{\mathfrak p}(V)\); новое обозначение только расширяет набор простых до всех хороших.

Для бесквадратной n>1 имеем \(\sum_{\mathfrak p\mid n}\log q_{\mathfrak p}=\log q_n\). Поэтому **точно**
\[
 \boxed{R_{\rm sf}(W)=
 \sum_{\mathfrak p\ \mathrm{good}}
 h_{\mathfrak p}\,Z_{\mathfrak p}(W_L^\dagger),
 \qquad h_{\mathfrak p}=\frac{\log q_{\mathfrak p}}{\log L}.}
 \tag{SI.16}
\]
Каждая живая колонка восстановлена с коэффициентом один. В частности, гладкая колонка восстанавливается своими простыми **не больше Y**. Здесь нет ни маски произведения всех больших простых, ни деления на случайное число больших простых, ни замены гладкого сектора нулём.

Пусть \(q=q_{\mathfrak p}\). Точное извлечение одной простой в принятой проекции даёт
\[
 \boxed{Z_{\mathfrak p}(a,u;V)=
 \frac{1_{(a,\mathfrak p)=1}\psi_u(\mathfrak p)}{\sqrt q}
 \left\{-M_u^{[a\mathfrak p]}(L/q;V)
       -I_{{\rm sf},Y,u}^{[a\mathfrak p]}(L/q;V)
       +2I_{{\rm sf},Y/q,u}^{[a\mathfrak p]}(L/q;V)\right\}.}
 \tag{SI.17}
\]
Это PLQ20–21 со всеми порогами, использованные в общей логарифмической сумме. На кофакторе стоит ровно
\[
 r_Y(m)-2r_{Y/q}(m)=-\mu(m)+S_Y(m)-2S_{Y/q}(m).
\]
При q>Y последний S равен нулю; член \(-\mu(m)\) остаётся. При q=Y сохраняется \(S_1\). Маска \(a\mathfrak p\) отвечает настоящему \((m,a\mathfrak p)=1\). Скаляр \(\psi_u(\mathfrak p)\), включая его нуль при \(\mathfrak p\mid u\), не выброшен.

### 4.3. Коэффициентное сокращение действительно уменьшает полный диапазон

Если q>Y и \(q_m\le Y\), то \(\mathfrak p\nmid m\) и все короткие делители \(\mathfrak p m\) делят m. Тождество \(c_2*\mathbf1=\mu\) даёт
\[
 r_Y(\mathfrak p m)=-\mu(m)+\sum_{d\mid m}c_2(d)=0.
 \tag{SI.18}
\]
Это включает равенство \(q_m=Y\). Следовательно, на исходном окне \(q_n\le\beta L\) вся ветвь с
\(q_{\mathfrak p}>\beta L/Y\) тождественно нулевая, как только \(\beta L/Y>Y\). Последнее единообразно верно на полосе (SI.5).

Таким образом, (SI.16) можно записать с **доказанным**, не эвристическим cap
\[
 \boxed{R_{\rm sf}(W)=
 \sum_{q_{\mathfrak p}\le T_*}h_{\mathfrak p}Z_{\mathfrak p}(W_L^\dagger),
 \qquad T_*:=\beta L/Y.} \tag{SI.19}
\]
Включение равенства в cap безвредно: соответствующая концевая ветвь также проверяется по (SI.18), а не удаляется по предельному рассуждению. Простые q≤Y и весь их действительный вклад сохранены.

Именно эта фактическая опора коэффициента отличает следующий полный выход от прежнего суммирования всех делительных меток до нормы \(\beta L\). Она не делает сами простые в (SI.19) ортогональными.

### 4.4. Общий профиль и законная условная оценка каждого вектора

**[COFINAL_FAMILY; PAPER для профильного утверждения].** При
\(\log L\ge2\max\{|\log\alpha|,|\log\beta|,1\}\) знаменатель (SI.14) не меньше \((\log L)/2\). Для каждого фиксированного j производные
\((y\partial_y)^j[\log L/(\log L+\log y)]\) равномерно ограничены на фиксированном аннулюсе. Поэтому \(W_L^\dagger\) имеет один носитель и **равномерные конечные логарифмические полунормы** — границы конечного числа логарифмических производных. Норм-твисты стоят в том же общем профиле и имеют прежнюю полиномиальную высотную цену.

Профиль выбран **до** строки, усилителя и текущей простой. В (SI.17) нет отдельно выбранной Fourier-плотности для каждого u или каждой простой: после точного масштаба \(T=L/q\) ко всем трём полиномам применяется один \(W_L^\dagger\). При дополнительном разделении общего окна плотность выбирается на полном произведении норм до строкового неравенства; отдельная поточечная оценка не заменяет это правило.

**[COFINAL_FAMILY; CONDITIONAL на (SI.7)–(SI.8)].** Для каждого фиксированного \(\mathfrak p\) сначала оставляем всю скобку (SI.17), затем применяем конечный треугольник и прежние входы. Получаем
\[
 \|Z_{\mathfrak p}(V)\|^2
 \ll\frac Pq\left\{U+U^{1/6}(L/q)^{5/6}\right\}\mathscr L.
 \tag{SI.20}
\]
Учитываются все исходные a. Для каждого a маска \(a\mathfrak p\) фиксирована по u, а её радикальная норма не больше \(q_aq_{\mathfrak p}\le PT_*\), то есть фиксированной степени U. Не построена одна гигантская гладкая маска. На cap (SI.19) масштаб \(L/q\ge Y/\beta\); после общего позднего порога он даже больше единицы. Случаи y=Y/q<1 обработаны как I=0, не как \(r_y=0\).

### 4.5. Замыкание полной суммы и точное место потери

Из (SI.19)–(SI.20), **неравенства Минковского** — треугольного неравенства для нормы — **в исходном пространстве всех (a,u)** и одного бюджета \(\mathscr L\),
\[
 \begin{split}
 \|R_{\rm sf}(W)\|
 &\le\sum_{q_{\mathfrak p}\le T_*}h_{\mathfrak p}
                  \|Z_{\mathfrak p}(W_L^\dagger)\|\\
 &\ll P^{1/2}\mathscr L^{1/2}
 \left\{U^{1/2}\sum_{q_{\mathfrak p}\le T_*}h_{\mathfrak p}q_{\mathfrak p}^{-1/2}
 +U^{1/12}L^{5/12}
       \sum_{q_{\mathfrak p}\le T_*}h_{\mathfrak p}q_{\mathfrak p}^{-11/12}\right\}.
 \end{split} \tag{SI.21}
\]
На всей полосе \(0<h_{\mathfrak p}\le C\). Элементарный идеальный счёт, без теоремы о простых в движущемся проводнике, даёт
\[
 \sum_{q_{\mathfrak p}\le T_*}q_{\mathfrak p}^{-1/2}\ll T_*^{1/2},\qquad
 \sum_{q_{\mathfrak p}\le T_*}q_{\mathfrak p}^{-11/12}\ll T_*^{1/12}.
\]
Можно просто увеличить обе положительные суммы до всех хороших идеалов. Следовательно,
\[
 \begin{split}
 \mathcal E_{R_{\rm sf}}
 &\ll P\left\{UT_*+U^{1/6}L^{5/6}T_*^{1/6}\right\}\mathscr L\\
 &\ll P\left\{UL/Y+U^{1/6}LY^{-1/6}\right\}\mathscr L
 \ll PUL/Y\,\mathscr L.
 \end{split} \tag{SI.22}
\]
Отношение второго члена к первому равно, с точностью до фиксированного множителя,
\((Y/U)^{5/6}=U^{-2/3}\). Это сравнение действует на всей полосе, а не на конечной сетке.

Поскольку \(\mathcal C_Y=\mathcal E_{R_{\rm sf}}-\mathcal Q_Y\),
\[
 -CPU\mathscr L\le\mathcal C_Y\le CPUL/Y\,\mathscr L.
 \tag{SI.23}
\]
Здесь \(L/Y\to\infty\) единообразно, поэтому (SI.23) доказывает (SI.1), в том числе абсолютную границу. **Оценён весь функционал**, но полученный показатель недостаточен.

Первый неоплаченный шаг виден **до первой строки (SI.21)**. Точно
\[
 \boxed{\mathcal C_Y(W)=
 \Re\sum_{q_{\mathfrak p},q_{\mathfrak q}\le T_*}
 h_{\mathfrak p}h_{\mathfrak q}
 \langle Z_{\mathfrak p}(W_L^\dagger),Z_{\mathfrak q}(W_L^\dagger)\rangle
 -\mathcal Q_Y(W).} \tag{SI.24}
\]
Нужна верхняя оценка **этой всей комбинации**, включая малые простые, все пары разных диад и \(\mathfrak p\ne\mathfrak q\), а не только её диагонали. В частности, **вычитается первоначальная \(\mathcal Q_Y(W)\), не \(\mathcal Q_Y(W_L^\dagger)\)**. Эти два профиля нельзя отождествить ради повторного кредита.

Минковский законен, но заменяет взаимное расположение этих действительных векторов суммой длин. Полученная потеря \(T_*\) в первой ветви (SI.22) и есть неустранённая цена выбранного замыкания. Формула (SI.24) — указание места неудачи исполненного расчёта, **не новая принятая ковариационная предпосылка**.

### 4.6. Проверка прямого моментного импорта на фактическом билинейном блоке

Возьмём часть q>Y с q\(\asymp A\), \(q_m\asymp B\), AB\(\asymp L\). Коэффициент ровно \(-\mu(m)+S_Y(m)\), оба окна и \((m,a\mathfrak p)=1\) сохранены. ## 7. Полный возврат к исходной MB34

### 7.1. Никакой бесплатной замены исходного R его проекцией

**[ABSTRACT; PAPER].** Из точных \(M=I+R=I_{\rm sf}+R_{\rm sf}\),
\[
 R-R_{\rm sf}=-(I-I_{\rm sf}),
\]
\[
 \|R-R_{\rm sf}\|^2+2\Re\langle R-R_{\rm sf},R_{\rm sf}\rangle
 =\mathcal E_R-\mathcal E_{R_{\rm sf}}
 =\mathcal J_{\rm sf}-\mathcal J_I.
 \tag{SI.29}
\]
Это возвращает **все несвободные от квадратов колонки и все их смешанные члены**, а не по одной квадратной ветви с потерянными пересечениями.

Первоначальная PL3 для любого фиксированного простого остаётся
\[
 R=F_0+1_{(a,\mathfrak p)=1}\sum_{j\ge1}\psi_u(\mathfrak p)^jF_j,
\quad
 F_j=L^{-1/2}\sum_{\mathfrak p\nmid m}
 r_Y(\mathfrak p^jm)\psi_u(m)1_{(m,a)=1}W(q_{\mathfrak p}^jq_m/L).
\]
Её полный квадрат содержит все j,k. Для j≥2 сохраняются три порога Y, Y/q, Y/q² и окно с \(q^j\); \(r_t=\mu\) при t<1. Ни фазу \(\nu(\mathfrak p)^j\), ни граничные значения окон нельзя заменить шестипериодической константой. Конечная верхняя граница j задаётся исходной поддержкой. Логарифмическое представление проекции не отменяет этой формулы: её изменение оплачено **в точности (SI.29)**.

### 7.2. Исходное центрирование и первоначальная масочная диагональ

def cp(p: I, u: I):

    if l*l==q:

        def pw(x,k):
            v=(1,0)
            while k:
                if k&1: v=mm(v,x)
                x=mm(x,x); k//=2
            return v
        x=(u[0]%l,u[1]%l)
        if x==(0,0): return ZERO
        roots=[pw((1,1),j) for j in range(6)]
        return ROOT[roots.index(pw(x,(q-1)//6))]
    w=(-p[0]*pow(p[1],-1,q))%q
    x=(u[0]+w*u[1])%q
    if x==0: return ZERO
    roots=[pow((1+w)%q,j,q) for j in range(6)]
    return ROOT[roots.index(pow(x,(q-1)//6,q))]

    v=ONE

        if c==ZERO: return ZERO

    total=0
    ps=list(f)

        if q**5<=U: total+=prod((1,-2,1)[e] for e in es)
    return total
