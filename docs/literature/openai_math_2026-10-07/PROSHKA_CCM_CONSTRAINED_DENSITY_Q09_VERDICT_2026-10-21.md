## 1. Неизменённый источник и точный класс плотностей

**[FINITE_CELL | PAPER — определения].** Сохраняем
\[
 L=\log m,\quad M=R=\lfloor m^\epsilon\rfloor,
 \quad 0<\epsilon<1/32\text{ фиксировано},
 \quad \omega_j=2\pi j/L,\quad\Omega=2\pi M/L.
\]
Полоса \(|j|\le M\) дополняется нулями в прежний carrier \(N=m\). Для
\[
 f(t)=\frac1{\sqrt L}\sum_{|j|\le M}c_je^{i\omega_jt},\quad0\le t\le L,
 \qquad c\in\operatorname{ran}P,
\]
сохраняются
\[
 f(0)=f(L)=0,\qquad
 \int_0^Le^{t/2}f(t)dt=\int_0^Le^{-t/2}f(t)dt=0,
 \qquad\|f\|_2^2=\|c\|_2^2.
 \tag{1.1}
\]
Все оценки однородны; при ненулевом c можно положить \(\|c\|=1\). При нулевом пространстве операторные утверждения тривиальны.

Пишем
\[
 a_m(\xi)=2\sum_{2\le n\le m}\frac{\Lambda(n)}{\sqrt n}\cos(\xi\log n),
\]
\[
 g_m(\xi)=2\int_0^Le^{s/2}\cos(\xi s)ds,
 \qquad b_m=a_m-g_m,
 \qquad r(\xi)=\frac1{\xi^2+1/4}.
 \tag{1.2}
\]
Для нулевого продолжения f пусть
\[
 \widehat f(\xi)=\int_0^L f(t)e^{-i\xi t}dt,
 \qquad \rho_c(\xi)=\frac{|\widehat f(\xi)|^2}{2\pi}.
\]
Принятый точный класс имеет вид
\[
 \rho_c(\xi)=
 \frac{4\sin^2(\xi L/2)}{2\pi L}
 \frac{(\xi^2+1/4)^2|p_c(\xi)|^2}{D_M(\xi)^2},
 \quad \deg p_c\le2M-3,
 \quad D_M(\xi)=\prod_{|j|\le M}(\xi-\omega_j).
 \tag{1.3}
\]
Каждый ненулевой полином этого класса соответствует ровно одному c с контактами; нормировка — \(\int\rho_c=\|c\|^2\), **не** сумма квадратов коэффициентов p. Полюса в реальных узлах устранимы в \(\widehat f\). Смешанные члены \(|p|^2\) не удаляются.

Пусть H — физический интегральный оператор с ядром \(e^{-|t-u|/2}\) на \([0,L]\), \(h_f=\langle f,Hf\rangle\). Тогда
\[
 0\le h_f\le4\|f\|^2,
\]
\[
 \boxed{
 \langle c,S_mc\rangle
 =\int_{\mathbb R}b_m(\xi)\rho_c(\xi)d\xi-h_f,
 \qquad S_m=PA_{{\rm prime},m}P.
 }
 \tag{1.4}
\]
Поскольку преобразование ядра \(e^{-|s|/2}\) равно r, также
\[
 h_f=\int r(\xi)\rho_c(\xi)d\xi.
\]
Удобно обозначить **полностью возвращённый символ**
\[
 \beta_m(\xi)=b_m(\xi)-r(\xi).
\]
Тогда на исходном классе
\[
 \boxed{\langle c,S_mc\rangle=\int\beta_m\rho_c.}
 \tag{1.5}
\]
Это лишь включение уже оплаченного отрицательного H в ту же форму, не новый арифметический выигрыш.

**Настоящая арифметика.** Во всех формулах
\[
 \Lambda(n)=\sum_{d\mid n}\mu(d)\log(n/d),
 \qquad\Lambda(p^k)=\log p.
 \tag{1.6}
\]
Поэтому каждый a_m можно до любых оценок раскрыть как сумму по \(db\le m\) с коэффициентом \(\mu(d)\log b/\sqrt{db}\). Никакой смены фаз или отбрасывания proper powers нет. Верхний атом n=m остаётся в символе; его интеграл против каждой допустимой плотности равен нулю по исходной поддержке. В §2.3 показано, как этот нуль воспроизводит квадратура.

## 2. Один конкретный механизм: точная квадратура на двух связанных сетках

### 2.1. Полушаговые коэффициенты — не независимая плотность

**[FINITE_CELL | PAPER].** Введём
\[
 \nu_k=\frac{2\pi(k+1/2)}L,\quad k\in\mathbb Z,
 \qquad
 u_k=\frac1{\sqrt L}\widehat f(\nu_k).
\]
Прямое интегрирование каждого исходного монома даёт
\[
 \boxed{
 u_k=(Uc)_k=\frac{i}{\pi}
       \sum_{|j|\le M}\frac{c_j}{j-k-1/2}.
 }
 \tag{2.1}
\]
На всей \(\ell^2(\mathbb Z)\) U — смена двух ортонормированных Fourier-базисов на **том же** \([0,L]\): обычного и умноженного на \(e^{i\pi t/L}\). Следовательно,
\[
 \sum_k|u_k|^2=\sum_j|c_j|^2.
 \tag{2.2}
\]
Для точной плотности (1.3) это также
\[
 u_k=\frac{2i}{L}
 \frac{(\nu_k^2+1/4)p_c(\nu_k)}{D_M(\nu_k)}.
\]
Все смешанные члены находятся внутри **одного** \(|u_k|^2\):
\[
 |u_k|^2=\frac1{\pi^2}\sum_{j,\ell}
 \frac{c_j\overline{c_\ell}}
 {(j-k-1/2)(\ell-k-1/2)}.
 \tag{2.3}
\]
Замена правой стороны только диагональю не используется.

Кроме того, из f(0)=f(L)=0 и интегрирования по частям
\[
 \sum_k\nu_k^2|u_k|^2
 =\|f'\|_2^2
 =\sum_j\omega_j^2|c_j|^2
 \le\Omega^2\|c\|^2.
 \tag{2.4}
\]
Для этой строки не требуется ошибочное утверждение, что нулевое продолжение f принадлежит H²: достаточно H¹, а граничный член первой производной равен нулю.

### 2.2. Полная signed-квадратура, без частотного усечения

**Лемма 1 [FINITE_CELL | PAPER].** Для a_m, g_m и b_m из (1.2)
\[
 \boxed{
 \int b_m(\xi)\rho_c(\xi)d\xi
 =\frac12\sum_{|j|\le M}b_m(\omega_j)|c_j|^2
  +\frac12\sum_{k\in\mathbb Z}b_m(\nu_k)|u_k|^2.
 }
 \tag{2.5}
\]
Аналогичные равенства верны с a_m либо g_m вместо b_m. Вторая сумма бесконечна; она не подменяется исходной сеткой и не удаляется.

**Доказательство.** Только для вычисления вложим нулевое продолжение f в круг длины 2L. Это изометрическое вложение, а **не изменение производственного окна**. Его Fourier-коэффициенты
\[
 q_r=\widehat f(\pi r/L)/\sqrt{2L}
\]
равны \(q_{2j}=c_j/\sqrt2\), \(q_{2k+1}=u_k/\sqrt2\).

При каждом \(0\le s\le L\) круговой сдвиг после сжатия обратно на \([0,L]\) совпадает с исходным причинным сдвигом: завернувшаяся часть попадает в половину круга, где функция равна нулю. Это верно и при s=L почти всюду. Поэтому Parseval даёт
\[
 \boxed{
 c^*Q_M(s)c
 =\sum_j\cos(\omega_js)|c_j|^2
  +\sum_k\cos(\nu_ks)|u_k|^2.
 }
 \tag{2.6}
\]
Сначала умножаем (2.6) на **все** исходные \(\Lambda(n)/\sqrt n\) и суммируем n≤m; затем применяем ту же формулу к непрерывной мере \(e^{s/2}ds\). Все перестановки допустимы: меры конечны при фиксированном m, сумма \(|q_r|^2\) конечна. Вычитание выполняется со знаком. Получается (2.5). ∎

Никакая гипотеза о положительности signed measure не нужна. В частности, это не применение старой heat-Carleson теоремы к другой норме. Свою квадратурную формулу здесь доказываем непосредственно.

### 2.3. Обязательный отрицательный контроль: верхний атом

**[FINITE_CELL | PAPER].** В s=L точная (2.6) даёт
\[
 \|c\|^2-\|Uc\|^2=0= c^*Q_M(L)c.
 \tag{2.7}
\]
Если оставить одну исходную сетку с обычной Parseval-нормировкой, получится вместо этого
\[
 \sum_j 2\cos(\omega_jL)|c_j|^2=2\|c\|^2\ne0.
\]
Такой ошибочный метод правильно восстанавливает норму, но неправильно восстанавливает **произведение символа и плотности**. При m — степени простого он меняет настоящий верхний атом. Это точный тест инструмента, не численное свидетельство об асимптотике.

## 3. Оба экспоненциальных контакта дают дополнительный общий момент

Нельзя ограничиться (2.2): пользовательский класс меньше произвольной пары положительных распределений одинаковой массы.

**Лемма 2 [FINITE_CELL | PAPER].** На исходном \(\operatorname{ran}P\)
\[
 \boxed{
 \sum_j r(\omega_j)|c_j|^2
 =\sum_k r(\nu_k)|u_k|^2
 =h_f.
 }
 \tag{3.1}
\]

**Доказательство с сохранённым непрерывным возвратом.** Прямое интегрирование даёт
\[
 g_m(\omega_j)=(\sqrt m-1)r(\omega_j),\qquad
 g_m(\nu_k)=-(\sqrt m+1)r(\nu_k).
 \tag{3.2}
\]
Для конечного затухающего символа
\[
 h_m^{\rm sym}(\xi)=2\int_0^Le^{-s/2}\cos(\xi s)ds
\]
значения равны
\[
 h_m^{\rm sym}(\omega_j)=(1-m^{-1/2})r(\omega_j),\qquad
 h_m^{\rm sym}(\nu_k)=(1+m^{-1/2})r(\nu_k).
\]
Сумма двух физических ядер — точная rank-two форма
\[
 e^{|t-u|/2}+e^{-|t-u|/2}
 =e^{t/2}e^{-u/2}+e^{-t/2}e^{u/2}.
\]
Её значение на f равно нулю по двум исходным моментам. Применив лемму 1 к g и h_sym, получаем
\[
 \frac{\sqrt m-m^{-1/2}}2
 \left[\sum_jr(\omega_j)|c_j|^2-
       \sum_kr(\nu_k)|u_k|^2\right]=0.
\]
Это доказывает равенство двух сумм. Подстановка в квадратуру для h_sym показывает, что их общее значение равно \(\langle f,Hf\rangle\). ∎

**Проверка против потери ограничений.** Для сырого f≡L^{-1/2}, не принадлежащего P, разность этих двух моментов равна
\[
 \frac{16}{L}\tanh(L/4)>0.
\]
Это следует из той же rank-two формулы, поскольку оба экспоненциальных момента теперь ненулевые. Следовательно, (3.1) не распространяется на все положительные плотности.

Из (2.5),(3.1) получается точная полная source-квадратура
\[
 \boxed{
 c^*S_mc=\frac12\sum_j\beta_m(\omega_j)|c_j|^2
             +\frac12\sum_k\beta_m(\nu_k)|u_k|^2,
 }
 \tag{3.3}
\]
где
\[
 \boxed{
 \beta_m(\omega_j)=a_m(\omega_j)-\sqrt m\,r(\omega_j),\qquad
 \beta_m(\nu_k)=a_m(\nu_k)+\sqrt m\,r(\nu_k).
 }
 \tag{3.4}
\]
Весь отрицательный H уже включён; дополнительный H-кредит повторно не прибавляется.

## 4. Испытываемый сертификат: оптимальное совместное распределение Green-кредита

Теперь выбираем **один определённый способ оценки**, а не объявляем (3.3) новым доказательством.

**[FINITE_CELL | PAPER].** При произвольном конечном вещественном t положим
\[
 A_m(t)=\max_{|j|\le M}
      [\beta_m(\omega_j)-t r(\omega_j)],
\]
\[
 B_m(t)=\sup_{k\in\mathbb Z}
      [\beta_m(\nu_k)+t r(\nu_k)],
\]
\[
 \boxed{\mathfrak C_m(t)=\tfrac12[A_m(t)+B_m(t)],
 \qquad\mathfrak C_m^*=\inf_{t\in\mathbb R}\mathfrak C_m(t).}
 \tag{4.1}
\]
Все величины конечны при фиксированном m,t. Коэффициент t может зависеть от m: ниже препятствие учитывает **всю** эту оптимизацию, без запрета больших t.

В отличие от двух несвязанных норм, один t перераспределяет кредит между сетками с противоположными знаками. По (2.2),(3.1), для каждого исходного c:
\[
 \begin{aligned}
 c^*S_mc
 &\le\tfrac12(A_m(t)+B_m(t))\|c\|^2
 +\tfrac t2\left[\sum_jr(\omega_j)|c_j|^2-
                    \sum_kr(\nu_k)|u_k|^2\right]\\
 &=\mathfrak C_m(t)\|c\|^2.
 \end{aligned}
\]
Следовательно,
\[
 \boxed{S_m\preceq\mathfrak C_m^*P.}
 \tag{4.2}
\]
Это достаточный сертификат; его оптимальность **среди всех способов оценки исходной формы не утверждается**.

**Первая потеря информации:** в переходе к двум потолкам забыта полная связь u=Uc. Сохранились масса и общий r-момент, но не все смешанные связи (2.3). Далее проверяется, достаточен ли этот более узкий, но всё же ослабленный набор данных.

### 4.1. Полная верхняя цена без недоказанной арифметики

Обозначим
\[
 W_m=\sum_{2\le n\le m}\Lambda(n)/\sqrt n.
\]
Из принятой elementary \(\psi(x)\le3x\) частичное суммирование даёт \(W_m\le6\sqrt m\).

В (4.1) разрешён выбор t=−√m. Тогда из (3.4) оба символа под потолками становятся просто a_m на соответствующей сетке. Поскольку все \(\Lambda(n)\ge0\),
\[
 a_m(\xi)\le2W_m\quad\text{для всех действительных }\xi.
\]
Поэтому **действительно получена полная оценка**
\[
 \boxed{S_m\preceq\mathfrak C_m^*P
       \preceq2W_mP\preceq12\sqrt mP.}
 \tag{4.3}
\]
Это старый elementary-показатель 1/2. Никакая малая Carleson-константа не использована. Ниже доказывается, что оптимизация t в данном сертификате **не может снизить эту степень**.

### 4.2. Калибровка на полном непрерывном источнике

Если для проверки заменить a_m на его точный непрерывный аналог g_m, то β=−r. При t=1 получаем
\[
 A_m(1)=-2r(\Omega),\qquad B_m(1)=0,
 \qquad\mathfrak C_m(1)=-r(\Omega).
\]
Следовательно, схема действительно возвращает
\[
 S_{\rm cont}=-H_P\preceq-r(\Omega)P.
\]
Это не подстановка непрерывного источника вместо настоящего. Это контроль: схема **умеет использовать оба момента и отрицательный Green-член**, поэтому предстоящее препятствие не вызвано ошибкой нормировки или забытым центрированием.

## 5. Источниковая арифметика: большие отсчёты существуют и после центрирования

Здесь не вводится новое семейство операторов с произвольными фазами. Исследуются значения **того же самого** a_m и β_m на законных частотах квадратуры.

### 5.1. Конечное арифметическое утверждение

**Лемма 3 [FINITE_CELL | PAPER].** Для каждого целого m≥4 и каждого конечного вещественного t:
\[
 \boxed{
 \limsup_{k\to+\infty}
 [\beta_m(\nu_k)+t r(\nu_k)]
 \ge2W_m-10\log m.
 }
 \tag{5.1}
\]
Значит, правая сторона — законная нижняя граница B_m(t), равномерная по выбору t. Не утверждается эффективное положение первого большого k.

**Доказательство.** Отделим простые p≤m, делящие m, от остальных. Их полная весовая масса, включая все степени, не превосходит
\[
 W_{\mid m}
 :=\sum_{\substack{p^a\le m\\p\mid m}}\frac{\log p}{p^{a/2}}
 \le\sum_{p\mid m}\frac{\log p}{\sqrt p-1}
 \le(\sqrt2+1)\log m<\frac52\log m.
 \tag{5.2}
\]
Использовано \(\sum_{p\mid m}\log p\le\log m\). Никакая масса proper powers не выброшена.

Для простых p≤m, p∤m, числа
\[
 1,\quad\{\log p/\log m:p\nmid m\}
\]
линейно независимы над рациональными. В самом деле, целая связь после экспоненцирования имела бы вид
\(m^h\prod_{p\nmid m}p^{h_p}=1\). Единственность факторизации вынуждает все h_p=0 и затем h=0.

Поэтому последовательность
\[
 \bigl((k+1/2)\log p/\log m\bmod1\bigr)_{p\nmid m}
\]
посещает каждую открытую окрестность нуля бесконечно часто. **Короткое доказательство используемого факта:** среднее любого нетривиального целочисленного характера этой последовательности есть геометрическая сумма с отношением, отличным от 1, и стремится к нулю. Для тригонометрических полиномов предел среднего равен постоянному коэффициенту. Непрерывные функции на конечномерном торе равномерно аппроксимируются такими полиномами (например, произведениями Fejér-средних); значит, то же верно для непрерывной неотрицательной функции с положительным интегралом, поддержанной в данной окрестности. Посещение лишь конечного числа раз противоречило бы этому пределу.

При фиксированном m имеется лишь конечное число степеней каждого простого. Следовательно, можно приблизить к 1 **одновременно** все
\[
 e^{i\nu_k\log(p^a)}
\]
для p∤m, с любой заранее выбранной точностью, вдоль неограниченной последовательности k. Степени одного простого не считаются независимыми: используется ровно a-кратная фаза его основания.

Вклад p|m ограничиваем снизу числом \(-2W_{\mid m}\), не назначая ему искусственных фаз. Получаем
\[
 \limsup_{k\to\infty}a_m(\nu_k)
 \ge2(W_m-W_{\mid m})-2W_{\mid m}
 \ge2W_m-10\log m.
\]
Наконец, из (3.4)
\[
 \beta_m(\nu_k)+t r(\nu_k)
 =a_m(\nu_k)+(\sqrt m+t)r(\nu_k),
\]
а последний член стремится к нулю при k→∞ для каждого фиксированного m,t. Это доказывает (5.1). ∎

**Что новое относительно Q07:** там менялись фазы коэффициентов вспомогательной матрицы. Здесь исходные коэффициенты не меняются; большая величина обнаруживается у настоящего скалярного символа в частотной переменной его точной квадратуры. Это по-прежнему **не** разрешение локализовать допустимую плотность возле любого такого отсчёта.

### 5.2. Два безусловных следствия PNT, необходимые для полной цены

**[COFINAL_FAMILY | PAPER — стандартный внешний вход и выведенные следствия].** Используется обычное \(\psi(x)=x+o(x)\). Его достаточно для
\[
 \boxed{W_m=(2+o(1))\sqrt m.}
 \tag{5.3}
\]
Доказательство — полное частичное суммирование
\[
 W_m=\frac{\psi(m)}{\sqrt m}
       +\frac12\int_1^m\frac{\psi(x)}{x^{3/2}}dx.
\]
Число и суммарный вес высших степеней возвращаются в ψ; это не формула только для простых.

Второе следствие: для каждого **фиксированного** C>0
\[
 \boxed{\sup_{|\xi|\le C}|b_m(\xi)|=o_C(\sqrt m).}
 \tag{5.4}
\]
Пусть E(x)=ψ(x)−(x−1). Точно
\[
 \begin{aligned}
 \tfrac12 b_m(\xi)=\Re\bigg[
 m^{-1/2+i\xi}E(m)
 +(1/2-i\xi)\int_1^m E(x)x^{-3/2+i\xi}dx
 \bigg].
 \end{aligned}
\]
После фиксированного x₀ имеем |E(x)|≤ηx. Ранняя часть интеграла — константа, делённая после нормировки на √m; поздняя имеет цену не больше \(2η\sqrt m\sqrt{1/4+C^2}\). Затем η→0. Это даёт (5.4) без RH-сильной ошибки и без растущего частотного C.

Поскольку 0<r≤4, та же (5.4) верна для β_m. **Нельзя** подставить C=Ω(m) в этот качественный фиксированный вывод.

## 6. Точная нижняя цена всего семейства сбалансированных потолков

### Теорема 4. Оптимизация общего Green-момента не даёт subhalf-power

**[COFINAL_FAMILY | PAPER; безусловная PNT].** Для каждого фиксированного \(0<\epsilon<1/32\), на исходном расписании:
\[
 \boxed{
 \liminf_{m\to\infty}\frac{\mathfrak C_m^*}{\sqrt m}\ge2,
 \qquad
 \limsup_{m\to\infty}\frac{\mathfrak C_m^*}{\sqrt m}\le4.
 }
 \tag{6.1}
\]
Таким образом, выбранная **полная цена сертификата**, даже после оптимизации t, имеет половинную степень. Это не утверждение о нижнем размере \(\lambda_{\max}S_m\).

**Доказательство — явный двойственный свидетель, не численная оптимизация.** Фиксируем ξ₀>0 и берём
\[
 j_m=\left\lceil\frac{\xi_0 L}{2\pi}\right\rceil.
\]
При каждой фиксированной ε этот j_m находится в исходной полосе позднее, поскольку M/L→∞. Положим
\[
 x_m=\omega_{j_m}\to\xi_0,
 \quad y_m=\nu_0=\pi/L\to0,
 \quad q_m=\frac{r(x_m)}{r(y_m)}\in(0,1)
\]
на достаточно позднем диапазоне. Обозначим
\[
 e_m=\beta_m(x_m),\quad o_m=\beta_m(y_m),
 \quad C_m^\infty=2W_m-10L.
\]
Из определения A_m и леммы 3:
\[
 A_m(t)\ge e_m-t r(x_m),
 \qquad B_m(t)\ge C_m^\infty,
 \qquad B_m(t)\ge o_m+t r(y_m).
\]
Последние две границы можно сложить с неотрицательными весами 1−q_m и q_m. **После этого t сокращается точно:**
\[
 \boxed{
 \mathfrak C_m(t)\ge
 \frac12\left[e_m+(1-q_m)C_m^\infty+q_mo_m\right]
 \quad\text{для всех }t\in\mathbb R.
 }
 \tag{6.2}
\]
Это конечный проверяемый сертификат нижней границы **лучшего бюджета семейства**. В нём нет нижней оценки реальной формы на каком-либо f.

Из (5.3),(5.4)
\[
 \frac{C_m^\infty}{\sqrt m}\to4,
 \qquad\frac{e_m}{\sqrt m},\frac{o_m}{\sqrt m}\to0,
 \qquad q_m\to\frac1{1+4\xi_0^2}.
\]
Следовательно,
\[
 \liminf\frac{\mathfrak C_m^*}{\sqrt m}
 \ge2\left(1-\frac1{1+4\xi_0^2}\right).
 \tag{6.3}
\]
Это верно для каждого фиксированного ξ₀. Взятие supremum правых частей по таким фиксированным константам даёт 2. **Ни ε, ни ξ₀ не подстраиваются с m внутри PNT-переноса.** Для простого конкретного препятствия достаточно ξ₀=1: правая сторона (6.3) равна 8/5.

Верхняя граница следует из \(\mathfrak C_m^*\le2W_m\) и (5.3). ∎

### Точная область опровержения

Для любого фиксированного η<1/2 и конечного K, на достаточно позднем диапазоне уже из ξ₀=1:
\[
 K m^\eta-\mathfrak C_m^*
 \le K m^\eta-\sqrt m<0.
 \tag{6.4}
\]
Это строго отрицательный **верхний конверт запаса сертификата**. Он исключает получение такого показателя из семейства (4.1), в том числе на любой неограниченной подпоследовательности исходных m.

Он **не** исключает \(S_m\preceq K m^\eta P\). Двойственный свидетель (6.2) состоит из разрешённых точек для скалярных потолков, но не предъявляет достижимую пару распределений \((|c_j|^2,|(Uc)_k|^2)\). Это различие обязательно.

Также (5.1) не задаёт, где находится первый большой отсчёт: соответствующий k может быть намного больше любого выбранного степенного cutoff. Поэтому теорема 4 не опровергает сравнение на **конечном** окне с честно оплаченной частотной внешностью.

## 7. Почему истинная плотность не обязана оплачивать эти дальние пики

Этот раздел проверяет границу отрицательного результата и полностью оплачивает допустимый вариант усечения. Он не вводит ещё одну попытку получить новую степень из неоценённого внутреннего интеграла.

**[FINITE_CELL | PAPER].** Пусть K≥2M — целое, и во второй сетке сохраняются индексы −K≤k≤K−1. Для остальных x=k+1/2 имеем |x|≥K+1/2. Из исходного \(\sum c_j=0\):
\[
 \sum_j\frac{c_j}{j-x}
 =\sum_j\frac{j c_j}{x(j-x)}.
\]
Поэтому
\[
 |u_k|^2\le\frac{4(2M+1)M^2}{\pi^2|k+1/2|^4}\|c\|^2.
\]
Интегральное сравнение выпуклой функции x⁻⁴ с её значениями в серединах единичных интервалов даёт
\[
 \boxed{
 \sum_{k\notin[-K,K-1]}|u_k|^2
 \le\frac{8(2M+1)M^2}{3\pi^2K^3}\|c\|^2.
 }
 \tag{7.1}
\]
Для |β_m|≤16√m+4≤18√m при m≥4 полный signed-return (3.3) после усечения имеет ошибку
\[
 \boxed{
 |\mathcal R_K(c)|
 \le\frac{24(2M+1)M^2\sqrt m}{\pi^2K^3}\|c\|^2.
 }
 \tag{7.2}
\]
Первая сетка уже конечна по точной Fourier-поддержке c. Хвост второй сетки **не** объявлен нулевым.

Например, при фиксированном κ>0 можно взять
\[
 K=\max\left(2M,\left\lceil Lm^{1/6+\epsilon+\kappa}\right\rceil\right).
\]
Тогда
\[
 |\mathcal R_K(c)|\le\frac{72}{\pi^2L^3}m^{-3\kappa}\|c\|^2.
 \tag{7.3}
\]
Это тот же порядок достаточного cutoff, что в preflight, теперь для точной дискретной квадратуры. **Новая арифметическая степень из (7.3) не следует.** Большие частоты из доказательства (5.1) могут оказаться в этой уже оплачиваемой внешности, где суммарная масса действительно мала.

Для конечной части сохраняется весь
\[
 \tfrac12\sum_{|j|\le M}\beta_m(\omega_j)|c_j|^2
 +\tfrac12\sum_{-K\le k<K}\beta_m(\nu_k)
 \left|\frac i\pi\sum_{|j|\le M}\frac{c_j}{j-k-1/2}\right|^2.
 \tag{7.4}
\]
Новая односторонняя арифметическая оценка (7.4) в этой работе **не получена**. Она не становится готовым supplier после объявления (7.3).

Для сравнения, уже проверенный в пакете PNT-конверт
\[
 |b_m(\xi)|\le C(1+|\xi|)\sqrt m\,e^{-c\sqrt L}
\]
через (2.2),(2.4) возвращает только
\[
 \int b_m\rho_c\le C(1+\Omega)\sqrt m e^{-c\sqrt L}\|c\|^2,
\]
то есть цену \(1/2+\epsilon-o(1)\). Это **перепроверка бюджета прежнего входа**, не новое доказательство нужной малости.

## 8. Полный возврат к исходным S, T, V и K

**[COFINAL_FAMILY | PAPER — новая попытка, без ZF78].** Действительно завершённый верхний конверт можно взять
\[
 s_m=2W_m\le12\sqrt m.
\]
Для любого из доказанных s_m (включая конкретное значение \(\mathfrak C_m(t)\)):
\[
 \boxed{
 T_{>R}\preceq s_mP-T_{\le R},\qquad
 PK_mP\succeq D_m-s_mP,
 }
 \tag{8.1}
\]
где \(D_m=P(A_{\rm arch}-c_AI)P\). Скалярно:
\[
 T_{>R}\preceq(s_m+b_{\rm small})P,
 \quad
 PK_mP\succeq-(s_m+50L+8)P,
\]
\[
 b_{\rm small}=(56+32\Omega)\sqrt R+12(1+\log R)^2.
 \tag{8.2}
\]
В частности,
\[
 \boxed{
 PK_mP\succeq-[12\sqrt m+50L+8]P.
 }
\]
Это ранее доступный elementary-результат, не прогресс Q09 в полном показателе.

Короткая часть платится один раз только при scalar-контракте T. При прямом возврате к K она сокращается алгебраически. Центрирование и H уже полностью возвращены в (1.5),(3.3); второй H-кредит не добавляется.

Для отдельного \(V=C+E_{\rm slow}\) принимается ровно Q02:
\[
 T_{>R}=V+\Delta_2,\quad\|\Delta_2\|\le F_2,
\]
\[
 F_2=32(1+D_1)N_D(1+2L)+\frac{\mathfrak K_2}{\pi^2m^{3/2}},
\]
\[
 D_1=2/L+4\Omega,\quad D_2=4\Omega/L+4\Omega^2,
 \quad\mathfrak K_2=16/3+20D_1/9+4D_2/9,
 \quad N_D=\lceil\log_2(m/R)\rceil.
\]
Тогда
\[
 V\preceq(s_m+F_2)P-T_{\le R}.
 \tag{8.3}
\]
F₂ не начисляется прямому S/K-доказательству.

| Шаг | Полная цена | Степень / область |
|---|---|---|
| Двухсеточная квадратура | Точное равенство | Нулевая ошибка, не арифметическая оценка |
| Общий Green-момент | Точное равенство, H≤4 | Отрицательный кредит возвращён полностью |
| Лучший глобальный balanced-cap сертификат | \(\mathfrak C_m^*\), между \((2-o(1))\sqrt m\) и \((4+o(1))\sqrt m\) | Половинная степень **цены сертификата** |
| Завершённый elementary S | \(2W_m\le12\sqrt m\) | 1/2, не новое улучшение |
| Scalar T short-return | \(b_{\rm small}\) | 3ε/2 с логарифмами, один раз |
| Direct K arch-return | 50L+8 | Полилогарифмическая цена |
| Опциональный T–V | F₂ | ε с логарифмами, только отдельный V |
| Дискретный tail при (7.3) | \(O(m^{-3\kappa}/L^3)\) | Оплачивает хвост, не (7.4) |
| Лучший принятый Q03 | \(O_\epsilon(m^{3/8}L)\) | **Условно на прежнюю ZF78**, не получено заново |

Любой общий для всех векторов кофинальный вывод из (4.1) также сохраняет половинную степень цены, по (6.1). Это не отрицательная оценка фактических positive-part moments S и не запрет другого общего кофинального механизма.

## 9. Сильнейшее возражение и содержательный откат

**Возражение:** «Ты проверил только одну усиленную схему; законная совместная оценка плотностей не обязана проходить через два глобальных потолка». **Верно.** Это точная граница теоремы 4. Здесь не предъявлено ни доказательства невозможности исходной задачи, ни новой малой цены её полной формы.

Однако проверка не свелась к новому имени остатка:

* квадратура доказана на точном, а не расширенном классе;
* обе исходные экспоненциальные связи реально потрачены через (3.1);
* полнота бесконечной сетки и всех mixed terms сохранена;
* оптимизация свободного Green-баланса выполнена на уровне всего семейства, без фиксации удобного t;
* настоящий арифметический источник даёт явную нижнюю цену этого семейства, даже после центрирования;
* та же схема корректно принимает отрицательный непрерывный контроль.

**Откат — до перехода от (3.3) к (4.1), то есть до разрыва полной связи u=Uc.** Не к новому положительному остатку и не к другой матрице. Двойственный свидетель (6.2) использует большой дальний отсчёт с ненулевой свободной массой. У истинного u эта масса ограничена (7.1), а исходные значения c и u связаны всеми элементами U. Поэтому такой свидетель отделяет **сертификат** от истинной задачи.

**Отличный от прежних discriminator:** любой предлагаемый sampled-перенос обязан одновременно пройти
\[
 Q_M(L)=0,\quad\|Uc\|=\|c\|,
 \quad\sum r(\omega)|c|^2=\sum r(\nu)|Uc|^2,
\]
и tail (7.1), не превращая u в независимое распределение. Для реального конечного candidate-bound дополнительно вычисляется **полная** (7.4) с матричными cross terms и добавляется именно (7.2). Верхний отрицательный Rayleigh-запас опровергает только закреплённую ячейку/константы; нижний неотрицательный — принимает только её. Нулесодержащий интервал требует повышения точности/усечения или точного аргумента, не округления.

Два представления **одной точки отката**, а не две новые задачи:

| Представление | Сохранённая информация | Различающая сила / цена |
|---|---|---|
| Полная (3.3) с точным u=Uc, либо её (7.4)+(7.2) | Точная достижимость плотности, все межмодовые связи, источник фиксирован | Высокая против grid-only/independent-mass ошибок; малая цена геометрической проверки, новая арифметическая цена неизвестна |

## Приложение D. Неинтервальная проверка нормировки и квадратуры

Сохрани блок как `diagnostic_q09.py`. Запуск: `python3 diagnostic_q09.py` в среде с `mpmath`; переменные и пути подставлять не требуется. Применены 55 десятичных знаков. Зависимость не устанавливалась в ходе работы. Результат — `diagnostic_results.json` рядом со скриптом.

Код сравнивает **геометрию исходного ядра** с независимыми интегралами и конечной двухсеточной квадратурой с доказанной хвостовой ценой. Он не суммирует простые до указанного огромного m и не вычисляет полный CCM-спектр.

```python
"""Q09 source-geometry checks, not interval or CCM spectral certificates.
Run: python3 diagnostic_q09.py (mpmath required).
No parameter or path substitution is needed. No dependency is installed here.
"""
from pathlib import Path
import hashlib,json
import mpmath as mp
mp.mp.dps=55
L=192*mp.log(2); M=8; K=2048; w=2*mp.pi/L
js=list(range(-M,M+1)); om=[w*j for j in js]
v=(-1,3,-3,1)
g=[mp.mpc((-1)**k*(k+1)/(k+2), (k%3-1)/(k+3)) for k in range(2*M-2)]
c=[mp.mpc(0)]*(2*M+1)
for k,gk in enumerate(g):
    for r,vr in enumerate(v):
        c[k+r]-=(mp.mpf(1)/4+om[k+r]**2)*vr*gk
norm=mp.sqrt(mp.fsum(abs(x)**2 for x in c));c=[x/norm for x in c]
assert max(abs(mp.fsum(c)),abs(mp.fsum(cj/(mp.mpf('.5')+1j*x) for cj,x in zip(c,om))),abs(mp.fsum(cj/(mp.mpf('.5')-1j*x) for cj,x in zip(c,om)))) < mp.mpf('1e-48')
ks=list(range(-K,K));nu=[w*(k+mp.mpf('.5')) for k in ks]
ucoef=[1j/mp.pi*mp.fsum(cj/(j-k-mp.mpf('.5')) for j,cj in zip(js,c)) for k in ks]
weights=[abs(z)**2 for z in ucoef]
tail=mp.mpf(8)*(2*M+1)*M*M/(3*mp.pi**2*K**3)
norm_defect=1-mp.fsum(weights)
assert -mp.mpf('1e-45')<=norm_defect<=tail
r=lambda x:1/(mp.mpf('.25')+x*x)

assert -mp.mpf('1e-45')<=h_even-h_half<=h_tail

def f(t):return mp.fsum(cj*mp.exp(1j*x*t) for x,cj in zip(om,c))/mp.sqrt(L)
u_errors=[]
for k in (-3,0,2):
    x=w*(k+mp.mpf('.5'))
    direct=mp.quad(lambda t:f(t)*mp.exp(-1j*x*t)/mp.sqrt(L),[L*a/16 for a in range(17)])

    error=abs(direct-formula);assert error<mp.mpf('1e-45')
    u_errors.append(str(error))

    if j==k:return 2*(1-s/L)*mp.cos(w*j*s)
    return (mp.sin(w*k*s)-mp.sin(w*j*s))/(mp.pi*(j-k))
rows=[]
for frac in (mp.mpf('0.15'),mp.mpf('0.37'),mp.mpf(1)):
    s=L*frac

    quadrature=mp.fsum(mp.cos(x*s)*abs(cj)**2 for x,cj in zip(om,c))+mp.fsum(mp.cos(x*s)*ww for x,ww in zip(nu,weights))
    error=abs(source-quadrature)

# The endpoint test would return 2, not 0, on the original grid alone.
assert abs(mp.fsum(2*mp.cos(x*L)*abs(cj)**2 for x,cj in zip(om,c))-2)<mp.mpf('1e-45')
```
