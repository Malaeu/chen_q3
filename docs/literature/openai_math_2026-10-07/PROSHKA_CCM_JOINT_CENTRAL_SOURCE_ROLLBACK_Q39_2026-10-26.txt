G_Z&=\sum_\ell\frac{|g_Z(\ell)|\tau(\ell)}{\sqrt\ell},\qquad
\delta_Z=\frac1{\zeta(2)}\sum_\ell g_Z(\ell)\prod_{p\mid\ell}\frac1{p+1},\\
I_m&=2L+\frac{1+2\Omega}{2}L^2,\qquad K_{\rm pp}=\frac2{1-1/\sqrt2},\\
u_{m,Z}&=8\delta_Z+3G_Z I_m+\frac{4Z^{5/2}\log Z}{C_Z^2}
 +12\sqrt Z+K_{\rm pp}L(1+L).
\end{split}
\tag{2.11}
\]
Это старый S5(7.5), с допустимой первой, более простой платой за малые целые. Имеем \(0\le\delta_Z\le1/C_Z\) и
\[
G_Z\le4\,3^{16}Z(1+\log Z)^6.
\tag{2.12}
\]
Все оценки этого абзаца унаследованы, не являются новым арифметическим знаком Q38.

## 3. Один выбранный совместный механизм: полное парное произведение

### 3.1. Конечная алгебра и производная

**[FINITE_CELL | PAPER]** Для вещественного \(\sigma\) введём
\[
X_n(\sigma)=n^{-\sigma}V_{\log n},\quad X_1=I,
\quad X_nX_k=X_{nk},\quad X_n=0\ (n\ge m).
\tag{3.1}
\]
Все формулы ниже конечны. При дифференцировании по \(\sigma\) **фиксированы** \(m,L,Z,P,g_Z\). Это не производная по производственному расписанию.

Полные два канала задаются настоящими коэффициентами:
\[
E_+(\sigma)=\sum_{n\le m}\mu(n)^2a_Z(n)X_n(\sigma),
\qquad
E_-(\sigma)=\sum_{n\le m}\mu(n)a_Z(n)X_n(\sigma).
\tag{3.2}
\]
Их можно назвать каналами суммы и разности чётного/нечётного числа простых множителей. Это **не** прежние чётная и нечётная Fourier-полусетки и не независимые случайные фазы.

Пишем
\[
D_\pm=-\partial_\sigma E_\pm,
\qquad K_Z=E_+E_-,\qquad Q_Z=-\partial_\sigma K_Z.
\tag{3.3}
\]
Цель попытки: проверить, даёт ли совместное арифметическое сокращение в \(Q_Z\) малый односторонний остаток после полного восстановления \(C_{\rm sf}\). Возможное положительное свойство \(Q_Z\) заранее не назначается.

### 3.2. Все реальные \(g_Z\)-каналы и их пересечения

Для квадратсвободного \(\ell\) положим
\[
E_{\ell,+}=X_\ell\prod_{\substack{p\le m\\p\nmid\ell}}(I+X_p),\qquad
E_{\ell,-}=\mu(\ell)X_\ell\prod_{\substack{p\le m\\p\nmid\ell}}(I-X_p).
\tag{3.4}
\]
Полные произведения конечны. Любое произведение с общим индексом \(n\ge m\) физически равно нулю; его арифметический коэффициент не объявляется нулём. По единственности разложения на простые
\[
E_\pm=\sum_\ell g_Z(\ell)E_{\ell,\pm}.
\tag{3.5}
\]

Для \(d=(\ell,k)\) буквальное перемножение даёт
\[
\boxed{
E_{\ell,+}E_{k,-}
=\mu(k)X_{\ell k}
\prod_{p\nmid\ell k}(I-X_{p^2})
\prod_{p\mid k/d}(I+X_p)
\prod_{p\mid\ell/d}(I-X_p).
}
\tag{3.6}
\]
В первом произведении также \(p\le m\). Простые, делящие оба индекса, не порождают дополнительного локального фактора: их квадрат уже находится в \(X_{\ell k}\). При простом, делящем только один индекс, остаётся соответствующий линейный фактор. Знак \(\mu(k)\) обязателен.

Это даёт полную формулу **до модулей**:
\[
\boxed{
K_Z(\sigma)=
\sum_{\ell,k}g_Z(\ell)g_Z(k)\mu(k)
\sum_{r\mid\ell/d}\sum_{s\mid k/d}\mu(r)
\sum_{\substack{v^2\ell krs\le m\\(v,\ell k)=1}}
\mu(v)X_{\ell krs v^2}(\sigma).
}
\tag{3.7}
\]
Именно здесь используется дополнительная совместная арифметика: на простом, отсутствующем в обоих реальных каналах, линейные части сокращаются **между каналами**, оставляя квадрат. Это свойство не следует из их отдельных норм и не выполняется для произвольных весов той же массы.

Однако (3.7) само по себе — тождество. Его первое количественное следствие и полный возврат ниже; оно не объявляется знаком CCM.

## 4. Первая новая количественная оценка и её ограничение

### 4.1. Полный бюджет дифференцированного произведения

**[FINITE_CELL | PAPER]** Запишем формальный коэффициент \(k_Z(n)\) равенством
\[
K_Z(\sigma)=\sum_{n\le m}k_Z(n)X_n(\sigma).
\tag{4.1}
\]
Даже для \(n=m\) это определяет арифметический коэффициент; физическое представление его обнуляет. Определение коэффициента — конечная Dirichlet-свёртка из (3.2), поэтому оно не неоднозначно из-за нулевого оператора на границе.

При \(\sigma=1/2\) из (3.7), **после полного межканального сокращения**, имеем
\[
\begin{split}
\sum_{n\le m}\frac{|k_Z(n)|}{\sqrt n}
&\le\sum_{\ell,k}\frac{|g_\ell g_k|}{\sqrt{\ell k}}
 \sum_{r\mid\ell/d}r^{-1/2}\sum_{s\mid k/d}s^{-1/2}
 \sum_{v\le\sqrt{m/(\ell krs)}}\frac1v\\
&\le(1+L/2)
\left(\sum_\ell\frac{|g_\ell|\tau(\ell)}{\sqrt\ell}\right)^2.
\end{split}
\tag{4.2}
\]
Невозможные гиперболические области дают пустую сумму. Снятие условия взаимной простоты происходит только в неотрицательной вспомогательной плате, не в источниковом равенстве.

Производная вносит \(\log n\le L\), а каждый \(V_{\log n}\) — сжатие. Поэтому
\[
\boxed{
\|K_Z(1/2)\|\le(1+L/2)G_Z^2,\qquad
\|Q_Z(1/2)\|\le\mathfrak d_{m,Z}:=L(1+L/2)G_Z^2.
}
\tag{4.3}
\]
Используя (2.12), получаем явный верх
\[
\mathfrak d_{m,Z}
\le16\,3^{32}Z^2(1+\log Z)^{12}L(1+L/2)
=O_\epsilon(m^{\epsilon/2}L^{14}).
\tag{4.4}
\]
Это физическая операторная оценка до сжатия; она действует на все векторы и не платит за число Fourier-мод. Сжатие исходным \(\mathcal I\) в дальнейшем лишь сохраняет эту цену.

### 4.2. Что именно сократилось

**[FINITE_CELL | PAPER]** Если \(p>Z\), то \(p\nmid\ell k\) для каждого ненулевого \(g_\ell g_k\). Поэтому во всём (3.7) этот простой входит только как \(p^0\) или \(p^2\). Следовательно,
\[
\boxed{
 v_p(n)\text{ нечётно для некоторого }p>Z
 \quad\Longrightarrow\quad k_Z(n)=0.
}
\tag{4.5}
\]
Производная по \(\sigma\) не меняет поддержку. В частности, \(Q_Z\) зануляет не только большие простые, но и **каждый rough-квадратсвободный \(n>1\)**.

Это немедленный источникозависимый discriminator. Нельзя из дешёвого (4.3) заключить lower для квадратсвободных составных, не вернув именно ту часть, которую связанное произведение уничтожило. Формула (4.5) устанавливается до какого-либо большого вычисления или спектральной панели.

## 5. Полный signed-возврат: ни один составной коэффициент не исчезает бесплатно

### 5.1. Производная, первичный канал и все перекрёстные члены

Все операторы в этом разделе взяты при \(\sigma=1/2\); исходное физическое пространство не меняется. Обозначим через \(D_e\) сумму \(a_Z(n)\log n\,X_n\) по квадратсвободным \(n\) с чётным \(\omega(n)\ge2\); через \(D_o\) — по нечётным \(\omega(n)\ge3\). \(\omega\) здесь — число различных простых множителей, не исходная Fourier-частота.

Пусть \(\Pi_a=\sum_{p\le m}a_Z(p)\log p\,X_p\). Тогда
\[
D_+=\Pi_a+D_e+D_o,\qquad
D_-=-\Pi_a+D_e-D_o.
\tag{5.1}
\]
Сохраняем полный смешанный остаток
\[
\boxed{
N_Z=D_+(E_--I)+(E_+-I)D_-.
}
\tag{5.2}
\]
Никакого adjoint в (5.2) нет. Правило произведения даёт
\[
Q_Z=D_+E_-+E_+D_-=D_++D_-+N_Z=2D_e+N_Z.
\tag{5.3}
\]
Оба смешанных члена обязательны; их коэффициенты — реальные арифметические свёртки, а не \(\Lambda(uv)\) и не независимо назначенные фазы.

Пусть \(D_{{\rm comp},\le Z}\) — полная малая квадратсвободная составная часть. Буквальная причинная целевая форма
\[
C^\to_{\rm sf}=D_+-D_{+,\le Z}-\Pi_{>Z}^\to
=D_e+D_o-D_{{\rm comp},\le Z}
\tag{5.4}
\]
содержит настоящий prime-deletion член с коэффициентом один. Равенство использует \(a_Z(p)=1\) при \(p>Z\), а малые простые отменяются с их фактическими \(a_Z(p)\).

Отсюда точный возврат:
\[
\boxed{
C^\to_{\rm sf}=\frac12Q_Z+\mathscr R_Z,\qquad
\mathscr R_Z=D_o-D_{{\rm comp},\le Z}-\frac12N_Z.
}
\tag{5.5}
\]
Для исходных комплексных векторов вводим
\[
\mathcal Q_Z=\tfrac12\mathcal I^*(Q_Z+Q_Z^*)\mathcal I,
\qquad
\mathcal R_Z=\mathcal I^*(\mathscr R_Z+\mathscr R_Z^*)\mathcal I.
\tag{5.6}
\]
Тогда
\[
\boxed{
C_{\rm sf}=\mathcal Q_Z+\mathcal R_Z,
\qquad\|\mathcal Q_Z\|\le\mathfrak d_{m,Z}.
}
\tag{5.7}
\]
Это равенство **целых** квадратичных форм. В нём обе временные стороны, все комплексные self/cross и все частотные коэффициенты сохраняются. Нет промежуточного \(P\) и нет допущения, что \(E_\pm f\) удовлетворяют контактам.

### 5.2. Буквальные коэффициенты возвращённого остатка

Положим
\[
\gamma_Z(n)=\mathbf1_{Z<n\le m,\ n\ {\rm squarefree\ composite}}a_Z(n),
\quad
r_Z(n)=\left(\gamma_Z(n)-\tfrac12k_Z(n)\right)\log n.
\tag{5.8}
\]
Тогда \(\mathscr R_Z=\sum_{n\le m}r_Z(n)n^{-1/2}V_{\log n}\).

На rough-квадратсвободных \(n>1\) получаем точно:
\[
\boxed{
r_Z(n)=
\begin{cases}
0,&n\text{ простое},\\
\log n,&n\text{ составное}.
\end{cases}}
\tag{5.9}
\]
Для чётного числа простых в таком составном коэффициент \(N_Z\) равен \(-2\log n\). Для нечётного числа \(\ge3\) он равен нулю, а весь вклад возвращается через \(D_o\). Поэтому нельзя оставить только «благоприятную» чётную ветвь и потерять нечётную.

Дополнительный контроль: при \(p>Z\) имеем
\[
k_Z(p^2)=-1,\quad Q_Z[p^2]=-2\log p,\quad
r_Z(p^2)=\log p.
\tag{5.10}
\]
Значит, \(\tfrac12Q_Z+\mathscr R_Z\) возвращает ноль на \(p^2\), как требует квадратсвободная цель. Настоящий \(\Lambda(p^2)=\log p\) исходной \(A\) находится в прежнем \(U_{\rm sf}\), не удалён из CCM.

### 5.3. Первая неоплаченная строка

Для успеха потребовалось бы независимо доказать
\[
\mathcal R_Z\succeq-s_{m,\epsilon}P
\tag{5.11 OPEN}
\]
с исчезающим степенным показателем после добавления \(\mathfrak d_{m,Z}\) и остальных расходов. Но
\[
\mathcal R_Z\succeq-sP\Rightarrow C_{\rm sf}\succeq-(s+\mathfrak d)P,
\qquad
C_{\rm sf}\succeq-tP\Rightarrow\mathcal R_Z\succeq-(t+\mathfrak d)P.
\tag{5.12}
\]
Поэтому произвольная малость (5.11) — **тот же долг с оплаченной малой поправкой**, а не новый независимый вход. В этом ответе (5.11) не назначается предпосылкой. Численный знак \(\mathcal R_Z\) не вычислялся.

## 6. Завершённая цена выбранного сертификата

### 6.1. Законная оценка и её точная область

**[FINITE_CELL | PAPER]** Полная оплата возвращённого остатка по его коэффициентам даёт
\[
\mathcal R_Z\succeq-\mathfrak r_{m,Z}P,
\qquad
\boxed{\mathfrak r_{m,Z}=2\sum_{2\le n<m}\frac{|r_Z(n)|}{\sqrt n}.}
\tag{6.1}
\]
Это первая строка, на которой теряется нужная связь арифметического знака с \(f\). До неё (5.5)–(5.9) — точные связанные формулы. Обе временные стороны учтены множителем 2. При \(n=m\) не начисляется плата за нулевой физический сдвиг; коэффициент в (5.8) остаётся в алгебре.

Выбранный полный allowance для \(A\):
\[
\boxed{s_{\rm trial}=u_{m,Z}+\mathfrak d_{m,Z}+\mathfrak r_{m,Z}.}
\tag{6.2}
\]
Не оптимизируем произвольные модульные веса или разбиения. Задача §6 — довести именно этот завершённый способ до полного показателя.

### 6.2. Явный верх scalar-mass возвращения

Сохраняя истинную массу модели,
\[
\mathfrak r_{m,Z}\le2\mathfrak M_{m,Z}+\mathfrak d_{m,Z},
\quad
\mathfrak M_{m,Z}=\sum_{\substack{Z<n<m\\n\ {\rm squarefree\ composite}}}
\frac{a_Z(n)\log n}{\sqrt n}.
\tag{6.3}
\]
Для её полного верха используем принятый в S5 счёт **всех** квадратсвободных кратных, не prime-deleted счёт:
\[
A_Z^{\rm sf}(x)=\sum_{n\le x}\mu(n)^2a_Z(n)=\delta_Zx+E_Z(x),
\qquad |E_Z(x)|\le3G_Z\sqrt x.
\tag{6.4}
\]
При скалярном \(w(x)=\log x/\sqrt x\), с сохранением верхнего endpoint,
\[
\begin{split}
\mathfrak M_{m,Z}
&\le\sum_{n\le m}\mu(n)^2a_Z(n)w(n)\\
&\le\delta_Z\,[2\sqrt mL-4\sqrt m+4]
 +3G_Z\left(2L+\frac{L^2}{4}\right).
\end{split}
\tag{6.5}
\]
Действительно, верхняя ошибка \(E_Z(m)w(m)\) стоит \(3G_ZL\), а
\[
\int_1^m |E_Z(x)w'(x)|dx
\le3G_Z\int_1^m\frac{1+\frac12\log x}{x}dx
=3G_Z(L+L^2/4).
\]
Нижний атом включён: \(w(1)=0\). В этой **скалярной** массе \(w(m)\ne0\), поэтому верхний член не удалялся по операторному свойству \(h(m)=0\).

Можно получить достаточный грубый верх для \(\delta_Z\) без PNT или нового решетного входа. Из Q34-счёта с \(\ell=1\), \(\zeta(2)<2\) и Abel следует
\[
C_Z\ge\sum_{n\le Z}\frac{\mu(n)^2}{n}
\ge\tfrac12\log Z-6.
\tag{6.6}
\]
Итак, при \(\log Z\ge24\), \(C_Z\ge\tfrac14\log Z\). Если \(\kappa=\epsilon/4\) фиксировано, то eventually \(\log\lfloor m^\kappa\rfloor\ge\kappa L/2\), откуда
\[
\delta_Z\le\frac8{\kappa L},\qquad
\mathfrak M_{m,Z}\le\frac{16}{\kappa}\sqrt m
+3G_Z(2L+L^2/4).
\tag{6.7}
\]
Следовательно,
\[
\boxed{
s_{\rm trial}\le
u_{m,Z}+2\mathfrak d_{m,Z}
+\frac{32}{\kappa}\sqrt m
+6G_Z(2L+L^2/4)
=O_\epsilon(\sqrt m).
}
\tag{6.8}
\]
Все остальные слагаемые, кроме явного \(\sqrt m\), имеют показатель меньше \(1/2\). Это полноценный верх, но его удобная явная константа хуже старого fallback.

### 6.3. Нижняя цена именно этой оплаты: настоящее множество rough-семипростых

**[COFINAL_FAMILY | PAPER]** Покажем, что половинный показатель в (6.1) не является только артефактом грубого верхнего счёта. Утверждение относится к **цене (6.1)**, не к самому знаковому оператору.

Сначала элементарная количественная лемма о настоящих простых. Для каждого натурального \(n\)
\[
\binom{2n}{n}\mid\operatorname{lcm}(1,\ldots,2n),\qquad
\binom{2n}{n}\ge\frac{4^n}{2n+1}.
\tag{6.9}
\]
Первое следует из формулы Лежандра: каждая разность
\(\lfloor2n/p^j\rfloor-2\lfloor n/p^j\rfloor\) равна 0 или 1, так что показатель \(p\) не превышает \(\lfloor\log_p(2n)\rfloor\). Второе следует из суммы всех биномиальных коэффициентов и максимальности центрального.

Поскольку \(\log\operatorname{lcm}(1,\ldots,\lfloor x\rfloor)=\psi(x)\), для \(x\ge64\)
\[
\psi(x)\ge(x-2)\log2-\log(x+1)\ge x/4.
\tag{6.10}
\]
Например, \(\log2\ge2/3\) получается интегрированием выпуклого \(1/t\) на \([1,2]\), а \(\log(x+1)\le x/8\) для \(x\ge64\) проверяется в 64 и по производной. Эти границы достаточны для последнего перехода.

Весь proper-power вклад ограничен без удаления каких-либо настоящих простых степеней:
\[
\psi(x)-\vartheta(x)
\le\frac{\sqrt x(\log x)^2}{\log2}\le x/8
\quad(x\ge2^{64}).
\tag{6.11}
\]
Последняя граница проверяется при \(2^{64}\), а \((\log x)^2/\sqrt x\) после этого убывает. Поэтому
\[
\pi(x)\ge\frac{x}{8\log x},\qquad
\#\{p:x^{2/3}<p\le x\}\ge\frac{x}{16\log x}
\quad(x\ge2^{64}).
\tag{6.12}
\]
Для второго перехода достаточно \(x^{1/3}\ge16\log x\), что также выполняется начиная с этого порога. Это намеренно грубая элементарная оценка; PNT не используется.

Берём \(x=\sqrt m\). На каждом достаточно позднем \(m\) имеется не менее
\[
N_m=\frac{\sqrt m}{8L}
\]
настоящих простых в \((m^{1/3},\sqrt m]\). Они все больше \(Z\). Из различных пар образуются не менее \(m/(256L^2)\) различных квадратсвободных чисел
\[
m^{2/3}<pq<m.
\tag{6.13}
\]
Строгое верхнее неравенство следует из различия простых; подстановка \(p=q=\sqrt m\) запрещена. На каждом таком числе \(a_Z(pq)=1\), \(r_Z(pq)=\log(pq)\), и
\[
\frac{\log(pq)}{\sqrt{pq}}\ge\frac{2L}{3\sqrt m}.
\]
Отсюда
\[
\mathfrak M_{m,Z}\ge\frac{\sqrt m}{384L},\qquad
\boxed{\mathfrak r_{m,Z}\ge\frac{\sqrt m}{192L}.}
\tag{6.14}
\]
В первой границе используется только подсемейство rough-семипростых. Вторая имеет дополнительный множитель 2 из обеих временных сторон (6.1).

Вместе с (6.8):
\[
\boxed{
\lim_{m\to\infty}\frac{\log s_{\rm trial}}{\log m}=\frac12
}
\tag{6.15}
\]
для каждого фиксированного \(\epsilon\). Никакая кофинальная подпоследовательность не меняет показатель **этой цены**. Это не утверждает нижней границы \(\lambda_{\max}(A)\) или \(-\lambda_{\min}(C_{\rm sf})\); положительные и отрицательные физические overlap могут сокращаться.

## 7. Полный возврат на исходный \(P\)

### 7.1. Все исходные векторы и матричные веса

**[COFINAL_FAMILY | PAPER]** Из (2.10), (5.7), (6.1) для всех комплексных \(c=Pc\) одновременно:
\[
A\preceq s_{\rm trial}P.
\tag{7.1}
\]
Соответствующие неравенства следов выполняются для всех \(W=PWP\succeq0\), умножаясь на \(\operatorname{Tr}W\), не на размерность. Причинные алгебраические формулы выполнены до компрессии; норма исходного \(c\) не меняется.

Полный consumer-return:
\[
\boxed{
T_{>R}\preceq[s_{\rm trial}+b_{\rm div}]P,
\qquad
PK_mP\succeq-[s_{\rm trial}+50L+8]P,
}
\tag{7.2}
\]
\[
b_{\rm div}=(56+32\Omega)\sqrt R+12(1+\log R)^2.
\tag{7.3}
\]
В \(s_{\rm trial}\) уже один раз содержится \(u_{m,Z}\). Неквадратсвободный и proper-power возвраты нельзя прибавить поверх него ещё раз. В прямом \(K_m\)-переходе отдельного \(b_{\rm div}\) нет.

Все малые новые/унаследованные расходы имеют цену не более \(C_\epsilon m^{2\epsilon}\) eventually:
\[
u_{m,Z}+\mathfrak d_{m,Z}+b_{\rm div}+50L+8
\le C_\epsilon m^{2\epsilon}.
\tag{7.4}
\]
Это полезная условная карта для независимого lower \(\mathcal R_Z\), но такой lower не получен. Большая \(\mathfrak r\) не удаляется из (7.2).

Сохраняем S10, не заменяя его более дорогим явным верхом (6.8):
\[
\begin{split}
s_{\rm keep}&=W_{<}(m)+W(\lfloor\sqrt m\rfloor)
\le6\sqrt m+6m^{1/4},\\
A&\preceq s_{\rm keep}P,\\
T_{>R}&\preceq(s_{\rm keep}+b_{\rm div})P,\\
PK_mP&\succeq-[s_{\rm keep}+50L+8]P.
\end{split}
\tag{7.5}
\]
Можно формально сохранить минимум двух законных цен, но это не доказывает новый показатель и здесь не объявляется улучшением. Условные прежние \(3/8\) сохраняют свою ZF78-предпосылку; она не использована в Q38.

### 7.2. Проверка всех краёв и возвращений

1. **\(n=1\).** \(E_+(1)\) и \(E_-(1)\) имеют постоянный коэффициент 1; производная этого коэффициента нулевая. Удаление единиц в \(N_Z\) сделано явно.
2. **\(n=Z\).** Входит ровно в малую часть \(D_{{\rm comp},\le Z}\); большая составная часть начинается с \(n>Z\).
3. **\(n=m\).** Все формальные коэффициенты сохраняются, но \(V_L=0\). Это не вывод \(k_Z(m)=r_Z(m)=0\). Производная по \(\sigma\) не сдвигает \(L\), поэтому тоже оставляет нулевой физический оператор.
4. **Гиперболический край.** В (3.7) полное условие \(\ell krs v^2\le m\) сохранено. Все более длинные причинные произведения равны нулю. Никакая такая поддержка не переносится на reverse/Gram-произведения; последние здесь не использованы.
5. **Все степени простых.** Парное вспомогательное произведение имеет свои квадратные члены; исходная \(A\) остаётся полной \(\Lambda\)-суммой. Точная карта (2.10) возвращает каждый \(p^j\), включая \(j\ge2\), один раз.
6. **Смешанные каналы и комплексные векторы.** Суммируются все \(\ell,k\), все \(d,e\) внутри \(g_Z\), оба члена правила произведения и полный adjoint финальной формы. Фаза \(c\) не заменена модулем или вещественным вектором.
7. **Континуум.** \(C^0=A+H_d\) сохраняет \(0\preceq H_d\preceq4P\). Его не разрывали на два больших канала. При возврате из \(C^0\) к \(A\) он отменяется точно; отдельной полустепенной платы фону нет.
8. **Проектор.** \(P\) стоит только в начале/конце физической формы. Ни \(PE_\pm=E_\pm P\), ни сохранение контактов промежуточными векторами не предполагается. Новой Fourier/cutoff ошибки в основном all-\(P\) расчёте нет.
9. **Actual zero-selective pair.** All-\(P\) bounds применимы к целому возвращённому вектору пары, но здесь нет новой оценки её специальной фазы. Унаследованные S11–S12 не превращают (6.15) в margin; отдельная благоприятная pair-оценка не заявлена.

## 8. Содержательный откат и выполненная различающая проверка

### 8.1. Останавливаем не источник, а конкретное завершение

Дешёвое произведение не сохранило неоплаченную squarefree-поддержку: (4.5) удаляет все её большие нечётные простые степени. **Возвращение коэффициента один в (5.9) — точная причина остановки**, а не отсутствие численной точности. Нельзя тратить (4.3) на \(C_{\rm sf}\), оставляя \(N_Z\), \(D_o\) или prime-deletion без платы.

Математически не исключены другие партнёры, signed-congruence, прямое сравнение до такого умножения или source-specific оценка на фактическом образе. Здесь не доказан запрет всех парных произведений. Локальные факторизации и малые нормы сами по себе не поставляют эти дополнительные свойства.

### 8.2. Выполненный откат до парного умножения

Возвращаемся к **полной первой производной \(D_+\)** с сохранением её первичного компонента, а не продолжаем оценивать \(K_Z\). Точные карты:
\[
C_{\rm sf}
=\mathcal I^*\operatorname{Sym}
(D_+-D_{+,\le Z}-\Pi_{>Z}^{\to})\mathcal I,
\tag{8.1}
\]
\[
\boxed{C^0=-C_{\rm sf}+U_{\rm sf}+H_d.}
\tag{8.2}
\]
Здесь \(\operatorname{Sym}X=X+X^*\), без коэффициента \(1/2\). Добавочная ошибка этих карт нулевая, полный существующий budget дан в §7. Это не новый поставщик.

**Проверка на точке отката выполнена на настоящих коэффициентах, а не произвольной модели:** для всякого rough-квадратсвободного составного \(n<m\) коэффициент производной (8.1) равен \(\log n\), хотя у \(Q_Z\) он равен нулю. Для простого он равен нулю после literal deletion; для \(p^2\) оба вспомогательных члена (5.10) возвращают ноль составной squarefree-формы, а \(U_{\rm sf}\) восстанавливает \(\Lambda(p^2)\). Таким образом, различаются источник и «облегчённое» произведение до любого спектрального вывода.

Это более ранний откат с проверенной границей информации: дальнейшее уменьшение нормы \(K_Z\) без оценки восстановления не меняет коэффициенты (5.9). Новый ход должен использовать signed-связь **до аннулирования этих коэффициентов**, либо оценить их полный возврат независимо, а не назвать его малым.

### 8.3. Контроль ложного обращения — не второй механизм

Следующий ограниченный контроль приведён, чтобы не принять \(E_-\) за обратный \(E_+\). Он не используется как новый источник знака и не заменяет настоящую модель \(a_Z\equiv1\).

В неситом базовом конечном произведении
\[
E_0=\prod_{p\le m}(I+X_p)
\]
обратный коэффициент равен функции Лиувилля
\(\lambda_{\rm L}(n)=(-1)^{\sum_p v_p(n)}\), **не \(\mu(n)\)**. Тогда
\[
(-\partial_\sigma E_0)E_0^{-1}
=\sum_{p^j\le m}(-1)^{j+1}\log p\,X_{p^j}.
\tag{8.3}
\]
Эта классическая finite-algebra проверка не нова. Её полный отличающий контроль: разность с настоящим причинным Mangoldt-оператором — \(-2\sum_{p^{2j}\le m}\log p\,X_{p^{2j}}\), а не ноль. При \(\sigma=1/2\)
\[
\sum_{p^{2j}\le m}\frac{\log p}{p^j}
\le2\sum_{p\le\sqrt m}\frac{\log p}{p}
\le12+3L.
\tag{8.4}
\]
Поэтому двусторонняя физическая разность имеет норму не более \(48+12L\). Но отдельная норма обратного \(\|E_0^{-1}\|\le2\sqrt m\), а \(\|\partial_\sigma E_0\|\le2\sqrt mL\), возвращают до сжатия только \(4mL\) для их произведения. Точное coefficient-return (8.3) возвращает первую prime-форму, не её благоприятный знак. Для настоящих \(g_Z\) обратный не отождествлялся с этим базовым случаем.

Тем самым ни формальная замена партнёра обратным, ни старый логарифмический derivative не обходят проверенный долг. Это локальный отрицательный контроль при откате, а не второй успешный арифметический ход и не повтор Q37 log-chord.

### 8.4. Что осталось исследовательским долгом

**Нового независимого источникового знакового свойства, достаточного для \(C_{\rm sf}\), здесь не установлено.** Нужна оценка полной (8.1) или (8.2), использующая взаимодействие actual-coefficients с attainable original-\(P\) корреляцией. Малость отдельного \(K_Z\), знаковая симметрия числа простых и дешёвый полный модельный возврат этого не заменяют.

Две допустимые re-representation ветви, не два новых поручения:

| Представление | Точная карта / цена | Различающий тест | Kill-power / стоимость |
|---|---|---|---|
| Полная производная до парного умножения, (8.1) | Нулевая ошибка карты; старые \(u_{m,Z},b_{\rm div}\) остаются | Сохраняются \(pq,pqr\) и фактические nonrough \(g_Z\)-каналы; необходим lower без их независимых модулей | Высокая для ошибки коэффициентной карты; локальный exact-контроль дёшев. Новый знак не поставлен |
| Первичная центрированная \(C^0\), (8.2) | Нулевая ошибка; \(U_{\rm sf}\) оплачен, \(H_d\) возвращён точно | Полный непрерывный фон не приобретает \(\sqrt m\)-плату; actual-комплексная корреляция не заменяется \(|f|\) | Высокая против неверного возврата, не против RH; аналитическая стоимость нового sign-input неизвестна |

Это не обещание выполнить ещё один метод автоматически. Исходная цель не объявляется невозможной. Данный modulus-completion прекращается; Q39 не запускается.

## 9. Самоаудит, наиболее сильное возражение и границы результата

**Возражение:** дешёвое произведение могло быть всего лишь искусственным уничтожением трудной части; в таком случае его оценка не продвигает доказательство.

**Ответ:** именно это обнаружено и количественно возвращено. Поэтому первичный статус — NO_PROGRESS. Утверждение (4.3) сохраняет ценность как проверенная вспомогательная оценка настоящих полных каналов, но (5.9) запрещает его бесплатную трату на исходную форму. Полный расход завершения установлен в §6, а не скрыт под названием «остаток».

Второе возражение: нижняя цена rough-семипростых не является препятствием на исходном \(P\). **Верно.** §6.3 не утверждает существование плохого \(P\)-вектора, отрицательного собственного значения или неизбежно большой нормы \(\mathcal R_Z\). Он ограничивает лишь положительный scalar allowance (6.1). Неизвестное физическое сокращение остаётся возможным.

Третье возражение: \(a_Z\) не мультипликативно, поэтому локальные Euler-факторы нельзя использовать. **Учитывается:** (3.5)–(3.7) сохраняют всю двойную сумму по \(g_Z\); (2.8) и planted control обнаруживают ложную мультипликативную подмену.

Четвёртое возражение: сложение с adjoint уничтожает полученную поддержку. Нет: физический оператор включает отдельно причинный коэффициент и его adjoint с тем же реальным коэффициентом. Поддержка arithmetic-index в каждом остаётся прежней. Внутри причинных произведений adjoint не вставляется. Контроль на 2×2 nilpotent shift проверяет только эту алгебраическую разницу; он не служит контрпримером CCM.

Пятое возражение: малое число тестовых мод или формализация могли бы автоматически улучшить расход. Здесь ни число мод, ни точность не участвуют в нижней цене (6.14). Но это не запрещает использовать структуру actual образа в иной оценке; S12 не заменяет её готовым результатом.

- **Что стало меньше:** новая вспомогательная совместная производная оплачена \(O_\epsilon(m^{\epsilon/2}L^{14})\); неоплаченная CCM-область не стала меньше.

## 11. Проверки, воспроизводимость и внешние сведения

Выполнены 45 групп exact-контролей и обнаружены 10 намеренных ошибок. Каждая группа проверяет все коэффициенты своего указанного конечного диапазона; число групп не выдаётся за число независимых математических попыток. Коэффициенты \(g_Z\) вычисляются точно в `fractions.Fraction`, а \(\log p\) представлены формальными переменными с рациональными коэффициентами. Множитель \(n^{-\sigma}\) остаётся символическим и одинаковым у всех факторизаций одного \(n\).

Конечные случаи: \((Z,N)=(2,128),(3,420),(5,512),(8,320)\). Это **алгебраические сечения**, не производственные ячейки расписания \(Z=\lfloor m^{\epsilon/4}\rfloor\). Панель не утверждает спектральную положительность и не заменяет доказательств §4, §6.

Проверяются: полная Ramanujan-модель; все \(g_\ell g_k\); общие и непересекающиеся простые; полная производная; оба mixed-слагаемых; odd-large-prime cancellation; возврат rough \(pq,pqr\); \(A+C_{\rm sf}=U_{\rm sf}\) на каждом коэффициенте с proper powers; отличие физического верхнего нуля от формального коэффициента. Отдельные контроли инверсии и adjoint — только проверки запрещённых подмен.

Намеренные ошибки: удаление mixed \(g\), обнуление nonrough-веса, фиктивная мультипликативность \(a_Z\), adjoint вместо причинного партнёра, удаление square-коэффициента, потеря semiprime-return, потеря odd-composite-return, подмена полной производной логарифмической, \(\mu\) вместо Liouville inverse, ложное арифметическое обнуление верхнего атома.

**Не выполнялись:** Lean, Arb, production spectrum, независимый новый аудит, запуск прежних исторических скриптов как новых команд. Код ниже написан для Q38, затем повторно извлечён из собранного ответа и исполнен; результат replay фиксируется в приложениях.

Внешняя проверка ограничена официальными DLMF §27.10.E5 (дивизорная формула Ramanujan sums) и §27.4 (обычные Euler/Dirichlet conventions и их область абсолютной сходимости). URL для архивной сверки:

```text
https://dlmf.nist.gov/27.10.E5
https://dlmf.nist.gov/27.4
```

Эти определения не являются новым внешним sign-supplier. Все основные новые формулы доказаны в конечной причинной алгебре; бесконечный Euler product не переносился в \(\sigma=1/2\). Классическая бесконечная формула требует своей области сходимости; здесь в ней нет необходимости.

@lru_cache(None)
def factors(n):
    out = []
    p = 2
    while p*p <= n:
        a = 0
        while n % p == 0:
            a += 1
            n //= p
        if a:
            out.append((p, a))
        p += 1
    if n > 1:
        out.append((n, 1))
    return tuple(out)

@lru_cache(None)
def divisors(n):
    out = [1]
    for p, a in factors(n):
        out = [d*p**j for d in out for j in range(a+1)]
    return tuple(sorted(out))

def mu(n):
    fs = factors(n)
    return 0 if any(a > 1 for p, a in fs) else (-1)**len(fs)

def phi(n):
    for p, a in factors(n):
        n = n//p*(p-1)
    return n

def prime(n):
    return len(factors(n)) == 1 and factors(n)[0][1] == 1

def ram(q, n):
    return sum(d*mu(q//d) for d in divisors(gcd(q, n)))

    CZ = sum((F(mu(q)**2, phi(q)) for q in range(1, Z+1)), F(0))
    u = {}
    for d in range(1, Z+1):
        inner = sum((F(mu(k)**2, phi(k)) for k in range(1, Z//d+1)
                     if gcd(k, d) == 1), F(0))
        u[d] = F(mu(d)*d, phi(d))*inner/CZ
    g = defaultdict(F)
    for d, ud in u.items():
        for e, ue in u.items():
            g[lcm(d, e)] += ud*ue
    return CZ, u, {n:v for n,v in g.items() if v}

    return {n:sum((a.get(d, 0)*b.get(n//d, 0) for d in divisors(n)), F(0))
            for n in range(1, N+1)}

    out = defaultdict(F)
    for scale, term in terms:
        for p, x in term.items():
            out[p] += scale*x
    return {p:v for p,v in out.items() if v}

#!/usr/bin/env python3
"""Verify the canonical Q38 bytes and all twelve size-locked source bodies.

Run: python verify_sources_q38.py PROSHKA_CCM_SQUAREFREE_SIGNED_RETURN_Q38_2026-10-26.txt
Only reads the supplied packet and writes source_verification_q38.json.
"""
import argparse
import hashlib
import json
import re
from pathlib import Path

EXPECTED_NAME = 'PROSHKA_CCM_SQUAREFREE_SIGNED_RETURN_Q38_2026-10-26.txt'
EXPECTED_BYTES = 215599
EXPECTED_LF = 3497
EXPECTED_SHA = '173dddc9e6e3904b2d6d413d61f841a00c19dcf73774cd0a4629cce5215c376e'
HEADER = re.compile(rb'^BEGIN_SOURCE (S\d+) ([^\n]+)\nBYTES: (\d+)\nSHA256: ([0-9a-f]{64})\nBODY:\n', re.M)

def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('packet', nargs='?', type=Path, default=Path(EXPECTED_NAME))
    args = parser.parse_args()
    data = args.packet.read_bytes()
    data.decode('utf-8', errors='strict')
    sha = hashlib.sha256(data).hexdigest()
    if (len(data), data.count(b'\n'), sha) != (EXPECTED_BYTES, EXPECTED_LF, EXPECTED_SHA):
        raise ValueError('Canonical request byte count, LF count, or SHA-256 differs')
    records = []
    pos = 0
    for index in range(1, 13):
        match = HEADER.search(data, pos)
        if match is None or match.group(1) != ('S%d' % index).encode():
            raise ValueError('Missing or out-of-order source %d' % index)
        size = int(match.group(3))
        begin = match.end()
        end = begin + size
        body = data[begin:end]
        body.decode('utf-8', errors='strict')
        digest = hashlib.sha256(body).hexdigest()
        if len(body) != size or digest != match.group(4).decode():
            raise ValueError('Body bytes or SHA differ: ' + match.group(1).decode())
        if not data[end:].startswith(b'\nEND_SOURCE\n'):
            raise ValueError('Invalid separator or end marker')
        first = data[:begin].count(b'\n') + 1
        records.append(dict(id=match.group(1).decode(), name=match.group(2).decode(),
                            bytes=size, lf=body.count(b'\n'), sha256=digest,
                            start_line=first, end_line=first+body.count(b'\n')-1))
        pos = end + len(b'\nEND_SOURCE\n')
    if HEADER.search(data, pos) is not None:
        raise ValueError('Unexpected extra source body')
    out = dict(status='EXACT_BYTES_VERIFIED_NOT_MATHEMATICAL_CERTIFICATION',
               request=EXPECTED_NAME, bytes=len(data), lf=data.count(b'\n'),
               sha256=sha, source_count=len(records), sources=records)
    Path('source_verification_q38.json').write_text(
        json.dumps(out, ensure_ascii=False, indent=2)+'\n', encoding='utf-8')
    print(json.dumps({'bytes':len(data),'lf':data.count(b'\n'),'sources':len(records),'sha256':sha}))

if __name__ == '__main__':
    main()

#!/usr/bin/env python3
"""Extract only Q38's six declared assets and replay both new checkers.

Usage: python replay_q38.py VERDICT.md CANONICAL.txt --out q38_replay
No historical source commands, network calls, or repository writes.
"""
import argparse
import hashlib
import json
from pathlib import Path
import re
import subprocess
import sys

NAMES = {'check_q38.py', 'q38_checks.json', 'verify_sources_q38.py',
         'source_verification_q38.json', 'registered_predictions.json', 'replay_q38.py'}
HEADER = re.compile(rb'<!-- BEGIN_FILE ([A-Za-z0-9_.-]+) BYTES (\d+) SHA256 ([0-9a-f]{64}) -->\n````[a-z]*\n')

def main():
    ap = argparse.ArgumentParser(description=__doc__)
    ap.add_argument('verdict', type=Path)
    ap.add_argument('packet', type=Path)
    ap.add_argument('--out', type=Path, default=Path('q38_replay'))
    args = ap.parse_args()
    verdict = args.verdict.read_bytes()
    packet = args.packet.resolve(strict=True)
    args.out.mkdir(parents=True, exist_ok=True)
    found = set()
    for match in HEADER.finditer(verdict):
        name = match.group(1).decode()
        if name not in NAMES or name in found:
            raise ValueError('Unexpected or duplicated asset: '+name)
        size = int(match.group(2))
        body = verdict[match.end():match.end()+size]
        if len(body) != size or hashlib.sha256(body).hexdigest() != match.group(3).decode():
            raise ValueError('Bad asset hash or length: '+name)
        suffix = b'````\n<!-- END_FILE '+name.encode()+b' -->'
        if not verdict[match.end()+size:].startswith(suffix):
            raise ValueError('Invalid asset closing frame: '+name)
        (args.out/name).write_bytes(body)
        found.add(name)
    if found != NAMES:
        raise ValueError('Missing assets: '+str(NAMES-found))
    expected = {name:(args.out/name).read_bytes()
                for name in ('q38_checks.json','source_verification_q38.json')}
    subprocess.run([sys.executable,'check_q38.py'], cwd=args.out, check=True)
    subprocess.run([sys.executable,'verify_sources_q38.py',str(packet)], cwd=args.out, check=True)
    for name,data in expected.items():
        if (args.out/name).read_bytes() != data:
            raise AssertionError('Replay output differs: '+name)
    print(json.dumps({'assets_verified':len(found),'exact_groups':45,
                      'planted_errors_detected':10,'source_bodies_verified':12,
                      'output_jsons_byte_identical':True},indent=2))

if __name__ == '__main__':
    main()

\[
 h(m)=h'(m)=0,\qquad
 \int_1^m h(x)dx=-H_d,\quad 0\preceq H_d\preceq4P.
 \tag{1.5}
\]
Второй endpoint здесь необходим: из одного \(Q_M(L)=0\) не следует законность второго дифференцирования продолжения. Его даёт S1, с исходным \(P\mathbf1=0\); новое граничное условие не вводится.

Пусть
\[
 B=\max(4,\lceil m^{2\epsilon}\rceil),\quad X_j=2^jB,
\]
а J — минимальное целое с \(2X_J\ge m\). Для достаточно поздних m имеем \(2B<m\). Используем **ровно** cutoff S1:
\[
 \chi(v)=1\ (v\le1),\quad \chi(v)=0\ (v\ge2),\quad
 \chi(1+u)=1-10u^3+15u^4-6u^5\ (0<u<1),
\]
\[
 \chi_j(x)=\chi(x/(2X_j))-\chi(x/X_j),\quad
 I_j=[X_j,\min(4X_j,m)]\cap\mathbb Z.
 \tag{1.6}
\]
Тогда \(\chi(x/B)+\sum_{j=0}^J\chi_j(x)=1\) на всем \([1,m]\).

Обозначим
\[
 b_{0,j}(n)=(\Lambda(n)-1)\mathbf1_{I_j}(n),\qquad
 a_j(x)=\chi_j(x)h(x)\mathbf1_{[1,m]}(x).
 \tag{1.7}
\]
**Cutoff один:** он находится в \(a_j\), не второй раз в арифметике. Переменная t ниже двойственна целому n, а не физической координате \(\log n\):
\[
 \widehat b_j(t)=\sum_{n\in I_j}(\Lambda(n)-1)e(-nt),\quad
 \widehat a_j(t)=\sum_{n\in I_j}a_j(n)e(-nt).
 \tag{1.8}
\]

### 1.1. Полный вход S1, не новый результат

Для \(\tau_j=X_j^{-1/2}\)
\[
 N_0=\sum_j\int_{|t|<\tau_j}\widehat b_j(t)\widehat a_j(-t)dt.
 \tag{1.9}
\]
S1 даёт на всем исходном P
\[
 \boxed{A_m=N_0+E_0,\qquad \|E_0\|\le r_0(m)\le C_\epsilon m^{2\epsilon}.}
 \tag{1.10}
\]
Более явная форма принятой цены:
\[
 r_0\le (8+4\Omega)+16\sqrt{2B}
       +C_FK^2(L+1)(J+1).
 \tag{1.11}
\]
Первые два слагаемых оплачивают всю дискретную постоянную модель и smooth base через \(2B\); третье — все прежние far arcs, включая верхнюю оболочку. При \(K\asymp_\epsilon m^\epsilon/L\), \(J+1=O(L)\) правая часть не больше \(C_\epsilon m^{2\epsilon}\).

В (1.10) не применена E1, отсутствует discarded Siegel-character term: используется отдельное точное разложение \(\Lambda=1+(\Lambda-1)\). Модельный атом 1 и его residual \(-1\) сокращаются в полной сборке.

### 1.2. Полный матричный тест

Из (1.4), S1 и точного второго разностного равенства следует с одним абсолютным \(C_a\ge1\):
\[
 \boxed{
 \|\widehat a_j(t)\|
 \le C_a\sqrt X\min\left(1,\frac{K^2}{X^2t^2}\right),
 \quad X=X_j,\quad |t|\le1/2.}
 \tag{1.12}
\]
В точке 0 берётся первая ветвь. Первая оценка — сумма норм \(2/\sqrt n\) по не более чем \(3X+1\) атомам. Для второй
\[
 (1-e(t))^2\widehat a_j(t)=\widehat{\Delta_+^2a_j}(t),\quad
 \sum_n\|\Delta_+^2a_j(n)\|\le\int\|a_j''(x)\|dx,
\]
и \(|1-e(t)|\ge4|t|\). Нулевые value/first-derivative seams в (1.5) исключают дополнительные дельта-члены. Можно взять \(C_a=\max(8,C_{\chi,h}/16)\), где \(C_{\chi,h}\) — константа последнего интегрального входа S1.

Это полная op-норма, без множителя размерности. Для любого \(W=PWP\succeq0\), \(\operatorname{Tr}W=1\), верно
\(|\operatorname{Tr}(W\widehat a_j)|\le\|\widehat a_j\|\). До использования этого неравенства все комплексные mixed entries сохраняются.

## 2. Аудит major/minor-arc гипотез: что законно, а что нет

### 2.1. Точный рациональный выбор вне микроскопического центра

**[FINITE_CELL | PAPER + EV]** Пусть \(X\ge16\), \(2/X\le|t|\le X^{-1/2}\). Для \(t>0\) выберем
\[
 q=\lfloor1/t\rfloor,\quad a=1;
\]
для \(t<0\) возьмём \(a=-1\) с тем же q. Тогда
\[
 \frac1{2|t|}\le q\le\frac1{|t|}\le X/2,
 \quad |t-a/q|<\frac1{q(q+1)}<q^{-2}.
 \tag{2.1}
\]
На двух буквальных префиксах \(Y=\min(4X,m)\) и \(X-1\) условия [EV] выполнены, поскольку \(X-1\ge X/2\). Поэтому разность префиксов, без удаления нижнего атома, даёт
\[
 \boxed{
 |\widehat b_j(t)|\le C_b\ell_X^4
   \left[X\sqrt{|t|}+X^{4/5}+\sqrt{X/|t|}\right],
 \quad \ell_X=\log(8X),}
 \tag{2.2}
\]
где, увеличив абсолютный запас, можно положить \(C_b=16(C_V+1)\).

Дискретная постоянная часть НЕ потеряна. Ее геометрическая сумма имеет модуль не больше \(1/(2|t|)\). На диапазоне \(|t|\ge2/X\) она поглощается \(\sqrt{X/|t|}\). Все веса Мангольдта и prime powers входят в сам [EV].

На оставшемся диапазоне действует только элементарная общая оценка
\[
 |\widehat b_j(t)|\le32X.
 \tag{2.3}
\]
Например, из принятого \(\sum_{n\le x}\Lambda(n)/\sqrt n\le6\sqrt x\) следует \(\psi(x)\le6x\), и \(\sum_{n\in I_j}|\Lambda(n)-1|\le28X\). Запас 32 включает все конечные концы.

### 2.2. Почему центральная полоса не получает minor-arc power бесплатно

**[ABSTRACT | PAPER]** На открытом интервале
\[
 |t|\le1/(100X)
 \tag{2.4}
\]
не существует ненулевого числителя a и знаменателя \(2\le q\le X\), удовлетворяющих \(|t-a/q|\le q^{-2}\). Действительно,
\[
 |t-a/q|\ge1/q-1/(100X)\ge99/(100q)>q^{-2}.
\]
Рациональное приближение \(a=0,q=1\) законно, но [EV] при q=1 имеет цену порядка \(X\log^4X\), не меньшую степень. Подстановка \(q=\lfloor1/|t|\rfloor\) в (2.4) даёт \(q\ge100X\); это вне использованного диапазона \(q\le x\), а даже unrestricted член \(\sqrt{xq}\) был бы большим.

После вычитания постоянной модели
\[
 \widehat b_j(0)=\psi(Y)-\psi(X-1)-(Y-X+1).
 \tag{2.5}
\]
Из оценки модуля \(\sum\Lambda e(nt)\) и отдельной оценки \(\sum e(nt)\) не следует новый знак их разности. Старый scalar-PNT completion из S1 здесь повторно не используется.

**Вывод feasibility-аудита:** [EV] применим к части сохранённой области, но не поставляет новый signed-input для её центра. Это установлено до попытки объявить \(N_0\) малым. Ни одна формула ниже не маркирует весь \(|t|<\tau_j\) как minor arcs.

## 3. Точный центральный объект — до всех модулей

Для произвольного \(0<\lambda\le1/2\) введём
\[
 k_\lambda(d)=\begin{cases}
 2\lambda,&d=0,\\
 \dfrac{\sin(2\pi\lambda d)}{\pi d},&d\ne0.
 \end{cases}
 \tag{3.1}
\]
Конечная Fourier-сборка даёт без ошибки
\[
 \boxed{
 \int_{|t|<\lambda}\widehat b_j(t)\widehat a_j(-t)dt
 =\sum_{n,l\in I_j}(\Lambda(n)-1)a_j(l)k_\lambda(l-n).}
 \tag{3.2}
\]
Для trace с W используется ровно тот же W при всех n,l,j. Нечётная часть частотной интеграции сопряжена с чётной; матрица в (3.2) Hermitian. Это не утверждение о неотрицательности.

Если тестировать буквальную Type-II/делительную структуру, источник (3.2) имеет точную форму
\[
\begin{aligned}
 \mathcal L_j(\lambda)={}&
 \sum_{\substack{d,k\ge1\\dk\in I_j}}
 \mu(d)\log k\,\widetilde a_{j,\lambda}(dk)
 -\sum_{n\in I_j}\widetilde a_{j,\lambda}(n),\\
 \widetilde a_{j,\lambda}(n)={}&
 \sum_{l\in I_j}a_j(l)k_\lambda(l-n).
\end{aligned}
 \tag{3.3}
\]
Здесь применено только доказанное делительным свёртыванием \(\Lambda=\mu*\log\). Формула сама по себе не новый supplier. Все гиперболические ограничения \(dk\le m\), концы \(I_j\), настоящие \(\mu\), \(\log k\), оба времени и полный \(P\) находятся внутри одной суммы. Ни convolution coefficient, ни \(\Lambda(p^k)\) не переопределяются.

**Особенно важный верхний край.** Хотя \(a_j(m)=0\), обычно
\(\widetilde a_{j,\lambda}(m)\ne0\). Поэтому атом \(n=m\) в near-части нельзя удалять отдельно; его законное нулевое исходное значение возвращается только вместе с дополнением. Точно так же нельзя применять к \(\widetilde a\) исходную Euler/contact-лемму для \(h\), не вернув изменившиеся граничные значения. Я такой перенос не делаю.

Будущих арифметических атомов здесь нет: оба индекса n,l явно ограничены \(I_j\subset[1,m]\). Sinc имеет бесконечный носитель как функция аргумента, но это не разрешает продлить арифметическую сумму за m.

На более узком \(\lambda=1/(100X)\) и \(|l-n|\le3X\)
\[
 k_\lambda(l-n)\ge\lambda>0.
 \tag{3.4}
\]
Это следует из интегрирования \(\cos(2\pi t(l-n))\) и \(6\pi/100<\pi/3\). Однако \(\Lambda(n)-1\) знакопеременно, а \(\operatorname{Tr}(Wa_j(l))\) не обязано быть неотрицательным. **Положительный sinc на этом участке не упорядочивает полную mixed-сумму.**

Даже у прямоугольного билинейного подблока \(d\asymp D,k\asymp K_1,DK_1\asymp X\) центральная фаза \(tdk\) меняется лишь на константу при \(|t|=O(1/X)\). Нужная осцилляция не возникает от слова «билинейная». После Cauchy остались бы реальные корреляции \(\mu(d)\mu(d')\) с полным \(\widetilde a(dk)\widetilde a(d'k')\); они здесь не оцениваются предположенным благоприятным знаком.

## 4. Оплаченная внешняя часть near-полосы

**[COFINAL_FAMILY | PAPER + EV]** Выберем один общий для каждого shell cutoff
\[
 \lambda_j=X_j^{-5/8}<\tau_j=X_j^{-1/2},
\]
\[
 N_\star=\sum_j\int_{|t|<\lambda_j}
                 \widehat b_j(t)\widehat a_j(-t)dt,
 \qquad N_0=N_\star+O_{\rm ann}.
 \tag{4.1}
\]
Выбор не зависит от W. На \(\lambda_j\le|t|<\tau_j\) условия (2.2) выполнены eventually; \(X^{-5/8}\ge2/X\) при \(X\ge16\).

Применяя нормы только к **этому** дополнению, из (1.12),(2.2) получаем
\[
\begin{aligned}
 \|O_{{\rm ann},j}\|
 \le C_aC_bK^2\ell_X^4\bigg[
 4X^{-1/2}\lambda_j^{-1/2}
 +2X^{-7/10}\lambda_j^{-1}
 +\frac43X^{-1}\lambda_j^{-3/2}\bigg].
\end{aligned}
 \tag{4.2}
\]
Все три слагаемых получены интегрированием, включая обе стороны \(t>0,t<0\):
\(\int_\lambda^\infty t^{-3/2}=2\lambda^{-1/2}\),
\(\int_\lambda^\infty t^{-2}=\lambda^{-1}\),
\(\int_\lambda^\infty t^{-5/2}=2\lambda^{-3/2}/3\).
Продление положительного верхнего интеграла до бесконечности не продлевает область применимости [EV]: сам supplier использовался лишь на исходном конечном участке.

Подставляя \(\lambda=X^{-5/8}\), получаем степени
\[
 -3/16,\quad -3/40,\quad -1/16.
\]
Следовательно,
\[
 \|O_{{\rm ann},j}\|
 \le8C_aC_bK^2\ell_X^4X^{-1/16}.
 \tag{4.3}
\]
И по всей точной геометрической сетке
\[
 \boxed{
 \|O_{\rm ann}\|\le r_V(m):=
 \frac{8C_aC_b}{1-2^{-1/16}}
 K^2\log^4(8m)B^{-1/16}.}
 \tag{4.4}
\]
При фиксированном \(\epsilon\)
\[
 r_V(m)=O_{\epsilon,V}(m^{15\epsilon/8}L^2)
       \le C_{\epsilon,V}m^{2\epsilon}\quad\text{eventually}.
 \tag{4.5}
\]
Таким образом,
\[
 \boxed{A_m=N_\star+E_\star,\quad
 \|E_\star\|\le r_\star:=r_0+r_V
 \le C_{\epsilon,V}m^{2\epsilon}.}
 \tag{4.6}
\]

**Граница результата.** (4.4) — первая новая количественная арифметическая цена данной попытки: она использует распределение аддитивных фаз настоящей \(\Lambda\) из [EV], а не только \(|\Lambda(n)|\le\log n\). Но тест в её завершении используется через норму (1.12). Это оценка выделенного дополнения, **не** требуемая новая joint sign estimate центральной формы и не изменение полного показателя CCM.

## 5. Законное завершение центра: полный, но недостаточный бюджет

Здесь сначала сохраняется точное \(N_\star\) из (3.2),(4.1). Проверяем, что выбранный supplier даёт при доступном завершении. Это **не** заново введённая PNT-оценка и не E1 для \(\Lambda-1\).

### 5.1. Первая явная потеря joint-фазы

Для \(W\succeq0\), \(W=PWP\), \(\operatorname{Tr}W=1\), завершение использует
\[
\begin{aligned}
 \Re\operatorname{Tr}(WN_\star)
 &\le\sum_j\int_{|t|<\lambda_j}
 |\widehat b_j(t)|\,
 |\operatorname{Tr}(W\widehat a_j(-t))|dt\\
 &\le\sum_j\int_{|t|<\lambda_j}
 |\widehat b_j(t)|\,\|\widehat a_j(-t)\|dt.
\end{aligned}
 \tag{5.1}
\]
**Именно первая строка (5.1) теряет направление совместного знака.** Все mixed coefficients входят в тест до этой строки; они не объявлены нулевыми. Однако направление их связи с арифметической фазой больше не используется. Поэтому (5.1) не отвечает более сильному joint-требованию Q32.

### 5.2. Полный интеграл одного shell

Центр \(|t|<2/X\) по (2.3),(1.12) стоит не более \(128C_a\sqrt X\). Для остальной части используем (2.2), затем замену \(y=X|t|\). Три нужных положительных интеграла вычисляются точно:
\[
\begin{aligned}
 \int_0^\infty y^{1/2}\min(1,K^2/y^2)dy&=\frac83K^{3/2},\\
 \int_0^\infty \min(1,K^2/y^2)dy&=2K,\\
 \int_0^\infty y^{-1/2}\min(1,K^2/y^2)dy&=\frac83\sqrt K.
\end{aligned}
 \tag{5.2}
\]
Следовательно, даже при сохранении всех source terms до (5.1) законно получается лишь
\[
 \boxed{
 \|N_{\star,j}\|
 \le128C_a\sqrt X+
 2C_aC_b\ell_X^4\left[
 \frac83K^{3/2}+2KX^{3/10}+\frac83\sqrt{KX}\right].}
 \tag{5.3}
\]
Интегралы (5.2) являются вычислением положительной allowance; вне исходного диапазона не утверждается новый арифметический bound.

### 5.3. Полная сумма и показатели

Пусть \(D_r=(1-2^{-r})^{-1}\). Поскольку \(X_J<m\),
\(\sum_jX_j^r\le D_rm^r\). Определим явный полный конверт центра
\[
\begin{aligned}
 s_{\rm core}(m)={}&128C_aD_{1/2}\sqrt m\\
 &+2C_aC_b\log^4(8m)\left[
 \frac83(J+1)K^{3/2}+2D_{3/10}Km^{3/10}
 +\frac83D_{1/2}\sqrt{Km}\right].
\end{aligned}
 \tag{5.4}
\]
Тогда
\[
 N_\star\preceq s_{\rm core}P,\qquad
 A_m\preceq s_{\rm trial}P,\quad s_{\rm trial}=s_{\rm core}+r_\star.
 \tag{5.5}
\]

| Сектор полного испытанного сертификата | Цена |
|---|---|
| Начальная constant-model/base/far реконструкция S1 | \(O_\epsilon(m^{2\epsilon})\) |
| Новое внешнее near-кольцо | \(O_{\epsilon,V}(m^{15\epsilon/8}L^2)\) |
| Микроцентр из \(|t|<2/X\) | \(O(\sqrt m)\) |
| Член \(X\sqrt{|t|}\) из [EV] | \(O_V(K^{3/2}L^5)\) |
| Член \(X^{4/5}\) из [EV] | \(O_V(Km^{3/10}L^4)\) |
| Член \(\sqrt{X/|t|}\) из [EV] | \(O_V(\sqrt{Km}L^4)\) |
| Новая ошибка проекции | 0: тест, P и норма не менялись |

На исходном расписании доминирует
\[
 s_{\rm trial}=O_{\epsilon,V}
 \left(m^{1/2+\epsilon/2}L^{7/2}+m^{2\epsilon}\right).
 \tag{5.6}
\]
В частности, показатель не стремится к нулю. Сам положительный сертификат (5.4) уже содержит \(128C_aD_{1/2}\sqrt m\); поэтому его нельзя объявить sub-half-power за счёт изменения словесной интерпретации. **Это нижняя цена только выписанной allowance, не нижняя граница истинного \(N_\star\), \(A_m\) или спектра.**

В применении сохраняем более сильный прежний fallback
\[
 s_{\rm use}=\min\{12\sqrt m,\ s_{\rm trial}\}.
 \tag{5.7}
\]
Не заявляется, что более дорогой новый upper улучшил старую оценку. Q31 \(\sqrt m/L^{1/8}+m^{2\epsilon}\) остаётся отдельно доступным только с его E1-зависимостью. Прежние условные \(3/8\) остаются условными на старую ZF78; ни E1, ни ZF78 в новом выводе не использовались.

## 6. Центральный тест действительно достижим на исходном P

Этот контроль исключает только возможную ошибку «контакты автоматически стирают центральную additive-дугу». Он **не** оценивает арифметическую ошибку \(\Lambda-1\), не утверждает наличие внепрямого нуля и не является новой нижней оценкой CCM.

### 6.1. Точный допустимый вектор

**[COFINAL_FAMILY | PAPER, actual test, no EV]** Пусть \(\omega=2\pi/L\), \(M\ge2\). На \([0,L]\) положим
\[
 u_L(t)=-\frac34+(1+4\omega^2)\cos(\omega t)
              -(\tfrac14+4\omega^2)\cos(2\omega t),
\]
\[
 Z_L=\|u_L\|_2^2
 =L\left(\frac{35}{32}+5\omega^2+16\omega^4\right),\qquad
 f_L=u_L/\sqrt{Z_L}.
 \tag{6.1}
\]
Endpoint равен нулю. Для \(a=\pm1/2\), используя \(\omega L=2\pi\),
\[
 \frac{-3/4}{a}
 +\frac{(1+4\omega^2)a}{a^2+\omega^2}
 -\frac{(1/4+4\omega^2)a}{a^2+4\omega^2}=0.
 \tag{6.2}
\]
Умножение на \(e^{aL}-1\) возвращает буквальные два экспоненциальных интеграла. Поэтому f_L соответствует единичному \(c_L\in\operatorname{ran}P\), с нулями во всех остальных исходных модах. Никакой удобный новый проектор не создаётся.

### 6.2. Настоящий overlap на верхних оболочках

На каждом фиксированном \(0\le t\le\log4\)
\[
 \frac{u_L(t)}{\omega^4t^2}
 \longrightarrow 6-\frac{t^2}{8}
 \quad\text{равномерно, с продолжением при }t=0.
 \tag{6.3}
\]
Это прямое Taylor-разложение конечных косинусов. Правая часть строго больше 5 на этом интервале. Поэтому для достаточно больших L
\(u_L(t)\ge5\omega^4t^2\), \(Z_L\le2L\).

Благодаря периодичности и чётности u_L, для \(0\le s\le\log4\)
\[
\begin{aligned}
 q_L(L-s)&=2\Re\int_0^s\overline{f_L(t)}f_L(t-s)dt\\
 &\ge\frac{5\omega^8}{6L}s^5\ge0.
\end{aligned}
 \tag{6.4}
\]
Вся исходная корреляция сохранена. Для проверки ведущего полинома, если \(p(t)=6t^2-t^4/8\),
\[
 \int_0^s p(t)p(s-t)dt
 =\frac65s^5-\frac1{70}s^7+\frac1{40320}s^9.
 \tag{6.5}
\]
Средний член в (6.5) — настоящий mixed-term, не удаляемая поправка.

### 6.3. Не одна точка, а центральный интервал

Для J≥1 положим \(\theta_{\rm top}=\chi_{J-1}+\chi_J\). Так как
\(m/2\le X_J<m\), ее физический носитель лежит в \([m/4,m]\). При \(x\le m\)
\[
 \theta_{\rm top}(x)=1-\chi(2x/X_J).
\]
На \([3m/4,7m/8]\) имеем \(\theta_{\rm top}\ge1/2\). На всём носителе \(q_L(\log x)\ge0\) по (6.4), а на указанном меньшем интервале
\[
 q_L(\log x)\ge c_0L^{-9},\qquad
 c_0=\frac56(2\pi)^8[\log(8/7)]^5>0.
\]
Следовательно,
\[
 \operatorname{Tr}\left(W_L[\widehat a_{J-1}(0)+\widehat a_J(0)]\right)
 \ge \frac{c_0}{32}\frac{\sqrt m}{L^9},\quad W_L=c_Lc_L^*.
 \tag{6.6}
\]
Все коэффициенты скалярного теста в этой сумме неотрицательны. Для
\(|t|\le1/(12m)\) имеем \(\cos(2\pi nt)\ge1/2\), \(n\le m\). Поэтому
\[
 \boxed{
 \Re\operatorname{Tr}\left(W_L[\widehat a_{J-1}(-t)+\widehat a_J(-t)]\right)
 \ge \frac{c_0}{64}\frac{\sqrt m}{L^9},
 \quad |t|\le\frac1{12m}.}
 \tag{6.7}
\]
Этот интервал находится внутри обеих сохранённых центральных дуг (4.1) для всех поздних m.

**Что доказано:** три контакта не дают нулевой или автоматически дешёвой центральной additive coupling теста. Это настоящий исходный тест с единичной нормой, а не произвольный bump.

**Чего не доказано:** никакая нижняя оценка \(\Re\operatorname{Tr}(W_LN_\star)\). Источники \(\widehat b_j\) различаются между оболочками, имеют свои комплексные фазы, и именно их совместный знак остался неизвестным. Умножать (6.7) на предполагаемый положительный арифметический коэффициент запрещено. Старый endpoint-шаблон используется здесь как проверка применимости, не как объявление нового препятствия полной CCM.

## 7. Полный возврат исходному потребителю

**[COFINAL_FAMILY | PAPER + EV where used]** Исходный делительный R не равен знаменателю q и не равен частотным cutoffs. Его уже оплаченная двухсторонняя цена
\[
 b_{\rm div}=(56+32\Omega)\sqrt R+12(1+\log R)^2
 =O_\epsilon(m^{3\epsilon/2}/L+m^{\epsilon/2}+L^2).
 \tag{7.1}
\]
Для любого действительно доказанного upper \(s\) на \(N_\star\)
\[
 \boxed{
 T_{>R}\preceq(s+r_\star+b_{\rm div})P,
 \qquad
 PK_mP\succeq-[s+r_\star+50L+8]P.}
 \tag{7.2}
\]
Это точный input/output: поставленный \(s=D_\epsilon m^{\theta(\epsilon)}\) дал бы \(\max(\theta(\epsilon),2\epsilon)\). В настоящем расчёте поставлен только (5.4), а не \(\theta\to0\).

С сохранённым более выгодным fallback (5.7):
\[
 T_{>R}\preceq(s_{\rm use}+b_{\rm div})P,
 \qquad PK_mP\succeq-[s_{\rm use}+50L+8]P.
 \tag{7.3}
\]

### 7.1. Все обязательные расходы

**P и норма.** Ни один новый тест не вводится в main estimate: все матрицы изначально действуют на том же P. Все W имеют нормировку \(\operatorname{Tr}W=1\); размерностного множителя нет. Дополнительный вектор §6 — лишь явный допустимый диагностический тест, не замена all-P области.

**Два времени и mixed terms.** Они находятся внутри Q_M и полного \(a_j(l)\). В (3.2) не отброшены ни \(n\ne l\), ни межмодовые комплексные члены. Если подставить настоящую пару из S6, все ее self/cross terms и комплексные prefactors остаются внутри полного c. Никакой замены \(\kappa\) его модулем нет.

**Prime powers и μ.** [EV] применяется к \(\Lambda\), включая все proper powers. В (3.3) μ и log соответствуют буквальному конечному произведению dk; \(\Lambda(dk)\) не подставляется вместо произведения или свёртки коэффициентов. Отдельная proper-power плата не добавляется поверх уже полной Λ-оценки.

**Все концы.** Cutoff-перекрытия складываются в 1. Интервалы \(I_j\) конечны, нижний атом X включён, последний shell заканчивается в m, где сохранены оба исходных jets. Нулевое значение исходного n=m не переносится на отдельные near/far части. Неправильный такой перенос обнаруживает exact-контроль в приложении.

**Будущие атомы.** В (3.2) и (3.3) нет n>m; Fourier-gate не разрешает их добавить. Переменная l тоже остаётся в \(I_j\). Не использованы Perron height, бесконечная Λ-сумма или новая contour inversion, поэтому новой finite-height утечки нет.

**Непрерывный фон.** Точный \(\int h=-H_d\) сохраняется. Если source measure буквально dx, центрированный источник равен нулю точно, а не оценивается двумя большими каналами. Для дискретного control \(\Lambda(n)\rightsquigarrow1\) имеем b0=0 и обе near-части исчезают точно; остаётся законная отдельная Euler-модель \(\sum h\), ограниченная \(8+4\Omega\). Это разные, явно различённые controls. В прямой K-оценке лишняя +4 не начисляется.

**Короткий и архимедов расходы.** \(b_{\rm div}\) добавляется один раз только при T_{>R}; архимедова плата \(50L+8\) — один раз при прямом K-return. Не надо дополнительно складывать все прежние расходы Q10/Q31 поверх (7.3).

**Полилогарифмическая пара S6.** Она является отдельно достаточным receiver, а не разрешением заменить all-P. Если только повторить здесь ту же нормовую оценку с \(\Omega_0=O(L)\), она стоит \(O_V(\sqrt mL^{9/2})\) плюс меньшие члены. Отношение allowance к \(m^\delta/L^{2\delta}\) равно \(\gg m^{1/2-\delta}L^{9/2+2\delta}\), что не стремится к нулю для фиксированного \(0<\delta<1/2\). И даже полный исходный \(12\sqrt m\) имеет ту же дефицитную степень. Дешёвый S6-возврат \(o(1)\) этого не меняет. Это проверка данного norm-completion, не запрет source-specific pair estimate.

## 8. Первая неоплаченная строка и выполненный более ранний откат

### 8.1. Конкретный долг

Не доказан направленный верх
\[
 \Re\sum_j\sum_{n,l\in I_j}
 (\Lambda(n)-1)k_{\lambda_j}(l-n)
 \operatorname{Tr}(Wa_j(l))
 \le D_\epsilon m^{\theta(\epsilon)},\qquad \theta(\epsilon)\to0,
 \tag{8.1 OPEN}
\]
равномерно по **тому же** \(W=PWP\succeq0\), \(\operatorname{Tr}W=1\), на общей семье m. Или достаточный более слабый coefficient-margin на настоящей целой паре.

(8.1) — не новая поставленная лемма. Это точная остающаяся обязанность после оплаченного дополнения. [EV] не задаёт ее знак; S1/S3 E1 к \(\Lambda-1\) неприменима; гипотетическая сильная variance из S5 не использовалась.

Для успеха выбранного central Type-II пути требовалось бы реальное неравенство для (3.3), сохраняющее **корреляцию μ(d), log k и самого матричного \(\widetilde a(dk)\)**. Перестановка конечных сумм законна, но не уменьшает ее. В этом ответе такого неравенства нет. Контроль §6 исключает только попытку удалить центральную область через контакты без новой арифметики.

### 8.2. Откат к документированному S7, а не ещё один cutoff

Выбираемый более ранний fork — полный конечный центрированный источник, **до аддитивного Fourier-разделения**:
\[
 C_m^0=A_m+H_d.
\]
Выполненная обратная сборка из (4.6) точна:
\[
 \boxed{C_m^0=N_\star+H_d+E_\star,\qquad\|E_\star\|\le r_\star.}
 \tag{8.2}
\]
Из уже принятого all-P результата S7, не делая нового contour shift,
\[
 A_m=-H_d+V_m-R_{\rm sign}+E_c,
 \quad \|V_m\|\le B_m,\quad\|E_c\|\le e_m,
\]
\[
 B_m=O_\epsilon(m^\epsilon L\log L),\qquad
 e_m=O_\epsilon(m^{-1/4}/L^2).
\tag{8.3}
\]
Следовательно,
\[
 \boxed{
 N_\star=-H_d+V_m-R_{\rm sign}+(E_c-E_\star),
 \quad\|E_c-E_\star\|\le e_m+r_\star.}
 \tag{8.4}
\]
Это точный общий original-P map; неизвестные знаки не поменялись. Дальние контурные края, кратности и фактические source residues остаются ровно теми, что были оплачены S7. Новый контур, зависящий от W, не вводится. Дополнения H0 и cross-blocks отсутствуют, поскольку работа шла на всем P.

Количественно новый upper s для \(N_\star\) дал бы
\[
 R_{\rm sign}\succeq-[s+B_m+e_m+r_\star+4]P,
\]
а lower \(R_{\rm sign}\succeq-dP\) дал бы
\[
 N_\star\preceq[d+B_m+e_m+r_\star]P-H_d.
\]
Все добавочные расходы здесь \(O_{\epsilon,V}(m^{2\epsilon})\). **Ни одна сторона не объявлена независимым источником другой.** Это бухгалтерия выполненного отката, не повторное объявление эквивалентности прорывом.

Причина выбора этого fork конкретна: испытанный norm-completion теряет взаимодействие центра с фактическим тестом. Возврат к C0 прекращает дробление этой связи на independent arithmetic/test sizes и сохраняет ее в исходном линейном источнике. Он не требует платить две большие положительные энергии, variance или inverse norm.

**Нового пригодного источникового неравенства после этого отката я не нашёл.** Поэтому дальнейшая оптимизация \(\lambda_j\), q или логарифмической степени внутри (5.1) не назначается новой попыткой и не объявляется дорогой к доказанному знаку.

### 8.3. Две сохраняемые записи и дискриминатор

Эти записи фиксируются для аудита, не как каталог запускаемых методов:

| Представление | Полная уже оплаченная цена | Проверка, которая может изменить вывод; стоимость |
|---|---|---|
| Конечная совместная sinc/divisor сумма (3.3), то же W | \(r_\star=O_{\epsilon,V}(m^{2\epsilon})\), без future atoms | Проверить первую предлагаемую signed-строку на гиперболических краях и исходном тесте §6. Высокая чувствительность к потере фазы; конечная алгебра, без production spectrum. |
| Выбранный ранний fork C0 и all-P S7 | \(B_m+e_m+r_\star+4=O_{\epsilon,V}(m^{2\epsilon})\) | Проверить, поставлено ли независимое joint-неравенство, а не та же residue/sup-norm цель. Бюджет уже дан; большая контурная вычислительная работа не требуется. |

**DISCRIMINATOR:** любая новая оценка обязана одновременно (i) возвращать нуль для полного centered continuous source, (ii) сохранять (6.7), не утверждая ложное удаление additive-центра, и (iii) указать строку, в которой настоящий \(\Lambda-1\) согласован с фактическим тестом, а не только с его Lp-нормой. Выполнение первых двух controls не заменяет доказательства третьего.

### 9.2. Самая сильная атака на попытку

**Возражение:** это опять независимые нормы, хотя Q32 требовал нового совместного знака.

**Ответ:** верно для центрального завершения (5.1), поэтому оно здесь и признано неудачным. Исследование установило, где [EV] действительно применяется, оплатило только соответствующую часть и не назвало ее всем ответом. Новый source/test signed-input не найден. Это точный отказ кандидату после его hypothesis/budget map, а не утверждение выполнения первоначальной цели.

**Второе возражение:** большая центральная тестовая реакция не доказывает большой N0.

**Ответ:** верно. §6 говорит только о достижимом тесте и опровергает его автоматическое зануление. Знак \(\widehat b_j\), компенсация оболочек и всю CCM он не оценивает снизу. Синтетические finite-code examples также не считаются production ячейками.

**Третье возражение:** вспомогательная внешняя near-экономия не должна раздувать счётчик прогресса.

**Ответ:** статус по исходному потребителю — **NO_PROGRESS**. Улучшен оплаченный диапазон, но неизвестный знак не стал доказанным. Нет нового полного показателя ниже 1/2, нет coefficient margin, нет результата RH.

### 9.3. Предсказания и фактическая проверка

Prospective registration записана после полного чтения пакета и inspection внешнего statement, до exact-контролей и окончательной сборки доказательства. Ее неизменённое тело включено в приложение.

- P1: гипотезы рационального приближения и незакрытый q=1 центр — подтверждены §2.
- P2: внешняя часть near имеет \(m^{O(\epsilon)}\)-возврат — подтверждено §4; не promoted в полный знак.
- P3: завершённая нормовая цена не дает vanishing exponent — подтверждено §5.
- P4: настоящий исходный тест не удаляет additive-центр — подтверждено §6.
- P5: все необходимые возвраты записываются без смены P — подтверждено §7.

Выполнены **70 точных локальных математических контролей**, обнаружены **8 намеренно внесённых ошибок**. Отдельный стандартный Python-проверяющий подтвердил канонический хеш и все семь тел. Контроли проверяют finite algebra, коэффициенты, cutoffs, полный sinc mixed pairing, действительные prime powers, контакты и рациональные показатели. Они не проверяют асимптотический спектральный знак и не воспроизводят доказательство [EV].

В плане был контроль неверного знака Fourier-инверсии. Для симметричной sinc-дуги одновременная смена всех знаков не меняет ядро, поэтому фиктивного «обнаружения» такого изменения не заявляется. Проверены вместо этого полный второй разностный Fourier-фактор и действительные mixed coefficients. В процессе подготовки удалены три тавтологические bookkeeping-проверки из счётчика; окончательный счёт 70 не включает их.

Lean, Arb, production-спектр, новый независимый аудит и репозиторные записи не запускались. Гипотетическим нулям не назначались численные значения. Код не использует модельный нуль как данные.

## Приложение B. Воспроизведение конечных контролей

Локальная среда запуска: Python 3.13.5, SymPy 1.14.0. Ничего не устанавливалось.
Первый скрипт проверяет только точную конечную алгебру; второй — только байты источника.
Ни один из них не является checker-ом глобального неравенства CCM.

Ниже помещены пять файлов с буквальными длинами и SHA-256. Код извлечения можно сохранить
как `extract_q32.py`; он проверяет каждый вложенный файл до записи. Аргумент 1 — путь к
этому Markdown, аргумент 2 — каталог вывода, например `q32_replay`.

```python
#!/usr/bin/env python3
"""Extract byte-framed Q32 replay files; verifies each length and SHA-256."""
from pathlib import Path
import hashlib,re,sys
if len(sys.argv)!=3:
    raise SystemExit('Usage: python extract_q32.py ANSWER.md OUTPUT_DIRECTORY')
data=Path(sys.argv[1]).read_bytes()
out=Path(sys.argv[2]); out.mkdir(parents=True,exist_ok=True)
pat=rb'^<!-- Q32_ASSET name=([^ ]+) bytes=(\d+) sha256=([0-9a-f]{64}) -->\n```[^\n]*\n'
seen=set()
for hit in re.finditer(pat,data,re.M):
    rawname,rawsize,rawhash=hit.groups(); name=rawname.decode('ascii')
    if Path(name).name!=name or name in seen:
        raise ValueError('Unsafe or duplicate asset name: '+name)
    seen.add(name); size=int(rawsize)
    payload=data[hit.end():hit.end()+size]
    if len(payload)!=size or hashlib.sha256(payload).hexdigest()!=rawhash.decode():
        raise ValueError('Asset checksum mismatch: '+name)
    tail=b'```\n<!-- END_Q32_ASSET -->'
    if data[hit.end()+size:hit.end()+size+len(tail)]!=tail:
        raise ValueError('Asset framing mismatch: '+name)
    (out/name).write_bytes(payload)
if len(seen)!=5:
    raise ValueError('Expected five assets, got '+str(len(seen)))
print('Verified and extracted',len(seen),'Q32 assets')
```
