Взаимность отождествляет две фазы, но не делает их единицами. При простых первичных образующих \(-2-3\omega\) и \(1-3\omega\) точный тест ниже даёт их произведение \(\omega\), не 1.

### 3.2. Все степени и все четыре парные делимости

**Лемма 1 [ABSTRACT; PAPER из (SC.10)].** Для любого хорошего первичного \(\mathfrak p\) и каждого \(\xi\in\varpi^{-4}\mathcal O\setminus\{0\}\)
\[
 d_H(\mathfrak p^3\xi)=\sqrt{q_{\mathfrak p}}d_H(\xi).       \tag{SC.12}
\]
Она включает общие простые n,c и нулевую поддержку.

**Доказательство.** В (SC.10) заменяется только \(c\mapsto\mathfrak p c\). Первичность сохраняет u,k. Коэффициент растёт на \(|\mathfrak p|\). Дополнительная аддитивная фаза равна 1: при \(\mathfrak p=1+3v\)
\(\mathfrak p^3-1=9v+27v^2+27v^3\in9\mathcal O=\varpi^4\mathcal O\),
поэтому \((\mathfrak p^3-1)\xi\in\mathcal O\). Если локальный показатель \(v_{\mathfrak p}(\xi)\equiv2\pmod3\), обе стороны нулевые. При показателе \(1+3j\) простой находится одновременно в n и c при j>0; это не исключается. ∎

Для \(\mathfrak p\nmid\xi\) переход к первой степени дополнительно содержит
\[
 \frac{\alpha(\mathfrak p)}{\sqrt{q_{\mathfrak p}}}
 \widetilde g_{a_{H,k,u}}(\mathfrak p)(\mathfrak p/n)_3^2
               \check e(\delta_H(\mathfrak p-1)\xi).         \tag{SC.13}
\]
Это точный множитель для \(d_H\alpha/\sqrt{q_\xi}\). Значит, после извлечения кубов остаются **настоящие** квадратсвободные Gauss-фазы; они не заменены независимыми знаками. Все локальные показатели имеют вид \(\epsilon+3j\), \(\epsilon=0,1\), либо принадлежат нулевой ветви \(2\pmod3\).

В парном ядре при общем простом \(\mathfrak p\mid(B,C)\) четыре флага делимости двух полных аргументов дают
\[
 k_q(0,0)=0,\quad k_q(1,0)=k_q(0,1)=q,\quad k_q(1,1)=q(2-q).
                                                               \tag{SC.14}
\]
Каждый такой множитель стоит перед **комплексной парой**, в которой остаются (SC.10), (SC.13), обе \(\alpha\), оба профиля и \(\mu(B)\mu(C)A_h(B)\overline{A_h(C)}\). Последующая редукция выполняет кубическую часть этой полной пары, а не назначает последнему числу автоматический знак.

### 3.3. Доказательство кубической ковариантности всей G

**Лемма 2 [ABSTRACT; CONDITIONAL на буквальную F-reflection и принятую CP20].** Верна (SC.1) для каждого \(\lambda>0,t,\xi\) и хорошего \(\mathfrak p\nmid Rh\).

**Доказательство.** Зафиксируем исходный h,R, лучевой член и базовую активную ветвь. На \(\xi\mapsto\mathfrak p^3\xi\), \(\lambda\mapsto q_{\mathfrak p}\lambda\) оба нормовых аргумента в (SC.7) совпадают точно. По (SC.12) множитель \(d_H\alpha/\sqrt{q_\xi}\) меняется на \(\alpha(\mathfrak p)^3/q_{\mathfrak p}\).

Пусть \(\Psi_{\rm mov}(x)=\prod_{v\in\mathcal P_0}\chi_v(x)^{j_v}\), где \(\mathcal P_0=\operatorname{supp}\operatorname{rad}(Rh_{\rm good})\). Во всех нерамануджановых активных локальных ветвях
\[
 B_{v,j_v}(\mathfrak p^3z)
 =\chi_v(\mathfrak p)^{-3j_v}B_{v,j_v}(z).
\]
При j=4 флаг делимости z не меняется, а \(-3j\equiv0\pmod6\); при активном j=0 множитель также равен 1. Неактивные нулевые ветви не меняются. Поэтому **для любого выбора активности** общий базовый множитель равен \(\Psi_{\rm mov}(\mathfrak p)^{-3}\), с сохранёнными нулями z.

Остаётся аддитивная S-фаза. Выполним перестановку всех фиксированных Fourier-классов
\(h_0'\equiv\mathfrak p^{-3}h_0\). Обратный здесь берётся только в достаточно большом **фиксированном S-кольце**, не в нулевой ветви характера. Можно выбрать первичный lift r, обратный \(\mathfrak p\) во всех используемых S-модулях, и транспортировать представителя как \(r^3h_0\).

Точный нормированный \(c_F\), его единица, cusp-функция и базовые локальные знаменатели сохраняются. Числитель умножается на \(r^3\). Кубический множитель \(\kappa_F\) получает куб символа, то есть 1; аддитивный коэффициент получает \(r^{-3}\), что даёт ровно прежнюю фазу от \(\mathfrak p^3z\). При замене транспортированного lift исходным используется **исправленная CP20**: c делит разность \(\delta'\), частное лежит в \(3\mathcal O\), и настоящий cusp automorphy-закон компенсирует изменение аддитивной фазы коэффициентно. Это не аргумент только по норме \(c_F\). fileciteturn109file1L131-L132

Для фиксированной \(\phi\) из CP13 конечная Fourier-инверсия даёт
\[
 \widehat\phi(\mathfrak p^{-3}h_0)=\phi(\mathfrak p)^3
                                  \widehat\phi(h_0).
\]
Следовательно, прежняя полная S-сумма с фазой от \(\mathfrak p^3z\) равна \(\phi(\mathfrak p)^{-3}\) умножить на исходную полную S-сумму. Кубический supplementary-множитель в \(\phi\) исчезает лишь после кубирования, так что \(\phi(\mathfrak p)^3=\Psi_0(\mathfrak p)^3\); фиксированный лучевой \(\Psi_0^3\) не объявляется единицей.

Совместный множитель равен
\[
 \frac{\alpha(\mathfrak p)^3}{q_{\mathfrak p}}
 [\Psi_0(\mathfrak p)\Psi_{\rm mov}(\mathfrak p)]^{-3}
 =\frac{\overline{A_h(\mathfrak p)}}{q_{\mathfrak p}},
\]
поскольку нулесохраняющая взаимность отождествляет куб этой \(\Psi\) с кубом первоначального \(\nu_*\chi(h)\bar\chi(e)\). Все аргументы \(\mathfrak p\) здесь единичны относительно Rh; нули двойственного z не делятся. Получена (SC.1). ∎

Итерация даёт для любого c с хорошими простыми вне Rh
\[
 G_{q_c\lambda}(c^3\xi;t)
       =\frac{\overline{A_h(c)}}{q_c}G_\lambda(\xi;t).        \tag{SC.15}
\]
Здесь сохраняются **все степени c**. Это точный перенос коэффициентов и профиля, не оценка нового момента.

## 4. Совместная редукция двух кубических носителей с конечной границей

### 4.1. Неизменяемая область и новый точный индекс

Для фиксированных исходных h,R,Z положим
\[
 \mathcal P_Z=\{\mathfrak p\notin S:\mathfrak p\nmid Rh,
                                      \ q_{\mathfrak p}\le Z\}.
\]
Это конечный **набор для алгебры**, не новый фиксированный модуль аналитической леммы. Его произведение не помещается ни в P, ни в K, ни в константы отражения.

На носителе каждого d, а значит и G, единственно выделим
\[
 \xi=c^3\xi_0,\qquad c\text{ поддержан на }\mathcal P_Z,
 \quad v_{\mathfrak p}(\xi_0)\in\{0,1\}\quad(\mathfrak p\in\mathcal P_Z).
\]
Остальные простые, все S-части, все единицы и все оставшиеся кубы \(\xi_0\) сохраняются. Нулевые показатели \(2\pmod3\) были нулевыми по (SC.10), а не удалены новой гипотезой. Обозначим полученный носитель \(\Xi_Z\); для \(z_0=\varpi^4\xi_0\) все перечисленные показатели целочисленны.

Одновременно с c выделяем \(j=(B,c)\):
\[
 \boxed{B=bj,\quad c=aj,\qquad
 b,j\ \rm sf,\quad (b,j)=1,\quad(a,b)=1.}                  \tag{SC.16}
\]
**\((a,j)=1\) не требуется.** Например, \(B=\mathfrak p,c=\mathfrak p^2\) даёт \(b=1,j=\mathfrak p,a=\mathfrak p\). Обратное отображение единственно; a пробегает все \(\mathcal P_Z\)-поддержанные идеалы со всеми степенями. Из исходного \(q_B\le Z\) следует \(q_b\le Z\).

По (SC.15) точный скаляр **одной** стороны преобразуется в
\[
 \frac{\mu(B)A_h(B)}{q_B}\frac{\overline{A_h(c)}}{q_c}
 =\frac{\mu(b)A_h(b)\overline{A_h(a)}}{q_bq_a}
                         \frac{\mu(j)}{q_j^2},
 \qquad \frac{q_B}{q_c}=\frac{q_b}{q_a}.
\]
Это одновременное сокращение реальной фазы, знака и нормы. Знаменатель \(q_j^2\), а не \(q_j\), следует из **двух** первоначальных знаменателей; никакой ортогональности j не использовано.

### 4.2. Полное ограниченное ядро

Проделав то же с \(C=b'j',c'=a'j'\), получаем
\[
\boxed{\begin{aligned}
 W_Z(b,b';z_0,z'_0)=
 \sum_{\substack{j,j'\ \rm sf,\ \operatorname{supp}(jj')\subset\mathcal P_Z\\
                         (j,b)=(j',b')=1}}
 \frac{\mu(j)\mu(j')}{q_j^2q_{j'}^2}
 \mathscr D_Z(bj,b'j')
 K^{\rm full}_{(bj,b'j')}(z_0j^3,z'_0j'^3).
\end{aligned}}                                               \tag{SC.17}
\]
**[ABSTRACT; PAPER из (SC.15), условного на источник].** Почему из аргументов K исчезли a,a′? На любом простом общего \((bj,b'j')\) первая сторона либо содержит его в b — тогда \((a,b)=(j,b)=1\) и флаг равен \(1_{\mathfrak p\mid z_0}\), — либо содержит его в j, и тогда полная двойственная колонка уже делима. Наличие дополнительной степени в a ничего не меняет. То же для второй стороны. На простых вне общего делителя K не зависит от флага. Это точное объяснение, не забытая маска.

Определим **фактическую амплитуду**
\[
 \mathcal F_b(\xi_0;t)=\frac{\mu(b)A_h(b)}{q_b}
 \sum_{\substack{a:\operatorname{supp}(a)\subset\mathcal P_Z\\(a,b)=1}}
       \frac{\overline{A_h(a)}}{q_a}
                         G_{q_b/q_a}(\xi_0;t).              \tag{SC.18}
\]
Никакого \((a,\xi_0)=1\) нет. Все её коэффициенты и масштабы заданы исходником. Это не произвольный вектор на котором затем постулируется хороший операторный результат.

Тогда полная исходная пара равна
\[
 \boxed{\mathscr Q_h(t,t')=
 \sum_{\substack{b,b'\ \rm sf,good\\(bb',Rh)=1,\ q_b,q_{b'}\le Z}}
 \sum_{\xi_0,\xi'_0\in\Xi_Z}
 \mathcal F_b(\xi_0;t)\overline{\mathcal F_{b'}(\xi'_0;t')}
                         W_Z(b,b';z_0,z'_0).}              \tag{SC.19}
\]
Здесь сохранены все \(b,b',a,a',\xi_0,\xi'_0\)-cross, в том числе совпадающие и несовпадающие квадратсвободные части. При последующей подстановке в \(\mathfrak A\) также остаются все \(t,t'\), внешние знаки и первоначальные h-границы.

### 4.3. Почему бесконечный a-ряд законен

Он возник из **уже бесконечной двойственной c-части cusp-носителя**, не из расширения конечного обратного ряда B. В (SC.17) j,j′ конечны, а \(\mathscr D_Z\) хранит прежние границы B,C.

Из SG32–33 и источниковых bounds для \(V^\sharp\), с прямым учётом базовых j=4-факторов, для любого \(\lambda>0\) и хорошего sf f вне Rh:
\[
 \sum_{\substack{\xi\ne0\\ f\mid\varpi^4\xi}}
 |G_\lambda(\xi;t)|
 \ll \mathscr H(t)\,(q_Rq_h)^{1+\epsilon}
                         \frac{\lambda^{3/2}}{\sqrt{X_0}q_f}.
\]
Здесь \(\mathscr H(t)\) — одна фиксированная полиномиальная профильная цена. Для её вывода на каждом базовом cusp берётся \(T=q_{c_\iota}^2\lambda^3/X_0\); SG33 даёт \(\sqrt T/q_f\). Базовые Ramanujan-факторы оплачиваются их настоящей делимостью, как в SG32–33; \(f\) с ними взаимно прост. Число базовых ветвей делительно ограничено нормами R,h, не размером \(\mathcal P_Z\).

После \(\lambda=q_b/q_a\) а-ряд мажорируется
\(\sum_aq_a^{-5/2}\le\zeta_F(5/2)<\infty\). Это единая граница, независимая от числа простых \(\mathcal P_Z\). Оценка работает при \(T<1\) и при \(\lambda<1\); ни один отражённый ряд не обрезан. Поэтому (SC.18) и обе её совместные суммы абсолютно сходятся. Конечные j-перестановки, две cusp-суммы и общая Fourier-мера с достаточно большим фиксированным B допустимы. Это доказательство сходимости, а не новый моментный поставщик.

## 5. Новый знаковый совместный шаг: точная локальная матрица

### 5.1. Алгебраическая полная сетка и обязательный возврат

Введём вспомогательный \(W_\square\): ту же **конечную** сумму (SC.17), но с множителем 1 вместо \(\mathscr D_Z\). Одновременно определим \(W_\partial\) той же суммой с \(1-\mathscr D_Z\). Поэтому
\[
 W_Z=W_\square-W_\partial
\]
**буквально**, со всеми знаками. Область b,b′ в (SC.19) остаётся \(q_b,q_{b'}\le Z\). Этот конечный алгебраический приём не выдаётся за удаление границы из источника: вся \(W_\partial\) ниже возвращена точно и оценена. Никакие бесконечные обратные индексы не добавлены.

Вспомогательные bj могут иметь большую норму, но к ним не вызывается аналитическая лемма с «фиксированным» огромным модулем. Они встречаются только в конечном j-ядре. Их явные веса \(q_j^{-2}\) будут суммированы локально с равномерной ценой. Основной неизменённый объект — всё ещё (SC.17), а не \(W_\square\).

Для каждого \(\mathfrak p\in\mathcal P_Z\) введём три состояния индекса \((b,\xi_0)\):

| Состояние | Точное условие |
|---|---|
| 0 | \(\mathfrak p\nmid b\); обе возможности делимости \(\xi_0\) суммируются с их настоящими коэффициентами |
| 1 | \(\mathfrak p\mid b\), \(\mathfrak p\nmid\varpi^4\xi_0\) |
| 2 | \(\mathfrak p\mid b\), \(\mathfrak p\mid\varpi^4\xi_0\) |

При состоянии 0 j может не содержать простой либо содержать его с коэффициентом \(-q^{-2}\). Во втором случае полный двойственный аргумент делим на \(\mathfrak p\), независимо от квадратсвободного флага. При состояниях 1,2 простой не может входить в j.

### 5.2. Полное вычисление всех локальных пар

**Лемма 3 [ABSTRACT; PAPER].** Для состояния 0 на обеих сторонах сумма четырёх вариантов j,j′ равна
\[
 1-\frac1{q^2}-\frac1{q^2}+\frac{q(2-q)}{q^4}
       =1-\frac3{q^2}+\frac2{q^3}=c_q.
\]
На паре состояний 0 и 1 она равна \(1-q/q^2=a_q\); на паре 0 и 2 — \(1-q(2-q)/q^2=2a_q\). Если простой находится в обоих b,b′, никаких факультативных j-показателей нет, и остаются четыре исходных числа (SC.14). Следовательно,
\[
 W_\square(b,b';z_0,z'_0)
 =\prod_{\mathfrak p\in\mathcal P_Z}
       (\mathbb M_{q_{\mathfrak p}})_{
             \sigma_{\mathfrak p}(b,\xi_0),
             \sigma_{\mathfrak p}(b',\xi'_0)},\qquad
 \mathbb M_q=\begin{pmatrix}c_q&a_q&2a_q\\a_q&0&q\\2a_q&q&q(2-q)\end{pmatrix}.
                                                               \tag{SC.20}
\]
Это **полная парная свёртка \(\mu(j)\mu(j')\)**, не произведение независимых оценок однопростых энергий. Все фазы из (SC.10)–(SC.13) находятся в \(\mathcal F_b\); кубические фазы уже сокращены посредством доказанной (SC.15), а не заменены модулем. Нормы q — идеальные, не рациональные простые; инертная норма 25 обрабатывается так же.

### 5.3. Разложение Шура и нулевой канал

**Лемма 4 [ABSTRACT; PAPER].** Положим
\[
 c=c_q=\frac{(q-1)^2(q+2)}{q^3}>0,\quad
 v_q=\frac{q^2}{(q-1)(q+2)},\quad d_q=\frac q{q+2}>0,
\]
\[
 l_q^+=(1,v_q,2v_q),\qquad l_q^-=(0,1,-q).
\]
Тогда
\[
 \boxed{\mathbb M_q=c_q(l_q^+)^*(l_q^+)
                          -d_q(l_q^-)^*(l_q^-).}           \tag{SC.21}
\]
В частности, для сложных x,y,z
\[
 \boxed{(x,y,z)^*\mathbb M_q(x,y,z)
 =c_q|x+v_q(y+2z)|^2-d_q|y-qz|^2.}                         \tag{SC.22}
\]
Поляризация сохраняет эту формулу для **двух разных** векторов; ниже это обязательно, поскольку t и t′ различны.

**Доказательство.** Первый Schur-pivot равен c>0. После его выделения нижний блок точно равен
\[
 \begin{pmatrix}0&q\\q&q(2-q)\end{pmatrix}
 -\frac1c\begin{pmatrix}a\!\\2a\end{pmatrix}(a,2a)
 =-\frac q{q+2}\begin{pmatrix}1&-q\\-q&q^2\end{pmatrix}.
\]
Он имеет ранг один и неположителен. Оставшийся нулевой pivot **не обращается**. Весь \(\mathbb M_q\) имеет инерцию \((1,1,1)\), где последнее число — размер ядра. Его точный нулевой вектор
\[
 (-q^2/(q-1),q,1).
\]
Это доказывается одновременно \(l_q^+z=l_q^-z=0\). Ненулевой отрицательный минор \(-a_q^2\) и c>0 исключают ошибочное объявление всей матрицы положительной. ∎

**Предел вывода:** (SC.22) — доказанное разложение на действительных состояниях источника, не доказанная контракция исходного вектора. В частности, нельзя отбросить отрицательный локальный канал в каждом простом и затем тензорировать: произведение двух отрицательных каналов даёт **положительный** глобальный вклад. При общей знаковой внешней мере нельзя и каждому квадрату назначить прежний знак после интегрирования.

## 6. Полная знаковая форма на настоящих векторах

### 6.1. Никакой свободной колонки

Пусть \(\sigma\in\{0,1,2\}^{\mathcal P_Z}\). Введём вектор **путём группировки уже заданных амплитуд**, без выбора новых коэффициентов:
\[
 \mathcal V_\sigma(t)=
 \sum_{\substack{b\ \rm sf,good,\ (b,Rh)=1,\ q_b\le Z\\
                  \xi_0\in\Xi_Z,\ \sigma(b,\xi_0)=\sigma}}
                                  \mathcal F_b(\xi_0;t).    \tag{SC.23}
\]
Сходимость доказана в §4.3. Обозначение \(\mathcal V_\sigma\) не связано с исходным положительным резервом \(\mathcal V_N\).

Для \(E\subseteq\mathcal P_Z\) положим
\[
 C_E=\prod_{\mathfrak p\notin E}c_{q_{\mathfrak p}}
                   \prod_{\mathfrak p\in E}d_{q_{\mathfrak p}},
\]
\[
 Z_E(t)=\sum_\sigma\mathcal V_\sigma(t)
       \prod_{\mathfrak p\notin E}l^+_{q_{\mathfrak p}}(\sigma_{\mathfrak p})
       \prod_{\mathfrak p\in E}l^-_{q_{\mathfrak p}}(\sigma_{\mathfrak p}).
\]
Полная тензорная формула даёт
\[
 \mathscr Q_\square(t,t')=
       \sum_{E\subseteq\mathcal P_Z}(-1)^{|E|}C_E
                             Z_E(t)\overline{Z_E(t')}.       \tag{SC.24}
\]
Сумма конечна. Более того, \(l_q^-(0)=0\), поэтому при \(q_E>Z\) в \(Z_E\) нет ни одного b, делящегося на E: **такие каналы точно нулевые**. Размер формальной булевой группы не является новым аналитическим множителем.

### 6.2. Весь конечный возврат

Обозначим
\[
 \mathscr B_Z(t,t')=
 \sum_{b,b',\xi_0,\xi'_0}
 \mathcal F_b(\xi_0;t)\overline{\mathcal F_{b'}(\xi'_0;t')}
                  W_\partial(b,b';z_0,z'_0),               \tag{SC.25}
\]

### 6.3. Почему это не ещё один бесплатный CP27-ноль

В CP27 при фиксированных исходных B,C суммировались **все** двойственные индексы, и пустота одного полного T уничтожала пропущенный s. Отдельный запрет \(\mathscr D_Z(bj,b'j')\) не является в этих координатах прежней полной cusp-суммой с фиксированным B,C. Утверждение о нулевом значении всей \(\mathscr B_Z\) здесь не доказано и не используется.

Конечный коэффициентный контроль: одна простая норма q, b=b′=1, \(\mathfrak p\nmid z_0z'_0\), \(Z=q^2\). Разрешены j=j′=1 и j=j′=\(\mathfrak p\); два односторонних включения нарушают \(q^3\le Z\). Поэтому
\[
 W_Z=1+\frac{q(2-q)}{q^4}=1-\frac1{q^2}+\frac2{q^3},
 \qquad W_\square=1-\frac3{q^2}+\frac2{q^3},
\]
\[
 \boxed{W_Z-W_\square=\frac2{q^2}.}                          \tag{SC.27}
\]
Это обнаруживает **поточечное** стирание новой конечной границы. Это не ненулевое значение полной (SC.25), не контрпример к CP27 и не нижняя оценка \(\mathfrak H_{05}\). Все исходные границы в (SC.17) и (SC.26) остаются включёнными по знаку равенства.

## 8. Исполненная совместная оценка и полная цена её неудачи

### 8.1. Точная мажоранта всех знаковых каналов, без экспоненты за число простых

**[ABSTRACT; PAPER].** После полного вычисления (SC.20)–(SC.26) оценим сумму модулей каналов Шура. Её локальная матрица мажорирования —
\[
 L_q(i,j)=c_q|l_q^+(i)l_q^+(j)|+d_q|l_q^-(i)l_q^-(j)|.
\]
Её существенные значения:
\[
\begin{gathered}
 L_q(0,0)=c_q\le1,\quad L_q(0,1)=a_q\le1,\quad
 L_q(0,2)=2a_q\le2,\\
 L_q(1,1)=\frac{2q}{q+2}\le2,\quad L_q(1,2)=q,\quad
 L_q(2,2)=\frac{q(q^2+4)}{q+2}\le q^2.
\end{gathered}                                               \tag{SC.30}
\]
Таким образом, для \(f=(b,b')\) тензорная мажоранта не больше
\[
 2^{\omega(bb')}q_{(f,z_0)}q_{(f,z'_0)}.
\]
Простые вне \(bb'\) дают \(c_q\le1\), а не множитель 2. В частности, нельзя оценивать число каналов отдельно числом \(2^{|\mathcal P_Z|}\): это потеряло бы уже вычисленную компенсацию и породило бы ложную экспоненциальную цену.

Для **всего граничного члена** берём модуль только после его явного определения (SC.25). Увеличение суммы модулей j,j′ до полной конечной булевой суммы даёт в паре состояний 0,0
\[
 1+\frac3{q^2}-\frac2{q^3}\le1+\frac3{q^2}.
\]
Произведение таких множителей ограничено одной постоянной. В паре 0,1 имеем \(1+1/q\le2\), в паре 0,2 — \(2-2/q\le2\); на остальных парах стоят модули (SC.14). Значит,
\[
 |W_\partial(b,b';z_0,z'_0)|
 \le C_F\,2^{\omega(bb')}q_{(f,z_0)}q_{(f,z'_0)},            \tag{SC.31}
\]
с одной константой, независимой от Z,h,R. Граница не объявлена нулевой. Не взят её модуль по каждому первоначальному cusp-каналу до совместной редукции.

**Именно здесь теряется дальнейшая информация:** (SC.30) заменяет подписанное сочетание \(Z_E\overline{Z'_E}\) суммой модулей; (SC.31) отдельно расходует связь с конечной областью. Это конкретный испытанный достаточный способ оценки, а не обязательное усиление CP34.

### 9.6. Общие профили, все концы и конечное обращение

Сначала весь вывод относится к каждому общему \(W_j\in\mathcal F\), с двумя возможными различными \(V_t,V_{t'}\). После гипотетически доказанной полной оценки восстанавливается положительная \(\mathcal E_M\), и **лишь затем** допускается прежний положительный Соболев для строковых параметров. Производная масштаба остаётся
\(\mathcal D W=-W/2-yW'\); параметрические производные вставляют \(\log y\). P, U, арифметические селекторы и конечные множества меток в текущем точечном доказательстве не дифференцируются.

У обоих концов полосы остаются односторонние единичные логарифмические окна; вышедшие вниз масштабы оплачиваются старым возвратом. Широкое взвешенное окно не даёт бесплатного удаления множителя \(U^{1/1000}\).

Исходное шестистепенное обращение:
\[
 M_u(D;W)=\sum_{d_0\mid\operatorname{rad}a_0}
 \frac{\mu(d_0)\psi_u(d_0)}{\sqrt{q_{d_0}}}
                         M_{u a_0^6}(D/q_{d_0};W).          \tag{SC.44}
\]
Общие простые u,a0, все масштабы и все d0-cross сохраняются. d0 не совпадает ни с d решета, ни с s, ни с новым j.

При **доказанном** полном gain \(\eta'\) исходный потребитель имел бы
\[
 \sum_{u^{(6)}}|M_u(U^r;W_{\sigma_u,t_u})|^2
 \ll\frac HP U^{-\eta'}\mathscr L
 =U^{(1+5r)/6-(\eta'-5rc_0/6)}\mathscr L.                   \tag{SC.45}
\]
Нужны \(\eta'>113/1200000\) **плюс все действительные потери**. При \(\eta=1/200\) сырой минимум — \(5887/1200000\); после \(\theta=1/250\) остаётся \(1087/1200000\). Конечный порядок A должен быть зафиксирован до роста \(T_1\). Полный антецедент здесь не доказан; нового обратного, высокого или нуль-свободного результата нет.

## 10. Самоатака: что новая редукция доказывает и чего не доказывает

**Сильнейшее возражение:** «Ты получил ещё одну точную форму, а затем настолько грубо оценил её границу, что показатель стал хуже. Это не доказательство MB34». Верно. Основной вердикт — **NO_DERIVATION**. Новая бумажная работа состоит в источниковой кубической ковариантности, настоящей матрице состояний и вычисленной цене конкретного совместного оценочного выхода. Она не закрывает требуемый софинальный квантор.

**Возражение к самому входу:** «Фаза куба из d ещё не является фазой всей G». Именно поэтому §3.3 отдельно возвращает \(\alpha\), все базовые \(B_{v,j}\), фиксированную Fourier-перестановку \(h_0\mapsto\mathfrak p^{-3}h_0\), нормированный \(c_F\), \(\kappa_F\), аддитивный характер и lift-компенсацию CP20. Одна (SC.12) без этого доказательства не давала бы (SC.1). Это первоочередное место независимого аудита.

**Возражение к булевому произведению:** «Оно стирает исходный cutoff». Для самого \(W_Z\) произведения не заявлено. Формула (SC.26) сохраняет точный \(W_\square-W_\partial\), а (SC.17) — исходную область вообще без расширения. Дополнительные j остаются конечными алгебраическими слагаемыми, все они вычтены через \(\mathscr B_Z\). Если при дальнейшем использовании потерять этот член, результат уже не относится к исходному потребителю.

**Возражение к знаку:** «Локальный отрицательный квадрат может доминировать». Его доминирование на фактических \(\mathcal V_\sigma\) не доказано; обратное тоже не доказано. Два отрицательных локальных канала дают положительный глобальный канал, а внешняя Fourier-мера не обязана быть положительной. Поэтому не использованы ни локальная PSD-подмена, ни положительный квадратный корень, ни предположение о спектральном зазоре. Нулевой канал хранится без обращения.

**Возражение к локальному product-only исключению:** «Положительная нижняя граница произведения не означает большую исходную сумму». Именно так. (SC.29) отвергает только попытку получить степень U от самого произведения \(c_q\); она ничего не говорит о размере амплитуд \(Z_E\), их компенсации или массе high-poor. Полной отрицательной верхней огибающей запаса MB34 здесь нет.

        return tuple((p+[F(0)]*self.d)[:self.d])
    def add(self,a,b): return tuple(x+y for x,y in zip(a,b))
    def sub(self,a,b): return tuple(x-y for x,y in zip(a,b))
    def sm(self,c,a): return tuple(c*x for x in a)
    def mul(self,a,b):
        p=[F(0)]*(2*self.d-1)
        for i,x in enumerate(a):
            if x:
                for j,y in enumerate(b):
                    if y: p[i+j]+=x*y
        return self.reduce(p)
    def root(self,j): return self.roots[j%self.n]
    def conj(self,a):
        v=self.zero
        for j,x in enumerate(a):
            if x: v=self.add(v,self.sm(x,self.root(-j)))
        return v
    def phase(self,x):
        e=self.n*tr(x)
        if e.denominator!=1: raise AssertionError(('wrong cyclotomic order',self.n,e))
        return self.root(int(e))
    def sum(self, xs):
        v=self.zero
        for x in xs: v=self.add(v,x)
        return v

@lru_cache(None)
def ff(ell):
    """The inert residual field F_(ell^2), represented in the Eisenstein basis."""
    def mul(x,y):
        z=em(x,y); return int(z[0])%ell,int(z[1])%ell
    def power(x,k):
        z=(1,0)
        while k:
            if k&1: z=mul(z,x)
            x=mul(x,x); k//=2
        return z
    def red(x): return int(x[0])%ell,int(x[1])%ell
    def ch(x,order):
        x=red(x)
        if x==(0,0): return None
        z=power(x,(ell*ell-1)//order)
        if order==3: return [(1,0),(0,1),((-1)%ell,(-1)%ell)].index(z)
        if order==2: return 0 if z==(1,0) else 1
        raise ValueError(order)
    return mul,power,red,ch

@lru_cache(None)
def split_ch(p,x):
    q=int(norm(p)); w=(-int(p[0])*pow(int(p[1]),-1,q))%q
    z=(int(x[0])+int(x[1])*w)%q
    if z==0: return None
    return [1,w,pow(w,2,q)].index(pow(z,(q-1)//3,q))

def gauss_split(ring,p,a):
    q=int(norm(p)); result=ring.zero
    for x in range(q):
        j=split_ch(p,(x,0))
        if j is not None:
            z=ed(em(a,(F(x),F(0))),p)
            result=ring.add(result,ring.mul(ring.root(j*ring.n//3),ring.phase(z)))
    return result

def gauss_product(ring,p,q,a):
    Np,Nq=int(norm(p)),int(norm(q))
    wp=(-int(p[0])*pow(int(p[1]),-1,Np))%Np
    wq=(-int(q[0])*pow(int(q[1]),-1,Nq))%Nq
    qr=(int(q[0])+int(q[1])*wp)%Np
    pr=(int(p[0])+int(p[1])*wq)%Nq
    ip,iq=pow(qr,-1,Np),pow(pr,-1,Nq)
    result=ring.zero; pq=em(p,q)
    for x,y in product(range(Np),range(Nq)):
        j=split_ch(p,(x,0)); k=split_ch(q,(y,0))
        if j is None or k is None: continue
        r=ea(scale(x*ip,q),scale(y*iq,p))
        result=ring.add(result,ring.mul(ring.root((j+k)*ring.n//3),ring.phase(ed(em(a,r),pq))))
    return result

def kp(q,x,y): return 1-(-1+q*x)*(-1+q*y)
def optional(q,left,right):

def domain(Z,B,C):

def kernel(qs,b,bp,eps,epsp,Z=None):
