## 3. Настоящие коэффициенты полного конечнопростого оператора

### 3.1. Неизменяемый объект

**[ABSTRACT; PAPER]** Работаем в \(F=\mathbb Q(\sqrt{-3})\), с хорошими идеалами и их исходными первичными образующими. Все строки \(u\ne0\) — **элементы**, включая шесть единиц и допустимые \(S\)-простые с показателями от нуля до пяти. Фиксированы \(\nu\), \(\varepsilon_\chi\in\{1,-1\}\), исходный \(S\), \(\rho\ge0\) и общий гладкий профиль \(W\) с

\[
 \operatorname{supp}W\subset[\alpha_W,\beta_W]\subset(0,\infty).
\]

Полагаем

\[
 \psi_u(n)=\nu(n)\chi_n(u)^{\varepsilon_\chi},\qquad
 M_u^{[R]}(N;W)=N^{-1/2}
 \sum_{\substack{n\ {
m good}\\(n,R)=1}}
       \mu(n)\psi_u(n)W(q_n/N).
 \tag{MB.6}
\]

Значения символов в нулевых ветвях не делятся и не заменяются единицами. На хороших простых \(|\psi_u(p)|^2=1_{p\nmid u}\). Все дальнейшие формулы сохраняют обе исходные ориентации.

При \(\mathcal P_K=\{p\notin S:q_p\le K\}\) пусть

\[
 A_pv(N)=\sum_{j\ge1}\psi_u(p)^j q_p^{-j/2}v(N/q_p^j),
 \qquad A_T=\prod_{p\in T}A_p,
\]

и \(Q_{u,R,K}[v]=\sum_{T\subset\mathcal P_K,\ (\prod_{p\in T}p,R)=1}(-1)^{|T|}|A_Tv|^2\). Это буквальный оператор P5 из нового входа, а не произведение независимо обрезанных однопростых энергий. fileciteturn0file0L108-L122

### 3.2. Одновременное обращение всех степеней

**Лемма 1 [ABSTRACT; PAPER].** Пусть \(t=\prod_{p\in T}p\), \((t,R)=1\). Тогда

\[
 \boxed{
 A_T M_u^{[R]}(N;W)
 =\frac{\psi_u(t)}{\sqrt{q_t}}
      M_u^{[Rt]}(N/q_t;W).
 }\tag{MB.7}
\]

Это утверждение о полном локально конечном ряде степеней. Если \(\psi_u(t)=0\), обе стороны равны нулю.

**Доказательство.** Используем проверенное во входе полное геометрическое обращение

\[
 M^{[Rp]}=\sum_{j\ge0}\psi_u(p)^j q_p^{-j/2}
                              M^{[R]}(N/q_p^j),
\]

откуда \(A_pM^{[R]}=\psi_u(p)q_p^{-1/2}M^{[Rp]}(N/q_p)\). Операторы разных простых коммутируют; последовательное применение, каждый раз к уже полученной маске, доказывает (MB.7).

Можно проверить именно сохранение степеней по коэффициентам. При \(n=dm\) нормировка сокращается как

\[
 q_d^{-1/2}(N/q_d)^{-1/2}=N^{-1/2}.
\]

Для показателя \(k=v_p(n)\ge1\) остаётся сумма \(\sum_{j=1}^{k}\mu(p^{k-j})\). Она равна единице при \(k=1\) и нулю при \(k\ge2\), причём последнее сокращение использует две последние степени. Удаление сдвига \(j=2\) уже при \(k=2\) оставляет \(-1\) вместо нуля. Таким образом, степени **суммированы точно**, а не отброшены. ∎

Из (MB.7) немедленно получается

\[
 \boxed{
 Q_{u,R,K}[M_u^{[R]}](N)
 =\sum_{\substack{t\ {
m sf,good}\\p\mid t\Rightarrow q_p\le K\\(t,R)=1}}
      \frac{\mu(t)}{q_t}\,1_{(u,t)=1}
      |M_u^{[Rt]}(N/q_t;W)|^2.
 }\tag{MB.8}
\]

Введённый здесь **радикал** \(t\) — произведение различных простых. Это не ограничение прежних двух сдвигов \(d_1,d_2\) бесквадратными идеалами: их полные геометрические суммы уже выполнены в (MB.7).

### 3.3. Что меняет верхний отсекатель: полный смешанный коэффициент

Для проверки реальной границы, а не только внутренней части, возьмём
\(v_D(N)=1_{N\le D}M_u^{[R]}(N;W)\). Для непустого \(T\) запишем
\(n=n_Tm\), где \(n_T=\prod_{p\in T}p^{k_p}\), все \(k_p\ge1\),
\((m,t)=1\), \(m\) бесквадратен. Обозначим
\(t_2(n)=\prod_{p\in T:k_p\ge2}p\). Тогда

\[
\begin{split}
 A_Tv_D(N)
 &=N^{-1/2}
   \sum_{\substack{n=n_Tm\ {
m good}\\(n,R)=1\\m\ {
m sf},\ (m,t)=1}}
   \mu(m)\psi_u(n)W(q_n/N)
       \kappa_T\!\left(n;\frac ND\right),\\
 \kappa_T(n;x)
 &=\sum_{e\mid t_2(n)}\mu(e)
          1_{\,x\le q_{n_T}/q_e}.
\end{split}\tag{MB.9}
\]

**Вывод.** В каждом ненулевом члене \(j_p=k_p\) либо \(j_p=k_p-1\); второе разрешено только при \(k_p\ge2\). Выбор вторых вариантов образует \(e\mid t_2(n)\). Исходный отсекатель есть одно условие
\(N\le D\prod_{p\in T}q_p^{j_p}=Dq_{n_T}/q_e\). Его нельзя заменить отдельным условием для каждого \(p\). При фиксированном \(N\) сумма конечна по поддержке \(W\), поэтому перестановка точна.

Например, для двух независимых простых норм \(7,13\) и \((k_1,k_2)=(2,2)\)

\[
 \kappa(x)=1_{x\le8281}-1_{x\le1183}
                        -1_{x\le637}+1_{x\le91}.
\]

При \(x=100\) это \(-1\), при \(x=2000\) — \(1\). Это **точный коэффициентный контроль**, не утверждение о знаке полного исходного полинома. Квадрат (MB.9) сохраняет обе независимые колонки и все перекрёстные члены. Для \(T=\varnothing\) остаётся исходный \(v_D\), который во внешнем хвосте равен нулю.

Следующие разделы оценивают полную сборку этих смешанных членов, не распределяя их по независимым простым.

## 4. Сумма по исходному общему делителю: решающее \(K>G\)

### 4.1. Полная перегруппировка

**Лемма 2 [ABSTRACT; PAPER].** Пусть \(K>G>1\), как в текущем запросе. Определим

\[
 \beta_G(h)=\sum_{\substack{g\mid h\\q_g<G}}\mu(h/g)
 \qquad(h\ {
m sf,good}).
\]

Тогда буквальный конечнопростой префикс Q10(19) удовлетворяет

\[
\boxed{
\begin{split}
 \mathfrak H_K^{\rm pr}(L)
 ={}&\sum_{\substack{h\ {
m sf,good}\\p\mid h\Rightarrow q_p\le K}}
       \frac{\beta_G(h)}{q_h}
       \sum_{\substack{a\ {
m good},\ q_a\le P\\(a,h)=1}}
       \sum_u^{(6)}\rho(q_u/U)1_{(u,h)=1}\\
 &\hspace{27mm}\times
       |M_u^{[ah]}(L/q_h;W)|^2.
\end{split}}\tag{MB.10}
\]

**Доказательство.** Вставляем (MB.8) в Q10(9) с исходным внешним коэффициентом \(1/q_g\), исходным \(a\le P,(a,g)=1\) и \(1_{(u,g)=1}\). Условия дают \((t,ag)=1\); следовательно, \(h=gt\) бесквадратен, и

\[
 \frac1{q_gq_t}=\frac1{q_h},\qquad
 \frac L{q_gq_t}=\frac L{q_h},\qquad
 1_{(u,g)=1}1_{(u,t)=1}=1_{(u,h)=1}.
\]

Маска становится ровно \(ah\), а условие усилителя — \((a,h)=1\). Каждый простой \(g\) имеет норму меньше \(G<K\); поэтому \(h\) поддержан на \(\mathcal P_K\). Обратно, для каждого такого \(h\) и любого делителя \(g\mid h,q_g<G\) допустим \(t=h/g\); его знак равен \(\mu(h/g)\). Все остальные множители уже независимы от выбора \(g\). Получается (MB.10). ∎

Поскольку при \(q_h<G\) участвуют все делители,

\[
 \boxed{\beta_G(1)=1,\qquad
 \beta_G(h)=0\quad(1<q_h<G).}\tag{MB.11}
\]

На границе \(q_h=G\) обнуления не утверждается: условие исходно строгое. В частности, для простого \(h\) нормы \(G\) коэффициент равен \(-1\). За границей также возможны оба знака. Всегда \(|\beta_G(h)|\le d_{\mathcal O}(h)\).

Получаем точное равенство

\[
 \mathfrak H_K^{\rm pr}(L)=\mathcal E(L)+\mathcal T_{G,K}(L),
\]

где \(\mathcal T_{G,K}\) — вся правая сторона (MB.10) с \(q_h\ge G\).

**Это возврат исходной энергии с коэффициентом один.** Его нельзя зачислить как новое сокращение. В частности, простые \(q_p>K\), общие у остаточных колонок, не исчезли: они по-прежнему разрешены внутри квадратов \(M^{[ah]}\). Разница с исходным взаимно-простым префиксом возвращается прежним Q10-хвостом.

### 4.2. Вся оставшаяся \(h\)-граница оплачивается совместно

**Лемма 3 [COFINAL_FAMILY; CONDITIONAL на M].** Равномерно по \(0<L\le D\)

\[
 \boxed{
 |\mathcal T_{G,K}(L)|
 \ll P(UPD)^\epsilon(1+T_1)^A
       \{U+U^{1/6}L^{5/6}G^{-5/6}\}.
 }\tag{MB.12}
\]

**Доказательство.** Непустой масочный полином при масштабе \(L/q_h\) требует
\(q_h\le\beta_WL\). Поэтому в каждом действительном вызове M маска удовлетворяет
\(q_{ah}\le P\beta_WD\); её малостепенная цена равномерна, хотя она движется.

Только теперь используем \(|\beta_G(h)|\le d_{\mathcal O}(h)\) и неотрицательность каждой внутренней энергии. Удаление \(1_{(u,h)=1}\) разрешено внутри этой положительной верхней оценки. Число исходных \(a\) не превосходит \(C_SP\). По (MB.4) остаются

\[
 CP(UPD)^\epsilon(1+T_1)^A
 \left\{
 U\sum_{G\le q_h\le\beta_WL}\frac{d_{\mathcal O}(h)}{q_h}
 +U^{1/6}L^{5/6}
       \sum_{q_h\ge G}\frac{d_{\mathcal O}(h)}{q_h^{11/6}}
 \right\}.
\]

Для любого заранее малого \(\epsilon_1>0\) делительная оценка и подсчёт идеалов дают
первую сумму \(\ll D^{\epsilon_1}\), вторую \(\ll G^{-5/6+\epsilon_1}\).
Предварительные потери выбираются внутри итогового \(\epsilon\). Это доказывает (MB.12).

Здесь нет множителя \(2^{|\mathcal P_K|}\), произведения норм всех малых простых или потери от независимого оценивания подмножеств. Все подмножества сначала собраны в **один действительный коэффициент** \(\beta_G(h)\). ∎

## 5. Полная смешанная внешняя граница

### 5.1. Физическая нормировка

Для каждого исходного \(g,a,u\) положим

\[
 D_g=L_0/q_g,\qquad
 v_{u,ag,L_0}(N)=1_{N\le D_g}M_u^{[ag]}(N;W).
\]

Определим без сокращения суммы подмножеств

\[
\boxed{
\begin{split}
 \mathcal B_\delta(L_0)
 ={}&L_0^{-\delta}
 \sum_{\substack{g\ {
m sf,good}\\q_g<G}}q_g^{\delta-1}
 \sum_{\substack{a\ {
m good},\ q_a\le P\\(a,g)=1}}
 \sum_u^{(6)}\rho(q_u/U)1_{(u,g)=1}\\
 &\quad\times\int_{L_0/q_g}^{\infty}
    \sum_{\substack{T\subset\mathcal P_K\\(\prod_{p\in T}p,ag)=1}}
       (-1)^{|T|}|A_Tv_{u,ag,L_0}(N)|^2
                              N^\delta\,\frac{dN}{N}.
\end{split}}\tag{MB.13}
\]

Коэффициент снаружи равен **\(q_g^{\delta-1}\), не \(q_g^{-1}\)**. Это физический возврат \(L=q_gN\):
\(L^\delta/q_g=q_g^{\delta-1}N^\delta\). Отсутствие этого множителя изменило бы функционал.

Обозначим через \(\mathcal F_\delta(L_0)\) ту же сборку с интегралом по \((0,\infty)\), а через
\(\mathcal T_\delta(L_0)=L_0^{-\delta}\int_0^{L_0}\mathcal T_{G,K}(L)L^\delta dL/L\).
Причинность сдвигов гарантирует: при \(N\le D_g\) они используют только исходный полином, а не новые значения за отсекателем. Поэтому (MB.10) даёт точное равенство

\[
 \boxed{
 \mathcal B_\delta(L_0)
 =\mathcal F_\delta(L_0)
       -\mathcal E_\delta(L_0)-\mathcal T_\delta(L_0).
 }\tag{MB.14}
\]

**[ABSTRACT; PAPER]** Это включает весь смешанный хвост (MB.9). Однопростые энергии нигде не складывались как независимые.

### 5.2. Сходимость и цена полной части

Взвешенный множитель W1–W2 уже проверен во входе; его вывод здесь не повторяется. Используется ровно его заключение:

\[
 0\le\int_0^\infty Q_{u,R,K}[v](N)N^\delta\frac{dN}{N}
 \le\exp\!\left(-\frac49
      \sum_{\substack{p\in\mathcal P_K\\p\nmid Ru}}q_p^{\delta-1}\right)
       \|v\|_\delta^2.
 \tag{MB.15}
\]

Конечное произведение абсолютно сходящихся операторных геометрических рядов обеспечивает существование полной и внешней частей для каждого фиксированного \(U\). Тест \(v\) снизу пуст, сверху ограничен и принадлежит взвешенному \(L^2\). Его скачок на \(D_g\) допустим: дифференцирование отсекателя не применяется. Исходный положительный множитель требует \(q_p\ge7\), \(\delta=1/10\), и эти условия сохранены. fileciteturn0file0L159-L192

Остаётся проверить **равномерность** малости полной части, не делая из неё оконного вывода. Для фиксированного поля обычная теорема о простых идеалах даёт

\[
 \#\{p\notin S:K/2<q_p\le K\}\gg_{F,S}K/\log K.
\]

Используется только фиксированное поле, то есть частный случай фиксированного расширения в теореме Чеботарёва. Это также ровно вид входа S:7019–7039. Внешняя проверка ограничена формулировкой Thorner–Zaman, arXiv:1803.02823v3, с. 1–2, включая возможный исключительный член; для фиксированного поля он не меняет асимптотику при \(K\to\infty\). **Равномерной области без нулей по движущимся Hecke-характерам отсюда не берётся.** citeturn306952view0

На исходном носителе \(q_{uag}\le C_\rho UPG\). Число простых из \((K/2,K]\), делящих \(uag\), не превосходит

\[
 \frac{\log(C_\rho UPG)}{\log(K/2)}=O(1),
 \qquad K=U^{1/80}.
\]

Константа равномерна по \(r\in[28/25,113/100]\), поскольку
\(\log_UP=(r(1+c_0)-1)/6\) лежит в фиксированном интервале. Удаление первоначального фиксированного \(S\) меняет только порог. Значит, при достаточно большом \(U\), равномерно по всем исходным строкам и маскам,

\[
 \sum_{\substack{p\in\mathcal P_K\\p\nmid uag}}q_p^{-9/10}
 \gg \frac{K^{1/10}}{\log K}.
\]

Обозначая \(c_*>0\) фиксированную константу, получаем

\[
 \Theta(U)=\exp\!\left(-c_*\frac{U^{1/800}}{\log U}\right),
 \qquad \Theta(U)\ll_M U^{-M}\quad\text{для каждого фиксированного }M.
 \tag{MB.16}
\]

**[COFINAL_FAMILY; PAPER]** для этой оценки множителя. Порог может зависеть от \(M\) и фиксированных данных, но не от \(u,g,a\), высоты или текущего простого.

После (MB.4) полная сумма норм в (MB.15) не превосходит

\[
 \begin{split}
 &L_0^{-\delta}\sum_{g<G}q_g^{\delta-1}
       \sum_{a\le P}\sum_u^{(6)}\rho(q_u/U)
          \int_0^{L_0/q_g}|M_u^{[ag]}(N;W)|^2N^\delta\frac{dN}{N}\\
 &\qquad\ll P(UPD)^\epsilon(1+T_1)^A
       \left\{\frac U\delta\sum_{g<G}\frac1{q_g}
        +\frac{U^{1/6}L_0^{5/6}}{\delta+5/6}
                          \sum_{g<G}q_g^{-11/6}\right\}.
 \end{split}
\]

Здесь M вызывается только с маской \(ag\) и масштабами \(N\le L_0/q_g\le D\). **Момент для огромной маски, содержащей все простые до \(K\), не используется.** Сумма \(q_g^{-1}\) логарифмична, вторая сходится. Следовательно,

\[
 0\le\mathcal F_\delta(L_0)
 \ll \Theta(U)P(UPD)^\epsilon(1+T_1)^A
       \{U+U^{1/6}L_0^{5/6}\}.
 \tag{MB.17}
\]

Область и проверка (MB.17): **[COFINAL_FAMILY; CONDITIONAL на M]**. Полная часть действительно сверхполиномиально мала. Но она **не** равна требуемому оконному функционалу.

### 5.3. Доказательство совместной оценки границы

Интегрируя (MB.12), получаем

\[
 |\mathcal T_\delta(L_0)|
 \ll P(UPD)^\epsilon(1+T_1)^A
 \left\{\frac U\delta+
    \frac{U^{1/6}L_0^{5/6}G^{-5/6}}{\delta+5/6}\right\}.
 \tag{MB.18}
\]

Подстановка (MB.17)–(MB.18) в **точное** (MB.14) доказывает (MB.1). Полная малость (MB.17) поглощается ошибкой с любым нужным фиксированным степенным запасом.

Это и есть выполненная совместная оценка: неизвестная многопростая внешняя граница сведена к **минус одной исходной положительной энергии**, с равномерно оплаченной ошибкой. У неё не осталось неоплаченного дополнительного множителя за подмножества, за степени, за \(g\), за усилитель или за перемещение маски.

Есть полезная точная дихотомия. Пусть \(\mathcal R_\delta\ge0\) — доказанная правая верхняя огибающая ошибки в (MB.1), с фиксированной достаточно большой константой. Тогда

\[
 \mathcal E_\delta\le2\mathcal R_\delta
 \quad\text{либо}\quad
 \mathcal B_\delta\le-\mathcal E_\delta+\mathcal R_\delta
                      <-\tfrac12\mathcal E_\delta<0.
 \tag{MB.19}
\]

В первой ветви энергия уже оплачена. Во второй реальная граница обязана быть отрицательной и сравнимой с этой энергией. **Какая ветвь имеет место для всей исходной семьи, не установлено.** Поэтому (MB.19) не выдаётся за опровержение арифметической цели или за доказательство отрицательности границы во всех случаях.

## 6. Нижнее окно, диагональ и полный бюджет

### 6.1. Нижняя часть не удаляется по знаку

Пусть \(L_-=DU^{-1/100}\). Для общего \(0<L_1<L_0\) точное оконное равенство имеет вид

\[
 \begin{split}
 L_0^{-\delta}\int_{L_1}^{L_0}
       \mathfrak H_K^{\rm pr}(L)L^\delta\frac{dL}{L}
 ={}&\mathcal F_\delta(L_0)-\mathcal B_\delta(L_0)\\
 &-L_0^{-\delta}\int_0^{L_1}
       \mathfrak H_K^{\rm pr}(L)L^\delta\frac{dL}{L}.
 \end{split}\tag{MB.20}
\]

Последний интеграл сохранён. Из (MB.2), (MB.4), (MB.12) следует

\[
 \begin{split}
 &L_0^{-\delta}
 \left|\int_0^{L_-}\mathfrak H_K^{\rm pr}(L)L^\delta\frac{dL}{L}\right|\\
 &\qquad\ll P(UPD)^\epsilon(1+T_1)^A
       \left(\frac{L_-}{L_0}\right)^\delta
       \{U+U^{1/6}L_-^{5/6}\},\qquad L_0\ge L_-.
 \end{split}\tag{MB.21}
\]

Фактическая пустота самых малых масштабов сохранена. Если алгебраическое продолжение префикса к этим масштабам включает \(b=c=1\), этот член входит в (MB.20)–(MB.21), а не объявляется гауссовым нулём. На верхней полосе \(L\gg G\) его аннулярный профиль пуст при достаточно большом \(U\).

### 6.2. Точные показатели

Положим

 h_0=r(1+c_0),\quad p_0=(h_0-1)/6,\quad

\]

Показатели двух членов ошибки (MB.1) равны

 p_0+1,\qquad
 p_0+\frac16+\frac{5\ell}{6}-\frac1{120}.
 \tag{MB.22}
\]

Вторая разность с целью \(h_0-1/200\) минимальна при \(\ell=r\), затем при минимальном \(r=28/25\). Она равна

 \frac1{120}-\frac1{200}+\frac{5rc_0}{6}

В этой записи предварительные малые степени \((UPD)^{\epsilon_1}\) переобозначены как \(U^\epsilon\), поскольку все логарифмические диапазоны ограничены. Это не бесплатное удаление потерь: \(\epsilon_1\) выбирается заранее в зависимости от итогового \(\epsilon\).

Добавленная в \(\mathfrak H_K^{\rm pr}\) диагональ равных первичных колонок имеет прежнюю собственную цену \(\ll PU(UPD)^\epsilon\), Q10(20). Она сохранена как часть точного (MB.10). Её нельзя повторно вычесть, сославшись на гауссову диагональ Q9. Эти две диагонали принадлежат разным представлениям. fileciteturn0file0L908-L920

## 7. Первый неоплаченный арифметический объект — не ещё одно граничное тождество

### 7.1. Точная мера разреженного образа

**[ABSTRACT; PAPER]** Для каждого ненулевого элемента \(v\in\mathcal O\) определим

\[
 \Omega_{U,P}(v)
 =\sum_{\substack{u^{(6)},\ a\ {
m good},\ q_a\le P\\ua^6=v}}
                       \rho(q_u/U).
 \tag{MB.24}
\]

В сумме не более одной пары. В самом деле, показатели простых modulo шесть определяют идеал \((u)\), а целые частные — \(a\); его первичный образующий фиксирует сам элемент \(u\), включая единицу. Для простых из \(S\) условие \(a\ {
m good}\) сохраняется: строки с \(v_{\mathfrak p}(v)\ge6\) хотя бы при одном \(\mathfrak p\in S\) не попадают в этот образ. Во всём исходном \(u\)-семействе показатели из \(S\) от нуля до пяти остаются. Это именно инъекция источника, без допущения \((u,a)=1\). fileciteturn4file0L110-L117

Нуле-сохраняющее равенство
\(\psi_{ua^6}(n)=\psi_u(n)1_{(n,a)=1}\) даёт

\[
 \boxed{\mathcal E(L;W)=\sum_{v\ne0}\Omega_{U,P}(v)|M_v(L;W)|^2.}\tag{MB.25}
\]

Пусть \(C_H\ge1\) фиксировано так, чтобы носитель \(\Omega\) лежал в
\(\mathcal V_H=\{v:0<q_v\le C_H H\}\). Можно взять \(C_H\) не меньше верхней границы носителя \(\rho\), поскольку \(UP^6=H\). Положим

\[
 \begin{gathered}
 V_H=\#\mathcal V_H,\qquad
 Z_{U,P}=\sum_v\Omega_{U,P}(v),\qquad
 \lambda_{U,P}=Z_{U,P}/V_H,\\
 \omega_{U,P}(v)=\Omega_{U,P}(v)
                      -\lambda_{U,P}1_{\mathcal V_H}(v).
 \end{gathered}\tag{MB.26}
\]

Здесь \(V_H>0\), а при пустом исходном образе \(\lambda=0\). По инъекции

\[
 Z_{U,P}
 =\#\{a\ {
m good}:q_a\le P\}
       \sum_u^{(6)}\rho(q_u/U)\ll_{\mathcal A,\rho}PU.
\]

Подсчёт элементов даёт \(V_H\gg H\), поэтому

\[
 0\le\lambda_{U,P}\ll PU/H=P^{-5},\qquad
 \sum_v\omega_{U,P}(v)=0,\qquad
 \sum_v|\omega_{U,P}(v)|\le2Z_{U,P}\ll PU.
 \tag{MB.27}
\]

**[COFINAL_FAMILY; PAPER]** для счётных границ. Число \(\lambda\) — точное отношение масс, общее для всех профилей и обеих ориентаций. Оно не зависит от колонки или отдельно выбранной строки. Никакая гипотеза о равномерном распределении образа не введена.

### 7.2. Оплаченное сравнение и точная двухколоночная корреляция

Положим \(\mathcal R_H(L;W)=\sum_{v\in\mathcal V_H}|M_v(L;W)|^2\). Тогда

\[
 \mathcal E(L;W)
 =\lambda_{U,P}\mathcal R_H(L;W)
 +\frac1L\sum_{b,c\ {
m good}}
     \mu(b)\mu(c)\nu(b)\overline{\nu(c)}
     W(q_b/L)\overline{W(q_c/L)}\Delta_{U,P}(b,c),
 \tag{MB.28}
\]

где **точный арифметический дефект** — это

\[
\begin{split}
 \Delta_{U,P}(b,c)
 ={}&w_P(bc)\sum_u^{(6)}\rho(q_u/U)
              \chi_b(u)^{\varepsilon_\chi}
              \chi_c(u)^{-\varepsilon_\chi}\\
 &-\lambda_{U,P}\sum_{v\in\mathcal V_H}
              \chi_b(v)^{\varepsilon_\chi}
              \chi_c(v)^{-\varepsilon_\chi}.
\end{split}
\]

Здесь \(w_P\) не заменён плотностью: он получен точным суммированием
\(1_{(a,bc)=1}\) по первоначальным \(a\). Первая сумма содержит все прежние шестистепенно-свободные элементы и все их нули. Вторая сумма — отдельное вспомогательное сравнение по всем элементам, **с явным возвратом** \(\lambda\mathcal R_H\).

Искомый оставшийся объект теперь можно выписать без граничных операторов:

\[
\boxed{
\begin{split}
 \mathfrak D_{\rm off}(U,P,L;W)
 =\frac1L\operatorname{Re}\!
 \sum_{\substack{b,c\ {
m sf,good}\\b\ne c}}
       \mu(b)\mu(c)\nu(b)\overline{\nu(c)}
       W(q_b/L)\overline{W(q_c/L)}\\
 \hspace{17mm}\times\left[
 w_P(bc)\sum_u^{(6)}\rho(q_u/U)
          \chi_b(u)^{\varepsilon_\chi}\chi_c(u)^{-\varepsilon_\chi}
 -\lambda_{U,P}\sum_{v\in\mathcal V_H}
          \chi_b(v)^{\varepsilon_\chi}\chi_c(v)^{-\varepsilon_\chi}
 \right].
\end{split}}\tag{MB.29}
\]

При общем \(W,\overline W\) вещественность следует из перестановки \(b,c\), так что \(\operatorname{Re}\) лишь подчёркивает нужную ориентацию неравенства. Это не оценка каждого \(\Delta(b,c)\) отдельно.

По R и (MB.27)

\[
 0\le\lambda_{U,P}\mathcal R_H(L;W)
 \ll PU(HD)^\epsilon(1+T_1)^A.
 \tag{MB.30}
\]

**[COFINAL_FAMILY; CONDITIONAL на R]**. Таким образом, радиальная часть действительно оплачена, а не просто вычтена.

### 7.3. Центрирование массы не убирает диагональную маску

На \(b=c\)

\[
 \Delta_{U,P}(b,b)=\sum_v\omega_{U,P}(v)1_{(v,b)=1}.
\]

Равенство \(\sum_v\omega(v)=0\) **не** означает, что это выражение равно нулю. Диагональная часть (MB.28), обозначенная \(\mathfrak D_{\rm diag}\), удовлетворяет

\[
 \begin{split}
 |\mathfrak D_{\rm diag}|
 &\le\frac{\|W\|_\infty^2}{L}
       \#\{b:q_b\in[\alpha_WL,\beta_WL]\}
       \sum_v|\omega(v)|\\
 &\ll_{\mathcal A,W}PU
 \end{split}\tag{MB.31}
\]

для верхних масштабов; пустые и ограниченные масштабы покрываются тем же конечным соглашением о носителе. Это **[COFINAL_FAMILY; PAPER]**, не новое моментное предположение.

## Приложение A. Воспроизводимые точные диагностики

Сохрани следующий блок как `Q01_MIXED_EXACT_CHECK.py` и запусти `python3 Q01_MIXED_EXACT_CHECK.py` в Linux или macOS. Внешних пакетов нет. Числа `ps` — нормы независимых формальных простых слотов; `G`, `K`, `L` — конкретные контрольные отсекатели и масштабы. Они не заменяют исходное бесконечное арифметическое семейство. Все рациональные константы заданы через `Fraction`; проверка аналитических M/R этим запуском не выполняется.

```python
"""Finite algebra diagnostics. Not a certificate of any analytic moment bound."""
from fractions import Fraction as F
from itertools import product
from math import prod
from collections import Counter

checks = Counter()

def mu_power(e: int) -> int:
    return 1 if e == 0 else -1 if e == 1 else 0

def divisors_sf(ps: tuple[int, ...]):
    for bits in product((0, 1), repeat=len(ps)):
        yield prod(p for p, b in zip(ps, bits) if b), (-1) ** sum(bits)

# Coefficient of a full prime-power inverse, on up to three independent slots.
for s in (1, 2, 3):
    for ks in product(range(1, 6), repeat=s):
        lhs = sum(prod(mu_power(k-j) for k, j in zip(ks, js))
                  for js in product(*(range(1, k+1) for k in ks)))
        assert lhs == int(all(k == 1 for k in ks))
        checks['all_power_collapse'] += 1

# The exact PRODUCT-cutoff finite difference, at every breakpoint and midpoint.
for ps in ((7, 13), (7, 13, 19)):
    for ks in product(range(1, 5), repeat=len(ps)):
        dnorm = prod(p**k for p, k in zip(ps, ks))
        eps_primes = tuple(p for p, k in zip(ps, ks) if k >= 2)
        eps = list(divisors_sf(eps_primes))
        breaks = sorted({F(dnorm, e) for e, _ in eps})
        probes = {F(1, 2), *breaks, breaks[-1] + 1}
        probes.update((a+b)/2 for a, b in zip(breaks, breaks[1:]))
        probes.add(breaks[0]/2)
        for x in sorted(probes):
            lhs = sum(prod(mu_power(k-j) for k, j in zip(ks, js))
                      * int(x <= prod(p**j for p, j in zip(ps, js)))
                      for js in product(*(range(1, k+1) for k in ks)))
            rhs = sum(sign * int(x <= F(dnorm, e)) for e, sign in eps)
            assert lhs == rhs
            checks['coupled_cutoff'] += 1

# h = g*t recombination with strict q_g<G, including every boundary equality.
ps = (7, 13, 19, 31)
for selected in product((0, 1), repeat=len(ps)):
    hs = tuple(p for p, b in zip(ps, selected) if b)
    h = prod(hs)
    divs = list(divisors_sf(hs))
    for G in (F(2), F(7), F(8), F(13), F(14), F(20), F(31), F(32)):
        beta = sum((-1)**len(hs) * mug for g, mug in divs if g < G)
        direct = sum(mut for t, mut in divs if F(h, t) < G)
        assert beta == direct
        if h < G:
            assert beta == int(h == 1)
        checks['g_t_recombination'] += 1

# Finite actual Mobius-coefficient polynomial test in a three-prime monoid.
# Any profile values are allowed in this identity; this test is not an analytic input.
ps = (7, 13, 19)
rows = list(product((0, 1), repeat=3))
ideals = [(prod(p for p, b in zip(ps, bits) if b), bits,
           (-1)**sum(bits)) for bits in rows]

def cp(bits, other):
    return not any(a and b for a, b in zip(bits, other))

def phase(bits, values):
    return prod(x for x, b in zip(values, bits) if b)

def W(y):
    return (2*y-1)*(2-y) if F(1, 2) <= y <= 2 else F(0)

for values in product((-1, 0, 1), repeat=3):
    for abits in rows:
        for L in (F(7), F(50), F(250)):
            for G, K in ((F(8), F(14)), (F(20), F(23))):
                direct = F(0)
                collapsed = F(0)
                for qg, gbits, _ in ideals:
                    if not(qg < G and cp(abits, gbits)) or phase(gbits, values) == 0:
                        continue
                    for qb, bbits, mub in ideals:
                        if not cp(bbits, tuple(x or y for x, y in zip(abits, gbits))):
                            continue
                        for qc, cbits, muc in ideals:
                            if not cp(cbits, tuple(x or y for x, y in zip(abits, gbits))):
                                continue
                            # Common primes above K remain permitted.
                            if any(b and cc and prime <= K
                                   for prime, b, cc in zip(ps, bbits, cbits)):
                                continue
                            direct += (mub*muc*phase(bbits, values)*phase(cbits, values)
                                       *W(qg*qb/L)*W(qg*qc/L))
                for qh, hbits, muh in ideals:
                    if any(b and prime > K for prime, b in zip(ps, hbits)):
                        continue
                    if not cp(abits, hbits) or phase(hbits, values) == 0:
                        continue
                    beta = 0
                    for qg, gbits, mug in ideals:
                        if qg < G and all(not b or h for b, h in zip(gbits, hbits)):
                            beta += muh*mug
                    poly = sum(mun*phase(nbits, values)*W(qh*qn/L)
                               for qn, nbits, mun in ideals
                               if cp(nbits, tuple(x or y for x, y in zip(abits, hbits))))
                    collapsed += beta*poly**2
                assert direct == collapsed
                checks['masked_polynomial_recombination'] += 1

# Every exponent is affine in (r, ell), so these are all polytope vertices.
rlo, rhi, c, eta = F(28, 25), F(113, 100), F(1, 10000), F(1, 200)
mins = {}
for r in (rlo, rhi):
    h = r*(1+c)
    p = (h-1)/6
    for ell in (r-F(1, 100), r):
        exponents = {
            'PU': p+1,
            'g_boundary': p+F(1, 6)+F(5, 6)*ell-F(1, 120),
            'Euler_mixed': p+F(7, 12)+F(5, 12)*ell-F(1, 192),
            'Euler_long': p+F(1, 6)+F(5, 6)*ell-F(1, 96),
            'short_scale': p+F(1, 6)+F(5, 6)*(r-F(1, 100)),
        }
        for name, exponent in exponents.items():
            margin = h-eta-exponent
            assert margin > 0
            mins[name] = min(mins.get(name, margin), margin)
            checks['budget_vertices'] += 1
assert mins['PU'] == F(1783,18750)
assert mins['g_boundary'] == mins['short_scale'] == F(257,75000)
assert mins['Euler_mixed'] == F(30181,600000)
assert mins['Euler_long'] == F(551,100000)
assert eta-F(5,6)*rhi*c == F(5887,1200000)
assert F(1,10)*F(1,100) == F(1,1000)
checks['rational_equalities'] += 7

# Planted defects: deleting repeated shifts; independent cutoffs; omitted mixed term;
# centering does not cancel a zero-extended character diagonal; strict-boundary error.
assert mu_power(1) == -1  # n=p^2, retaining only shift j=1 leaves -1 instead of 0.
assert (7*13 >= 50) and not (7 >= 50 and 13 >= 50)
assert tuple(1-int(x<=1183)-int(x<=637)+int(x<=91)
             for x in (F(100), F(2000))) == (-1, 1)
assert 1-1-1+1 == 0 and 1-1-1 != 0  # omitted two-prime intersection fails
assert F(1,2)-F(1,2) == 0 and F(1,2)*1-F(1,2)*0 == F(1,2)
assert sum((-1)*mug for g,mug in divisors_sf((7,)) if g < 7) == -1
checks['planted_defects_detected'] += 6

print('EXACT_FINITE_DIAGNOSTICS_ONLY')
for key, value in checks.items():
    print(key, value)
print('TOTAL', sum(checks.values()))
print('MARGINS', {k: str(v) for k,v in mins.items()})
print('NO_ANALYTIC_SOURCE_CERTIFICATION; NO_LEAN; NO_ARB; NO_COMPARATOR')
```
