# Q34. Квадратные делители: оплаченный совместный сектор и точная граница оставшегося знака

## 0. Результат и его масштаб

**Независимую нижнюю оценку всей \(C_{\rm comp}\), достаточную исходному потребителю, я не получил.** Ни \(\eta(\epsilon)\to0\) для полной \(T_{>R}\), ни благоприятный коэффициентный запас на настоящей условной паре здесь не доказаны.

Испытан один конкретный арифметический ход: **разделение настоящих составных коэффициентов по наличию квадратного делителя**, с количественным подсчётом квадратсвободных кратных в каждом исходном НОК-канале. Это не попытка сделать Helson-матрицу положительной и не новая независимая оплата её блоков.

Получен полный частный результат:
\[
\boxed{
\left\|
\sum_{\substack{Z<n\le m\\\mu(n)^2=0}}
 b_Z(n)\,\frac{P Q_M(\log n)P}{\sqrt n}
\right\|
\le C_\epsilon m^{5\epsilon/4}(\log m)^7.
}
\tag{0.1}
\]
Он относится ко **всем векторам исходного \(P\)**. Здесь не только собственные степени простых, но и, например, все \(p^2q\), \(p^2qr\), числа с несколькими повторяющимися простыми множителями. Их пересечения учтены настоящей \(\mu\), а не суммой отдельных положительных масок.

Для оставшегося квадратсвободного составного сектора сохраняется точное вычитание настоящей суммы по большим простым с коэффициентом один. Его независимый нижний знак не установлен. Поэтому **(0.1) — оплаченный сектор, а не улучшение полного показателя CCM**.

Классическое свойство квадратсвободного счёта не объявляется новым открытием. Новый расчёт этого ответа — его равномерный перенос с настоящими конечными Ramanujan-коэффициентами, всеми их смешанными НОК-членами и исходным матричным тестом. Все нужные количественные леммы ниже доказаны элементарно; новая PNT-, Mertens- или zero-free-гипотеза не используется.

## 1. Фиксация источника и унаследованные входы

**[COFINAL_FAMILY | PAPER; исходные определения S3–S9]** Сначала фиксируется \(0<\epsilon<1/32\), затем растёт целое \(m\):
\[
L=\log m,\qquad M=R=\lfloor m^\epsilon\rfloor,
\qquad Z=\lfloor m^{\epsilon/4}\rfloor,
\qquad \Omega=2\pi M/L.
\tag{1.1}
\]
Работаем на достаточно поздних ячейках, где \(m\ge4\), \(Z\ge2\), \(Z^2\le m\). Начало области может зависеть от фиксированного \(\epsilon\), но не от вектора. Вспомогательный \(Z\) нигде не заменяет исходный делительный \(R\).

Для исходного синтеза \(f=F_Mc\), \(c=Pc\), сохраняются
\[
\|f\|_{L^2(0,L)}=\|c\|_2,\qquad f(0)=f(L)=0,
\qquad \int_0^L e^{\pm t/2}f(t)\,dt=0.
\tag{1.2}
\]
Функция продолжается нулём. Все \(c\) могут быть комплексными. Положим
\[
h(x)=x^{-1/2}P Q_M(\log x)P,\qquad
A=\sum_{n\le m}\Lambda(n)h(n),
\qquad C^0=A+H_d,
\tag{1.3}
\]
где принятый непрерывный возврат даёт
\[
\int_1^m h(x)\,dx=-H_d,\qquad 0\preceq H_d\preceq4P.
\tag{1.4}
\]
Обозначим матричный логарифмический тест через
\[
\mathcal L(x)=\log x\,h(x),\qquad
J=\int_1^m\mathcal L(x)\,dx.
\tag{1.5}
\]
Из уже принятых входов S3 §1, §4.1, S4, S9:
\[
\begin{gathered}
\|h(x)\|\le2x^{-1/2},\qquad
\|h'(x)\|\le(1+2\Omega)x^{-3/2},\qquad
h(m)=0,\\
\mathcal L(1)=\mathcal L(m)=0,\qquad
\|J\|\le8,\\
\|\mathcal L'(x)\|
\le[2+(1+2\Omega)\log x]x^{-3/2}.
\end{gathered}
\tag{1.6}
\]
Малость \(J\) — **старое** совместное использование двух экспоненциальных контактов, не новая арифметическая оценка. Действительно, производная растущего rank-two ядра при параметре \(1/2\) после сжатия равна минус производной затухающего; поэтому логарифмический растущий момент возвращается в \(\int_0^L s e^{-s/2}Q_P(s)ds\), чья норма не превосходит 8.

Полный возврат доказанного \(A\preceq sP\) остаётся прежним:
\[
T_{>R}\preceq(s+b_{\rm div})P,
\qquad
PK_mP\succeq-[s+50L+8]P,
\tag{1.7}
\]
\[
b_{\rm div}=(56+32\Omega)\sqrt R+12(1+\log R)^2.
\tag{1.8}
\]
Все исходные \(\Lambda(p^k)\) остаются в \(A\). Короткая делительная цена начисляется только в первой формуле; архимедова — один раз во второй.

### 1.1. Что не переоценивается заново

S1 исключает лишь указанные отдельные HS- и op/trace-завершения, в том числе exhaustive entry-partition с отдельной HS-платой. Его нижние цены **не** считаются оценками signed trace. S2–S4 и S9 уже оплачивают полный модельный оператор. S5–S6 уже показывают, почему удаление простых с коэффициентом один не становится дешёвым от переименования.

В данном ответе эти утверждения используются в их записанной области. Новая полная проверка всей upstream Weil/CCM-цепи и прежних независимых аудитов не заявляется.

## 2. Настоящие конечные коэффициенты и выбранное свойство

**[FINITE_CELL | PAPER; точные коэффициенты S4 и S9]** Используется та же нормировка:
\[
\lambda_Z(n)=\sum_{q\le Z}\frac{\mu(q)c_q(n)}{\varphi(q)},
\qquad C_Z=\sum_{q\le Z}\frac{\mu(q)^2}{\varphi(q)},
\qquad b_Z(n)=\frac{\lambda_Z(n)^2}{C_Z^2}\log n.
\tag{2.1}
\]
Пусть
\[
u_Z(d)=
\frac{\mu(d)d}{\varphi(d)C_Z}
\sum_{\substack{k\le Z/d\\(k,d)=1}}\frac{\mu(k)^2}{\varphi(k)},
\qquad
 g_Z(\ell)=\sum_{\substack{d,e\le Z\\[d,e]=\ell}}u_Z(d)u_Z(e).
\tag{2.2}
\]
Точное конечное раскрытие имеет вид
\[
\left(\frac{\lambda_Z(n)}{C_Z}\right)^2
=\sum_{\ell\mid n}g_Z(\ell),\qquad
b_Z(n)h(n)=\sum_{\ell\mid n}g_Z(\ell)\mathcal L(n).
\tag{2.3}
\]
Все пары \((d,e)\), включая \(d\ne e\), сохранены. Стоит НОК, не произведение. У \(g_Z\) нет предполагаемого положительного знака.

Дополнительное используемое свойство:
\[
\boxed{
 u_Z(d)=0\quad\text{при }\mu(d)^2=0,
 \qquad
 g_Z(\ell)=0\quad\text{при }\mu(\ell)^2=0.
}
\tag{2.4}
\]
Второе следует из первого, поскольку НОК двух квадратсвободных чисел квадратсвободен. Поэтому все существенные делительные каналы \(\ell\) допускают следующий **количественный квадратсвободный счёт**. Его ошибка имеет степень \(1/2\) в обычной координате \(x\), что после множителя \(x^{-1/2}\), полного логарифмического момента и исходных контактов даёт лишь логарифмы по \(m\) и цену, зависящую степенно от \(Z,M\).

Это различает настоящий арифметический сектор и произвольные положительные атомы. Но свойство \(\mu(n)^2=1\) ещё не отделяет простые от квадратсвободных составных; именно эта граница окажется решающей.

## 3. Количественная лемма: все квадратсвободные кратные

### 3.1. Точная конечная формула

**[ABSTRACT | PAPER]** Для квадратсвободного целого \(\ell\ge1\) и вещественного \(x\ge1\) положим
\[
Q_\ell(x)=\sum_{\substack{n\le x\\\ell\mid n}}\mu(n)^2,
\qquad
\delta_\ell=\frac1{\zeta(2)}\prod_{p\mid\ell}\frac1{p+1}.
\tag{3.1}
\]
Пустое произведение при \(\ell=1\) равно единице. Тогда
\[
\boxed{
Q_\ell(x)=
\sum_{\substack{d\le\sqrt{x/\ell}\\(d,\ell)=1}}\mu(d)
\sum_{a\mid\ell}\mu(a)
\left\lfloor\frac{x}{\ell d^2a}\right\rfloor .
}
\tag{3.2}
\]
Если \(x<\ell\), правая сумма пуста и обе стороны нулевые.

**Доказательство.** По разложению на простые степени
\[
\mu(k)^2=\sum_{d^2\mid k}\mu(d).
\tag{3.3}
\]
Для квадратсвободного \(\ell\) имеем
\(\mu(\ell k)^2=\mu(k)^2\mathbf1_{(k,\ell)=1}\).
После \(k=d^2v\) необходимо оставить одновременно \((d,\ell)=1\) и \((v,\ell)=1\). Второе раскрывается как \(\sum_{a\mid(v,\ell)}\mu(a)\). Это даёт (3.2), с буквальным целым верхом и каждым скачком. □

Область «\(\ell\) квадратсвободно» существенна. При \(\ell=4\) левая сторона тождественно нулевая, и формулу плотности (3.1) нельзя применять. Именно (2.4) делает эту область законной для всех настоящих \(g_Z(\ell)\).

### 3.2. Равномерная ошибка с явной постоянной

Для всех указанных \(x,\ell\):
\[
\boxed{
|Q_\ell(x)-\delta_\ell x|
\le (\tau(\ell)+2)\sqrt{x/\ell}
\le3\tau(\ell)\sqrt{x/\ell}.
}
\tag{3.4}
\]
Здесь \(\tau\) — число положительных делителей, а не временной параметр.

**Доказательство при \(x\ge\ell\).** Положим \(Y=x/\ell\), \(D=\lfloor\sqrt Y\rfloor\). Замена каждого пола в (3.2) на аргумент даёт ошибку не более \(\tau(\ell)D\). Главный член равен
\[
Y\frac{\varphi(\ell)}\ell
\sum_{\substack{d\le D\\(d,\ell)=1}}\frac{\mu(d)}{d^2}.
\tag{3.5}
\]
Бесконечное продолжение этой **абсолютно сходящейся** числовой суммы стоит не более
\[
Y\frac{\varphi(\ell)}\ell\sum_{d>D}\frac1{d^2}
\le\frac YD\le2\sqrt Y.
\tag{3.6}
\]
Последнее верно для всех \(Y\ge1\). Её полный коэффициент:
\[
\frac1\ell\frac{\varphi(\ell)}\ell
\prod_{p\nmid\ell}(1-p^{-2})
=\frac1{\zeta(2)}\prod_{p\mid\ell}\frac1{p+1}=\delta_\ell.
\tag{3.7}
\]
Если \(x<\ell\), то \(Q_\ell=0\), \(0\le\delta_\ell\le1/\ell\), поэтому \(\delta_\ell x\le\sqrt{x/\ell}\). Это завершает все случаи. □

**Это первая дополнительная количественная арифметическая оценка выбранного хода.** Она использует настоящую совместную делимость и её пересечения; из одних масс или норм произвольных атомов она не следует. В доказательстве нет Mertens-оценки: конечные \(\mu(d)\) при оценке пола ограничены по модулю единицей, а только вспомогательный хвост \(\sum d^{-2}\) суммируется абсолютно. Никакая физическая сумма по \(n>m\) не добавлена.

### 3.3. Средний коэффициент настоящего квадрата

Положим
\[
\delta_Z^{\rm sf}=\sum_\ell g_Z(\ell)\delta_\ell.
\tag{3.8}
\]
Тогда для каждого конечного \(Z\)
\[
\boxed{0\le\delta_Z^{\rm sf}\le1/C_Z.}
\tag{3.9}
\]
Действительно, \(a_Z(n)=(\lambda_Z(n)/C_Z)^2\ge0\), а
\(0\le\mu(n)^2a_Z(n)\le a_Z(n)\).
Для фиксированного \(Z\), (3.4) и конечная сумма (2.3) дают среднее левой последовательности \(\delta_Z^{\rm sf}\). Полное периодическое среднее \(a_Z\) равно \(\sum_\ell g_Z(\ell)/\ell=1/C_Z\), принятому точному коэффициенту S4/S9. Переход к средним доказывает (3.9) для каждого целого \(Z\).

Это доказательство не заменяет производственный отрезок \([1,m]\) полным периодом. Неравенство (3.9) — точное параметрическое утверждение для всех \(Z\); ошибка на растущем \(Z=Z(m)\) ниже оценивается отдельно и равномерно через (3.4).

## 4. Полная цена настоящих смешанных коэффициентов

**[ABSTRACT | PAPER]** Нужна не новая оценка старой модели, а её дивизорный вес, возникающий в (3.4):
\[
G_Z^*=\sum_{\ell\le Z^2}
\frac{|g_Z(\ell)|\tau(\ell)}{\sqrt\ell}.
\tag{4.1}
\]
Для всех \(Z\ge2\) достаточно следующей явной границы:
\[
\boxed{
G_Z^*\le 4\,3^{16}\,Z(1+\log Z)^6.
}
\tag{4.2}
\]
Константа намеренно не оптимизируется: это не главный неоплаченный расход.

**Доказательство.** Из точной формулы (2.2), как в S4,
\(|u_Z(d)|\le d/\varphi(d)\le\tau(d)\). Также
\(\tau([d,e])\le\tau(d)\tau(e)\). Поэтому, только для этой вспомогательной неотрицательной платы,
\[
G_Z^*\le
\sum_{d,e\le Z}
\frac{\tau(d)^2\tau(e)^2}{\sqrt{[d,e]}}.
\tag{4.3}
\]
Пишем \(d=ha,e=hb\), \((a,b)=1\), и убираем это последнее ограничение лишь в положительном верхе. По субмультипликативности \(\tau\):
\[
G_Z^*\le
\sum_{h\le Z}\frac{\tau(h)^4}{\sqrt h}
\left(\sum_{a\le Z/h}\frac{\tau(a)^2}{\sqrt a}\right)^2.
\tag{4.4}
\]
Поскольку \(\tau(n)^2\le d_4(n)\), где \(d_k\) считает упорядоченные \(k\)-факторные разложения,
\[
\sum_{a\le X}\frac{\tau(a)^2}{\sqrt a}
\le2\sqrt X(1+\log X)^3.
\tag{4.5}
\]
Это следует из четырёх факторных сумм: внутреннюю сумму \(d^{-1/2}\) оцениваем через \(2\sqrt{X/(abc)}\), остальные три гармонические суммы — через \((1+\log X)^3\).

Наконец \(\tau(n)^4\le d_{16}(n)\). Для полноты, локальная инъекция на \(p^a\) такова: каждой четвёрке \(e_1,\ldots,e_4\in\{0,\ldots,a\}\) сопоставить числа уровней \(t=1,\ldots,a\), на которых множество \(\{j:e_j\ge t\}\) равно каждому из 16 подмножеств. Это 16 неотрицательных чисел с суммой \(a\); из них восстанавливаются все \(e_j\). Значит,
\((a+1)^4\le {a+15\choose15}\), и утверждение перемножается по простым.

Отсюда
\[
\sum_{h\ge1}\frac{\tau(h)^4}{h^{3/2}}
\le\left(\sum_{n\ge1}n^{-3/2}\right)^{16}\le3^{16}.
\tag{4.6}
\]
Подстановка (4.5) в (4.4) доказывает (4.2). □

Каждый смешанный \(u_Z(d)u_Z(e)\) сначала принадлежал точной формуле (2.3). Не утверждается, что удаление таких членов сохраняет модель. Их модули появляются только в доказанной вспомогательной цене (4.1), после точной арифметической сборки.

## 5. Совместное матричное сравнение до оплаты остатка

### 5.1. Весь квадратсвободный модельный оператор

**[FINITE_CELL | PAPER]** Положим
\[
B_Z=\sum_{n\le m}b_Z(n)h(n),\qquad
B_Z^{\rm sf}=\sum_{n\le m}\mu(n)^2b_Z(n)h(n).
\tag{5.1}
\]
Из (2.3) и (3.2), до норм и модулей,
\[
B_Z^{\rm sf}
=\sum_\ell g_Z(\ell)\int_{[1,m]}\mathcal L(x)\,dQ_\ell(x).
\tag{5.2}
\]
Введём настоящий скалярный остаток
\[
\mathscr E_Z(x)=\sum_\ell g_Z(\ell)
\bigl(Q_\ell(x)-\delta_\ell x\bigr).
\tag{5.3}
\]
Полное интегрирование по частям даёт
\[
\boxed{
B_Z^{\rm sf}
=\delta_Z^{\rm sf}J-
\int_1^m\mathscr E_Z(x)\mathcal L'(x)\,dx
=:\delta_Z^{\rm sf}J+E_Z^{\rm sf}.
}
\tag{5.4}
\]
Оба endpoint-члена равны нулю именно из-за \(\mathcal L(1)=\mathcal L(m)=0\), а не из-за фиктивной непрерывности арифметического счёта. В \(Q_\ell\) остаются все скачки, включая верхний атом. Не требуется предположения о знаке \(\mathscr E_Z\) или \(\mathcal L'\).

Теперь применим **доказанную** (3.4) к совместно собранному остатку:
\[
|\mathscr E_Z(x)|\le3G_Z^*\sqrt x.
\tag{5.5}
\]
Полная интегральная цена равна
\[
I_m:=\int_1^m
\frac{2+(1+2\Omega)\log x}{x}\,dx
=2L+\frac{1+2\Omega}{2}L^2.
\tag{5.6}
\]
Поэтому
\[
\boxed{
\|E_Z^{\rm sf}\|\le 3G_Z^* I_m,
\qquad
\|B_Z^{\rm sf}\|\le
\mathfrak S_{m,Z}:=8\delta_Z^{\rm sf}+3G_Z^*I_m.
}
\tag{5.7}
\]
Это не раздельная оценка \(H\) и \(B\) из Helson-представления. Прежде нормы выполнена точная совместная арифметическая группировка по квадратным делителям, а её главный член возвращён **тем же исходным \(J\)**. Произвольная положительная мера с теми же отдельными массами не удовлетворяет (3.4).

Неравенство (5.7) двустороннее и сильнее одностороннего для этого **частного сектора**. Оно не используется для оценки исключённых простых без их возвращения.

### 5.2. Старый модельный возврат остаётся старым

S4/S9 уже дают
\[
B_Z=J/C_Z+E_Z^{\rm mod},
\qquad
\|E_Z^{\rm mod}\|\le\mathfrak E_{m,Z}^{\rm mod},
\tag{5.8}
\]
где можно сохранить минимум двух принятых цен:
\[
\mathfrak E_{m,Z}^{\rm mod}=
\min\left\{
3888Z(1+D_M)(1+\log Z)^2(1+2\log Z),
\frac{64Z^2}{C_Z^2}(8+4D_M)
\right\},
\quad D_M=(2+8\pi M)/L.
\tag{5.9}
\]
Это не новое достижение Q34. В частности, более сильный weighted-LCM вход S4 не заменяется более дорогим Q33-конвертом.

### 5.3. Весь неквадратсвободный составной сектор

Определим буквально
\[
C_{\rm nsf}:=
\sum_{\substack{Z<n\le m\\\mu(n)^2=0}}b_Z(n)h(n),
\qquad
B_{{\rm nsf},\le Z}:=
\sum_{n\le Z}(1-\mu(n)^2)b_Z(n)h(n).
\tag{5.10}
\]
Для \(n>1\) неквадратсвободность уже означает составность. До отдельных оценок:
\[
\boxed{
C_{\rm nsf}
=(C_Z^{-1}-\delta_Z^{\rm sf})J
+E_Z^{\rm mod}-E_Z^{\rm sf}-B_{{\rm nsf},\le Z}.
}
\tag{5.11}
\]
Общий \(J\) **не оплачивается дважды**. Из (3.9) его коэффициент неотрицателен и не превосходит \(C_Z^{-1}\); знак самого \(J\) не предполагается.

Для любой подмаски малых целых достаточно
\[
q_Z=4\sqrt Z\log Z\,
\min\left\{Z^2/C_Z^2,(1+\log Z)^8\right\}.
\tag{5.12}
\]
Первая граница следует из \(|\lambda_Z(n)|\le Z\); вторая — из принятого S9 неравенства \(b_Z(n)\le\log n\,\tau_9(n)\) и \(\sum_{n\le Z}\tau_9(n)/\sqrt n\le2\sqrt Z(1+\log Z)^8\). Можно использовать только первую границу: итоговый главный показатель не изменится.

Итак,
\[
\boxed{
-\mathfrak N_{m,Z}P\preceq C_{\rm nsf}\preceq\mathfrak N_{m,Z}P,
}
\tag{5.13}
\]
\[
\boxed{
\mathfrak N_{m,Z}=
8(C_Z^{-1}-\delta_Z^{\rm sf})
+\mathfrak E_{m,Z}^{\rm mod}
+3G_Z^*I_m+q_Z.
}
\tag{5.14}
\]
Все величины в этом бюджете определены явно. Его доказательство не требует ни Helson-положительности, ни свободной замены матрицы корреляций, ни неизвестной маленькой \(\mu\)-префиксной нормы.

На расписании (1.1):
\[
\mathfrak E_{m,Z}^{\rm mod}=O_\epsilon(m^{5\epsilon/4}L^2),
\qquad
3G_Z^*I_m=O_\epsilon(m^{5\epsilon/4}L^7),
\qquad
q_Z=O_\epsilon(m^{\epsilon/8}L^9).
\tag{5.15}
\]
Следовательно, для каждого фиксированного \(\epsilon\)
\[
\boxed{
\mathfrak N_{m,Z}=O_\epsilon(m^{5\epsilon/4}L^7)
\le C_\epsilon m^{2\epsilon}
}
\tag{5.16}
\]
на достаточно поздних ячейках. Последний более грубый показатель оставляет логарифмический запас и не является целью дополнительной оптимизации.

## 6. Связь с настоящим product-index carrier

**[FINITE_CELL | PAPER]** Пусть \(H,B\) — буквальные матрицы S1:
\[
H_{uv}=\alpha(uv),\qquad
B_{uv}=\frac{\rho_f(uv)}{\tau(uv)-2}
\mathbf1_{Z<uv\le m,\ uv\ {\rm composite}},
\tag{6.1}
\]
\[
\alpha(n)=\mathbf1_{Z<n\le m,\ n\ {\rm composite}}
\frac{b_Z(n)}{\sqrt n},
\qquad
\rho_f(n)=2\Re\int_0^{L-\log n}\overline{f(t)}f(t+\log n)\,dt.
\tag{6.2}
\]
Индексы \(u,v\ge2\) имеют прежний конечный диапазон. Точный возврат использует **\(\tau(n)-2\) упорядоченных пар**, включая диагональные пары при квадратах.

Положим
\[
H^{\rm sf}_{uv}=\mu(uv)^2H_{uv},\qquad
H^{\rm nsf}_{uv}=(1-\mu(uv)^2)H_{uv}.
\tag{6.3}
\]
Тогда без изменения \(B\), его нормы или его квадратичной зависимости от \(c\)
\[
\operatorname{Tr}(H^{\rm nsf}B)=c^*C_{\rm nsf}c,
\qquad
\operatorname{Tr}(H^{\rm sf}B)=c^*C_{\rm sf}c,
\qquad C_{\rm comp}=C_{\rm nsf}+C_{\rm sf}.
\tag{6.4}
\]
Здесь
\[
C_{\rm sf}=\sum_{\substack{Z<n\le m\\n\ {\rm composite}}}
\mu(n)^2 b_Z(n)h(n).
\tag{6.5}
\]
Для первой части (5.13) даёт настоящий совместный результат
\[
\boxed{
\big|\operatorname{Tr}(H^{\rm nsf}B(c))\big|
\le\mathfrak N_{m,Z}\|c\|^2.
}
\tag{6.6}
\]
В него входят обе временные ориентации и все комплексные межмодовые члены \(\rho_f\). Ни HS-норма \(H\), ни HS-/trace-норма \(B\) не подставлялись в эту строку.

Это не противоречит S1(H6): его нижний расход строился, в частности, на настоящих **различных rough-простых \(pq\)**, которые квадратсвободны и остаются во второй части (6.4). Вообще S1 ограничивает отдельную оплату норм, а не точный signed trace.

В оставшемся carrier имеется точная маска
\[
\mu(uv)^2=\mu(u)^2\mu(v)^2\mathbf1_{(u,v)=1}.
\tag{6.7}
\]
Она не позволяет выбрать независимые фазы для разных факторизаций одного произведения. Не предполагается положительность маски как оператора или Gram-положительность \(B\). Для несимметричного коэффициентного возврата \(B'\) pairing по-прежнему использует \(B'_{vu}\); маска в HS-записи транспонируется, как требует S1.

### 6.1. Все края

* \(n=1\): \(b_Z(1)=0\), \(\mathcal L(1)=0\). Добавленной массы нет.
* \(n=Z\): целиком принадлежит возвращённой малой части, а не обоим секторам сразу.
* \(n=m\): исходный \(h(m)=0\) сохраняет нулевой overlap. Все счётные формулы включают атом; граничное произведение исчезает вследствие \(\mathcal L(m)=0\), не из-за удаления скачка.
* \(uv>m\): не входит ни в один физический оператор. Конечные полы в (3.2) сохраняют гиперболический край. Бесконечная числовая сумма (3.6) только определяет плотность с явно оплаченной ошибкой.
* Если \(n=p^k\), \(k\ge2\), оно находится в неквадратсвободном секторе модели; настоящее слагаемое \(\Lambda(p^k)=\log p\) исходной \(A\) возвращается отдельно в точной формуле следующего раздела. Никакое определение xi или \(\Lambda\) не меняется.

## 7. Первая неоплаченная строка: простые не стали квадратсвободной ошибкой

### 7.1. Полный возврат квадратсвободного остатка

Определим
\[
B^{\rm sf}_{Z,\le Z}=\sum_{n\le Z}\mu(n)^2b_Z(n)h(n),
\quad
\Pi_{>Z}=\sum_{Z<p\le m}\log p\,h(p),
\quad
\Pi_{\le Z}=\sum_{p\le Z}\log p\,h(p),
\tag{7.1}
\]
а также **полную** собственно-степенную часть
\[
P_{\rm pp}=\sum_{\substack{p^k\le m\\k\ge2}}\log p\,h(p^k).
\tag{7.2}
\]
Поскольку \(b_Z(p)=\log p\) для каждого простого \(p>Z\), точно
\[
\boxed{
C_{\rm sf}=B_Z^{\rm sf}-B^{\rm sf}_{Z,\le Z}-\Pi_{>Z},
\qquad
A+C_{\rm sf}=B_Z^{\rm sf}-B^{\rm sf}_{Z,\le Z}
+\Pi_{\le Z}+P_{\rm pp}.
}
\tag{7.3}
\]
Здесь нет асимптотической замены: большие простые вычитаются с коэффициентом **ровно один**.

Старые элементарные платы дают
\[
\|\Pi_{\le Z}\|\le12\sqrt Z,
\qquad
\|P_{\rm pp}\|\le K_{\rm pp}L(1+L),
\qquad K_{\rm pp}=\frac2{1-1/\sqrt2}.
\tag{7.4}
\]
Поэтому, для полного Hermitian оператора
\(U_{\rm sf}:=A+C_{\rm sf}\),
\[
\boxed{
\|U_{\rm sf}\|\le
\mathfrak R_{m,Z}:=
\mathfrak S_{m,Z}+q_Z+12\sqrt Z+K_{\rm pp}L(1+L)
=O_\epsilon(m^{5\epsilon/4}L^7).
}
\tag{7.5}
\]
Это другая точная карта к исходной \(A\), а не замена \(A\) квадратсвободным prime-only объектом.

### 7.2. Чего оценка квадратсвободной плотности не доказывает

Не выведено
\[
\boxed{
 C_{\rm sf}\succeq-D_\epsilon m^{\theta(\epsilon)}P,
 \qquad\theta(\epsilon)\to0.
}
\tag{7.6 OPEN}
\]
Такая оценка через (7.5) поставила бы исходную цель. Но из малости **всей** квадратсвободной модели она не следует: в (7.3) осталось \(-\Pi_{>Z}\). Подстановка (3.4) в этот prime-deleted счёт незаконна. Формула (3.4) относится ко всем квадратсвободным кратным, включая простые.

В частности, попытка утверждать, что подсчёт квадратсвободных составных имеет ту же маленькую ошибку после удаления простых, должна вернуть настоящий вычитаемый \(\pi(x)\) с его логарифмическим матричным весом. Знаковая информация о нём не дана ни (3.2), ни (3.4).

**Это первая неоплаченная арифметическая строка полного хода.** Я не называю (7.6) новым готовым поставщиком. С точностью до оплаченной \(\mathfrak R_{m,Z}\) она эквивалентна прежнему one-sided upper для \(A\):
\[
 C_{\rm sf}\succeq-sP\Longrightarrow A\preceq(s+\mathfrak R_{m,Z})P,
\quad
 A\preceq aP\Longrightarrow C_{\rm sf}\succeq-(a+\mathfrak R_{m,Z})P.
\tag{7.7}
\]

### 7.3. Законное завершение доступным входом

Положим \(W_{>Z}^{\rm pr}=\sum_{Z<p\le m}\log p/\sqrt p\). Только в этой строке теряется оставшийся знак:
\[
\Pi_{>Z}\preceq2W_{>Z}^{\rm pr}P.
\tag{7.8}
\]
Из (7.3) можно получить нижнюю оценку \(C_{\rm sf}\):
\[
C_{\rm sf}\succeq
B_Z^{\rm sf}-B^{\rm sf}_{Z,\le Z}-2W_{>Z}^{\rm pr}P.
\tag{7.9}
\]
При совместном возврате (7.3) **общие модельные члены сокращаются**, а не оплачиваются второй раз. Затем законная полная оценка равна только
\[
\boxed{
 A\preceq2W_m P\preceq12\sqrt m\,P,
 \qquad W_m=\sum_{n\le m}\Lambda(n)/\sqrt n.
}
\tag{7.10}
\]
В \(W_m\) все prime powers остаются. Включение нулевого верхнего overlap в положительную скалярную цену допустимо, но не объявляется точной спектральной массой.

Итак, **новая полная степень не получена**. Это не доказательство неизбежной нижней половинной степени самого \(C_{\rm sf}\), \(C_{\rm comp}\) или CCM. Это лишь итог единственного завершённого неравенства этой попытки. Ранее принятые более сильные оценки сохраняют собственные области и предпосылки; этот ответ их не заменяет. В частности, старые условные \(3/8\) не становятся безусловными.

## 8. Бюджет до исходного потребителя и область векторов

### 8.1. Все исходные векторы

**[COFINAL_FAMILY | PAPER]** Результаты (5.13), (6.6), (7.5) одновременны для всех комплексных \(c=Pc\); у нормированных \(W=PWP\succeq0\) соответствующие trace-бюджеты умножаются только на \(\operatorname{Tr}W\), не на размерность.

При гипотетически поставленном, но **не используемом здесь** верхе \(s\) из (7.6), точный полный ledger был бы
\[
T_{>R}\preceq[s+\mathfrak R_{m,Z}+b_{\rm div}]P,
\qquad
PK_mP\succeq-[s+\mathfrak R_{m,Z}+50L+8]P.
\tag{8.1}
\]
Все явно оплаченные дополнительные члены не превосходят \(C_\epsilon m^{2\epsilon}\) со временем. Поэтому такое **независимое** \(s=D_\epsilon m^{\theta(\epsilon)}\) дало бы \(\eta=\max\{\theta,2\epsilon\}\to0\). Это только карта вход→выход, не утверждение наличия входа.

Фактически поставлено только (7.10), и сохраняется
\[
\boxed{
T_{>R}\preceq[12\sqrt m+b_{\rm div}]P,
\qquad PK_mP\succeq-[12\sqrt m+50L+8]P.
}
\tag{8.2}
\]
Никаких дополнительных \(P\)-поправок нет: функции не изменялись, матрицы с самого начала сжаты исходным \(P\), а между физическими сдвигами промежуточные проекторы не вставлялись.

| Статья | Полный бюджет | Область |
|---|---|---|
| Новая squarefree counting error | \(3G_Z^*I_m\) | исходный полный матричный тест |
| Старый модельный возврат | \(\mathfrak E_{m,Z}^{\rm mod}\) | S4/S9, не новый результат |
| Малая модельная часть, любой из двух секторов | \(q_Z\) | все целые \(n\le Z\) |

### 8.2. Условный свидетель

**[COFINAL_FAMILY | CONDITIONAL; только S7]** Если фиксированный настоящий гипотетический нуль имеет \(w=\delta+i\gamma\), \(\delta>0\), принятый S7-свидетель в исходном \(P\) имеет ограниченную норму и сигнал порядка \(m^\delta/L^{2\delta}\), с указанными в S7 исходными cutoff/Fourier/contact-возвратами.

Наши all-\(P\) секторные оценки применяются к **целому** возвращённому вектору; они не разрывают его на независимо нормированные части. Если один раз выбрать допустимое \(\epsilon\) с \(2\epsilon<\delta\), то
\[
\frac{m^{5\epsilon/4}L^7}{m^\delta/L^{2\delta}}\longrightarrow0.
\tag{8.3}
\]
Значит, отдельно оплаченный неквадратсвободный сектор не является недостающим главным масштабом этого свидетеля. Но знак оставшегося квадратсвободного сектора не оценён: **благоприятного коэффициентного запаса на настоящей паре тоже нет**.

Никакого численного значения внепрямого нуля не назначалось. Существование такого нуля не утверждается. S7 и его upstream source construction не пересертифицированы заново.

## 9. Выполненный откат и следующий различающий тест

Из Helson-carrier выполнена точная сборка по произведению, затем оплачено удаление неквадратсвободного сектора. Если эта координата не даёт нового знака, **возврат к более раннему конечному источнику** выписан буквально:
\[
\boxed{
C^0=-C_{\rm sf}+U_{\rm sf}+H_d,
\qquad
U_{\rm sf}=B_Z^{\rm sf}-B^{\rm sf}_{Z,\le Z}
+\Pi_{\le Z}+P_{\rm pp},
\qquad
\|U_{\rm sf}\|\le\mathfrak R_{m,Z}.
}
\tag{9.1}
\]
Обратная сборка до самого \(C^0\) точна; дополнительной ошибки помимо уже названного \(U_{\rm sf}\) нет. Никакой новый контур, высота, свободная корреляционная матрица или бесконечная сумма простых не вводится. Старый all-\(P\) контур S8 остаётся возможной координатой **того же** источника; его signed residue debt не объявлен решённым этой формулой.

**Почему откат содержателен, но не решает задачу:** теперь с доказанной ценой отделены все повторяющиеся простые множители. Продолжать поиск только внутри таких множителей ради главного знака не обосновано: их весь подписанный сектор уже мал. Остаются связи между различными простыми в квадратсвободных произведениях, и соответствующий prime deletion имеет коэффициент один. В частности, старый rough-semiprime контроль S1 не удалился.

Два точных представления оставлены как варианты проверки, не как два новых математических поручения:

| Представление | Что проверять | Стоимость и сила различения |
|---|---|---|
| Квадратсвободный coprime-product trace с маской (6.7) | исходные \(pq,pqr\), все упорядоченные факторизации и квадратичную зависимость от одного \(c\); нельзя подменять это свободным \(B\) | конечная арифметика дешёвая; обнаруживает потерю источника, но сама не даёт глобальный знак |
| Полный конечный \(C^0\) через (9.1) | совместный знак без повторной платы модели и непрерывного фона | возврат уже стоит \(\mathfrak R_{m,Z}=O_\epsilon(m^{5\epsilon/4}L^7)\); решающая сила появляется только у независимого signed-неравенства, которого здесь нет |

**DISCRIMINATOR для следующего предполагаемого сокращения:** на \(n=pq>Z\), \(p\ne q\), оба rough-простых должны оставлять \(\mu(n)^2=1\), \(b_Z(n)=\log(pq)\) и обе факторизации. На \(n=p^2q\) новый секторный возврат должен работать с настоящим включением–исключением, а не удалением одной положительной маски. На больших простых коэффициент вычитания в (7.3) обязан оставаться единицей. Если предполагаемая новая оценка уменьшает этот коэффициент без отдельного доказательства, она потеряла источник.

**Одно следующее действие:** ограниченный независимый PAPER-аудит леммы (3.4), веса (4.2), полного матричного переноса (5.4)–(5.16) и коэффициента простых в (7.3). Не запускать новый арифметический цикл только ради иного имени \(C_{\rm sf}\), дополнительного split или более точной численной панели.

<!-- Q34_ASSET name=verify_sources_q34.py bytes=2206 sha256=0d897694621839dcd0bcd09a2a0d777a68a7b5f5cfda85d7d8a14d26abb336ed -->
```python
#!/usr/bin/env python3
"""Verify the exact Q34 request and all nine size-locked UTF-8 bodies."""
import argparse
import hashlib
import json
import re
from pathlib import Path

EXPECTED = 'bb135a92b766d6715599ce64627f8333b492cce3ee2e7ae9b8294da9beb0e037'

def digest(data: bytes) -> str:
    return hashlib.sha256(data).hexdigest()

def verify(path: Path) -> dict:
    raw = path.read_bytes()
    if len(raw) != 123546 or raw.count(b'\n') != 2044 or digest(raw) != EXPECTED:
        raise ValueError('Q34 request length, LF or SHA256 mismatch')
    raw.decode('utf-8', errors='strict')
    pattern = rb'^BEGIN_SOURCE (S\d+) ([^\n]+)\nBYTES: (\d+)\nSHA256: ([0-9a-f]{64})\nBODY:\n'
    records = []
    for match in re.finditer(pattern, raw, re.M):
        sid, name, size, sha = match.groups()
        size = int(size)
        start, end = match.end(), match.end() + size
        body = raw[start:end]
        if len(body) != size or digest(body) != sha.decode():
            raise ValueError('Body mismatch: ' + sid.decode())
        if not raw[end:].startswith(b'\nEND_SOURCE\n'):
            raise ValueError('Wrong separator or body boundary: ' + sid.decode())
        body.decode('utf-8', errors='strict')
        records.append({'id': sid.decode(), 'name': name.decode(), 'bytes': size,
                        'lf': body.count(b'\n'), 'sha256': digest(body)})
    if [x['id'] for x in records] != [f'S{i}' for i in range(1, 10)]:
        raise ValueError('Source IDs or count do not match S1--S9')
    return {'request_bytes': len(raw), 'request_lf': raw.count(b'\n'),
            'request_sha256': digest(raw), 'source_count': len(records),
            'all_hashes_match': True, 'sources': records}

def main() -> None:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('packet', type=Path)
    parser.add_argument('--output', type=Path, default=Path('q34_sources.json'))
    args = parser.parse_args()
    output = verify(args.packet)
    args.output.write_text(json.dumps(output, ensure_ascii=False, indent=2) + '\n', encoding='utf-8')
    print(json.dumps({'source_count': output['source_count'], 'all_hashes_match': True}))

if __name__ == '__main__':
    main()
```
