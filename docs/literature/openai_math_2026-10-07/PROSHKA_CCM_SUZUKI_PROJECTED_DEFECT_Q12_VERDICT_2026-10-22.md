## 1. Обозначения, которые здесь нельзя смешивать

**[FINITE_CELL | PAPER.]**

* \(D_{\rm ker}=K_{\rm norm}-K_{\rm ar}\) — разность двух непрерывных ядер. Буква `N` в старом \(K_N\) означает **norm**, не производственный cutoff.
* \(\mathscr D_t\psi=i\psi'\) — дифференциальный вход в преобразование Сузуки, не \(D_{\rm ker}\).
* \(\mathcal D_{\rm arch}(\psi)=\int_0^\infty a(s)\|\psi(\cdot+s)-\psi\|_2^2ds\) — положительная архимедова энергия.
* \(D_{{\rm arch},m}=P(A_{\rm arch}-c_AI)P\) — конечная архимедова матрица после постоянного сдвига; она не обязана быть положительной.

Пусть
\[
\mathcal N_m[f]=\pi^{-1}\|\widehat{\mathcal P}_{\mathscr D_t\psi}\|_2^2,
\qquad
\Delta_m[f]=\langle\partial_t\partial_uD_{\rm ker},

\]
Точная исходная связь имеет знак
\[
\boxed{\mathcal Q(f)=\mathcal N_m[f]-\Delta_m[f].}
\tag{1.1}
\]
Она определяет разность, а не утверждает её малость. \(\mathcal Q(f)=\mathcal Q(\psi)=c^*K_mc\) — неизменённая полная форма.

Из S7 и (0.2), до каких-либо оценок,

\tag{1.2}

\[
S_m[f]=2\Re\sum_{2\le n\le m}\frac{\Lambda(n)}{\sqrt n}

Все степени простых и комплексные смешанные коэффициенты остаются. Атом \(n=m\) присутствует с нулевым перекрытием; \(\Lambda(p^a)=\log p\). Смена prefactor в исправлении Сузуки не меняет (1.2), \(c_A\) или исходную CCM.

## 2. Начальная точка: именно оба сентябрьских дефекта

### 2.1. Что уже вычислено и здесь не выдаётся за новизну

**[ABSTRACT | PAPER — S3, уравнения (15), (16a), (24), (L++), (L+-); алгебра повторно проверена.]** Пишем
\[
X(z)=\xi(1/2-iz),\qquad X'(z)=\frac{dX(z)}{dz},
\]
\[
\alpha(x)=\frac{X'(x)}{X(x)-iX'(x)},\qquad
\beta(x)=\frac{X(x)}{X(x)-iX'(x)},
\]
\[
\omega=|\beta|^2,\qquad\eta=\alpha\overline\beta\in\mathbb R.
\]
На действительной оси значения при общих нулях определяются устранимым пределом. Для вещественного \(p>1/2\):
\[
\kappa_p=-\frac{\xi'(1/2+p)}{\xi(1/2+p)},\quad
\Omega_p=\frac1\pi\int\frac{p\omega(x)}{p^2+x^2}dx,
\]
\[
J_{pq}=\frac1\pi\int x\eta(x)
\left(\frac1{p^2+x^2}-\frac1{q^2+x^2}\right)dx,
\]
\[
r_p=\Omega_p-\frac1{1-\kappa_p},\qquad
h_{pq}=J_{pq}+\Omega_p-\Omega_q.
\tag{2.1}
\]
Разность в \(J_{pq}\) не разрывается на два не доказанных по отдельности интеграла.

При \(a=\kappa_p,b=\kappa_q\) настоящий дефект имеет два преобразования:
\[
\mathcal L_{++}D_{\rm ker}
=
\frac{(a-1)(b+1)r_p+(b-1)(a+1)r_q+(b-a)h_{pq}}
 {pq(p+q)},
\tag{2.2}
\]
\[
\mathcal L_{+-}D_{\rm ker}
=
\frac{(1-a)(1-b)(r_p-r_q)+(a+b)h_{pq}}
 {pq(q-p)}.
\tag{2.3}
\]
Предел \(p=q\) сохраняется. В частности,
\[
\mathcal L_{++}D_{\rm ker}(p,p)
=\frac{(\kappa_p^2-1)r_p}{p^3}.
\tag{2.4}
\]
Исчезновение коэффициента при \(h_{pp}\) в (2.4) не удаляет \(h\) из других параметров или смешанного квадранта.

Ни \(r_p=0\), ни \(h_{pq}=0\) не используются. Сентябрьская эквивалентность полной идентичности ядра скалярной Poisson-формуле остаётся историческим результатом с открытым последним равенством; её не перепродаём как Q12.

### 2.2. Возврат на конечное окно без пересечения полюсов

В обоих знаках времени используем уже вычисленное ориентированное представление
\[
A_t(x)=\int_0^t e^{-ixr}dr,\qquad
B_t(x)=\int_0^t e^{-ix(t-r)}g'(r)dr,
\tag{2.5}
\]
\[
S_t^{\rm ref}(x)=\alpha(x)A_t(x)-i\beta(x)B_t(x).
\]
Исправленный prefactor \(-i\) меняет \(S^{\rm ref}\) на общий минус; ниже он удаляется **только внутри норм и Gram**. Отрицательное время в (2.5) остаётся ориентированным, не чётным.

Для проверки двух знаков:
\[
\int_0^\infty e^{-pt}S_t^{\rm ref}(x)dt
=\frac{\alpha-i\kappa_p\beta}{p(p+ix)},\qquad
\int_0^\infty e^{-pt}S_{-t}^{\rm ref}(x)dt
=\frac{-\alpha-i\kappa_p\beta}{p(p-ix)}.
\tag{2.6}
\]
Они дают соответственно (2.2) и (2.3) после Gram-произведения и вычитания арифметического ядра. Абсолютная Bochner-сходимость при \(p>1/2\) следует из имеющегося \(\|S_t\|\le C(1+|t|)e^{|t|/2}\). Здесь не нужен контур через неизвестные полюса.

Для получения оценки не выполняем приближённого обращения Лапласа. Работать с точным конечновременным (2.5) означает сохранять **тот же** обратный объект, включая все его непуассоновские члены. Ошибка численного/контурного обращения в доказательстве равна нулю: такое обращение не используется.

## 3. Конкретный испытываемый механизм: действительная спектральная проекция

### 3.1. Полный оператор теста

**[ABSTRACT | PAPER — S3 (7)–(10), с явной нормировкой.]** Пусть \(\mathcal F\) — унитарное преобразование Фурье с экспонентой \(e^{-ixr}\). Определим
\[
(\mathcal B_T\psi)(r)=
\begin{cases}
-\displaystyle\int_0^\infty g'(s)\psi'(r+s)ds,&r>0,\\
-\displaystyle\int_0^\infty g'(s)\psi'(r-s)ds,&r<0.
\end{cases}
\tag{3.1}
\]
Нулевое продолжение \(\psi\) делает интегралы конечными. Значение в одной точке \(r=0\) не меняет \(L^2\)-оператор. Два знака в (3.1) нельзя отождествлять с одним глобальным причинным свёрточным оператором.

Точный corrected Gram:
\[
\boxed{
\mathcal N_m[f]
=2\|\alpha\mathcal F\psi-i\beta\mathcal F(\mathcal B_T\psi)\|_2^2.
}
\tag{3.2}
\]
Множитель 2 — \(1/\pi\) из Gram, умноженный на \(2\pi\) из исходной ненормированной Fourier-конвенции. Он не подбирается по нулевому тесту.

Для комплексных тестов полезно проверить реальность ядра: на действительной оси
\(\alpha(-x)=-\overline{\alpha(x)}\), \(\beta(-x)=\overline{\beta(x)}\),
\(S_t^{\rm ref}(-x)=-\overline{S_t^{\rm ref}(x)}\).
Следовательно \(K_{\rm norm}\) реально и симметрично. Поэтому комплексное сопряжение в определении \(\widehat{\mathcal P}\) даёт ту же диагональную форму (3.2), а не другую конвенцию на mixed coefficients.

Интегрирование по частям использует \(A_0=B_0=0\) и нулевые внешние следы \(\psi(\pm T)=0\). Ненулевое \(\psi(0)\) не выкидывается. Ни в одной строке не подставляется конечное число вместо \(g'(0+)\).

### 3.2. Совместная проекция до оценок

На действительной оси тождественно
\[
|\alpha|^2+|\beta|^2=1,\qquad
\eta^2=\omega(1-\omega),\qquad
\Pi_\xi(x)=
\begin{pmatrix}1-\omega&-i\eta\\i\eta&\omega\end{pmatrix}
=\Pi_\xi(x)^*=\Pi_\xi(x)^2.
\tag{3.3}
\]
Это настоящий ранг-один проектор, заданный \(X,X'\), а не выбранный независимо bounded multiplier.

При \(F=\mathcal F\psi,G=\mathcal F\mathcal B_T\psi\):
\[
\mathcal N_m[f]
=2\int\left[(1-\omega)|F|^2+\omega|G|^2
+i\eta(F\overline G-G\overline F)\right]dx.
\tag{3.4}
\]
**Оба mixed-члена остаются.** Эквивалентно,
\[
\boxed{
\mathcal N_m[f]
=2\left[\|\psi\|^2+\|\mathcal B_T\psi\|^2
-\|\overline\beta F+i\overline\alpha G\|^2\right].
}
\tag{3.5}
\]
Последний квадрат — точный положительный кредит дополнения спектральной проекции. Это не ещё одна гипотеза о положительности арифметической формы.

**Проверяемая количественная часть механизма:** оценить полный \(\mathcal B_T\) без прежней платы \(\|\psi'\|_1^2\sim L\Omega^2\). Если затем отбрасывание последнего квадрата не даёт требуемую степень, явно остановить именно этот переход, не объявляя отрицательный результат для actual cancellation.

## 4. Точное разложение Volterra-оператора с исходными контактами

Из S2/S3, для \(s>0\),
\[
g'(s)=\underbrace{-4\sinh(s/2)}_{v_{\rm pole}(s)}
+\underbrace{\sum_{n\le e^s}\frac{\Lambda(n)}{\sqrt n}}_{v_{\rm pr}(s)}
+\underbrace{\frac{c_A}{2}-\frac12e^{-s/2}\Phi(e^{-2s},1,1/4)}_{v_{\rm ar}(s)}.
\tag{4.1}
\]
Все три части возвращаются. В частности, отбрасывание \(v_{\rm pole}\) до использования контактов было бы неверным.

Определим **направленный от середины сдвиг**
\[
(\mathcal W_s\psi)(r)=
\begin{cases}\psi(r+s),&r>0,\\\psi(r-s),&r<0,\end{cases}
\quad s\ge0,
\qquad (J\psi)(r)=\operatorname{sgn}(r)\psi(r).
\tag{4.2}
\]
Он не заменяет исходные prime shifts: это буквальное представление (3.1).
\[
\|\mathcal W_s\|\le1,\qquad
\|(\mathcal W_s-I)\psi\|\le\min\{s\|\psi'\|,2\|\psi\|\}.
\tag{4.3}
\]
Для второго неравенства используем
\(\mathcal W_s\psi-\psi=\int_0^s\mathcal W_v(J\psi')dv\).
Здесь не дифференцируется разрывный множитель \(J\), и не требуется нулевое значение \(\psi\) в середине. Обе полупрямые интегрируются вместе; дополнительного множителя размерности или \(\sqrt2\) нет.

### Лемма 1. Полный полюсный вклад становится затухающим

**[FINITE_CELL | PAPER — новый количественный возврат.]** На точном классе (0.2)
\[
\boxed{
\mathcal B_{\rm pole}\psi=k*\psi,
\qquad k(t)=\operatorname{sgn}(t)e^{-|t|/2},
\qquad \|\mathcal B_{\rm pole}\psi\|_2\le2\|\psi\|_2.
}
\tag{4.4}
\]

**Доказательство.** При \(r>0\) интегрирование полюсной части (3.1) по частям даёт
\[
\mathcal B_{\rm pole}\psi(r)
=-e^{-r/2}\int_r^T e^{u/2}\psi(u)du
-e^{r/2}\int_r^T e^{-u/2}\psi(u)du.
\]
Первый интеграл, и только он, заменяется с помощью полного контакта \(\int_{-T}^Te^{u/2}\psi(u)du=0\). Получаем
\[
\mathcal B_{\rm pole}\psi(r)
=\int_{-T}^r e^{-(r-u)/2}\psi(u)du
-\int_r^T e^{-(u-r)/2}\psi(u)du.
\tag{4.5}
\]
При \(r<0\) интегрирование даёт сумму двух интегралов по \([-T,r]\) с положительным знаком; контакт с \(e^{-u/2}\) превращает её в ту же (4.5). Снаружи окна выражение тоже нулевое именно по двум полным контактам.

Fourier-множитель свёртки равен
\[
\widehat k(x)=-\frac{2ix}{x^2+1/4},\qquad
\sup_{x\in\mathbb R}|\widehat k(x)|=2.
\]
Планшерель даёт (4.4). Ни нормы растущего ядра, ни отдельного обрезанного непрерывного блока в этой строке не оплачено. Это точное совместное использование исходных экспоненциальных условий. ∎

### Лемма 2. Архимедов вклад имеет логарифмическую, а не степенную полосу

**[FINITE_CELL | PAPER — новый количественный возврат.]** Имеем точную формулу
\[
\boxed{
\mathcal B_{\rm ar}\psi
=J\left[\frac{c_A}{2}\psi+
\int_0^\infty a(s)(\mathcal W_s\psi-\psi)ds\right],
\qquad a(s)=\frac{e^{-s/2}}{1-e^{-2s}}.
}
\tag{4.6}
\]
Интеграл — сходящийся в \(L^2\) интеграл разностей. Более того,
\[
\boxed{
\|\mathcal B_{\rm ar}\psi\|_2
\le\left[\frac{c_A}{2}+7+\log(1+\Omega)\right]\|\psi\|_2.
}
\tag{4.7}
\]

**Доказательство тождества.** Буквальный Lerch-член имеет первообразную
\[
v_{\rm ar}(s)=\frac{c_A}{2}-A(s),\qquad
A(s)=\int_s^\infty a(v)dv
=\operatorname{artanh}(e^{-s/2})+\arctan(e^{-s/2}).
\tag{4.8}
\]
Это следует либо из ряда, либо из подстановки \(z=e^{-v/2}\):
\(2/(1-z^4)=1/(1-z^2)+1/(1+z^2)\).
Вставляем (4.8) в (3.1), меняем порядок интегрирования сначала с нижним отсечением и затем возвращаем разность. На положительной полупрямой
\(\int_0^v\psi'(r+s)ds=\psi(r+v)-\psi(r)\),
на отрицательной
\(\int_0^v\psi'(r-s)ds=\psi(r)-\psi(r-v)\).
Получается (4.6). Сингулярное значение \(A(0)=+\infty\) не выделяется отдельным членом.

По (4.3) интеграл нормы не больше
\[
I(\Omega)=\int_0^\infty a(s)\min\{s\Omega,2\}ds.
\]
Неравенство \(1/(1-e^{-2s})\le1+1/(2s)\) даёт
\(a(s)\le e^{-s/2}(1+1/(2s))\).
Первое слагаемое интегрируется с ценой не больше \(4\). Для второго делим в \(s_0=(1+\Omega)^{-1}\) и в 1:
\[
\int_0^{s_0}\frac{e^{-s/2}}{2s}\min(s\Omega,2)ds\le\frac12,
\]
\[
\int_{s_0}^1\frac{e^{-s/2}}{2s}\min(s\Omega,2)ds\le\log(1+\Omega),
\]
\[
\int_1^\infty\frac{e^{-s/2}}{2s}\min(s\Omega,2)ds<2.
\]
Следовательно \(I(\Omega)\le7+\log(1+\Omega)\), что доказывает (4.7). Константы не зависят от \(L,M\). ∎

Ни `gprime(0)=0`, ни конечное `gprime(0)`, ни несуществующая высокая гладкость нулевого продолжения не использованы.

### Лемма 3. Полная временная простая часть и её фактическая цена

**[FINITE_CELL | PAPER.]** Из каждого буквального скачка в (4.1):
\[
\boxed{
\mathcal B_{\rm pr}\psi
=J\sum_{2\le n\le e^T}\frac{\Lambda(n)}{\sqrt n}\mathcal W_{\log n}\psi.
}
\tag{4.9}
\]
Поэтому
\[
\boxed{\|\mathcal B_{\rm pr}\psi\|\le W(e^T)\|\psi\|,\qquad
W(y)=\sum_{2\le n\le y}\frac{\Lambda(n)}{\sqrt n}.}
\tag{4.10}
\]
В точке \(\log n=T\) исходный сдвиг нулевой почти всюду; он может оставаться в сумме. Никакая степень простого не потеряна.

**Почему \(e^T=\sqrt m\) не является заменой производственного cutoff.** Это поддержка временного Volterra-члена отдельного Gram-представления. Полная арифметическая форма (1.3) всё ещё содержит \(n\le m\). Кроме того, \(\alpha,\beta\) определены полной \(\xi\). Утверждение, что все простые между \(\sqrt m\) и \(m\) исчезли из ошибки, было бы неверным.

Для полноты оплачиваем (4.10) элементарной арифметикой, без PNT-ошибки. Если \(n=2^{j-1}\), то
\[
\psi(2n)-\psi(n)\le\log\binom{2n}{n}\le2n\log2.
\]
Каждая простая степень в \((n,2n]\) даёт единицу в соответствующем valuation центрального биномиального коэффициента; другие valuation-слагаемые неотрицательны. Суммирование по степеням двух и округление вверх дают
\[\psi(x)\le4(\log2)x<3x\quad(x\ge1).\]
Отсюда точное частичное суммирование даёт
\[
W(y)=\frac{\psi(y)}{\sqrt y}
+\frac12\int_1^y\psi(t)t^{-3/2}dt
\le6\sqrt y.
\tag{4.11}
\]
Малые начальные значения также покрываются. Это слабая, но доказанная цена, не скрытая RH-предпосылка.

### Сборка трёх частей

Из (4.4), (4.7), (4.10), при
\[
C_\Omega=9+\frac{c_A}{2}+\log(1+\Omega),\qquad
b_m=W(\sqrt m)+C_\Omega,
\tag{4.12}
\]
получается
\[
\boxed{
\mathcal B_T=\mathcal B_{\rm pole}+\mathcal B_{\rm ar}+\mathcal B_{\rm pr},
\qquad \|\mathcal B_T\psi\|\le b_m\|\psi\|.
}
\tag{4.13}
\]
Равенство сохраняет все взаимные произведения при последующем квадрате. Неравенство — первый скалярный бюджет для всего этого линейного оператора; знак взаимных частей после него уже не используется.

## 5. Полная односторонняя ошибка и её окончательная степень

### Теорема. Безусловный верх полного исправленного дефекта

**[FINITE_CELL | PAPER — новый аналитический конверт.]** На исходном пространстве (0.1), с величинами (4.12),
\[
\boxed{
\begin{aligned}
\Delta_m[f]
&\le \mathfrak e_m\|f\|^2-\mathcal D_{\rm arch}(\psi),\\
\mathfrak e_m
&=2(1+b_m^2)+2W(m)+c_A.
\end{aligned}}
\tag{5.1}
\]
В частности,
\[
\boxed{\Delta_m[f]\le\mathfrak e_m\|f\|^2.}\tag{5.2}
\]
Оценка едина по **всем** комплексным исходным векторам при данном \(m\). Она также действует после суммирования по спектральному разложению любого \(W=PWP\succeq0\) с \(\operatorname{Tr}W=1\); веса отдельных мод или пар не подбираются под \(W\).

**Доказательство.** Контрактность действительной проекции (3.3) даёт
\[
\mathcal N_m[f]\le2\bigl(\|\psi\|^2+\|\mathcal B_T\psi\|^2\bigr)
\le2(1+b_m^2)\|\psi\|^2.
\tag{5.3}
\]
Точная исходная форма (1.2), а не неоценённая September identity, даёт
\[
\Delta_m[f]
=\mathcal N_m[f]-\mathcal D_{\rm arch}(\psi)
+c_A\|\psi\|^2+S_m[f].
\tag{5.4}
\]
Полное \(S_m\) ограничивается настоящей суммой всех весов:
\[
S_m[f]\le2W(m)\|\psi\|^2,
\]
поскольку каждый исходный сдвиг — сжатие унитарного полного сдвига, а его симметризация имеет норму не больше двух. Подстановка доказывает (5.1), положительность \(\mathcal D_{\rm arch}\) — (5.2). ∎

**Граница использования знака.** Это односторонняя оценка \(\Delta\), не равенство \(\Delta=0\), не верх её абсолютной величины и не оценка знака каждого \(r_p\) или \(h_{pq}\). В proof (5.4) все простые между \(\sqrt m\) и \(m\) сохраняются через \(S_m\). Межпраймовые произведения внутри \(\mathcal N_m\) сохранены до (5.3); в этой строке они **оплачены**, а не объявлены нулевыми.

### 5.1. Явная степенная цена

Из (4.11):
\[
b_m\le6m^{1/4}+C_\Omega,
\]
\[
\boxed{
\mathfrak e_m\le
84\sqrt m+24C_\Omega m^{1/4}+2C_\Omega^2+c_A+2.
}
\tag{5.5}
\]
На расписании \(M=\lfloor m^\epsilon\rfloor\), при фиксированном \(\epsilon\),
\[
C_\Omega=9+c_A/2+\log(1+2\pi M/L)=O_\epsilon(1+L).
\]
Поэтому
\[
\boxed{\mathfrak e_m=O_\epsilon(m^{1/2}).}\tag{5.6}
\]
Здесь нет скрытого \(m^{2\epsilon}\), платы за число мод, коэффициентов локального базиса или зависящего от \(m\) порядка производных.

| Часть полного бюджета | Доказанная цена | Степень на исходном расписании |
|---|---:|---:|
| Полюсный Volterra-вклад после **обоих** контактов | \(2\) | \(0\) |
| Архимедов Volterra-вклад | \(c_A/2+7+\log(1+\Omega)\) | \(0\) с логарифмами |
| Простая Volterra-часть | \(W(\sqrt m)\le6m^{1/4}\) | \(1/4\) до квадрата |
| Полный Gram после совместной спектральной проекции и её контрактности | \(2[1+(W(\sqrt m)+C_\Omega)^2]\) | \(1/2\) |
| Полный линейный простой член в \(\Delta\) | \(2W(m)\le12\sqrt m\) | \(1/2\) |
| Остальной явный архимедов вклад в \(\Delta\) | \(c_A\|f\|^2-\mathcal D_{\rm arch}\) | Верх \(c_A\|f\|^2\) |
| Ошибка смены окна / частот / проектора | \(0\) | Такие замены не выполнялись |
| Ошибка численного обратного Laplace/Fourier-преобразования | \(0\) | Численное обращение в доказательстве не используется |

Прежняя оценка S1 имела цену \(C\sqrt m M^2L\), то есть \(1/2+2\epsilon\). Здесь **вся исправленная ошибка** получает меньший конверт (5.5). Но это улучшение цены представления. Уже принятая исходная CCM имеет элементарную половинную степень; арифметический показатель не уменьшился.

### 5.2. Домен и оба физических края

**[FINITE_CELL | PAPER.]** Формулы для \(A_t,B_t\) сначала дают тождества для компактных гладких тестов. На фиксированном \([-T,T]\) прежний Bochner-конверт S2/S3 делает нормовое преобразование непрерывным по \(\|\psi'\|_1\). Обычная \(H_0^1\)-аппроксимация возвращает (3.1)–(3.2) для настоящего \(\psi\). Гладкие аппроксиманты нужны для доменного перехода, не для изменения заявленного конечного тестового пространства.

Новые оценки (4.4), (4.6) доказаны непосредственно для исходного \(H_0^1\)-теста. При необходимости аппроксиманты можно исправить двумя фиксированными компактными профилями для сохранения экспоненциальных моментов; их поправки стремятся к нулю при фиксированной ячейке. Это не является новой асимптотической платой и не добавляет условий на \(f\).

Для арифметической формы \(S_m\) число атомов при фиксированном \(m\) конечно. Каждый сдвиг непрерывен в \(L^2\). Архимедова энергия также непрерывна при \(H^1\)-сходимости: возле нуля применяется \(\|\tau_s\psi-\psi\|\le s\|\psi'\|\), вдали — \(2\|\psi\|\). Поэтому (5.4) возвращается с точной нормировкой, без предполагаемой полной Poisson identity.

Ничего не обрезано около \(r=0\). На двух физических концах \(\psi(\pm T)=0\) устраняет граничные значения самой функции, но не вводит \(\psi'(\pm T)=0\). В (4.6) хвост \(s>T\) сохраняется: там \(\mathcal W_s\psi=0\), однако слагаемое \(-\psi\) продолжает давать точный конечный вклад. Он не выкинут.

### 5.3. Возврат в исходный потребитель: не начислять расходы дважды

**[COFINAL_FAMILY | PAPER — следствие (5.2) на принятых source maps.]** Так как \(\mathcal N_m\ge0\),
\[
\boxed{PK_mP\succeq-\mathfrak e_m P.}\tag{5.7}
\]
Это уже прямая нижняя оценка **полной** \(\mathcal Q\). Дополнительный `arch50L+8` поверх неё не нужен.

Если нужен именно простой оператор, исходное равенство
\[
PK_mP=D_{{\rm arch},m}-S_m
\]
даёт
\[
S_m\preceq D_{{\rm arch},m}+\mathfrak e_mP
\preceq(\mathfrak e_m+50L+8)P.
\tag{5.8}
\]
Затем ровно
\[
T_{>R}=S_m-T_{\le R}
\preceq(\mathfrak e_m+50L+8)P-T_{\le R},
\]
а для скалярного конверта добавляется один раз

\tag{5.9}
\]
Q02-плата \(F_2=O_\epsilon(m^\epsilon\log m)\) нужна только для отдельного перехода \(V=T_{>R}+(V-T_{>R})\), не для прямой (5.7).

\]
Он не нуждается в Suzuki-разложении. Поэтому (5.7) нельзя выдавать за улучшение полной CCM. Прежний Q03 с показателем \(3/8\) остаётся **условным на ту же ZF78**; в настоящем выводе ZF78 не использована и не передоказана.

Ни (5.7), ни (5.10) не дают \(\eta(\epsilon)\to0\). Усреднение по \(m\) или выбор масштаба в зависимости от вектора не применялись. Полученная граница действует на всех ячейках в заявленной области, но имеет прежнюю половинную степень.

## 6. Настоящий joint-остаток: что именно ещё не оценено

### 6.1. Полная арифметика до отдельных норм

**[FINITE_CELL | PAPER — точное выявление неоплаченной строки, не новый supplier.]** Положим
\[
\mathcal B_0=\mathcal B_{\rm pole}+\mathcal B_{\rm ar},
\qquad \|\mathcal B_0\psi\|\le C_\Omega\|\psi\|,
\]
\[
Y\psi=\alpha\mathcal F\psi-i\beta\mathcal F\mathcal B_0\psi,
\qquad
Z\psi=\beta\mathcal F\mathcal B_{\rm pr}\psi.
\]
Тогда
\[
\mathcal N_m[f]=2\|Y\psi-iZ\psi\|^2,
\]
и при скалярном произведении, линейном по первому аргументу,
\[
\boxed{
\begin{aligned}
\Delta_m[f]={}&2\|Z\psi\|^2+S_m[f]
+4\Re\langle Y\psi,-iZ\psi\rangle\\
&+2\|Y\psi\|^2-\mathcal D_{\rm arch}(\psi)+c_A\|\psi\|^2.
\end{aligned}}
\tag{6.1}
\]
В частности, полный квадрат простого Volterra-оператора равен
\[
\begin{aligned}
\|Z\psi\|^2
={}&\sum_{n,r\le\sqrt m}
\frac{\Lambda(n)\Lambda(r)}{\sqrt{nr}}\\
&\ \cdot\left\langle
\beta\mathcal FJ\mathcal W_{\log n}\psi,
\beta\mathcal FJ\mathcal W_{\log r}\psi
\right\rangle.
\end{aligned}
\tag{6.2}
\]
Это все \(n,r\), а не только диагональ. Каждое преобразование содержит обе временные полупрямые. После Fourier-множителя они в общем случае взаимодействуют; замена \(\omega\) константой или удаление этих смешанных произведений не использована в равенстве.

Веса действительно арифметические:
\[
\Lambda(n)=\sum_{d\mid n}\mu(d)\log(n/d).
\tag{6.3}
\]
Они остаются такими одновременно в (6.2) и в полном линейном \(S_m\) до \(m\). Раскрытие (6.3) только перегруппирует все пары делителей. В данном расчёте оно не поставило знака для (6.1).

### 6.2. Первая потеря и первая неоплаченная количественная строка

**Первое ослабление** — (5.3), то есть удаление точного комплементарного квадрата в (3.5). В нём хранилось согласование \(\mathcal F\psi\) и \(\mathcal F\mathcal B_T\psi\) с конкретными \(X,X'\). После этого используются только единичная длина строки \((\alpha,-i\beta)\) и отдельные нормы временных частей.

В самом (6.1) не доказан верх полной знаковой суммы, который стоил бы \(o(m^{1/2})\) по фиксированной степени или \(m^{\eta(\epsilon)}\), \(\eta\to0\). Оставшиеся доступные самостоятельные цены имеют вид
\[
2W(\sqrt m)^2+2W(m)
+4(1+C_\Omega)W(\sqrt m)
+2(1+C_\Omega)^2+c_A.
\tag{6.4}
\]
Это снова половинная степень. Здесь \(\|Y\psi\|\le(1+C_\Omega)\|\psi\|\), а не предполагаемая независимость \(Y\) и \(Z\).

**Это не нижняя граница (6.1).** Большие по отдельности положительные суммы не исключают компенсацию через реальный спектральный множитель и mixed terms. Особенно нельзя заключать, что отдельный контроль \(\Delta\) доказанно слишком силён: для такого утверждения нужна настоящая нижняя оценка \(\Delta\) на исходном \(P\). В Q12 она не получена. Следовательно, данный ответ не объявляет ни actual \(\Delta\), ни совместную форму \(\mathcal N-\Delta\) невозможной.

Переформулировка (6.1) как «новой леммы» не изменила бы математический долг. Она приведена только для идентификации **того шага, который не поставлен**, и проверки того, что никакой спектральный или арифметический член не потерян.

### 6.3. Что могло бы реально отличить следующий механизм

Новый механизм обязан использовать больше, чем \(0\le\omega\le1\), \(\eta^2=\omega(1-\omega)\) и отдельные нормы \(\mathcal B\). В частности, он должен сохранить связь настоящего \(\xi\)-множителя с **тем же** арифметическим \(g'\) при оценке (6.1) либо непосредственно \(\mathcal N-\Delta\).

Дешёвый положительный контроль: при корректной all-real convention два Laplace-квадранта должны давать именно (2.2)–(2.3), а на исходном тесте полюсный оператор обязан равняться (4.5), с полным хвостом архимедовой разности. Отрицательный контроль: согласованная мероморфная модель из §7.2 имеет unitary real-axis algebra, но ненулевые \(r,h\). Алгоритм, который уничтожает её остаток по одной boundary-unitarity, неправилен. Успех такого отрицательного контроля **не** доказывает ничего о знаке дефекта настоящей \(\xi\).

## 7. Проверки: что исполнено и что они не сертифицируют

### 7.1. Регистрация и exact-контроли

**[ABSTRACT / FINITE_CELL | PAPER — проверяемая конечная алгебра; это не LEAN и не ARB_INTERVAL.]** До запуска новых скриптов, но после чтения источников и предварительного бумажного вывода, сохранена регистрация `registration.json`. Это не прогноз будущего открытия задним числом.

Выполнены **449 exact-проверок** с рациональными числами Python `Fraction` и символьной алгеброй SymPy. Они проверяют:

1. ранг-один проектор и комплементарный квадрат, включая комплексные mixed terms; намеренные удаление и переворот знака \(\eta\) обнаруживаются;
2. оба Laplace-вычитания, диагональ \(p=q\) и предельный смешанный квадрант;
3. калибровочную real-zero модель и ненулевой согласованный non-Poisson контроль;
4. оба полюсных контактных преобразования, Fourier-норму, архимедову первообразную и конечные направленные сдвиги;
5. буквальную \(\Lambda=\mu*\log\) до \(n=180\) с формальными коэффициентами при \(\log p\), а не floating-point логарифмами;
6. окончательное раскрытие коэффициентов бюджета (5.5).

**Не замалчиваем ошибку инструмента.** Первый запуск остановился на проверке `pole_fourier_norm_square`: один и тот же полином сравнивался оператором структурного равенства в разложенном и факторизованном виде. Математическая идентичность
\[
4(y^2+1/4)^2-4y^2=4(y^2-1/4)^2
\]
верна. Проверка исправлена на раскрытие **разности** и сравнение её с нулём; ни утверждение, ни константа не менялись. Начальный неуспешный скрипт сохранён локально. Он не засчитан как успешная проверка и не выдан за опровержение математики. Итоговые 449 относятся только к исправленному запуску.

### 7.2. Согласованный non-Poisson контроль — только контроль метода

**[ABSTRACT | PAPER — вспомогательная модель, НЕ \(\xi\), НЕ actual CCM.]** Возьмём
\[
X_H(z)=z^2+\frac{33}{256},\qquad b=\frac1{16},\quad c=\frac{33}{16},\quad bc=\frac{33}{256}.
\]
Тогда \(X_H\) вещественная чётная, её нули \(\pm i\sqrt{33}/16\) находятся в полосе \(|\Im z|<1/2\). Реальные множители имеют **ту же точную** алгебру (3.3), а
\[
(X_H(x))^2+(X_H'(x))^2=(x^2+b^2)(x^2+c^2).
\]
Непосредственное интегрирование рациональных дробей даёт
\[
\Omega_H(p)=1-\frac{4p}{(b+c)(p+b)(p+c)},\qquad
\kappa_H(p)=\frac{2p}{bc-p^2},
\]
\[
J_H(p,q)=\frac2{b+c}\left[
 b\left(\frac1{b+p}-\frac1{b+q}\right)
+c\left(\frac1{c+p}-\frac1{c+q}\right)
\right].
\tag{7.1}
\]
Здесь \(\kappa_H=-F_H'/F_H\), \(F_H(p)=X_H(ip)=bc-p^2\); это согласованная подмена целого источника для контроля, не произвольная независимая подмена \(\omega,\eta\).

В частности,
\[
\boxed{r_H(1)=\frac{512}{4335}\ne0,\qquad h_H(1,2)\ne0.}\tag{7.2}
\]
В \(F_H/(F_H+F_H')\) есть полюс \(p=1/16>0\). Поэтому бесплатное Poisson-восстановление нарушилось бы именно в запрещённой строке, где выкинули мероморфный вклад. Рациональные интегралы в (7.1), их вычитания и ненулевой \(h_H\) проверены точно; для факта \(r_H\ne0\) не нужна численная интеграция.

Эта модель не удовлетворяет всем арифметическим свойствам \(\xi\), её \(g'\) не является исходным простым рядом. Она не устанавливает ненулевой \(r_p\) или полюс для настоящей функции и не является новым источниковым no-go. Это проверка корректности выбранного инструмента. Известное сентябрьское предупреждение о boundary-unitarity остаётся предупреждением, а не новым результатом Q12.

Локальная среда: Python 3, SymPy 1.14.0. Код использует точные дроби и символы. Он проверяет перечисленные конечные тождества, не бесконечное семейство CCM. Переменная `base` — каталог самого скрипта; `registration.json` должен находиться рядом. `M` производственной матрицы не является параметром этих алгебраических тестов.

```python check_q12.py
from fractions import Fraction as F
from math import comb
from pathlib import Path
import json, hashlib
import sympy as s

checks=[]
def check(name, condition):
    if not bool(condition): raise AssertionError(name)
    checks.append(name)

# Rank-one identity and the full complex cross term: exact rational arithmetic.
def mul(z,w): return (z[0]*w[0]-z[1]*w[1],z[0]*w[1]+z[1]*w[0])
def add(z,w): return (z[0]+w[0],z[1]+w[1])
def conj(z): return(z[0],-z[1])
def norm2(z): return z[0]*z[0]+z[1]*z[1]
I=(F(0),F(1)); mi=(F(0),F(-1))
for h in [F(-3),F(-2,3),F(0),F(1,3),F(1),F(4)]:
    w=1/(1+h*h); eta=h*w
    alpha=(eta,1-w); beta=(w,eta)
    check(f'unit_row/{h}',norm2(alpha)+norm2(beta)==1)
    check(f'determinant/{h}',w*(1-w)==eta*eta)
    for v in [(F(1),F(0)),(F(1,2),F(-2,3)),(F(0),F(1))]:
      for g in [(F(0),F(1)),(F(2,3),F(1,5)),(F(-1),F(0))]:
        z=add(mul(alpha,v),mul(mi,mul(beta,g)))
        zc=add(mul(conj(beta),v),mul(I,mul(conj(alpha),g)))
        # Direct expression for i eta(v bar(g)-g bar(v)).
        q=(1-w)*norm2(v)+w*norm2(g)-2*eta*mul(v,conj(g))[1]
        check(f'full_mixed/{h}/{v}/{g}',norm2(z)==q)
        check(f'complement/{h}/{v}/{g}',norm2(z)+norm2(zc)==norm2(v)+norm2(g))

alpha=beta=(F(1,2),F(1,2)); v=(F(1),F(0));g=(F(0),F(1))
z=add(mul(alpha,v),mul(mi,mul(beta,g)))
diagonal=F(1,2)*(norm2(v)+norm2(g))
wrong_sign=diagonal+mul(v,conj(g))[1]
check('planted_eta_omission',norm2(z)!=diagonal)
check('planted_eta_wrong_sign',norm2(z)!=wrong_sign)

# Both supplied transform defects, treated as algebra, not assumed zero.
a,b,Op,Oq,J,p,q=s.symbols('a b Op Oq J p q')
rp=Op-1/(1-a);rq=Oq-1/(1-b);hpq=J+Op-Oq
Npp=(2+(a*b-1)*(Op+Oq)+(b-a)*J)/(p*q*(p+q))
App=-(a+b)/(p*q*(p+q))
Dpp=((a-1)*(b+1)*rp+(b-1)*(a+1)*rq+(b-a)*hpq)/(p*q*(p+q))
Npm=((1+a*b)*(Op-Oq)+(a+b)*J)/(p*q*(q-p))
Apm=(a-b)/(p*q*(q-p))
Dpm=((1-a)*(1-b)*(rp-rq)+(a+b)*hpq)/(p*q*(q-p))
check('Lpp_full_subtraction',s.factor(Npp-App-Dpp)==0)
check('Lpm_full_subtraction',s.factor(Npm-Apm-Dpm)==0)
check('Lpp_diagonal',s.factor((Npp-App-Dpp).subs({b:a,Oq:Op,J:0,q:p}))==0)
ap,op,jp=s.symbols('aprime Oprime Jprime')
rprime=op-ap/(1-a)**2
limit_from_defect=(-(1-a)**2*rprime+2*a*(jp-op))/p**2
limit_from_subtraction=(ap-(1+a*a)*op+2*a*jp)/p**2
check('Lpm_diagonal_limit',s.factor(limit_from_defect-limit_from_subtraction)==0)
check('real_zero_multiplier_limit',norm2((F(0),F(1)))+norm2((F(0),F(0)))==1)


# A consistent even polynomial plant, zeros at +/- i sqrt(33)/16.
b0=F(1,16); c0=F(33,16); A=b0*c0
omega=lambda p: 1-4*p/((b0+c0)*(p+b0)*(p+c0))
kappa=lambda p: 2*p/(A-p*p)
jfun=lambda p,q: F(2)/(b0+c0)*(b0*(1/(b0+p)-1/(b0+q))+c0*(1/(c0+p)-1/(c0+q)))
plant=[]
for pv in [F(3,4),F(1),F(3,2),F(2),F(3)]:
    r=omega(pv)-1/(1-kappa(pv))
    check(f'nonpoisson_actual_plant/{pv}',r!=0)

x=s.symbols('x',real=True)

for pv in [F(1),F(3,2),F(2),F(4)]:

        check(f'real_zero_pm/{pv}/{qv}',((1+av*bv)*(op-oq)+(av+bv)*jv)/(pv*qv*(qv-pv))==(av-bv)/(pv*qv*(qv-pv)))

# Positive/negative pole quadrant algebra with exact moment constraints.
# A+/A- are split at an arbitrary r. Set total exponential moments to zero.
r,ap,bp,am,bm=s.symbols('r ap bp am bm', real=True)
# ap,bp: e^(u/2) integrals below/above r; am,bm: e^(-u/2).
C=s.exp(-r/2)*ap-s.exp(r/2)*bm
Cp=-s.exp(-r/2)*bp-s.exp(r/2)*bm
Cm=s.exp(r/2)*am+s.exp(-r/2)*ap
check('pole_positive_contact',s.simplify(Cp.subs(bp,-ap)-C)==0)
check('pole_negative_contact',s.simplify(Cm.subs(am,-bm)-C)==0)
y=s.symbols('y', real=True)
check('pole_fourier_norm_square',s.expand(4*(y*y+s.Rational(1,4))**2-4*y*y-4*(y*y-s.Rational(1,4))**2)==0)

# Arch logarithmic cancellation and exact derivative of Lerch partial terms.
t=s.symbols('t',positive=True)
for n in range(12):
    v=-s.exp(-(2*n+s.Rational(1,2))*t)/(2*n+s.Rational(1,2))
    check(f'arch_term_derivative/{n}',s.simplify(s.diff(v,t)-s.exp(-(2*n+s.Rational(1,2))*t))==0)

# Full arithmetic log coefficients: Lambda = mu * log, with formal prime logs.
def factor(n):
    ans={};d=2
    while d*d<=n:
        while n%d==0:ans[d]=ans.get(d,0)+1;n//=d
        d+=1
    if n>1:ans[n]=ans.get(n,0)+1
    return ans

def mu(n):
    f=factor(n)
    return 0 if any(a>1 for a in f.values()) else (-1)**len(f)
for n in range(1,181):
    out={}
    for d in range(1,n+1):
      if n%d==0:
        for prime,power in factor(n//d).items():out[prime]=out.get(prime,0)+mu(d)*power
    out={p:a for p,a in out.items() if a}
    f=factor(n);target={next(iter(f)):1} if len(f)==1 else {}
    check(f'actual_mobius_prime_power/{n}',out==target)
# Two halves of outward shifts do not create a factor sqrt(2) in their norm.
for N in range(2,10):
    for shift in range(0,N+1):
        vec=[F((i*7)%11-5,7) for i in range(2*N)]
        old=sum(v*v for v in vec)
        new=sum(v*v for v in vec[:N-shift])+sum(v*v for v in vec[N+shift:])
        check(f'outward_contractivity/{N}/{shift}',new<=old)

# Finite full budget arithmetic; no proof of the target is asserted here.
w,Cc,ca=s.symbols('w Cc ca',nonnegative=True)
E=2*(1+(6*w+Cc)**2)+12*w*w+ca
check('full_defect_fee_expand',s.expand(E-(84*w*w+24*w*Cc+2*Cc*Cc+ca+2))==0)

base=Path(__file__).resolve().parent
out={'status':'PASS_EXACT_LOCAL_ALGEBRA_NOT_CCM_CERTIFICATION','count':len(checks),
```

## Приложение D. Полный неинтервальный диагностический скрипт

Локальная среда: mpmath 1.3.0, 40 десятичных знаков. `m=64`, `M=2` — явно заданная конечная диагностика тождеств; они не подставляются в асимптотический receiver как производственная пара. `ratio` задаёт положение `r=ratio*T` внутри исходного центрированного окна.

```python diagnostic_q12.py
from pathlib import Path
import mpmath as mp
import json,hashlib
mp.mp.dps=40
m=64; L=mp.log(m); T=L/2; w=2*mp.pi/L
cA=mp.euler+mp.log(8*mp.pi)+mp.pi/2
E0=-mp.mpf(3)/4;E1=1+4*w*w;E2=-(mp.mpf(1)/4+4*w*w)
O1=mp.mpf(1)/4+w*w;O2=-(mp.mpf(1)/4+4*w*w)/2
norm=mp.sqrt(L*(E0**2+(E1**2+E2**2+O1**2+O2**2)/2))
def psi(r):
    if r < -T or r > T:return mp.mpc(0)
    t=r+T
    return (E0+E1*mp.cos(w*t)+E2*mp.cos(2*w*t)+1j*(O1*mp.sin(w*t)+O2*mp.sin(2*w*t)))/norm

def dpsi(r):
    t=r+T
    return (-E1*w*mp.sin(w*t)-2*E2*w*mp.sin(2*w*t)+1j*(O1*w*mp.cos(w*t)+2*O2*w*mp.cos(2*w*t)))/norm

def mangoldt(n):
    for p in range(2,n+1):
        if any(p%d==0 for d in range(2,int(p**.5)+1)):continue
        v=n
        while v%p==0:v//=p
        if v==1:return mp.log(p)
    return mp.mpf(0)

atoms=[(mp.log(n),mangoldt(n)/mp.sqrt(n)) for n in range(2,9) if mangoldt(n)]
def a(s):return mp.exp(-s/2)/(-mp.expm1(-2*s))
def tail(s):
    u=mp.exp(-s/2)
    return mp.atanh(u)+mp.atan(u)
def arch(s):return cA/2-tail(s)
def pole(s):return -4*mp.sinh(s/2)

results=[]
for ratio in [mp.mpf(-3)/4,mp.mpf(-1)/2,mp.mpf(-1)/4,mp.mpf(1)/4,mp.mpf(1)/2,mp.mpf(3)/4]:
    r=ratio*T;sg=mp.sign(r);A=T-abs(r)
    pole_direct=-mp.quad(lambda s:pole(s)*dpsi(r+sg*s),[0,A])
    pole_conv=mp.quad(lambda u:mp.exp(-(r-u)/2)*psi(u),[-T,r])-mp.quad(lambda u:mp.exp(-(u-r)/2)*psi(u),[r,T])
    arch_direct=-mp.quad(lambda s:arch(s)*dpsi(r+sg*s),[0,A/2,A])
    def diff(s):
        if s==0:return sg*dpsi(r)/2
        return a(s)*(psi(r+sg*s)-psi(r))
    arch_repaired=sg*(cA*psi(r)/2+mp.quad(diff,[0,A/2,A])-psi(r)*tail(A))
    prime_repaired=sg*sum(v*psi(r+sg*ell) for ell,v in atoms if ell<=A)
    hinges=sorted([mp.mpf(0)]+[ell for ell,v in atoms if ell<A]+[A])
    def gp(s):return pole(s)+arch(s)+sum(v for ell,v in atoms if ell<=s)
    full_direct=-sum(mp.quad(lambda s:gp(s)*dpsi(r+sg*s),[left,right]) for left,right in zip(hinges,hinges[1:]))
    repaired=pole_conv+arch_repaired+prime_repaired
    residuals=[abs(pole_direct-pole_conv),abs(arch_direct-arch_repaired),abs(full_direct-repaired)]
    if max(residuals)>mp.mpf('1e-32'):raise AssertionError((ratio,residuals))
    results.append({'r_over_T':str(ratio),'pole_residual':mp.nstr(residuals[0],8),'arch_residual':mp.nstr(residuals[1],8),'full_residual':mp.nstr(residuals[2],8)})

# Verify both original exponential contacts for this complex mode combination.
contacts=[abs(mp.quad(lambda r:mp.exp(s*r/2)*psi(r),[-T,0,T])) for s in [-1,1]]
if max(contacts)>mp.mpf('1e-32'):raise AssertionError(contacts)
base=Path(__file__).resolve().parent
out={'status':'PASS_DIAGNOSTIC_NOT_INTERVAL','dps':mp.mp.dps,
     'm':m,'M':2,'schedule_scope':'local finite-band identity test, not the asymptotic production M=floor(m^epsilon)',
     'results':results,'contacts':[mp.nstr(x,8) for x in contacts],
     'script_sha256':hashlib.sha256(Path(__file__).read_bytes()).hexdigest()}
(base/'diagnostic_results.json').write_text(json.dumps(out,indent=2))
print(json.dumps(out,indent=2))
```

## Приложение E. Воспроизведение из одного Markdown

Следующий код извлекает **ровно** приложенные блоки; исходный Markdown должен находиться в текущем каталоге под указанным именем. `archive` — путь к этому файлу; при переносе в другой каталог меняется только строка `Path(...)`. `out` — отдельный каталог проверок. Никакие файлы репозитория не изменяются.

```python extract_q12.py
from pathlib import Path
import re

archive = Path("PROSHKA_CCM_SUZUKI_PROJECTED_DEFECT_Q12_VERDICT_2026-10-22.md")
out = Path("q12_reproduction")
out.mkdir(exist_ok=True)
text = archive.read_text(encoding="utf-8")
for name, language in [
    ("registration.json", "json"),
    ("check_q12.py", "python"),
    ("diagnostic_q12.py", "python"),
    ("exact_results.json", "json"),
    ("diagnostic_results.json", "json"),
]:
    pattern = rf"^```{language} {re.escape(name)}\n(.*?)^```$"
    matches = re.findall(pattern, text, flags=re.M | re.S)
    if len(matches) != 1:
        raise RuntimeError(f"Expected exactly one block for {name}: {len(matches)}")
    target = out / ("expected_" + name if name.endswith("results.json") else name)
    target.write_text(matches[0], encoding="utf-8")
print(out.resolve())
```

```bash
python3 extract_q12.py
cd q12_reproduction
uv run --with sympy==1.14.0 check_q12.py
uv run --with mpmath==1.3.0 diagnostic_q12.py
python3 - <<'PY'
from pathlib import Path
import json
for name in ("exact_results.json", "diagnostic_results.json"):
    got = json.loads(Path(name).read_text())
    expected = json.loads(Path("expected_" + name).read_text())
    if got != expected:
        raise SystemExit(f"Mismatch: {name}; inspect versions and the exact difference")
    print("MATCH", name)
PY
```

Совпадение exact JSON проверяет воспроизведение конечного журнала и хешей. Совпадение diagnostic JSON в той же версии — воспроизведение неинтервальной диагностики. Несовпадение последних десятичных цифр при иной версии не является само по себе опровержением теоремы; сначала требуется изолировать различие. Ни один из этих запусков не заменяет независимый PAPER-аудит, Arb-сертификацию или Lean.

**Конечная граница:** исходный corrected Suzuki object, исходный `P`, все временные квадранты, простые степени и mixed terms сохранены. Полный односторонний дефект оплачен половинной степенью, без прежней платы `M^2`. Новая полная арифметическая степень и RH не доказаны.
