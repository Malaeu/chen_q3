\[

 C(y)=\int\overline{g(t)}k(t+y)dt,\qquad

## 2. Дополнительная точная арифметика и её конечная формула

### 2.1. Не статистическая гипотеза, а тождество настоящих коэффициентов

**Лемма 1 [ABSTRACT | PAPER].** Для каждого целого \(q\ge1\)
\[
 \mathfrak a(q):=\sum_{n\mid q}\Lambda(n)d_2(q/n)
              =\frac12d_2(q)\log q.                              \tag{2.1}
\]

**Доказательство.** С \(\mathbf1(n)=1\) имеем \(d_2=\mathbf1*\mathbf1\) и
\(\Lambda*\mathbf1=\log\). Поэтому \(\Lambda*d_2=\log*\mathbf1\).
В сумме \(\sum_{d\mid q}\log d\) замена \(d\mapsto q/d\) даёт
\(\sum\log d=d_2(q)\log q-\sum\log d\). Отсюда (2.1). Для q=1 обе стороны нулевые. Это конечное доказательство; никакой области сходимости ряда Дирихле пока нет. \(\square\)

Например,
\[
 \mathfrak a(p^j)=\frac{j(j+1)}2\log p,
 \qquad \mathfrak a(pq)=2(\log p+\log q)\quad(p\ne q).
\]
Удаление высших степеней нарушает первую формулу. Связь относится к тому же источнику, который определяет xi, а не только к среднему числу атомов.

### 2.2. Физический cutoff не заменяется бесконечным коэффициентом

**[FINITE_CELL | PAPER].** Определим
\[
 \mathfrak a_m(q)=\sum_{\substack{n\mid q\\2\le n\le m}}
                       \Lambda(n)d_2(q/n).                       \tag{2.2}
\]
Тогда
\[
 \mathfrak a_m(q)=\mathfrak a(q)\ (q\le m),\qquad
 0\le\mathfrak a_m(q)\le\mathfrak a(q)\ (q>m).                     \tag{2.3}
\]
При q>m разность не равна нулю. Она включает **все** делители n>m, отсутствующие в физической сумме. Никаких прямоугольных замен гиперболы nk=q нет.

Следующий раздел связывает именно (2.2), а не отвлечённую числовую сумму, с настоящей комплексной C. Пока (2.1)–(2.3) — только exact algebra, не улучшение CCM.

## 3. Реальный источниковый множитель и явное ядро

### 3.1. Отражение настоящего xi, без свободного поворота оси

**[ABSTRACT | PAPER].** Для \(s=1/2-z\) функциональное уравнение xi даёт
\[
 A(z)=\mathcal G_\Gamma(z)\zeta(1/2-z),\qquad
 \mathcal G_\Gamma(z)=
 -2(z^2-1/4)^2\pi^{z/2-1/4}\Gamma(1/4-z/2).                       \tag{3.1}
\]
Это отражение того же A, не новая xi и не reciprocal-множитель. На прямой
\(\Re z=-1\) аргумент zeta имеет действительную часть 3/2, так что её обычный ряд и его производная абсолютно сходятся.

Введём только **вспомогательное** гамма-ядро
\[
 b_\Gamma(t)=-4(\partial_t^2-1/4)^2
                 [e^{-t/2}e^{-\pi e^{-2t}}].                      \tag{3.2}
\]
Оно не является новым допустимым физическим тестом. При \(x=\pi e^{-2t}\)
\[
 b_\Gamma(t)=e^{-t/2}e^{-x}p_\Gamma(x),\quad
 p_\Gamma(x)=-64x^4+448x^3-656x^2+144x.                            \tag{3.3}
\]
Подстановка x в Euler-интеграл даёт
\[
 \mathcal M[e^{-t/2}e^{-\pi e^{-2t}}](z)
  =\tfrac12\pi^{z/2-1/4}\Gamma(1/4-z/2),\quad\Re z<1/2.
\]
Четыре интегрирования по частям в (3.2) законны в этой области; следовательно
\[
 \mathcal M_{b_\Gamma}(z)=\mathcal G_\Gamma(z).                     \tag{3.4}
\]
Из явного полинома: справа b и все фиксированные производные имеют цену
\(O(e^{-5t/2})\), слева — двойной экспоненциальный хвост. Поэтому взвешенные производные интегрируемы равномерно в любом фиксированном подинтервале \(-1\le\Re z\le1/4\). В частности, \(\mathcal G_\Gamma\) там убывает быстрее любой фиксированной обратной степени высоты. Для этого не требуется оценка zeta или отсутствие нулей.

### 3.2. Вспомогательный полюсный фильтр: его область оговорена

Положим \(V_\Gamma=b_\Gamma*b_\Gamma\) и
\[
 \mathscr H_w(y)=\frac{\kappa}{(2r-1)!}
       \int_0^\infty u^{2r-1}e^{\bar w u}V_\Gamma(y-u)\,du.        \tag{3.5}
\]
**Знак в экспоненте положительный.** Это не старый стабильный Q17-резольвент и не доказанно ограниченный L2-оператор. Функция \(\mathscr H_w\) может расти при \(y\to+\infty\). Её не проецируют посредством P и не объявляют физическим профилем.

Однако \(e^{-y}\mathscr H_w(y)\in L^1\): взвешенное ядро на \(u\ge0\) интегрируемо, поскольку \(\delta<1\), а \(e^{-y}V_\Gamma(y)\in L^1\). Поэтому абсолютно законна формула
\[
 \mathcal M_{\mathscr H_w}(z)
  =\frac{\kappa\mathcal G_\Gamma(z)^2}{(z+\bar w)^{2r}},
  \qquad \Re z=-1.                                               \tag{3.6}
\]
Равенство \((-z-\bar w)^{-2r}=(z+\bar w)^{-2r}\) использует чётный порядок 2r. На правой линии, введённой позднее, (3.6) используется как **мероморфное продолжение**, а не как заведомо сходящийся Laplace-интеграл \(\mathscr H_w\).

### 3.3. Явные константы для хвоста

Чтобы цена возврата не скрывала арифметической гипотезы, зафиксируем вычислимую постоянную
\[
 A_0=\sum_{j=1}^{4}|p_j|\left[
 \pi^{1/4}\left(\frac{2(j-1/4)}e\right)^{j-1/4}
 +\pi^{-3/4}\left(\frac{2(j+3/4)}e\right)^{j+3/4}
 \right],                                                       \tag{3.7}
\]
где \((p_1,p_2,p_3,p_4)=(144,-656,448,-64)\). Максимум \(x^ae^{-x/2}\) равен \((2a/e)^a\); раздельно для t≥0 и t<0 это даёт
\[
 |b_\Gamma(t)|\le A_0e^{-|t|}e^{-(\pi/2)e^{-2t}}.                  \tag{3.8}
\]
Следовательно,
\[
 |V_\Gamma(t)|\le A_0^2(1+|t|)e^{-|t|}e^{-\pi e^{-t}}
               \le A_0^2e^{-\pi e^{-t}}.                        \tag{3.9}
\]
Здесь использованы \(e^{-2v}+e^{-2(t-v)}\ge2e^{-t}\) и точная свёртка
\(e^{-|\cdot|}*e^{-|\cdot|}=(1+|t|)e^{-|t|}\).

Определим
\[
 H_*:=\frac{|\kappa|A_0^2}{(2r-1)!}
       \int_0^\infty u^{2r-1}e^{\delta u}e^{-(\pi/2)e^u}\,du<\infty.
                                                                    \tag{3.10}
\]
Для y≤0 неравенство \(e^{-y}e^u\ge(e^{-y}+e^u)/2\) даёт
\[
 \boxed{|\mathscr H_w(y)|\le H_*e^{-(\pi/2)e^{-y}}\quad(y\le0).}     \tag{3.11}
\]
Модули в этом разделе оплачивают **аналитический хвост**, а не заменяют действительной положительной мерой основное знаковое спаривание.

## 4. Полное конечное представление настоящей пары и его край

### 4.1. Сборка квадрата xi

**Лемма 2 [ABSTRACT | CONDITIONAL только на существование/нормировку пары].**
\[
 \boxed{C(y)=\sum_{k\ge1}\frac{d_2(k)}{\sqrt k}\,
                       \mathscr H_w(y-\log k).}                  \tag{4.1}
\]
Равенство понимается поточечно и в \(L^1(e^{-y}dy)\).

**Доказательство.** Сумма абсолютных взвешенных L1-норм правой стороны равна
\[
 \|e^{-\cdot}\mathscr H_w\|_1\sum_{k\ge1}d_2(k)k^{-3/2}
 =\|e^{-\cdot}\mathscr H_w\|_1\zeta(3/2)^2<\infty.
\]
На \(\Re z=-1\) её преобразование по (3.6) равно
\(\kappa\mathcal G_\Gamma(z)^2\zeta(1/2-z)^2/(z+\bar w)^{2r}\), то есть буквальной (1.4). Единственность Fourier-преобразования взвешенных L1-функций доказывает равенство почти всюду. Локально равномерная сходимость из (3.11) и непрерывность дают поточечное равенство. Никакой перестановки несобственной prime-суммы со старым резольвентом здесь нет. \(\square\)

При \(y=2a\) обозначим две временные стороны через \(J_m^-(y),J_m^+(y)\). До любой оценки:
\[
 J_m^-(y)=\sum_{q\ge1}\frac{\mathfrak a_m(q)}{\sqrt q}
                         \mathscr H_w(y-\log q),                 \tag{4.2}
\]
\[
 J_m^+(y)=\sum_{n\le m}\sum_{k\ge1}
       \frac{\Lambda(n)d_2(k)}{\sqrt{nk}}
                 \mathscr H_w(y-\log(k/n)).                     \tag{4.3}
\]
Таким образом \(J(a;m)=J_m^-(2a)+J_m^+(2a)\). В (4.3) возникает **отношение k/n**, не произведение nk. Эту сторону нельзя заменить второй копией (4.2). Она будет оценена только после точного возвращения полной C.

Все k и n-комбинации в (4.2)–(4.3) относятся к одной исходной C. Квадрат A — аналитический квадрат, не \(|A|^2\) на произвольной комплексной линии. Смешанная фаза не удалена.

### 4.2. Первая количественная оценка нового переноса

Определим
\[
 \mathcal J_\infty(y)=\sum_{q\ge1}\frac{\mathfrak a(q)}{\sqrt q}
                                   \mathscr H_w(y-\log q),
\]
\[
 \mathcal E_m^{\rm div}(y)=
 \sum_{q>m}\frac{\mathfrak a_m(q)-\mathfrak a(q)}{\sqrt q}
                                   \mathscr H_w(y-\log q).
\]
Тогда **точно**
\[
 J_m^-(y)=\mathcal J_\infty(y)+\mathcal E_m^{\rm div}(y).           \tag{4.4}
\]
Несмотря на отрицательные коэффициенты разности, знак \(\mathcal E_m^{\rm div}\) не назначается: \(\mathscr H_w\) комплексна.

**Лемма 3 [FINITE_CELL | CONDITIONAL: фиксированная пара].** Для \(0\le y\le\log m\)
\[
 \boxed{|\mathcal E_m^{\rm div}(y)|
 \le\frac{16H_*}{\pi^2}e^{2y}
                 \exp\left(-\frac\pi4me^{-y}\right).}            \tag{4.5}
\]

**Доказательство.** Элементарно \(d_2(q)\le2\sqrt q\), поэтому
\(\mathfrak a(q)/\sqrt q\le\log q\le q\). Для q>m аргумент ядра отрицателен. Положив \(\lambda=(\pi/2)e^{-y}\), из (3.11) получаем
\[
 |\mathcal E_m^{\rm div}(y)|\le H_*\sum_{q>m}q e^{-\lambda q}
 \le H_* e^{-\lambda m/2}\sum_{q\ge1}q e^{-(\lambda/2)q}
 \le4H_*\lambda^{-2}e^{-\lambda m/2}.
\]
Последнее следует из
\(\sum_{q\ge1}q e^{-vq}=[4\sinh^2(v/2)]^{-1}\le v^{-2}\).
Это (4.5). \(\square\)

На настоящем интервале переводов \(y=2a\le L-2\log L\), следовательно
\[
 \boxed{\sup_{h-T\le a\le h}|\mathcal E_m^{\rm div}(2a)|
 \le\frac{16H_*}{\pi^2}m^2e^{-\pi L^2/4}=o(1).}                 \tag{4.6}
\]
Это конкретная оплаченная оценка, отсутствующая у одной формальной свёртки. Она **не** означает малого основного члена \(\mathcal J_\infty\). Вспомогательный q>m-край здесь мал благодаря левому хвосту нового явно построенного ядра; старый необрезанный theta-край не объявляется малым по аналогии.

## 5. Основная знаковая сумма: все полюса и ориентация

### 5.1. Законная начальная линия

**[ABSTRACT | CONDITIONAL].** В \(\Re s>1\)
\[
 \sum_{q\ge1}\frac{\mathfrak a(q)}{q^s}=-\zeta(s)\zeta'(s).
\]
Поэтому на \(\Re z=-1\)
\[
 \mathcal J_\infty(y)=\frac1{2\pi i}\int_{(-1)}
                          \mathcal L_w(z)e^{-zy}\,dz,             \tag{5.1}
\]
\[
 \mathcal L_w(z)=
 -\frac{\kappa\mathcal G_\Gamma(z)^2
            \zeta(1/2-z)\zeta'(1/2-z)}{(z+\bar w)^{2r}}.          \tag{5.2}
\]
Появление бесконечного ряда законно: \(\sum\mathfrak a(q)q^{-3/2}<\infty\), и тот же взвешенный L1-довод, что в лемме 2, даёт абсолютную свёртку. Fourier-инверсия законна, поскольку множитель (5.2) интегрируем на исходной прямой.

### 5.2. Что именно сокращается — и что нет

В полосе \(-1\le\Re z\le1/4\):

* В z=−1/2 функция zeta имеет полюс: \(\zeta\zeta'\) — порядка 3. Но \(\mathcal G_\Gamma^2\) имеет там нуль порядка 4. Поэтому весь (5.2) имеет устранимую особенность и нуль как минимум порядка 1. Никакого бесплатного \(e^{y/2}\)-вычета здесь нет.
* Остальные нули zeta не порождают полюсов произведения \(\zeta\zeta'\). Никакой гипотезы об их отсутствии или простоте не требуется.
* Gamma не имеет полюса внутри этой полосы: первый возможный на правой стороне находится в z=1/2, который **не пересекается**. Его фактическое сокращение нам не нужно.
* Единственный полюс после выбранного нормирующего деления — z=−\bar w.

**Лемма 4 [ABSTRACT | CONDITIONAL: настоящий нуль любой кратности].**
\[
 \boxed{\operatorname{Res}_{z=-\bar w}\mathcal L_w(z)=r.}          \tag{5.3}
\]

**Доказательство.** Можно пользоваться (5.2) непосредственно. При \(u=z+\bar w\) и \(s_0=1/2+\bar w\) нуль \(\zeta(s_0-u)\) имеет порядок r. Числитель \(-\zeta\zeta'\) имеет порядок **2r−1**, а не 2r. После деления на \(u^{2r}\) остаётся простой полюс.

Для коэффициента используем только нормировку (1.4):
\[
 \mathcal L_w(z)=\mathcal M_C(z)
              \left[-\frac{\zeta'(1/2-z)}{\zeta(1/2-z)}\right]
\]
на проколотой окрестности. Поскольку
\(-\zeta'/\zeta(1/2-z)=r/(z+\bar w)+O(1)\), а \(\mathcal M_C(-\bar w)=1\), получаем (5.3). Это локальное вычисление не предполагает искомого знака CCM. \(\square\)

Дополнительная точная проверка там, где записанные дроби определены:
\[
 \mathcal L_w(z)=\tfrac12\mathcal M_C'(z)
   +\left[\frac r{z+\bar w}-\frac{\mathcal G_\Gamma'(z)}{\mathcal G_\Gamma(z)}\right]
        \mathcal M_C(z).                                        \tag{5.4}
\]
Сингулярности правой записи, отсутствующие в (5.2), понимаются после совместного сокращения. (5.4) — контроль, не новый поставщик. Не переносим в этот расчёт Selberg-комбинацию с \(\Lambda*\Lambda\): коэффициенты и порядок здесь другие.

### 5.3. Правая линия и явный остаток

Нам достаточно линии \(\beta=1/4\). Прежде чем двигать контур, докажем используемые bounds.
Из точного floor-интеграла сначала в \(\Re s>1\), затем по продолжению в \(\Re s>0\),
\[
 \zeta(s)=\frac{s}{s-1}-s\int_1^\infty\{x\}x^{-s-1}dx.            \tag{5.5}
\]
Интеграл абсолютно сходится и локально равномерно дифференцируется в этой полуплоскости. На \(s=1/4-it\)
\[
 |\zeta(s)|\le4(1+|t|),\qquad
 |\zeta'(s)|\le16(1+|t|).                                        \tag{5.6}
\]
Действительно, интегралы без и с log x ограничены 4 и 16, \(|s|\le1/4+|t|\), \(|s-1|\ge3/4\). Это слабый элементарный вертикальный контроль, не zero-free/PNT input.

Пусть
\[
 B_*:=\|e^{\cdot/4}b_\Gamma\|_1+
              \|\partial_t^2(e^{t/4}b_\Gamma(t))\|_1<\infty.
\]
Тогда
\[
 |\mathcal G_\Gamma(1/4+it)|\le\frac{4B_*}{(1+|t|)^2}.
\]
B_* можно заменить полностью явным верхом
\[
 \frac1{2\pi^{1/8}}\sum_{j=1}^{6}(|p_j|+|p^{[2]}_j|)\Gamma(j+1/8),
\]
где отсутствующие \(p_j\) равны нулю и
\[
 p^{[2]}(x)=-256x^6+4160x^5-19972x^4+31852x^3-13721x^2+729x.
\]
Этот полином получается двумя дифференцированиями \(e^{-t/4}e^{-x}p_\Gamma(x)\).

Отсюда
\[
 \frac1{2\pi}\int_{\mathbb R}|\mathcal L_w(1/4+it)|dt
 \le K_*:=\frac{1024|\kappa|B_*^2}{\pi(\delta+1/4)^{2r}}<\infty.  \tag{5.7}
\]
Ни один знаменатель не содержит неизвестный минимум |zeta|.

На горизонтальных сторонах прямоугольника \(\mathcal G_\Gamma\) убывает быстрее любой фиксированной обратной степени высоты равномерно по действительной части. Формула (5.5) даёт polynomial control для \(\zeta\zeta'\) там же при большой высоте. Выбирая высоту больше \(|\gamma|+1\), горизонтальные интегралы стремятся к нулю. Это делается при каждом фиксированном y; итоговая правая оценка затем едина для всех y≥0. Не предполагается равномерный уход в неизвестную свободную от нулей полосу.

Для явной проверки предела: положим
\[
 B_N^\sharp=\sup_{-1\le\sigma\le1/4}
 \left(\|e^{\sigma\cdot}b_\Gamma\|_1+
 \|\partial_t^N(e^{\sigma t}b_\Gamma(t))\|_1\right)<\infty.
\]
При \(Y\ge2(|\gamma|+1)\), N≥2, полная сумма модулей двух горизонтальных интегралов не превышает
\[
 C_{w,N}(B_N^\sharp)^2 e^y Y^{2-2N-2r},
\]
с постоянной, получаемой из длины полосы 5/4, (5.5) и интегрирования по частям N раз. Это стремится к нулю при каждом фиксированном y. Хвост правой вертикальной линии после |t|>Y имеет явную цену не более \(K_*e^{-y/4}/(1+Y)\). Мы используем точный предел Y→∞; никакого конечного непосчитанного contour cutoff в (5.8) нет.

**Лемма 5 [ABSTRACT | CONDITIONAL].** Для y≥0
\[
 \boxed{\mathcal J_\infty(y)=-r e^{\bar w y}+\mathcal R_w(y),
        \qquad |\mathcal R_w(y)|\le K_*e^{-y/4}.}                 \tag{5.8}
\]

**Доказательство знака.** Обе вертикальные прямые направлены вверх, а инверсия содержит \(e^{-zy}\). Прямоугольник, идущий вверх по левой прямой и вниз по правой, ориентирован по часовой стрелке. Поэтому
\(I_{-1}-I_{1/4}=-\sum\operatorname{Res}\), откуда минус в (5.8). Обратная проверка: на \(\Re z<-\Re b\) функция \(1/(z+b)\) есть bilateral transform от \(-e^{by}\mathbf1_{y>0}\), не от \(+e^{by}\mathbf1_{y>0}\). Остаток ограничен (5.7). \(\square\)

**Именно здесь надежда на бесплатное зануление всего главного члена не срабатывает.** Большинство особенностей сократилось, но нормировка настоящей пары сохраняет один полный вычет r. Оценивать остаток вместо этого вычета недостаточно.

## 6. Вторая сторона времени, фаза, усреднение и фон

### 6.1. Вторая сторона не удаляется по названию

**[FINITE_CELL | CONDITIONAL].** Сначала возвращаем (4.3) в точную C. Из (1.5), для y≥0,
\[
 |J_m^+(y)|\le C_C\sum_{n\ge2}n e^{-c_Cne^y}
 \le K_+e^{-2y}e^{-c_Ce^y},\qquad K_+=4C_C/c_C^2.                \tag{6.1}
\]
Здесь \(\Lambda(n)/\sqrt n\le n\). Обе фазы времени присутствовали в равенстве до этого неравенства. Использована лишь абсолютная цена реально убывающей обратной стороны, не модули прямого главного члена.

### 6.2. Полный комплексный результат с конечным cutoff

Объединяя (4.4), (4.6), (5.8), (6.1), на настоящем интервале переводов получаем
\[
 \begin{split}
 \left|e^{2i\gamma a}J(a;m)+r e^{2\delta a}\right|
 \le{}&K_*e^{-a/2}
 +\frac{16H_*}{\pi^2}m^2e^{-\pi L^2/4}\\
 &+K_+e^{-4a}e^{-c_Ce^{2a}}.
 \end{split}                                                     \tag{6.2}
\]
Использовано точное \(e^{2i\gamma a}e^{2\bar w a}=e^{2\delta a}\). Никакой независимой фазы для каждого n или частоты нет. Модуль \(\kappa\) появился только в константах аналитических ошибок; основной коэффициент выведен из комплексной нормировки.

После усреднения:
\[
 \boxed{|B_T+rE_T|\le\rho_{\rm div}(m),}                           \tag{6.3}
\]
\[
 \begin{split}
 \rho_{\rm div}(m):={}&
 \frac{2K_*}{T}e^{-(h-T)/2}(1-e^{-T/2})
 +\frac{16H_*}{\pi^2}m^2e^{-\pi L^2/4}\\
 &+K_+e^{-c_Ce^{2(h-T)}}=o(1).
 \end{split}                                                     \tag{6.4}
\]
В последнем члене лишь ослаблено \(e^{-4a}\le1\). Все постоянные фиксируются вместе с настоящим гипотетическим w,r; равномерность при \(\delta\downarrow0\) или \(|\gamma|\to\infty\) не заявляется.

Первая часть ошибки имеет степень \(-1/4+\alpha/2<0\), с фиксированными логарифмами; два других члена меньше любой фиксированной обратной степени. Но **главный член не есть ошибка**: он равен \(-rE_T\). Нельзя объявить показатели (6.4) новым благоприятным показателем CCM.

### 6.3. Полный непрерывный фон остаётся целым

Если нужен центрированный объект, берём прежнее
\[
 D_m^0(z)=\frac{m^{1/2+z}-1}{1/2+z}
         +\frac{m^{1/2-z}-1}{1/2-z},
 \qquad B_T=\widetilde B_T+B_T^0.                                 \tag{6.5}
\]
Обе нижние границы и верх m сохранены. Из принятых источников
\[
 |B_T^0|\le e_m^0:=C_w[e^{-c_we^{2(h-T)}}+\sqrt m e^{-c_wL^2}]
                 =o(1).
\]
Поэтому
\[
 \widetilde B_T=-rE_T-B_T^0+e_m,\qquad |e_m|\le\rho_{\rm div}.
\]
В прямом возврате к B член B0 сокращается точно. В оценке только центрированного объекта можно заплатить e0 один раз. Здесь нет повторной полустепенной платы за фон, ни на частотных секторах, ни на делительных клетках.

Удаление proper powers в определениях xi, A, g, k запрещено и не выполнялось. Все \(\Lambda(p^j)\) входят в (2.2). Известная отдельная Q23 proper-power цена не начисляется поверх той же полной суммы вторично.

## 7. Полный возврат в исходную CCM

**[COFINAL_FAMILY | CONDITIONAL: наследуемый receiver S9/S11].** Все новые операции выполнены в вычислении скалярного спаривания уже заданной настоящей пары. В физическом пространстве тест не меняется. Ни вспомогательное \(\mathscr H_w\), ни коэффициентные ряды не проецируются вместо него.

Пусть z_(m,a) — прежний cutoff/Fourier/трёхконтактный возврат **целой** (1.6). Выбирается один фиксированный \(q>1/\epsilon+2\). Для \(\Omega=2\pi M/L\) сохраняются
\[
 E_q=C_q[\sqrt m\,\Omega^{1/2-q}+\Omega^{3/2-q}+\Omega^{1-q}],
\]
\[
 \begin{split}
 \rho_K=C_{w,q}[&m e^{-c_wL^2}+m\Omega^{1/2-q}
 +\sqrt m\Omega^{3/2-q}+\sqrt m\Omega^{1-q}+E_q^2\\
 &+\sqrt m L^{q+1/2}M^{1/2-q}]=o(1),
 \end{split}                                                     \tag{7.1}
\]
\[
 \rho_S\le C_{w,q}[\sqrt m L^{q-1/2}M^{1/2-q}
                         +m^{C_w}e^{-c_wL^2}]=o(1).              \tag{7.2}
\]
Они включают линейные mixed-errors, их квадратичный остаток, обе экспоненциальные коррекции, endpoint, полосы нулевого продолжения и исчезающие после cutoff хвосты n>m. Для новой коэффициентной формулы отдельно уже оплачен весь вспомогательный q>m. Это разные края; ни один не подменяет другой.

Полная сборка простого оператора:
\[
 \overline{z_{m,a}^*S_m z_{m,a}}
 =A_{\rm self}(m)-2B_T+e_S,\quad
 |A_{\rm self}(m)|\le C_{{\rm self},w},\quad |e_S|\le\rho_S.
\]
Обе self-компоненты остаются, со всеми степенями простых. Из (6.3) получается законный **полный нижний конверт**
\[
 \boxed{
 \overline{z_{m,a}^*K_mz_{m,a}}
 \ge -2rE_T-igl[2\rho_{\rm div}
       +D_w(50L+8)+C_{{\rm self},w}+\rho_S\bigr].}                 \tag{7.3}
\]
Здесь \(D_w\) ограничивает квадрат нормы возвращённой пары. Архимедова цена оплачивается один раз. \(\rho_K\) используется при отдельной проверке источникового adverse value и не прибавляется поверх \(\rho_S\) к (7.3) без причины.

Унаследованная adverse identity даёт \(\overline{z^*K_mz}=-2rE_T+O(\rho_K)\); (7.3) ей не противоречит. Наш новый расчёт (6.3) не использовал эту identity в качестве входа. Он воспроизводит её mixed-компонент с непосредственно оплаченной аналитической ошибкой, **но не предоставляет противостоящую ей оценку**.

Требуемый запас отсутствует именно в главном коэффициенте: (7.3) содержит 2r, а не \(2(r-\vartheta_w)\). Равенство показателя выбранному сигналу не является выигрышем, когда знак/коэффициент остались неблагоприятными.

Для direct-pair вывода нет дополнительной Vaughan/short-divisor платы. Если когда-либо выводить **all-vector** \(T_{>R}\) из нового all-vector S-верха, его прежняя плата
\((56+32\Omega)\sqrt R+12(1+\log R)^2\) потребуется один раз. В Q26 такого all-vector S-верха не получено; pair-specific (7.3) не подменяет его.

| Компонент | Доказанная цена/значение | Что она означает |
|---|---:|---|

## 8. Первая неоплаченная строка и граница выполненного отката

**[COFINAL_FAMILY | CONDITIONAL: диагноз выбранного механизма].** Если неверно отменить выбранный полюс вместе с остальными, получится \(B_T=O(\rho_{\rm div})\) и мнимый favorable gain. Лемма 4 обнаруживает точную ошибку: в числителе лишь 2r−1 нулей, а не 2r.

После правильного расчёта попытка получить (1.9) из одной только малости всех остальных частей требовала бы
\[
 \frac1T\int_{h-T}^{h}\Re\!\left(e^{2i\gamma a}
 [\mathcal R_w(2a)+\mathcal E_m^{\rm div}(2a)+J_m^+(2a)]\right)da
 \ge\vartheta_w E_T-e_w.                                           \tag{8.1}
\]
Однако абсолютная величина левой стороны уже не превышает \(\rho_{\rm div}=o(1)\). Поэтому данный точный перенос с последующим использованием **только этих аналитических оценок** не создаёт нужный коэффициентный зазор. Он предъявляет полную цену, а не неоплаченный знак под новым названием.

Это не доказывает существование w или невозможность независимого аргумента, который исключит его существование. В частности, из условного adverse-вычисления нельзя заключить, что благоприятная RH-теорема вообще ложна. Область отрицательного вывода — предложенное автоматическое зануление/получение запаса от этого переноса.

**Выполненный более ранний откат:** локальные моменты → настоящий квадрат xi → конечная \(\Lambda*d_2\)-свёртка с ядром (3.5). Дополнительная арифметическая жёсткость использована, а не только названа. Она оплачивает честный finite-to-infinite coefficient return и позволяет вычислить surviving source coefficient. Но благоприятного неравенства сверх этого не возникло. Продолжать сдвигать ту же прямую или повышать точность этой алгебры не нужно.

Открытый источникозависимый вход остаётся **независимой** оценкой (1.9) на исходной паре либо достаточным исходным all-vector lower floor. Нового входа под именем \(\mathcal J_\infty\) не регистрируем. Сигнал уже вычислен; недостаёт другого обоснования, несовместимого с гипотетическим w, а не ещё одного вычисления того же сигнала.

У второго представления нет бесплатного consumer-map: без выбранного деления исчезает именно та нормировка, которая обеспечивает принятый свидетель. Поэтому возвращение «ещё раньше» нельзя объявить выполненным доказательством RH.

## 9. Сильнейшие возражения к результату

**«Ты повторил прежнее adverse identity».** Неблагоприятный итог действительно известен из S9 и не заявляется новым выигрышем. Проверена другая, выбранная в этом задании арифметическая связь: конечная \(\Lambda*d_2\) вместе с реальным gamma-factor того же xi, с новым явным коэффициентным краем. Её outcome не улучшает consumer; в заголовке стоит NO_PROGRESS.

**«Это тот же Selberg double-pole».** Нет: не используется ни \(\Lambda\log+\Lambda*\Lambda\), ни её O(x)-рекурсия. В (2.1) присутствует \(d_2=1*1\), потому что настоящая C содержит \(\zeta^2\). Кратность контролируется заново в \(-\zeta\zeta'\). Главное отличие не название: finite q>m-return доказан до переноса контура, и все оставшиеся части посчитаны.

**«Бесконечная сумма введена через неизвестные нули».** Начальная линия имеет \(\Re s=3/2\), абсолютную сходимость и взвешенную L1-модель. Продолжение осуществляется уже для явной мероморфной функции (5.2). Неизвестные нули являются нулями её числителя, а не скрытыми полюсами. Выбранный полюс сохранён полностью.

**«На правой линии не сходится исходный Laplace-интеграл H».** Он и не использовался там. (3.6) — transform на левой линии; переход вправо оплачен вычетом. Если считать H-integral сходящимся справа без возврата, будет как раз потерян основной член.

**«Ты отбросил второй временной знак или proper powers».** Их буквальная формула (4.3) сохранена, затем весь C имеет цену (6.1). Все \(\Lambda(p^j)\) входят в finite coefficients и source numerator; примеры после леммы 1 и exact tests обнаруживают их удаление.

**«Полустепенная ошибка спрятана в фоне или P».** Фон остаётся полным (6.5), а исходный P применяется только к настоящей целой паре. Все ошибки receiver выписаны в §7; дополнительно возникающий q>m-край оплачен (4.6). На правой линии нет множителя, растущего с m, кроме явно показанного \(e^{-y/4}\).

**«Существование w уже принято как доказанный факт».** Нет. Все конструкции g,k,C и выводы их точного leading coefficient условны. Без заданного настоящего нуля они не являются численными объектами для подстановки произвольных \(\delta,\gamma\). Никакой такой подстановки не сделано.

- `FAILURE_TYPE`: NO_DERIVATION благоприятного знака; не COUNTEREXAMPLE для CCM.

Проверки конечной алгебры воспроизвести приложенными скриптами. Успех означает приёмку только полного расчёта этой неудачной попытки; не `RH`, не новый exponent и не новое supplier assumption. При дефекте указать первую неверную формулу и её минимальную правку. Репозиторий и route-state в рамках этого ответа не изменяются.

## 11. META closeout

**Что стало меньше?** Не главный арифметический долг. У этой конкретной формы полностью оплачены finite product edge, противоположное время, fixed-strip remainder и inverse orientation; прежнее обещание «все нули числителя всё занулят» заменено точным r.

**Что исключено?** Только автоматическое favorable completion, которое удаляет выбранный вычет или принимает малость аналитического остатка за малость всего B_T. Формального KILL для семейства CCM нет.

**Что не повторять?** Считать (2.1), (4.1) или контурный перенос самостоятельным улучшением; удалять q>m, менять комплексную нормировку, платить фон отдельными модулями; считать pole-free результатом один лишь квадрат xi до его выбранного деления.

def check(name: str, condition: bool) -> None:
    if not bool(condition):
        raise AssertionError(name)

def reject(name: str, false_condition: bool) -> None:
    if bool(false_condition):
        raise AssertionError('Planted error was not detected: ' + name)
    planted.append(name)

def factors(n: int) -> dict[int, int]:
    ans: dict[int, int] = {}
    p = 2
    while p*p <= n:
        while n % p == 0:
            ans[p] = ans.get(p, 0) + 1
            n //= p
        p += 1
    if n > 1:
        ans[n] = ans.get(n, 0) + 1
    return ans

def divisors(n: int) -> list[int]:
    return [d for d in range(1, n+1) if n % d == 0]

def d2(n: int) -> int:
    ans = 1
    for e in factors(n).values():
        ans *= e+1
    return ans

def lam(n: int, primes_only: bool = False) -> dict[int, sp.Expr]:
    f = factors(n)
    if len(f) == 1:
        p, e = next(iter(f.items()))
        if not primes_only or e == 1:
            return {p: sp.Integer(1)}
    return {}

    for p, v in vec.items():
        out[p] = out.get(p, sp.Integer(0)) + scale*v

def clean(vec: dict) -> dict:
    return {p: sp.simplify(v) for p, v in vec.items() if sp.simplify(v) != 0}

        if m is None or d <= m:

    return clean(out)

check('gamma_kernel_mellin_multiplier',sp.factor(ratio+2*(z*z-sp.Rational(1,4))**2)==0)

reject('delete_linear_mixed_return',sp.simplify(quad(y+e)-quad(y)-quad(e))==0)
