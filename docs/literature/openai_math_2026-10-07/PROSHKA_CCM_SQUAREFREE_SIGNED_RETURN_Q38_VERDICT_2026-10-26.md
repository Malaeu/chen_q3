# Q38. Связанные чётный и нечётный арифметические каналы: малое произведение и полный знаковый возврат

## 0. Результат и точная область утверждений

**Искомой независимой нижней оценки полной \(C_{\rm sf}\) не получено.** Проверен один механизм: соединить настоящие квадратсвободные коэффициенты с их настоящим мёбиусовым знаком, продифференцировать **всё произведение**, а затем вернуть исходную составную форму. Это не вероятностное условливание, не замена фаз Haar-средним и не оценка производной логарифмической хордой.

Есть законное дополнительное арифметическое сокращение. После сохранения всех смешанных каналов \(g_Z(\ell)g_Z(k)\) производная связанного произведения имеет полную физическую норму
\[
\mathfrak d_{m,Z}=L(1+L/2)G_Z^2
=O_\epsilon(m^{\epsilon/2}L^{14}).
\tag{0.1}
\]
Однако это произведение зануляет **каждый** коэффициент с нечётной степенью простого \(p>Z\), в частности все rough-квадратсвободные составные. При буквальном возвращении они возникают с коэффициентом один. Поэтому (0.1) не превращается в нижнюю оценку \(C_{\rm sf}\).

Доведённая до конца оплата возвращённого остатка модулями имеет положительную цену \(s_{\rm trial}\), для которой доказано
\[
\frac{\sqrt m}{192\log m}\le s_{\rm trial}\le C_\epsilon\sqrt m
\tag{0.2}
\]
на каждой достаточно поздней ячейке. **Нижняя граница относится к выписанной цене сертификата, не к норме или собственному значению \(C_{\rm sf}\), \(A\), \(K_m\).** Для неё не используется PNT: достаточно приведённой ниже элементарной биномиальной оценки количества простых.

## 2. Исходный объект и буквальные коэффициенты

**[COFINAL_FAMILY | PAPER, inherited]** Фиксируем сначала \(0<\epsilon<1/32\), затем рассматриваем все достаточно большие целые \(m\):
\[
L=\log m,\qquad M=R=\lfloor m^\epsilon\rfloor,
\qquad Z=\lfloor m^{\epsilon/4}\rfloor,
\qquad\Omega=2\pi M/L.
\tag{2.1}
\]
Начало области может зависеть от фиксированного \(\epsilon\). Ни \(\epsilon\), ни исходный \(P\) не выбираются по вектору или по простому.

Пусть \(F_M\) — исходный нормированный Fourier-синтез на \([0,L]\), а \(P\) — прежний проектор на три контакта. Пишем \(\mathcal I=F_M|_{\operatorname{ran}P}\). Тогда
\[
\|\mathcal Ic\|_{L^2(0,L)}=\|c\|_2,
\qquad f(0)=f(L)=0,\qquad\int_0^Le^{\pm t/2}f(t)\,dt=0.
\tag{2.2}
\]
На физическом пространстве
\[
(V_sf)(t)=\mathbf1_{s\le t\le L}f(t-s),\quad
V_sV_t=V_{s+t},\quad V_s=0\quad(s\ge L).
\tag{2.3}
\]
Adjoint добавляется только после полного причинного расчёта. Он не заменяет второй арифметический канал.

Положим
\[
h(n)=\frac1{\sqrt n}\mathcal I^*(V_{\log n}+V_{\log n}^*)\mathcal I,
\qquad
A=\sum_{n\le m}\Lambda(n)h(n),\qquad C^0=A+H_d.
\tag{2.4}
\]
Здесь \(0\preceq H_d\preceq4P\), а \(\int_1^m h(x)dx=-H_d\). Источниковый \(n=m\) overlap равен нулю точно.

**[FINITE_CELL | PAPER, inherited]** Настоящая модель:
\[
C_Z=\sum_{q\le Z}\frac{\mu(q)^2}{\varphi(q)},\quad
\lambda_Z(n)=\sum_{q\le Z}\frac{\mu(q)c_q(n)}{\varphi(q)},\quad
 a_Z(n)=\frac{\lambda_Z(n)^2}{C_Z^2},\quad b_Z(n)=a_Z(n)\log n.
\tag{2.5}
\]
Сохраняем буквальное раскрытие S5:
\[
\begin{split}
u_Z(d)&=\frac{\mu(d)d}{\varphi(d)C_Z}
 \sum_{\substack{k\le Z/d\\(k,d)=1}}\frac{\mu(k)^2}{\varphi(k)},\\
g_Z(\ell)&=\sum_{[d,e]=\ell}u_Z(d)u_Z(e),\qquad
 a_Z(n)=\sum_{\ell\mid n}g_Z(\ell).
\end{split}
\tag{2.6}
\]
Все \(d\ne e\) сохранены. Поддержка \(g_Z\) состоит из квадратсвободных \(\ell\le Z^2\), простые делители которых не превосходят \(Z\).

В частности,
\[
a_Z(1)=1,\qquad
 a_Z(n)=1\quad\text{при }p\mid n\Longrightarrow p>Z.
\tag{2.7}
\]
Последнее не утверждает мультипликативность \(a_Z\). Например, при \(Z=3\):
\[
a_3(2)=1/25,\quad a_3(3)=4/25,\quad a_3(6)=4/25
\ne a_3(2)a_3(3).
\tag{2.8}
\]
Поэтому одно произведение свободно назначенных локальных весов не является нашим источником.

Настоящий оставшийся сектор:
\[
 C_{\rm sf}=\sum_{\substack{Z<n\le m\\n\ {\rm squarefree\ composite}}}b_Z(n)h(n).
\tag{2.9}
\]
Из S4–S5 принято
\[
 A+C_{\rm sf}=U_{\rm sf},\qquad \|U_{\rm sf}\|\le u_{m,Z}
 =O_\epsilon(m^{5\epsilon/4}L^7).
\tag{2.10}
\]
Чтобы полный бюджет не скрывался за \(O\)-обозначением, можно буквально взять
\[
\begin{split}
G_Z&=\sum_\ell\frac{|g_Z(\ell)|\tau(\ell)}{\sqrt\ell},\qquad
\delta_Z=\frac1{\zeta(2)}\sum_\ell g_Z(\ell)\prod_{p\mid\ell}\frac1{p+1},\\
I_m&=2L+\frac{1+2\Omega}{2}L^2,\qquad K_{\rm pp}=\frac2{1-1/\sqrt2},\\
u_{m,Z}&=8\delta_Z+3G_Z I_m+\frac{4Z^{5/2}\log Z}{C_Z^2}
 +12\sqrt Z+K_{\rm pp}L(1+L).
\end{split}
\tag{2.11}
\]
Это старый S5(7.5), с допустимой первой, более простой платой за малые целые. Имеем \(0\le\delta_Z\le1/C_Z\) и
\[
G_Z\le4\,3^{16}Z(1+\log Z)^6.
\tag{2.12}
\]
Все оценки этого абзаца унаследованы, не являются новым арифметическим знаком Q38.

## 3. Один выбранный совместный механизм: полное парное произведение

### 3.1. Конечная алгебра и производная

**[FINITE_CELL | PAPER]** Для вещественного \(\sigma\) введём
\[
X_n(\sigma)=n^{-\sigma}V_{\log n},\quad X_1=I,
\quad X_nX_k=X_{nk},\quad X_n=0\ (n\ge m).
\tag{3.1}
\]
Все формулы ниже конечны. При дифференцировании по \(\sigma\) **фиксированы** \(m,L,Z,P,g_Z\). Это не производная по производственному расписанию.

Полные два канала задаются настоящими коэффициентами:
\[
E_+(\sigma)=\sum_{n\le m}\mu(n)^2a_Z(n)X_n(\sigma),
\qquad
E_-(\sigma)=\sum_{n\le m}\mu(n)a_Z(n)X_n(\sigma).
\tag{3.2}
\]
Их можно назвать каналами суммы и разности чётного/нечётного числа простых множителей. Это **не** прежние чётная и нечётная Fourier-полусетки и не независимые случайные фазы.

Пишем
\[
D_\pm=-\partial_\sigma E_\pm,
\qquad K_Z=E_+E_-,\qquad Q_Z=-\partial_\sigma K_Z.
\tag{3.3}
\]
Цель попытки: проверить, даёт ли совместное арифметическое сокращение в \(Q_Z\) малый односторонний остаток после полного восстановления \(C_{\rm sf}\). Возможное положительное свойство \(Q_Z\) заранее не назначается.

### 3.2. Все реальные \(g_Z\)-каналы и их пересечения

Для квадратсвободного \(\ell\) положим
\[
E_{\ell,+}=X_\ell\prod_{\substack{p\le m\\p\nmid\ell}}(I+X_p),\qquad
E_{\ell,-}=\mu(\ell)X_\ell\prod_{\substack{p\le m\\p\nmid\ell}}(I-X_p).
\tag{3.4}
\]
Полные произведения конечны. Любое произведение с общим индексом \(n\ge m\) физически равно нулю; его арифметический коэффициент не объявляется нулём. По единственности разложения на простые
\[
E_\pm=\sum_\ell g_Z(\ell)E_{\ell,\pm}.
\tag{3.5}
\]

Для \(d=(\ell,k)\) буквальное перемножение даёт
\[
\boxed{
E_{\ell,+}E_{k,-}
=\mu(k)X_{\ell k}
\prod_{p\nmid\ell k}(I-X_{p^2})
\prod_{p\mid k/d}(I+X_p)
\prod_{p\mid\ell/d}(I-X_p).
}
\tag{3.6}
\]
В первом произведении также \(p\le m\). Простые, делящие оба индекса, не порождают дополнительного локального фактора: их квадрат уже находится в \(X_{\ell k}\). При простом, делящем только один индекс, остаётся соответствующий линейный фактор. Знак \(\mu(k)\) обязателен.

Это даёт полную формулу **до модулей**:
\[
\boxed{
K_Z(\sigma)=
\sum_{\ell,k}g_Z(\ell)g_Z(k)\mu(k)
\sum_{r\mid\ell/d}\sum_{s\mid k/d}\mu(r)
\sum_{\substack{v^2\ell krs\le m\\(v,\ell k)=1}}
\mu(v)X_{\ell krs v^2}(\sigma).
}
\tag{3.7}
\]
Именно здесь используется дополнительная совместная арифметика: на простом, отсутствующем в обоих реальных каналах, линейные части сокращаются **между каналами**, оставляя квадрат. Это свойство не следует из их отдельных норм и не выполняется для произвольных весов той же массы.

Однако (3.7) само по себе — тождество. Его первое количественное следствие и полный возврат ниже; оно не объявляется знаком CCM.

## 4. Первая новая количественная оценка и её ограничение

### 4.1. Полный бюджет дифференцированного произведения

**[FINITE_CELL | PAPER]** Запишем формальный коэффициент \(k_Z(n)\) равенством
\[
K_Z(\sigma)=\sum_{n\le m}k_Z(n)X_n(\sigma).
\tag{4.1}
\]
Даже для \(n=m\) это определяет арифметический коэффициент; физическое представление его обнуляет. Определение коэффициента — конечная Dirichlet-свёртка из (3.2), поэтому оно не неоднозначно из-за нулевого оператора на границе.

При \(\sigma=1/2\) из (3.7), **после полного межканального сокращения**, имеем
\[
\begin{split}
\sum_{n\le m}\frac{|k_Z(n)|}{\sqrt n}
&\le\sum_{\ell,k}\frac{|g_\ell g_k|}{\sqrt{\ell k}}
 \sum_{r\mid\ell/d}r^{-1/2}\sum_{s\mid k/d}s^{-1/2}
 \sum_{v\le\sqrt{m/(\ell krs)}}\frac1v\\
&\le(1+L/2)
\left(\sum_\ell\frac{|g_\ell|\tau(\ell)}{\sqrt\ell}\right)^2.
\end{split}
\tag{4.2}
\]
Невозможные гиперболические области дают пустую сумму. Снятие условия взаимной простоты происходит только в неотрицательной вспомогательной плате, не в источниковом равенстве.

Производная вносит \(\log n\le L\), а каждый \(V_{\log n}\) — сжатие. Поэтому
\[
\boxed{
\|K_Z(1/2)\|\le(1+L/2)G_Z^2,\qquad
\|Q_Z(1/2)\|\le\mathfrak d_{m,Z}:=L(1+L/2)G_Z^2.
}
\tag{4.3}
\]
Используя (2.12), получаем явный верх
\[
\mathfrak d_{m,Z}
\le16\,3^{32}Z^2(1+\log Z)^{12}L(1+L/2)
=O_\epsilon(m^{\epsilon/2}L^{14}).
\tag{4.4}
\]
Это физическая операторная оценка до сжатия; она действует на все векторы и не платит за число Fourier-мод. Сжатие исходным \(\mathcal I\) в дальнейшем лишь сохраняет эту цену.

### 4.2. Что именно сократилось

**[FINITE_CELL | PAPER]** Если \(p>Z\), то \(p\nmid\ell k\) для каждого ненулевого \(g_\ell g_k\). Поэтому во всём (3.7) этот простой входит только как \(p^0\) или \(p^2\). Следовательно,
\[
\boxed{
 v_p(n)\text{ нечётно для некоторого }p>Z
 \quad\Longrightarrow\quad k_Z(n)=0.
}
\tag{4.5}
\]
Производная по \(\sigma\) не меняет поддержку. В частности, \(Q_Z\) зануляет не только большие простые, но и **каждый rough-квадратсвободный \(n>1\)**.

Это немедленный источникозависимый discriminator. Нельзя из дешёвого (4.3) заключить lower для квадратсвободных составных, не вернув именно ту часть, которую связанное произведение уничтожило. Формула (4.5) устанавливается до какого-либо большого вычисления или спектральной панели.

## 5. Полный signed-возврат: ни один составной коэффициент не исчезает бесплатно

### 5.1. Производная, первичный канал и все перекрёстные члены

Все операторы в этом разделе взяты при \(\sigma=1/2\); исходное физическое пространство не меняется. Обозначим через \(D_e\) сумму \(a_Z(n)\log n\,X_n\) по квадратсвободным \(n\) с чётным \(\omega(n)\ge2\); через \(D_o\) — по нечётным \(\omega(n)\ge3\). \(\omega\) здесь — число различных простых множителей, не исходная Fourier-частота.

Пусть \(\Pi_a=\sum_{p\le m}a_Z(p)\log p\,X_p\). Тогда
\[
D_+=\Pi_a+D_e+D_o,\qquad
D_-=-\Pi_a+D_e-D_o.
\tag{5.1}
\]
Сохраняем полный смешанный остаток
\[
\boxed{
N_Z=D_+(E_--I)+(E_+-I)D_-.
}
\tag{5.2}
\]
Никакого adjoint в (5.2) нет. Правило произведения даёт
\[
Q_Z=D_+E_-+E_+D_-=D_++D_-+N_Z=2D_e+N_Z.
\tag{5.3}
\]
Оба смешанных члена обязательны; их коэффициенты — реальные арифметические свёртки, а не \(\Lambda(uv)\) и не независимо назначенные фазы.

Пусть \(D_{{\rm comp},\le Z}\) — полная малая квадратсвободная составная часть. Буквальная причинная целевая форма
\[
C^\to_{\rm sf}=D_+-D_{+,\le Z}-\Pi_{>Z}^\to
=D_e+D_o-D_{{\rm comp},\le Z}
\tag{5.4}
\]
содержит настоящий prime-deletion член с коэффициентом один. Равенство использует \(a_Z(p)=1\) при \(p>Z\), а малые простые отменяются с их фактическими \(a_Z(p)\).

Отсюда точный возврат:
\[
\boxed{
C^\to_{\rm sf}=\frac12Q_Z+\mathscr R_Z,\qquad
\mathscr R_Z=D_o-D_{{\rm comp},\le Z}-\frac12N_Z.
}
\tag{5.5}
\]
Для исходных комплексных векторов вводим
\[
\mathcal Q_Z=\tfrac12\mathcal I^*(Q_Z+Q_Z^*)\mathcal I,
\qquad
\mathcal R_Z=\mathcal I^*(\mathscr R_Z+\mathscr R_Z^*)\mathcal I.
\tag{5.6}
\]
Тогда
\[
\boxed{
C_{\rm sf}=\mathcal Q_Z+\mathcal R_Z,
\qquad\|\mathcal Q_Z\|\le\mathfrak d_{m,Z}.
}
\tag{5.7}
\]
Это равенство **целых** квадратичных форм. В нём обе временные стороны, все комплексные self/cross и все частотные коэффициенты сохраняются. Нет промежуточного \(P\) и нет допущения, что \(E_\pm f\) удовлетворяют контактам.

### 5.2. Буквальные коэффициенты возвращённого остатка

Положим
\[
\gamma_Z(n)=\mathbf1_{Z<n\le m,\ n\ {\rm squarefree\ composite}}a_Z(n),
\quad
r_Z(n)=\left(\gamma_Z(n)-\tfrac12k_Z(n)\right)\log n.
\tag{5.8}
\]
Тогда \(\mathscr R_Z=\sum_{n\le m}r_Z(n)n^{-1/2}V_{\log n}\).

На rough-квадратсвободных \(n>1\) получаем точно:
\[
\boxed{
r_Z(n)=
\begin{cases}
0,&n\text{ простое},\\
\log n,&n\text{ составное}.
\end{cases}}
\tag{5.9}
\]
Для чётного числа простых в таком составном коэффициент \(N_Z\) равен \(-2\log n\). Для нечётного числа \(\ge3\) он равен нулю, а весь вклад возвращается через \(D_o\). Поэтому нельзя оставить только «благоприятную» чётную ветвь и потерять нечётную.

Дополнительный контроль: при \(p>Z\) имеем
\[
k_Z(p^2)=-1,\quad Q_Z[p^2]=-2\log p,\quad
r_Z(p^2)=\log p.
\tag{5.10}
\]
Значит, \(\tfrac12Q_Z+\mathscr R_Z\) возвращает ноль на \(p^2\), как требует квадратсвободная цель. Настоящий \(\Lambda(p^2)=\log p\) исходной \(A\) находится в прежнем \(U_{\rm sf}\), не удалён из CCM.

### 5.3. Первая неоплаченная строка

Для успеха потребовалось бы независимо доказать
\[
\mathcal R_Z\succeq-s_{m,\epsilon}P
\tag{5.11 OPEN}
\]
с исчезающим степенным показателем после добавления \(\mathfrak d_{m,Z}\) и остальных расходов. Но
\[
\mathcal R_Z\succeq-sP\Rightarrow C_{\rm sf}\succeq-(s+\mathfrak d)P,
\qquad
C_{\rm sf}\succeq-tP\Rightarrow\mathcal R_Z\succeq-(t+\mathfrak d)P.
\tag{5.12}
\]
Поэтому произвольная малость (5.11) — **тот же долг с оплаченной малой поправкой**, а не новый независимый вход. В этом ответе (5.11) не назначается предпосылкой. Численный знак \(\mathcal R_Z\) не вычислялся.

## 6. Завершённая цена выбранного сертификата

### 6.1. Законная оценка и её точная область

**[FINITE_CELL | PAPER]** Полная оплата возвращённого остатка по его коэффициентам даёт
\[
\mathcal R_Z\succeq-\mathfrak r_{m,Z}P,
\qquad
\boxed{\mathfrak r_{m,Z}=2\sum_{2\le n<m}\frac{|r_Z(n)|}{\sqrt n}.}
\tag{6.1}
\]
Это первая строка, на которой теряется нужная связь арифметического знака с \(f\). До неё (5.5)–(5.9) — точные связанные формулы. Обе временные стороны учтены множителем 2. При \(n=m\) не начисляется плата за нулевой физический сдвиг; коэффициент в (5.8) остаётся в алгебре.

Выбранный полный allowance для \(A\):
\[
\boxed{s_{\rm trial}=u_{m,Z}+\mathfrak d_{m,Z}+\mathfrak r_{m,Z}.}
\tag{6.2}
\]
Не оптимизируем произвольные модульные веса или разбиения. Задача §6 — довести именно этот завершённый способ до полного показателя.

### 6.2. Явный верх scalar-mass возвращения

Сохраняя истинную массу модели,
\[
\mathfrak r_{m,Z}\le2\mathfrak M_{m,Z}+\mathfrak d_{m,Z},
\quad
\mathfrak M_{m,Z}=\sum_{\substack{Z<n<m\\n\ {\rm squarefree\ composite}}}
\frac{a_Z(n)\log n}{\sqrt n}.
\tag{6.3}
\]
Для её полного верха используем принятый в S5 счёт **всех** квадратсвободных кратных, не prime-deleted счёт:
\[
A_Z^{\rm sf}(x)=\sum_{n\le x}\mu(n)^2a_Z(n)=\delta_Zx+E_Z(x),
\qquad |E_Z(x)|\le3G_Z\sqrt x.
\tag{6.4}
\]
При скалярном \(w(x)=\log x/\sqrt x\), с сохранением верхнего endpoint,
\[
\begin{split}
\mathfrak M_{m,Z}
&\le\sum_{n\le m}\mu(n)^2a_Z(n)w(n)\\
&\le\delta_Z\,[2\sqrt mL-4\sqrt m+4]
 +3G_Z\left(2L+\frac{L^2}{4}\right).
\end{split}
\tag{6.5}
\]
Действительно, верхняя ошибка \(E_Z(m)w(m)\) стоит \(3G_ZL\), а
\[
\int_1^m |E_Z(x)w'(x)|dx
\le3G_Z\int_1^m\frac{1+\frac12\log x}{x}dx
=3G_Z(L+L^2/4).
\]
Нижний атом включён: \(w(1)=0\). В этой **скалярной** массе \(w(m)\ne0\), поэтому верхний член не удалялся по операторному свойству \(h(m)=0\).

Можно получить достаточный грубый верх для \(\delta_Z\) без PNT или нового решетного входа. Из Q34-счёта с \(\ell=1\), \(\zeta(2)<2\) и Abel следует
\[
C_Z\ge\sum_{n\le Z}\frac{\mu(n)^2}{n}
\ge\tfrac12\log Z-6.
\tag{6.6}
\]
Итак, при \(\log Z\ge24\), \(C_Z\ge\tfrac14\log Z\). Если \(\kappa=\epsilon/4\) фиксировано, то eventually \(\log\lfloor m^\kappa\rfloor\ge\kappa L/2\), откуда
\[
\delta_Z\le\frac8{\kappa L},\qquad
\mathfrak M_{m,Z}\le\frac{16}{\kappa}\sqrt m
+3G_Z(2L+L^2/4).
\tag{6.7}
\]
Следовательно,
\[
\boxed{
s_{\rm trial}\le
u_{m,Z}+2\mathfrak d_{m,Z}
+\frac{32}{\kappa}\sqrt m
+6G_Z(2L+L^2/4)
=O_\epsilon(\sqrt m).
}
\tag{6.8}
\]
Все остальные слагаемые, кроме явного \(\sqrt m\), имеют показатель меньше \(1/2\). Это полноценный верх, но его удобная явная константа хуже старого fallback.

### 6.3. Нижняя цена именно этой оплаты: настоящее множество rough-семипростых

**[COFINAL_FAMILY | PAPER]** Покажем, что половинный показатель в (6.1) не является только артефактом грубого верхнего счёта. Утверждение относится к **цене (6.1)**, не к самому знаковому оператору.

Сначала элементарная количественная лемма о настоящих простых. Для каждого натурального \(n\)
\[
\binom{2n}{n}\mid\operatorname{lcm}(1,\ldots,2n),\qquad
\binom{2n}{n}\ge\frac{4^n}{2n+1}.
\tag{6.9}
\]
Первое следует из формулы Лежандра: каждая разность
\(\lfloor2n/p^j\rfloor-2\lfloor n/p^j\rfloor\) равна 0 или 1, так что показатель \(p\) не превышает \(\lfloor\log_p(2n)\rfloor\). Второе следует из суммы всех биномиальных коэффициентов и максимальности центрального.

Поскольку \(\log\operatorname{lcm}(1,\ldots,\lfloor x\rfloor)=\psi(x)\), для \(x\ge64\)
\[
\psi(x)\ge(x-2)\log2-\log(x+1)\ge x/4.
\tag{6.10}
\]
Например, \(\log2\ge2/3\) получается интегрированием выпуклого \(1/t\) на \([1,2]\), а \(\log(x+1)\le x/8\) для \(x\ge64\) проверяется в 64 и по производной. Эти границы достаточны для последнего перехода.

Весь proper-power вклад ограничен без удаления каких-либо настоящих простых степеней:
\[
\psi(x)-\vartheta(x)
\le\frac{\sqrt x(\log x)^2}{\log2}\le x/8
\quad(x\ge2^{64}).
\tag{6.11}
\]
Последняя граница проверяется при \(2^{64}\), а \((\log x)^2/\sqrt x\) после этого убывает. Поэтому
\[
\pi(x)\ge\frac{x}{8\log x},\qquad
\#\{p:x^{2/3}<p\le x\}\ge\frac{x}{16\log x}
\quad(x\ge2^{64}).
\tag{6.12}
\]
Для второго перехода достаточно \(x^{1/3}\ge16\log x\), что также выполняется начиная с этого порога. Это намеренно грубая элементарная оценка; PNT не используется.

Берём \(x=\sqrt m\). На каждом достаточно позднем \(m\) имеется не менее
\[
N_m=\frac{\sqrt m}{8L}
\]
настоящих простых в \((m^{1/3},\sqrt m]\). Они все больше \(Z\). Из различных пар образуются не менее \(m/(256L^2)\) различных квадратсвободных чисел
\[
m^{2/3}<pq<m.
\tag{6.13}
\]
Строгое верхнее неравенство следует из различия простых; подстановка \(p=q=\sqrt m\) запрещена. На каждом таком числе \(a_Z(pq)=1\), \(r_Z(pq)=\log(pq)\), и
\[
\frac{\log(pq)}{\sqrt{pq}}\ge\frac{2L}{3\sqrt m}.
\]
Отсюда
\[
\mathfrak M_{m,Z}\ge\frac{\sqrt m}{384L},\qquad
\boxed{\mathfrak r_{m,Z}\ge\frac{\sqrt m}{192L}.}
\tag{6.14}
\]
В первой границе используется только подсемейство rough-семипростых. Вторая имеет дополнительный множитель 2 из обеих временных сторон (6.1).

Вместе с (6.8):
\[
\boxed{
\lim_{m\to\infty}\frac{\log s_{\rm trial}}{\log m}=\frac12
}
\tag{6.15}
\]
для каждого фиксированного \(\epsilon\). Никакая кофинальная подпоследовательность не меняет показатель **этой цены**. Это не утверждает нижней границы \(\lambda_{\max}(A)\) или \(-\lambda_{\min}(C_{\rm sf})\); положительные и отрицательные физические overlap могут сокращаться.

## 7. Полный возврат на исходный \(P\)

### 7.1. Все исходные векторы и матричные веса

**[COFINAL_FAMILY | PAPER]** Из (2.10), (5.7), (6.1) для всех комплексных \(c=Pc\) одновременно:
\[
A\preceq s_{\rm trial}P.
\tag{7.1}
\]
Соответствующие неравенства следов выполняются для всех \(W=PWP\succeq0\), умножаясь на \(\operatorname{Tr}W\), не на размерность. Причинные алгебраические формулы выполнены до компрессии; норма исходного \(c\) не меняется.

Полный consumer-return:
\[
\boxed{
T_{>R}\preceq[s_{\rm trial}+b_{\rm div}]P,
\qquad
PK_mP\succeq-[s_{\rm trial}+50L+8]P,
}
\tag{7.2}
\]
\[
b_{\rm div}=(56+32\Omega)\sqrt R+12(1+\log R)^2.
\tag{7.3}
\]
В \(s_{\rm trial}\) уже один раз содержится \(u_{m,Z}\). Неквадратсвободный и proper-power возвраты нельзя прибавить поверх него ещё раз. В прямом \(K_m\)-переходе отдельного \(b_{\rm div}\) нет.

Все малые новые/унаследованные расходы имеют цену не более \(C_\epsilon m^{2\epsilon}\) eventually:
\[
u_{m,Z}+\mathfrak d_{m,Z}+b_{\rm div}+50L+8
\le C_\epsilon m^{2\epsilon}.
\tag{7.4}
\]
Это полезная условная карта для независимого lower \(\mathcal R_Z\), но такой lower не получен. Большая \(\mathfrak r\) не удаляется из (7.2).

Сохраняем S10, не заменяя его более дорогим явным верхом (6.8):
\[
\begin{split}
s_{\rm keep}&=W_{<}(m)+W(\lfloor\sqrt m\rfloor)
\le6\sqrt m+6m^{1/4},\\
A&\preceq s_{\rm keep}P,\\
T_{>R}&\preceq(s_{\rm keep}+b_{\rm div})P,\\
PK_mP&\succeq-[s_{\rm keep}+50L+8]P.
\end{split}
\tag{7.5}
\]
Можно формально сохранить минимум двух законных цен, но это не доказывает новый показатель и здесь не объявляется улучшением. Условные прежние \(3/8\) сохраняют свою ZF78-предпосылку; она не использована в Q38.

### 7.2. Проверка всех краёв и возвращений

1. **\(n=1\).** \(E_+(1)\) и \(E_-(1)\) имеют постоянный коэффициент 1; производная этого коэффициента нулевая. Удаление единиц в \(N_Z\) сделано явно.
2. **\(n=Z\).** Входит ровно в малую часть \(D_{{\rm comp},\le Z}\); большая составная часть начинается с \(n>Z\).
3. **\(n=m\).** Все формальные коэффициенты сохраняются, но \(V_L=0\). Это не вывод \(k_Z(m)=r_Z(m)=0\). Производная по \(\sigma\) не сдвигает \(L\), поэтому тоже оставляет нулевой физический оператор.
4. **Гиперболический край.** В (3.7) полное условие \(\ell krs v^2\le m\) сохранено. Все более длинные причинные произведения равны нулю. Никакая такая поддержка не переносится на reverse/Gram-произведения; последние здесь не использованы.
5. **Все степени простых.** Парное вспомогательное произведение имеет свои квадратные члены; исходная \(A\) остаётся полной \(\Lambda\)-суммой. Точная карта (2.10) возвращает каждый \(p^j\), включая \(j\ge2\), один раз.
6. **Смешанные каналы и комплексные векторы.** Суммируются все \(\ell,k\), все \(d,e\) внутри \(g_Z\), оба члена правила произведения и полный adjoint финальной формы. Фаза \(c\) не заменена модулем или вещественным вектором.
7. **Континуум.** \(C^0=A+H_d\) сохраняет \(0\preceq H_d\preceq4P\). Его не разрывали на два больших канала. При возврате из \(C^0\) к \(A\) он отменяется точно; отдельной полустепенной платы фону нет.
8. **Проектор.** \(P\) стоит только в начале/конце физической формы. Ни \(PE_\pm=E_\pm P\), ни сохранение контактов промежуточными векторами не предполагается. Новой Fourier/cutoff ошибки в основном all-\(P\) расчёте нет.
9. **Actual zero-selective pair.** All-\(P\) bounds применимы к целому возвращённому вектору пары, но здесь нет новой оценки её специальной фазы. Унаследованные S11–S12 не превращают (6.15) в margin; отдельная благоприятная pair-оценка не заявлена.

## 8. Содержательный откат и выполненная различающая проверка

### 8.1. Останавливаем не источник, а конкретное завершение

Дешёвое произведение не сохранило неоплаченную squarefree-поддержку: (4.5) удаляет все её большие нечётные простые степени. **Возвращение коэффициента один в (5.9) — точная причина остановки**, а не отсутствие численной точности. Нельзя тратить (4.3) на \(C_{\rm sf}\), оставляя \(N_Z\), \(D_o\) или prime-deletion без платы.

Математически не исключены другие партнёры, signed-congruence, прямое сравнение до такого умножения или source-specific оценка на фактическом образе. Здесь не доказан запрет всех парных произведений. Локальные факторизации и малые нормы сами по себе не поставляют эти дополнительные свойства.

### 8.2. Выполненный откат до парного умножения

Возвращаемся к **полной первой производной \(D_+\)** с сохранением её первичного компонента, а не продолжаем оценивать \(K_Z\). Точные карты:
\[
C_{\rm sf}
=\mathcal I^*\operatorname{Sym}
(D_+-D_{+,\le Z}-\Pi_{>Z}^{\to})\mathcal I,
\tag{8.1}
\]
\[
\boxed{C^0=-C_{\rm sf}+U_{\rm sf}+H_d.}
\tag{8.2}
\]
Здесь \(\operatorname{Sym}X=X+X^*\), без коэффициента \(1/2\). Добавочная ошибка этих карт нулевая, полный существующий budget дан в §7. Это не новый поставщик.

**Проверка на точке отката выполнена на настоящих коэффициентах, а не произвольной модели:** для всякого rough-квадратсвободного составного \(n<m\) коэффициент производной (8.1) равен \(\log n\), хотя у \(Q_Z\) он равен нулю. Для простого он равен нулю после literal deletion; для \(p^2\) оба вспомогательных члена (5.10) возвращают ноль составной squarefree-формы, а \(U_{\rm sf}\) восстанавливает \(\Lambda(p^2)\). Таким образом, различаются источник и «облегчённое» произведение до любого спектрального вывода.

Это более ранний откат с проверенной границей информации: дальнейшее уменьшение нормы \(K_Z\) без оценки восстановления не меняет коэффициенты (5.9). Новый ход должен использовать signed-связь **до аннулирования этих коэффициентов**, либо оценить их полный возврат независимо, а не назвать его малым.

### 8.3. Контроль ложного обращения — не второй механизм

Следующий ограниченный контроль приведён, чтобы не принять \(E_-\) за обратный \(E_+\). Он не используется как новый источник знака и не заменяет настоящую модель \(a_Z\equiv1\).

В неситом базовом конечном произведении
\[
E_0=\prod_{p\le m}(I+X_p)
\]
обратный коэффициент равен функции Лиувилля
\(\lambda_{\rm L}(n)=(-1)^{\sum_p v_p(n)}\), **не \(\mu(n)\)**. Тогда
\[
(-\partial_\sigma E_0)E_0^{-1}
=\sum_{p^j\le m}(-1)^{j+1}\log p\,X_{p^j}.
\tag{8.3}
\]
Эта классическая finite-algebra проверка не нова. Её полный отличающий контроль: разность с настоящим причинным Mangoldt-оператором — \(-2\sum_{p^{2j}\le m}\log p\,X_{p^{2j}}\), а не ноль. При \(\sigma=1/2\)
\[
\sum_{p^{2j}\le m}\frac{\log p}{p^j}
\le2\sum_{p\le\sqrt m}\frac{\log p}{p}
\le12+3L.
\tag{8.4}
\]
Поэтому двусторонняя физическая разность имеет норму не более \(48+12L\). Но отдельная норма обратного \(\|E_0^{-1}\|\le2\sqrt m\), а \(\|\partial_\sigma E_0\|\le2\sqrt mL\), возвращают до сжатия только \(4mL\) для их произведения. Точное coefficient-return (8.3) возвращает первую prime-форму, не её благоприятный знак. Для настоящих \(g_Z\) обратный не отождествлялся с этим базовым случаем.

Тем самым ни формальная замена партнёра обратным, ни старый логарифмический derivative не обходят проверенный долг. Это локальный отрицательный контроль при откате, а не второй успешный арифметический ход и не повтор Q37 log-chord.

## 9. Самоаудит, наиболее сильное возражение и границы результата

**Возражение:** дешёвое произведение могло быть всего лишь искусственным уничтожением трудной части; в таком случае его оценка не продвигает доказательство.

**Ответ:** именно это обнаружено и количественно возвращено. Поэтому первичный статус — NO_PROGRESS. Утверждение (4.3) сохраняет ценность как проверенная вспомогательная оценка настоящих полных каналов, но (5.9) запрещает его бесплатную трату на исходную форму. Полный расход завершения установлен в §6, а не скрыт под названием «остаток».

Второе возражение: нижняя цена rough-семипростых не является препятствием на исходном \(P\). **Верно.** §6.3 не утверждает существование плохого \(P\)-вектора, отрицательного собственного значения или неизбежно большой нормы \(\mathcal R_Z\). Он ограничивает лишь положительный scalar allowance (6.1). Неизвестное физическое сокращение остаётся возможным.

Третье возражение: \(a_Z\) не мультипликативно, поэтому локальные Euler-факторы нельзя использовать. **Учитывается:** (3.5)–(3.7) сохраняют всю двойную сумму по \(g_Z\); (2.8) и planted control обнаруживают ложную мультипликативную подмену.

Четвёртое возражение: сложение с adjoint уничтожает полученную поддержку. Нет: физический оператор включает отдельно причинный коэффициент и его adjoint с тем же реальным коэффициентом. Поддержка arithmetic-index в каждом остаётся прежней. Внутри причинных произведений adjoint не вставляется. Контроль на 2×2 nilpotent shift проверяет только эту алгебраическую разницу; он не служит контрпримером CCM.

Пятое возражение: малое число тестовых мод или формализация могли бы автоматически улучшить расход. Здесь ни число мод, ни точность не участвуют в нижней цене (6.14). Но это не запрещает использовать структуру actual образа в иной оценке; S12 не заменяет её готовым результатом.

## 11. Проверки, воспроизводимость и внешние сведения

Выполнены 45 групп exact-контролей и обнаружены 10 намеренных ошибок.         while n % p == 0:

            n //= p
        if a:
            out.append((p, a))
        p += 1
    if n > 1:
        out.append((n, 1))
    return tuple(out)

    return 0 if any(a > 1 for p, a in fs) else (-1)**len(fs)

    for p, a in factors(n):

"""Verify the canonical Q38 bytes and all twelve size-locked source bodies.

Run: python verify_sources_q38.py PROSHKA_CCM_SQUAREFREE_SIGNED_RETURN_Q38_2026-10-26.txt
Only reads the supplied packet and writes source_verification_q38.json.
"""
import argparse
import hashlib
import json
import re
from pathlib import Path

EXPECTED_NAME = 'PROSHKA_CCM_SQUAREFREE_SIGNED_RETURN_Q38_2026-10-26.txt'
EXPECTED_BYTES = 215599
EXPECTED_LF = 3497
EXPECTED_SHA = '173dddc9e6e3904b2d6d413d61f841a00c19dcf73774cd0a4629cce5215c376e'
HEADER = re.compile(rb'^BEGIN_SOURCE (S\d+) ([^\n]+)\nBYTES: (\d+)\nSHA256: ([0-9a-f]{64})\nBODY:\n', re.M)

def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('packet', nargs='?', type=Path, default=Path(EXPECTED_NAME))
    args = parser.parse_args()
    data = args.packet.read_bytes()
    data.decode('utf-8', errors='strict')
    sha = hashlib.sha256(data).hexdigest()
    if (len(data), data.count(b'\n'), sha) != (EXPECTED_BYTES, EXPECTED_LF, EXPECTED_SHA):
        raise ValueError('Canonical request byte count, LF count, or SHA-256 differs')
    records = []
    pos = 0
    for index in range(1, 13):
        match = HEADER.search(data, pos)
        if match is None or match.group(1) != ('S%d' % index).encode():
            raise ValueError('Missing or out-of-order source %d' % index)
        size = int(match.group(3))
        begin = match.end()
        end = begin + size
        body = data[begin:end]
        body.decode('utf-8', errors='strict')
        digest = hashlib.sha256(body).hexdigest()
        if len(body) != size or digest != match.group(4).decode():
            raise ValueError('Body bytes or SHA differ: ' + match.group(1).decode())
        if not data[end:].startswith(b'\nEND_SOURCE\n'):
            raise ValueError('Invalid separator or end marker')
        first = data[:begin].count(b'\n') + 1
        records.append(dict(id=match.group(1).decode(), name=match.group(2).decode(),
                            bytes=size, lf=body.count(b'\n'), sha256=digest,
                            start_line=first, end_line=first+body.count(b'\n')-1))
        pos = end + len(b'\nEND_SOURCE\n')
    if HEADER.search(data, pos) is not None:
        raise ValueError('Unexpected extra source body')

if __name__ == '__main__':
    main()
