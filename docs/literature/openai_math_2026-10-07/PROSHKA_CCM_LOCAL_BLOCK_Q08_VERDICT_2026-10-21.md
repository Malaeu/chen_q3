## 1. Смешанный элемент двух четырёхмодовых столбцов

**[FINITE_CELL | PAPER — определения источника].** Сохраняются
\[
 L=\log m,\quad M=R=\lfloor m^\epsilon\rfloor,\quad
 0<\epsilon<1/32\quad\text{фиксировано},\qquad
 \omega_j=2\pi j/L,\quad\Omega=2\pi M/L.
\]
Полоса дополняется нулями в прежний полный carrier \(N=m\). Пусть
\[
 n_c=2M-2,\quad v=(-1,3,-3,1),\quad
 a_j=\tfrac14+\omega_j^2,\quad j_k=k-M\quad(0\le k<n_c).
\]
Исходная карта из локальных координат:
\[
 E=-\operatorname{diag}(a_j)D_3,\qquad
 E_{j_k+r,k}=-a_{j_k+r}v_r\quad(0\le r\le3).
\]
Её образ — **всё** исходное трёхусловное пространство, а не уменьшенный класс тестов. \(E\) не является изометрией. Обозначим метрику локальных координат
\[
 \mathsf G_E=E^*E.
\]
При \(M\ge2\) она положительно определена; из пакета
\[
 \mathsf G_E\succeq\frac1{16\binom{n_c+2}{3}^2}I.
 \tag{1.1}
\]

Для любого \(s\in[0,L]\) **весь** смешанный элемент равен
\[
 \boxed{
 \mathcal Q_{k\ell}(s)
 =\sum_{r,t=0}^{3}
 v_rv_t\,a_{j_k+r}a_{j_\ell+t}
 Q_M(s)_{j_k+r,j_\ell+t}.}
 \tag{1.2}
\]
Здесь все шестнадцать слагаемых сохранены. Более явно:
\[
\begin{aligned}
\mathcal Q_{k\ell}(s)
={}&2(1-s/L)
 \sum_{\substack{0\le r,t\le3\\k+r=\ell+t}}
 v_rv_t a_{j_k+r}^{\,2}\cos(\omega_{j_k+r}s)\\
&+\frac1\pi
 \sum_{\substack{0\le r,t\le3\\k+r\ne\ell+t}}
 v_rv_t a_{j_k+r}a_{j_\ell+t}
 \frac{\sin(\omega_{j_\ell+t}s)-\sin(\omega_{j_k+r}s)}
      {k-\ell+r-t}.
\end{aligned}
 \tag{1.3}
\]
Условия равенства индексов существенны для \(|k-\ell|\le3\); заменять их общей внедиагональной формулой нельзя.

Пусть \(f_k=FEe_k\). Эквивалентная проверяемая запись:
\[
 \mathcal Q_{k\ell}(s)=
 \int_0^{L-s}
 \bigl[\overline{f_k(t+s)}f_\ell(t)
       +\overline{f_k(t)}f_\ell(t+s)\bigr]dt.
 \tag{1.4}
\]
Она сохраняет исходное окно, а не круговой сдвиг. При \(s=L\) весь элемент равен нулю; при \(s=0\) \(\mathcal Q(0)=2\mathsf G_E\).

Поэтому для **полной** \(K_{\rm loc}=E^*A_{\rm prime}E\)
\[
 \boxed{
 (K_{\rm loc})_{k\ell}
 =\sum_{2\le n\le m}\frac{\Lambda(n)}{\sqrt n}\mathcal Q_{k\ell}(\log n)
 =\sum_{db\le m}\frac{\mu(d)\log b}{\sqrt{db}}
                \mathcal Q_{k\ell}(\log(db)).}
 \tag{1.5}
\]
Во второй сумме \(b\) — целочисленный множитель, **не** индекс столбца. \(b=1\) имеет нулевой вес, \(db=m\) — исходный нулевой kernel, но оба края остаются в точных формулах. \(\Lambda(p^j)=\log p\) для всех \(j\ge1\).

**Выбранный коэффициентный механизм.** Не менять фазы и не брать каждый простой по отдельности. Выделить **одним конечным включением–исключением** все делители, составленные из малых простых. Их полные внутренние \(b\)-суммы уже допускают недорогой continuous/quadrature возврат. Затем проверить, позволяет ли точная арифметика оставшегося составного коэффициента перенести это на верхний порядок \(K_{\rm loc}\). Именно последний переход, а не (1.5), является испытываемой частью.

## 3. Точная многопростая сборка: коэффициенты, которые действительно получаются

### 3.1. Конечное решето без смены исходной фазы

**[FINITE_CELL | PAPER].** Для вещественного \(y\ge2\) положим
\[
 \mathfrak p_y=\prod_{p\le y}p,\qquad
 \mu_y(d)=\mu(d)\mathbf1_{d\mid\mathfrak p_y},
\]
\[
 \Lambda_y(n)=\sum_{d\mid n}\mu_y(d)\log(n/d).
 \tag{3.1}
\]
Это вспомогательный коэффициент; исходный \(\Lambda\) **не заменён** им. Разница будет сохранена точно.

Пусть \(\mathcal P_y(n)=\{p\le y:p\mid n\}\). Полное включение–исключение даёт
\[
 \boxed{
 \Lambda_y(n)=
 \begin{cases}
 \log n,&|\mathcal P_y(n)|=0,\\
 \log p,&\mathcal P_y(n)=\{p\},\\
 0,&|\mathcal P_y(n)|\ge2.
 \end{cases}}
 \tag{3.2}
\]
При \(n=1\) первая строка равна нулю. Для доказательства раскрываем
\(\log(n/d)=\log n-\sum_{p\mid d}\log p\); постоянная часть и каждый линейный коэффициент суммируются по всем подмножествам \(\mathcal P_y(n)\). При двух и более простых оба типа коэффициентов исчезают. При одном остаётся \(\log p\).

В частности,
\[
 \boxed{0\le\Lambda(n)\le\Lambda_y(n)\le\log n.}
 \tag{3.3}
\]
Все собственные степени сохранены. Если \(p\le y\), то \(\Lambda_y(p^j)=\log p\). Если \(p>y\), то \(\Lambda_y(p^j)=j\log p\), и лишние \((j-1)\log p\) обязательно возвращаются в остатке.

### 3.2. Остаток не является произвольной последовательностью

Положим
\[
 r_y(a)=\mathbf1_{(a,\mathfrak p_y)=1}.
\]
Из \(\mu_y*\mathbf1=r_y\) и \(\log=\mathbf1*\Lambda\) получается конечное коэффициентное равенство
\[
 \boxed{\Lambda_y=r_y*\Lambda.}
 \tag{3.4}
\]
Значит,
\[
 \boxed{
 \Delta_y(n):=\Lambda_y(n)-\Lambda(n)
 =\sum_{\substack{ab=n\\a>1,\ (a,\mathfrak p_y)=1}}\Lambda(b)\ge0.}
 \tag{3.5}
\]
Член \(a=1\) — ровно исходная \(\Lambda(n)\); забыть его значило бы изменить источник. \(b\) включает все простые степени, а \(a\) — все целые без простого делителя \(\le y\), в том числе степени и смешанные произведения.

Обозначим на исходном \(P\)
\[
 S=P A_{\rm prime}P,
\quad S_y=\sum_{n\le m}\frac{\Lambda_y(n)}{\sqrt n}P Q_M(\log n)P,
\]
\[
 D_y=\sum_{n\le m}\frac{\Delta_y(n)}{\sqrt n}P Q_M(\log n)P.
\]
Тогда **полное**, не покомпонентно ослабленное равенство:
\[
 \boxed{S=S_y-D_y.}
 \tag{3.6}
\]

В локальных координатах положим
\[
 K_y=E^*A_yE,\quad K_{\Delta,y}=E^*A_{\Delta,y}E.
\]
Так как \(PE=E\),
\[
 \boxed{K_{\rm loc}=K_y-K_{\Delta,y},}
 \tag{3.7}
\]
\[
 \boxed{
 (K_{\Delta,y})_{k\ell}
 =\sum_{\substack{a>1,\ (a,\mathfrak p_y)=1\\ab\le m}}
 \frac{\Lambda(b)}{\sqrt{ab}}\mathcal Q_{k\ell}(\log(ab)).}
 \tag{3.8}
\]
Это весь смешанный остаток. Здесь не введены независимые фазы, прямоугольное расширение гиперболы, новые физические частоты или разбиение простых на independently-small raw shells.

Включение следующего малого простого \(q\) даёт также точно
\[
 \Lambda_{y\cup\{q\}}(n)=\Lambda_y(n)-\mathbf1_{q\mid n}\Lambda_y(n/q).
 \tag{3.9}
\]
По коэффициентам это монотонное убывание. Будет проверено, почему **матрицы** так упорядочить нельзя.

## 4. Что реально оплачивает включение–исключение

### 4.1. Полный внутренний оператор каждого делителя

**[COFINAL_FAMILY | PAPER; конечная оценка при \(L\ge4\)].** Для \(1\le d\le m\) определим
\[
 B_{m,d}=\sum_{b\le m/d}\frac{\log b}{\sqrt{db}}
                     P Q_M(\log(db))P.
\]
Имеем прежнюю достаточную цену
\[
 \boxed{\|B_{m,d}\|\le\frac{b_m}{\sqrt d},\qquad b_m=40+16\Omega.}
 \tag{4.1}
\]
Ниже дан краткий вывод из входов Q08/Q10, чтобы не расширить их область незаметно.

Положим \(A(t)=t^{-1/2}P Q_M(\log t)P\), \(D_1=2/L+4\Omega\). Тогда
\[
 \|A(t)\|\le2t^{-1/2},\qquad
 \|A'(t)\|\le(1+D_1)t^{-3/2}.
\]
Для \(F_d(t)=\log(t/d)A(t)\), \(F_d(d)=F_d(m)=0\). Точное суммирование Эйлера, с \(\beta(t)=\lfloor t/d\rfloor-t/d\), даёт
\[
 B_{m,d}=C_{m,d}+E_{m,d},\quad
 C_{m,d}=\frac1d\int_d^m\log(t/d)A(t)dt,
\quad E_{m,d}=-\int_d^m\beta(t)F'_d(t)dt.
\]
С \(|\beta|\le1\)
\[
 \|E_{m,d}\|
 \le\frac{8+4D_1}{\sqrt d}
 \le\frac{10+16\Omega}{\sqrt d}.
 \tag{4.2}
\]
Границы и все целочисленные скачки сохранены; \(db=m\) не создаёт скрытого остатка.

Принятые полные непрерывные identity:
\[
 \int_1^m A(t)dt=-H_P,\qquad
 \int_1^m\log t\,A(t)dt=J_P,
\quad\|H_P\|\le4,\quad\|J_P\|\le8.
\]
Поэтому
\[
 C_{m,d}=\frac{J_P+\log d\,H_P}{d}
 -\frac1d\int_1^d\log(t/d)A(t)dt.
\]
Первые два слагаемых имеют суммарную цену \(12/\sqrt d\), нижний интеграл — \(8/\sqrt d\). С (4.2) получаем даже \((30+16\Omega)/\sqrt d\); оставляем совместимый с источником \(b_m\) из (4.1). Это **повторно выведенный вход**, не новый показатель Q08.

### 4.2. Целый многопростой сектор — не отдельные локальные диагонали

По (3.1), с полным \(b\)-возвратом до норм,
\[
 \boxed{
 S_y=\sum_{\substack{d\mid\mathfrak p_y\\d\le m}}\mu(d)B_{m,d}.}
 \tag{4.3}
\]
Обозначим положительную **цену данного нормового переноса**
\[
 \Xi_y(m)=\sum_{\substack{d\mid\mathfrak p_y\\d\le m}}d^{-1/2}.
\]
Тогда
\[
 \boxed{-u_yP\preceq S_y\preceq u_yP,\qquad
 u_y=b_m\Xi_y(m).}
 \tag{4.4}
\]
Все делители \(d>R\), состоящие только из малых простых, входят в (4.3). Это не прежнее простое усечение \(d\le R\).

Полная конечная факторизация положительного конверта даёт
\[
 \Xi_y(m)\le\prod_{p\le y}(1+p^{-1/2})
 \le\exp\left(\sum_{p\le y}p^{-1/2}\right)
 \le e^{2\sqrt y}.
 \tag{4.5}
\]
Добавленные при оценке произведения делители \(d>m\) используются только в **положительном верхнем бюджете**; их исходные операторы нулевые, никакие будущие атомы не входят в (4.3).

Теперь выберем лишь вспомогательный уровень
\[
 \boxed{y=y_m=\max\{2,\lfloor(\epsilon L/8)^2\rfloor\}.}
 \tag{4.6}
\]
Это не изменение \(R\), \(M\), \(P\) или исходной фазы. Для каждой фиксированной \(\epsilon\), после конечного старта,
\[
 \boxed{
 \|S_{y_m}\|\le(40+16\Omega)m^{\epsilon/4}
 =O_\epsilon(m^{5\epsilon/4}/L).}
 \tag{4.7}
\]
Таким образом, **целая вспомогательная матрица**, а не одна её диагональ, оплачена степенью, стремящейся к нулю вместе с \(\epsilon\). Это реальная оценка (4.3), но она **не** является оценкой \(S\), пока не возвращён \(D_y\).

### 4.3. Полная локальная метрика и цена ненужного перехода к строкам

Из (4.4) сразу следует точная по метрике оценка
\[
 \boxed{-u_y\mathsf G_E\preceq K_y\preceq u_y\mathsf G_E.}
 \tag{4.8}
\]
В ней нет платы \(M^6\): она уже выражена в правильной норме \(\|Eg\|^2\).

Если всё-таки перейти к абсолютным смешанным элементам, то
\[
 |(K_y)_{k\ell}|\le u_y\|Ee_k\|\,\|Ee_\ell\|
 \le20a_{\max}^2u_y,
\quad a_{\max}=1/4+\Omega^2.
\]
Row-return пакета затем стоит
\[
 320\,n_c\binom{n_c+2}{3}^{2}a_{\max}^{2}u_y.
 \tag{4.9}
\]
На расписании это имеет степенную цену \(49\epsilon/4\), с соответствующими логарифмами, вместо \(5\epsilon/4\) в (4.8). Обе вспомогательные степени стремятся к нулю, но (4.9) здесь не требуется. **Ни один смешанный член не занулён для получения (4.8).**

## 5. Первая неподтверждённая строка и действительно полный бюджет

Равенство (3.7) и доказанная (4.8) дают только
\[
 \boxed{K_{\rm loc}\preceq u_y\mathsf G_E-K_{\Delta,y}.}
 \tag{5.1}
\]
Для малого окончательного бюджета нужно одностороннее **нижнее** ограничение всей \(K_{\Delta,y}\) относительно \(\mathsf G_E\). Из \(\Delta_y(n)\ge0\) такого ограничения не следует: \(Q_M(s)\) не является положительной матрицей. Конкретная фактическая неудача вывода \(K_{\Delta,y}\succeq0\) будет доказана в §6, не заменена общим примером с произвольными коэффициентами.

**Первая неподтверждённая арифметическая строка:** получить для полной суммы (3.8) нижний конверт, после которого (5.1) имеет новую допустимую степень. Такое неравенство **не принимается в предпосылки** и не получает статуса нового готового supplier. Его связь с исходной задачей почти эквивалентна: дешёвая (4.7) уже оплачена, а весь неопределённый знак перешёл в \(-D_y\).

### 5.1. Что получается без этого недоказанного входа

Из (3.3), для полного физического оператора, до любой проекции,
\[
 \|A_{\Delta,y}\|
 \le2\sum_{n\le m}\frac{\Delta_y(n)}{\sqrt n}
 \le2L\sum_{n\le m}n^{-1/2}
 \le4\sqrt m\,L.
 \tag{5.2}
\]
Следовательно, доказано полное, но слабое
\[
 \boxed{K_{\rm loc}\preceq
 [u_y+4\sqrt mL]\mathsf G_E,\qquad
 S\preceq[u_y+4\sqrt mL]P.}
 \tag{5.3}
\]
После всех возвратов степень этой попытки — **\(1/2\)**. Абсолютные строки дали бы ещё худшую цену \(1/2+11\epsilon\); мы её не расходуем, поскольку (5.3) сохраняет метрику.

Из принятой элементарной \(\psi(x)\le3x\) уже следует более сильное
\[
 \boxed{\|S\|\le12\sqrt m.}
 \tag{5.4}
\]
Поэтому (5.3) не рекламируется как улучшение даже безусловного elementary-конверта. Новый результат — стоимость выделенного сектора и точная проверка знакового переноса, а не новый полный показатель.

## 6. Отрицательный контроль на настоящем полном остатке решета

### Теорема. Коэффициентный порядок не становится Loewner-порядком на исходном P

**[COFINAL_FAMILY | PAPER — исходное расписание; PNT только для выбора ближайшего простого].** Для каждого фиксированного \(0<\epsilon<1/32\), при (4.6), пусть \(q=q(m)\) — первый простой больше \(y_m\), \(n_0=2q\). На каждой достаточно поздней исходной ячейке существуют два единичных вектора \(c_m^\pm\in\operatorname{ran}P\), для которых
\[
 \boxed{
 (c_m^+)^*D_{y_m}c_m^+\ge\frac{\log2}{2\sqrt{n_0}},\qquad
 (c_m^-)^*D_{y_m}c_m^-\le-\frac{\log2}{2\sqrt{n_0}}.}
 \tag{6.1}
\]
Это **полная** \(D_y\), со всеми её атомами, после возвращения в первоначальную конечную полосу. Таким образом,
\[
 \Lambda_y\ge\Lambda\quad\not\Longrightarrow\quad S_y\succeq S.
 \tag{6.2}
\]
Сама величина в (6.1) имеет лишь обратнологарифмический масштаб. **Она не опровергает нижнюю оценку \(D_y\succeq-C_\epsilon m^{\eta(\epsilon)}P\)** и не даёт нижней оценки большого положительного спектра исходной \(S\). Никакого half-power obstruction для всей \(S\) из неё не выводится.

### 6.1. Первый ненулевой остаточный коэффициент

Из (3.5) при \(a>1\) имеем \(a\ge q\), а ненулевое \(\Lambda(b)\) требует \(b\ge2\). Поэтому
\[
 \boxed{\Delta_y(n)=0\ (n<2q),\qquad
        \Delta_y(2q)=\log2.}
 \tag{6.3}
\]
У \(2q\) два различных простых делителя, так что \(\Lambda(2q)=0\). Здесь проявляется именно фактическая делительная арифметика; никаких модельных знаков нет.

По PNT \(\pi(2y)-\pi(y)>0\) позднее, поэтому \(y<q\le2y\). На (4.6)
\[
 n_0=O_\epsilon(L^2),\qquad \log n_0=O_\epsilon(\log L).
 \tag{6.4}
\]
Не требуется оценка ошибки RH-силы и не утверждается численно сертифицированный onset.

### 6.2. Два компактных профиля, выполняющих все исходные контакты

Выберем один раз целое
\[
 r=\lceil1/\epsilon\rceil+2,\qquad N_0=r+3,
\]
и полином
\[
 b(x)=x^{N_0}(1-x)^{N_0}\mathbf1_{[0,1]}(x).
\]
Положим
\[
 \ell=\frac1{8n_0},\qquad
 h_\ell(t)=b((t-1)/\ell),\qquad
 g_\ell=(\partial_t^2-1/4)h_\ell,\qquad
 u_\ell=g_\ell/\|g_\ell\|_2.
\]
Функции равны нулю вне \([1,1+\ell]\). Их нужные граничные производные равны нулю. Точное интегрирование по частям даёт
\[
 \int e^{t/2}u_\ell(t)dt=
 \int e^{-t/2}u_\ell(t)dt=0.
 \tag{6.5}
\]
При этом
\[
 \|g_\ell\|_2^2
 =\ell^{-3}\|b''\|_2^2+\tfrac12\ell^{-1}\|b'\|_2^2
       +\tfrac1{16}\ell\|b\|_2^2>0.
 \tag{6.6}
\]
Для каждого фиксированного производного порядка \(j\le r\)
\[
 \|u_\ell^{(j)}\|_1\le C_r\ell^{1/2-j}.
 \tag{6.7}
\]
Это следует прямо из масштабирования двух членов \(g_\ell\) и нижней границы \(\|g_\ell\|_2\ge\ell^{-3/2}\|b''\|_2\). Константы зависят от фиксированного \(r\), а не от \(m\).

Пусть \(s_0=\log n_0\) и
\[
 f_\pm(t)=\frac{u_\ell(t)\pm u_\ell(t-s_0)}{\sqrt2}.
 \tag{6.8}
\]
Поддержки не пересекаются и обе лежат внутри \((0,L)\) позднее. Следовательно, \(\|f_\pm\|_2=1\). Перенос сохраняет нулевые моменты (6.5), а у концов исходного окна функции равны нулю. Никаких новых ограничений на production-пространство не вводится.

### 6.3. Все физические атомы посчитаны до проекции

Самоперекрытия поддержаны на \(|s|\le\ell<\log2\), значит никакой атом \(\log n\), \(n\ge2\), в них не попадает. Положительное перекрёстное перекрытие поддержано на \(|s-s_0|\le\ell\).

В этом последнем интервале из целых логарифмов находится только \(\log n_0\). Действительно,
\[
 \frac{n_0}{1-\ell}<n_0+1,\qquad
 n_0(1-\ell)>n_0-1,
\]
а \(e^\ell\le(1-\ell)^{-1}\), \(e^{-\ell}\ge1-\ell\). Поэтому
\[
 2\Re\langle f_\pm,V_{\log n_0}f_\pm\rangle=\pm1.
\]
Все остальные положительные целочисленные сдвиги дают нуль **на этих ещё не спроецированных профилях**. Отсюда точно
\[
 \boxed{
 \langle f_\pm,A_{\Delta,y}f_\pm\rangle
      =\pm\frac{\log2}{\sqrt{n_0}},\qquad
 \langle f_\pm,A_{\rm prime}f_\pm\rangle=0.}
 \tag{6.9}
\]
На этих же профилях \(A_y\) имеет значение \(\pm\log2/\sqrt{n_0}\). Поэтому отрицательный остаток нужен, в частности, чтобы **компенсировать искусственный составной атом** в коэффициентном верхнем конверте. Это наглядная проверка точного source-return (3.6), не отрицательный спектр исходной \(K_m\).

### 6.4. Fourier-усечение и все три исходных ограничения

Профили (6.8) пока не конечные Fourier-полиномы. Использовать их без возврата было бы ошибкой.

Из (6.7), \(r\) интегрирований по частям в исходном окне, для \(j\ne0\), дают
\[
 |\widehat f_\pm(j)|
 \le C_r L^{r-1/2}\ell^{1/2-r}|j|^{-r}.
\]
Поэтому при исходном усечении \(|j|\le M\)
\[
 \|f_\pm-Fc_{M,\pm}\|_2
 \le C_r\left(\frac L{\ell M}\right)^{r-1/2}
 =:\rho_m.
 \tag{6.10}
\]
Та же цена ограничивает нормированное endpoint-условие: абсолютная сумма хвостовых коэффициентов делится на \(\sqrt{2M+1}\). Для двух нормированных экспоненциальных условий используем их точные полные нули и отношение полной нормы экспоненты к норме её первоначального усечения, ограниченное на позднем диапазоне пакета. Каждый остаток не больше \(C\rho_m\).

Принятая Gram-граница \(\ge I_3/2\) исходных трёх нормированных столбцов даёт
\[
 \|(I-P)c_{M,\pm}\|\le C_r\rho_m.
\]
После нормировки \(Pc_{M,\pm}\) получаем единичные \(c_m^\pm\) и
\[
 \boxed{\|Fc_m^\pm-f_\pm\|_2\le C_r\rho_m.}
 \tag{6.11}
\]
Здесь \(P\) прежний, а Fourier-частоты по-прежнему \(2\pi j/\log m\).

Из (6.4) имеем \(\ell^{-1}=O_\epsilon(L^2)\), так что
\[
 \rho_m\le C_{r,\epsilon}L^{3(r-1/2)}m^{-\epsilon(r-1/2)}.
 \tag{6.12}
\]
Порядок \(r\) фиксирован после выбора \(\epsilon\); он не растёт с \(m\).

### 6.5. Возврат всех вновь активированных атомов и всех mixed terms

После проекции нельзя продолжать утверждать, что поддержка корреляции содержит только \(n_0\). Вместо этого используем **полную** физическую норму (5.2). Для двух единичных функций разность их квадратичных форм не превосходит удвоенной нормы оператора, умноженной на расстояние. Значит,
\[
 \left|(c_m^\pm)^*D_yc_m^\pm
         -\langle f_\pm,A_{\Delta,y}f_\pm\rangle\right|
 \le C_{r,\epsilon}\sqrt mL\rho_m.
 \tag{6.13}
\]
В отношении к сигналу \(\log2/\sqrt{n_0}\) эта ошибка ограничена
\[
 C_{r,\epsilon}
 m^{1/2-\epsilon(r-1/2)}
 L^{3(r-1/2)+2}\longrightarrow0,
 \tag{6.14}
\]
поскольку выбранное \(r\) удовлетворяет \(\epsilon(r-1/2)>1/2\). Формулы (6.9), (6.13)–(6.14) доказывают (6.1).

Коэффициенты \(g_m^\pm\) в локальном базисе существуют единственным образом; они определены явно исходной обратной формулой
\[
 d_j=-c_j/a_j,\qquad
 g_k=-\sum_{i=0}^k\binom{k-i+2}{2}d_i
\]
в смещённой индексации пакета. В частности, \(\|Eg_m^\pm\|=1\), и (6.1) является также проверкой **полной** \(K_{\Delta,y}\) относительно \(\mathsf G_E\), включая все межстолбцовые элементы.

### 6.6. Область опровержения

Доказан строго отрицательный верхний запас для предполагаемого порядка \(D_y\succeq0\):
\[
 (c_m^-)^*D_yc_m^-\le-\frac{\log2}{2\sqrt{2q}}<0.
\]
Это source-derived контрпример **операторной монотонности коэффициентного решета**. Он не использует unrestricted twists и не меняет исходную CCM в контрольном сравнении: \(S_y-D_y=S\) возвращается целиком.

Но абсолютный размер контрольного сигнала имеет порядок \(1/\sqrt y\), здесь порядка \(1/L\). Он не доказывает, что остаток имеет недопустимую степень. Поэтому запрещён только бесплатный переход \(\Lambda_y\ge\Lambda\Rightarrow S_y\succeq S\). Возможность полезного количественного lower-bound для всего \(D_y\), а следовательно actual cancellation, не исключена.

## 7. Можно ли просто углубить решето до исчезновения остатка?

**[COFINAL_FAMILY | PAPER — точная цена выбранного абсолютного бюджета; тождество cutoff конечное].** Пусть \(q\) снова первый простой больше \(y\). Из (3.5), (6.3)
\[
 \boxed{\Delta_y(n)=0\ \text{для всех }n\le m
       \quad\Longleftrightarrow\quad 2q>m.}
 \tag{7.1}
\]
Если условие справа выполнено, у всех целых \(d\le X=\lfloor m/2\rfloor\) простые факторы уже \(\le y\). Следовательно, все бесквадратные такие \(d\) входят в \(\Xi_y(m)\).

Число небесквадратных целых до \(X\) не превосходит
\[
 \sum_{k=2}^{\lfloor\sqrt X\rfloor}\lfloor X/k^2\rfloor
 \le X\sum_{k=2}^\infty k^{-2}\le3X/4.
\]
Поэтому бесквадратных не меньше \(X/4\), и
\[
 \boxed{
 \Xi_y(m)\ge\frac{\sqrt X}{4}
 \ge\frac{\sqrt m}{4\sqrt3}\quad(m\ge4).}
 \tag{7.2}
\]
С другой стороны, всегда \(\Xi_y(m)\le2\sqrt m\). Таким образом, **для этого конкретного конверта** полное уничтожение остаточных коэффициентов ценой углубления решета возвращает бюджет \(b_m\sqrt m\), а не subpower.

Это нижняя граница **вычисленной цены \(b_m\Xi_y\)**, не нижняя граница \(\|S_y\|\) или \(\lambda_{\max}(S)\). Сумма настоящих знаковых операторов может быть значительно меньше суммы норм. Формула (7.2) не запрещает другое использование знаков при большом \(y\); она запрещает объявить этот абсолютный бюджет малым.

## 8. Весь возврат к T, V и K и проверка показателей

Для реально выведенной цены
\[
 s_m^{\rm sieve}=u_y+4\sqrt mL
\]
имеем
\[
 T_{>R}\preceq s_m^{\rm sieve}P-T_{\le R},\qquad
 PK_mP\succeq D_m-s_m^{\rm sieve}P.
 \tag{8.1}
\]
Скалярный контракт для \(T\) оплачивает
\[
 b_{\rm small}=(56+32\Omega)\sqrt R+12(1+\log R)^2
\]
**один раз**. Прямой контракт для \(K\) оплачивает лишь \(50L+8\); короткая часть сократилась в точной source identity, а не получила неизвестный благоприятный знак.

Действительно более дешёвая elementary-цена (5.4) даёт
\[
 \boxed{
 T_{>R}\preceq12\sqrt mP-T_{\le R},\qquad
 PK_mP\succeq D_m-12\sqrt mP
 \succeq-[12\sqrt m+50L+8]P.}
 \tag{8.2}
\]
Это **ранее доступная** оценка, не итоговый новый выигрыш Q08.

Для отдельного \(V=C+E_{\rm slow}\) принимается ровно Q02:
\[
 T=V+\Delta_2,\quad\|\Delta_2\|\le F_2,
\]
\[
 F_2=32(1+D_1)N_D(1+2L)+\frac{\mathfrak K_2}{\pi^2m^{3/2}},
\quad N_D=\lceil\log_2(m/R)\rceil,
\]
\[
 D_2=4\Omega/L+4\Omega^2,
\qquad\mathfrak K_2=16/3+20D_1/9+4D_2/9.
\]
Тогда \(V\preceq(s_m+F_2)P-T_{\le R}\). Эта плата не добавляется повторно к прямой оценке \(S\) или \(K\).

| Объект | Полная цена | Степень | Что это означает |
|---|---|---:|---|
| Один полный делитель | \(b_m/\sqrt d\) | \(\epsilon\) в коэффициенте | Переиспользованный continuous/quadrature вход |
| Все smooth squarefree divisors при (4.6) | \(u_y\le b_m m^{\epsilon/4}\) | \(5\epsilon/4\) | Оплачен весь \(S_y\), не исходный \(S\) |
| Тот же сектор через ненужный absolute-row возврат | (4.9) | \(49\epsilon/4\) | Цена \(E^*E\) не забыта; этот путь не используется |
| Полный составной остаток по доступной норме | \(4\sqrt mL\) | \(1/2\) | Знак не получен; доминирует в (5.3) |
| Полный источник из выбранного переноса | \(u_y+4\sqrt mL\) | \(1/2\) | Не улучшение |
| Более сильная старая elementary-оценка | \(12\sqrt m\) | \(1/2\) | Сохраняется как более сильный элементарный конверт |
| Scalar T short return | \(b_{\rm small}\) | \(3\epsilon/2\) | Один раз |

Нового кофинального вывода нет. Например, из (8.2) следует лишь
\[
 \operatorname{Tr}(S_+^4)\le(2M+1)12^4m^2.
\]
Усреднение по \([X,2X)\) оставляет эту степень \(2+\epsilon\); извлечение корня не превращает её в показатель, стремящийся к нулю. Хороший общий для всех векторов масштаб новой оценкой не выделен.

## 9. Что сохраняется и где выполнен откат

**Самая сильная атака на этот результат:** «Ты построил дешёвую вспомогательную матрицу и не доказал дешевизну исходной». **Верно.** Поэтому (4.7) не объявляется ответом на исходную спектральную задачу. В (3.6) исходник возвращён с точным остатком, его elementary-плата и предел неудачного sign-transfer предъявлены.

Первый опасный переход — не локальный базис и не его обусловленность. Это попытка использовать \(\Lambda_y\ge\Lambda\) как порядок матриц. §6 показывает ошибку на **фактических коэффициентах того же решета**, после полного возвращения к прежнему \(P\). Первая потеря в выполненной количественной верхней оценке — переход от полного \(-D_y\) к его абсолютной массе (5.2). После него остаётся половинная степень.

**Один обоснованный более ранний откат:** вернуться перед скалярной коэффициентной мажорантой к исходному совместному fixed-cell спариванию, в эквивалентных координатах \(K_{\rm loc}\preceq s\mathsf G_E\). Сам локальный базис можно сохранить как способ точного вычисления, но нельзя назначать отдельные строки или знак sieve-remainder обязательным supplier. Новой независимой арифметической оценки этого спаривания в Q08 не получено.

Два представления этой **одной точки отката**, не две новые кампании:

| Представление | Что остаётся совместным | Различающая сила / цена |
|---|---|---|
| \(g^*(K_y-K_{\Delta,y})g\) с исходной \(\mathsf G_E\) | Все 16 локальных слагаемых, весь rough-composite возврат, отрицательные вклады | Высокая против ошибки в коэффициентах/метрике; малая цена точной алгебры, неизвестная цена нового арифметического знака |
| \(\sum_{db\le m}\mu(d)\log b\,(db)^{-1/2}\langle f,(V_{\log(db)}+V_{\log(db)}^*)f\rangle\), \(f=FEg\) | Полная исходная \(\mu\), гипербола, физические края и один действительный тест | Высокая против незаконного позитивного сравнения; никакая новая оценка не следует только из смены записи |

Ни (3.8), ни новое имя для lower-bound \(D_y\) не выдвигаются как доказанное продвижение. Следующий новый исследовательский запрос имел бы основание только при наличии независимого аргумента, сохраняющего **неравенство квадратичных форм**, а не лишь порядок скалярных коэффициентов.

### Три проверки структуры в выбранном механизме

1. **Связь:** конечная делительная алгебра \(\mu_y*\mathbf1=r_y\) — точная coefficient identity, не случайная независимость.
2. **Зануление:** два исходных экспоненциальных момента оплачивают непрерывные full-k вклады; они не зануляют остаток (3.5), чей первый атом явно ненулевой.
3. **Схлопывающий перенос:** если бы coefficient-majorization был Loewner-majorization, (4.7) дал бы нужную степень. §6 опровергает именно этот дополнительный перенос. Если вместо него обнулить остаток поддержкой, §7 возвращает большую цену выбранного абсолютного конверта.

### Discriminators

- Для полного целевого контракта на закреплённой ячейке проверять \(C_\epsilon m^\eta\mathsf G_E-K_{\rm loc}\), а не матрицу с отброшенными смешанными элементами. - Для coefficient-order shortcut использовать \(g_m^-\) из §6: верхний конверт \((g_m^-)^*K_{\Delta,y}g_m^-\le-\log2/(2\sqrt{2q})<0\). Это полноценный PAPER-дискриминатор, а не решение по округлению.
- Для конечного нулесодержащего интервала mixed entry: поднять точность полного шестнадцатичленного расчёта или использовать точное ядро в специальной точке. Малый отдельный элемент не заменяет контроль generalized pencil.
- Для заявления «остаток обнулился»: проверять (6.3)/(7.1), включая атом \(2q\) и proper powers. Если \(2q\le m\), коэффициент не нулевой.

```python
            assert sum(column)==0
            stats['all_three_exact_local_contacts']+=1
        # This is literally the source kernel at s=L/2: Q diagonal=(-1)^j.
        Qhalf=[[F(((-1)**(i-M)) if i==j else 0) for j in range(d)] for i in range(d)]
        A=[[F((i+1)*(j+1),1+abs(i-j)) for j in range(d)] for i in range(d)]
        for Q in (Qhalf,A):
            K=mul(mul(transpose(E),Q),E)
            for k in range(n):
                for l in range(n):
                    explicit=sum(v[r]*v[t]*aj[k+r]*aj[l+t]*Q[k+r][l+t]
                                 for r in range(4) for t in range(4))
                    assert explicit==K[k][l]
            stats['sixteen_term_mixed_entry_matches_congruence']+=1
            g=[F((-1)**k*(k+1),k+2) for k in range(n)]
            c=mv(E,g)
            assert dot(g,mv(K,g))==dot(c,mv(Q,c))
            mixed_detected |= dot(g,mv(K,g))!=sum(g[k]**2*K[k][k] for k in range(n))
            stats['all_mixed_terms_return_to_source_form']+=1
        g=[F((-1)**k,k+1) for k in range(n)]; c=mv(E,g)
        h=[-c[i]/aj[i] for i in range(d)]
        rec=[-sum(F(comb(k-i+2,2))*h[i] for i in range(k+1)) for k in range(n)]
        assert rec==g
        Cn=comb(n+2,3)
        assert dot(g,g)<=16*Cn*Cn*dot(c,c)
        stats['triple_difference_inverse_and_metric_fee']+=1
        wrong_metric |= dot(g,g)!=dot(c,c)
assert mixed_detected and wrong_metric
stats['discarded_mixed_column_terms_detected']+=1
stats['identity_metric_substitution_detected']+=1

# Exact polynomial profiles; scaling does not remove the two moment contacts.
def padd(a,b):
    z=[F(0)]*max(len(a),len(b))
    for i,c in enumerate(a):z[i]+=c
    for i,c in enumerate(b):z[i]+=c
    return z
def scale(t,a): return [t*c for c in a]

    z=[F(0)]*(len(a)+len(b)-1)
    for i,x in enumerate(a):
        for j,y in enumerate(b):z[i+j]+=x*y
    return z

for N in (5,6,8):

        assert norm==expected and norm>0
        stats['scaled_profile_exact_norm']+=1

            assert val(q,0)==val(q,1)==0
            stats['both_exponential_contacts_via_exact_primitive']+=1
        assert val(g,0)==val(g,1)==0
        stats['profile_endpoint_zeros']+=1
# Integer interval isolating n0: exp(ell) <=1/(1-ell) for ell in(0,1).
for q in (3,5,7,11,17,29):
```

## Приложение D. Полная неинтервальная диагностика смешанного ядра

Сохрани блок как `diagnostic_q08.py`. При наличии `mpmath` запускай `python3 diagnostic_q08.py`. Подстановок нет. Зависимость при необходимости устанавливается в отдельной среде через `uv`; она не нужна exact-проверяющему.

```python
"""Original four-mode kernel identities, not spectral certificates.
Run: python3 diagnostic_q08.py (mpmath required). No path substitutions.
No large prime sum, zeta zero, or full CCM spectrum is evaluated.
"""
from pathlib import Path
import hashlib,json
import mpmath as mp
mp.mp.dps=65
L=mp.mpf(512)*mp.log(2); M=256; w=2*mp.pi/L
v=(-1,3,-3,1)
def a(j):return mp.mpf(1)/4+(w*j)**2
def col(j,t):return -sum(v[r]*a(j+r)*mp.exp(1j*w*(j+r)*t) for r in range(4))/mp.sqrt(L)
def Q(j,k,s):
    if j==k:return 2*(1-s/L)*mp.cos(w*j*s)
    return (mp.sin(w*k*s)-mp.sin(w*j*s))/(mp.pi*(j-k))
rows=[]
for j,k,frac in ((-2,1,mp.mpf('0.21')),(-3,-1,mp.mpf('0.5')),(0,2,mp.mpf('0.91'))):
    s=frac*L
    mixed=sum(v[r]*v[t]*a(j+r)*a(k+t)*Q(j+r,k+t,s) for r in range(4) for t in range(4))
    knots=[(L-s)*i/32 for i in range(33)]
    overlap=mp.quad(lambda t:mp.conj(col(j,t+s))*col(k,t)+mp.conj(col(j,t))*col(k,t+s),knots)
    err=abs(overlap-mixed)
    assert err<mp.mpf('1e-48')
    csum=sum(-v[r]*a(j+r) for r in range(4))
    pos=sum(-v[r]*a(j+r)/(mp.mpf('.5')+1j*w*(j+r)) for r in range(4))
    neg=sum(-v[r]*a(j+r)/(-mp.mpf('.5')+1j*w*(j+r)) for r in range(4))
    assert max(abs(csum),abs(pos),abs(neg))<mp.mpf('1e-55')
    rows.append({'left_start_mode':j,'right_start_mode':k,'s_over_L':str(frac),
                 'mixed_entry':str(mixed),'overlap_error':str(err),
                 'normalized_constraint_residual':str(max(abs(csum),abs(pos),abs(neg)))})
out={'status':'PASS_DIAGNOSTIC_NOT_INTERVAL','cases':len(rows),'decimal_digits':mp.mp.dps,
     'source_cell':'m=2^512,epsilon=1/64,M=R=256,L=512log(2)',
     'scope':'Only individual mixed kernels and original contacts. No prime spectra or asymptotic validation.',
     'rows':rows,'actual_large_prime_sums':0,'full_ccm_spectral_runs':0,'arb_runs':0,'lean_runs':0,
     'script_sha256':hashlib.sha256(Path(__file__).read_bytes()).hexdigest()}
Path(__file__).with_name('diagnostic_results.json').write_text(json.dumps(out,ensure_ascii=False,indent=2)+'\n')
print(json.dumps(out,ensure_ascii=False,indent=2))
```
