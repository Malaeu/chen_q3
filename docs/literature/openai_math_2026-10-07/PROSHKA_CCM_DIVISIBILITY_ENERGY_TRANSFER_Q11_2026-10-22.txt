## 1. Полная исходная форма — до сглаживания

**[FINITE_CELL | PAPER — определения источника.]** Пишем
\[
 L=\log m,\quad M=R=\lfloor m^\epsilon\rfloor,\quad
 \omega_j=2\pi j/L,\quad\Omega=2\pi M/L,\quad A=1+\Omega.
\]
\(P\) — прежний проектор внутри исходной полосы, дополненной нулями в carrier \(N=m\). Для \(c\in\operatorname{ran}P\), \(f=Fc\):
\[
 f(0)=f(L)=0,\qquad \int_0^L e^{t/2}f(t)dt=
 \int_0^L e^{-t/2}f(t)dt=0,\qquad\|f\|_2=\|c\|_2.
\]
При данном \(m\) ни \(P\), ни частоты далее не двигаются.

Обозначим
\[
 H_m(x)=x^{-1/2}P Q_M(\log x)P,\quad 1\le x\le m,
\]
\[
 S_m=\sum_{n\le m}\Lambda(n)H_m(n),\qquad
 E(x)=\psi(x)-(x-1),\quad dE=d\psi-dx.
\]
Здесь \(H_m\) — вес в переменной \(x\), не затухающее ядро. Последнее обозначим \(\mathcal H_P\):
\[
 0\preceq\mathcal H_P\preceq4P,\qquad
 \int_1^m H_m(x)dx=-\mathcal H_P.
\]
Следовательно, **полная** исходная форма равна
\[
 \boxed{S_m=-\mathcal H_P+\int_{[1,m]}H_m(x)\,dE(x).}\tag{1.1}
\]
В частности, вторая часть — тот же совместный интеграл \(\int b_m\rho_c\) из Q09. Работа в физической переменной не расширяет точный класс достижимых плотностей.

Арифметика всюду буквальна:
\[
 \Lambda(n)=\sum_{d\mid n}\mu(d)\log(n/d),\qquad
 \Lambda(p^a)=\log p.
\tag{1.2}
\]
Сначала объединяются настоящие делители, а не их модули. Верхний атом \(n=m\), когда он простая степень, сохраняется с точным значением \(Q_M(L)=0\).

Все матричные равенства сохраняют каждую пару исходных Fourier-мод. Не используется ни \(\operatorname{Tr}(WB_d)\operatorname{Tr}(WB_e)=\operatorname{Tr}(WB_dB_e)\), ни удаление промежуточного проектора, ни замена нормы локальных координат евклидовой нормой.

## 2. Край: что действительно гладко, а что нет

### 2.1. Нельзя применять высокий порядок через исходное продолжение нулём

**[FINITE_CELL | PAPER — принятый тест, его следствие выписано явно.]** Пусть
\[
 q_c(s)=c^*Q_M(s)c.
\]
Для исходного допустимого sine-вектора из пакета \(a=f'(0)=-3(2\pi/L)^3\ne0\). Тогда
\[
 q_c(L-u)=-\frac{|a|^2}3u^3+O_m(u^4),
\]
\[
 c^*H_m(m-z)c=-\frac{|a|^2}{3m^{7/2}}z^3+O_m(z^4).
\tag{2.1}
\]
Третья производная слева в \(m\) равна \(2|a|^2/m^{7/2}\), а справа у нулевого продолжения она нулевая. Это \(C^2\), но не \(C^3\) в общем случае. Дополнительного исходного условия \(f'(0)=0\) нет.

На кубическом nullspace остаётся положительный пятый порядок другого настоящего вектора. Поэтому нельзя просто удалить весь край по отрицательности кубического члена.

**Точный planted-control высокого порядка.** Для локальной модели \(w(t)=(m-t)_+^3\), порядка \(k=4\) и \(t=m+h/2\):
\[
 \mathcal B_{4,h}w(t)=-\frac{71}{768}h^3,\qquad w(t)=0.
\tag{2.2}
\]
Следовательно, ошибка не имеет универсального порядка \(h^4\). Модель проверяет Taylor-перенос; source-неприменимость уже устанавливает настоящий вектор (2.1). При необходимости модель можно обрезать вдали от указанного края, не меняя расчёт.

### 2.2. Внутренние производные имеют правильную полосу и не платят размерностью

**Лемма 1 [FINITE_CELL | PAPER].** Для каждого фиксированного целого \(r\ge0\), внутри \(1<x<m\), при \(L\ge4\):
\[
 \boxed{\|H_m^{(r)}(x)\|\le q_r A^r x^{-r-1/2},
 \qquad q_r=(4+2r)(r+1)^r.}\tag{2.3}
\]
Для \(r=0\) также используем более точное \(\|H_m(x)\|\le2/\sqrt x\).

**Доказательство.** Для конечной Hilbert-матрицы \(\mathsf H_{j\ell}=1/(j-\ell)\), с нулевой диагональю, \(\|\mathsf H\|\le\pi\). Это сжатие свёртки на \(\mathbb Z\) с Fourier-множителем \(i(\pi-\theta)\), \(0<\theta<2\pi\); можно сначала взять Abel-регуляризацию.

Буквальное ядро удовлетворяет
\[
 Q_M(s)=\operatorname{diag}(2(1-s/L)\cos\omega_js)
 -\pi^{-1}[\operatorname{diag}(\sin\omega_js),\mathsf H].
\]
При \(r\ge1\):
\[
 \|Q_M^{(r)}(s)\|\le4\Omega^r+(2r/L)\Omega^{r-1}
 \le(4+2r)A^r.
\]
Кроме того,
\[
 H_m^{(r)}(x)=x^{-r-1/2}P
 \prod_{\nu=0}^{r-1}(\partial_s-\nu-1/2)
 Q_M(s)P\big|_{s=\log x}.
\]
Сумма абсолютных коэффициентов последнего полинома с весом \(A\) равна
\(\prod_{\nu=0}^{r-1}(A+\nu+1/2)\le(r+1)^rA^r\).
Это даёт (2.3). Ни размерность, ни \(m\)-зависимая константа не спрятаны. ∎

Лемма действует **внутри** исходного интервала. Через нулевое продолжение в \(m\) она не применяется.

### 2.3. Полная верхняя цена последней оболочки

**[FINITE_CELL | PAPER; E2–E3 — вход пакета.]** Для единичного исходного \(c\), из \(f(0)=f(L)=0\):
\[
 |q_c(L-u)|\le\frac{(2M+1)\Omega^2}{3L}u^3,
\tag{2.4}
\]
поскольку \(|f(t)|\le\|f'\|_\infty |t|\) у обоих концов,
\(\|f'\|_\infty^2\le(2M+1)\Omega^2/L\), и
\(2\int_0^u t(u-t)dt=u^3/3\).

Для дискретного **верха**, сохраняя отрицательный кубический кредит, используется именно
\[
 P Q_M(L-u)P\preceq\frac{3(2M+1)\Omega^4}{80L}u^5P.
\tag{2.5}
\]

Пусть \(0\le e_m(x)\le1\) поддержан в \([m-2d_0,m]\). Обозначим
\[
 \delta=d_0/m,\qquad u_0=-\log(1-2\delta)\le4\delta
 \quad(\delta\le1/4),\quad u_0\le1.
\]
Тогда полный **центрированный** край имеет верхнюю цену
\[
 \int e_m(x)H_m(x)dE(x)\preceq e_{\rm edge}P,
\tag{2.6}
\]
\[
 \boxed{\begin{aligned}
 e_{\rm edge}={}&
 \frac3{80}e^{u_0/2}(2M+1)\Omega^4u_0^5
       (\sqrt m\,u_0+m^{-1/2})\\
 &+\frac{(2M+1)\Omega^2}{12L}\sqrt m\,u_0^4.
 \end{aligned}}\tag{2.7}
\]
Первая строка получается из (2.5), \(\Lambda(n)\le L\) и подсчёта **всех** целых в оболочке. Она остаётся верной с весом \(e_m\), поскольку применяется поатомный верхний конверт, а не ошибочное сравнение двух знаковых сумм.

Вторая строка — обязательный возврат удалённой **непрерывной** части. Подстановка \(x=me^{-u}\) в интеграл абсолютной (2.4) даёт
\[
 \int_{m-2d_0}^m\|H_m(x)\|dx
 \le\frac{(2M+1)\Omega^2}{3L}\sqrt m\int_0^{u_0}u^3du.
\]
Обрезанный непрерывный оператор не назван полным \(-\mathcal H_P\).

Берём
\[
 \boxed{\kappa=1/8+\epsilon,\quad \delta=m^{-\kappa},
 \quad d_0=m^{1-\kappa}.}\tag{2.8}
\]
Три степенные цены (2.7), на исходном расписании:
\[
 \begin{array}{c|c}
 \text{дискретная объёмная}&-1/4-\epsilon\quad\text{с }L^{-4}\\
 \text{дискретный целочисленный край}&-9/8\quad\text{с }L^{-4}\\
 \text{непрерывная кубическая}&-\epsilon\quad\text{с }L^{-3}.
 \end{array}\tag{2.9}
\]
В частности, весь последний край имеет \(o(1)\) **верхний** бюджет. Норма всего края из одной E3 не утверждается.

## 3. Геометрическое разбиение без пропавших cutoff-производных

**[FINITE_CELL | PAPER — явная конструкция.]** Фиксируем \(k\ge1\) и
\[
 0<\gamma<\min(1-\epsilon,1-\kappa),\qquad
 Y=8k A m^\gamma.
\tag{3.1}
\]
Работаем на позднем диапазоне, где
\[
 L\ge4,\quad 2Y+2d_0<m,\quad d_0\ge8k m^\gamma,
 \quad u_0\le1.
\tag{3.2}
\]
Каждое из этих условий наступает при фиксированных допустимых параметрах.

### 3.1. Отсечка задана формулой, а не словом «гладкая»

Пусть \(p=2k\) и
\[
 \Theta_k(v)=\frac{(2p+1)!}{(p!)^2}
   \int_0^v t^p(1-t)^pdt\quad(0\le v\le1).
\]
Определим
\[
 \zeta_k(u)=\begin{cases}
 0,&u\le1,\\ \Theta_k(u-1),&1<u<2,\\1,&u\ge2.
 \end{cases}
\tag{3.3}
\]
Она неубывает, лежит в \([0,1]\), имеет класс \(C^{2k}\), и все производные порядков \(1,\ldots,2k\) согласуются с нулём у двух стыков. Именно \(C^k\) нужно далее; \(C^\infty\) исходного ядра через \(m\) не предполагается.

Для \(r\le k\) положим \(a_0=1\), а \(a_r\) — любую вычисленную из этого полинома верхнюю границу \(\|\zeta_k^{(r)}\|_\infty\). Например, сумма модулей коэффициентов его r-й производной на \([0,1]\) подходит. Все \(a_r\) зависят лишь от фиксированного \(k\).

### 3.2. Оба семейства оболочек и точная сумма весов

Пусть
\[
 X_i=2^iY,\quad d_j=2^jd_0\qquad(i,j\ge0),
\]
\[
 \phi_i(x)=\zeta_k(x/X_i)-\zeta_k(x/(2X_i)),
\]
\[
 \chi_j(x)=\zeta_k((m-x)/d_j)-\zeta_k((m-x)/(2d_j)).
\]
Оба веса неотрицательны. Их поддержки лежат соответственно в
\([X_i,4X_i]\) и \([m-4d_j,m-d_j]\).

Суммируем лишь непустые пересечения
\[
 I_{ij}=[\max(X_i,m-4d_j),\ \min(4X_i,m-d_j)]
\tag{3.4}
\]
положительной длины; обозначим множество индексов через \(\mathcal I_m\), его мощность — \(N_m\). Положим
\[
 w_{ij}(x)=\phi_i(x)\chi_j(x)H_m(x)
\tag{3.5}
\]
на поддержке и ноль вне её.

Нижний и верхний несглаживаемые веса:
\[
 \ell_m(x)=1-\zeta_k(x/Y),\qquad
 e_m(x)=1-\zeta_k((m-x)/d_0).
\]
Из (3.2) их переходные области не пересекаются. Телескопирование даёт, **во всём \([1,m]\)**,
\[
 \boxed{1=\ell_m(x)+e_m(x)+\sum_{(i,j)\in\mathcal I_m}
             \phi_i(x)\chi_j(x).}\tag{3.6}
\]
Вне исходного окна эта формула не используется для источника. В \(x=m\) верхний вес равен единице, а исходная матрица атома нулевая.

Непустое пересечение требует \(m\le4(X_i+d_j)\). Поэтому хотя бы один из двух масштабов не меньше \(m/8\). В каждом семействе таких крупных масштабов не более четырёх. Отсюда, например,
\[
 \boxed{N_m\le8(2+\log_2m).}\tag{3.7}
\]
Это не квадрат числа оболочек и не множитель размера Fourier-полосы.

### 3.3. Все производные отсечек включены

Обозначим
\[
 r_{ij}=\min(X_i/A,d_j),\qquad
 \lambda_{ij}=|I_{ij}|\le3\min(X_i,d_j).
\]
Из (2.3) и полного правила Лейбница:
\[
 \boxed{
 \|w_{ij}^{(k)}\|_\infty
 \le C_k^{\rm cut}X_i^{-1/2}r_{ij}^{-k},
 }
\tag{3.8}
\]
где можно взять явную конечную константу
\[
 C_k^{\rm cut}=4\sum_{r+s+t=k}\frac{k!}{r!s!t!}a_ra_sq_t.
\tag{3.9}
\]
Действительно, производные двух отсечек стоят не больше
\(2a_rX_i^{-r}\), \(2a_sd_j^{-s}\), а производная H —
\(q_t A^tX_i^{-t-1/2}\). Каждая обратная длина не превосходит \(r_{ij}^{-1}\). Ничего не удалено под предлогом «низкого ранга» или «малой поддержки».

Кроме того,
\[
 \boxed{
 \left(\int_{I_{ij}}\|w_{ij}(x)\|^2dx\right)^{1/2}
 \le2\sqrt{\lambda_{ij}/X_i}
 \le\sqrt{12\min(X_i,d_j)/X_i}.
 }
\tag{3.10}
\]
Это именно выигрыш длины оболочки, предложенный в запросе.

Каждый \(w_{ij}\), продолженный нулём, принадлежит \(C^k(\mathbb R)\): он отделён от \(x=1,m\), а его собственные края имеют нужные нулевые производные. Негладкий исходный jet в \(m\) не пересекается.

## 4. Signed Richardson: точное сглаживание и полный возврат

**[FINITE_CELL | PAPER.]** Пусть
\[
 \alpha_j=(-1)^{j+1}\binom kj,\quad1\le j\le k,
\]
\[
 \mathcal A_hw(t)=\frac1h\int_{t-h}^t w(x)dx,
 \qquad \mathcal B_{k,h}w=\sum_{j=1}^k\alpha_j\mathcal A_{jh}w.
\]
Точные моменты:
\[
 \sum_j\alpha_j=1,\qquad
 \sum_j\alpha_jj^r=0\ (1\le r<k),\qquad
 \sum_j\alpha_jj^k=(-1)^{k+1}k!.
\tag{4.1}
\]
По Taylor с интегральным остатком,
\[
 \boxed{\|w-\mathcal B_{k,h}w\|_\infty
 \le T_kh^k\|w^{(k)}\|_\infty,
 \quad T_k=\frac1{(k+1)!}\sum_{j=1}^k|\alpha_j|j^k.}
\tag{4.2}
\]
Знаки \(\alpha_j\) сохранены в равенстве; модуль используется только в доказанной цене ошибки. \(\mathcal B\) не является положительным средним.

Определим **нормированный совместный прирост**
\[
 \boxed{\mathcal R_{k,h}E(x)=
 \sum_{j=1}^k\frac{\alpha_j}{jh}
            [E(x+jh)-E(x)].}\tag{4.3}
\]
Точный Fubini-return:
\[
 \boxed{\int\mathcal B_{k,h}w(t)dE(t)
       =\int w(x)\mathcal R_{k,h}E(x)dx.}\tag{4.4}
\]
При фиксированных носителях обе стороны конечны; это равенство для знаковой меры, а не вероятностный аргумент.

### 4.1. Законная ширина для каждой оболочки

Берём
\[
 \boxed{h_{ij}=\frac{m^{-\gamma}}{8k}
                \min(X_i/A,d_j).}\tag{4.5}
\]
Каждая \(h_{ij}\) постоянна по переменной интегрирования x внутри своего куска; формула с переменной шириной без Jacobian здесь не применяется. По (3.2), \(h_{ij}\ge1\). Для каждого \(1\le j'\le k\):
\[
 j'h_{ij}\le X_i/8,\qquad j'h_{ij}\le d_j/8.
\tag{4.6}
\]
Сглаживание \(\mathcal A_{j'h}\) сдвигает поддержку вправо не больше чем на \(j'h\). Поэтому
\[
 \sup\operatorname{supp}(\mathcal B_{k,h_{ij}}w_{ij})
 \le m-d_j+kh_{ij}\le m-7d_j/8<m.
\tag{4.7}
\]
И нижняя поддержка остаётся выше 1. **Ни один будущий атом здесь не появляется.** Это доказано точными неравенствами, а не заявлено на основании малого \(h/m\). В частности, все аргументы \(x+j'h_{ij}\), встречающиеся с ненулевым весом в (4.4), меньше \(m\).

Если использовать иную ширину, будущие атомы обязаны остаться в обеих сторонах возврата. Проверяющий содержит конкретный контроль: при \(m=16\), весе на \([12,15]\) и \(h=4\) сглаживание активирует настоящий простой атом 17. Его коэффициент сокращается с коррекцией, но не может быть удалён только из сглаженной части.

### 4.2. Реконструкция всей внутренней части

Сумма вариаций \(d\psi+dx\) на \([X_i,4X_i+kh_{ij}]\) не больше \(20X_i\), по \(\psi(5X_i)\le15X_i\). Поэтому
\[
 \left\|\int(w_{ij}-\mathcal B_{k,h_{ij}}w_{ij})dE\right\|
 \le C_k^{\rm ret}\sqrt{X_i}\,m^{-k\gamma},
\tag{4.8}
\]
\[
 C_k^{\rm ret}=20T_k C_k^{\rm cut}(8k)^{-k}.
\]
Суммируя **все** части:
\[
 \boxed{\|\mathfrak R_m\|\le
 C_k^{\rm ret}N_m\sqrt m\,m^{-k\gamma},}
\tag{4.9}
\]
где \(\mathfrak R_m=\sum\int(w-\mathcal Bw)dE\). Это полный оплаченный остаток, не предположение о его знаке.

Нижняя часть имеет отдельную конечную цену:
\[
 \boxed{\left\|\int\ell_mH_m\,dE\right\|
       \le16\sqrt{2Y}.}\tag{4.10}
\]
Здесь \(\sum_{n\le x}\Lambda(n)/\sqrt n\le6\sqrt x\),
\(\|Q\|\le2\), и весь непрерывный интеграл нижнего участка включён. В \(x=1\) не выполнялось искусственное продолжение H нулём для Taylor.

## 5. Полная аналитическая теорема — без арифметической предпосылки

Определим явную **сглаженную арифметическую матрицу**
\[
 \boxed{\mathfrak A_{k,m}=
 \sum_{(i,j)\in\mathcal I_m}
 \int_{I_{ij}}w_{ij}(x)\,
           \mathcal R_{k,h_{ij}}E(x)dx.}\tag{5.1}
\]
Это не новый оператор производства: он входит в точный возврат исходного S. Внутри каждой \(w\) остаются исходный \(P\) и вся матрица \(Q\); сумма по оболочкам сначала сохраняется со знаком.

**Теорема 2 [COFINAL_FAMILY | PAPER, без RH/ZF78/variance input].** При явно указанных (3.2):
\[
 S_m=-\mathcal H_P+\mathfrak A_{k,m}
 +\mathfrak R_m+\int\ell_mH_m\,dE+\int e_mH_m\,dE,
\tag{5.2}
\]
и
\[
 \boxed{
 S_m\preceq\mathfrak A_{k,m}-\mathcal H_P+
 \left[16\sqrt{2Y}+e_{\rm edge}
 +C_k^{\rm ret}N_m\sqrt m\,m^{-k\gamma}\right]P.
 }\tag{5.3}
\]
**Доказательство:** (1.1), точная partition (3.6), Fubini (4.4), затем (2.7), (4.9), (4.10). Никакой части полного непрерывного источника не заменяли \(-\mathcal H_P\) отдельно: это равенство было применено только к **полному** интегралу в (1.1). ∎

Это закрывает конкретный аналитический дефект пакета: **не нужны ни бесконечная гладкость нулевого продолжения, ни неоплаченные cutoff derivatives, ни выброшенный непрерывный край.** Но сама (5.3) не оценивает арифметику (5.1) новой степенью.

Для любого настоящего \(W=PWP\succeq0\) тот же результат получается взятием следа. Его константы едины по W. Нет выбора отдельного масштаба \(m(W)\), перестановки адаптивного максимума со средним или добавления лишней размерностной цены.

## 6. Какой именно арифметический вход потребляется и что он дал бы

### 6.1. Точная достаточная дисперсия — не cumulative \(J_E\)

**[COFINAL_FAMILY | CONDITIONAL — гипотеза только в этой секции.]** Достаточно, чтобы на всех использованных пересечениях и ширинах выполнялось
\[
 \boxed{
 \mathcal J_{ij}:=\int_{I_{ij}}
       |\mathcal R_{k,h_{ij}}E(x)|^2dx
 \le C_{\rm var}\frac{X_i}{h_{ij}}L^2.
 }\tag{SV}
\]
\(C_{\rm var}\) может зависеть от фиксированных \(\epsilon,k,\gamma\), но не от \(m,i,j\). **(SV) здесь не доказана.**

Это нормированный **совместный** прирост с одним знаковым Richardson-ядром, а не \(\int|E(x)|^2dx\). Полная смешанная арифметика разных ширин включена в квадрат.

Более сильный обычный вход
\[
 \int_{X}^{4X}|E(x+a)-E(x)|^2dx\le C\,aX\log^2(5X)
\tag{6.1}
\]
для всех требуемых \(a=j'h_{ij}\) поставлял бы (SV) по Minkowski, с множителем
\(\bigl(\sum_{j'=1}^k|\alpha_{j'}|/\sqrt{j'}\bigr)^2\).
Этот переход не предполагает независимости ширин. (6.1) достаточна, но не обязательна; она тоже **не объявляется безусловно установленной**.

### 6.2. Суммирование оболочек не портит показатель

Из (3.10) и (SV):
\[
 \left\|\int_{I_{ij}}w_{ij}\mathcal R_{k,h_{ij}}E\right\|
 \le\sqrt{12C_{\rm var}\min(X_i,d_j)/h_{ij}}\,L.
\]
Но
\[
 \frac{\min(X_i,d_j)}{\min(X_i/A,d_j)}\le A.
\]
Поэтому
\[
 \boxed{\|\mathfrak A_{k,m}\|
 \le N_m\sqrt{96k C_{\rm var} A}\,m^{\gamma/2}L.}
\tag{6.2}
\]
Это и есть \(\sqrt{d/h}\)-цена возле верхнего края, а не ошибочная \(\sqrt{m/h}\) для каждой короткой оболочки.

Вместе с теоремой 2 получен **полный условный** конверт:
\[
 \boxed{\begin{aligned}
 S_m\preceq\bigl[&16\sqrt{2Y}+e_{\rm edge}
 +C_k^{\rm ret}N_m m^{1/2-k\gamma}\\
 &+N_m\sqrt{96k C_{\rm var}A}\,m^{\gamma/2}L\bigr]P
 -\mathcal H_P.
 \end{aligned}}\tag{6.3}
\]
Все ранние блоки и оба верхних возврата здесь присутствуют. Не требуется оплачивать дополнительно хвост частотной плотности: ни частотного усечения, ни замены плотности в этом доказательстве нет.

### 6.3. Оптимальный показатель именно этого бюджета

На исходной полосе \(A=O(m^\epsilon/L)\) позднее, \(N_m=O(L)\). Два существенных показателя (6.3):
\[
 \frac{\epsilon+\gamma}{2},\qquad \frac12-k\gamma.
\]
Первый также оплачивает нижний блок \(Y\); край из (2.9) убывает. Баланс достигается при
\[
 \boxed{\gamma=\frac{1-\epsilon}{2k+1},\qquad
 \eta_0(k,\epsilon)=\frac1{4k+2}+\frac{k\epsilon}{2k+1}.}\tag{6.4}
\]
Эта \(\gamma\) удовлетворяет ограничениям (3.1) для каждого \(k\ge1\) в указанном диапазоне \(\epsilon\).

При **(SV)** доказано, например,
\[
 S_m\preceq C_{\epsilon,k,\rm var}m^{\eta_0}(1+L)^2P.
\tag{6.5}
\]
Логарифмический конверт намеренно консервативен. Скрытого фактора \(m^{c\epsilon k}\) сверх выписанного бюджета нет; \(C_k^{\rm cut}\), \(T_k\) могут быть очень большими, но k фиксирован.

Для \(k=1\) получается \(1/6+\epsilon/3\), как в preflight. Для
\[
 k=\lceil1/\epsilon\rceil
\]
имеем \(\eta_0<3\epsilon/4\). Поглощая фиксированную степень логарифма оставшимся \(\epsilon/4\), получаем условное
\[
 \boxed{S_m\preceq C_\epsilon m^\epsilon P.}\tag{6.6}
\]
**(6.6) — не новый доказанный арифметический выигрыш:** оно зависит от неустановленной (SV). Успех аналитического возврата отделён от этой зависимости.

## 7. Арифметическая попытка: настоящий совместный прирост и его корреляции

Далее (SV) **снимается**. Проверяем, что действительно можно доказать для \(\Lambda=\mu*\log\), не подставляя искомую малость.

### 7.1. Одно signed-ядро, все коэффициенты и все ширины

Для фиксированных k,h положим
\[
 K_{k,h}(u)=\sum_{j=1}^k\frac{\alpha_j}{jh}
              \mathbf1_{0<u\le jh}.
\tag{7.1}
\]
Точно
\[
 \int K_{k,h}=1,\qquad
 \int u^rK_{k,h}(u)du=0\quad(1\le r<k).
\tag{7.2}
\]
Но \(K\) знакопеременно при \(k\ge2\). Например, при k=2 оно равно
\(3/(2h)\) на \((0,h]\) и \(-1/(2h)\) на \((h,2h]\).

Для настоящего E:
\[
 \boxed{\mathcal R_{k,h}E(x)
 =\sum_n\Lambda(n)K_{k,h}(n-x)-1
 =\sum_{db}\mu(d)\log b\,K_{k,h}(db-x)-1.}\tag{7.3}
\]
Суммы конечны на каждой используемой области; все произведения \(db\) сохраняются. Никакой случайной модели или независимости \(\mu\) не введено.

Для I=[a,b] обозначим
\[
 \omega_I(n)=\sum_{j=1}^k\frac{\alpha_j}{jh}
 [\min(b,n)-\max(a,n-jh)]_+,
\]
\[
 \omega_I(n,r)=\sum_{j,l=1}^k\frac{\alpha_j\alpha_l}{jl h^2}
 [\min(b,n,r)-\max(a,n-jh,r-lh)]_+.
\tag{7.4}
\]
Тогда **полная** дисперсия равна
\[
 \boxed{
 \mathcal J_{k,h}(I)=
 \sum_{n,r}\Lambda(n)\Lambda(r)\omega_I(n,r)
 -2\sum_n\Lambda(n)\omega_I(n)+|I|.
 }\tag{7.5}
\]
В \(\Lambda(n)\Lambda(r)\) при раскрытии Мёбиуса остаются все
\(\mu(d)\mu(e)\log(n/d)\log(r/e)\), \(d\mid n,e\mid r\).
Все сдвиги \(n-r\), совпадения, высшие простые степени и обрезанные overlap-интервалы присутствуют. Это не произведение двух отдельного вида следов.

Ни \(\omega_I(n,r)\), ни произведение двух signed-сглаживаний не считается положительным поэлементно. При k=2 уже
\[
 \int K_{2,h}(u)K_{2,h}(u+3h/2)du=-\frac3{8h}.
\tag{7.6}
\]
Именно такие межатомные знаки теряются при автоматической замене на положительное среднее.

### 7.2. Диагональ действительно имеет нужную цену, но не равна полной дисперсии

Положим
\[
 V_k=\sum_{j,l=1}^k\frac{\alpha_j\alpha_l}{\max(j,l)}
       =h\|K_{k,h}\|_2^2>0.
\]
На I⊂[X,4X], при kh≤X, все ненулевые n лежат ниже5X. Поэтому
\[
 \boxed{
 \sum_n\Lambda(n)^2\omega_I(n,n)
 \le15V_k\frac{X\log(5X)}h.
 }\tag{7.7}
\]
Использованы \(\Lambda(n)^2\le\log(5X)\Lambda(n)\) и
\(\psi(5X)\le15X\). Это настоящий арифметический расчёт диагонали.

Оставшаяся комбинация в (7.5) включает **все off-diagonal плюс оба mean-terms**. В Q10 не выведено, что она ограничена тем же \(X/h\)-масштабом. Выбрасывать её из-за общей неотрицательности \(\mathcal J\) нельзя.

### 7.3. Полная безусловная оценка, которая действительно получается

Пусть \(A_k^0=\sum|\alpha_j|=2^k-1\). При h≥1:
\[
 \sum_n|K_{k,h}(n-x)|
 \le\sum_{j=1}^k\frac{|\alpha_j|}{jh}(jh+1)
 \le2A_k^0,
 \qquad\|K_{k,h}\|_1\le A_k^0.
\]
Взвешенный Cauchy, затем интегрирование всей суммы, дают
\[
 \int_I\left|\sum_n\Lambda(n)K_{k,h}(n-x)\right|^2dx
 \le2(A_k^0)^2\sum_{n\le5X}\Lambda(n)^2
 \le30(A_k^0)^2X\log(5X).
\]
Следовательно, с возвратом обоих центрирующих членов,
\[
 \boxed{
 \mathcal J_{k,h}(I)
 \le66(A_k^0)^2X\log(5X).
 }\tag{7.8}
\]
Это полный, действительный, безусловный конверт; он **не** содержит нужного деления на h. Неравенство \(|z-1|^2\le2|z|^2+2\), использованное здесь, явно теряет компенсацию со средним, а Cauchy до него теряет знаки (7.6).

На геометрическом разбиении сумма \(\sum\sqrt{|I_{ij}|}\le48\sqrt m\): разделяем индексы по \(X_i\ge m/8\) либо \(d_j\ge m/8\), затем суммируем геометрические ряды квадратных корней. Из (3.10),(7.8):
\[
 \boxed{\|\mathfrak A_{k,m}\|
 \le800(2^k-1)\sqrt{m\log(5m)}.}\tag{7.9}
\]
Поэтому (5.3), с действительно поставленным входом, остаётся на степени \(1/2\), с логарифмом. Прямой прежний \(12\sqrt m\) сильнее. **Никакой full gain из оплаты диагонали (7.7) не заявляется.**

Это первая неподтверждённая арифметическая строка выбранного механизма: перейти от полного (7.5) к цене (SV), либо доказать более слабую направленную оценку его настоящего спаривания (5.1), без потери знака. Такая направленная оценка в этой работе тоже не получена.

## 8. Не скрыта ли RH в предлагаемом входе?

### 8.1. Проверенные внешние источники не поставляют безусловный вход

**[ABSTRACT | PAPER — source mapping.]** В Brent–Platt–Trudgian, *The mean square of the error term in the prime number theorem*, верхняя оценка \(I(X)=\int_X^{2X}(\psi(x)-x)^2dx\) в Theorem1 явно предполагает RH. Она к тому же относится к **cumulative** ошибке, не к (7.5).

Cully-Hugill–Dudek, *An explicit mean-value estimate for the PNT in intervals*, также явно предполагает RH в своём основном сильном mean-square результате. Его формулировка использует относительные интервалы и \(\theta\); её нельзя без отдельного переноса объявлять безусловной аддитивной оценкой для нашей \(\psi\).

Эти сверки показывают область конкретных источников. Они не являются утверждением о полном отсутствии других работ. В новое доказательство их условные верхние границы не импортированы.

### 8.2. Отдельная Mellin-проверка силы нормированной signed variance

**Теорема 3 [ABSTRACT | PAPER — условная импликация, не доказательство предпосылки].** Пусть фиксированы \(0<q<1\), целое k≥1. Для всех достаточно больших dyadic X положим
\[
 h_X=\frac{X^{1-q}}{8k}.
\]
Предположим для настоящего E, что
\[
 \int_X^{4X}|\mathcal R_{k,h_X}E(x)|^2dx
 \le C X^q(1+\log X)^B.
\tag{8.1}
\]
Тогда нет нетривиальных нулей дзета в полуплоскости
\[
 \boxed{\Re s>
 \tau_{k,q}:=\max\left(\frac{1+q}{2},\,1-kq\right).}
\tag{8.2}
\]

**Доказательство.** Возьмём гладкую до порядка k dyadic partition \(\varphi_X\), поддержанную в [X,4X], и для комплексного s вес
\(v_{X,s}(x)=\varphi_X(x)x^{-s}\). На каждом компакте по s:
\[
 \|v_{X,s}\|_2\le C X^{1/2-\sigma},\qquad
 \|v_{X,s}^{(k)}\|_\infty\le C_{k,s}X^{-k-\sigma},
 \quad\sigma=\Re s.
\]
Тот же **доказанный** Richardson/Fubini-return даёт
\[
 \int v_{X,s}\,dE
 =\int v_{X,s}\mathcal R_{k,h_X}E\,dx
 +\int(v_{X,s}-\mathcal B_{k,h_X}v_{X,s})dE.
\]
По (8.1) первая часть имеет цену
\[
 C X^{(1+q)/2-\sigma}(1+\log X)^{B/2},
\]
а по элементарной полной массе вторая —
\[
 C_{k,s}X^{1-\sigma-kq}.
\]
Их dyadic сумма сходится локально равномерно и голоморфна при \(\sigma>\tau_{k,q}\). Начальный компактный диапазон даёт целую функцию. В \(\sigma>1\), где допустима абсолютная Dirichlet-сборка, сумма равна
\[
 \int_1^\infty x^{-s}dE(x)
 =-\frac{\zeta'}{\zeta}(s)-\frac1{s-1}.
\tag{8.3}
\]
Значит, правая часть имеет голоморфное продолжение в указанную полуплоскость. Любой нуль \(\zeta\) там породил бы неустранимый полюс её логарифмической производной. Вычитание \(1/(s-1)\) удаляет только известный полюс в1. Это доказывает (8.2). Никакой контур через неизвестные нули не сдвигался с выбрасыванием residues. ∎

Если \(kq\ge(1-q)/2\), граница равна \((1+q)/2\). Семейство таких оценок при фиксированных \(q\downarrow0\), с соответствующими фиксированными k, влечёт RH по функциональной симметрии. Это проверка именно **signed normalized increments**, не подмена их старым \(J_E\).

(8.1) — более широкая чистая dyadic формулировка, чем минимальный список пересечений (SV). Эквивалентность каждой отдельной (SV) этой широкой гипотезе не утверждается. Однако семейство **самих (SV)** при \(k=\lceil1/\epsilon\rceil\) тоже влечёт RH: теорема2 и §6 дают \(PK_mP\succeq-C_\epsilon m^\epsilon P\), а принятый sparse witness противоречит этому при \(\epsilon<\Re\rho-1/2\). Это условная логическая сила, не поставленная оценка и не доказательство RH.

**Важно:** RH-сила не делает гипотезу ложной или запрещённой исследовательской целью. Она запрещает только пользоваться ею как уже известным независимым лёгким входом. Конечная проверка одной ячейки и неограниченный all-X/receiver-квантор различаются.

### 8.3. Отличающий проверяемый тест: что Richardson делает с медленной ошибкой

Для фиксированного комплексного z и модели \(E_z(x)=x^z-1\), при kh≤X/8:
\[
 \boxed{\mathcal R_{k,h}E_z(x)
 =z x^{z-1}+O_{z,k}(h^kX^{\Re z-k-1}),
 \qquad X\le x\le4X.}\tag{8.4}
\]
Это непосредственный Taylor-расчёт с (4.1). В частности, коэффициент ведущей производной равен **одному**. При вещественном \(1/2<\beta<1\), \(h=X^{1-q}/(8k)\):
\[
 \int_X^{2X}|\mathcal R_{k,h}E_\beta(x)|^2dx
 \asymp_{\beta,k}X^{2\beta-1}.
\tag{8.5}
\]
Поэтому высокий порядок не превращает любую медленную ошибку в \(X/h\)-variance: при \(\beta>(1+q)/2\) (8.1) для этой модели ложна.

Эта модель — **не настоящая \(\mu\) и не контрпример CCM**. Она отсекает лишь автоматический довод «много отменённых моментов \(\Rightarrow\) слабый арифметический вход». Отменённые моменты относятся к **возврату веса**; ведущий низкочастотный компонент источника сохранён.

## 9. Полный возврат: отдельно фактический и условный результаты

Для любого **доказанного** верхнего бюджета \(S_m\preceq s_mP\):
\[
 \boxed{T_{>R}\preceq s_mP-T_{\le R},\qquad
 PK_mP\succeq D_m-s_mP,\quad\|D_m\|\le50L+8.}\tag{9.1}
\]
Скалярный контракт T добавляет
\[
 b_{\rm small}=(56+32\Omega)\sqrt R+12(1+\log R)^2
\]
**ровно один раз**. Прямой контракт K не добавляет короткую цену: она сокращается алгебраически в исходной сборке S.

Для отдельного \(V=C+E_{\rm slow}\), только когда нужен этот объект:
\[
 V\preceq(s_m+F_2)P-T_{\le R},
\]
\[
 F_2=32(1+D_1)N_D(1+2L)+\frac{\mathfrak K_2}{\pi^2m^{3/2}},
\]
\[
 D_1=2/L+4\Omega,\quad D_2=4\Omega/L+4\Omega^2,
 \quad\mathfrak K_2=16/3+20D_1/9+4D_2/9,
 \quad N_D=\lceil\log_2(m/R)\rceil.
\]
F₂ не начисляется прямому доказательству S/K и не оплачивает саму арифметическую (SV).

| Шаг | Доказанная цена / статус | Полный показатель |
|---|---|---:|
| Последний центрированный край | (2.7), включая непрерывный кубический вклад | Убывает: главный \(-\epsilon\) |
| Нижний блок | \(16\sqrt{2Y}\) | \((\epsilon+\gamma)/2\) |
| Все отсечки и реконструкция | \(C_kN_m\sqrt m\,m^{-k\gamma}\) | \(1/2-k\gamma\) |
| Арифметическая часть при **непоставленной (SV)** | (6.2) | \((\epsilon+\gamma)/2\) |
| Полная условная теорема | (6.3)–(6.5) | \(\eta_0=(1+2k\epsilon)/(4k+2)\) |
| Условно, \(k=\lceil1/\epsilon\rceil\) | После явного логарифмического запаса | Direct S/K: \(\epsilon\); scalar T: \(3\epsilon/2\) |
| **Действительно полученная арифметика** | (7.8), (7.9), все mixed terms оплачены грубо | \(1/2\), логарифмы |
| Более сильный прежний elementary source bound | \(S\preceq12\sqrt mP\) | \(1/2\) |
| Лучший принятый Q03 | \(O_\epsilon(m^{3/8}\log m)\), **ZF78** | \(3/8\), без изменения |

Следовательно, без (SV) наиболее сильный здесь предъявленный безусловный исходный возврат остаётся прежним:
\[
 \boxed{PK_mP\succeq-[12\sqrt m+50L+8]P.}\tag{9.2}
\]
Нового общего кофинального масштаба с малой степенью не получено. Если бы (SV) была доказана только на неограниченном наборе исходных m, общем для всех векторов, аналитический перенос действовал бы на нём; такой набор не установлен. Полный SP и его дополнение не заменены этим отдельным restricted receiver.

## 10. Содержательный откат и граница текущей попытки

**Сильнейшее возражение:** «Ты доказал хороший аналитический перенос из гипотезы, но не доказал саму гипотезу». **Верно.** Поэтому Q10 закрывает краевой/геометрический долг предлагаемого переноса, а не арифметический долг исходной CCM.

Первая потеря, которую имеет смысл отменить, — **Cauchy в §6.2**, превращающий направленное спаривание \(\int w\mathcal R E\) в независимую абсолютную variance источника. Эта variance уже слишком сильна, чтобы считаться бесплатным входом. Возвращаться к дефектному глобальному Taylor через m не нужно: его корректный ремонт теперь есть.

Обоснованный откат — сохранить **одну совместную сумму (5.1)** с настоящими \(w_{ij}\), знаками Richardson и всеми её ширинами **до** независимой оценки \(\mathcal J_{ij}\). Это не объявление (5.1) новым поставщиком. Нового направленного арифметического аргумента для неё здесь не получено, и автоматический следующий запрос «докажи (5.1)» не предлагается.

**Отличающий тест для следующего конкретного аргумента:** сначала вычислить его действие на \(E_z=x^z-1\) посредством (8.4), с полным возвратом исходного веса. Если аргумент обещает степенное сокращение только из порядка k, он обязан объяснить, куда законно делся ненулевой ведущий \(zx^{z-1}\). Если он доказывает универсальную норму источника, применить Mellin-тест §8.2 и явно назвать полученную zero-free силу. Если же он использует свойства настоящей \(\mu\), указать точную строку, неверную для этой контрольной модели. Это различает новый арифметический факт и повторную оптимизацию гладкости.

Два представления **этой одной точки отката**, не две новые кампании:

| Представление | Сохраняемая информация | Различающая сила / цена |
|---|---|---|
| Полная \(\sum\int w_{ij}\mathcal R_{k,h_{ij}}E\), без Cauchy по источнику | Исходный P, все mixed modes, совместные ширины и направленный знак | Высокая против потери source-weight связи; малая цена exact algebra, арифметическая цена пока неизвестна |
| Mellin-тест того же локального сглаживания | Масса ядра1, полный логарифмический производный ряд и все потенциальные полюса | Высокая против скрытого RH-входа; малая аналитическая цена проверки, не самостоятельная оценка CCM |

Не разрешается расширять этот результат до «невозможности сглаживания», «невозможности actual cancellation» или смерти CCM. Ни один из таких выводов не доказан.

## 11. Проверки и различающие функционалы

**[FINITE_CELL | PAPER — точные локальные контроли.]** Выполнены **783** проверки стандартной библиотекой Python. Они охватывают:

* все требуемые jets выбранных полиномиальных отсечек, точную partition, реальные пределы её support-return и количество активных оболочек;

* planted cubic crossing, отрицательную часть signed kernel, будущий настоящий простой при небезопасной ширине, все итоговые степени.

**Чего эти проверки не доказывают:** (SV), асимптотику реальных prime correlations, спектр полной CCM, условный sparse witness. Больших prime sums, actual CCM spectral runs, Arb, Lean и независимого review не было. Никакой почти нулевой интервал не был принят как нуль.

Run: python3 check_q10.py
Place registration.json beside the script. No variable/path substitutions.
Not a Lean/Arb certificate, prime-correlation theorem, or CCM spectral run.

from fractions import Fraction as F
from collections import Counter
from math import comb, factorial
from pathlib import Path
import hashlib, json

counts=Counter()
def ck(ok,name):
    if not ok: raise AssertionError(name)
    counts[name]+=1

def alpha(k): return [(-1)**(j+1)*comb(k,j) for j in range(1,k+1)]
for k in range(1,13):
    aa=alpha(k)
    ck(sum(aa)==1,'Richardson_constant_reproduced')
    for r in range(1,k):
        ck(sum(a*j**r for j,a in enumerate(aa,1))==0,'cancelled_weight_moments')
    ck(sum(a*j**k for j,a in enumerate(aa,1))==(-1)**(k+1)*factorial(k),
       'first_uncancelled_moment')
    V=sum(F(a*b,max(j,l)) for j,a in enumerate(aa,1) for l,b in enumerate(aa,1))
    ck(V>0,'signed_kernel_L2_coefficient_positive')

    for r in range(1,k+1):
        x=F(7,3);h=F(1,5)
        got=sum(F(a,j)*((x+j*h)**r-x**r)/h for j,a in enumerate(aa,1))
        ck(got==r*x**(r-1),'slow_source_derivative_is_retained_not_annihilated')

def value(p,x):
    out=F(0)
    for c in reversed(p):out=out*x+c
    return out

def primitive(p):return [F(0)]+[c/F(i+1) for i,c in enumerate(p)]
def pmul(a,b):
    z=[F(0)]*(len(a)+len(b)-1)
    for i,x in enumerate(a):
        for j,y in enumerate(b):z[i+j]+=x*y
    return z

    p=2*k; C=F(factorial(2*p+1),factorial(p)**2)
    z=[F(0)]*(2*p+2)
    for j in range(p+1):z[p+j+1]=C*(-1)**j*comb(p,j)/F(p+j+1)
    return z

for k in range(1,9):
    p=theta_poly(k)
    ck(value(p,F(0))==0 and value(p,F(1))==1,'cutoff_normalization')
    for r in range(1,2*k+1):

for `M ≤ 1` — so the theorem is proved for every `M`.

## Proof (the verdict's, verbatim)

Expand the square termwise (`norm_sub_div_ofReal_sq`).  The `|c_n|²` term collects
into `B M n` (`sum_divPairs_curry`).  The `|c_{nd}|²` term is re-indexed by `j = n d`
(`sum_divPairs_reindex`) and uses `∑_{d ∣ j} Λ d = log j`
(`ArithmeticFunction.vonMangoldt_sum`); `d = 1` drops out because `Λ 1 = 0`
(`sum_vonMangoldt_ge_two`).  The mixed term is `−P_M(c)`.

## Corollaries

* `energy_nonneg` — (i), the right-hand side is `≥ 0`;
* `plant_energy_zero`, `plant_identity_zero`, `plant_doubled_edge_eq`,
  `plant_doubled_edge_neg` — (ii), the verdict's calibration plant `M = 2`,
  `c = (1, 1/√2)`: the right-hand side vanishes, and with the prime edge illegally
  doubled the left-hand side equals `−log 2 < 0`.  A checker that only tests
  Hermitian symmetry therefore does not certify the identity;
* `primeForm_le_diag`, `primeForm_le_max` — (iii) in diagonal and uniform form;
* `B_one_le`, `diagWeight_le`, `primeForm_le_log` — the verdict's `(B)`/`(PRIME)`
  with Mathlib's Chebyshev constant: `B(N) ≤ log N + (log 4 + 4)` and
  `P_M(c) ≤ (log M + (log 4 + 4)) ‖c‖²`.  The verdict's sharper `4 log 2` needs its
  own central-binomial run of `ψ`; Mathlib supplies `Chebyshev.psi_le_const_mul_self`
  with `(log 4 + 4)`, so that constant is what is proved here.  The step
  `∑_{j ≤ N} log j = ∑_{d ≤ N} Λ d ⌊N/d⌋` is not in Mathlib and is proved here
  (`sum_log_eq_sum_floor`) from the same divisor re-indexing.

Nothing in this file depends on any other Q3 module.
-/

/-- Pairs `(n, d)` with `n ≥ 1`, `d ≥ 2` and `n * d ≤ M`. -/
def divPairs (M : ℕ) : Finset (ℕ × ℕ) :=
  (Finset.Icc 1 M ×ˢ Finset.Icc 2 M).filter fun p => p.1 * p.2 ≤ M

/-- Pairs `(j, d)` with `1 ≤ j ≤ M`, `d ≥ 2` and `d ∣ j`. -/
def divisorPairs (M : ℕ) : Finset (ℕ × ℕ) :=
  (Finset.Icc 1 M ×ˢ Finset.Icc 2 M).filter fun p => p.2 ∣ p.1

lemma mem_divPairs {M : ℕ} {p : ℕ × ℕ} :
    p ∈ divPairs M ↔ 1 ≤ p.1 ∧ 2 ≤ p.2 ∧ p.1 * p.2 ≤ M := by
  constructor
  · intro h
    simp only [divPairs, Finset.mem_filter, Finset.mem_product, Finset.mem_Icc] at h
    exact ⟨h.1.1.1, h.1.2.1, h.2⟩
  · rintro ⟨h1, h2, h3⟩
    have hd1 : 1 ≤ p.2 := le_trans one_le_two h2
    have hn : p.1 ≤ p.1 * p.2 := by
      calc p.1 = p.1 * 1 := (mul_one _).symm
        _ ≤ p.1 * p.2 := Nat.mul_le_mul (le_refl _) hd1
    have hd : p.2 ≤ p.1 * p.2 := by
      calc p.2 = 1 * p.2 := (one_mul _).symm
        _ ≤ p.1 * p.2 := Nat.mul_le_mul h1 (le_refl _)
    simp only [divPairs, Finset.mem_filter, Finset.mem_product, Finset.mem_Icc]
    exact ⟨⟨⟨h1, le_trans hn h3⟩, ⟨h2, le_trans hd h3⟩⟩, h3⟩

lemma mem_divisorPairs {M : ℕ} {p : ℕ × ℕ} :
    p ∈ divisorPairs M ↔ 1 ≤ p.1 ∧ p.1 ≤ M ∧ 2 ≤ p.2 ∧ p.2 ∣ p.1 := by
  constructor
  · intro h
    simp only [divisorPairs, Finset.mem_filter, Finset.mem_product, Finset.mem_Icc] at h
    exact ⟨h.1.1.1, h.1.1.2, h.1.2.1, h.2⟩
  · rintro ⟨h1, h1M, h2, hdvd⟩
    have hdle : p.2 ≤ p.1 := Nat.le_of_dvd (by omega) hdvd
    simp only [divisorPairs, Finset.mem_filter, Finset.mem_product, Finset.mem_Icc]
    exact ⟨⟨⟨h1, h1M⟩, ⟨h2, le_trans hdle h1M⟩⟩, hdvd⟩

/-- `B M n = ∑_{d ≥ 2, n d ≤ M} Λ(d)/d`, i.e. the judge's `B(M/n)`. -/
def B (M n : ℕ) : ℝ :=
  ∑ d ∈ (Finset.Icc 2 M).filter fun d => n * d ≤ M, vonMangoldt d / d

/-- Diagonal weight `a_n^{(M)} = log n + B(M/n)`. -/
def diagWeight (M n : ℕ) : ℝ := Real.log n + B M n

/-- `P_M(c) = 2 Re ∑_{n ≥ 1, d ≥ 2, n d ≤ M} Λ(d)/√d · conj(c_n) c_{nd}`. -/
def primeForm (M : ℕ) (c : ℕ → ℂ) : ℝ :=
  2 * (∑ p ∈ divPairs M,
      ((vonMangoldt p.2 : ℝ) : ℂ) / ((Real.sqrt p.2 : ℝ) : ℂ) *
        (starRingEnd ℂ) (c p.1) * c (p.1 * p.2)).re

/-- `∑_{n ≥ 1, d ≥ 2, n d ≤ M} Λ(d) |c_{nd} − c_n/√d|²`. -/
def energy (M : ℕ) (c : ℕ → ℂ) : ℝ :=
  ∑ p ∈ divPairs M, vonMangoldt p.2 * ‖c (p.1 * p.2) - c p.1 / ((Real.sqrt p.2 : ℝ) : ℂ)‖ ^ 2

lemma norm_sub_div_ofReal_sq (A z : ℂ) (s : ℝ) (hs : s ≠ 0) :
    ‖A - z / (s : ℂ)‖ ^ 2
      = ‖A‖ ^ 2 + ‖z‖ ^ 2 / s ^ 2 - 2 * (((starRingEnd ℂ) z * A).re) / s := by
  have h : ∀ w : ℂ, ‖w‖ ^ 2 = w.re * w.re + w.im * w.im := by
    intro w; rw [← Complex.normSq_eq_norm_sq, Complex.normSq_apply]
  simp only [h, Complex.sub_re, Complex.sub_im, Complex.div_re, Complex.div_im,
    Complex.ofReal_re, Complex.ofReal_im, Complex.normSq_apply, Complex.mul_re,
    Complex.conj_re, Complex.conj_im]
  field_simp
  ring

lemma sum_divPairs_curry (M : ℕ) (f : ℕ → ℕ → ℝ) :
    ∑ p ∈ divPairs M, f p.1 p.2
      = ∑ n ∈ Finset.Icc 1 M, ∑ d ∈ (Finset.Icc 2 M).filter (fun d => n * d ≤ M), f n d := by
  refine Finset.sum_finset_product' _ _ _ ?_
  intro p
  simp only [divPairs, Finset.mem_filter, Finset.mem_product, Finset.mem_Icc]
  tauto

lemma sum_divisorPairs_curry (M : ℕ) (f : ℕ → ℕ → ℝ) :
    ∑ p ∈ divisorPairs M, f p.1 p.2
      = ∑ j ∈ Finset.Icc 1 M, ∑ d ∈ (Finset.Icc 2 M).filter (fun d => d ∣ j), f j d := by
  refine Finset.sum_finset_product' _ _ _ ?_
  intro p
  simp only [divisorPairs, Finset.mem_filter, Finset.mem_product, Finset.mem_Icc]
  tauto

lemma sum_divPairs_reindex (M : ℕ) (g : ℕ → ℕ → ℝ) :
    ∑ p ∈ divPairs M, g (p.1 * p.2) p.2 = ∑ p ∈ divisorPairs M, g p.1 p.2 := by
  refine Finset.sum_nbij' (fun p => (p.1 * p.2, p.2)) (fun p => (p.1 / p.2, p.2))
    ?_ ?_ ?_ ?_ ?_
  · intro p hp
    obtain ⟨h1, h2, h3⟩ := mem_divPairs.mp hp
    refine mem_divisorPairs.mpr ⟨?_, h3, h2, ⟨p.1, mul_comm _ _⟩⟩
    have : 1 * 1 ≤ p.1 * p.2 := Nat.mul_le_mul h1 (by omega)
    simpa using this
  · intro p hp
    obtain ⟨h1, h1M, h2, hdvd⟩ := mem_divisorPairs.mp hp
    have hq : p.1 / p.2 * p.2 = p.1 := Nat.div_mul_cancel hdvd
    refine mem_divPairs.mpr ⟨?_, h2, ?_⟩
    · rcases Nat.eq_zero_or_pos (p.1 / p.2) with h | h
      · rw [h, zero_mul] at hq; omega
      · exact h
    · rw [hq]; exact h1M
  · intro p hp
    obtain ⟨h1, h2, h3⟩ := mem_divPairs.mp hp
    have : p.1 * p.2 / p.2 = p.1 := Nat.mul_div_cancel _ (by omega)
    simp [this]
  · intro p hp
    obtain ⟨h1, h1M, h2, hdvd⟩ := mem_divisorPairs.mp hp
    have : p.1 / p.2 * p.2 = p.1 := Nat.div_mul_cancel hdvd
    simp [this]
  · intro p _; rfl

lemma sum_vonMangoldt_ge_two (M j : ℕ) (hj : 1 ≤ j) (hjM : j ≤ M) :
    ∑ d ∈ (Finset.Icc 2 M).filter (fun d => d ∣ j), vonMangoldt d = Real.log j := by
  rw [← vonMangoldt_sum (n := j)]
  refine Finset.sum_subset ?_ ?_
  · intro d hd
    simp only [Finset.mem_filter, Finset.mem_Icc] at hd
    exact Nat.mem_divisors.mpr ⟨hd.2, by omega⟩
  · intro d hd hnot
    rw [Nat.mem_divisors] at hd
    have hdle : d ≤ j := Nat.le_of_dvd (by omega) hd.1
    have hd0 : d ≠ 0 := by
      rintro rfl
      exact hd.2 (Nat.eq_zero_of_zero_dvd hd.1)
    simp only [Finset.mem_filter, Finset.mem_Icc, not_and] at hnot
    have : d = 1 := by
      by_contra hne
      exact absurd hd.1 (by
        have h2 : 2 ≤ d := by omega
        exact fun _ => (hnot ⟨h2, by omega⟩) hd.1)
    rw [this, vonMangoldt_apply_one]

/-- **(DIV)** the judge's `mangoldt_divisibility_energy_identity`. -/
theorem mangoldt_divisibility_energy_identity (M : ℕ) (c : ℕ → ℂ) :
    (∑ n ∈ Finset.Icc 1 M, diagWeight M n * ‖c n‖ ^ 2) - primeForm M c = energy M c := by
  -- termwise expansion of the energy
  have hE : energy M c = ∑ p ∈ divPairs M,
      (vonMangoldt p.2 * ‖c (p.1 * p.2)‖ ^ 2
        + vonMangoldt p.2 / p.2 * ‖c p.1‖ ^ 2
        - 2 * (vonMangoldt p.2 / Real.sqrt p.2 *
            ((starRingEnd ℂ) (c p.1) * c (p.1 * p.2)).re)) := by
    refine Finset.sum_congr rfl fun p hp => ?_
    obtain ⟨h1, h2, h3⟩ := mem_divPairs.mp hp
    have hd0 : (0 : ℝ) < (p.2 : ℝ) := by
      have : (2 : ℝ) ≤ (p.2 : ℝ) := by exact_mod_cast h2
      linarith
    have hs0 : (0 : ℝ) < Real.sqrt p.2 := Real.sqrt_pos.mpr hd0
    have hsq : Real.sqrt (p.2 : ℝ) ^ 2 = (p.2 : ℝ) := Real.sq_sqrt hd0.le
    rw [norm_sub_div_ofReal_sq _ _ _ (ne_of_gt hs0), hsq]
    ring
  have hP : primeForm M c = ∑ p ∈ divPairs M,
      2 * (vonMangoldt p.2 / Real.sqrt p.2 *
        ((starRingEnd ℂ) (c p.1) * c (p.1 * p.2)).re) := by
    rw [primeForm, Complex.re_sum, Finset.mul_sum]
    refine Finset.sum_congr rfl fun p _ => ?_
    rw [mul_assoc, ← Complex.ofReal_div, Complex.re_ofReal_mul]
  have hDiag : ∑ p ∈ divPairs M, vonMangoldt p.2 / (p.2 : ℝ) * ‖c p.1‖ ^ 2
      = ∑ n ∈ Finset.Icc 1 M, B M n * ‖c n‖ ^ 2 := by
    rw [sum_divPairs_curry M (fun n d => vonMangoldt d / (d : ℝ) * ‖c n‖ ^ 2)]
    refine Finset.sum_congr rfl fun n _ => ?_
    rw [B, Finset.sum_mul]
  have hLog : ∑ p ∈ divPairs M, vonMangoldt p.2 * ‖c (p.1 * p.2)‖ ^ 2
      = ∑ j ∈ Finset.Icc 1 M, Real.log j * ‖c j‖ ^ 2 := by
    rw [sum_divPairs_reindex M (fun j d => vonMangoldt d * ‖c j‖ ^ 2),
      sum_divisorPairs_curry M (fun j d => vonMangoldt d * ‖c j‖ ^ 2)]
    refine Finset.sum_congr rfl fun j hj => ?_
    rw [Finset.mem_Icc] at hj
    rw [← Finset.sum_mul, sum_vonMangoldt_ge_two M j hj.1 hj.2]
  rw [hE, Finset.sum_sub_distrib, Finset.sum_add_distrib, hLog, hDiag, ← hP,
    ← Finset.sum_add_distrib]
  refine congrArg (fun x => x - primeForm M c) (Finset.sum_congr rfl fun n _ => ?_)
  rw [diagWeight, add_mul]

/-- (i) the right-hand side of (DIV) is nonnegative. -/
theorem energy_nonneg (M : ℕ) (c : ℕ → ℂ) : 0 ≤ energy M c :=
  Finset.sum_nonneg fun _ _ => mul_nonneg vonMangoldt_nonneg (sq_nonneg _)

/-- (iii) (PRIME, diagonal form). -/
theorem primeForm_le_diag (M : ℕ) (c : ℕ → ℂ) :
    primeForm M c ≤ ∑ n ∈ Finset.Icc 1 M, diagWeight M n * ‖c n‖ ^ 2 := by
  have h := mangoldt_divisibility_energy_identity M c
  have h0 := energy_nonneg M c
  linarith

/-- (iii') uniform version. -/
theorem primeForm_le_max (M : ℕ) (c : ℕ → ℂ) (A : ℝ)
    (hA : ∀ n ∈ Finset.Icc 1 M, diagWeight M n ≤ A) :
    primeForm M c ≤ A * ∑ n ∈ Finset.Icc 1 M, ‖c n‖ ^ 2 := by
  refine le_trans (primeForm_le_diag M c) ?_
  rw [Finset.mul_sum]
  exact Finset.sum_le_sum fun n hn => by
    exact mul_le_mul_of_nonneg_right (hA n hn) (sq_nonneg _)

/-! ## Calibration plant (`M = 2`, `c = (1, 1/√2)`) -/

/-- The plant vector `c = (1, 1/√2)`. -/
def plantVec : ℕ → ℂ := fun n => if n = 1 then 1 else ((Real.sqrt 2 : ℝ) : ℂ)⁻¹

lemma divPairs_two : divPairs 2 = {(1, 2)} := by
  ext p
  simp only [mem_divPairs, Finset.mem_singleton, Prod.ext_iff]
  constructor
  · rintro ⟨h1, h2, h3⟩
    have hn : p.1 = 1 := by
      by_contra h
      have h2' : 2 ≤ p.1 := by omega
      have : 2 * 2 ≤ p.1 * p.2 := Nat.mul_le_mul h2' h2
      omega
    refine ⟨hn, ?_⟩
    rw [hn, one_mul] at h3
    omega
  · rintro ⟨h1, h2⟩
    rw [h1, h2]
    norm_num

lemma plant_energy_zero : energy 2 plantVec = 0 := by
  rw [energy, divPairs_two, Finset.sum_singleton]
  norm_num [plantVec]

lemma plant_primeForm : primeForm 2 plantVec = Real.log 2 := by
  have hpos : (0:ℝ) < Real.sqrt 2 := Real.sqrt_pos.mpr (by norm_num)
  have hss : Real.sqrt 2 * Real.sqrt 2 = 2 := Real.mul_self_sqrt (by norm_num)
  have hL : vonMangoldt 2 = Real.log 2 := by
    simpa using vonMangoldt_apply_prime Nat.prime_two
  have hne : Real.sqrt 2 ≠ 0 := ne_of_gt hpos
  have hre : (Complex.log 2).re = Real.log 2 := by
    rw [Complex.log_re]
    norm_num
  rw [primeForm, divPairs_two, Finset.sum_singleton]
  norm_num [plantVec, hL]
  rw [hre]
  field_simp

theorem plant_identity_zero :
    (∑ n ∈ Finset.Icc 1 2, diagWeight 2 n * ‖plantVec n‖ ^ 2) - primeForm 2 plantVec = 0 := by
  rw [mangoldt_divisibility_energy_identity, plant_energy_zero]

theorem plant_doubled_edge_eq :
    (∑ n ∈ Finset.Icc 1 2, diagWeight 2 n * ‖plantVec n‖ ^ 2) - 2 * primeForm 2 plantVec
      = -Real.log 2 := by
  have h := plant_identity_zero
  have hp := plant_primeForm
  linarith

theorem plant_doubled_edge_neg :
    (∑ n ∈ Finset.Icc 1 2, diagWeight 2 n * ‖plantVec n‖ ^ 2) - 2 * primeForm 2 plantVec < 0 := by
  rw [plant_doubled_edge_eq]
  exact neg_lt_zero.mpr (Real.log_pos (by norm_num))

/-! ## A Chebyshev-type cap for `B` (Lemma 3, with Mathlib's constant) -/

lemma sum_divisorPairs_swap (N : ℕ) (f : ℕ → ℕ → ℝ) :
    ∑ p ∈ divisorPairs N, f p.1 p.2
      = ∑ d ∈ Finset.Icc 2 N, ∑ j ∈ (Finset.Icc 1 N).filter (fun j => d ∣ j), f j d := by
  refine Finset.sum_finset_product_right' _ _ _ ?_
  intro p
  simp only [divisorPairs, Finset.mem_filter, Finset.mem_product, Finset.mem_Icc]
  tauto

lemma card_multiples (N d : ℕ) :
    ((Finset.Icc 1 N).filter (fun j => d ∣ j)).card = N / d := by
  have h : Finset.Icc 1 N = Finset.Ioc 0 N := by
    ext x; simp only [Finset.mem_Icc, Finset.mem_Ioc]; omega
  rw [h]
  exact Nat.Ioc_filter_dvd_card_eq_div N d

lemma sum_log_eq_sum_floor (N : ℕ) :
    ∑ j ∈ Finset.Icc 1 N, Real.log j
      = ∑ d ∈ Finset.Icc 2 N, vonMangoldt d * ((N / d : ℕ) : ℝ) := by
  have h1 : ∑ p ∈ divisorPairs N, vonMangoldt p.2 = ∑ j ∈ Finset.Icc 1 N, Real.log j := by
    rw [sum_divisorPairs_curry N (fun _ d => vonMangoldt d)]
    refine Finset.sum_congr rfl fun j hj => ?_
    rw [Finset.mem_Icc] at hj
    exact sum_vonMangoldt_ge_two N j hj.1 hj.2
  have h2 : ∑ p ∈ divisorPairs N, vonMangoldt p.2
      = ∑ d ∈ Finset.Icc 2 N, vonMangoldt d * ((N / d : ℕ) : ℝ) := by
    rw [sum_divisorPairs_swap N (fun _ d => vonMangoldt d)]
    refine Finset.sum_congr rfl fun d _ => ?_
    rw [Finset.sum_const, nsmul_eq_mul, card_multiples]
    ring
  rw [← h1, h2]

lemma B_one_eq (N : ℕ) : B N 1 = ∑ d ∈ Finset.Icc 2 N, vonMangoldt d / d := by
  rw [B]
  congr 1
  refine Finset.filter_true_of_mem fun d hd => ?_
  rw [Finset.mem_Icc] at hd
  simpa using hd.2

lemma psi_natCast (N : ℕ) : Chebyshev.psi N = ∑ d ∈ Finset.Icc 2 N, vonMangoldt d := by
  rw [Chebyshev.psi, Nat.floor_natCast]
  refine (Finset.sum_subset ?_ ?_).symm
  · intro d hd
    rw [Finset.mem_Icc] at hd
    rw [Finset.mem_Ioc]
    omega
  · intro d hd hnot
    rw [Finset.mem_Ioc] at hd
    simp only [Finset.mem_Icc, not_and, not_le] at hnot
    have hd1 : d = 1 := by
      by_contra hne
      have h2 : 2 ≤ d := by omega
      have := hnot h2
      omega
    rw [hd1, vonMangoldt_apply_one]

/-- Lemma 3 in the judge's numbering, with Mathlib's Chebyshev constant
`log 4 + 4` in place of `4 log 2`. -/
lemma B_one_le (N : ℕ) (hN : 1 ≤ N) :
    B N 1 ≤ Real.log N + (Real.log 4 + 4) := by
  have hNpos : (0 : ℝ) < N := by exact_mod_cast hN
  have key : (N : ℝ) * B N 1
      ≤ ∑ d ∈ Finset.Icc 2 N, vonMangoldt d * (((N / d : ℕ) : ℝ) + 1) := by
    rw [B_one_eq, Finset.mul_sum]
    refine Finset.sum_le_sum fun d hd => ?_
    rw [Finset.mem_Icc] at hd
    have hd0 : (0 : ℝ) < d := by
      have : (2 : ℝ) ≤ (d : ℝ) := by exact_mod_cast hd.1
      linarith
    have hfloor : (N : ℝ) / d ≤ ((N / d : ℕ) : ℝ) + 1 := by
      have h := Nat.lt_floor_add_one ((N : ℝ) / (d : ℕ))
      rw [Nat.floor_div_natCast, Nat.floor_natCast] at h
      exact le_of_lt h
    calc (N : ℝ) * (vonMangoldt d / d) = vonMangoldt d * ((N : ℝ) / d) := by ring
      _ ≤ vonMangoldt d * (((N / d : ℕ) : ℝ) + 1) :=
          mul_le_mul_of_nonneg_left hfloor vonMangoldt_nonneg
  have hsplit : ∑ d ∈ Finset.Icc 2 N, vonMangoldt d * (((N / d : ℕ) : ℝ) + 1)
      = (∑ d ∈ Finset.Icc 2 N, vonMangoldt d * ((N / d : ℕ) : ℝ))
        + ∑ d ∈ Finset.Icc 2 N, vonMangoldt d := by
    rw [← Finset.sum_add_distrib]
    exact Finset.sum_congr rfl fun d _ => by ring
  have hlogsum : ∑ j ∈ Finset.Icc 1 N, Real.log j ≤ (N : ℝ) * Real.log N := by
    calc ∑ j ∈ Finset.Icc 1 N, Real.log j ≤ ∑ _j ∈ Finset.Icc 1 N, Real.log N := by
          refine Finset.sum_le_sum fun j hj => ?_
          rw [Finset.mem_Icc] at hj
          have hj0 : (0 : ℝ) < j := by exact_mod_cast hj.1
          exact Real.log_le_log hj0 (by exact_mod_cast hj.2)
      _ = (N : ℝ) * Real.log N := by
          rw [Finset.sum_const, Nat.card_Icc, nsmul_eq_mul]
          norm_num
  have hpsi : ∑ d ∈ Finset.Icc 2 N, vonMangoldt d ≤ (Real.log 4 + 4) * N := by
    rw [← psi_natCast N]
    exact Chebyshev.psi_le_const_mul_self (by positivity)
  have hchain : (N : ℝ) * B N 1 ≤ (N : ℝ) * (Real.log N + (Real.log 4 + 4)) := by
    rw [hsplit, ← sum_log_eq_sum_floor] at key
    nlinarith [key, hlogsum, hpsi]
  exact le_of_mul_le_mul_left hchain hNpos

lemma B_eq_div (M n : ℕ) (hn : 1 ≤ n) : B M n = B (M / n) 1 := by
  rw [B, B]
  refine Finset.sum_congr ?_ fun d _ => rfl
  ext d
  simp only [Finset.mem_filter, Finset.mem_Icc, one_mul]
  constructor
  · rintro ⟨⟨h2, _⟩, hnd⟩
    have hdq : d ≤ M / n := (Nat.le_div_iff_mul_le (by omega)).mpr (by rw [mul_comm]; exact hnd)
    exact ⟨⟨h2, hdq⟩, hdq⟩
  · rintro ⟨⟨h2, hdq⟩, _⟩
    have hdn : d * n ≤ M := (Nat.le_div_iff_mul_le (by omega)).mp hdq
    have hdM : d ≤ M := le_trans (Nat.le_mul_of_pos_right d (by omega)) hdn
    exact ⟨⟨h2, hdM⟩, by rw [mul_comm]; exact hdn⟩

lemma diagWeight_le (M n : ℕ) (hn : 1 ≤ n) (hnM : n ≤ M) :
    diagWeight M n ≤ Real.log M + (Real.log 4 + 4) := by
  have hq : 1 ≤ M / n := (Nat.one_le_div_iff (by omega)).mpr hnM
  have hB := B_one_le (M / n) hq
  have hn0 : (0 : ℝ) < n := by exact_mod_cast hn
  have hq0 : (0 : ℝ) < ((M / n : ℕ) : ℝ) := by exact_mod_cast hq
  have hlog : Real.log n + Real.log ((M / n : ℕ) : ℝ) ≤ Real.log M := by
    rw [← Real.log_mul (ne_of_gt hn0) (ne_of_gt hq0)]
    refine Real.log_le_log (by positivity) ?_
    have hnat : n * (M / n) ≤ M := by
      calc n * (M / n) = M / n * n := by rw [mul_comm]
        _ ≤ M := Nat.div_mul_le_self M n
    exact_mod_cast hnat
  rw [diagWeight, B_eq_div M n hn]
  linarith

/-- **(PRIME)** the explicit logarithmic cap on the prime operator. -/
theorem primeForm_le_log (M : ℕ) (c : ℕ → ℂ) :
    primeForm M c ≤ (Real.log M + (Real.log 4 + 4)) * ∑ n ∈ Finset.Icc 1 M, ‖c n‖ ^ 2 := by
  refine primeForm_le_max M c _ fun n hn => ?_
  rw [Finset.mem_Icc] at hn
  exact diagWeight_le M n hn.1 hn.2

end
