# Q36. Настоящие частотные уровни и точный отказ переноса длинного среднего

## 0. Ответ и граница нового результата

**Независимого совместного благоприятного знакового входа для CCM я в этой попытке не нашёл.** Выполнен разрешённый в верхнем запросе вариант (в): количественно проверен один статистический источникозависимый вход и осуществлён откат до его неоплаченного переноса.

Проверяемое дополнительное свойство — **независимость координат различных простых в бесконечном невзвешенном частотном среднем**, вытекающая из единственности разложения целых на простые. Оно не означает независимости степеней одного простого. Из него действительно получается сильный закон больших значений буквального конечного символа с настоящими \(\Lambda(p^k)\). В отличие от общего \(\|a_m\|_\infty\)-верха этот закон содержит совместную арифметику всех prime-frequency координат.

Однако нужная мера в CCM — не это длинное среднее. Это **точная достижимая** \(\rho_c(\xi)d\xi\), связанная с одним исходным вектором. Проверка возвращения обнаруживает три конкретных факта.

1. Для каждого фиксированного \(0\le\eta<1/2\), на всех достаточно поздних ячейках **настоящие центрированные** множества

   \{\xi:b_m(\xi)>m^\eta\},\qquad
   \{\xi:b_m(\xi)<-m^\eta\}
   \]
   имеют бесконечную меру Лебега. Это доказано без PNT. Следовательно, конечность меры полного исключительного множества — не просто непредъявленный вход к буквальному finite-measure uncertainty-импорту: в этой форме гипотеза ложна.
2. На всём исходном \(P\) есть конкретная проверка против бесплатной замены меры на независимые фазы. Для одной общей пары **настоящих** простых \(p_m\ne q_m\) её смешанный ratio-character удовлетворяет
   \[
   \Re\int e^{i\xi\log(p_m/q_m)}\rho_c(\xi)d\xi
   \ge1-524288\pi^2(M/m)^2
   \]
   для **каждого** единичного \(c=Pc\). В Haar-среднем его значение ноль.
3. Законный конечновысотный моментный возврат, рассчитанный ниже со всеми смешанными секторами, не исправляет это различие. Его выписанная положительная цена насыщается на полной массе один и возвращает степень \(1/2\).

Это не опровержение самой event-specific оценки \(\int_E\rho_c\), не нижняя оценка \(C^0\), не найденный внепрямой нуль и не запрет всех uncertainty/Bohr/моментных подходов. В частности, **бесконечная мера \(E\) совместима с очень малой \(\rho_c\)-массой его далёкой части**. Хвост возвращён явно.

\]

\tag{1.3}

В частности, нулевое продолжение принадлежит \(H^1(\mathbb R)\), и

\tag{1.4}
\]
Это не произвольная плотность. Буквальная параметризация S5:

## 2. Настоящий prime-phase закон: что доказывается без замены источника

### 2.1. Фазы различных простых и все степени одного простого

**[FINITE_CELL | PAPER; собственный вывод из уникальности факторизации]**
Зафиксируем целое \(m\ge2\). Для каждого простого \(p\le m\) положим
\[
 K_p=\lfloor\log m/\log p\rfloor,
 \quad X_p(\theta)=2\log p\sum_{k=1}^{K_p}p^{-k/2}\cos(k\theta),
 \quad v_p=\log p\sum_{k=1}^{K_p}p^{-k/2}.
\tag{2.1}
\]
Точный конечный символ есть
\[
 a_m(\xi)=\mathscr A_m((\xi\log p)_p),\qquad
 \mathscr A_m(\boldsymbol\theta)=\sum_{p\le m}X_p(\theta_p).
\tag{2.2}
\]
Гармоники \(k\theta_p\) одного простого **связаны**, не рандомизируются по отдельности.

Для любого ненулевого целочисленного вектора \(\boldsymbol h=(h_p)\)
\[
 \lambda_{\boldsymbol h}:=\sum_{p\le m}h_p\log p\ne0.
\tag{2.3}
\]
Иначе произведение простых с положительными показателями равнялось бы произведению с отрицательными, что противоречит единственности факторизации. Поэтому
\[
 \frac1{2Y}\int_{-Y}^{Y}e^{i\xi\lambda_{\boldsymbol h}}d\xi
 =\operatorname{sinc}(Y\lambda_{\boldsymbol h})\longrightarrow0
 \quad(Y\to\infty),
\tag{2.4}
\]
где \(\operatorname{sinc}x=\sin x/x\), \(\operatorname{sinc}0=1\).
Для нулевого вектора среднее равно единице. Линейность доказывает сходимость для тригонометрических полиномов на конечном торе. Равномерное приближение непрерывных периодических функций полиномами, например свёрткой с произведением ядер Фейера, доказывает её для всякой непрерывной функции. Для множеств с границей Haar-меры ноль используется приближение сверху и снизу непрерывными функциями.

Итак, **для фиксированного \(m\)** невзвешенное длинное среднее действительно равно независимому Haar-среднему по координатам простых. В (2.4) нет ни скорости, равномерной по \(m\), ни права подставить вместо длинного среднего \(\rho_c(\xi)d\xi\).

\tag{2.5}
\]
На Haar-пространстве \(\mathbb E X_p=0\), \(|X_p|\le2v_p\). Если \(X\in[-r,r]\), \(\mathbb E X=0\), то выпуклость экспоненты на этом отрезке даёт
\[
 \mathbb E e^{uX}\le\cosh(ur)\le e^{u^2r^2/2}.
\tag{2.6}
\]
Последнее следует из \(\tanh t\le t\) для \(t\ge0\) и чётности. Применяя (2.6) к независимым координатам (2.1), получаем
\[
 \mathbb E_{\rm Haar}e^{u\mathscr A_m}\le e^{2u^2\mathscr V_m}.
\]
Для \(t>0\) марковская оценка и выбор \(u=t/(4\mathscr V_m)\) дают
\[
 \boxed{\mathbb P_{\rm Haar}(\mathscr A_m>t),\ 
 \mathbb P_{\rm Haar}(\mathscr A_m<-t)
 \le\exp\!\left(-\frac{t^2}{8\mathscr V_m}\right).}
\tag{2.7}
\]
Это вычисленный закон фактического prime-power символа, а не fit и не заявление о CCM.

Его дисперсионная плата действительно логарифмическая:
\[
 \begin{aligned}
 \mathscr V_m
 &\le(1-2^{-1/2})^{-2}\sum_{p\le m}\frac{\log^2p}{p}
 \le(1-2^{-1/2})^{-2}S_2(m),\\
 S_2(m)&\le L\sum_{n\le m}\frac{\Lambda(n)}n
 \le L(6+3L).
 \end{aligned}
\tag{2.8}
\]
Последняя строка — интегрирование (1.8):
\(\sum\Lambda(n)/n=W(m)/\sqrt m+\tfrac12\int_1^m W(x)x^{-3/2}dx\).
Все proper powers участвуют в \(S_2\), а в первой строке их гармоники были сохранены в \(v_p\).

### 2.3. Центрирование и порядок пределов

Прямое интегрирование даёт
\[
 g_m(\xi)=2\Re\frac{m^{1/2+i\xi}-1}{1/2+i\xi},\qquad
 |g_m(\xi)|\le\frac{2(\sqrt m+1)}{\sqrt{1/4+\xi^2}}.
\tag{2.9}
\]
Поэтому \(g_m(\xi)\to0\) при \(|\xi|\to\infty\) для фиксированного \(m\).
У \(\mathscr A_m\) нет атомов в распределении значений: зафиксировав все координаты, кроме одной, получаем ненулевой одномерный тригонометрический полином, уравнение которого с данным уровнем имеет конечное множество корней. Фубини даёт нулевую Haar-меру каждого level set.

Следовательно, по зажатию порогами \(t\pm\delta\) существуют пределы
\[
 d_m^\pm(t):=\lim_{Y\to\infty}
 \frac{|\{\xi\in[-Y,Y]:\ \pm b_m(\xi)>t\}|}{2Y}
 =\mathbb P_{\rm Haar}(\pm\mathscr A_m>t).
\tag{2.10}
\]
Для \(t>0\) они удовлетворяют (2.7). **Сначала фиксирован \(m\), потом \(Y\to\infty\)**. Эта очередность не заменяется производственным \(Y=Y(m)\), и тем более не весом \(\rho_c\). Квантор — важная часть результата.

## 3. Полные центрированные исключительные множества действительно бесконечны

### 3.1. Элементарная нижняя масса: PNT не нужна

**[COFINAL_FAMILY | PAPER]** Обозначим \(\psi(m)=\sum_{n\le m}\Lambda(n)\).
При \(n=\lfloor m/2\rfloor\) каждое слагаемое в формуле Лежандра для
\(v_p\binom{2n}{n}\) равно 0 или 1; поэтому
\[
 \binom{2n}{n}\mid\operatorname{lcm}(1,\ldots,2n).
\]
Центральный биномиальный коэффициент — максимальный среди \(2n+1\) слагаемых суммы \(4^n\). Значит,
\[
 \boxed{\psi(m)\ge(m-1)\log2-\log(m+1).}
\tag{3.1}
\]
В частности,
\[
 W(m)\ge\frac{\psi(m)}{\sqrt m}
 \ge(\log2)\sqrt m-
 \frac{\log2+\log(m+1)}{\sqrt m}.
\tag{3.2}
\]
Все степени простых нужны уже в \(\log\operatorname{lcm}=\psi\).

Положим
\[
 \mathcal P_H(m)=\{p:\sqrt m<p\le m,\ p\text{ простое}\},\quad
 N_H=|\mathcal P_H(m)|,\quad
 W_H=\sum_{p\in\mathcal P_H(m)}\frac{\log p}{\sqrt p},
 \quad W_L=W(m)-W_H.
\tag{3.3}
\]
У каждого \(p\in\mathcal P_H\) в исходном cutoff есть ровно одна степень. Всё остальное, в том числе высокие степени малых простых, остаётся в \(W_L\).
С \(c_{\rm pp}=(1-2^{-1/2})^{-1}\) имеем
\[
 \sum_{\substack{p^k\le m\\k\ge2}}\frac{\log p}{p^{k/2}}
 \le c_{\rm pp}\sum_{p\le\sqrt m}\frac{\log p}{p}
 \le c_{\rm pp}L(1+L).
\tag{3.4}
\]
Здесь использованы лишь геометрическая сумма, \(\log p\le L\) и гармоническая сумма. Поэтому
\[
 W_L\le6m^{1/4}+c_{\rm pp}L(1+L).
\tag{3.5}
\]
Определим **фактическую** величину \(D_m=W_H-2W_L=W(m)-3W_L\). Из (3.2)–(3.5):
\[
 D_m\ge(\log2)\sqrt m-18m^{1/4}-3c_{\rm pp}L(1+L)
 -\frac{\log2+\log(m+1)}{\sqrt m}.
\tag{3.6}
\]
В частности, со временем \(D_m\ge\tfrac12(\log2)\sqrt m>0\).

### 3.2. Два настоящих phase-box, с полным возвратом low-сектора

На торе зададим только координаты \(p\in\mathcal P_H\):
\[
 \mathcal B_+=\{\cos\theta_p\ge1/2\ \forall p\in\mathcal P_H\},\qquad
 \mathcal B_-=\{\cos\theta_p\le-1/2\ \forall p\in\mathcal P_H\}.
\tag{3.7}
\]
Остальные координаты **не ограничиваем**. Обе коробки имеют Haar-меру \(3^{-N_H}\). Их вклад в \(\mathscr A_m\) равен соответственно не менее \(W_H\) и не более \(-W_H\). Полный оставшийся вклад имеет модуль не более \(2W_L\), откуда
\[
 \mathscr A_m\ge D_m\text{ на }\mathcal B_+,
 \qquad \mathscr A_m\le-D_m\text{ на }\mathcal B_-.
\tag{3.8}
\]
Таким образом, для каждого конечного \(m\) с \(D_m>t\ge0\)
\[
 \boxed{d_m^+(t)\ge3^{-N_H}>0,\qquad d_m^-(t)\ge3^{-N_H}>0.}
\tag{3.9}
\]
Можно проверить центрирование непосредственно: при
\[
 |\xi|\ge\frac{4(\sqrt m+1)}{D_m-t}
\tag{3.10}
\]
его модуль не превосходит \((D_m-t)/2\). Удаление этого конечного центрального интервала не меняет длинной плотности phase-box.

Для фиксированного \(0\le\eta<1/2\), из (3.6) следует \(D_m>m^\eta\) со временем. Поэтому
\[
 \boxed{|\{b_m>m^\eta\}|=|\{b_m<-m^\eta\}|=\infty.}
\tag{3.11}
\]
Это утверждение **про центрированный** \(b_m\), не перенос zero-frequency препятствия для \(a_m\).

Нет противоречия с (2.7): для фиксированного \(\eta>0\) длинная относительная плотность может быть чрезвычайно мала при росте \(m\), оставаясь строго положительной для каждого фиксированного \(m\), а абсолютная мера — бесконечной. Ни (3.9), ни (2.7) не дают нужной \(\rho_c\)-массы.

### 3.3. Проверка внешнего finite-measure входа

В первичном PDF Philippe Jaming, *Nazarov’s uncertainty principles in higher dimension*, arXiv:math/0612367v1, проверены Fourier-нормировка на печатной странице 1 и теорема на странице 2, в том числе изображения обеих страниц. Теорема требует конечной меры обоих множеств. Здесь \(S=[0,L]\), но \(\Sigma=\{b_m>m^\eta\}/(2\pi)\) по (3.11) имеет бесконечную меру.

Это исключает **буквальное применение указанной теоремы ко всему этому множеству**. Это не опровержение самой теоремы и не отрицание иных оценок для бесконечных множеств. Полное доказательство статьи заново не проверялось; файл PDF в контейнер скачать не удалось, его бинарный хеш не заявляется. Теорема не используется как положительный поставщик в последующих оценках.

При конечном срезе \(E_Y=\{b_m>t\}\cap[-Y,Y]\) гипотеза конечной меры верна. Но даже допустимый вывод об outside-массе нельзя подменять нужной малой inside-массой; хвост и точная цена возвращения приведены в §6. Это сохраняет правильную границу S3, теперь с проверенным отказом её целолинейной гипотезы.

## 4. Перенос на настоящую плотность: точная карта и конкретный отказ

### 4.1. Достижимый закон не Haar

**[FINITE_CELL | PAPER]** Пусть \(\nu_{m,c}\) — pushforward именно \(\rho_c(\xi)d\xi\) при отображении
\(\xi\mapsto(\xi\log p\bmod2\pi)_{p\le m}\). Он имеет полную массу 1. Для целочисленного \(\boldsymbol h\) точная формула есть
\[
 \boxed{\int e^{i\boldsymbol h\cdot\boldsymbol\theta}d\nu_{m,c}
 =r_f\!\left(\sum_p h_p\log p\right),\qquad
 r_f(s)=\int\overline{f(t)}f(t+s)dt.}
\tag{4.1}
\]
Она следует из Plancherel с (1.4), без усреднения по \(c\). Для \(|s|\ge L\) корреляция равна нулю, для остальных сдвигов в общем случае нет.

У Haar-меры правая сторона для \(\boldsymbol h\ne0\) была бы нулём. Само наличие (2.3) даёт лишь **ненулевую** частоту \(s\), но не делает корреляцию \(r_f(s)\) малой. Так выглядит точная карта до потери зависимости от одного исходного \(f\).

### 4.2. Общая близкая пара настоящих простых без PNT

**[COFINAL_FAMILY | PAPER]** При достаточно большом \(m\) существует пара разных простых
\[
 m/64<p<q\le m,\qquad q-p\le8L.
\tag{4.2}
\]
Доказательство с полными арифметическими расходами. По (3.1), \(\psi(m)\ge m/2\) со временем. Из (1.8) следует \(\psi(x)\le6x\). Если \(\vartheta(x)=\sum_{p\le x}\log p\), то
\[
 0\le\psi(m)-\vartheta(m)
 \le\frac{\sqrt m\,L^2}{\log2}=o(m):
\tag{4.3}
\]
для каждого \(k\ge2\) число допустимых оснований не больше \(\sqrt m\), их логарифм не больше \(L\), а число \(k\) не больше \(L/\log2\). Поэтому
\[
 \vartheta(m)-\vartheta(m/64)
 \ge m/2-6m/64-\frac{\sqrt m\,L^2}{\log2}\ge m/4
\tag{4.4}
\]
со временем. В этом интервале не меньше \(m/(4L)\) простых. Как только их число \(N\ge2\), минимальный соседний промежуток не больше
\(m/(N-1)\le8L\). Это доказывает (4.2).

Пара выбирается по \(m\), **одна для всех векторов данной ячейки**, не под каждый \(c\). При \(m>4096\) оба простых больше \(\sqrt m\), их произведение больше \(m\), но
\[
 0<\log(q/p)\le(q-p)/p\le512L/m.
\tag{4.5}
\]

### 4.3. Нижняя оценка настоящего смешанного момента

Для любого единичного исходного \(f\) на всей прямой
\[
 2-2\Re r_f(s)=\|f(\cdot+s)-f\|_2^2
 \le s^2\|f'\|_2^2\le\Omega^2s^2.
\tag{4.6}
\]
Трансляции применяются к нулевому продолжению. Граница оплачена тем, что (1.3) делает его \(H^1\)-функцией. Нет промежуточного \(P\) или предположения о поддержке преобразования Фурье.

Подстановка (4.5) даёт
\[
 \boxed{\Re r_f(\log(p/q))
 \ge1-524288\pi^2(M/m)^2.}
\tag{4.7}
\]
При фиксированном \(\epsilon<1/32\) ошибка стремится к нулю на всём исходном \(P\).

Ещё более прямой двухкоординатный тест сохраняет **обе** комбинации частот:
\[
 \int\cos(\xi\log p)\cos(\xi\log q)\rho_c(\xi)d\xi
 =\tfrac12\Re r_f(\log(pq))+	frac12\Re r_f(\log(p/q)).
\tag{4.8}
\]
Первая часть нулевая точно, поскольку \(pq>m\); вторая остаётся. Значит,
\[
 \boxed{\int\cos(\xi\log p)\cos(\xi\log q)\rho_c(\xi)d\xi
 \ge\frac12-262144\pi^2(M/m)^2.}
\tag{4.9}
\]
Haar-значение для \(p\ne q\) равно нулю. Это **смешанный момент, не центрированная ковариация**: маргинальные средние исходной меры здесь неизвестны и не зануляются.

Например, утверждение о равномерном возвращении этого момента с абсолютной ошибкой \(\le1/4\) имеет на всех достаточно поздних ячейках отрицательный margin:
\[
 \frac14-\int\cos(\xi\log p)\cos(\xi\log q)\rho_c(\xi)d\xi
 \le-\frac18<0
\tag{4.10}
\]
после достижения \(262144\pi^2(M/m)^2\le1/8\). Это точное опровержение **конкретного равномерного Haar-moment переноса**. Оно не даёт нижнего знака полной \(C^0\) и не опровергает более слабую оценку только на специально выбранном исключительном множестве.

Итак, арифметическая раздельность простых в факторизации и их **физическая частотная разрешимость** — разные свойства. Для настоящего исходного теста близкие большие простые дают почти одинаковые логарифмические фазы; в бесконечном невзвешенном среднем любые разные фазы ортогональны. Это различие посчитано на действительном источнике, а не на произвольной синтетической четвёрке.

## 5. Полный конечновысотный расчёт до модулей

Отказ (4.10) запрещает бесплатный импорт Haar-оценки (2.7), но сам по себе не доказывает, что все конечные оценки бесполезны. Поэтому ниже рассчитан один законный, полностью явный возврат на конечной полосе. Он нужен для **цены данного завершения**, не как ещё одна независимая попытка.

### 5.1. Все discrete/continuous/mixed сектора

**[FINITE_CELL | PAPER]** Обозначим \(w_n=\Lambda(n)/\sqrt n\), \(K_Y(z)=\operatorname{sinc}(Yz)\). Точное равенство:
\[
\begin{aligned}
 \frac1{2Y}\int_{-Y}^{Y}b_m(\xi)^2d\xi
={}&2\sum_{n,r\le m}w_nw_r
 [K_Y(\log(n/r))+K_Y(\log(nr))]\\
&-4\sum_{n\le m}w_n\int_1^m x^{-1/2}
 [K_Y(\log(n/x))+K_Y(\log(nx))]dx\\
&+2\int_1^m\!\int_1^m (xy)^{-1/2}
 [K_Y(\log(x/y))+K_Y(\log(xy))]dxdy .
\end{aligned}
\tag{5.1}
\]
Здесь \(\Lambda(1)=0\); все суммы конечны. Никакие \(n=r\), \(p^k\), противоположные времена, product/ratio сектора, края \(1,m\) или квадратные смешения не удалены. Непрерывная мера исходная \(dx\), не распределение по округлённым целым.

В бесконечном невзвешенном среднем смешанные недиагональные члены исчезают. При конечном \(Y\) \(K_Y\) **не** является символом Кронекера. В частности, \(\log(n/r)\) может быть очень малым. Уникальность факторизации исключает точное равенство \(n/r=1\), но не малость этого логарифма.

### 5.2. Законное положительное завершение и его цена

В следующем неравенстве начинается потеря signed-связи с непрерывным фоном:
\[
 (a_m-g_m)^2\le2a_m^2+2g_m^2.
\tag{5.2}
\]
Это не равенство. Затем используется \(|K_Y(z)|\le\min(1,1/(Y|z|))\). Полные дискретные перекрёстные члены оплачиваются так:
\[
 \sum_{n\ne r}\frac{w_nw_r}{|\log(n/r)|}
 \le m\sum_{n\ne r}\frac{w_nw_r}{|n-r|}
 \le2m\mathfrak h_{m-1}S_2(m),
\tag{5.3}
\]
где \(\mathfrak h_{m-1}=\sum_{j=1}^{m-1}1/j\). Последний шаг — \(2uv\le u^2+v^2\) и полный двусторонний гармонический ряд по \(r\ne n\). Нулевые веса не удаляют поддержанные prime-power пары. Также
\[
 \sum_{n,r\ge2}\frac{w_nw_r}{\log(nr)}\le\frac{W(m)^2}{\log4}.
\tag{5.4}
\]
Таким образом,
\[
 \frac1{2Y}\int_{-Y}^{Y}a_m^2
 \le2S_2+\frac{4m\mathfrak h_{m-1}S_2+2W^2/\log4}{Y}.
\tag{5.5}
\]
Для полного непрерывного символа (1.6) Plancherel, с нашей нормировкой, даёт
\[
 \int_{\mathbb R}g_m(\xi)^2d\xi
 =2\pi\int_{-L}^{L}e^{|s|}ds=4\pi(m-1).
\tag{5.6}
\]
Введём явную положительную цену
\[
 \mathscr Q_m=8m\mathfrak h_{m-1}S_2(m)+\frac{4W(m)^2}{\log4}+4\pi(m-1).
\tag{5.7}
\]
Из (5.2), (5.5), (5.6):
\[
 \boxed{\frac1{2Y}\int_{-Y}^{Y}b_m^2\le4S_2(m)+\frac{\mathscr Q_m}{Y}.}
\tag{5.8}
\]
Все константы конечны и явны; это верх, не оценка снизу настоящего момента. С (2.8), (1.8), \(\mathfrak h_{m-1}\le1+L\) получаем \(\mathscr Q_m=O(m(1+L)^3)\).

Существенный отрицательный контроль: если подставить в точное сравнение источник, равный непрерывному фону, то в (5.1) результат нулевой **до** оценок. (5.2) даёт большую положительную цену. Поэтому именно это завершение не проходит D0-discriminator как механизм сохранения полезной компенсации; его нельзя продавать как независимый signed-вход. Равенство (1.7) при этом не изменилось.

## 6. Возвращение плотности, хвоста и всех расходов

### 6.1. Не подменяем \(\rho_c\) конечной частотной поддержкой

**[FINITE_CELL | PAPER; переиспользование S5, не новый выигрыш]** Для \(Y\ge2\Omega\) исходный endpoint-контакт даёт
\[
 \tau_c(Y):=\int_{|\xi|>Y}\rho_c(\xi)d\xi
 \le\frac{16d\Omega^2}{3\pi L Y^3},
\]
\[
 \boxed{\left|\int_{|\xi|>Y}b_m\rho_c\right|
 \le\mathfrak r_m(Y):=
 \frac{256d\Omega^2\sqrt m}{3\pi L Y^3}.}
\tag{6.1}
\]
Все \(\xi\) вне окна возвращены; нет объявления \(\widehat f\) band-limited. Выбор одной общей для всех векторов высоты
\[
 Y_m=\max\{2\Omega,m^{1/6+\epsilon+\nu}\},\qquad\nu>0\text{ фиксировано},
\tag{6.2}
\]
даёт \(\mathfrak r_m(Y_m)=O_{\epsilon,\nu}(m^{-3\nu}/L^3)=o(1)\).
Это достаточная высота данного прежнего конверта, не минимально необходимая высота.

### 6.2. Стоимость moment-to-exceptional-mass перехода

Пусть \(0<t\le B_m\), \(E_{t,Y}=\{\xi\in[-Y,Y]:b_m(\xi)>t\}\).
На настоящем исходном тесте
\(\rho_c\le L/(2\pi)\) по Cauchy–Schwarz в (1.2). Это верх для той же плотности, а не смена её класса. Из (5.8):
\[
 \boxed{
 \int_{E_{t,Y}}\rho_c
 \le\min\{1,\mathfrak F_m(Y,t)\},\qquad
 \mathfrak F_m(Y,t)=\frac{L}{\pi t^2}
 [4YS_2(m)+\mathscr Q_m].}
\tag{6.3}
\]
До этого шага source-specific Haar-law не переносился незаконно. Цена (6.3) получена из конечного \(b_m\), со всеми остатками (5.1), а не из неподставленного предела.

Однако \(S_2(m)\ge(\log2)^2/2>1/8\), и \(\mathfrak h_{m-1}\ge\log m=L\). Следовательно, для **всех** \(0<t\le16\sqrt m\) и **любой** \(Y>0\)
\[
 \boxed{\mathfrak F_m(Y,t)\ge\frac{L^2}{256\pi}.}
\tag{6.4}
\]
При \(L\ge16\sqrt\pi\) выписанный mass-allowance в (6.3) тождественно равен единице. Это нижняя цена **именно данного положительного конверта**, а не нижняя оценка \(\int_E\rho_c\). Более точная интегральная оценка могла бы быть меньше; она здесь не поставлена.

Из исходного signed-разбиения, с хвостом,
\[
 c^*Ac\le t+(B_m-t)\min\{1,\mathfrak F_m(Y,t)\}
 +\mathfrak r_m(Y)-c^*H_dc.
\tag{6.5}
\]
По (6.4), полная цена этого завершения —
\[
 \boxed{s_{\rm trial}=16\sqrt m+\mathfrak r_m(Y_m)=16\sqrt m+o(1).}
\tag{6.6}
\]
Её можно уменьшить до \(16\sqrt m\) прямым глобальным \(|b_m|\le B_m\); это не меняет степень и хуже сохранённого source-cap. Неизвестная скорость равномерного возвращения (2.7) в производственный cutoff не прячется внутри малого \(o(1)\): (6.3)–(6.6) — полный реально доказанный конечный конверт.

### 6.3. Возврат в \(T_{>R}\) и \(K_m\)

Сохраняем лучший приложенный S10-вход, не выдавая его за результат Q36:
\[
 s_{\rm keep}=W_<(m)+W(\lfloor\sqrt m\rfloor),\qquad
 W_<(m)=\sum_{2\le n<m}\frac{\Lambda(n)}{\sqrt n},
\]
\[
 \boxed{A\preceq s_{\rm keep}P,
 \qquad s_{\rm keep}\le6\sqrt m+6m^{1/4}.}
\tag{6.7}
\]
Итоговый бюджет на неизменном потребителе:
\[
 \boxed{
 T_{>R}\preceq[s_{\rm keep}+b_{\rm div}]P,\qquad
 PK_mP\succeq-[s_{\rm keep}+50L+8]P,
 }
\tag{6.8}
\]
\[
 b_{\rm div}=(56+32\Omega)\sqrt R+12(1+\log R)^2.
\tag{6.9}
\]
В (6.8) не добавляются повторно \(H_d\), \(U_{\rm sf}\), proper-power плата или короткий делительный сектор. (6.7) уже оценивает всю \(A\) напрямую. Реальные коэффициенты Мёбиуса в исходном делительном разбиении не заменялись; их полный короткий возврат — ровно (6.9).

На расписании (1.1) \(b_{\rm div}=O_\epsilon(m^{3\epsilon/2}/L+m^{\epsilon/2}+L^2)\); он не устраняет основной показатель \(1/2\). Архимедова плата \(50L+8\) начислена один раз. Для произвольного \(W=PWP\succeq0\) все операторные выводы применяются к тому же \(W\), с множителем \(\operatorname{Tr}W\), без изменения фаз или отдельного выбора частотного окна.

## 7. Первая неоплаченная строка и выполненный rollback

Имеются две различные меры:
\[
 d_m^+(t)=\mathbb P_{\rm Haar}(\mathscr A_m>t),\qquad
 \int_{\{b_m>t\}}\rho_c(\xi)d\xi.
\tag{7.1}
\]
**Первая неоплаченная строка** была бы количественным переносом малого значения первой величины во вторую, равномерно по исходному \(c=Pc\), с полной скоростью порядка \(m^{\eta-1/2}\) при \(t=m^\eta/2\). Она не следует из (2.7) или из существования внеисключительной массы. Она не принималась в предпосылки.

Более сильный равномерный Haar-moment перенос уже опровергнут (4.9)–(4.10). Это не делает event-specific перенос ложным: исключительное множество зависит от полного источника, и для него может существовать специальная связь, не контролирующая все отдельные моменты. **Такой связи я не доказал.**

Выполненный содержательный откат — **до выбора статистического закона и до положительного level-set payment**, к исходному конечному signed-спариванию:
\[
 \boxed{C^0=\sum_{n\le m}\Lambda(n)h(n)-\int_1^m h(x)dx,
 \quad h(x)=x^{-1/2}P Q_M(\log x)P.}
\tag{7.2}
\]
Вся проверяемая цепь возвращается к (7.2) точно через (1.7); добавочная ошибка карты нулевая. Это не новое имя доказанной леммы и не объявление нового поставщика. Причина отката конкретна: **при переходе к независимым фазам теряется доказанно большой настоящий mixed-ratio момент на всех исходных тестах**, а при конечном нормовом ремонте возвращается полустепенная цена.

Частотные хвосты (6.1) остаются доступными, но их дальнейшее уменьшение не оплачивает (7.1). Условные \(3/8\) остаются условными на прежнюю ZF78, которая здесь не использовалась. Ни новая \(\eta(\epsilon)\to0\), ни margin для настоящей нулеселективной пары не получены.

### 7.1. Более слабый настоящий receiver не закрыт

**[COFINAL_FAMILY | CONDITIONAL; только унаследованные S11–S12]**
При фиксированном гипотетическом настоящем нуле \(w=\delta+i\gamma\), \(0<\delta<1/2\), прежний возвращённый целый вектор имеет сигнал порядка \(m^\delta/L^{2\delta}\). Наша текущая all-\(P\) цена сравнительно с ним сохраняет отношение
\[
 m^{1/2-\delta}L^{2\delta}\longrightarrow\infty.
\tag{7.3}
\]
Это сравнение цены достаточного сертификата с условным сигналом, не оценка фактической ошибки снизу. Нуль не назначается численно. Меньшая полилогарифмическая полоса S12 не меняет смешанный характер (4.1); наша all-\(P\) цель не заменена оценкой только на ней. Никакого нового cutoff/contact/profile-return для пары не требуется: физические функции в попытке не менялись.

### 8.2. Сильнейшее возражение

**Возражение:** бесконечные исключительные множества находятся в том числе очень далеко, где \(\rho_c\) мала; а ненулевой pair-character ещё не оценивает массу сложного source-defined множества.

**Ответ:** верно. Именно поэтому (3.11) используется только для отказа буквальной finite-measure гипотезе, а (4.10) — только для отказа равномерному Haar-moment возврату. Ни из одного не выводится спектральный знак \(A\), \(C^0\) или \(C_{\rm sf}\). В частности,

может быть сколь угодно малой при большом \(Y\), хотя множество имеет бесконечную меру.

**Второе возражение:** finite-second-moment оплата груба. Это тоже верно. (6.4) — строгий анализ цены именно выписанного конверта, а не доказательство оптимальности всех статистических/моментных методов. Улучшение signed-части (5.1) или event-specific совместная оценка не исключены.

## 12. Полные исполняемые приложения

Каждый размер и SHA-256 относятся только к телу внутри ограды, включая конечный LF. Для извлечения сохранить следующий код как `extract_q36.py` рядом с Markdown и запустить `python extract_q36.py`. Он проверяет пять assets перед записью, не исполняет содержимое автоматически.

from pathlib import Path
import hashlib
import re

md = Path("PROSHKA_CCM_SIGNED_DENSITY_ROLLBACK_Q36_VERDICT_2026-10-26.md")
raw = md.read_bytes()
out = Path("q36_replay")
out.mkdir(exist_ok=True)
pattern = rb"^<!-- Q36_ASSET name=([^ ]+) bytes=(\d+) sha256=([0-9a-f]{64}) -->\n```[^\n]*\n"
count = 0
for mt in re.finditer(pattern, raw, re.M):
    name, size, sha = mt.groups()
    name = name.decode("utf-8")
    if Path(name).name != name:
        raise ValueError("Unsafe asset path")
    size = int(size)
    body = raw[mt.end():mt.end()+size]
    if hashlib.sha256(body).hexdigest() != sha.decode():
        raise ValueError("Hash mismatch: " + name)
    if not raw[mt.end()+size:].startswith(b"```\n<!-- Q36_END_ASSET -->"):
        raise ValueError("Framing mismatch: " + name)
    (out/name).write_bytes(body)
    count += 1
if count != 5:
    raise ValueError("Expected exactly five assets")
print("Verified and extracted", count, "assets")

#!/usr/bin/env python3
"""Verify the exact Q36 request and its twelve byte-locked source bodies."""
from pathlib import Path
import argparse
import hashlib
import json
import re

EXPECTED = 'be32d09c682a6993eba01dd8dea28a996c8b1f5a3c4c0879df4a05be17448d9e'

def verify(path):
    raw = Path(path).read_bytes()
    digest = hashlib.sha256(raw).hexdigest()
    if (len(raw), raw.count(b'\n'), digest) != (140635, 2263, EXPECTED):
        raise ValueError('Canonical byte/LF/SHA mismatch')
    raw.decode('utf-8', errors='strict')
    pat = rb'^BEGIN_SOURCE (S\d+) ([^\n]+)\nBYTES: (\d+)\nSHA256: ([0-9a-f]{64})\nBODY:\n'
    rows = []
    for mt in re.finditer(pat, raw, re.M):
        sid, name, size, sha = mt.groups()
        size = int(size)
        body = raw[mt.end():mt.end()+size]
        got = hashlib.sha256(body).hexdigest()
        if len(body) != size or got != sha.decode():
            raise ValueError('Body hash mismatch: ' + sid.decode())
        if not raw[mt.end()+size:].startswith(b'\nEND_SOURCE\n'):
            raise ValueError('Body framing mismatch: ' + sid.decode())
        body.decode('utf-8', errors='strict')
        rows.append({'id':sid.decode(), 'name':name.decode(), 'bytes':size,
                     'lf':body.count(b'\n'), 'sha256':got,
                     'start_line':raw[:mt.end()].count(b'\n')+1,
                     'end_line':raw[:mt.end()+size].count(b'\n')})
    if [r['id'] for r in rows] != ['S'+str(i) for i in range(1,13)]:
        raise ValueError('Expected exactly S1 through S12')
    return {'request_bytes':len(raw), 'request_lf':raw.count(b'\n'),
            'request_sha256':digest, 'source_count':len(rows),
            'all_hashes_match':True, 'sources':rows}

def main():
    ap = argparse.ArgumentParser(description=__doc__)
    ap.add_argument('packet',type=Path)
    ap.add_argument('--output',type=Path,default=Path('q36_sources.json'))
    a=ap.parse_args()
    obj=verify(a.packet)
    a.output.write_text(json.dumps(obj,ensure_ascii=False,indent=2)+'\n',encoding='utf-8')
    print(json.dumps({'source_count':obj['source_count'],'all_hashes_match':True}))

if __name__=='__main__':
    main()
