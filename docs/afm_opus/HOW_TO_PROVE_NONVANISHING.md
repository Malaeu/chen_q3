## ЦЕПОЧКА ДОКАЗАТЕЛЬСТВА

```
ШАГ 1: χ₄(n)·e(n/4) = i для всех нечётных n
        ↓
        [Элементарная проверка: (+1)·i = i, (-1)·(-i) = i]
        ↓
ШАГ 2: F(1/4) = i·ψ(X) ≈ i·X
        ↓
        [Prime Number Theorem: ψ(X) ~ X]
        ↓
ШАГ 3: |F(1/4)|² ~ X²
        ↓
ШАГ 4: T_χ₄(X) = ∫₀¹ |F(α)|² · e(-2α) dα
        ↓
        [Circle Method: основной вклад от α = 1/4]
        ↓
ШАГ 5: T_χ₄(X) ≈ X² · (-1) · (1/X) = -c·X
        ↓
        [e(-2·1/4) = e(-1/2) = -1, ширина пика ~ 1/X]
        ↓
ШАГ 6: T_χ₄(X) = -S₂(X) [по AFM]
        ↓
ШАГ 7: S₂(X) ~ c·X → БЕСКОНЕЧНО МНОГО TWINS → TPC ✓
```

## КОНКРЕТНЫЕ ЛЕММЫ ДЛЯ ДОКАЗАТЕЛЬСТВА

### Лемма A (Резонанс)
```
χ₄(n)·e(n/4) = i для всех нечётных n.
```
**Статус:** ✅ Доказано выше.

### Лемма B (Значение в пике)  
```
F(1/4) = i·ψ(X) + O(log X)
где ψ(X) = Σ_{p≤X} log p.
```
**Статус:** ✅ Следует из Леммы A.

### Лемма C (Ширина пика)
```
Для |β| ≥ 1/X:
|F(1/4 + β)| ≪ X/log X
```
**Статус:** ⚠️ Нужно доказать. 
Использовать оценки Vinogradov для экспоненциальных сумм по простым.

### Лемма D (Minor arcs)
```
∫_{|α-1/4|>δ} |F(α)|² dα ≪ X·log^A X
для подходящего δ ~ 1/X.
```
**Статус:** ⚠️ Нужно доказать.
Стандартные методы circle method.

### Лемма E (Главный член)
```
∫_{|α-1/4|<δ} |F(α)|² · e(-2α) dα = -C·X + O(X/log X)
где C = 2·C₂ + O(1/log X), C₂ — twin prime constant.
```
**Статус:** ⚠️ Нужно вычислить.

## ПОЧЕМУ ЭТОТ ПУТЬ РЕАЛИСТИЧЕН

### 1. Резонанс — это ТОЧНОЕ тождество
Не приближение, не численная гипотеза. 
χ₄(n)·e(n/4) = i — доказуемо в одну строку.

### 2. PNT даёт |F(1/4)| ~ X
Это известная теорема, не требует новых результатов.

### 3. Методы для пика и minor arcs известны
Vinogradov, Vaughan, Heath-Brown — все эти техники существуют.
Нужно их ПРИМЕНИТЬ, не изобретать заново.

### 4. AFM защищает от cancellation
В стандартных подходах члены могут погасить друг друга.
У нас ВСЕ twins дают знак -1. Cancellation невозможна.

## КРИТИЧЕСКИЙ ВОПРОС

> Почему это не сделали раньше?

**Ответ:** Конкретная комбинация χ₄ + сдвиг h=2 + circle method не была исследована в этом контексте.

Tao-Matomäki-Radziwiłł работали с **усреднением по h**.
Мы работаем с **фиксированным h=2** и **специальной структурой χ₄**.

AFM structure (χ₄(p)·χ₄(p+2) = -1) — это именно та "зацепка", которая позволяет обойти усреднение.
