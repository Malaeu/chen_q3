# Принцип конечного сертификата — архитектурная рамка Route B

**Происхождение:** разбор владельца с внешним корреспондентом, 2026-08-26
(две параллельные стены → калибровка → finite-rank constraint collapse →
коэрцитивный сертификат). Формулировки ниже — уже после адверсариальной
чистки: без O(∞), без «геометрия аннулирует автоматически».

## Принцип

Не мощность пространства поиска определяет сложность задачи, а наличие или
отсутствие компактного структурного сертификата. Континуум кандидатов
иногда уничтожается одной формулой (калибровка, dual certificate,
sum-of-squares факторизация); конечная задача иногда остаётся NP-трудной.
Граница проходит не между конечным и бесконечным, а чаще между выпуклым и
невыпуклым.

Короткая форма: не считай все пути — найди свидетеля, перед которым все
остальные пути проигрывают одновременно.

Строгие опоры (классика, не новая математика): вариационный сертификат две
стены/нормаль; калибровки Харви–Лоусона; конечноранговая редукция
квадратичной задачи с m линейными ограничениями к системе Грама m×m;
sum-of-squares разложение E(γ) − h² = ‖v_n − h‖² + ‖v_⊥‖².

Пределы (что принцип НЕ утверждает): Эйлер–Лагранж даёт стационарность, не
глобальность; кратчайшие пути среди 3D-препятствий NP-трудны (Кэнни–Райф);
допустимая эвристика A* не гарантирует узкий конус; discovery и
verification — разные сложности: короткий сертификат может быть сколь
угодно трудно НАЙТИ.

## Целевая форма для Route B

    Universal positivity = coercive tail + finite exact certificate

Разбиение H = V_N ⊕ V_N^⊥; форма блоками (A_N, B_N; B_N*, C_N); если хвост
коэрцитивен (C_N ⪰ μI, μ>0) и взаимодействие контролируется, остаётся
конечный Schur-комплемент A_N − B_N C_N^{-1} B_N* ⪰ 0 — точный конечный
сертификат бесконечномерной позитивности.

## Кандидат Lean-теоремы (сформулирован 2026-08-26, ждёт ратификации судьи)

Абстрактный конечно-сертификатный ресивер — «программа-минимум», доказуемая
одним дешёвым узлом без всякой цикличности (чистая геометрия гильбертова
пространства):

    Теорема (FINITE_CERTIFICATE_RECEIVER). Пусть H — гильбертово
    пространство, V ⊆ H — замкнутое подпространство с ортопроектором P,
    T — ограниченный самосопряжённый оператор, Q(h) = ⟪h, T h⟫. Если
    (i)  хвост коэрцитивен: ⟪w, T w⟫ ≥ μ‖w‖² для всех w ⊥ V, μ > 0;
    (ii) взаимодействие ограничено: ‖P T (1−P)‖ ≤ B;
    (iii) конечная часть с запасом: ⟪v, T v⟫ ≥ ν‖v‖² на V, где ν·μ ≥ B²;
    то Q(h) ≥ 0 для всех h ∈ H.

Доказательство — три строки: h = v + w, Q ≥ ν‖v‖² − 2B‖v‖‖w‖ + μ‖w‖² ≥ 0
по дискриминанту. Конечномерность V не нужна для ресивера; она появится в
поставщике (iii), где конечная проверка и есть «точный сертификат».

VOI-ветки для судьи (по VOI-гейту):
- ЕСЛИ ратифицирует: строится узел-ресивер (~150 строк, входов ноль), и
  три гипотезы получают имена поставщиков, совпадающие с существующими
  фронтами (коэрцитивность хвоста / контроль взаимодействия / конечная
  нижняя грань) — список открытых входов НЕ растёт, W9 соблюдён.
- ЕСЛИ отклонит (напр. преждевременно, пока конкретные формы не приведены
  к этой сигнатуре): рамка остаётся докой, стоимость нулевая.

Уходит судье батчем вместе с отчётом по узлу 1 Sturm-цепи.
