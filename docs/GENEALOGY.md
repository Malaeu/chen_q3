### Где ошибка — дословно из абстракта

> *«The main conceptual correction of the present draft is that the RH endgame
> must run through the **positive-definite / convolution-square Weil cone**,
> not through the broad cone of all even nonnegative compactly supported tests.»*

**Брали не тот конус.** Проверяли положительность на всех чётных неотрицательных
финитных тестах, а работать надо на узком конусе свёрточных квадратов `Φ = ψ * ψ̃`.

### Почему Prime-сертификаты не считались

Публикация называет препятствие прямо:

```
W_K(u) = â*_K(u) − Σ_{ξ_n ∈ Ξ_K} (2Λ(n)/√n)·cos(uξ_n)  ≥ 0  ?

a*_K ∈ L¹  ⟹  â*_K(u) → 0            (Риман–Лебег)
конечная положительная сумма косинусов возвращается
почти к полной массе БЕСКОНЕЧНО ЧАСТО
```

Разность уходит в минус. **Цель недостижима в принципе** — дело не в точности
вычислений и не в мощности машин.

Компактный скалярный пакет `S1/S2/S3/S4` оставлен как «корректная диагностическая
редукция», не как живой маршрут.

### Два маршрута, которые статья оставляет живыми

`sections/Main_closure.tex:1374` — теорема **условная**, с выбором:

```
(i)  fallback packet route:   A1-pd + packet-Rayleigh-pd + PSD-pd
(ii) мост Судзуки/Йосиды:     H1ᶠ ⟹ H2ᶠ ⟹ H3ᶠ ⟹ H4ᶠ
```

Оба ведут к `Q*(t;Φ) ≥ 0` на исправленном конусе `W^pd`, а оттуда — к RH.

Чего конкретно не хватает по тексту: **H1ᶠ** — «симметричный двусторонний
фильтрованный хвостовой мост», чтобы конечная эрмитова энергия Q3 вытянулась
как обобщённая пара форм Судзуки.

## 7. Оценка трёх маршрутов (2026-08-09, наша, не судейская)

Прочитана конструкция (ii) — `sections/Main_closure.tex:1535-1585`:

```
S*_{a,M,N} · G_g[a] · S_{a,M,N} = κ(a)·Q̃_{M,N} + F_{a,M,N}
S*_{a,M,N} · J_a    · S_{a,M,N} = B_{M,N}
B_{M,N} = Δ*_{M,N} Δ_{M,N}        Q̃_{M,N} = Δ*_{M,N} Q_{M+1} Δ_{M,N}

⟹ H3ᶠ filtered gap transfer ⟹ H4ᶠ Suzuki Theorem 1.4

Блокер по автору: exact four-block bulk comparison on the filtered tail
+ finite-dimensional Suzuki cap.

## 11. У маршрута появилась сторона PASS (2026-08-10)

До этого дня в Route B говорила **только сторона KILL**. Прибор из §8 умеет опровергать:
верхняя огибающая Ритца может показать, что пол ниже цели. Подтвердить он не может —
поточечная положительность каждой конечной щели ничего не говорит о `inf_N`.

Вердикт Прошки от 09.08 (`GLOWER_ODD_FLOOR`) сменил конструкцию: вместо ещё одного
расчёта `β_N` доказывается бесконечномерное `Q₁₃^odd(f) ≥ c₀‖f‖²` при `c₀ = 1e-58`. Тогда
каждая конечная матрица — компрессия этой формы, и `β*_N ≥ c₀` выпадает для всех `N`
разом, а `L = inf_N β*_N ≥ c₀ > 0`.

Механизм — Feshbach: голова `H_R` плюс хвост `T_R`; хвост закрывается коэрцитивностью
высоких мод (`D_c ⪰ dI`), голова — одним конечным сертификатом `B_c − d⁻¹R_c*R_c ⪰ 0`.

### Что измерено 10.08 (preflight, read-only, Lean не тронут)

**Вход 1 — где начинается хвостовой пол.**

```
R(μ=1) = 70          K_odd[70:,70:] ⪰ 1·I,  69 проваливается, 70 держит
```

Устойчиво по обрезанию: точное значение 70 при `N = 120` и `N = 240`. Минимальный пивот
застыл — `0.7342389581660078168603269624116358064253` совпадает при `N = 240` и `N = 480`
до сороковой цифры.

Внешняя оценка этой же константы давала вилку `[2·10², 10⁵]` со словами «вся стоимость
проекта сидит в этой вилке». Измерение сузило её в 500 раз и легло **ниже нижнего конца**.

**Вход 2 — конечный сертификат.**

```
