                                                                                                                                                                        
  x-critical - Critical Path & Fragility Analysis                                                                                                                        
                                                                                                                                                                         
  Что делает                                                                                                                                                             
                                                                                                                                                                         
  Превращает хаос (stream of consciousness описание задачи) в структурированный анализ:                                                                                  
                                                                                                                                                                         
  1. Парсит хаос → извлекает структуру                                                                                                                                   
  2. Строит граф зависимостей → кто от кого зависит                                                                                                                      
  3. Классифицирует блокеры → HARD vs SOFT                                                                                                                               
  4. Оценивает хрупкость → risk score 0-100                                                                                                                              
  5. Находит critical path → оптимальный порядок выполнения                                                                                                              
  6. Генерит execution plan → приоритизированный по риску                                                                                                                
                                                                                                                                                                         
  Использование                                                                                                                                                          
                                                                                                                                                                         
  /x-critical "нужно закрыть аксиомы в Q3, есть RKHS и A3 branches..."                                                                                                   
  /x-critical --source PROJECT_STATUS.md "доп контекст"                                                                                                                  
  /x-critical --mode quick "быстрый анализ"                                                                                                                              
                                                                                                                                                                         
  Типы блокеров                                                                                                                                                          
  ┌──────────────┬────────────────────────────────┐                                                                                                                      
  │     Тип      │           Что значит           │                                                                                                                      
  ├──────────────┼────────────────────────────────┤                                                                                                                      
  │ HARD BLOCKER │ Если упадёт — вся ветка мёртва │                                                                                                                      
  ├──────────────┼────────────────────────────────┤                                                                                                                      
  │ SOFT BLOCKER │ Есть workaround                │                                                                                                                      
  ├──────────────┼────────────────────────────────┤                                                                                                                      
  │ DEPENDENCY   │ Надо завершить до следующего   │                                                                                                                      
  ├──────────────┼────────────────────────────────┤                                                                                                                      
  │ INDEPENDENT  │ Можно параллелить              │                                                                                                                      
  └──────────────┴────────────────────────────────┘                                                                                                                      
  Формула риска                                                                                                                                                          
                                                                                                                                                                         
  risk = complexity * 30 + uncertainty * 30                                                                                                                              
       + (is_hard_blocker ? 25 : 10)                                                                                                                                     
       + (blocked_deps / total) * 15                                                                                                                                     
                                                                                                                                                                         
  Логика                                                                                                                                                                 
                                                                                                                                                                         
  Начинаем с самого хрупкого + блокирующего — если что-то сломается, узнаем сразу, а не через месяц работы.                                                              
                                                                                                                                                                         
  Для Q3 проекта это идеально                                                                                                                                            
                                                                                                                                                                         
  Покажет какие axiom'ы самые опасные и в каком порядке их закрывать.
