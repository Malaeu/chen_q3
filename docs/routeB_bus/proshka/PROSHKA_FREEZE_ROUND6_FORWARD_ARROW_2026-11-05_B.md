## S6-B. Прямая положительная цепочка и проверка последнего звена

[ABSTRACT / COFINAL_FAMILY | CONDITIONAL: выходная оценка не предполагается.]

1. **Положительный старт.** Единичная форма в прямой сумме L2-пространств с индексом n in N. Структурные данные — обычная целая решётка, Gaussian exp(-pi n^2 x), её дифференцирование и точная формула Пуассона. Для стандартного xi использовать even kernel Phi(u), определённое через theta и удовлетворяющее xi(1/2+it)=integral_R Phi(u)exp(itu)du. Нормировка и полюсные края будут выведены, не угаданы.

2. **Разрешённые звенья.** X -> S*XS, неотрицательные суммы, Schur product с явно построенной Gram-матрицей, сжатия и обоснованные пределы положительных форм. Конкретный начальный выход — физическая Gram-форма integral Phi(u)|S_m z(u)|^2 du; допускаются дальнейшие операции перечисленных классов, построенные из текущего состояния и целочисленных данных. Для каждого класса доказывается сохранение PSD для любого PSD-входа. Не используются корни из A_m, его eigenvectors, psi-x или неизвестные нули.

3. **Аддитивное звено.** Тождество theta(x)=x^(-1/2)theta(1/x), получаемое суммированием по аддитивной решётке Z. Отдельно различать: точную исходную Gaussian theta; её дифференциальные следствия; общее свойство положительности/чётности полученного ядра. Эти три уровня не подменять друг другом. Делимость/GCD сами по себе не являются этим звеном.

4. **Выход.** Для буквальных A_m и z in K_m требуется A_m[z]>=P_m[z]-C(1+log m)^r G_m[z] с одними C,r по всем поздним целым m. P_m — результат PSD-цепочки, а не положительная часть A_m. Доказательство этой оценки — отдельное обязательное звено. Положительность Phi или промежуточных Gram-матриц не считается доказательством выходной оценки.

5. **Проверяемый более широкий класс поставщика.** Сначала проверить, может ли выходное звено следовать универсально только из положительности, чётности, быстрого убывания theta-производного ядра, его источниковой Fourier/Mellin формулы и аддитивных Poisson-тождеств с их точно преобразованными производными. В этом классе допускаются фиксированные чётные полиномиальные дифференциальные операторы, если их применение оставляет ядро положительным. Это более широкий класс, чем строго исходное Phi. Его опровержение убивает только такое универсальное выходное звено, не все источник-специфические цепочки для Q.

6. **Отрицательный контроль, зарегистрированный заранее.** a=1/3, gamma=100. Определить

   Q(z)=((z-a)^2+gamma^2)((z+a)^2+gamma^2),
   Phi_plant=Q(-d/du)Phi
            =Phi''''+2(gamma^2-a^2)Phi''+(gamma^2+a^2)^2 Phi.

   Проверить аналитически, остаётся ли Phi_plant строго положительным на R. Ожидаемый дешёвый судья — точный рациональный полином одной theta-слагаемой при y=pi n^2 exp(2u)>=pi>3, а не численная сетка. Нормировка может быть поделена на положительную Q(1/2), чтобы xi_plant(0)=xi_plant(1)=1/2. Если gamma=100 не проходит, это записывается как MISS; не менять параметр задним числом. Для нового параметра нужен новый явно обозначенный тест, не правка freeze.

7. **Собственный источник plant.** xi_plant(s)=Q(s-1/2)xi(s)/Q(1/2). В форму Вейля добавляется весь quartet-source, не оставляются прежние Lambda и Gamma под видом полного plant. Строгий отрицательный судья должен использовать это добавление и исходный K_m/G_m, с оплаченными cutoff, projection и полюсными моментами. Нельзя считать положительный theta-Gram отрицательным свидетелем для настоящего A_m.

### Предсказания до проверок

P1: Phi_plant при указанных a,gamma остаётся положительным; ожидается точное алгебраическое доказательство на полупрямой, без Arb.
P2: положительность всех Gram-стадий и аддитивные Poisson-следствия переживут plant, но универсальный возврат к полной Weil-форме с polylog-дефектом не переживёт его. Это должно дать запрет всего класса в пункте 5, а не одной матрицы.
P3: один лишь multiplicative/GCD поставщик переносится на формальный свободный коммутативный моноид DMV. Обычное аддитивное Gaussian Poisson-звено на него автоматически не переносится. Не приписывать DMV функциональное уравнение.
P4: для собственной кривой E/F3 цепочка identity -> Fourier/spectral Gram даёт полный положительный выход; не подставлять zeta-Gamma в кривую.
P5: если универсальное выходное звено не работает, для Q останется необходимость использовать точные коэффициенты недеформированного theta-ядра либо другой источник-специфический аддитивный механизм. Отсутствие такого механизма здесь означает RESEARCH_DEBT, не смерть RH-маршрута.

Никаких больших численных прогонов. Символьный тест фиксирован: вычислить полином Q(-D)[exp(u/2)(4y^2-6y)exp(-y)]/[exp(u/2-y)], где D=1/2+2y*d/dy-2y на полиномиальном множителе; доказать знак для y>=3 точными рациональными средствами. Если выбранная форма сертификата не проходит, знак остаётся OPEN до другого аналитического доказательства. Нулевой остаток различается точным полиномиальным тождеством; внеосевой нуль — ненулевым вычетом логарифмической производной, не машинным near-zero.
