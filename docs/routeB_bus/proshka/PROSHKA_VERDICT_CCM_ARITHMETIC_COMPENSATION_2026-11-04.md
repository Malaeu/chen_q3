## 2. Неизменяемый объект и один точный нулевой тест

**[ABSTRACT / COFINAL_FAMILY | PAPER; inherited R1, R5.]**

Пишем \(I_L=(-L/2,L/2)\), \(L=\log m\), \(\omega_j=2\pi j/L\). Синтез \(\mathcal S_m:\mathbb C^{m+1}\to L^2(I_L)\) использует исходные физически ортонормированные косинусы

\[
 \phi_j(x)=d_j(-1)^j L^{-1/2}\cos(\omega_jx),\qquad
 d_0=1,\quad d_j=\sqrt2\ (j>0).
\]

Все функции вне окна продолжены нулём. Для вещественного чётного теста:

\[
 \begin{split}
 W[f]&=\int_0^\infty j(u)\|f-T_uf\|_2^2du-c_*\|f\|_2^2
       +|\langle p,f\rangle|^2
       -2\sum_{n\ge2}\frac{\Lambda(n)}{\sqrt n}
                    \int f(x)f(x+\log n)\,dx,\\
 j(u)&=\frac{e^{-u/2}}{1-e^{-2u}},\qquad
 c_*=\gamma_E+\log(8\pi)+\frac\pi2,\qquad
 p(x)=\sqrt2\cosh(x/2).
 \end{split}                                                     \tag{2.1}
\]

Комплексная эрмитова форма получается поляризацией; все доказательства допускают комплексные коэффициенты в том же чётном carrier. На \(V_m\) это в точности \(A_m=H_m+P_m-B_m\). В этом файле \(B_m\) означает оператор с положительными коэффициентами \(\Lambda(n)/\sqrt n\), но **не** утверждается \(B_m\succeq0\). В R1 знак буквы B местами противоположен; (2.1) устраняет неоднозначность.

Пусть \(\mathscr D_c=C_c^\infty(\mathbb R)_{\rm even}\), а \(\mathscr D=\mathcal S_{\exp,\rm even}\): все производные имеют любой фиксированный экспоненциально взвешенный \(L^2\)-норматив. На \(\mathscr D\) все слагаемые (2.1) сходятся. Fourier-конвенция:

\[
 \widehat f(z)=\int_{\mathbb R}f(x)e^{-izx}dx,\qquad
 \Xi(z)=\xi(1/2+iz),\qquad
 \widehat h_0(z)=\Xi(z)e^{-z^2}.                              \tag{2.2}
\]

Это **определение через целую ξ**, не произведение по неизвестным нулям. Например, ξ можно определить через обычную тета-функцию:

\[
 \xi(s)=\frac12+\frac{s(s-1)}4\int_1^\infty(\Theta(u)-1)
               [u^{s/2}+u^{(1-s)/2}]\frac{du}{u},\quad
 \Theta(u)=\sum_{n\in\mathbb Z}e^{-\pi n^2u}.                 \tag{2.3}
\]

\(h_0\) вещественна, чётна, ненулевая и принадлежит \(\mathscr D\). Горизонтальные сдвиги контура в (2.2), оплаченные Gaussian, дают все требуемые экспоненциальные нормы. Обратный Fourier-интеграл также делает \(h_0(x)\) целой по x; её быстрое убывание равномерно в каждой горизонтальной x-полосе.

Унаследованная **смешанная** явная формула даёт

\[
                  W(h_0,f)=0\quad(f\in\mathscr D).           \tag{2.4}
\]

В каждом комплексном нуле стоит точный нуль \(\widehat h_0\). Абсолютный квадрат в комплексной точке не подставляется. Все кратности, Γ и полюс сохранены. Это радикальность, а не следствие RH.

Фиксируем чётную \(\chi\in C_c^\infty(-1,1)\), равную 1 на \([-1/2,1/2]\), и обозначаем

\[
 \mathcal I_m f=P_m[\chi(2x/L)f(x)],\qquad
 z_m(f)=\mathcal S_m^*\mathcal I_m f.                        \tag{2.5}
\]

\(P_m\) — именно исходная косинусная проекция. Из R1 §4, для каждого фиксированного \(f\in\mathscr D\) и любого фиксированного N:

\[
 \|\mathcal I_m f-f\|_2=O_{f,N}(m^{-N}),\qquad
 z_m(f)^*A_mz_m(f)=W[f]+O_{f,N}(m^{-N}).                    \tag{2.6}
\]

Endpoint-следы после проекции включены в этот возврат. **\(h_0\) не вставляется в конечную матрицу напрямую:** всюду далее используется \(f_m=\mathcal I_m h_0\). В частности,

\[
 W[f_m]=O_N(m^{-N}),\qquad \|f_m\|_2^2\longrightarrow H_0^2:=\|h_0\|_2^2>0.
 \tag{2.7}
\]

## 3. Настоящая эйлерово-мёбиусова факторизация — до вывода о знаке

**[FINITE_CELL | PAPER; точная арифметическая алгебра для каждого m.]**

На полном вспомогательном \(L^2(I_L)\) определим причинный обрезанный сдвиг

\[
 (S_uf)(x)=\mathbf1_{I_L}(x-u)f(x-u),\quad u\ge0.
\]

Точно \(S_uS_v=S_{u+v}\); при \(u\ge L\) это нулевой оператор. Поэтому для \(e_n=n^{-1/2}S_{\log n}\):

\[
 e_ne_k=e_{nk},\qquad e_n=0\ (n\ge m).
\]

Введём **полные** конечные операторы

\[
 Z_L=\sum_{n<m}e_n,\qquad M_L=\sum_{n<m}\mu(n)e_n,\qquad
 C_L=\sum_{2\le n<m}\Lambda(n)e_n.                          \tag{3.1}
\]

Все операции в (3.1) предшествуют сжатию на \(V_m\). Ни обратная от сжатой Z, ни искусственная периодизация не используется.

Обычная единственность разложения целых даёт

\[
 \boxed{M_LZ_L=Z_LM_L=I,\qquad
 Z_L=\prod_{p<m}(I-e_p)^{-1},\qquad
 \log Z_L=\sum_{p^k<m}\frac{e_{p^k}}k.}                    \tag{3.2}
\]

Ряды здесь конечны: алгебра положительных сдвигов нильпотентна. Коэффициент при \(e_n\) в первом равенстве — \(\sum_{d\mid n}\mu(d)=\mathbf1_{n=1}\). Никакая оценка Mertens не вводится.

Положим \(Y_df(x)=(x+L/2+d)f(x)\), \(d\ge0\). Тогда \(Y_d\succeq0\) и

\[
 [Y_d,e_n]=(\log n)e_n,
 \qquad
 \boxed{C_L=M_L[Y_d,Z_L]=M_LY_dZ_L-Y_d.}                  \tag{3.3}
\]

Коэффициент (3.3) равен \(\sum_{a\mid n}\mu(a)\log(n/a)=\Lambda(n)\). **Это точное место обычной арифметики ζ.** Все степени простых остаются в \(C_L\). На границе \(n=m\) сдвиг равен нулю по мере перекрытия, а не по приблизительному отсечению.

Исходный арифметический блок есть

\[
 B_m=\mathcal S_m^*(C_L+C_L^*)\mathcal S_m.                \tag{3.4}
\]

Теперь применяем точную поляризацию, с произвольным \(t>0\):

\[
 \begin{split}
 R_m(t,d)&=Y_d^{1/2}\bigl(\sqrt t\,Z_L-t^{-1/2}M_L^*\bigr)\mathcal S_m,\\
 E_m(t,d)&=H_m+P_m+2\mathcal S_m^*Y_d\mathcal S_m\\
 &\quad-\mathcal S_m^*\bigl(t Z_L^*Y_dZ_L+t^{-1}M_LY_dM_L^*\bigr)\mathcal S_m.
 \end{split}                                                   \tag{3.5}
\]

**Получена требуемая по форме исходниковая идентичность**

\[
                 \boxed{A_m=R_m(t,d)^*R_m(t,d)+E_m(t,d).}  \tag{3.6}
\]

Доказательство — раскрытие квадрата. Два смешанных члена дают
\(M_LY_dZ_L+Z_L^*Y_dM_L^*=C_L+C_L^*+2Y_d\), что в точности возвращает (3.4). R построен из целых, μ и положительного координатного оператора; нули ζ и спектральный квадратный корень A не использованы. Γ и полюс не потеряны: они целиком находятся в E.

Но **наличие (3.6) ещё ничего не говорит о нижнем поле E**. Следующая теорема решает именно этот вопрос, для всех t и d одновременно.

## 4. Теорема 1: весь скалярно-балансируемый класс имеет большой отрицательный остаток

**[COFINAL_FAMILY | PAPER; KILL_SCOPE=THEOREM_SHAPE.]** Существуют \(c>0\) и \(m_0\), такие что

\[
 \boxed{\forall m\ge m_0\ \forall t>0\ \forall d\ge0:\quad
 \lambda_{\min}E_m(t,d)\le-c\,L\,m^{1/4}.}                 \tag{4.1}
\]

Следовательно, никакой выбор \(t=t_m>0,d=d_m\ge0\) не делает (3.6) факторизацией с \(E_m\succeq-o(1)I\), даже на неограниченной подпоследовательности. Добавление к R ещё положительных ортогональных каналов только ухудшает этот остаток.

### 4.1. Две части одного и того же исходникового свидетеля

Работаем с фиксированным \(h=h_0\) из (2.2). На всей прямой определим абсолютно, локально равномерно сходящиеся суммы

\[
 z(x)=\sum_{n\ge1}n^{-1/2}h(x-\log n),\qquad
 v(x)=\sum_{n\ge1}\mu(n)n^{-1/2}h(x+\log n).               \tag{4.2}
\]

Сходимость использует быстрое убывание h, а не гипотезу об отмене μ.

**Правая часть окна.** Положим
\(k(y)=y^{-1/2}h(-\log y)\), \(y>0\). Функция и её производная интегрируемы, а \(k(0)=0\). Обычная правосторонняя риманова сумма имеет явную ошибку

\[
 \left|\frac1X\sum_{n\ge1}k(n/X)-\int_0^\infty k(y)dy\right|
 \le\frac1X\int_0^\infty|k'(y)|dy.
\]

Обозначая

\[
 a_0:=\int_0^\infty k(y)dy
 =\int_{\mathbb R}e^{-x/2}h(x)dx
 =\widehat h(-i/2)=\xi(1)e^{1/4}=\frac{e^{1/4}}2>0,
\]

получаем, при \(x\to+\infty\),

\[
 z(x)=a_0e^{x/2}+O(K_1e^{-x/2}),\qquad
 K_1=\int_0^\infty|k'(y)|dy<\infty.                       \tag{4.3}
\]

Это не PNT: суммируются все обычные целые n. Константа \(\xi(1)=1/2\) — точная полюсная нормировка. Она не заменена эвристикой.

**Центр окна.** Функция v не тождественно нулевая. Действительно, абсолютная двойная сумма даёт

\[
 \sum_{n\ge1}n^{-1/2}v(x+\log n)
 =\sum_{r\ge1}r^{-1/2}h(x+\log r)\sum_{d\mid r}\mu(d)=h(x). \tag{4.4}
\]

Абсолютная сходимость следует, например, из \(d(r)\le r\) и любого достаточно большого экспоненциального веса для h. Так как h ненулевая, v ненулевая. Более того, v целая по x: ряд нормально сходится в каждой компактной комплексной области. Поэтому

\[
 \beta:=\|v\|_{L^2(-1,1)}>0,\qquad
 K:=1+\|z\|_{L^2(-1,1)}<\infty.                           \tag{4.5}
\]

\(\beta\) — норма **явной сходящейся функции (4.2)**, её строгая положительность доказана (4.4) и аналитичностью. Это не неизвестный спектральный gap.

### 4.2. Возврат обеих областей в буквальное V_m

Пусть \(f_m=\mathcal I_mh\), \(g_L=\chi(2x/L)h\). Элементарные операторные границы
\(\|Z_L\|,\|M_L\|\le\sum_{n<m}n^{-1/2}\le2\sqrt m\)
используются **только для оплаты ошибки проекции**, не вместо основного арифметического знака. С (2.6) они показывают, что замена \(g_L\) на \(f_m\) после Z или M стоит быстрее любой обратной степени m в \(L^2\).

Для замены \(g_L\) на h в полной сумме используется
\(|h-g_L|(x)\le C_A e^{-AL/4}e^{-A|x|}\), с любым фиксированным A после увеличения исходного веса. При \(x\ge0\) и \(A>1/2\)

\[
 \sum_{n\ge1}n^{-1/2}e^{-A|x-\log n|}\le C'_Ae^{x/2}.      \tag{4.6}
\]

Это получается разбиением \(n\le e^x\) и \(n>e^x\). Для \(x\in[-1,1]\) аналогичная сумма с \(x+\log n\) равномерно конечна. Поэтому (4.3)–(4.5) переносятся в Z и M на исходных \(f_m\), со сверхполиномиально малой добавкой.

Положим

\[
 b=\tfrac12\log2,\quad J_m=(L/2-b,L/2),\quad
 a_R=a_0\sqrt{1-e^{-b}}>0.
\]

Из (4.3), равномерно на правом краю,

\[
 \|Z_Lf_m\|_{L^2(J_m)}\ge\tfrac12a_Rm^{1/4},\quad
 \|f_m\|_{L^2(J_m)}\longrightarrow0.                       \tag{4.7}
\]

И здесь имеется **точное краевое тождество**:

\[
                  (M_L^*f_m)(x)=f_m(x)\quad(x\in J_m).    \tag{4.8}
\]

Причина: для любого n≥2 будущий аргумент \(x+\log n\) уже вне окна, поскольку \(b<\log2\). Все такие члены M* равны нулю по поддержке, не выброшены как ошибка.

На фиксированном центральном отрезке, для достаточно поздних m,

\[
 \|M_L^*f_m\|_{L^2(-1,1)}\ge\beta/2,\qquad
 \|Z_Lf_m\|_{L^2(-1,1)}\le K.                             \tag{4.9}
\]

Все пороги в (4.7)–(4.9) не зависят от t и d.

### 4.3. Любая скалярная балансировка проигрывает в одной из двух областей

Если \(t\ge m^{-1/4}\), используем правый край. Из (4.7)–(4.8), после увеличения \(m_0\) так, чтобы \(\|f_m\|_{J_m}\le a_R/4\),

\[
 \begin{split}
 \|R_m(t,d)z_m(h)\|^2
 &\ge (L-b)t\bigl(\|Z_Lf_m\|_{J_m}-t^{-1}\|f_m\|_{J_m}\bigr)^2\\
 &\ge \frac{a_R^2}{32}L m^{1/4}.
 \end{split}                                                   \tag{4.10}
\]

Здесь \(t^{-1}\le m^{1/4}\), а \(Y_d\ge L-b\) на \(J_m\).

Если \(0<t<m^{-1/4}\), используем центр. При \(m^{-1/4}K\le\beta/4\) и \(L\ge4\):

\[
 \begin{split}
 \|R_m(t,d)z_m(h)\|^2
 &\ge (L/2-1)t^{-1}
       \bigl(\|M_L^*f_m\|_{(-1,1)}-t\|Z_Lf_m\|_{(-1,1)}\bigr)^2\\
 &\ge \frac{\beta^2}{64}L m^{1/4}.
 \end{split}                                                   \tag{4.11}
\]

Таким образом, с

\[
 c_R=\min\{a_R^2/32,\,\beta^2/64\}>0,
 \qquad c=\frac{c_R}{4H_0^2}>0,
\]

один и тот же \(f_m\) даёт \(\|R_m(t,d)z_m(h)\|^2\ge c_R Lm^{1/4}\) для **всех** t,d. Наконец, точное (3.6) и (2.7) дают

\[
 \begin{split}
 \lambda_{\min}E_m(t,d)
 &\le\frac{z_m(h)^*E_m(t,d)z_m(h)}{\|f_m\|^2}\\
 &=\frac{W[f_m]-\|R_m(t,d)z_m(h)\|^2}{\|f_m\|^2}
 \le-cLm^{1/4}<0.
 \end{split}                                                   \tag{4.12}
\]

Это допустимый **верхний** Rayleigh envelope. Константа c определена через сходящиеся исходниковые интегралы и строго положительна. Порог m₀ конечен; его численное значение здесь не вычислено. Теорема доказана.

### 4.4. Точный смысл собственного FATAL

**[COFINAL_FAMILY | PAPER.]** (3.6) — правильное тождество, но попытка получить из него положительность через малый отрицательный остаток — невозможна для всего указанного класса. Это сильнее неуспеха какой-либо достаточной оценки: показано, что **сам остаток** имеет большой отрицательный Rayleigh quotient.

При этом (4.12) не утверждает отрицательности A. На том же свидетеле большая положительная энергия R*R обязана компенсироваться большим отрицательным E, поскольку полный источник равен \(O_N(m^{-N})\). Выбросить эту компенсацию нельзя.

Теорема не исключает другое разложение, балансировку оператором вместо положительного скаляра, пространственно зависимую балансировку или объединение предложенных каналов **до** взятия квадрата. Отсутствие анализа этих классов не маркируется как их невозможность.

## 5. Более общий запрет: нет ненулевой замыкаемой положительной части

### 5.1. Плотный радикал в физической и Sobolev-топологиях

**Лемма 2. [ABSTRACT | PAPER.]** Для \(a\in\mathbb R\) положим

\[
 \widehat h_a(z)=\Xi(z)e^{-z^2}\cos(az),\qquad
 \mathcal R=\operatorname{span}\{h_a:a\in\mathbb R\}.
\]

Тогда \(\mathcal R\subset\mathscr D\), \(W(h,f)=0\) для \(h\in\mathcal R,f\in\mathscr D\), и \(\mathcal R\) плотен в \(H^r(\mathbb R)_{\rm even}\) для каждого фиксированного целого \(r\ge0\).

**Доказательство плотности.** Если g ортогональна всем \(h_a\) в \(H^r\), то чётная \(L^1\)-функция
\((1+t^2)^r\overline{\widehat g(t)}\Xi(t)e^{-t^2}\)
имеет нулевое косинус-преобразование. Интегрируемость следует из Cauchy–Schwarz в \(H^r\). Единственность Fourier-преобразования даёт её равенство нулю почти всюду. Ненулевая целая Ξ имеет на вещественной оси лишь изолированные нули, поэтому \(\widehat g=0\) почти всюду. Радикальность — тот же безусловный множитель Ξ в полной смешанной явной формуле. □

Это плотность **в указанной норме**, не в норме формы W. Смешивать эти топологии нельзя.

### 5.2. Теорема 2: замыкаемый квадрат не может быть глобальным положительным слагаемым

**[ABSTRACT | PAPER; KILL_SCOPE=THEOREM_SHAPE.]** Пусть \(T:\mathscr D_c\to\mathcal K\) — линейный оператор в некоторое гильбертово пространство, замыкаемый относительно физического \(L^2\). Если

\[
                      \|Tf\|^2\le W[f]\quad(f\in\mathscr D_c),    \tag{5.1}
\]

то \(T=0\). Здесь **замыкаемость** означает: из \(f_n\to0\) в \(L^2\) и \(Tf_n\to y\) в \(\mathcal K\) следует \(y=0\).

**Доказательство.** Для любого \(h_a\) берём компактные обрезки \(h_{a,R}=\chi(x/R)h_a\). Они сходятся к \(h_a\) в \(L^2\), а полная исходниковая непрерывность даёт \(W[h_{a,R}]\to0\). Из (5.1) следует \(Th_{a,R}\to0\). Поэтому замыкание графика T содержит \((h_a,0)\) для всех a. Ядро замкнутого оператора замкнуто в исходном \(L^2\); оно содержит плотный линейный span из Леммы 2. Следовательно, это весь \(L^2_{\rm even}\), а замыкание T — нулевой оператор. □

Ненулевая замыкаемая неотрицательная квадратичная форма также не может быть минорантой W. Для сумм квадратов это означает, что каждый замыкаемый положительный канал должен исчезнуть. Из этого **не** следует отрицательность W: при RH положительная W является сингулярной относительно глобальной физической \(L^2\)-топологии.

### 5.3. Теорема 3: точный возврат запрета в конечные окна

**[COFINAL_FAMILY | PAPER; KILL_SCOPE=THEOREM_SHAPE.]** Пусть на неограниченной семье исходных m предлагаются

\[
 A_m=F_m^*F_m+E_m,\qquad F_m:\mathbb C^{m+1}\to\mathcal K_m.
\]

Предположим, что существуют сокращения \(C_m:\mathcal K_m\to\mathcal K\), \(\|C_m\|\le1\), и ненулевой замыкаемый оператор \(T:\mathscr D_c\to\mathcal K\), для которых

\[
 C_mF_mz_m(f)\longrightarrow Tf\quad(f\in\mathscr D_c).   \tag{5.2}
\]

Тогда \(E_m\succeq-o(1)I\) невозможно. Более точно, существуют фиксированные \(f\in\mathscr D_c\) и \(\eta>0\), такие что для всех достаточно поздних m этой семьи

\[
                         \lambda_{\min}E_m\le-\eta<0.     \tag{5.3}
\]

**Доказательство.** По Теореме 2 для ненулевого T найдётся компактный f с \(\delta:=\|Tf\|^2-W[f]>0\). По (2.6), (5.2) и норме сокращения

\[
 \limsup_m\frac{z_m(f)^*E_mz_m(f)}{\|z_m(f)\|^2}
 \le\frac{W[f]-\|Tf\|^2}{\|f\|^2}
 =-\frac\delta{\|f\|^2}.
\]

Можно взять \(\eta=\delta/(2\|f\|^2)\) после конечного порога. Это снова отрицательный **верхний** envelope остатка. □

(5.2) — существенная гипотеза. Не допускается автоматически приписывать её произвольным \(F_m\), пределам критических эйлеровых произведений или перестраиваемым спектральным квадратным корням. Равномерная ограниченность самого F не требуется, но **замыкаемость ненулевого предельного канала** требуется.

### 5.4. Один явный свидетель убивает все ненулевые обычные свёрточные квадраты

**Следствие 3.1. [COFINAL_FAMILY | PAPER.]** Пусть

\[
 Tf=\sum_{n\in\mathcal F}a_n f(\,\cdot-\log n),
 \quad \mathcal F\text{ конечное},\quad (a_n)\ne0,
\qquad q(t)=\sum_{n\in\mathcal F}a_ne^{-it\log n},
\]

имеем для одного и того же \(h_0\)

\[
 \eta_T:=\frac{\|Th_0\|^2}{\|h_0\|^2}
 =\frac{\int_{\mathbb R}|q(t)|^2|\Xi(t)|^2e^{-2t^2}dt}
        {\int_{\mathbb R}|\Xi(t)|^2e^{-2t^2}dt}>0.           \tag{5.4}
\]

Различные \(\log n\) дают линейно независимые экспоненты; это можно проверить производными в нуле и Vandermonde. Ненулевой q не может исчезать почти всюду. Поэтому числитель строго положителен. Ни положительный спектральный зазор T, ни расположение нулей ζ не нужны.

Здесь «сохраняется как канал» означает точное условие
\(\|F_m z\|\ge\|T\mathcal S_m z\|\) для всех z; например, \(T\mathcal S_m\) входит в Fₘ как отдельная ортогональная компонента. Поскольку фиксированный T ограничен в L², (2.6) даёт \(T\mathcal I_mh_0\to Th_0\). Поэтому
\(\limsup\lambda_{\min}E_m\le-\eta_T\).
Это включает фиксированные конечные эйлеровы/мёбиусовы фильтры. Для более общего канала достаточно явно доказать его сходимость на h₀; одной гипотезы (5.2), сформулированной лишь на компактных тестах, для этой конкретной константы η_T не подставляют. Аналогичное утверждение верно для абсолютно суммируемых свёрточных коэффициентов с ненулевым Fourier-множителем.

В частности, \(T=I-T_{\log2}\) не имеет фиксированного положительного спектрального зазора, но всё равно исключён. Запрет поэтому не является лишь повторением «нет равномерного положительного margin».

### 5.5. Положительная вещественная Fourier-мера должна неявно найти реальные нули

**Следствие 3.2. [ABSTRACT | PAPER.]** Пусть положительная локально конечная мера ν задаёт конечный функционал на \(\mathscr D\), и

\[
          \int_{\mathbb R}|\widehat f(t)|^2d\nu(t)\le W[f]
          \quad(f\in\mathscr D).                         \tag{5.5}
\]

Подстановка h₀ даёт

\[
          \operatorname{supp}\nu\subset\{t\in\mathbb R:\Xi(t)=0\}. \tag{5.6}
\]

Действительно, интеграл неотрицательной функции \(|\Xi(t)|^2e^{-2t^2}\) равен нулю. Вне её нулевого множества ν равна нулю. В частности, ненулевая абсолютно непрерывная положительная плотность здесь невозможна.

Это не запрещает **вывести** сингулярную положительную меру из источника. Но просто заменить источник положительной гладкой Fourier-плотностью нельзя: такой механизм уже опровергнут истинной ζ. Условие (5.6) — необходимое следствие, а не конструкция ν и не доказательство RH.

## 6. Самая сильная атака на запрет: не перепутана ли топология?

**[ABSTRACT | PAPER.]** Положительная форма действительно может не иметь ненулевого замыкаемого положительного слагаемого в данной исходной топологии. Простейший контроль на гладких функциях на [0,1]:

\[
 q[f]=|f(0)|^2\ge0,\qquad f_n(x)=(1-x)^n,
 \qquad \|f_n\|_2^2=\frac1{2n+1}\longrightarrow0,
 \quad q[f_n]=1,
 \quad q[f_n-f_k]=0.                                    \tag{6.1}
\]

Эта положительная форма не замыкаема в \(L^2(0,1)\). Поэтому вывод «нет замыкаемого квадрата ⇒ форма не положительна» ложен. Контроль (6.1) был включён в исполняемую проверку именно против такого усиления.

Тот же барьер нельзя обойти фразой «каждая конечная матрица имеет обычный квадратный корень». Конечномерные операторы замыкаемы; их **изменяющийся предельный объект** не обязан удовлетворять условию Теоремы 3. При RH нулевая Gram-реализация использует evaluation-функционалы на вещественных нулях, которые не являются непрерывными функционалами глобального физического L². Это объясняет совместимость запрета с условной положительностью, но не строит допустимую положительную меру без RH.

Короткий SOS на окне log 3 из R2 также не опровергается. На одном фиксированном коротком интервале нет всего глобального плотного радикала: обрезка hₐ всё большими интервалами выходит за этот фиксированный carrier. Запрет говорит о **сохранении одного регулярного положительного канала при неограниченном росте окна**, а не о невозможности локальной факторизации.

Наконец, h₀ и hₐ используются как **адверсариальные тесты**, а не как скрытое определение положительного R. Ряд по неизвестным нулям не используется для построения проверяемого квадрата (3.5). Ссылка на полную безусловную явную формулу служит доказательству точного нуля теста. Это существенно другой логический статус.

## 7. Двойственная репрезентация: достаточно фиксированного Sobolev-пола

### 7.1. Теорема 4 — более слабый consumer, но не готовый supplier

**[COFINAL_FAMILY | PAPER; inherited full-source criterion plus Lemma 2.]** Зафиксируем целое r≥0 и

\[
 X_m=\operatorname{diag}(\omega_j^2)_{j=0}^m,
 \qquad G_m^{(r)}=(I+X_m)^r.
\]

Для неизменного исходного CCM следующие утверждения эквивалентны:

\[
 \begin{split}
 &\text{RH};\\
 &\exists C\ge0\ \exists m_k\to\infty:
       \quad A_{m_k}\succeq-CG_{m_k}^{(r)}.
 \end{split}                                             \tag{7.1}
\]

C и r фиксированы, **не** зависят от k. Это утверждение об импликациях. В этой работе не доказана ни RH, ни нижняя оценка в правой части.

**Доказательство возврата graph-нормы.** Для любого фиксированного \(f\in\mathscr D\), \(g_m=\chi(2x/L)f\) гладко и тождественно равно нулю возле концов окна. Его периодическое продолжение гладко. Parseval для косинусного ряда и его производных даёт

\[
 \begin{split}
 z_m(f)^*G_m^{(r)}z_m(f)
 &=\sum_{j=0}^m(1+\omega_j^2)^r|\langle\phi_j,g_m\rangle|^2\\
 &=\sum_{\ell=0}^r\binom r\ell
       \| (\mathcal I_m f)^{(\ell)}_{\rm interior}\|_{L^2(I_L)}^2
 \longrightarrow \|f\|_{H^r(\mathbb R)}^2.                \tag{7.2}
 \end{split}
\]

Для обоснования последней сходимости выберем любое целое q>r. Нормы \(g_m^{(q)}\) равномерно ограничены по m; Fourier-хвост производной порядка ℓ ограничен \(\Omega_m^{\ell-q}\|g_m^{(q)}\|_2\), где \(\Omega_m=2\pi m/L\to\infty\). Производные самого cutoff сходятся к производным f в L². Поэтому (7.2) действительно относится к **тому же** finite carrier.

Важно: в (7.2) стоят внутренние производные. Нулевое продолжение косинуса может иметь скачок на конце и не принадлежать глобальному H¹. Оно не объявляется таковым; граничная цена в W отдельно оплачена унаследованным (2.6).

Теперь предположим нижний пол в (7.1). Сначала для каждого **фиксированного** f отправляем k→∞, используя (2.6) и (7.2):

\[
                    W[f]\ge-C\|f\|_{H^r}^2
                    \quad(f\in\mathscr D).              \tag{7.3}
\]

Для произвольного f∈𝒟 выберем по Лемме 2 радикальные \(h_n\in\mathcal R\), такие что \(h_n\to f\) в Hʳ. Полная смешанная радикальность даёт **точно**

\[
 W[f-h_n]=W[f],\qquad
 W[f]\ge-C\|f-h_n\|_{H^r}^2\longrightarrow0.              \tag{7.4}
\]

Получена неотрицательность полной исходной формы на 𝒟, в частности на всех компактных чётных гладких тестах. Унаследованный Weil/negative-witness consumer даёт RH. Здесь нет перестановки двух неконтролируемых пределов: (7.3) уже доказано для каждого теста; лишь затем выбирается последовательность hₙ. Обратно, под RH полная нулевая Gram-форма неотрицательна, следовательно каждый Aₘ⪰0 и C=0 подходит. □

**Сила и граница.** При r=1 отрицательная цена допускает \(C(1+\omega_j^2)\), а не исчезающую физическую L²-константу. Это строго более слабая по форме достаточная оценка. Но доказать её для истинной арифметики всё ещё требуется; она не получается из одной непрерывности W в экспоненциально взвешенной топологии.

### 7.2. Точная отрицательная альтернатива

**Следствие 4.1. [COFINAL_FAMILY | PAPER / CONDITIONAL ON NOT_RH.]** Если RH ложна, то для каждого фиксированного r≥0

\[
 \lambda_{\min}\!\left((G_m^{(r)})^{-1/2}
                       A_m(G_m^{(r)})^{-1/2}\right)
             \longrightarrow-\infty.                   \tag{7.5}
\]

Чтобы получить (7.5), возьмём фиксированный source-тест g с \(W[g]=-a<0\). По плотности радикала для любого требуемого D>0 найдётся h∈ℛ с \(\|g-h\|_{H^r}^2<a/(2D)\). Тогда W[g−h]=−a. После **фиксирования** этого теста literal-return работает для всех достаточно больших m и его graph-Rayleigh quotient меньше −D. Это именно предел на всей поздней семье, не численная экстраполяция и не нижняя оценка отдельного квартетного блока вместо полной матрицы.

Кроме того, остаток из Теоремы 1 не удовлетворяет даже более слабому фиксированному graph-полу: из (7.2) для h₀ и (4.12) следует

\[
 \lambda_{\min}\!\left((G_m^{(r)})^{-1/2}
                      E_m(t,d)(G_m^{(r)})^{-1/2}\right)
 \le-c_r Lm^{1/4}
 \quad(t>0,d\ge0)                                      \tag{7.6}
\]

для каждого фиксированного r, с некоторым cᵣ>0 и общим по t,d поздним порогом. Следовательно, ослабление цели до (7.1) не спасает **именно** скалярно-балансируемое эйлерово-мёбиусово разложение.

### 7.3. Оставшийся минимальный supplier

**[COFINAL_FAMILY | CONDITIONAL; не доказан.]** Для r=1 он записывается без неопределённых новых объектов:

\[
 \boxed{B_m\preceq H_m+P_m+C(I+X_m)
 \quad\text{на одной неограниченной семье целых m},
 \qquad C<\infty\text{ независимо от m}.}                 \tag{7.7}
\]

Это не ещё один заявленный результат. Необходимая аналитическая работа — получить (7.7) из совместной арифметики и Γ/полюса без предположения о знаке W. Последовательное применение модулей к Λ и μ не даёт этой компенсации; разложение (3.6) теперь строго исключено как её поставщик с малым остатком.

## 8. Обязательные судьи: где действительно меняется источник

### 8.1. Один точный отрицательный тест для завершённых внелинейных миров

**Лемма 5. [ABSTRACT | PAPER; conditional on the stated source-completion contract, not on RH.]** Пусть завершение даёт чётную целую функцию J(z) вещественного типа, ту же смешанную явную формулу с его **собственными** Γ/полюсами/арифметикой и Gaussian-допустимый рост. Пусть у него есть квартет

\[
       w,\bar w,-w,-\bar w,\qquad w=\gamma+ia,
       \quad \gamma a\ne0,
\]

с одинаковой кратностью ν. Обозначим

\[
 D(z)=[(z^2-w^2)(z^2-\bar w^2)]^\nu,\qquad J_0(z)=J(z)/D(z).
\]

J₀ цела и J₀(w)≠0. Выберем вещественные A,B по формулам

\[
 u=\frac{i}{J_0(w)e^{-w^2}},\qquad
 B=\frac{\Im u}{\Im(w^2)},\qquad A=\Re u-B\Re(w^2),
 \qquad \widehat g(z)=(A+Bz^2)J_0(z)e^{-z^2}.             \tag{8.1}
\]

Тогда g вещественна, чётна и принадлежит нужному экспоненциальному тестовому классу. Её Fourier-значения равны i в w,−w и −i в сопряжённых точках; во всех прочих нулях J они равны нулю. Поэтому **полная**, а не изолированно приближённая, явная формула даёт

\[
                         W_J[g]=-4\nu<0.                \tag{8.2}
\]

Все четыре квадрата равны −1; используется \(\widehat g(z)^2\), не \(|\widehat g(z)|^2\). В случае совпадения добавленного нуля с уже существующим берётся его **полная** кратность ν, и доказательство не меняется. Компактная обрезка и source-correct finite-return сохраняют строгую отрицательность для соответствующего источника.

Нули используются здесь законно: это **отрицательный судья** в мире, где выбран внелинейный квартет. По (8.1) не строится положительный R для настоящей ζ. Заявлять, будто такое использование запрещает сам фальсификатор, означало бы лишить метод требуемого отрицательного контроля.

### 8.3. Удвоенный атом: явный отрицательный upper-envelope

**[COFINAL_FAMILY | PAPER; inherited source equality, direct calculation.]** Пусть

\[
 \widehat h_R(z)=\Xi(z)e^{-Rz^2},\quad R>0,\qquad
 c_2=\frac{\log2}{\sqrt2},\quad a=\log2.
\]

W[h_R]=0, но у источника с удвоенным атомом

\[
 \frac{W_2[h_R]}{\|h_R\|^2}
 =-2c_2\frac{\int_{\mathbb R}|\Xi(t)|^2e^{-2Rt^2}\cos(at)dt}
                  {\int_{\mathbb R}|\Xi(t)|^2e^{-2Rt^2}dt}
 \longrightarrow-2c_2<0.                               \tag{8.3}
\]

Ξ(0)≠0; Gaussian concentration и доминирование оправдывают предел. Выбираем один достаточно большой **фиксированный** R, затем применяем буквальный return m→∞, отдельно оплачивая ограниченный добавленный сдвиг. Получается отрицательный upper-envelope для всех достаточно поздних окон. Порядок пределов не меняется, а остальные степени 2 не удаляются.

## 9. Почему это не переименование RH; альтернативы и dependency contract

### 9.1. Что действительно закрыто

**[ABSTRACT / COFINAL_FAMILY | PAPER.]** Теорема 1 — безусловная отрицательная теорема о полностью заданном остатке; её вывод **не эквивалент RH** и доказан независимо от того, верна RH или нет. В нём нет неизвестного знака, перенесённого в новое название. Арифметика входит в точные (3.2)–(3.3), (4.4), а обычная целая решётка и полюсная нормировка дают (4.3). В этом и находится законченное изменение результата: этот большой естественный класс больше не является кандидатом для требуемого малостаточного доказательства.

Теоремы 2–3 запрещают более широкий класс при **явно указанной дополнительной регулярности**. Они не объявляют регулярность необходимой для RH.

Теорема 4 — напротив, честно обозначенная эквивалентность/consumer. Её левый операторный знак не доказан. Она показывает допустимое ослабление следующего proof obligation, но не засчитывается как закрытие арифметического supplier.

### 9.2. Три структурные связи, проверенные до объявления остатка

**[ABSTRACT | PAPER.]**

1. **Конечная алгебра Дирихле → причинные сдвиги.** Это точное представление мультипликативного полугруппового закона, а не аналогия. Оно даёт обратную M и полный C без потери границы. Глобального знака не даёт; естественная поляризация имеет доказанный FATAL.
2. **Сингулярные квадратичные формы → предел суммы квадратов.** Плотный исходниковый радикал даёт прямое препятствие замыкаемости. Это закрывает регулярный класс за один шаг, не по ячейкам. Контроль (6.1) предотвращает ложное отрицание положительности.
3. **Факторпространство по радикалу → Sobolev-пол.** Точная идентичность W[f−h]=W[f] и Hʳ-плотность радикала сворачивают любой фиксированный semibound к знаку W. Это даёт более слабый достаточный consumer (7.1), но его supplier остаётся неоплаченным.

Нулевое тождество, действительно использованное вместо оценки, — **W(h₀,f)=0**. Оно убивает весь скалярно-балансируемый класс одним свидетелем. Оно не превращено в положительную меру и не выдаётся за доказательство RH.

## Appendix A. Воспроизводимая проверка

Код не доказывает RH и не подменяет аналитические аргументы выше. Он проверяет конечную алгебру точно и выполняет отделённый DIAG нормировок. Требуется Python≥3.10 и `mpmath`; рекомендованный запуск: `uv run --with mpmath python check_compensation.py --dps 35`, затем `--dps 55`. `--dps` — число десятичных знаков в DIAG, не параметр точных rational проверок.

```python
#!/usr/bin/env python3
"""Exact truncated Dirichlet algebra + non-certifying analytic DIAG.
No zero list, matrix positivity certificate, Arb, or Lean is used.
"""
from __future__ import annotations
from fractions import Fraction
import argparse
import json
from time import perf_counter
import mpmath as mp


def factor(n: int) -> dict[int, int]:
    out: dict[int, int] = {}
    p = 2
    while p * p <= n:
        while n % p == 0:
            out[p] = out.get(p, 0) + 1
            n //= p
        p += 1
    if n > 1:
        out[n] = out.get(n, 0) + 1
    return out


def mobius(n: int) -> int:
    f = factor(n)
    return 0 if any(e > 1 for e in f.values()) else (-1) ** len(f)


def addlog(out: dict[int, int], value: dict[int, int], scale: int = 1) -> None:
    for p, e in value.items():
        out[p] = out.get(p, 0) + scale * e
        if out[p] == 0:
            del out[p]


def exact_algebra() -> dict[str, object]:
    # e_n = n^(-1/2) S_log(n); e_a e_b = e_(ab), with e_n=0 for n>=M.
    cells = 0
    coefficients = 0
    for M in (3, 4, 8, 17, 33, 65, 129):
        cells += 1
        for n in range(1, M):
            ds = [d for d in range(1, n + 1) if n % d == 0]
            assert sum(mobius(d) for d in ds) == (1 if n == 1 else 0)
            v: dict[int, int] = {}
            for d in ds:
                addlog(v, factor(n // d), mobius(d))
            fn = factor(n)
            expected = {next(iter(fn)): 1} if len(fn) == 1 else {}
            assert v == expected, (M, n, v, expected)
            coefficients += 1
    # Doubling only the n=2 atom no longer equals the ordinary mu*log identity.
    ordinary_at_2 = {2: 1}
    doubled_at_2 = {2: 2}
    assert ordinary_at_2 != doubled_at_2
    # A positive A can have a uniformly negative residual after a positive square.
    A = (Fraction(0), Fraction(1))
    Q = (Fraction(1), Fraction(0))
    E = tuple(a - q for a, q in zip(A, Q))
    assert min(A) >= 0 and min(E) == -1
    # Positive point-evaluation form is nonclosable in L2(0,1):
    # f_n(x)=(1-x)^n, f_n(0)=1, ||f_n||^2=1/(2n+1).
    point_control = {str(n): str(Fraction(1, 2*n+1)) for n in (1, 10, 100, 1000)}
    assert Fraction(1, 2001) < Fraction(1, 200)
    return {
        'truncated_semigroup_cells': cells,
        'coefficient_checks': coefficients,
        'inverse_and_logarithmic_derivative': 'EXACT_PASS',
        'doubled_atom_source_mismatch': 'EXACT_DETECTED',
        'positive_A_negative_E_control': [str(x) for x in E],
        'nonclosable_positive_form_L2_norm_squared': point_control,
    }



def balanced_identity() -> int:
    F = Fraction
    n = 4
    eye = [[F(int(i == j)) for j in range(n)] for i in range(n)]
    zero = [[F(0) for _ in range(n)] for _ in range(n)]
    def add(*args):
        return [[sum(A[i][j] for A in args) for j in range(n)] for i in range(n)]
    def scale(a, A):
        return [[a*A[i][j] for j in range(n)] for i in range(n)]
    def mul(A, B):
        return [[sum(A[i][k]*B[k][j] for k in range(n)) for j in range(n)] for i in range(n)]
    def star(A):
        return [list(row) for row in zip(*A)]
    U = [[F(i+j+1, 7) if i > j else F(0) for j in range(n)] for i in range(n)]
    Z = add(eye, U)
    M, power = eye, eye
    for k in range(1, n):
        power = mul(power, U)
        M = add(M, scale(F((-1)**k), power))
    assert mul(Z, M) == eye and mul(M, Z) == eye
    checks = 0
    for offset in (F(0), F(1), F(7, 3)):
        Y = [[F(i)+offset if i == j else F(0) for j in range(n)] for i in range(n)]
        C = add(mul(mul(M, Y), Z), scale(F(-1), Y))
        A = add(eye, scale(F(-1), C), scale(F(-1), star(C)))
        for r in (F(1, 3), F(1), F(2), F(5)):
            Q = add(scale(r, Z), scale(-1/r, star(M)))
            gram = mul(mul(star(Q), Y), Q)
            E = add(eye, scale(F(2), Y),
                    scale(-r*r, mul(mul(star(Z), Y), Z)),
                    scale(-1/(r*r), mul(mul(M, Y), star(M))))
            assert add(gram, E) == A
            checks += 1
    return checks


def xi(z: mp.mpf | mp.mpc) -> mp.mpc:
    s = mp.mpf('0.5') + 1j*z
    return s*(s-1)*mp.power(mp.pi, -s/2)*mp.gamma(s/2)*mp.zeta(s)/2


def diag(dps: int) -> dict[str, str]:
    mp.mp.dps = dps
    a = mp.log(2)
    # These are quadrature diagnostics ONLY. No unreported tail enclosure.
    def weight(t: mp.mpf) -> mp.mpf:
        return abs(xi(t))**2 * mp.exp(-2*t*t)
    grid = [mp.mpf(x) for x in (0, 1, 2, 4, 6, 8)]
    base = mp.quad(weight, grid)
    diff = mp.quad(lambda t: 4*mp.sin(a*t/2)**2*weight(t), grid)
    euler = mp.quad(lambda t: abs(1-mp.exp(-1j*a*t)/mp.sqrt(2))**2*weight(t), grid)
    # Arbitrary nonzero complex value v of a divided completion at w:
    # one real affine polynomial in z^2 sets the planted value to i exactly.
    w = mp.mpf(7)+mp.j/3
    v = mp.mpc(2, 3)
    target = mp.j/v
    b = mp.im(target)/mp.im(w*w)
    aa = mp.re(target)-b*mp.re(w*w)
    phase_err = abs((aa+b*w*w)*v-1j)
    assert phase_err < mp.power(10, -dps+5)
    assert diff > 0 and euler > 0
    fmt = lambda x: mp.nstr(x, min(dps-5, 35))
    return {
        'dps': str(dps),
        'range': '0<=t<=8; no certified quadrature/tail bound',
        'norm_h0_squared_truncated_DIAG': fmt(base/mp.pi),
        'eta_I_minus_shift_log2_DIAG': fmt(diff/base),
        'eta_I_minus_2neg_half_shift_DIAG': fmt(euler/base),
        'quartet_phase_interpolation_error_DIAG': fmt(phase_err),
        'quartet_quadratic_value_multiplicity1': '-4 (algebraic)',
    }


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument('--dps', type=int, default=35)
    args = parser.parse_args()
    if args.dps < 25:
        parser.error('--dps must be at least 25')
    start = perf_counter()
    result = {'exact': exact_algebra(), 'balanced_identity_exact_checks': balanced_identity(), 'DIAG': diag(args.dps)}
    result['seconds'] = round(perf_counter()-start, 3)
    print(json.dumps(result, ensure_ascii=False, indent=2))

if __name__ == '__main__':
    main()
```
