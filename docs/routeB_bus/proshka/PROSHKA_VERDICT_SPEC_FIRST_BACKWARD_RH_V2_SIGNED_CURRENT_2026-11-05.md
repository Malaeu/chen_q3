## 1. Спецификация S: подписанный локальный ток конечного порядка

[ABSTRACT / COFINAL_FAMILY | CONDITIONAL: существование всего объекта не предполагается.]

Для каждого целого m>=3 фиксированы L=log m и буквальная фаза из f96a9072 (blob 25e58f845f4767908db41478210c1ac28dedf847):

    alpha_m(t)=q(t)-2 sum_(p<m) sum_(k>=1)
                         (log p) p^(-k/2) cos(k t log p),
    q(t)=Re psi(1/4+it/2)-log pi,
    tau_m=alpha_m(t) dt/(2*pi).

Все степени каждого p<m сохранены, включая p^k>=m в самой фазе. При f в буквальном V_m их физические перекрытия равны нулю. Исходная формула неизменна:

    A_m[z]=|p_m^*z|^2+integral |fhat(t)|^2 tau_m(dt),
    f=mathcal S_m z,  fhat(t)=integral f(x)exp(-itx)dx.

Искомый X состоит из одного целого d>=1 и семейств (nu_m,b_(0,m),...,b_(d,m)) для всех m>=3.

**S1.** d не зависит от m. Каждая nu_m — неотрицательная локально конечная tempered-мера на R. Каждая b_(j,m) — вещественная функция из L-infinity(R). Ни nu_m, ни b_(j,m) не определяются через неизвестные собственные векторы A_m или предполагаемое положение нулей.

**S2.** Имеется ТОЧНОЕ равенство распределений на R:

    tau_m = nu_m + sum_(j=0)^d partial_t^j b_(j,m).

Производные понимаются распределительно. Иными словами, для всякой phi in C_c^infinity(R):

    integral phi(t) alpha_m(t) dt/(2*pi)
      = integral phi dnu_m
        +sum_(j=0)^d (-1)^j integral b_(j,m)(t) phi^(j)(t)dt.

Это подписанные слагаемые. Они не объявляются положительными операторами, а их модули не вставляются в само тождество.

**S3.** Для каждого epsilon>0 существуют C_epsilon<infinity и M_epsilon, такие, что

    sum_(j=0)^d ||b_(j,m)||_infinity <= C_epsilon m^epsilon
       для каждого целого m>=M_epsilon.

Один d работает для всех epsilon, одна C_epsilon — для всех поздних m. Коэффициенты и мера могут зависеть от всего фактического источника при данном m. Подпоследовательность вместо всех поздних окон не разрешена в этой спецификации.

**Независимая проверяемость.** Для предъявленного X проверяются положительность явно заданной меры, тождество распределений и L-infinity-границы. В эти проверки не включены RH, знак A_m, (SD), (dagger) или гауссов one-sided bound в качестве посылок. Требование фиксированного дифференциального порядка и глобальных ограниченных коэффициентов — дополнительная структура; оно не выводится из одного подписанного trace-bound.

**Достаточность S => RH.** При f с поддержкой в окне длины L формула Parseval и правило Лейбница дают для w=|fhat|^2:

    ||partial_t^j w||_L1 <= 2*pi L^j ||f||_L2^2.

Используя гладкие монотонные частотные срезы, S2, положительность nu_m и затем снимая срез, получаем

    A_m[z] >= -2*pi sum_(j=0)^d

Краевые скачки нулевого продолжения не меняют эту оценку: производные здесь по Fourier-переменной, то есть умножения физического f на x^j. Для буквальных косинусов alpha_m(t)|fhat(t)|^2 интегрируема; детали снятия среза подлежат полному выводу ниже. При каждом epsilon>0 логарифмический множитель L^d поглощается m^(epsilon/2), применяя S3 с epsilon/2. Получается субполиномиальный нижний пол A_m на всех векторах. ## 3. Полное доказательство стрелки N1 => RH

[COFINAL_FAMILY | PAPER для импликации; предпосылка S не предполагается выполненной.]

Для f в L2 с поддержкой в [-L/2,L/2] имеем x^j f в L2 и

    ||partial_t^j fhat||_2 = sqrt(2*pi)||x^j f||_2
                          <=sqrt(2*pi)(L/2)^j||f||_2.

Функция f также в L1, поэтому fhat гладка. По Лейбницу и Cauchy–Schwarz для w=|fhat|^2:

    ||w^(j)||_1
      <=sum_(r=0)^j binom(j,r)||fhat^(r)||_2||fhat^(j-r)||_2
      <=2*pi*L^j||f||_2^2.                              (3.1)

Это не требует глобальной H1-гладкости нулевого продолжения.

Выберем chi in C_c^infinity, чётную, 0<=chi<=1, равную 1 возле 0 и невозрастающую по |t|. Тогда chi_R(t)=chi(t/R), chi_R^2*w возрастает к w. Для fixed m,f и каждого j:

    partial^j(chi_R^2*w) -> w^(j) в L1.                 (3.2)

Член с нулевой производной среза сходится по доминированной сходимости; остальные имеют множитель R^(-k) и ограниченную L1-норму w^(j-k). Это доказывает (3.2).

Для буквального f alpha_m(t)=O_m(log(2+|t|)), fhat(t)=O_f((1+|t|)^(-1)); значит integral alpha_m*w абсолютно сходится. Из S2, положительности nu_m и (3.2):

    A_m[z] >= -2*pi sum_(j=0)^d L^j||b_(j,m)||_infinity ||f||_2^2.
                                                               (3.3)

Более того, монотонная сходимость положительного nu-интеграла и конечность остальных пределов доказывают integral w dnu_m<infinity. Оно не было скрытой посылкой. Полюсный член не удалён: он неотрицателен на исходном чётном carrier.

Пусть B_m=sum_j||b_(j,m)||_infinity. При L>=1 правая цена (3.3) не больше 2*pi*L^d*B_m||f||_2^2. Для каждого epsilon>0 применяем S3 с epsilon/2 и используем (log m)^d=O_(d,epsilon)(m^(epsilon/2)). Поэтому

    A_m[z]>=-C'_epsilon*m^epsilon*||z||_2^2
             >=-C'_epsilon*m^epsilon*z^*G_m*z           (3.4)

для всех поздних m и всех z. Все константы независимы от z.

На явном graph-единичном Gaussian-направлении RG(6.6) отрицательный показатель равен Theta/2. (3.4) для каждого epsilon заставляет этот показатель равняться нулю, следовательно Theta=0. Тем самым N1 => RH доказано в унаследованном PAPER-пакете. Ни одна RH-эквивалентная оценка не взята входом для построения X.

## 4. Построение: S1–S2 выполнены точно при каждом фиксированном d

[FINITE_CELL | PAPER; это настоящая конструкция, но пока не S3.]

Положим q0=q(0). Из T2:

    q(t)-q0 = sum_(n>=0) (t/2)^2 /
              ((n+1/4)*((n+1/4)^2+(t/2)^2)) >=0.        (4.1)

Ряд сходится на компактах. Для любого целого d>=1 задаём

    dnu_m^can(t) = (q(t)-q0)dt/(2*pi),
    b_(0,m)^can(t)=q0/(2*pi),
    b_(j,m)^can=0  (0<j<d),
    b_(d,m)^can(t)= -(1/pi) sum_(p<m) sum_(k>=1)
       (log p)*p^(-k/2)/(k*log p)^d
          *cos(k*t*log p-d*pi/2).                       (4.2)

Это только Gamma, настоящие простые и их степени. Для fixed m ряды по k, вместе с каждой фиксированной производной, сходятся абсолютно и равномерно; конечных простых конечное число. Все b гладкие, вещественные и ограниченные. Положительная nu имеет лишь логарифмический рост плотности, поэтому tempered.

Поскольку d-я производная cos(at-d*pi/2) равна a^d cos(at), непосредственно

    tau_m = nu_m^can + b_(0,m)^can + partial^d b_(d,m)^can.
                                                               (4.3)

S1–S2 доказаны. p^k>=m в фазе не удалены. Их зануление происходит только при физическом спаривании, как в RP.

Построение не использует ни RH, ни нули. Оно не доказывает S3, поскольку ограниченность при каждом m и единый субполиномиальный бюджет — разные кванторы.

## 5. Точная цена всего класса, а не только кандидата

[COFINAL_FAMILY | PAPER.]

Для каждого фиксированного d>=1 определим

    B_d(m)=inf sum_(j=0)^d ||b_j||_infinity,

где inf берётся по ВСЕМ nu>=0 и действительным ограниченным b_j с tau_m=nu+sum_j partial^j b_j. Условие запрета определения через неизвестные нули здесь можно даже снять: нижняя граница действует на более широкий класс. По §4 множество непусто.

**Теорема 1.** Для каждого фиксированного d>=1 существуют c_d>0 и M_d, такие, что

    c_d*sqrt(m)/(log m)^d <= B_d(m)
       <=(2/pi+o_d(1))*sqrt(m)/(log m)^d                 (5.1)

для всех целых m>=M_d. В частности B_d(m) сравнима с sqrt(m)/(log m)^d. c_d ниже задан явным положительным интегралом и конечными L1-нормами одного fixed bump; численный onset M_d не заявляется.

### 5.1. Унаследованная арифметическая часть — не повторный новый результат

Из R0 §5, или непосредственно из theta(x)=x+o(x) частичным суммированием, равномерно при 1<=t<=2:

    alpha_m(t)/sqrt(m)
       =-2 Re(exp(i*L*t)/(1/2+it))+o(1).                (5.2)

Для полноты: sum_(p<m)(log p)p^(-1/2+it)
=m^(1/2+it)/(1/2+it)+o(sqrt(m)). Остаток integral E_theta(x)x^(-3/2+it)dx оценивается на [1,X] константой, а после X — eta*integral x^(-1/2)dx, затем eta->0. Множитель 1/2-it равномерно ограничен. Возможный атом p=m даёт лишь log(m)/sqrt(m).

Высшие степени, ВСЕ включая p^k>=m в фазе, по модулю O((log m)^2): сравнить sum_(p<m)log(p)/(p*(1-p^(-1/2))) с sum_(n<m)log(n)/n. Gamma ограничена на [1,2]. Это даёт (5.2). Никакого нового RH-знака в этой асимптотике нет.

### 5.2. Новый dual-свидетель для конечного порядка

Зафиксируем один ненулевой eta>=0 из C_c^infinity((1,2)). Например eta(t)=exp(-1/((t-5/4)(7/4-t))) внутри (5/4,7/4), нуль снаружи. Положим

    a(t)=1/(2*(1/4+t^2)),
    A_eta=(1/(2*pi))*integral eta(t)*a(t)dt >0,
    D_d=(1+2^d)*sum_(j=0)^d ||eta^(j)||_1 <infinity,
    phi_m(t)=eta(t)*(1+cos(L*t)) >=0.                   (5.3)

Это не физический вес, и он не объявляется таким. Его разрешает точное распределительное требование S2.

Пишем 1/(1/2+it)=a(t)-i b(t), b(t)=t/(1/4+t^2). Тогда (5.2) и интегрирование осциллирующих членов дают

    <tau_m,phi_m>/sqrt(m) -> -A_eta.                    (5.4)

Действительно, после раскрытия остаются eta*a*cos(Lt), eta*b*sin(Lt), eta*a*cos^2(Lt), eta*b*sin(Lt)cos(Lt). Все ненулевые гармоники стремятся к нулю интегрированием по частям. Среднее cos^2 равно 1/2; фактор -2/(2*pi) даёт ровно -A_eta. Равномерный o(1) оплачивается ||phi_m||_1<=2||eta||_1.

Следовательно для всех достаточно поздних m

    <tau_m,phi_m> <= -(A_eta/2)*sqrt(m).                 (5.5)

Для 0<=j<=d и L>=1 правило Лейбница даёт

    ||phi_m^(j)||_1 <= D_d*L^d.                         (5.6)

Теперь возьмём ЛЮБОЕ разложение из определения B_d(m). Поскольку nu>=0 и phi_m>=0:

    sum_j (-1)^j integral b_j phi_m^(j)
       =<tau_m,phi_m>-integral phi_m dnu
       <=-(A_eta/2)*sqrt(m).

С другой стороны, модуль этой суммы не больше D_d*L^d*sum_j||b_j||_infinity. Поэтому

    sum_j||b_j||_infinity
       >= [A_eta/(2*D_d)]*sqrt(m)/L^d.                  (5.7)

Берём c_d=A_eta/(2D_d)>0 и inf. Это доказывает нижнюю границу (5.1). Положительная часть может быть сингулярной, коэффициенты только измеримыми; дополнительных условий гладкости здесь нет.

### 5.3. Совпадающая верхняя цена: конструкция уже оптимальна по масштабу

Для кандидата (4.2):

    sum_j||b_(j,m)^can||_infinity
      <=|q0|/(2*pi)+(1/pi) sum_(p<m,k>=1)
                     (log p)*p^(-k/2)/(k*log p)^d.      (5.8)

Из PNT частичным суммированием:

    sum_(p<m)(log p)^(1-d)/sqrt(p)
       ~ 2*sqrt(m)/(log m)^d.                           (5.9)

Здесь integral_2^m x^(-1/2)(log x)^(-d)dx имеет ту же асимптотику. Ошибка theta(x)-x=o(x) оплачивается таким же разбиением на начальный отрезок и eta-хвост, как в §5.1; дополнительный множитель d/log x ограничен после 2. Никаких RH-остатков нет.

При k>=2 и d>=1:

    sum_(p<m,k>=2) (log p)^(1-d)*k^(-d)*p^(-k/2)
       <=[(log 2)^(1-d)/(1-2^(-1/2))]*sum_(2<=n<m)1/n
       =O_d(log m).                                    (5.10)

Для каждого fixed d это o(sqrt(m)/(log m)^d). Постоянный q0 также поглощается этим масштабом. (5.8)–(5.10) доказывают верхнюю границу (5.1). Теорема 1 доказана.

### 5.4. Почему frozen S ложна — правильное направление неравенства

Для любого fixed d S3 при epsilon=1/4 требовала бы B_d(m)<=C*m^(1/4). Но для каждого конечного C:

    C*m^(1/4)-sum_j||b_(j,m)||_infinity
       <= C*m^(1/4)-c_d*sqrt(m)/(log m)^d <0            (5.11)

при всех достаточно поздних m. Это строгий отрицательный upper-envelope для предполагаемого запаса, не провал одной достаточной оценки. Доказан запрет для ВСЕХ d, выбранных заранее; один большой, но фиксированный d не спасает объект. Любая кофинальная подпоследовательность также нарушает такой бюджет.

Не доказано и не утверждается аналогичное препятствие для d=d_m, для неограниченных коэффициентов с другой нормой, для нефиксированного представителя источника или для тождества только на физическом классе весов. Теорема охватывает ровно frozen S.

    sqrt(m)*cos((L+1)t)dt/(2*pi).                        (6.1)

На ВСЕХ физических функциях с support diameter<=L добавка точно нулевая: её спаривание равно sqrt(m)*Re C_f(L+1)=0. Таким образом полная форма, её положительность и известная RH кривой не меняются. Но finite-order S для изменённого представителя ложна. Для eta из §5 берём eta(t)*(1-cos((L+1)t)); добавка имеет отрицательное спаривание порядка sqrt(m), а собственная конечная tau_E,m имеет на фиксированной полосе плотность O(log m). Производные маски стоят O_d(L^d), и доказательство (5.7) повторяется. Это известный положительный источник с источниково-эквивалентным представителем, который не имеет frozen regularity certificate.

Следовательно обычный нижний бюджет физической формы не подразумевает новую S: она чувствительна к поведению за пределами физического Fourier-cone. Это не просто переименование RH-GAP или SD. При этом для ОДНОЙ фиксированной настоящей zeta логический тезис «RH истинна, а N1 ложна» потребовал бы самого доказательства RH. Его здесь нет. Термин «строго сильнее» имеет доказанный смысл дополнительной regularity-структуры сертификата; обратная RH=>N1 для Q не устанавливается и не используется.

## 7. Каждый узел на отрицательных мирах и на кривой

### 7.1. N1 и N2: DH, DMV, quartet

[COFINAL_FAMILY | PAPER с унаследованным RG §8; не новые численные проверки.]

В каждом мире tau_m означает СВОЙ полный оконный источник, а не старую zeta-фазу с новым названием. Для всякого такого source-exact распределительного S доказательство §3 даёт субполиномиальный lower floor. Отрицательный Gaussian-отклик RG §8 имеет на literal moving-return степенную отрицательную осцилляцию. Выбор epsilon меньше её положительного показателя нарушает этот floor.

| Мир | Source, исключающее свойство и точка отказа N1 | N2 |

| DMV | Finite u_m^B и tau_m^B определены по настоящим generalized primes с теми же явно заданными Gamma/pole из RJ. Нуль beta+i gamma, beta>3/4, даёт ненулевой Laplace-residue fixed Gaussian. Для уточнения quartet-строки: r(s)=4cosh(s/3)cos(7s) — собственное полное добавочное корреляционное ядро. Его оконный spectral-вклад равен 2 integral_0^L r(s)cos(ts)ds. Первообразная из таблицы ограничена при fixed L: отделить r(0)*integral_0^L sin(ts)/s ds от абсолютно интегрируемого остатка (r(s)-r(0))/s. У первого члена sine-integral равномерно ограничен, у второго есть конечная L1-норма. Никакого quartet-атома не удалено.

Это проверка каждого узла, а не обещание, что все S1–S2 тождества обязаны ломаться на фейках. Они могут переноситься. Различающим требованием является полный uniform budget S3. В Q он тоже оказался чрезмерным, но это установлено независимо в §5, не из сходства миров.

### 7.2. Положительный контроль: тот же конечный spectral-current проходит E/F3

[FINITE_CELL / COFINAL_FAMILY | PAPER; J_E=2cos(hz), h=log3 — источник RF §6.]

Пусть gamma_n=(pi/2+pi*n)/h. Собственная форма кривой:

    W_E[f]=sum_(n in Z)|fhat(gamma_n)|^2.

Её точный spectral-comb имеет Fourier-разложение распределений

    sum_n delta_(gamma_n)(t)
       =(h/pi)*sum_(k in Z)(-1)^k exp(2ikht).            (7.1)

Проверка (7.1): обе стороны периодичны периода pi/h; их k-й Fourier-коэффициент равен (h/pi)*exp(-2ikh*pi/(2h))=(h/pi)(-1)^k. Это не импорт RH zeta.

Для носителя длины L все корреляции на 2kh>=L нулевые. Поэтому положим M_m=ceil(L/(2h))-1>=0 и определим СВОЮ конечную оконную плотность

    tau_E,m(t)=(h/pi)*[1+2 sum_(k=1)^M_m (-1)^k cos(2kht)]dt.
                                                               (7.2)

Тогда integral |fhat|^2 tau_E,m=W_E[f] точно на том же physical window. Endpoint 2kh=L также нулевой. Для гладких компактных f это прямо (7.1); для буквальных косинусов переход через сглаживание законен, поскольку fhat=O(1/|t|), sampled squares суммируемы, а конечные корреляции непрерывны, включая endpoint.

Выбираем d=1:

    nu_E,m=0,
    b_(0,m)^E=h/pi,
    b_(1,m)^E(t)=(1/pi) sum_(k=1)^M_m (-1)^k sin(2kht)/k.
                                                               (7.3)

Производная возвращает (7.2) точно. Это ровно конструкция §4: постоянный arch/contact член и termwise primitive, с СОБСТВЕННЫМИ атомами кривой. Не используется другая inner-регуляризация.

Есть единый бюджет. Для всех N и theta:

    |sum_(k=1)^N sin(k theta)/k| <= 1+2*pi.              (7.4)

Доказательство: привести theta к [0,pi] по периодичности и нечётности. При theta=0 сумма нулевая. Первые k<=floor(1/theta) стоят не больше 1, поскольку |sin(k theta)|/k<=theta. Для хвоста частичные суммы синусов ограничены 1/sin(theta/2); Abel summation даёт не больше 2/((floor(1/theta)+1)*sin(theta/2))<=2*pi. При theta>=1 та же оценка хвоста начинается с k=1 и также работает. Число N может обрезать любой из двух участков. Это доказывает (7.4).

Заменив theta на 2ht+pi, получаем

    ||b_(0,m)^E||_infinity+||b_(1,m)^E||_infinity
       <= h/pi+(1+2*pi)/pi                              (7.5)

для ВСЕХ m. Таким образом N2[E] — THEOREM с d=1, затем N1[E] — THEOREM. Собственная RH кривой проходит тот же finite-window certificate. Нулевая nu допустима как неотрицательная мера.

### 7.3. Дешёвые судьи усилений

Для N1 и N2 на Q самый дешёвый решающий свидетель — (5.3)–(5.7). Он уже аналитически опровергает uniform S3 по всем поздним m. Не требуется Codex, численный спектр, интервал или поиск нуля. Несколько конечных чисел не заменили бы cofinal-квантор и не опровергли бы существование иной C_epsilon.

## 8. Сильнейшее возражение и точный следующий адрес

[ABSTRACT | PAPER для тождеств; CONDITIONAL для следующей неоплаченной оценки.]

**Возражение:** phi_m из §5 не является допустимым физическим весом. Именно поэтому теорема НЕ опровергает RH, (dagger) или (SD). Но S2 была заранее зафиксирована как равенство на ВСЕХ compact smooth phi, а nu неотрицательна на всех положительных phi. Применение phi_m законно для frozen S. После обнаружения цены нельзя заменить S2 тождеством только на физических весах и сохранить прежнее название спецификации.

**Что делать вместо неограниченного повышения fixed d.** До следующей спецификации можно явно убрать непрерывный pole-канал, сохранив source. Это уже разрешено нашей прежней полюсной геометрией. Положим

    v_L(t)=2 integral_0^L exp(s/2) cos(ts) ds
          =2 Re[(exp((1/2+it)L)-1)/(1/2+it)].             (8.1)

Для любого чётного исходного f:

    integral v_L(t)|fhat(t)|^2 dt/(2*pi)
       =integral_0^L exp(s/2)Q_f(s)ds=P[f]-J_-[f],
    J_-[f]=integral_0^L exp(-s/2)Q_f(s)ds>=0.           (8.2)

Последний знак следует из положительного Fourier-множителя 1/(t^2+1/4) ядра exp(-|x-y|/2). Поэтому ТОЧНО

    A_m[z]=integral [alpha_m(t)+v_L(t)]|fhat(t)|^2dt/(2*pi)
                         +J_-[f].                      (8.3)

Ни один prime-power или pole не выброшен. На [1,2] v_L убирает ведущую sqrt(m)-часть (5.2). Наш запрет относится к НЕПЕРЕНОРМИРОВАННОЙ tau_m и не переносится автоматически на tau_tilde_m=(alpha_m+v_L)dt/(2*pi).

(8.3) не является тайной заменой frozen S: она стоит после окончательного опровержения и обозначает ДРУГОЙ допустимый адрес следующей конструкции. Нового бюджета для tau_tilde не доказано; его остаток снова содержит фактическую signed theta-error. Прежняя ошибка «PNT даёт достаточно по модулю» не повторяется. Второй допустимый класс — нелокальное source-exact тождество только на автокорреляционных весах с моментными ограничениями, без требования глобальной положительной меры на всех spectral masks. Его sign supplier также не построен.
