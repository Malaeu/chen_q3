## 1. Нормировки и область, на которой кубический тест законен

Сохраняются определения [S1–S3]:

\[
\begin{aligned}
 h(x)&=e^{x/2}\sum_{n\ge1}(16\pi^2n^4e^{4x}-24\pi n^2e^{2x})e^{-\pi n^2e^{2x}},\\
 \widehat h(z)&=4\xi(1/2-iz),\qquad
 d\mu(x)=\tfrac12\cosh(x/2)h(x)\,dx,\qquad \tau(x)=\tanh(x/2),\\
 j(s)&=\frac{e^{-s/2}}{1-e^{-2s}},\quad a_n=\log n,\quad c_n=\frac{\Lambda(n)}{\sqrt n}.
\end{aligned}
 \tag{1.1}
\]

h — положительная чётная функция. \(\int\cosh(x/2)h(x)dx=2\), поэтому μ — вероятностная мера. Эти нормировки следуют из Mellin/Poisson-вычисления в MARKOV/CONFINE и \(\widehat h(\pm i/2)=2\), а не из численного интеграла массы.

Обозначим полный положительный функционал

\[
\begin{aligned}
\mathcal E_h(F)={}&\frac12\iint j(|x-y|)h(x)h(y)|F(x)-F(y)|^2\,dxdy\\
&+\sum_{n\ge2}c_n\int h(x)h(x+a_n)|F(x+a_n)-F(x)|^2\,dx.
\end{aligned}
 \tag{1.2}
\]

Билинейная форма обозначается тем же символом с двумя аргументами, с сопряжением первого. В этой части все испытательные функции вещественные. Энтропия — ненормированная однородная форма

\[
 \operatorname{Ent}_\mu(U)=\int U\log U\,d\mu
                  -\left(\int U\,d\mu\right)\log\left(\int U\,d\mu\right),
 \quad U\ge0,\quad0\log0=0.
 \tag{1.3}
\]

### L1. Рост отношения производных и все его моменты

**PROVED HERE. [ABSTRACT / PAPER]**

Положим \(q=h''/h\), \(g=q-1/4\). Тогда g гладкая, чётная, ограничена снизу и

\[
 |q(x)|+|g(x)|\le C e^{4|x|},\qquad |g'(x)|\le C e^{6|x|},
 \qquad g\in L^p(\mu)\quad(1\le p<\infty).
 \tag{1.4}
\]

**Область и входы:** фактический theta-ряд (1.1), его Poisson-чётность; никаких гипотез о нулях.

**Доказательство.** Для x≥0 пишем \(y_n=\pi n^2e^{2x}\). Дифференцирование одного слагаемого даёт

\[
 h^{(r)}(x)=e^{x/2}\sum_{n\ge1}P_r(y_n)e^{-y_n},\qquad
 P_{r+1}=(1/2-2y)P_r+2yP'_r,
 \tag{1.5}
\]

где

\[
\begin{aligned}
 P_0(y)&=16y^2-24y,\\
 P_1(y)&=-32y^3+120y^2-60y,\\
 P_2(y)&=64y^4-448y^3+660y^2-150y,\\
 R(y):=P_2(y)-P_0(y)/4&=16y(4y^3-28y^2+41y-9).
\end{aligned}
 \tag{1.6}
\]

Слагаемые P0 положительны при y≥π. Первое даёт нижнюю границу

\[
 h(x)\ge (16\pi^2-24\pi)e^{9x/2}e^{-\pi e^{2x}}.
\]

Для каждого фиксированного r, суммируя \(n^{2r+4}e^{-\pi(n^2-1)e^{2x}}\), получаем

\[
 |h^{(r)}(x)|\le C_r e^{(2r+9/2)x}e^{-\pi e^{2x}}.
 \tag{1.7}
\]

Ряд и дифференцированные ряды сходятся равномерно на компактах. Отношения дают (1.4), включая производную q по правилу частного. Чётность даёт левый хвост. Двойная экспонента в μ поглощает любую степень \(e^{|x|}\); все моменты конечны. Кроме того, R(y)>0 при y≥7, поскольку \(4y^2(y-7)+41y-9>0\). Поэтому g>0 при достаточно большом |x|, а на оставшемся компакте она непрерывна. ∎

**Остаток:** отсутствует для (1.4). Это не утверждение об энергии произвольной L²-функции.

### L2. Cutoff-продолжение полной jump-формы

**PROVED HERE. [ABSTRACT / PAPER]**

Для q, g и \(1+\varepsilon g\) корректно тождество MARKOV (6.8):

\[
 \mathfrak k[hF]=\mathcal E_h(F)-8\operatorname{Var}_\mu(F)
                    -8\left|\int\tau F\,d\mu\right|^2.
 \tag{1.8}
\]

В частности, все члены конечны. Если \(\chi_R(x)=\chi(x/R)\), где χ чётная, гладкая, равна 1 на [-1,1] и 0 вне [-2,2], то

\[
 \chi_RF\to F\text{ в }L^p(\mu),\qquad
 \mathcal E_h(\chi_RF-F)\to0.
 \tag{1.9}
\]

**Область и входы:** указанные гладкие F экспоненциального роста, (1.2), исходное тождество для компактных F. Все c_n сохраняются.

**Доказательство.** Для |s|≤1 теорема о среднем даёт

\[
 |F(x+s)-F(x)|^2\le s^2\sup_{|t-x|\le1}|F'(t)|^2.
\]

Из (1.4) и (1.7) интеграл по x с весом h(x)h(x+s) ограничен равномерно при |s|≤1. При этом \(\int_0^1s^2j(s)ds<\infty\). Те же мажоранты работают для χ_RF, их производных и разностей, равномерно по R≥1.

Для s≥1 используем

\[
 h(x)h(x+s)|F(x+s)-F(x)|^2
 \le2h(x)h(x+s)(|F(x)|^2+|F(x+s)|^2).
\]

Функции h и h|F|² имеют все экспоненциально взвешенные L²-нормы. Поэтому для любого A>0 интеграл правой части по x не превосходит \(C_Ae^{-As}\). Это оплачивает и архимедов хвост, и **весь** ряд

\[
 \sum_{n\ge2}\frac{\Lambda(n)}{\sqrt n}C_A n^{-A}
 \le C_A\sum_{n\ge2}\frac{\log n}{n^{A+1/2}}<\infty\quad(A>1/2).
\]

Те же мажоранты и поточечная сходимость дают (1.9) по dominated convergence на непрерывной и атомарной частях меры скачков. Здесь не используется окно с отсечением простых при n=m.

В то же время \(h\chi_RF\to hF\) со всеми фиксированными экспоненциально взвешенными производными. Непрерывность полной явной формулы на этом тестовом классе даёт сходимость \(\mathfrak k[h\chi_RF]\). Пределы дисперсии и τ-спаривания следуют из L²(μ)-сходимости. Переход в компактном тождестве доказывает (1.8). ∎

**Остаток:** отсутствует для этой области. Продолжение на всё физическое L² не заявляется.

### L3. Точная равенственная мода с энергией 8M2

**PROVED HERE. [ABSTRACT / PAPER]**

\[
 \int q\,d\mu=\frac14,\quad \int g\,d\mu=0,\quad
 \boxed{\mathcal E_h(g)=8M_2},\qquad M_j:=\int g^j\,d\mu.
 \tag{1.10}
\]

**Доказательство.** Дважды интегрируя по частям, без граничных членов ввиду (1.7), получаем

\[
 \int q\,d\mu=\tfrac12\int\cosh(x/2)h''(x)dx
   =\tfrac18\int\cosh(x/2)h(x)dx=\tfrac14.
\]

\(hg=h''-h/4\) — точный радикальный вектор: его преобразование равно \((-z^2-1/4)\widehat h(z)\). Следовательно, \(\mathfrak k[hg]=0\). g чётна, поэтому \(\int\tau g\,d\mu=0\). Применяем L2 к F=g. ∎

Таким образом, кубический тест использует **точное насыщение квадратичной оценки**, а не предполагает её истинность для всех функций.

Если t≥-1/2, интегральная форма остатка даёт \(|R_4(t)|\le(2/3)t^4\). При \(\varepsilon=10^{-3}\), L4 обеспечивает \(1+\varepsilon g>0.9\). Так что оценка применима **на всей прямой**, несмотря на неограниченность g сверху. Все интегралы конечны по L1.

Так как \(\int g=0\), имеем \(\int F_*^2=1+\varepsilon^2M_2\). Для u≥0 справедливо \((1+u)\log(1+u)\le u+u^2\). Поэтому

\[
\begin{aligned}
 \operatorname{Ent}_\mu((1+\varepsilon g)^2)
 &\ge2\varepsilon^2M_2+\tfrac23\varepsilon^3M_3
       -\varepsilon^4\bigl(\tfrac23M_4+M_2^2\bigr),\\
 \mathcal E_h(1+\varepsilon g)/4&=2\varepsilon^2M_2.
\end{aligned}
 \tag{2.6}
\]

Подставляя строгие интервальные границы,

\[
 \operatorname{Ent}_\mu(F_*^2)-\mathcal E_h(F_*)/4
 >120000\cdot10^{-9}
   -(\tfrac23\cdot10^8+4\cdot10^6)10^{-12}
 =\frac{148}{3000000}>4\cdot10^{-5}.
 \tag{2.7}
\]

Это отрицательная верхняя граница для **самого** разностного утверждения LSI. Далее \(\mathcal E_h(F_*)=8\varepsilon^2M_2<0.016\), откуда Ent/E>1/4+(4·10^-5)/0.016=101/400.

Если исходная LSI предлагалась только для компактных гладких F, берём χ_RF_*. По L2 энергии сходятся, а энтропии сходятся по dominated convergence: F_* имеет все μ-моменты, и \(|u\log u|\) контролируется константой плюс степенью u. Строгое нарушение сохраняется при всех достаточно больших R. Таким образом, ограничение формулировки гладкими компактными тестами контрпример не устраняет. ∎

При ε=10^-8 тот же расчёт даёт нарушение >10^-19; это был первый проверенный вариант. Увеличение ε до 10^-3 допустимо благодаря уже оплаченным M4 и нижней границе g, а не за счёт подгонки численной энтропии.

**Что убито:** ровно LSI с коэффициентом 1/4, уже в чётном секторе. **Что не убито:** острая квадратичная оценка E_h≥8Var, функционал с иной правой частью, no-escape и RH.

## 3. Что остаётся от настоящей энтропии источника

### L6. Консервативная jump-реализация и её равенственная мода

**PROVED HERE. [ABSTRACT / PAPER]**

На L²(μ) существует неотрицательный самосопряжённый оператор \(\mathcal L_h\), порождённый замыканием (1.2) на C_c^∞. Его полугруппа S_t консервативна и Markov. При этом

\[
 \mathcal L_h1=0,\qquad \boxed{\mathcal L_h g=8g.}
 \tag{3.1}
\]

В чётном секторе собственное значение 8 имеет бесконечно много линейно независимых собственных функций

\[
 g_r=\frac{h^{(2r)}}h-4^{-r},\qquad r=1,2,\ldots.
 \tag{3.2}
\]

**Доказательство.** Положительная симметричная мера пар в (1.2) состоит из непрерывной части и счётного числа графиков сдвигов. Она σ-конечна; h>0 делает μ эквивалентной мере Лебега. Если F_n фундаментальна в норме \(\|F\|_{L^2(\mu)}^2+\mathcal E_h(F)\) и сходится в L², можно выбрать почти всюду сходящуюся подпоследовательность. Сходимость сохраняется почти всюду на каждой парной компоненте, в том числе на каждом графике y=x+a_n. Fatou для разностей показывает сходимость в энергетической норме. Это доказывает замыкаемость и замкнутость завершения ядра; оно плотно, поскольку содержит C_c^∞.

Нормальные сжатия C с C(0)=0 уменьшают каждое \(|F(x)-F(y)|\). Сглаживание сжатия и замыкание дают Markov-свойство. Теорема представления замкнутой неотрицательной формы определяет \(\mathcal L_h\) и S_t. Не требуется глобальная самосопряжённая реализация исходной неопределённой Weil-формы.

Cutoff-доказательство L2 применимо и к F=1: χ_R→1 в энергетической норме и E_h(1)=0. Поэтому 1 принадлежит операторной области и L_h1=0. Отсюда S_t1=1; это консервативность, а не предположение об отсутствии взрыва процесса.

Для g используем поляризацию (1.8). Для любого компактного гладкого V

\[
 0=\mathfrak k(hg,hV)=\mathcal E_h(g,V)-8\langle g,V\rangle_\mu,
\]

поскольку mean(g)=0 и \(\langle\tau,g\rangle=0\). Равенство продолжается на всю замкнутую область формы, и правая часть ограничена в L²(μ). Это именно критерий g∈D(L_h), L_hg=8g.

Для g_r доказательство то же: интегрирование по частям 2r раз даёт \(\int h^{(2r)}/h\,d\mu=4^{-r}\), а фиксированные отношения производных удовлетворяют аналогам L1–L2. Их линейная независимость следует после умножения на h и Fourier-преобразования: ненулевой полином не может занулить H(z)=4ξ(1/2−iz) тождественно. ∎

**Что это означает.** Константа 8 действительно присутствует в источнике, но как точная энергия большого семейства направлений. Нижняя граница спектра на всём чётном mean-zero пространстве ещё не получена. Равенственная мода с ненулевым третьим моментом и есть конкретное препятствие к LSI с коэффициентом 1/4.

### L7. Диссипация — реальная, но движется внутри радикала

**PROVED HERE. [ABSTRACT / PAPER]**

Для положительной плотности ρ_t=S_tρ_0, с массой 1 и достаточной операторной регулярностью,

\[
 \frac d{dt}\operatorname{Ent}_\mu(\rho_t)
   =-\mathcal E_h(\rho_t,\log\rho_t)
   =-I_{\rm arch}(\rho_t)-I_{\rm prime}(\rho_t)\le0.
 \tag{3.3}
\]

Например, это верно для начальных плотностей из D(L_h), ограниченных сверху и отделённых от нуля. Отдельно существует явная допустимая неограниченная плотность

\[
 \rho_t=1+\varepsilon e^{-8t}g,\qquad0<\varepsilon\le10^{-3},
 \tag{3.4}
\]

для которой все дифференцирования оправданы L1. Её энтропия строго убывает, но

\[
 h\rho_t=(1-\varepsilon e^{-8t}/4)h+\varepsilon e^{-8t}h'',
 \qquad \mathfrak k(h\rho_t,\cdot)=0\quad\text{для всех }t.
 \tag{3.5}
\]

**Доказательство.** Консервативность даёт нулевую производную массы. Дифференцируем ∫ρ logρ и используем определение генератора. Билинейная jump-форма — сумма положительных весов, умноженных на

\[
 (\rho(x)-\rho(y))(\log\rho(x)-\log\rho(y))\ge0.
\]

Это одновременно доказывает знаки обеих частей и отсутствие автоматической «prime anti-entropy». Для (3.4) применяется (3.1); ρ_t≥0.9, масса 1. Рост g и его моменты дают доминирование для интегралов с logρ_t. Более явно,

\[
 \frac d{dt}\operatorname{Ent}_\mu(\rho_t)
 =-8\varepsilon e^{-8t}\int g\log(1+\varepsilon e^{-8t}g)\,d\mu<0,
\]

так как g и log(1+ag) имеют одинаковый знак вне g=0. Равенство (3.5) — линейная комбинация двух точных радикальных тождеств. ∎

Это полноценная source-эволюция, а не метафора. Но она не различает конечные уровни в почти нулевом кластере: после проекции (3.5) остаются quasimodes, а не доказанные bottoms. Оценка их residual сама по себе уже не обеспечивает T, как показывает NOESCAPE L9.

### L8. Кубическая компенсация чинит разложение, но не даёт недостающего знака

**PROVED HERE. [ABSTRACT / PAPER]**

Для вещественного F≥0 с a=∫F dμ>0 и конечными нужными моментами определим

\[
 \mathcal H_3(F):=\operatorname{Ent}_\mu(F^2)
             -\frac{2}{3a}\int(F-a)^3d\mu.
 \tag{3.6}
\]

Тогда

\[
 \boxed{\mathcal H_3(F)\le2\operatorname{Var}_\mu(F).}
 \tag{3.7}
\]

**Доказательство.** Пишем F=a(1+u), ∫u=0, u≥−1. Поскольку a^{(4)}(t)<0 на t>−1 для функции из L5,

\[
 (1+u)^2\log(1+u)^2\le2u+3u^2+\tfrac23u^3.
\]

Равенство на границе u=−1 понимается по непрерывности. Для v=∫u² используем \((1+v)\log(1+v)\ge v\), интегрируем и умножаем на a². ∎

Следовательно, предположение E_h≥8Var давало бы \(\mathcal H_3\le E_h/4\). Обратно, такая оценка для всех положительных возмущений константы, по линейзации в 1+εu, даёт E_h(u)≥8Var(u). На соответствующей полной чётной тестовой области это снова точная квадратичная цель; компенсация не оплатила её.

Для F_t=S_tF_0 с постоянным a и достаточной регулярностью её точная вариация имеет вид

\[
 \frac d{dt}\mathcal H_3(F_t)
 =-2\mathcal E_h\!\left(F_t,F_t\log\frac{F_t^2}{\|F_t\|_{L^2(\mu)}^2}\right)
   +\frac2a\mathcal E_h(F_t,(F_t-a)^2).
 \tag{3.8}
\]

Последняя парная разность содержит множитель F_t(x)+F_t(y)−2a, знак которого не фиксирован. Формула (3.8) не объявляется монотонностью. Поэтому (3.6) **не выбирается новым поставщиком**: это честная алгебраическая компенсация кубического дефекта, которая возвращает прежнюю неоплаченную Poincare-границу.

**EQUIVALENT TO RH — только следующая полная цель, не использованная как посылка:** E_h(F)≥8Var(F) на всех допустимых чётных F, с точным возвратом f=hF на Weil-тесты. Обе стороны эквивалентности расходуют исходную явную формулу и отдельный чётный отрицательный свидетель из CONFINE/NOESCAPE. Неоплачен именно универсальный нижний знак этой формы. L5 его не опровергает: на g квадратичная оценка выполнена с равенством.

## 4. Независимый X для m16: физические интегралы, а не total−F

Здесь m=N=16, L=log16, b=L/2=log4, I=[−b,b]. v обозначает вещественную чётную функцию из присланных координат после **интервальной нормировки**. Все формулы ниже верны и для произвольного вещественного чётного конечного вектора; eigenrelation нужна лишь в явно выделенной замене.

### L9. Точный физический crosswalk

**PROVED HERE. [FINITE_CELL / PAPER]**

Для функций с указанной поддержкой и смешанных theta/window пар используется форма

\[
\begin{aligned}
 \mathfrak k(f,v)={}&-c_*\langle f,v\rangle
  +\int_0^\infty j(s)\{2\langle f,v\rangle-Q_{f,v}(s)\}\,ds\\
 &-\sum_{n\ge2}c_nQ_{f,v}(a_n)
  +\langle f,p\rangle\langle p,v\rangle
  -\langle f,q_p\rangle\langle q_p,v\rangle,\\
 c_*={}&\gamma+\log(8\pi)+\pi/2,\quad
 p=\sqrt2\cosh(x/2),\quad q_p=\sqrt2\sinh(x/2).
\end{aligned}
 \tag{4.1}
\]

Для чётных реальных f,v последний полюсный член равен нулю по чётности, не удаляется из определения. В матричном применении

\[
 Q_{n,j}(s)=
 \begin{cases}
 2(1-s/L)\cos(2\pi ns/L),&n=j,\\
 \dfrac{\sin(2\pi js/L)-\sin(2\pi ns/L)}{\pi(n-j)},&n\ne j
 \end{cases}
 \quad(0\le s\le L),
 \tag{4.2}
\]

и Q=0 при s>L. Полюсная матрица — буквально κ(uu^T−vv^T) из MARKOV (1.5), где \(\kappa=32L\sinh^2(L/4)\). Таким образом, (4.1) восстанавливает **raw** CCM entries, а не подобранный численный surrogate.

**Доказательство.** Корреляция двух оконных экспонент вычисляется интегрированием на пересечении двух окон и даёт (4.2), включая диагональную ветвь и нулевое значение при s=L. Полюсные интегралы экспонент дают рациональное выражение MARKOV (1.5). Для архимедова члена группировка диагонали использует

\[
 \int_0^\infty\frac{e^{s/2}-1}{\sinh s}\,ds=\log2+\pi/2,
 \qquad
 J(L):=\int_L^\infty j(s)ds=\operatorname{atanh}(e^{-L/2})+\arctan(e^{-L/2}).
 \tag{4.3}
\]

Первое равенство получается разложением 1/(1−e^-2s) в положительный геометрический ряд и суммированием разностей простых дробей; второе — подстановкой z=e^-s/2. Получается та же константа и тот же архимедов хвост, что в закреплённой формуле. Простые степени обрезаются при n=16 только для двух оконных аргументов. Для h_out такой отсечки нет. ∎

Эта проверка аналитической карты не заменяет повторный запуск присланного Arb eigensolver. Сообщённые 289 совпадений матричных элементов остаются диагностикой другого исполнителя.

### L10. Полностью независимая реализация X

**PROVED HERE. [FINITE_CELL / PAPER]**

Положим

\[
 W(x)=\sum_{\ell\ne0}h(x+\ell L)\quad(x\in I),\quad
 I_W=\int_I W(x)v(x)dx,\quad P_v=\int_Ip(x)v(x)dx,
\]

\[
 P_W=\int_Ip(x)W(x)dx,\qquad
 P_{\rm out}=2\int_b^\infty p(x)h(x)dx.
\]

В корреляциях W и v нулево продолжаются. Обозначим

\[
 C_o(s)=\int_{\max(-b,b-s)}^b h(y+s)v(y)dy,
 \quad C_w(s)=\int_{-b}^{b-s}W(y)v(y+s)dy\quad(0\le s\le L).
 \tag{4.4}
\]

Тогда

\[
\boxed{
\begin{aligned}
 X(v)={}&(P_{\rm out}-P_W)P_v+c_*I_W
 -2\int_0^\infty j(s)C_o(s)ds\\
 &-\int_0^Lj(s)\{2I_W-2C_w(s)\}ds-2I_WJ(L)\\
 &-2\sum_{n\ge2}c_nC_o(a_n)
 +2\sum_{2\le n\le16}c_nC_w(a_n)
 +\langle P_mW,A_mv\rangle.
\end{aligned}}
 \tag{4.5}
\]

Если точная eigenrelation A_mv=λ_1v отдельно установлена, последний член равен λ_1 I_W. Без неё используется сырая конечная матрица, либо добавляется бюджет

\[
 |\langle P_mW,A_mv\rangle-\lambda_1I_W|
 \le\|P_mW\|\,\|A_mv-\lambda_1v\|.
 \tag{4.6}
\]

**Доказательство.** При чётных реальных аргументах Q=2C. Для h_out смена переменной в корреляции оставляет именно область y+s>b, что даёт C_o. Его внутреннее скалярное произведение с v равно нулю. Для W оба аргумента оконные, поэтому архимедов интеграл при s>L равен 2I_WJ(L), а простые n>16 отсутствуют. Наконец,

\[
 \mathfrak k((I-P_m)W,v)=\mathfrak k(W,v)-\langle P_mW,A_mv\rangle.
\]

Подстановка в \(X=\mathfrak k(h_{out},v)-\mathfrak k((I-P_m)W,v)\) доказывает (4.5). **Радикальность h в этом выводе не использована.** ∎

### Сингулярность в нуле: явное устранение, включая boundary strip

Пусть \(b_j\) — нормированные координаты в чётном базисе, так что

\[
 v(y)=\frac1{\sqrt L}\left[b_0+\sqrt2\sum_{j=1}^{16}b_j\cos(\omega_j(y+b))\right],
 \quad\omega_j=2\pi j/L.
\]

Определим всюду непрерывные функции

\[
 \rho(s)=s j(s),\quad\rho(0)=\tfrac12,
 \qquad
 d_v(y,s)=\frac{v(y)-v(y+s)}s,
\]

\[
 d_v(y,s)=\frac{\sqrt2}{\sqrt L}\sum_{j=1}^{16}b_j\omega_j
 \sin(\omega_j(y+b+s/2))\operatorname{sinc}(\omega_js/2).
 \tag{4.7}
\]

При s=0 это −v'(y), а sinc(0)=1. На [0,L]

\[
 2j(s)C_o(s)=2\rho(s)\int_0^1h(b+st)v(b-s+st)dt,
 \tag{4.8}
\]

\[
\begin{aligned}
 j(s)(2I_W-2C_w(s))=2\rho(s)\int_0^1\big[&(L-s)W(-b+(L-s)t)d_v(-b+(L-s)t,s)\\
 &+W(b-st)v(b-st)\big]dt.
\end{aligned}
 \tag{4.9}
\]

Второе слагаемое — **обязательная граничная полоска**, не мелкая поправка по соглашению. При s=0 пределы (4.8) и (4.9) соответственно h(b)v(b) и W(b)v(b). Они не зануляются постановкой ложных нулевых граничных условий. Для s≥L в C_o используем

\[
 C_o(s)=L\int_0^1h(s-b+Lt)v(-b+Lt)dt.
 \tag{4.10}
\]

Формулы (4.8)–(4.10) превращают задачу в интегралы непрерывных, кусочно аналитических функций на компактных прямоугольниках. Для ρ у нуля можно интервально вычислять

\[
 \rho(s)=\frac{e^{-s/2}}{2\sum_{k\ge0}(-2s)^k/(k+1)!},
\]

с остатком экспоненциального ряда. Для sinc используется её степенной ряд. **Раздельное интегрирование двух расходящихся членов не требуется.**

### L11. Явный бюджет всех бесконечных частей при m16

**PROVED HERE. [FINITE_CELL / PAPER]**

Следующие усечения превращают (4.5) и независимое F в конечную задачу с явным остатком:

```text
theta summation:        n = 1,...,8
periodization images:  ell = -1,+1
exterior prime sum:    2 <= n <= 64, all prime powers in that range
exterior arch integral:0 <= s <= log 64, split at s=L
exterior pole integral:b <= x <= 3
sampled Xi series F:   16 < |n| <= 160
```

Из присланных нормированных координат, независимо от eigenrelation, получено

\[
 \|v\|_\infty<2,\qquad \|v'\|_\infty<11,
 \qquad \|v''\|_\infty<87.
 \tag{4.11}
\]

Точные интервальные верхние значения до округления: 1.839259, 10.955244, 86.688193. В дальнейшем используются более слабые рациональные границы (4.11).

**Theta-ошибка.** На любом x≥0 хвосты h,h',h'' после n=8 по доказательству (2.2) имеют модуль <10^-90. Для R хвост неотрицателен; для производных используется двусторонняя граница. Эта оценка не обнуляет h при большом x: это именно абсолютный remainder.

**Периодизация.** При |x|≤b и |ell|≥2 имеем |x+ell L|≥3b. Из (1.7) и положительного ряда с геометрическим отношением следуют

\[
 \|W-h(L+\cdot)-h(L-\cdot)\|_\infty
 +\|W'-[h'(L+\cdot)-h'(L-\cdot)]\|_\infty<10^{-5000}.
 \tag{4.12}
\]

Например, положим Y=4096π. Мажоранты (1.5) дают для первого пропущенного аргумента 3b величины 32e^{3b/2}Y²e^-Y и 160e^{3b/2}Y³e^-Y. Отношение мажорант соседних образов меньше 1/2: y увеличивается в 256 раз. Поэтому суммарная ошибка и её первая производная не превосходят

\[
 4e^{3b/2}(32Y^2+160Y^3)e^{-Y}<10^{-5000}.
\]

Последнее следует уже из 3<π<4 и log10<2.31. Это оценка всего ряда образов, а не обнуление дальних слагаемых.

## 5. Как энтропийный механизм должен вернуться к буквальным bottoms

### L13. Правильная физическая метрика и все дополнительные члены

**PROVED HERE. [FINITE_CELL / PAPER]**

Умножение F↦hF не является унитарным отображением L²(μ) в физическое L²(dx). Точная метрика:

\[
 \|hF\|_{L^2(dx)}^2=\int w(x)|F(x)|^2d\mu(x),
 \qquad w(x)=\frac{2h(x)}{\cosh(x/2)}.
 \tag{5.1}
\]

Поэтому Markov-flow S_t из L6 не совпадает с минимизацией физического Rayleigh quotient. Для конечного пространства

\[
 \mathcal W_m=\{f/h:f\in V_{m,E}\}
\]

точная нормированная imaginary-time эволюция f'=−(A_m−R_m)f, R_m=<f,A_mf>, ||f||=1, в переменной F=f/h имеет слабую форму

\[
\begin{aligned}
 \langle wG,\dot F\rangle_\mu={}&-\mathcal E_h(G,F)
 +8\langle G,F\rangle_\mu
 -8\langle G,1\rangle_\mu\langle1,F\rangle_\mu\\
 &+8\langle G,\tau\rangle_\mu\langle\tau,F\rangle_\mu
 +R_m\langle wG,F\rangle_\mu,
 \qquad G\in\mathcal W_m.
\end{aligned}
 \tag{5.2}
\]

Член τ равен нулю в чисто чётном carrier, но показан, чтобы не потерять полный source law. Правая часть тестируется только на \(\mathcal W_m\): это weighted projection, которую нельзя убрать при обращении к L_h.

**Доказательство.** (5.1) следует из плотности μ. Для оконных тригонометрических функций тождество формы получается сглаживанием обоих граничных скачков: на фиксированном окне h отделена от нуля, а архимедова норма имеет логарифмический Fourier-вес; это тот же конечный source crosswalk, что в MARKOV (6.8). Дифференцирование f=hF и поляризация тождества дают (5.2). Точная нормированная физическая эволюция существует в конечной размерности при любом Hermitian A_m, в том числе с отрицательным bottom. ∎

Если бы проекции не было, формально правая часть содержала бы

\[
 w^{-1}[-\mathcal L_hF+8F-8\langle F\rangle
          +8\tau\langle\tau F\rangle]+R_mF,
\]

а не просто −L_hF. В конечном carrier нужно ещё вернуть weighted projection. Это конкретные компенсационные члены, а не переименование неизвестного overlap.

Для \(S=\int|F|^2d\mu\), \(\rho=|F|^2/S\), где допустимо дифференцирование, точная вариация нормированной энтропии есть

\[
 \frac d{dt}\operatorname{Ent}_\mu(\rho)
 =\frac2S\Re\int \overline F\dot F
          \left[\log\frac{|F|^2}{S}-\operatorname{Ent}_\mu(\rho)\right]d\mu.
 \tag{5.3}
\]

При нулях F это равенство можно сначала записать для regularized density и пройти к пределу там, где имеется доминирование. Подстановка (5.2) не превращает (5.3) в (3.3): иной вес, полюсные rank-one члены и проекция остаются. Их знаки не установлены.

### L14. Добавление фиксированной энергии к anchored KL не даёт универсальной монотонности

**PROVED HERE. [ABSTRACT / PAPER]**

Даже для positivity-improving конечной полугруппы не существует общего правила: «добавь фиксированное η·Rayleigh к KL относительно произвольного фиксированного якоря — получится убывание».

**Точный falsifier.** Возьмём

\[
 A=\begin{pmatrix}0&-1\\-1&0\end{pmatrix},\quad
 \phi_0=(1,1)/\sqrt2,\quad\phi_1=(1,-1)/\sqrt2,
 \quad q=(3/4,1/4).
\]

Bottom равен −1; e^-tA имеет строго положительные элементы при t>0. Пусть

\[
 f_\varepsilon=(\phi_0+\varepsilon\phi_1)/\sqrt{1+\varepsilon^2},
 \quad p_j=|(f_\varepsilon)_j|^2,
 \quad D(\varepsilon)=\sum p_j\log(p_j/q_j).
\]

Нормированный физический flow задаёт \(\dot\varepsilon=-2\varepsilon\). Непосредственно

\[
 D'(0)=-\log3,\quad
 \frac d{dt}D=2\varepsilon\log3+O(\varepsilon^2),
 \quad
 \frac d{dt}\langle f,Af\rangle=-\frac{8\varepsilon^2}{(1+\varepsilon^2)^2}.
 \tag{5.4}
\]

Для любого заранее фиксированного конечного η производная D+η<f,Af> положительна при достаточно малом ε>0. ∎

Это опровергает **общий компенсатор**, а не любой возможный source-specific функционал. Выбор якоря как неизвестного истинного ground-state распределения обходит пример ценой внесения самой задачи выбора bottom в определение якоря.

### L15. Слабейший полезный локализованный баланс без предположения простоты

**PROVED HERE. [ABSTRACT / PAPER]**

Фиксируем чётный jet J конечной размерности и C=P_J. Пусть (e_j) — фиксированный ONB из последовательного ортонормирования производных h; плотность этого семейства — вход CONFINE. Возьмём положительный trace-class якорь

\[
 \Sigma=\sum_{j\ge0}2^{-j-1}|e_j\rangle\langle e_j|,
 \quad \Sigma_m=\frac{P_m\Sigma P_m}{\operatorname{Tr}(P_m\Sigma P_m)},
 \quad C_m=P_mCP_m.
\]

Σ_m строго положительна на конечном carrier. Определим для **вспомогательного времени** t≥0

\[
 \varrho_m(t)=
 \frac{e^{-tA_m}\Sigma_m e^{-tA_m}}
      {\operatorname{Tr}(e^{-tA_m}\Sigma_m e^{-tA_m})},
 \quad B_m(t)=\operatorname{Tr}(C_m\varrho_m(t)).
 \tag{5.5}
\]

Это не Shannon-энтропия и не переименование overlap. Это физическая эволюция полного состояния, начальное фиксированное compact-mass которой известно. Если J — первые r базисных элементов, то

\[
 B_m(0)\longrightarrow\operatorname{Tr}(C\Sigma)=1-2^{-r}>0.
 \tag{5.6}
\]

Пусть Π_0 — весь ground eigenspace A_m; кратность не ограничивается. Тогда

\[
 \varrho_m(\infty)=\frac{\Pi_0\Sigma_m\Pi_0}{\operatorname{Tr}(\Pi_0\Sigma_m)},
 \qquad
 B_m(\infty)=\operatorname{Tr}(C_m\varrho_m(\infty)).
 \tag{5.7}
\]

**Доказательство.** Σ инъективна, поэтому её сжатие положительно определено. Исходное P_m→I сильно; trace-class аппроксимация конечными суммами даёт (5.6). Для фиксированного m домножение числителя и знаменателя (5.5) на e^{2tλ_0} оставляет в пределе только Π_0Σ_mΠ_0; его след положителен. Никакой uniform gap по m не использован. ∎

**IMPLIES RH — пока не доказанное следующее source-неравенство:** существование c>0 и неограниченного набора исходных m с B_m(∞)≥c. Оно даёт хотя бы один единичный bottom с ||P_Jf_m||²≥c. Этого достаточно для RH через NOESCAPE L6. Для заранее выбранного произвольного вектора в многомерном ground eigenspace это не гарантирует его личного overlap; смешанное состояние нельзя выдавать за bound для каждого выбора. Для существования RH-свидетеля данный выбор достаточен.

### L16. Полная вариация локализованного баланса и первое неоплаченное неравенство

**PROVED HERE. [FINITE_CELL / PAPER]**

Для R_m(t)=Tr(A_m varrho_m(t))

\[
 \dot\varrho_m=-A_m\varrho_m-\varrho_mA_m+2R_m\varrho_m,
\]

\[
 \dot B_m=\mathcal B_{A_m}(t),\qquad
 \mathcal B_D(t):=-2\Re\operatorname{Tr}(C_mD\varrho_m)
           +2\operatorname{Tr}(D\varrho_m)B_m.
 \tag{5.8}
\]

Для буквального разложения \(A_m=A_{{arch},m}-\sum_{2\le n\le m}c_nQ_{n,m}+W_{02,m}\)

\[
 \boxed{\dot B_m=\mathcal B_{A_{{arch},m}}
              -\sum_{2\le n\le m}c_n\mathcal B_{Q_{n,m}}
              +\mathcal B_{W_{02,m}}.}
 \tag{5.9}
\]

Все Q_{n,m} — сжатия двух настоящих нулево-продолженных сдвигов. Сохраняются все prime powers и оба полюсных сектора; на чётном секторе нечётная pole-компонента тождественно нулевая. Каждый член (5.9) — точная ковариация, не априори положительная или отрицательная.

**Доказательство.** Дифференцируем конечные матричные экспоненты и нормирующий след. Цикличность следа даёт (5.8); линейность по D — (5.9). При фиксированном m сходимость к (5.7) экспоненциальная после выделения ground eigenspace, поэтому интегральный баланс корректен. ∎

Первое неоплаченное source-неравенство здесь — ровно **суммарный знаковый перенос**, а не tightness всей последовательности:

\[
 \boxed{
 \int_0^\infty\left[
  \mathcal B_{A_{{arch},m}}-
  \sum_{2\le n\le m}c_n\mathcal B_{Q_{n,m}}+
  \mathcal B_{W_{02,m}}
 \right]dt\ \ge\ c-B_m(0)
 }
 \tag{5.10}
\]

на неограниченном исходном наборе m, с фиксированным J и c>0. Если доказать (5.10) из source entries, то (5.7) и NOESCAPE завершают импликацию к RH. В этом вердикте такой нижней оценки интеграла нет.

**Попытка через имеющуюся норму и место её провала.** Quasimode-контроль даёт малость ||C_mA_m|| для фиксированного J. Но из (5.8) следует лишь

\[
 \dot B_m\ge2R_mB_m-2\|C_mA_m\|.
 \tag{5.11}
\]

Нет оплаченной нижней границы R_m на нужном временном интервале; кроме того, время проекции на bottom может расти быстрее обратной quasimode-ошибки. Подставить cofinal lower floor R_m≥−o(1) как уже известное было бы использованием RH-эквивалентной цели в качестве посылки. Поэтому (5.11) не интегрируется в (5.10) имеющимися оценками.

**Отрицательный/escaping falsifier для всей машины.** На V_m=span(e_0,…,e_m) положим

\[
 A_me_j=2^{-m^2}e_j\ (j<m),\qquad A_me_m=-e_m.
 \tag{5.12}
\]

Для любого фиксированного jet residual стремится к нулю сверхполиномиально; Σ_m и начальная масса (5.6) остаются ровно теми же. Но \(\varrho_m(\infty)=|e_m\rangle\langle e_m|\), так что B_m(∞)=0 для m≥r, а интеграл в (5.10) равен −B_m(0). Он нарушает любой положительный бюджет c. Ни отрицательная eigenvalue, ни убегающее направление не проходят предложенный guard.

Это не новый доказанный supplier для T: (5.10) — точный остаток **реальной source-эволюции**, выписанный со всеми компенсационными членами. Он остаётся альтернативой для анализа, не заменой незавершённого F/X-теста.

## 6. Что именно сохранено для цели владельца

**IMPLIES RH:** T, persistent nonzero weak fingerprint или положительная сохраняющаяся фиксированная compact-mass bottom-состояния — по точному source-preserving мосту NOESCAPE. Конверс RH=>T здесь не утверждается.

**EQUIVALENT TO RH:** исчезающая нижняя граница λ_min(A_m)≥−r_m с r_m→0 на неограниченной исходной последовательности — по отдельным отрицательным свидетелям CONFINE/NOESCAPE. Она не расходуется как доказанный вход этого ответа.

**PROVED HERE:** острая LSI с коэффициентом 1/4 не может быть этим supplier. В противоположность ей, (1.8), (3.3), (4.5), (5.2) и (5.9) — реальные тождества источника. Из них пока не извлечены ни необходимый lower floor, ни сохраняющаяся compact-mass.

Для прежнего inverse-weighted пути остаётся полный бюджет

\[
 \sum_{\substack{i\ge1\\\lambda_{m,i}\ne0}}
 \frac{|F_{m,i}+X_{m,i}|^2}{Z_m^2\lambda_{m,i}^2}
 +\sum_{\substack{i\ge1\\\lambda_{m,i}=0}}|\langle P_mh/Z_m,v_{m,i}\rangle|^2
 \le c<1.
 \tag{6.1}
\]

Нулевые уровни сохранены. После этого ответа не появляется права отбросить X или его нулевые знаменатели: m16 attribution ещё не завершён.

Требование полной KL-ограниченности из запроса A не выбирается: оно действительно сильнее T. Его Gibbs-расчёт согласуется с \(\log E_qe^{tj}=\log(1+1/\sqrt2)\), t=log2/2. Для \((e_0+e_m)/\sqrt2\) T есть, а D=(m/2)log2 расходится. Никакой новый Shannon- или moving-reference shortcut не добавлен.

Lions используется только как **RELAY-аналогия**, не как теорема-посылка. В данном квадратичном фиксированном m задача с массой a имеет значение aλ_min(A_m); строгая субаддитивность той же задачи невозможна. Нового energy-at-infinity сравнения с оплаченными prime/pole членами здесь нет.

## 7. Контроль решения, предсказания и следующий точный тест

### Две альтернативы после опровержения LSI

| Представление | Что действительно проверяется | Kill-power / стоимость | Первая опасность |
|---|---|---|---|

Первая альтернатива остаётся ближайшим исполнимым discriminator. Вторая имеет точный consumer, но не получила здесь численной или аналитической оценки (5.10).

Три проверенных стыка: равенственная мода Dirichlet-формы дала кубический контрпример; periodization дала независимые физические интегралы X; конечная матричная эволюция дала compact-flux balance. Ни один стык не подменяет квантор «неограниченное множество m» конечной таблицей.

### Сильнейшая атака на собственный результат

LSI-контрпример провалился бы, если бы q не принадлежала полной энергетической области или если бы M3 имел неверный знак. L1–L2 оплачивают первую проблему, включая бесконечные prime powers; L4 оплачивает вторую интервально, с положительным хвостом. M4 нужен не для декоративной точности, а для явного ε=10^-3 и строгой отрицательной верхней границы.

F/X-ветка, напротив, не имеет права на положительный closeout: хвостовой бюджет — не интервал конечной знаковой суммы. Это оставлено в header и в (4.26) явно.

### Предсказания и закрытие

До интервального теста зарегистрировано собственное ожидание M3>10^5; оно **CONFIRMED** более сильной границей M3>180000. Более ранние диагностические значения M2/M3 из запроса не использовались как enclosures. Для m16 отдельного вероятностного прогноза о D_ext не регистрировалось и результата D_ext нет; ретроспективный «hit» не выставляется.

Что стало меньше: из рассмотрения исключён конкретный sharp-LSI supplier; устранены domain-gap кубического теста, нуль-согласованность присланного pairing-product и неопределённость независимой формулы X. Что не стало меньше: cofinal sign (6.1), source-flux bound (5.10), выбор bottom среди схлопывающихся уровней.

## 9. Proshka's own line

Идея энтропии получила здесь настоящую проверку, а не аналогию с Перельманом.
Первым выбран равенственный theta-вектор, потому что он проверяет точную константу.
Слабый тест на произвольной функции мог бы не увидеть дефект sharp LSI.
Норма residual снова была бы слишком грубым инструментом для выбора bottom.
Полная anchored KL потребовала бы существенно больше, чем нужно владельцу.
Ненулевой третий момент оказался не мелкой поправкой, а решающим знаком.
Оценка четвёртого момента сделала контрпример явным при конечном epsilon.
Я не стал заменять этот шаг согласованием двух mpmath-десятичных ответов.
Положительный хвост и интервальные rectangles дают отдельный проверяемый сертификат.
Важное структурное наблюдение: у auxiliary generator действительно есть eigenvalue 8.
Причём одна и та же энергия относится к бесконечному семейству чётных radical-направлений.
Поэтому сам факт существования такого генератора ещё не выбирает нужный confined state.
Его настоящая энтропия убывает даже вдоль полностью нулевого Weil-направления.
Именно это отделяет source-механику от обещания решить выбор ground state.
Кубическая компенсация устраняет дефект разложения, но возвращает Poincare-границу.
Я не предлагаю выдавать это возвращение за новый прогресс к RH.
Первый ход дальше — закончить независимый X на уже имеющемся m16.
Его может убить большой exterior-to-total ratio, а не ещё одна новая запись residual.
Второй ход — исследовать знаковый compact-flux balance с полной физической метрикой.
Его убьёт попытка оплатить долгий selection time лишь малой нормой quasimode.
Для первого хода полезен сохранённый source eigenpair certificate, не дополнительная таблица m.
Для второго нужна оценка полного знакового потока, не монотонность другой полугруппы.
Самое подозрительное место полки — слово «entropy» без указания меры и параметра.
Самое полезное новое место — точное насыщающее направление h''/h−1/4.
Цель остаётся доказанной RH; ни слабый compact target, ни исходный carrier не заменены.
Этот ответ уничтожает неверный supplier и сохраняет конкретный следующий проверяемый объект.


`--request` — путь к точному приложенному TXT; при другом расположении заменяется только путь, не содержимое. SHA-256 приведённого Python-файла (UTF-8 с конечным LF): `2555a93a33bb215c3634b4e26f008616beab80bb56c2f1622ee84aa2db403c91`.

```python
#!/usr/bin/env python3
"""ENTROPY: elementary interval certificates; no floating quadrature, no Arb.
Run: uv run --with mpmath==1.3.0 python certify_entropy.py
Optional: add --m16 with the authoritative TXT in the current directory.
"""
from __future__ import annotations
import argparse
import hashlib
import math
import re
import time
from pathlib import Path
import mpmath as mp

EXPECTED = "5a636544b8a6b0ee52a6e212201df7cd5fa64c98d4021767b36dc7e67a4eabf1"
iv = mp.iv

def progress(i: int, n: int, start: float) -> None:
    done = i / n
    eta = (time.monotonic() - start) * (n - i) / max(i, 1)
    bar = "#" * int(24 * done) + "-" * (24 - int(24 * done))
    print(f"[{bar}] {i}/{n} ETA {eta:.1f}s", flush=True)

def theta_hr(x):
    """h and h''-h/4 on x>=0, with uniform n>=9 remainder."""
    y = iv.pi * iv.exp(2*x)
    pref = iv.exp(x/2)
    H, R = iv.mpf(0), iv.mpf(0)
    for n in range(1, 9):
        z = y * n*n
        e = pref * iv.exp(-z)
        H += 8*z*(2*z-3)*e
        R += 16*z*(4*z**3-28*z**2+41*z-9)*e
    H += iv.mpf([0, "1e-90"])
    R += iv.mpf([0, "1e-90"])
    return H, R

def theta_h(x):
    y = iv.pi*iv.exp(2*x)
    pref = iv.exp(x/2)
    return (pref*sum(8*(y*n*n)*(2*y*n*n-3)*iv.exp(-y*n*n)
                     for n in range(1,9)) + iv.mpf([0,"1e-90"]))

def moments() -> None:
    iv.dps = 45
    y = iv.pi * 81
    theta_tail = 3000*y**4*iv.exp(-y)
    assert theta_tail.b < iv.mpf("1e-90").a
    print("theta remainder upper:", theta_tail)
    panels = 4096
    step = iv.mpf(3)/(2*panels)  # exact dyadic mesh
    M2, M3, M4 = iv.mpf(0), iv.mpf(0), iv.mpf(0)
    g_lower = iv.mpf(0)
    start = time.monotonic()
    for i in range(panels):
        x = iv.mpf([(step*i).a, (step*(i+1)).b])
        H, R = theta_hr(x)
        assert H.a > 0
        g = R/H
        co = (iv.exp(x/2)+iv.exp(-x/2))/2
        rho = co*H
        M2 += step*rho*g**2
        M3 += step*co*R**3/H**2
        M4 += step*rho*g**4
        if g.a < g_lower.a:
            g_lower = g.a
        if (i+1) % 1024 == 0:
            progress(i+1, panels, start)
    tail = (iv.mpf(1600000000)*math.factorial(10)*iv.exp(-60)
            * sum(iv.mpf(60)**k/math.factorial(k) for k in range(11)))
    print("M2 core:", M2)
    print("M3 core:", M3)
    print("M4 core:", M4)
    print("M2/M4 common positive tail majorant:", tail)
    print("g lower on core:", g_lower)
    assert M3.a > 180000
    assert M2.b + tail.b < 2000
    assert M4.b + tail.b < 100000000
    assert g_lower.a > -100
    # Outside the core, R(z)>0 since z>=pi*exp(3)>60>7.

def m16(path: Path) -> None:
    data = path.read_bytes()
    if hashlib.sha256(data).hexdigest() != EXPECTED:
        raise ValueError("Authoritative TXT SHA-256 mismatch")
    iv.dps = 100
    text = data.decode("utf-8")
    pairs = re.findall(r"^\d+ \[([^\s]+) \+/- ([^\]]+)\]", text, re.M)
    if len(pairs) != 17:
        raise ValueError("Expected exactly 17 even coordinates")
    def ball(a: str, r: str):
        ru = iv.mpf(r).b
        return iv.mpf(a)+iv.mpf([-ru, ru])
    X = [ball(a,r) for a,r in pairs]
    norm = iv.sqrt(sum(x*x for x in X))
    assert norm.a > 0
    X = [x/norm for x in X]
    lm = re.search(r"^lambda1=\[([^\s]+) \+/- ([^\]]+)\]", text, re.M)
    if lm is None:
        raise ValueError("Missing lambda1 ball")
    lam = ball(*lm.groups())
    L = iv.log(16); b = L/2; pi = iv.pi
    rt2 = iv.sqrt(2); rtL = iv.sqrt(L)
    B0 = (abs(X[0])+rt2*sum(abs(x) for x in X[1:]))/rtL
    B1 = rt2*sum(abs(X[j])*2*pi*j/L for j in range(1,17))/rtL
    B2 = rt2*sum(abs(X[j])*(2*pi*j/L)**2 for j in range(1,17))/rtL
    assert B0.b < 2 and B1.b < 11 and B2.b < 87
    print("Input norm:", norm)
    print("B0, B1, B2:", B0, B1, B2)
    panels = 4096
    dt = iv.mpf(1)/panels
    total = iv.mpf(0)
    start = time.monotonic()
    for i in range(panels):
        t = iv.mpf([(dt*i).a, (dt*(i+1)).b])
        x = b*t
        H = theta_h(x)
        v = (X[0]+rt2*sum(X[j]*iv.cos(2*pi*j*(x+b)/L)
                          for j in range(1,17)))/rtL
        total += 2*b*dt*H*v
        if (i+1) % 1024 == 0:
            progress(i+1,panels,start)
    product = lam*total
    assert total.a > iv.mpf(".0834").b
    assert total.b < iv.mpf(".0952").a
    assert product.a > iv.mpf("3.95e-33").b
    assert product.b < iv.mpf("4.51e-33").a
    print("<h,v>:", total)
    print("lambda1*<h,v>:", product)
    print("This certifies functions of INPUT BOXES, not a rerun of source eigenpair isolation.")
    yp = pi*65**2/16
    prime_tail = 128*L*2*pi**2/iv.mpf(4)**iv.mpf("4.5")*65**5*iv.exp(-yp)
    Y = pi*256
    arch_tail = 64*L*2*iv.exp(-b/2)*(Y+1)*iv.exp(-Y)
    a = pi*pi/(4*L)
    F_tail = 2*6000*1200/rtL*iv.exp(-a*161)/(1-iv.exp(-a))
    assert prime_tail.b < iv.mpf("9e-351").a
    assert arch_tail.b < iv.mpf("8e-345").a
    assert F_tail.b < iv.mpf("9e-56").a
    print("external prime tail:", prime_tail)
    print("external arch tail:", arch_tail)
    print("sampled F tail:", F_tail)
    print("D_ext NOT COMPUTED. No X=total-F substitution performed.")

if __name__ == "__main__":
```
