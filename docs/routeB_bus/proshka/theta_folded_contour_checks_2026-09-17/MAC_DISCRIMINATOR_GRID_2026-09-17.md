## 0. Вопрос и ответ

Вопрос (очередь шины, 17.09, «следующий зонд — наш»): на полосе 0 < σ < ½, √20 < T ≤ 60 построить
строгую таблицу дискриминатора [L_N, U_N] = [h_N − ℰ_N, h_N + ℰ_N] по (3.2)–(3.4) и (5.2), с упором
на σ → 0 на высотах нулей, где ℋ обязана касаться нуля и голова h_N могла бы провалиться ниже остатка.
Плюс полка: неравенство Лагерра X′² − XX″ ≥ 0 для ξ на критической прямой.

Ответ на конечной сетке: **ЕСЛИ_A.** Ни в одной из 1310 точек нижний край L_N не касается нуля.
Строго сертифицировано L_N > 0 везде, при этом h_N/ℰ_N ≥ 3.09·10⁴⁴ (минимум на T = 60, σ = 1/64).
На высотах нулей провала нет: при σ → 0 голова ведёт себя как 4σ·ℒ₁, ℒ₁ = j′² − jj″, а в простом
нуле j = 0 и ℒ₁ = j′² > 0. Наклон 4ℒ₁ − e_N сертифицирован положительным во всех 262 T, и
неравенство Лагерра для самой ξ сертифицировано во всех 262 T независимым путём.

Что это **не** значит: это конечное множество точек. Континуум по σ и T не сертифицирован, глобальный
знак головы (7.1) не доказан, никакого утверждения о RH.
**Знак ℋ на T ≤ 60 следует из верифицированных нулей через Хадамара; прогон сертифицирует представление, не знак.** «1310 POSITIVE» — это не свидетельство в пользу знака, а проверка того, что конечная контурная сумма с оплаченным остатком воспроизводит уже известный знак на конечных точках. Величина запаса (10⁴⁴) объясняется выбором
диагностического среза M = ⌈√(40/c)⌉: остаток несёт e^{−πcM²} ≤ e^{−40π}; при адаптивном срезе (6.3) запас
другой, здесь он не считался.

## 1. Что именно посчитано

Для каждой точки (σ, T):
- ϑ = π/4 − 1/(T+1), c = cos 2ϑ, M = ⌈√(40/c)⌉, N = M − 1 (зарегистрированный диагностический срез, не (6.3)).
- J_N, J_N′, J_N″ по (2.5): для каждого n ≤ N два луча, интеграл по t ∈ [0, L] через `acb.integral`
  (строгие шары), множители (t+iϑ)^j и (−(t−iϑ))^j для производных по p (второй луч даёт знак).
  Хвост t > L оценен аналитически: |подынтегральное| ≤ e^{−ϑT} e^{(j+σ)t}(4a²e^{9t/2}+6a e^{5t/2})e^{−ac e^{2t}},
  после u = e^{2t} мажоранта u³ и точное интегрирование по частям (как в §4 источника); хвост добавлен как шар.
  L выбирается так, чтобы хвост n=1 был < 10^{−(dps+8)}·e^{−ϑT}; на всей сетке L = 4.
- h_N = 4 Re(J_N′ · conj J_N) (3.4); e_N = 28672 c^{−5} M³ exp(−πcM² − 2ϑT) (раунд 8, (1.1)); ℰ_N = σ e_N;
  L_N = h_N − ℰ_N, U_N = h_N + ℰ_N. Сертификат знака: POSITIVE если нижний край шара > 0, NEGATIVE если верхний < 0, иначе UNDECIDED.
- Строгая проверка (4.2): F(p) = ξ(½+p) через `acb` zeta/gamma, |F − J_N| ≤ B e^{−ϑT}, B = 448 c^{−1} M³ e^{−πcM²}.
- Наклон σ → 0 в p = iT: j = Re J_N(iT), j′ = Re(i J_N′), j″ = Re(−J_N″), ℒ₁ = j′² − jj″; сертификат знака 4ℒ₁ − e_N.
- Отдельно (`check_laguerre_xi.py`): X(T) = ξ(½+iT), производные через интеграл Коши радиуса ½ в `acb.integral`,
  ℒ₁[ξ] = X′² − XX″ с сертификатом знака. Это **другое представление** (ζ/Γ, не контурная гамма-сумма).

Точность: arb на 80 десятичных знаках; максимальный относительный радиус шара h_N на сетке 1.0·10⁻⁶¹ (T = 60).

## 4. Что это даёт и не даёт для очереди

- Ветка **ЕСЛИ_A** очереди: L_N ≥ 0 на всей конечной сетке, включая σ = 1/64 у всех 13 нулей. Двусторонний
  бюджет (5.2) здесь не груб: он на 44 порядка меньше головы. Значит просить у Прошки направленную
  оценку остатка (R2) ради второго порядка по σ на этой полосе численно не мотивировано; мотивация R2
  остаётся структурной (совместимость с кратностью), не численной.
- Ветка **ЕСЛИ_B** (интервал через ноль у нулей) на этой сетке **не наступила**.
- Полка Лагерра для ξ на [4.5, 60] с шагом 0.25 и на нулях ±0.05 сертифицирована положительной. Это
  необходимое условие RH, оно не новое (известно численно далеко выше), здесь ценность в том, что оно
  получено тем же инструментом и совпадает с первым порядком ℋ по σ из контурной суммы на 46 знаков.
- Не сертифицирован континуум; не доказана (7.1); не тронут адаптивный срез (6.3)/(6.4).
- Открытый численный вопрос, который эта таблица ставит: где вообще L_N может стать малым? На этой сетке
  минимум h_N/ℰ_N монотонно падает с T (3.5e+51 при T≈15 → 3.1e+44 при T=60) из-за роста M и c^{−5};
  экстраполяция даёт запас > 10³⁰ до T ≈ 200 при том же срезе, но это не проверялось.
