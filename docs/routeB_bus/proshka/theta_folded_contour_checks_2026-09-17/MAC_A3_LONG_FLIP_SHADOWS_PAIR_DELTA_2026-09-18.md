## 1. Объекты

Срез (6.3), r = 0: ϑ = π/4 − 1/(T+1), c = cos 2ϑ, M = ⌈√((T+1)(32 + 20 ln(T+1))/3)⌉, N = M − 1.
Лучи r_{n,+}(p) = I_n(p,ϑ), r_{n,−}(p) = I_n(−p,−ϑ) (ζ: (3.3) раунда 7; DH: (3.3)^{DH} из v2), r_N(p) ∈ ℂ^{2N}, J_N = 𝟙·r_N.

**Пара и её pullback** (RAY_BLOCK (6)–(9)): для p_± = ±σ + iγ положим u = conj r_N(p_+), v = conj r_N(p_−);
блок пары B_{ρ,N} = m{ū vᵀ + v̄ uᵀ} сохраняет отрицательное направление ⟺ rank 2 ⟺
Δ_{ρ,N} = ‖u‖²‖v‖² − |u*v|² > 0. Нормировка: Δ̂ = Δ/(‖u‖²‖v‖²) = sin²∠(u,v) ∈ [0,1] (снимает масштаб e^{−2ϑT}).
При σ = 0 строки совпадают, Δ = 0 точно, Δ̂ = O(σ²).

**Лемма (Лагранж).** Δ_N − Δ_{N−1} = Σ_{i<2N−1} |u_i v_new − u_new v_i|² ≥ 0 для каждой добавленной пары компонент:
сырое Δ не убывает по N точно; прирост равен нулю тогда и только тогда, когда новые компоненты пропорциональны
старым — в частности, когда новый луч тождественно нулевой.

**Тени d_N.** ρ = ½ + iγ — нуль ζ (уточнён findroot до 30 знаков); тень — ближайший по высоте нуль d_N(s) = Σ_{n≤N} n^{−s}
в коробке s ∈ [0.01, 2] × [γ−1, γ+1] (оборот фазы + квадродерево + findroot); δ = s_тени − ρ ∈ ℂ (в JSON одним
комплексным полем). Первые принципы (владелец): ζ(s) ≈ d_N(s) + N^{1−s}/(s−1) ⇒ d_N(ρ) ≈ −N^{1−ρ}/(ρ−1) ⇒
δ_th = N^{1−ρ}/((ρ−1)ζ′(ρ)), |δ_th| ≈ √N/(|ρ−1||ζ′(ρ)|), arg δ_th = −γ log N + const.

**E_N тождества (9)** (JN_ZERO_FREE): J_N = B(p)d_N(s) + E_N, B(p) = s(s−1)/2·π^{−s/2}Γ(s/2), s = p + ½.

### 4.1 Структурная оговорка
Δ̂ = O(σ²) при σ → 0 — строки u, v совпадают на оси. Чувствительность к паре, прижатой к оси, падает
квадратично; это та же физика, что h_N = O(σ): нуль сбоку на расстоянии σ даёт сигнал порядка σ², и бюджет ℰ_N
должен быть меньше этого, чтобы его увидеть.

### 4.2 Граница разрешения судьи (REG_ADD_4, операционализация записана до счёта)
Сигнал пары S(σ,γ) := UV(1 − √(1 − Δ̂)) — нижняя оценка |λ₋(B_{ρ,N})|/m, модуля отрицательного собственного
значения блока пары (6) (λ± = m(Re s ± UV), |λ₋| ≥ m(UV − |s|)); единицы |r|², как у |J|². Бюджет ℰ_N = σ e_N.
S ∝ σ² (проверка: S(1/8)/S(1/64)/64 ∈ [1.001, 1.006] по всем γ), ℰ_N ∝ σ, поэтому порог по σ:
σ_min(γ) = σ·ℰ_N(σ,γ)/S(σ,γ) при σ = 1/64.

двух порядках EM, не доказательство. Континуум не сертифицирован, RH_CLAIM: false.
