## 1. Аддитивный объект, не свободный моноид

[ABSTRACT | PAPER.]

Различаем m — окно CCM, N — длину остаточного словаря, k — обычное целое, T — высоту разбиения нулевой суммы. Никакого тождества m=N нет.

    H=ell^2(k>=1, w_k=1/[k(k+1)]),  v(k)=1,
    r_n(k)=(k mod n)/n,  n>=2,  r_n(0)=0.              (C1)

Имеем ||v||²=1 и 0<=r_n<1. Все величины определены целочисленным делением. Ключевое совместное аддитивно-мультипликативное тождество:

    r_n(k)-r_n(k-1)=1/n-1_(n divides k).                (C2)

Здесь используется СОСЕДНЯЯ точка k-1 в обычной решётке. Абстрактная делимость generalized integers этого шага не задаёт.

Для x in (1/(k+1),1/k] положим (Ja)(x)=a(k). Тогда J — изометрия H в замкнутое step-подпространство L²(0,1), а

    Jr_n(x)={1/(n*x)}-(1/n){1/x}.                      (C3)

Действительно, 1/x=k+u, 0<=u<1, и floor((k+u)/n)=floor(k/n). Длины соседних интервалов равны ТОЧНО 1/[k(k+1)]. Это объясняет вес; замена его на 1/k² меняет объект.

Для Re s>1 суммирование (C2) даёт

    int_0^1 (Jr_n)(x)x^(s-1)dx
      =(1/s) sum_(k>=1) r_n(k)[k^(-s)-(k+1)^(-s)]
      =((1/n)-n^(-s))*zeta(s)/s.                       (C4)

Слева ограниченная функция, поэтому Mellin-transform голоморфен при Re s>0. Справа полюс при s=1 снимается. Аналитическое продолжение доказывает (C4) во всей этой полуплоскости. Это source identity, не RH.

В частности,

    b_n=<r_n,v>=log(n)/n.                              (C5)

Тот же аддитивный словарь имеет конечный Fourier-вид на Z/n:

    r_n(k)=(n-1)/(2n)
      -(1/n) sum_(a=1)^(n-1)
                exp(2*pi*i*a*k/n)/(1-exp(-2*pi*i*a/n)). (C6)

Проверка: ненулевой Fourier-коэффициент получается из
sum_(j=0)^(n-1) j z^j=-n/(1-z), z^n=1,z!=1. Положительная метрика ниже — не знак отдельных коэффициентов (C6), а квадрат полного словаря. Jacobi theta и Poisson-суммирование не использованы.

## 2. Все конечные PSD-звенья построены

[ABSTRACT / FINITE_CELL | PAPER.]

Обозначим Gamma_N=(<r_i,r_j>)_(2<=i,j<=N), b=(b_2,...,b_N), Pi_N ортопроекцию на span(r_2,...,r_N), и

    e_N=||v-Pi_N v||²=1-b*Gamma_N^(-1)b,  e_1=1.        (C7)

### 2.1. Положительная обратная независима от RH

Если sum_(n=2)^N c_n r_n(k)=0 для всех k, то (C2) при k=1 даёт sum c_n/n=0. Затем k=2,3,...,N последовательно даёт c_2=c_3=...=c_N=0. Уже первые N строк доказывают полный столбцовый ранг. Поэтому Gamma_N положительно определена; её обратная — обратная reference-Gram, а не обратная неизвестно положительной Weil-формы.

Для каждого K полная Gram-запись имеет entrywise-ошибку не больше 1/(K+1) после суммирования k<=K, поскольку все множители r_n,v лежат в [0,1] и sum_(k>K)w_k=1/(K+1). Рациональная Gram первых N строк даёт строго положительную нижнюю матрицу. Значит каждое конечное состояние можно заключать с оплаченной ошибкой без предположения предельной сходимости e_N.

При Q=lcm(2,...,N) все r_n(Q)=0. Поэтому для любых коэффициентов остаток цели в этой строке равен 1 и

    0<1/[Q(Q+1)]<=e_N<=1.                              (C8)

Ни один конечный префикс не даёт точного нулевого остатка.

### 2.2. Универсальная положительная карта

Augmented Gram

    Gref_N = [[1,b*],[b,Gamma_N]] >=0

строится конгруэнцией тождественной метрики H. Его Schur complement — e_N>=0. Положительность Schur complement следует из

    e_N = min_c (1,-c)* Gref_N (1,-c).

Это доказательство работает для любого PSD augmented input с положительно определённым нижним блоком, не только для наших чисел.

При добавлении r_(N+1) положим

    u_N=(I-Pi_N)r_(N+1),  a_N=||u_N||²>0,
    d_N=<u_N,v-Pi_Nv>.

Тогда точно

    e_(N+1)=e_N-|d_N|²/a_N,  0<e_(N+1)<=e_N.           (C9)

Это Pythagoras/ортогональное исключение. Положительный 2-by-2 Gram даёт |d_N|²<=a_N e_N.

Теперь берём ОДИН известный положительный старт Q_m=A_m(1/2). Определим

    P_m^(N)=e_N Q_m.

Переход каждого префикса имеет вид

    X -> s_N* X s_N,  s_N=sqrt(e_(N+1)/e_N) I.         (C10)

Для ЛЮБОГО PSD-входа X выход PSD. Коэффициент вычисляется только из текущего reference-Gram и следующего r_n. Эквивалентная реализация одного префикса — положительная tensor-map X->Gref_N tensor X, затем конгруэнция вектором (1,-Gamma_N^(-1)b) на первом множителе. Положительность tensor-map следует из Gram-разложения Gref_N, без знания знака A_m(0).

Все префиксы конечны и автономны. Цепочка не читает psi-x, нули, eigenvectors или знак A_m(0). Q_m — разрешённый доказанный старт; он не изменяется вдоль delta. Утверждение, что для каждого m существует конечный останавливающий префикс, пока НЕ доказано.

Точный первый контроль:

    b_2=(log 2)/2, Gamma_22=(log 2)/4,
    e_2=1-log 2.                                      (C11)

Использовано sum_(k odd)1/[k(k+1)]=log 2, а не численная оценка.

## 3. Конечный Mellin-судья: остаток управляет смещением каждого нуля

[ABSTRACT / FINITE_CELL | PAPER; без RH.]

Пусть R_N=1-J(Pi_N v) на (0,1). Его L²-норма в квадрате равна e_N. Для любого настоящего нуля rho=beta+i*gamma с beta>1/2 формула (C4) даёт

    int_0^1 R_N(x)x^(rho-1)dx=1/rho.

Функционал оценки ограничен в L²(0,1), с квадратом нормы 1/(2beta-1). Cauchy–Schwarz даёт

    e_N >= (2beta-1)/|rho|².                           (C12)

Здесь не предполагается, что такой нуль существует. Это безусловное ограничение для каждого нуля, который существует.

Функциональная симметрия настоящей ζ отражает beta<1/2 в 1-beta>1/2, сохраняя |gamma|. Поэтому для |gamma|<=T:

    |beta-1/2| <= a_N(T),
    a_N(T)=min(1/2, e_N(1+T²)/2).                       (C13)

Неизвестные нули используются в доказательстве оценки, а НЕ для построения Gram, выбора звеньев или остановочного порога. Это существенное различие.

### 3.1. Число нулей: независимые константы

T2 при K=Q даёт, грубым увеличением правой части,

    N_all(T)<=12 T log(T+2),  T>=1.

Отсюда Stieltjes-интегрированием:

    Sigma_0=sum_rho 1/(1+gamma²) <=100,
    sum_(|gamma|>T)1/(1+gamma²)
                <=48 log(T+2)/T,  T>=1.               (C14)

Кратности включены. Подробно, первое не больше
12 log3+24 int_1^infinity log(t+2)/t² dt=48 log3<100.
Для второго отбрасываем отрицательный boundary term и используем
int_T^infinity log(t+2)/t² dt
=log(T+2)/T+(1/2)log(1+2/T)<=2log(T+2)/T.
Эти константы не извлечены из таблицы критических нулей.

## 4. Количественный возврат в буквальную A_m

[FINITE_CELL / COFINAL_FAMILY | PAPER.]

Пусть f=S_m z, L=log m>=1 и

    E=||f||²+||f'_int||²=z*G_m z.

Определим F_f(a,gamma)=int_(-L/2)^(L/2) f(x)exp((a+i*gamma)x)dx. Все оценки ниже допустимы для комплексных коэффициентов z.

### 4.1. Два края нельзя выбросить

Из фундаментальной теоремы и Cauchy–Schwarz:

    ||f||_infinity²<=||f||²/L+2||f|| ||f'_int||<=2E.

Прямая оценка даёт |F_f|<=sqrt(L E)exp(|a|L/2). При gamma!=0 интегрирование по частям даёт оба endpoint-члена и интеграл от f'+a f. При |a|<=1/2 их сумма не превосходит 5sqrt(L E)exp(|a|L/2). Совмещая оценки,

    |F_f(a,gamma)|<=
       6sqrt(L E)exp(|a|L/2)/sqrt(1+gamma²).            (C15)

Для xf внутренняя энергия не больше (9/4)L²E. Поэтому

    |partial_a F_f(a,gamma)|<=
       9Lsqrt(L E)exp(|a|L/2)/sqrt(1+gamma²).           (C16)

Нулевое продолжение косинусов не объявлено глобально H¹. Именно endpoint-члены оплачены числом 5 в (C15).

### 4.2. Полная нулевая форма, не сумма модулей до RH

Смешанная явная формула даёт

    A_m[z]=sum_rho K_f(beta-1/2,gamma),
    K_f(a,gamma)=conjugate(F_f(-a,gamma))*F_f(a,gamma). (C17)

Для a=0 это |F_f(0,gamma)|²>=0; для a!=0 модуль квадрата НЕ подставляется. Полная сумма вещественна. Gamma, оба полюса и все prime powers находятся внутри равенства (C17).

Корректность (C17) для буквального носителя: сглаживаем нулевое продолжение f компактным mollifier. L1, L-infinity и полная вариация сглаженных функций равномерно ограничены, носители лежат в одном компактном окне. Fourier–Laplace-образы имеют равномерный O(1/|gamma|) благодаря BV-интегрированию по частям. По (C14) нулевая сумма сходится абсолютно и допускает предельный переход. На source-side арифметических атомов конечное число; корреляция на граничном сдвиге L стремится к нулю. Сгруппированный Gamma-интеграл у нуля имеет равномерный O(u) множитель против j(u)=O(1/u): используется ||f-T_u f||²<=const*u для BV-функций. Полюсные интегралы сходятся на фиксированной поддержке. Поэтому никаких краевых плат не потеряно.

Из (C15)–(C16), дифференцируя K_f по a и интегрируя от 0 до a:

    |K_f(a,gamma)-K_f(0,gamma)|
      <=108 |a| L² E exp(|a|L)/(1+gamma²).              (C18)

### Теорема 1. Конечная ошибка reference-Gram даёт полный source-floor

Для ВСЕХ m>=3, N>=1, T>=1 и всех z in C^(m+1):

    A_m[z] >= -D(m,N,T) G_m[z],                        (C19)

    D(m,N,T)=10800 L² a_N(T) exp(L*a_N(T))
            +1728 L sqrt(m) log(T+2)/T.               (C20)

Доказательство. В части |gamma|<=T сохраняем положительные K_f(0,gamma), а разность ограничиваем (C18), (C13) и Sigma_0<=100. Для хвоста (C15) даёт |K_f|<=36 L E sqrt(m)/(1+gamma²), поскольку |a|<1/2. Применяем вторую оценку (C14). Сумма двух нижних границ даёт (C19). Ни один настоящий нуль не удалён и ни один не посажен на линию. □

Это количественное условное-on-a-FINITE-number неравенство, а не вывод «RH эквивалентна двум критериям, значит один численный тест контролирует другой». Число e_N определено независимо и остаётся в правой части.

## 5. Оплаченный положительный старт и замороженный порог

[FINITE_CELL / COFINAL_FAMILY | PAPER; положительность Q_m — R4B §4.]

Нужно оплатить не только отрицательную часть A_m, но и положительный выход e_NQ_m. Имеется явная равномерная граница

    0 <= Q_m=A_m(1/2) <=64(1+L)G_m.                   (C21)

Приведём независимую грубую верхнюю оценку. Для 0<u<=1, L>=1:
||f-T_uf||²<=u²||f'_int||²+2u||f||_infinity²<=5uE,
j(u)<=1/u. Для u>=1 берём ||f-T_uf||²<=4||f||² и
int_1^infinity j(u)du<16/9. Поэтому исходная Gamma-форма H[f]<=16E; отрицательная contact-константа отброшена только в верхней границе.

Демпфирование Gamma при delta=1/2 меняет её не больше чем на
2||f||² int_0^infinity j(u)(1-exp(-u/2))du<4||f||².
Точное значение интеграла — (log2)/2+pi/4<2.
Полюсный член после полного демпфирования ограничен 2(L+1)||f||².

Элементарное theta(x)<=4x следует из делимости произведения простых n<p<=2n на binom(2n,n) и dyadic суммирования. Затем
psi(x)=sum_(k<=log_2x)theta(x^(1/k))<=12x:
все k>=2 оплачиваются 4sqrt(x)log_2x<=8x. Частичное суммирование даёт
sum_(n<m)Lambda(n)/n<=12(1+L). Поэтому модуль prime-части Q_m не больше 24(1+L)||f||². Сложение даёт (C21), с запасом. Положительность Q_m не выводится этим взятием модулей: она наследуется из полного scattering/Poisson якоря.

Таким образом для любого конечного префикса:

    A_m[z] >= P_m^(N)[z]
      -[D(m,N,T)+64(1+L)e_N]G_m[z].                   (C22)

### Теорема 2. Замороженная выходная оценка выполнена при достижении порога

Если e_N<=m^(-6), то для всех z:

    A_m[z] >= P_m^(N)[z]
        -40000(1+log m)^2 m^(-3/2)G_m[z].              (C23)

Доказательство. Берём предписанную высоту T=m². Тогда a_N(T)<=m^(-2), La_N(T)<=1 и exp(La_N(T))<3. Первый член D не больше 32400 L²m^(-2); второй не больше 5184 L²m^(-3/2), поскольку log(m²+2)<=3log m. Добавка положительного выхода не больше 64(1+L)m^(-6). Сумма меньше правой константы в (C23). Это доказывает точную степень frozen-спецификации, а не новую, более слабую степень. □

Кванторы существенны: (C23) относится к каждому ДОСТИГНУТОМУ конечному префиксу. Существование такого префикса для всех m не следует из него. Никакого сканирования m, нулей или eigenvalues для доказательства не проводилось.

## 6. Попытка закрыть остановку собственно арифметикой

[FINITE_CELL | PAPER для тождеств; сходимость ниже CONDITIONAL.]

Чтобы не остановиться на слове NB, строим явный интерполянт из обычной Mobius-инверсии. При N>=2 зададим

    M1(N-1)=sum_(n=1)^(N-1) mu(n)/n,
    a_n=-mu(n)  (2<=n<N),
    a_N=N*M1(N-1).                                    (C24)

Тогда sum_(n=2)^N a_n/n=1. Для
R_N^head(k)=1-sum_(n=2)^N a_n r_n(k) точное тождество
sum_(n<=k)mu(n)floor(k/n)=1 даёт

    R_N^head(k)=0,  1<=k<N,                           (C25)

    R_N^head(k)=sum_(n=N)^k mu(n)floor(k/n)
                  +N*M1(N-1)floor(k/N),  k>=N.        (C26)

Уничтожены все первые N-1 строки, а не выбранные отдельные простые. Но ошибка нормы равна ВСЕМУ хвосту

    ||R_N^head||²=sum_(k>=N)|R_N^head(k)|²/[k(k+1)].    (C27)

Её малость не доказана. Уже на N<=k<2N стоит совместная величина
M(k)-M(N-1)+N*M1(N-1). Почленная оплата через |mu|<=1 даёт растущий бюджет, не сходимость. Это не доказательство того, что оптимальный e_N не убывает к нулю: интерполянт (C24) не утверждается оптимальным.

Точное неоплаченное аддитивное утверждение:

    forall eta>0 exists N,c_2,...,c_N:
      sum_(k>=1) |1-sum_(n=2)^N c_n*(k mod n)/n|²
                                      /[k(k+1)] < eta. (C28)

Оно эквивалентно e_N->0. Достаточная, но не утверждаемая необходимой починка конкретного (C24) — исчезновение его хвоста (C27). Нельзя заменить (C28) правильной интерполяцией на всё большем конечном head: цена его компенсирующего tail не контролируется таким head.

### 6.1. Честная классификация неизвестной строки

RH=> (C28) следует из THEOREM T1, а не из новой работы. Покажем точное центрирование, чтобы не перепутать L²(0,1) и L²(0,infinity). При RH существуют конечные комбинации g_j=sum a_n{1/(nx)}, сходящиеся к 1_(0,1) в L²(0,infinity). На x>1 они равны A_j/x, где A_j=sum a_n/n, значит A_j->0. Функция {1/x} имеет конечную L²-норму. Поэтому

    g_j-A_j{1/x}=sum_(n>=2)a_n[Jr_n]

(продолженное нулём на x>1) также сходится к цели. Это даёт (C28). Обратно, (C12) исключает каждый нуль справа от линии при e_N->0, а симметрия завершает RH. Итак,

    (C28) <=> RH.                                     (C29)

Это классификация силы обязательства, НЕ поставщик прямого доказательства. Применять левую стрелку, предположив RH ради сходимости, в доказательстве RH нельзя. Более того, после доказательства capture сама (C12) уже выводит RH без матриц. Возврат (C20) нужен для количественной связи с буквальным A_m и выполнения source-контракта задания; он не обходит классическую трудность capture.

Кроме того, из нижней оценки T1 (1.2) для всех комбинаций с максимальным параметром N следует для нашего подкласса e_N>=c0/log N с некоторой c0>0, при больших N. Следовательно выбранный порог требует

    e_N<=m^(-6)  =>  log N>=c0 m^6.                   (C30)

Это НЕ быстрый вычислительный маршрут. Константа c0 здесь не оценивалась, а экспоненциальная цена не является запретом на аналитическое доказательство (C28). Оптимизация порога будущего метода могла бы изменить стоимость; замороженный порог в этой работе не меняется.

## 8. Где цепочка отличает источники, и где не отличает

[ABSTRACT / COFINAL_FAMILY | PAPER с явно указанными source hypotheses.]

Все универсальные PSD-карты по определению работают на любых PSD-данных. Было бы противоречием требовать, чтобы конгруэнция сама перестала сохранять PSD в ложном мире. Различающий link здесь — точное соединение остаточного Gram с ЗАДАННЫМ арифметическим источником, формула (C4), затем оценка (C12). Положительность Gram без source-match не является детектором RH.

### 8.1. DMV: отказ обычного аддитивного link и препятствие его source-correct замене

T3 предоставляет DMV-систему с правыми нулями. Для явно видимого нецелого атома можно взять её конечное Euler-расширение простым q=3/2:

    Z_B(s)=zeta_B(s)/(1-(3/2)^(-s)).

Это снова Beurling-система; в Re s>0 дополнительный множитель голоморфен и ненулевой, поэтому выбранные правые нули сохраняются. Если N_B(x)=kappa x+O(x^theta), то суммирование N_B(x/q^j) даёт тот же тип асимптотики с другим residue и тем же theta. Никакой функциональной симметрии не добавлено.

Её counting measure имеет положительный атом в 3/2, которого нет у d floor(x). Следовательно source identity (C3)–(C4), построенная из соседних обычных целых, не является Mellin identity этого источника. Она всё ещё вычисляет ζ, а не Z_B. Замена Z_B на ζ в выходной оценке была бы подменой задачи. Уже это именует точный отсутствующий link.

Есть более сильный контроль. Для ЛЮБОГО возможного source-correct L²(0,1)-словаря d_n, Mellin-образы которого зануляются в одном правом нуле rho_B, approximation of target 1 имела бы

    ||1-sum c_n d_n||² >= (2Re rho_B-1)/|rho_B|² >0.     (C31)

Доказательство буквально Cauchy–Schwarz из (C12). Поэтому source-correct ремонт не может одновременно иметь capture и этот Mellin-null link. Это не предположение существования такого ремонта; это запрет на прохождение всей цепочки. DMV-completion или dense radical не использованы.

### 8.2. Подсаженный квартет

Пусть a=1/3, gamma=7,
Q(w)=((w-a)^2+gamma²)((w+a)^2+gamma²), и
xi_plant(s)=Q(s-1/2)xi(s)/Q(1/2).
Собственный uncompleted фактор есть Z_plant(s)=Q(s-1/2)zeta(s)/Q(1/2). Его полная форма включает квартетное ядро; оно НЕ удаляется.

Обычные r_n по-прежнему имеют Mellin-transform (C4) с ζ. Уже при n=2,s=2 требуемая подстановка Z_plant вместо ζ неверна: Q(3/2)>Q(1/2), поскольку Q(w)=w^4+2(gamma²-a²)w²+(gamma²+a²)^2 строго растёт для w>0. Поэтому source-match link ломается точно, не по численной близости.

Для любого корректного заменяющего словаря, аннулирующего planted rho=5/6+7i, (C31) даёт положительный остаток, так что threshold m^(-6) не достигается при больших m. Сам старый integer-Gram после planting не меняется — это прямо признаётся, а не выдаётся за отрицательный контроль его PSD.

### 8.3. Davenport–Heilbronn

Если требовать (C4) с собственным D(s) вместо ζ(s), уже n=2 в открытой полуплоскости заставляет D(s)=ζ(s), что противоречит собственным Dirichlet-коэффициентам DH. Нельзя заменить все b_D(n), включая n=6, обычной Lambda. Это точный отказ Mellin source-match. Известный правый DH-нуль аналогично даёт (C31) для любого source-correct L²-ремонта; при невозможности L²-реализации ремонт останавливается ещё раньше. Положительность нашего Q_m не приписывается DH.

### 8.4. Кривая E/F3: собственный аддитивный forward-square

Пусть h=log3, ell=2h и gamma_n=(n+1/2)pi/h. Для собственного источника J_E(z)=2cos(hz) define

    (Per f)(x)=sum_(k in Z)(-1)^k f(x+k*ell), 0<=x<ell.

Для компактного f сумма конечна при каждом x. Fourier-базис exp(i gamma_n x) на ячейке ортогонален, и Parseval даёт

    W_E[f]=sum_n |fhat(gamma_n)|²
           =ell int_0^ell |Per f(x)|²dx.              (C32)

Поэтому identity на L²(0,ell) -> V_m*I V_m с V_m z=sqrt(ell) Per(S_m z) даёт A_m^E точно, с нулевым дефектом. Это автономная конгруэнция из собственной аддитивной решётки кривой; никакой zero-location hypothesis не нужна — Fourier-частоты заданы explicit cos. Она работает и для буквальных cosine-функций через L²-Parseval.

Это положительный контроль разрешённого map-class и source-return. Мы НЕ утверждаем, что обычный zeta-residue словарь (C1) после переименования вычисляет источник кривой. Его навязывание кривой было бы столь же неверно, как навязывание DMV. Собственный forward chain кривой завершается, а source-correct цепочки ложных миров не могут завершиться с требуемым дефектом.

## 9. Границы старых запретов и сильнейшая атака на результат

[ABSTRACT | PAPER для различий; CONDITIONAL для нового capture.]

**Положительный envelope 3d3ba2e6.** Здесь нет положительного оператора, мажорирующего -K_m на всей частотной прямой. Reference-Gram живёт на остатках целых. Выход сравнивается с A_m только через количественную теорему (C22), не через отдельную оплату отрицательных частотных масок.

**Ток e7be7f41.** Не требуется положительная мера плюс bounded derivatives неперенормированной alpha_m. Mellin-evaluation на L²(0,1) и точная integer-cell изометрия — другой класс. Условия конечного дифференциального порядка на alpha_m нет.

**Скалярный Euler–Mobius квадрат 8e584bb8.** Ни t Z*Y Z, ни t^(-1)M Y M* не являются нашими положительными каналами. Появление mu в отдельном интерполянте (C24) не отождествляет его L² target-error со старым scalar-balanced квадратом. Эта граница согласуется с RN.

**DMV SD.** Общий multiplicative PSD-механизм не экспортируется как источник DMV. Источник-специфичный link (C4) и обязательный capture отдельно проверяются в §8. Свободная делимость сама по себе не поставляет (C28).

**Статическая склейка d558268a.** Интервалы (1/(k+1),1/k] — ячейки для reference L², не endpoint-domain исходного i*d/dx и не его предполагаемый спектр. Кривая использует собственную периодизацию; на ζ она не переносится.

**Сентябрьские NULLFIELD/RESOLVENTGRAM/POINCARECOMP/RAW_RESPONSE_FLOOR/FINITE_PATH/SUPPORTSTABILITY.** Не утверждается доминирование полного источника фиксированным ненулевым положительным reservoir с нулевым запасом. Не строится положительная ёмкость простых как замена подписанного source. P_m^(N)=e_NQ_m сжимается; сравнение включает явно доказанный дефект. Никакая абсолютная мажоранта резольвенты не используется.

**Запрещённые whole-chain flows.** Нет backwards delta-flow, heat semigroup, unrestricted path или delta-curvature factor. От R4B взят лишь один доказанный положительный объект. Его наличие не является выводом об A_m(0).

**Сильнейшее возражение.** Можно получить сколь угодно много положительных префиксов и не приблизить цель. Более того, наш P_m^(N) уменьшается, а не воспроизводит всё больше A_m. Это возражение верно: только доказательство (C28) и независимый мост (C22) дают RH. Мы построили мост, но не доказали capture. Следовательно заявлять готовый autonomous RH-proof было бы ложью. Также source-match не должен быть спрятан в словах «та же решётка»: ordinary dictionary проходит PSD и после planting, но тогда перестаёт быть словарём ПОЛНОГО planted source.

1. **Полный residue-Gram / Schur:** доказать b*Gamma_N^(-1)b ->1. Аналитическая цена высокая; строгий положительный lower-limit для конкретного tail убьёт только этот coefficient ansatz, не оптимальный e_N.

Ни одна репрезентация не разрешает заменить знаковую отмену суммой модулей и назвать полученный растущий bound константой. Никаких новых обязательных supplier-имён сверх классического target capture не добавлено.
