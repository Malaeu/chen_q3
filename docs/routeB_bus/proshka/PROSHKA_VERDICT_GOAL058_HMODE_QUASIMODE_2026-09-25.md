## 1. Плотность полиномов и endpoint clipping: переход верен

**[ABSTRACT | PAPER]** Рабочая область
V = { u ∈ L²_even(−1,1) : u ∈ H¹_loc(−1,1), √(1−t²) u' ∈ L²(−1,1) },
‖u‖²_V = ‖u‖²_2 + ∫(1−t²)|u'|².
Норма формы учитывает функцию и взвешенную производную; глобальной невзвешенной H¹-регулярности не требует.
Полнота — из локального H¹-контроля (на внутренних компактах вес отделён от нуля); чётность сохраняется.

Для 0<a<1 оставляем u на [−a,a], на хвостах продолжаем **константами** u(±a). Взвешенный Коши—Буняковский:
|u(a)|² ≤ 2|u(0)|² + (∫(1−t²)|u'|²) · log((1+a)/(1−a)), значит (1−a)|u(a)|² → 0, и
‖u_a−u‖²_2 ≤ 2∫_{|t|>a}|u|² + 4(1−a)|u(a)|² → 0,  ∫(1−t²)|u_a'−u'|² = ∫_{|t|>a}(1−t²)|u'|² → 0.
На стыках значения совпадают: скачка функции и дельта-производной нет.

Каждое u_a ∈ H¹(−1,1); приближаем нечётную производную нечётными полиномами r_j в L², P_j(t)=u_a(0)+∫_0^t r_j.
**Чётные полиномы образуют form core.** Для φ_q=√((4q+1)/2) P_{2q}, ν_q=2q(2q+1):
‖u‖²_V = Σ_q (1+ν_q)|c_q|²   (1), откуда вложение V ↪ L²_even компактно.
Добавление Gt² при фиксированном G>0 сохраняет область; равномерность по G→∞ не утверждается и не используется.

**Отрицательный контроль.** Линейное обнуление u=1 на полосках ширины ε даёт энергию ошибки 2−(2/3)ε → 2, а не 0. Пакет использует правильное **постоянное продолжение**.
