## ROUTE MAP

### 1. Общий вердикт по идее Gemini

Идея имеет реальную ценность. Она не создаёт новую математику из одних названий
агентов. Она превращает уже существующую Q3-систему в более строгий компилятор:


Главный выигрыш ожидается не в количестве идей, а в двух величинах:

То есть система должна раньше находить уже доказанные suppliers и раньше убивать
wrong-object мосты. Консенсус агентов, красивое совпадение формул и успешный toy
model доказательством не являются.

## BRIDGE TYPING

### 3. Канонический `BRIDGE_KIND_V1`

```text
EXACT_ISOMORPHISM
UNITARY_INTERTWINER
FORM_IDENTITY
ONE_WAY_TRANSFER
ASYMPTOTIC_EQUIVALENCE
STRUCTURAL_ANALOGY
HEURISTIC_ANALOGY
```

Определения:

- `EXACT_ISOMORPHISM`: записаны прямая и обратная карты, обе композиции равны
  identity на объявленных carriers, перечислена сохраняемая структура.
- `UNITARY_INTERTWINER`: записан unitary map `U`, его domain/codomain и точное
  переплетение `UT = SU` либо соответствующая form identity.
- `FORM_IDENTITY`: равны конкретные формы или функционалы на одном именованном
  domain после точного crosswalk. Равенство координат не требуется.
- `ONE_WAY_TRANSFER`: доказана только одна импликация или односторонняя оценка.
- `ASYMPTOTIC_EQUIVALENCE`: указаны topology, normalization, cofinal schedule и
  rate/error ledger.
- `STRUCTURAL_ANALOGY`: source-backed совпадение mechanism signature без theorem.
- `HEURISTIC_ANALOGY`: поисковая гипотеза без source-locked transfer.

Автоматические понижения:

```text
EXACT_ISOMORPHISM без inverse maps
  → STRUCTURAL_ANALOGY.

UNITARY_INTERTWINER без unitary identities или exact carrier
  → ONE_WAY_TRANSFER либо STRUCTURAL_ANALOGY.

FORM_IDENTITY без domain/normalization
  → QUARANTINED_ANALOGY.

ASYMPTOTIC_EQUIVALENCE без topology или one cofinal schedule
  → CONDITIONAL / not composable.
```

Любой bridge обязан отдельно нести:

```yaml
SOURCE_OBJECT:
TARGET_OBJECT:
SOURCE_MAP:
INVERSE_OR_ADJOINT:
PRESERVES:
DROPS:
SCOPE:
VERIFIER:
```

Это является прямым operationalization карточки C04: одинаковые координаты не
означают одинаковый закон.

## INSIGHT STATE MACHINE

### 6. Исправленная машина состояний

§6.2 плана Mythos слишком быстро переходил от falsifier к kernel. Правильная
машина обязана разделять исходник, зелёное ядро и semantic admission:

```text
RAW_INSIGHT
  → GAP_LOCKED
  → SOURCE_LOCKED
  → CROSSWALK_TYPED
  → FALSIFIER_PASSED
  → THEOREM_PACKET_READY
  → SOURCE_WRITTEN
  → KERNEL_GREEN
  → SEMANTICALLY_ADMITTED
  → SHELF_REGISTERED
```

Боковые terminal/holding states:

```text
KILLED_WITH_AUTOPSY
QUARANTINED_ANALOGY
BLOCKED_SOURCE_MISSING
ZERO_CONSISTENT_NEEDS_DISCRIMINATOR
```

Минимальные переходные evidence:

| Переход | Требуемое evidence |
|---|---|
| `RAW_INSIGHT → GAP_LOCKED` | exact consumer + minimal missing identity |
| `GAP_LOCKED → SOURCE_LOCKED` | source/theorem pin или exact repo object |
| `SOURCE_LOCKED → CROSSWALK_TYPED` | bridge kind + preserves/drops + units |
| `CROSSWALK_TYPED → FALSIFIER_PASSED` | registered plant реально падает |
| `FALSIFIER_PASSED → THEOREM_PACKET_READY` | one theorem, one consumer, one gate |
| `THEOREM_PACKET_READY → SOURCE_WRITTEN` | source record, receipts, CLOSES/OPENS |
| `SOURCE_WRITTEN → KERNEL_GREEN` | exact commands + clean axiom/taint profile |
| `KERNEL_GREEN → SEMANTICALLY_ADMITTED` | source object, consumer and quantifiers audited |
| `SEMANTICALLY_ADMITTED → SHELF_REGISTERED` | capability catalog entry and provenance |

Критический firewall:

```text
KERNEL_GREEN != SEMANTICALLY_ADMITTED.
```

Этот firewall уже обязателен в действующем control-plane и не создаёт новую
политику.

## PROOF ASSEMBLER

### 7. Proof-space является AND-hypergraph

Переход

```text
A ∧ B ∧ C → D
```

хранится одной hyperedge с тремя обязательными входами. Его нельзя раскладывать
на `A→D`, `B→D`, `C→D`.

Assembler действует так:

```text
exact consumer
→ ask.sh / capability lookup
→ максимум три кандидата
→ hard eligibility gates
→ cheapest falsifier
→ ровно один theorem packet.
```

Hypergraph на первой стадии является типизированным представлением, а не
автономным ranker живого RH-фронта.
