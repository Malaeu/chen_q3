## 3. Полное тождество Стейна и независимая парная мера

### 3.1. Полиномы произвольной степени, с комплексными смешанными членами

**[ABSTRACT][PAPER; вывод из S2/S3]** Для любого \(q\in\mathbb C[u]\):

\[
 \boxed{\mathbb E_\nu[b(U)Uq(U)]
       =\mathbb E_\nu[q(U)+2Uq'(U)].}
\tag{6}
\]

**Доказательство.** Из (3) следует \(p_X'(x)=-xb(x^2)p_X(x)\). Интегрируем производную \(xq(x^2)p_X(x)\) по всей вещественной прямой. Оба граничных значения равны нулю по полному исходному убыванию. Производная абсолютно интегрируема по принятым взвешенным оценкам. Получаем (6). Действительная и мнимая части обрабатываются отдельно. □

В частности, для любых комплексных полиномов \(P,Q\)

\[
 \mathbb E[(b(U)U-1)\overline{P(U)}Q(U)]
 =2\mathbb E\!\left[U\{
     \overline{P'(U)}Q(U)+\overline{P(U)}Q'(U)\}\right].
\tag{7}
\]

При \(P=Q\) правая часть равна \(4\operatorname{Re}\mathbb E[U\overline P P']\), а не квадрату нормы. **Этот смешанный член не зануляется и не получает знак по названию «Stein».**

### 3.2. Двухпеременная мера

Пусть в дальнейшем \(U,V\) независимы с законом \(\nu\). Здесь случайная величина V — независимая копия U, не исходное интегральное ядро \(V_f\). Определим

\[
 \boxed{d\Lambda_b(u,v)=
 \frac14uv\,[b(u)-b(v)](u-v)\,d\nu(u)d\nu(v).}
\tag{8}
\]

**[ABSTRACT][PAPER]** Это независимая положительная исходная мера. По \(b'\ge1/2\)

\[
 d\Lambda_b(u,v)\ge\frac18uv(u-v)^2d\nu(u)d\nu(v).
\tag{9}
\]

Она строго положительна относительно \(\nu\otimes\nu\) вне диагонали при \(u,v>0\). Конечность всех её полиномиальных моментов следует из

\[
 uv|b(u)-b(v)||u-v|
 \le uv(b(u)+b(v))(u+v)
\]

и (4): в каждом возникающем члене степень при \(b(U)\) не меньше единицы. Квадрат \(b^2\) не нужен.

Для любого двухпеременного полинома \(R\) два применения (6) дают

\[
\boxed{\begin{aligned}
 \int R\,d\Lambda_b
 =\frac14\mathbb E\big[& (6UV-U^2-V^2)R(U,V)\\
 &+2UV(U-V)(\partial_u-\partial_v)R(U,V)\big].
\end{aligned}}
\tag{10}
\]

**Проверка знаков.** К \(b(U)\)-части применяется (6) с \(q(U)=V(U-V)R(U,V)\), а к \(b(V)\)-части — с \(q(V)=U(U-V)R(U,V)\). Их разность имеет скалярный множитель \(6UV-U^2-V^2\) и показанную производную. Fubini законен по той же полиномиальной мажоранте. Формула применима к \(R=\overline P Q\) и сохраняет обе производные произведения.

В частности, масса меры равна

\[
 \boxed{M_b:=\Lambda_b((0,\infty)^2)
       =\frac{3\mu_1^2-\mu_2}{2}=6a_1>0.}
\tag{11}
\]

Положительность (8) не зависит от неизвестного (H); она следует из принятого полного исходного \(b'\). Это и есть независимый положительный объект выбранного опыта. **Его соответствие нужной форме ещё должно быть доказано.**

## 4. Точное соответствие коэффициентному Ханкелю

### 4.1. Целая sinc-серия без выбора квадратного корня

Определим

\[
 s_w(u):=\sum_{k\ge0}\frac{(-1)^k(uw)^k}{(2k+1)!}.
\tag{12}
\]

Это целая функция \(w\). Запись \(\sin\sqrt{uw}/\sqrt{uw}\) допустима как сокращение (12), а не как выбор ветви. Ряд синуса сверён с DLMF 4.19.1; новых теорем о его нулях не используется [E1].

Из (6), сначала на коэффициентах, получается

\[
 \boxed{e(w)=\mathbb E[b(U)U s_w(U)],
 \qquad -2e'(w)=\mathbb E[U s_w(U)].}
\tag{13}
\]

Обе формулы действуют для всех комплексных \(w\). Полный аналитический бюджет следующий. На \(|w|\le R\)

\[
 |s_w(u)|\le e^{\sqrt R\sqrt u},
 \qquad |\partial_ws_w(u)|\le\frac u6e^{\sqrt R\sqrt u}.
\tag{14}
\]

Первая оценка следует из абсолютного ряда; для второй используется
\(k/(2k+1)!\le1/[6(2k-2)!]\), \(k\ge1\). Остальные фиксированные производные также ограничиваются полиномом от \(u\), умноженным на экспоненту такого вида.

В терминах исходника

\[
 b(u)u\,d\nu(u)=-Z^{-1}\Phi'(\sqrt u)\,du.
\tag{15}
\]

Следовательно, все интегралы \(u^Nb(u)u e^{R\sqrt u}\,d\nu(u)\) конечны по полным взвешенным оценкам для \(\Phi'\). Это оплачивает почленное интегрирование, фиксированные производные и продолжение (13), без отсечения theta-мод или полуоси. При \(u=0\) дополнительного граничного условия не возникает: исходное IBP выполнялось на всей прямой.

### 4.2. Полная ковариационная формула

Для разных \(u,v>0\) положим

\[
 \mathscr C_{u,v}(z,w)=
 \frac{s_z(u)s_w(v)-s_w(u)s_z(v)}{(z-w)(v-u)}.
\tag{16}
\]

Обе кажущиеся особенности устранимы. В частности, ниже выписаны все коэффициенты продолжения при \(u=v\). На диске, где \(e\ne0\), симметризация двух независимых интегралов в (13) даёт

\[
 \boxed{
 e(z)e(w)\frac{g(z)-g(w)}{z-w}
   =\int\mathscr C_{u,v}(z,w)\,d\Lambda_b(u,v).
 }
\tag{17}
\]

**Доказательство множителя 1/4.** Обозначим \(A(w)=\mathbb E[Us_w(U)]\), так что \(g=A/(2e)\). Числитель \(A(z)e(w)-A(w)e(z)\) равен

\[
 \tfrac12\mathbb E\!\left[UV(b(V)-b(U))
 \{s_z(U)s_w(V)-s_w(U)s_z(V)\}\right].
\]

Деление ещё на \(2(z-w)\) даёт (17) с мерой (8).

Для законности (17) не требуется отдельная мажоранта для \(1/(u-v)\). Этот множитель точно сокращается с (8). Делённую разность по \(z,w\) оцениваем интегралом первой производной вдоль отрезка. По (14) получается мажоранта вида

\[
 C_R UV(b(U)+b(V))(U+V)
          e^{\sqrt R(\sqrt U+\sqrt V)},
\]

интегрируемая по (15). Для коэффициентов фиксированного порядка добавляются только полиномиальные множители. Поэтому Fubini, извлечение коэффициентов и продолжение на \(z=w\) законны. Выбор \(n\) никогда не заменяется общим конечным cutoff.

Левая часть (17) после умножения на \(e(z)e(w)\) имеет целое продолжение
\([e'(w)e(z)-e'(z)e(w)]/(z-w)\). Мы не делим на \(e\) в его нулях. Для конечного коэффициентного вывода достаточно окрестности нуля.

### 4.3. Все коэффициенты внутренней матрицы

Для \(i,j\ge0\) определим однородный полином

\[
\boxed{
 C_{ij}(u,v)=(-1)^{i+j}
 \sum_{k=0}^{\min(i,j)}
 \frac{(uv)^k}{(2k+1)![2(i+j+1-k)+1]!}

}
\tag{18}
\]

Это коэффициент \(z^iw^j\) в (16). **Доказательство для произвольных индексов:** умножаем ряд (12) в двух переменных, делим антисимметричный числитель сначала на \(z-w\). Для \(i\ge j\) коэффициент равен сумме по \(0\le k\le j\) из

\[
 \frac{(-1)^{i+j+1}
 (u^{i+j+1-k}v^k-u^kv^{i+j+1-k})}
 {(2k+1)![2(i+j+1-k)+1]!(v-u)}.
\]

Используем конечное тождество
\((u^m-v^m)/(u-v)=\sum_{r=0}^{m-1}u^rv^{m-1-r}\).
Это даёт (18); симметрия покрывает \(j>i\). Формула полиномиальна также на диагонали \(u=v\) и осях. □

Здесь Cₙ обозначает только коэффициентную матрицу (не кривизну из предыдущих запросов). Пусть \(C_n(u,v)=[C_{ij}(u,v)]_{i,j=0}^n\),

\[
 B_n=\int C_n(u,v)\,d\Lambda_b(u,v),
 \qquad (T_n)_{ij}=\begin{cases}e_{i-j},&j\le i,\\0,&j>i.\end{cases}
\tag{19}
\]

Из (17) и разложения \((g(z)-g(w))/(z-w)=\sum a_{i+j+1}z^iw^j\) следует

\[
 \boxed{B_n=T_nH_nT_n^{\mathsf T},\qquad \det T_n=1.}
\tag{20}
\]

Это **конечная конгруэнция**, то есть замена координат эрмитовой формы; она сохраняет её знак. Матрица \(T_n\) вещественная, обратимая, зависит только от уже определённых \(e_j\). Для произвольного \(c\in\mathbb C^{n+1}\) положим \(d=T_n^{-\mathsf T}c\). Тогда точно

\[
 \boxed{c^*H_nc=d^*B_nd
    =\int d^*C_n(u,v)d\,d\Lambda_b(u,v).}
\tag{21}
\]

**Все комплексные смешанные члены сохранены.** Ограниченная обратимость бесконечной матрицы T не утверждается и не нужна. (20) доказано отдельно для каждого произвольного конечного \(n\), а не извлечено из конечной вычислительной серии.

## 5. Что действительно положительно при каждом порядке

**[COFINAL_FAMILY][PAPER; новый ограниченный вывод]** Для всех \(i,j\ge0\)

\[
 (-1)^{i+j}(B_n)_{ij}>0\quad\text{при }n\ge\max(i,j).
\tag{22}
\]

Это следует из (18): после удаления \((-1)^{i+j}\) каждое слагаемое положительно при \(u,v>0\), а \(\Lambda_b\) — ненулевая положительная мера. **Положительность элементов после знаковой конгруэнции не означает PSD.**

Более содержательно, для

\[
 v^{(n)}=(e_n,e_{n-1},\ldots,e_0)^{\mathsf T}
\]

имеем явный бюджет

\[
\boxed{
 (v^{(n)})^*H_nv^{(n)}=(B_n)_{nn}
 \ge
 \frac{\mu_{n+1}\mu_{n+3}-\mu_{n+2}^2}
 {4(2n+1)!(2n+3)!}>0,
 \qquad n\ge0.
}
\tag{23}
\]

**Доказательство.** В (18) при \(i=j=n\) сохраняем только положительное слагаемое \(k=n\):

\[
 C_{nn}(u,v)\ge\frac{(uv)^n}{(2n+1)!(2n+3)!}.
\]

Подставляем (9) и раскрываем \((u-v)^2\). Возникает ровно правая часть (23). Строгость следует из строгой дисперсии U под смещённой положительной мерой \(u^{n+1}d\nu\): источник имеет положительную плотность на всей полуоси и не сосредоточен в точке. □

При \(n=0\) это ровно принятый бюджет S2 для \(a_1\); его повтор не объявляется новым результатом. При произвольном \(n\) (23) представляет полностью доказанную **одномерную** форму. Для всех скаляров \(z\in\mathbb C\) её значение на \(zv^{(n)}\) умножается на \(|z|^2\). Никакое другое направление автоматически не оплачено.

Например,

\[
 (B_1)_{11}=rac{35\mu_2^2-14\mu_1\mu_3-\mu_4}{10080}
 \ge\frac{\mu_2\mu_4-\mu_3^2}{2880}>0.
\tag{24}
\]

Но \((B_1)_{00}>0\), \((B_1)_{11}>0\) и известный знак смешанного элемента ещё не дают знак определителя. **Именно этот пробел проверяется дальше, вместо повышения (23) до (H).**

### 6.1. Самый первый внутренний блок

**[FINITE_CELL][PAPER; точная алгебра, не theta-выборка]** Из (18)

\[
 C_1(u,v)=
 \begin{pmatrix}
  1/6&-(u+v)/120\\
  -(u+v)/120&(u^2+8uv+v^2)/5040

\tag{25}
\]

\[
 \boxed{\det C_1(u,v)
       =\frac{16uv-11(u-v)^2}{302400}.}
\tag{26}
\]

При \((u,v)=(1,4)\)

Таким образом, гипотеза «все внутренние коэффициентные матрицы Cₙ положительны» ложна уже при \(n=1\). Это не прежняя PT2-матрица \(J_u(x_i,x_j)\), не HCM, не half-thinning и не свёрточный оператор: это непосредственно матрица нового Stein-представления (21).

### 6.2. Отрицательный вклад существует на положительной мере именно источника

Единичная точка имела бы нулевую меру. Поэтому сохраняем тот же вектор на полном прямоугольнике

\[
 I=[1,101/100],\qquad J=[4,401/100],\qquad\mathcal R=I\times J.
\]

Из (25)

\[
 d^*C_1(u,v)d
 =\frac{105-42(u+v)+2(u^2+8uv+v^2)}{10080}.
\]

Для всего \(\mathcal R\) рациональная верхняя оценка равна

\[
 \boxed{d^*C_1(u,v)d
 \le-\frac{2999}{5040000}<-\frac1{2000}.}
\tag{28}
\]

Здесь в отрицательном линейном члене взято \(u+v\ge5\), а в положительном квадратном — \(u\le101/100\), \(v\le401/100\). Это верхняя огибающая, а не неудачная нижняя оценка.

По (9) на этом прямоугольнике

\[
 d\Lambda_b\ge\frac{89401}{20000}\,d\nu(u)d\nu(v).
\]

Так как обе исходные массы \(\nu(I),\nu(J)\) строго положительны,

\[
\boxed{
 \int_{\mathcal R}d^*C_1(u,v)d\,d\Lambda_b
 \le-\frac{89401}{40000000}\nu(I)\nu(J)<0.
}
\tag{29}
\]

Массы определены полным источником (2), без численного приближения. Их ненулевость доказана положительностью \(\Phi\). Для отбраковки поточечного механизма не требуется оценивать их десятичные значения.

**Точная область отрицательного результата:** (29) — отрицательный локализованный вклад внутри исходной парной формулы, не значение полного \(H_1\). Другая часть никуда не исчезает:

\[
 d^*B_1d=
 \int_{\mathcal R}d^*C_1d\,d\Lambda_b+
 \int_{\mathcal R^c}d^*C_1d\,d\Lambda_b.
\tag{30}
\]

Второе слагаемое может компенсировать первое. В H-координатах этот фиксированный d соответствовал бы \(T_1^{\mathsf T}d=(1/4-\mu_1/2,1)^{\mathsf T}\), но знак его **полной** формы не вычислен. Ни отрицательного H₁, ни физического K-свидетеля здесь нет.

## 7. Первый точный неоплаченный исходный вход

### 7.1. Полная матрица H₁ и проверка числителя запроса

Положим \(S=U+V\), \(P=UV\), \(D=U-V\). Нормируем уже доказанную меру:

\[
 d\widehat\Lambda_b=M_b^{-1}d\Lambda_b,
 \qquad \mathbb E_b,\operatorname{Var}_b
 \text{ — её ожидание и дисперсия}.
\tag{31}
\]

Из (25) следует

\[
 B_1=M_b
 \begin{pmatrix}
 1/6&-\mathbb E_b S/120\\
 -\mathbb E_b S/120&\mathbb E_b(S^2+6P)/5040
 \end{pmatrix}.
\tag{32}
\]

При устранении score посредством (10) получаем

\[
 B_1=
 \begin{pmatrix}
 (3\mu_1^2-\mu_2)/12&(\mu_3-5\mu_1\mu_2)/240\\
 (\mu_3-5\mu_1\mu_2)/240&(35\mu_2^2-14\mu_1\mu_3-\mu_4)/10080
 \end{pmatrix}.
\tag{33}
\]

В частности,

\[
 \boxed{\det B_1=\det H_1
      =\frac{10P_4P_8-21P_6^2}{1209600}.}
\tag{34}
\]

\(P_4,P_6,P_8\) — буквально полиномы из управляющего запроса. Конечная конгруэнция имеет определитель один; новая нормировка не изменила этот числитель. (33)–(34) дополнительно проверены точной символической арифметикой; проверка не подставляет значения theta-моментов.

### 7.2. Компенсация дисперсии вместо ложной поточечной суммы квадратов

Внутренняя матрица имеет точное разложение

\[
\boxed{
 C_1(u,v)=\frac16
 \binom{1}{-S/20}\begin{pmatrix}1&-S/20\end{pmatrix}
 +\frac{16P-11D^2}{50400}
 \begin{pmatrix}0&0\\0&1\end{pmatrix}.
}
\tag{35}
\]

Первый член — положительная матрица ранга один. Второй имеет переменный знак. При интегрировании и оптимизации первого коэффициента возникает дополнительная **дисперсия S**, и она не может быть отброшена.

Для любого \(d_0,d_1\in\mathbb C\) полный результат:

\[
\boxed{\begin{aligned}
 d^*B_1d={}&\frac{M_b}{6}
   \left|d_0-\frac{\mathbb E_bS}{20}d_1\right|^2\\
 &+\frac{M_b}{50400}\,\Psi_b\,|d_1|^2,\\
 \Psi_b:={}&21\operatorname{Var}_b(U+V)
       +16\mathbb E_b(UV)-11\mathbb E_b[(U-V)^2].
\end{aligned}}
\tag{36}
\]

Следовательно,

\[
 \boxed{\det H_1=\frac{M_b^2}{302400}\Psi_b.}
\tag{37}
\]

**[ABSTRACT][CONDITIONAL; первый неоплаченный вход]** Для продолжения выбранного механизма требуется исходное сравнение

\[
\boxed{
21\operatorname{Var}_{\widehat\Lambda_b}(U+V)
 +16\mathbb E_{\widehat\Lambda_b}(UV)
 \ \ge\ 11\mathbb E_{\widehat\Lambda_b}[(U-V)^2].
}
\tag{GAP-H1}
\]

Это конкретная конкуренция трёх конечных неотрицательных исходных величин. **Её знак здесь не доказан.** Доказательство \(b'\ge1/2\) даёт положительность меры, но не разрешает заменить внутреннюю знакопеременную матрицу нижней оценкой веса. (28) показывает, почему такой шаг недопустим: увеличение положительного веса усиливает и отрицательные направления.

Эквивалентная форма — \(10\operatorname{Var}_b(S)+60\mathbb E_b(P)\ge11(\mathbb E_bS)^2\). Она не добавляет новую теорему; в (GAP-H1) сохранён явный отрицательный канал \((U-V)^2\).

**Не доказано, что скалярные условия (M) логически не могут повлечь (GAP-H1).** Доказано более узкое: попытка получить его через поточечный PSD внутреннего sinc-ядра ложна. Возможное глобальное сравнение, использующее дополнительные связи между полными theta-моментами, остаётся открытым.

### 7.3. Где требуется theta-структура сверх скалярной кривизны

Весь независимый знак до (23) использует положительность \(\Phi\), полное убывание, Stein и \(b'\ge1/2\). На решающем шаге нужен контроль **совместного распределения** под \(\widehat\Lambda_b\), а не только знак его плотности. Именно здесь могли бы понадобиться полный theta-ряд, взаимность или TN-структура исходного r.

В этой попытке не выведена теорема, которая переносила бы принятую TN∞ таблицы \(r(a_i-b_j)\) на сравнение (GAP-H1). Между ними стоят нелинейная логарифмическая замена, переход к \(U=X^2\), score и факториальная коэффициентная карта (18). Соответствие порядка и знака на этих переходах не дано. **Это отсутствие доказанного переноса, а не невозможность любого TN-переноса.** Обе ранее опровергнутые свёрточные конструкции из S5 не повторяются.

### 7.4. Весь неоплаченный all-order остаток

Для произвольного n и каждого \(d\in\mathbb C^{n+1}\) всё ещё нужно

\[
 \int d^*C_n(u,v)d\,d\Lambda_b(u,v)\ge0.
\tag{38}
\]

(38) без нового исходного сравнения — **NO_PROGRESS_TAUTOLOGY**, точная другая запись (H) через (20). Она приведена только для фиксации остатка. (GAP-H1) необходимо и достаточно для первого непогашенного 2×2 коэффициентного блока; даже его отдельное доказательство не покрыло бы (38) при всех n.

Если когда-либо будет доказано \(\Psi_b<0\), (36) выдаст явный коэффициентный вектор, а (20) переведёт его обратно в H₁. Сейчас такой знак не установлен. Коэффициентный свидетель даже тогда не был бы буквально физической парой узлов K; требуется соответствующий аналитический перенос S1.

## Приложение E. Проверка авторитетных байтов

Этот checker проверяет байты и рамки, но **не проверяет содержательное чтение или доказательство**. Оба вида проверки в вердикте разведены.

Исходник `verify_packet.py`: 2223 байт, SHA-256 `35b65afa2451773445b999d5ccb9a903efad2f9c960891e97da0a55fed8a3603`.

```python
#!/usr/bin/env python3
"""Verify the attached byte-exact packet and its seven declared frames."""
import argparse
import hashlib
import json
import re
from pathlib import Path

def blob(data):
    return hashlib.sha1(b'blob ' + str(len(data)).encode() + b'\0' + data).hexdigest()

def main():
    parser = argparse.ArgumentParser()
    parser.add_argument('request', type=Path)
    args = parser.parse_args()
    data = args.request.read_bytes()
    data.decode('utf-8', errors='strict')
    assert len(data) == 85386
    assert data.count(b'\n') == 1772
    assert data.endswith(b'\n') and b'\r' not in data
    sha = hashlib.sha256(data).hexdigest()
    assert sha == 'e3ad1057d9c2bb3a8a8541942d8c224cc9ee9cefcfe1f0c001f01cc31c50a3d7'
    assert blob(data) == '28b3900a87f58fdde4d79e1359f07a7b1648b456'
    pattern = re.compile(rb'===== FILE (.*?) BYTES (\d+) LF (\d+) FINAL_LF (true|false) SHA256 ([0-9a-f]{64}) =====\n')
    lines = data.splitlines(keepends=True)
    frames = []
    for pos, line in enumerate(lines):
        match = pattern.fullmatch(line)
        if match is None:
            continue
        name, size, count, final, expected = match.groups()
        count = int(count)
        payload_lines = lines[pos+1:pos+1+count]
        assert len(payload_lines) == count
        assert all(x.startswith(b'| ') for x in payload_lines)
        payload = b''.join(x[2:] for x in payload_lines)
        payload.decode('utf-8', errors='strict')
        assert len(payload) == int(size)
        assert payload.count(b'\n') == count
        assert payload.endswith(b'\n') == (final == b'true')
        assert b'\r' not in payload
        assert hashlib.sha256(payload).hexdigest() == expected.decode()
        assert lines[pos+count+1] == b'===== END FILE ' + name + b' =====\n'
        frames.append({'path': name.decode(), 'bytes':len(payload),
                       'LF':count, 'sha256':expected.decode(), 'git_blob':blob(payload)})
    assert len(frames) == 7
    assert len({x['path'] for x in frames}) == 7
    print(json.dumps({'packet_sha256':sha, 'packet_blob':blob(data),
                      'frames_verified':len(frames), 'all_hashes_match':True}, indent=2))

if __name__ == '__main__':
    main()
```
