| ### 3.5. Смешанный элемент: верхняя оценка в правильном направлении
| 
| **[ABSTRACT][PAPER]** По симметрии достаточно x>=y>=4. Тогда вес x-y+2v в V(x,-y) неотрицателен, поэтому из OD1
| 
| \[
| 0<K(x,y)\le V(x,y).
| \tag{23}
| \]
| 
| Для обеих функций f(x+v),f(y+v) используем полные оценки (10). Их произведение ограничено сверху
| 
| \[
| \frac{21}{20}f(x)f(y)e^{-(\lambda_x+\lambda_y)v}
| \le\frac{21}{20}f(x)f(y)e^{-\lambda_x v}.
| \]
| 
| Таким образом,
| 
| \[
| \begin{aligned}
| \frac{K(x,y)}{f(x)f(y)}
| &\le\frac{21}{20}
| \left(\frac{x+y}{\lambda_x}+\frac2{\lambda_x^2}\right)\\
| &\le\frac{x}{\alpha_x}\frac{21}{20}
| \left(\frac43+\frac8{9\alpha_x x}\right)
| \le\frac{3x}{2\alpha_x}.
| \end{aligned}
| \tag{24}
| \]
| 
| Использованы x+y<=2x, lambda_x>=3alpha_x/2, alpha_x x>=400. Последний рациональный запас:
| 
| \[
| \frac32-\frac{21}{20}\left(\frac43+\frac1{450}\right)
| =\frac{293}{3000}>0.
| \]
| 
| Глобальное убывание f на всей положительной полуоси не нужно: обе функции в (24) контролируются непосредственно полной исходной факторизацией. Вычитание V(x,-y) используется только для верхней оценки положительного смешанного элемента. Для нижней оценки диагонали этот член полностью оплачен в (19).

| ### 3.6. Расстояние между узлами оплачивает определитель
| 
| **[COFINAL_FAMILY][PAPER]** Положим d=x-y>=4. Имеем
| 
| \[
| \frac xy\le1+\frac d4,
| \qquad
| \frac{\alpha_x}{\alpha_y}=e^{2d}.
| \]
| 
| Функция e^(2d)/(1+d/4) возрастает при d>=4, поскольку логарифмическая производная равна 2-1/(4+d)>0. В начальной точке
| 
| \[
| \frac{e^8}{2}>\frac{(8/3)^8}{2}>288,
| \]
| 
| причём последнее точное превышение равно 6499040/6561. Значит
| 
| \[
| \boxed{\frac{\alpha_x}{\alpha_y}>288\frac xy.}
| \tag{25}
| \]
| 
| Теперь (20), (24) дают
| 
| \[
| \begin{aligned}
| \frac{\Delta_-(x,y)}{f(x)^2f(y)^2}
| &\ge\frac{xy}{64\alpha_x\alpha_y}
| -\frac{9x^2}{4\alpha_x^2}\\
| &\ge\frac{xy}{128\alpha_x\alpha_y}>0.
| \end{aligned}
| \tag{26}
| \]
| 
| Во втором переходе используется ровно (25). Это доказывает (4). Получена положительная **нижняя огибающая**, не вывод из отсутствия отрицательного теста.

| ### 3.7. Все комплексные коэффициенты и исходные четыре узла
| 
| **[ABSTRACT][PAPER]** Рассмотрим положительную диагональную конгруэнцию — изменение матрицы вида DMD с положительной обратимой диагональной D:
| 
| \[
| \widetilde K_{ij}=\frac{K(x_i,x_j)}{f(x_i)f(x_j)}.
| \]
| 
| Из (22), (26) её диагональ положительна, определитель положителен. Следовательно, это положительно определённая вещественная симметричная, а также эрмитова матрица. Её след ограничен сверху:
| 
| \[
| \operatorname{tr}\widetilde K
| \le\frac32\left(\frac x{\alpha_x}+\frac y{\alpha_y}\right).
| \]
| 
| Для её положительных собственных чисел lambda_min<=lambda_max имеем lambda_min=det/lambda_max>=det/trace. Поэтому
| 
| \[
| \lambda_{\min}(\widetilde K)
| \ge\frac{xy}{192(x\alpha_y+y\alpha_x)}.
| \tag{27}
| \]
| 
| Подстановка вектора (f(x)c1,f(y)c2) доказывает (5) для произвольных комплексных c1,c2. Это однородная квадратичная нижняя оценка: при масштабировании коэффициентов обе стороны умножаются на квадрат модуля масштаба.
| 
| Равенство полной четырёхузловой V-формы величине 2c* Kc наследуется из точной чётностной сборки controlling request. Следовательно, (5) переносится туда без изменения источника и без ограничения фаз коэффициентов. Теорема R доказана на заявленной области. Независимая проверка этого нового доказательства ещё не выполнена. □

| ## 7. STRONGEST ATTACK и DISCRIMINATOR
| 
| **[ABSTRACT][PAPER]** Самая опасная ошибка этого продолжения — заменить область (3) всеми x,y>0. В частности, на диагонали правая часть (4) положительна, тогда как Delta_-(x,x)=0. Поэтому ограничение на расстояние между узлами несёт содержание, а не является украшением.

| Вторая ошибка — забыть отражённый хвост v>=z/2. Он полностью оплачен в (17)–(19); именно здесь применяется опубликованная исходная вогнутость в её принятой нормировке. Третья — потребовать только вещественные коэффициенты; конгруэнция и собственные числа в §3.7 дают всю C².

| **DISCRIMINATOR для IC:** на конкретной паре требуется строгая сертифицированная верхняя огибающая U(N)<0. Знак плавающего числа или недостаточная нижняя оценка не годятся.

| **DISCRIMINATOR для ODD2:** требуется либо L(Delta_-)>=0 на всей оставшейся области (29), либо один исходный объект с U(Delta_-)<0. При нулесогласованном результате около диагонали надлежащий объект — коэффициент

| \]
| 
| Множитель (1+z)^{5/4}/2 включает якобиан dz/[2(1+z)] и исходный e^{9v/2}. Полная отражённая часть остаётся внутри P с исходным знаком. Верхний предел по-прежнему бесконечность.
| 
| Для вычисления кривизны особенно полезно, что f(s)f(t)/H(α) является произведением функции s и функции t. Поэтому его смешанная логарифмическая производная равна нулю:
| 
| \[
| C(s,t)=\partial_s\partial_t\log I(s,t,\pi e^{2s}).
| \tag{20}
| \]
| 
| Это не ограниченный обратный оператор и не новая нормировка источника. Это точное отделение ненулевых скалярных факторов.
| 
| ### 4.4. Исходно-заданная константа для остатка
| 
| **[ABSTRACT][PAPER; собственное определение и доказательство конечности]** Все следующие производные непрерывны при t∈B, z≥0. Обозначим
| 
| \[
| \begin{aligned}
| L_B=1+\max_{j=0,1}\sup_{t\in B,\ z\ge0}\bigg(&|\partial_t^jU|+|\partial_t^jW|
| +|\partial_t^j\partial_z^2U|+|\partial_t^j\partial_z^2W|\\
| &+\left|\partial_t^j\partial_z\frac{U}{1+z}\right|
| +\left|\partial_t^j\partial_z\frac{W}{1+z}\right|\bigg).
| \end{aligned}
| \tag{21}
| \]
| 
| Это конечное число. Для z в ограниченном промежутке это следует из гладкости f и min_B f>0. В частности, t−v(z)=0 не является особой точкой: исходная f гладка на всей прямой.
| 
| При z→∞, равномерно по t∈B, |t±v(z)|≥v(z)−b. Из (8) следует для нужных производных f
| 
| \[
| |f^{(j)}(t\pm v(z))|
| \le D_j\exp[-c_B(1+z)],\qquad c_B=\frac\pi2e^{-2b}>0,
| \]
| 
| как только v(z)≥b. Производные по z добавляют только степени (1+z)^{-1}; остальные множители в (18) растут полиномиально и логарифмически. Производные по t, требуемые (21), используют f не выше третьей производной. Поэтому все функции в супремуме стремятся к нулю равномерно по B. Конечность L_B доказана независимо от знака C.
| 
| Константа не вычислялась численно. Это допустимая исходно-заданная PAPER-константа: её определение не содержит неизвестный знак K или C.
| 
| ### 4.5. Разложение полного интеграла с дифференцируемым остатком
| 
| **[ABSTRACT][PAPER; собственный вывод]** В нуле z=0 имеем точно
| 
| \[
| U(t,0)=0,\quad U_z(t,0)=\frac{p(t)}2,\quad
| W(t,0)=t,\quad W_z(t,0)=\frac{5t}4.
| \tag{22}
| \]
| 
| Рассмотрим s и α пока как независимые переменные и положим
| 
| \[
| \mathfrak D=\partial_s+2\alpha\partial_\alpha.
| \]
| 
| После α=πe^{2s} этот оператор есть полная производная по s. В частности, он дифференцирует и экспоненту e^{−αz}, и H(α(1+z)). Их производные не теряются.
| 
| Положим Q=P/(1+z). Используя (15), разложим I **точно**:
| 
| \[
| \begin{aligned}
| I={}&\int_0^\infty e^{-\alpha z}P\,dz
| -\frac3{2\alpha}\int_0^\infty e^{-\alpha z}Q\,dz
| +R_E,\\
| R_E={}&\int_0^\infty e^{-\alpha z}E(\alpha(1+z))P\,dz.
| \end{aligned}
| \tag{23}
| \]
| 
| Обозначим
| 
| \[
| \begin{aligned}
| R_1&=\int_0^\infty e^{-\alpha z}
| \left[P-t-\left(\frac{s p(t)}2+\frac{5t}4\right)z\right]dz,\\
| R_2&=\int_0^\infty e^{-\alpha z}(Q-t)\,dz.
| \end{aligned}
| \]
| 
| Формула Тейлора с интегральным остатком, определение L_B и
| 
| \[
| \int_0^\infty z^k e^{-\alpha z}dz=\frac{k!}{\alpha^{k+1}}
| \]
| 
| дают для j=0,1, s≥1, α≥100:
| 
| \[
| \begin{array}{c|c|c}
| \text{Остаток}&|\partial_t^j(\cdot)|&|\mathfrak D\partial_t^j(\cdot)|\\ \hline
| R_1&L_B(s+1)\alpha^{-3}&7L_B(s+1)\alpha^{-3}\\
| R_2&L_B(s+1)\alpha^{-2}&5L_B(s+1)\alpha^{-2}\\
| R_E&L_B(s+1)\alpha^{-5}&L_B(s+1)(2\alpha^{-4}+3\alpha^{-5})
| \end{array}
| \tag{24}
| \]
| 
| Детали второй колонки: остаток P ограничен L_B(s+1)z²/2, остаток Q — L_B(s+1)z. Для R_E используем (16) и |∂_t^jP|≤L_B(s+1).
| 
| Детали третьей колонки: производная экспоненты даёт −2αz. В R₁ её интеграл стоит 6L_B(s+1)α^{-3}, а явная ∂_s даёт ещё L_Bα^{-3}. В R₂ получаются 4L_B(s+1)α^{-2} и L_Bα^{-2}. В R_E производная E даёт
| 
| \[
| 2\alpha(1+z)|E'(\alpha(1+z))|\le2\alpha^{-3}(1+z)^{-3};
| \]
| 
| её интеграл ограничен 2L_B(s+1)α^{-4}. Производная экспоненты и явная ∂_s дают вместе не больше 3L_B(s+1)α^{-5}. Те же оценки действуют после ∂_t, поскольку L_B содержит обе t-производные. Они также служат абсолютными мажорантами для дифференцирования.
| 
| Из (22)–(24)
| 
| \[
| \boxed{
| I=\frac t\alpha+\frac{\tfrac{s p(t)}2-\tfrac t4}{\alpha^2}+R,
| \qquad R=R_1-\frac3{2\alpha}R_2+R_E.
| }
| \tag{25}
| \]
| 
| Здесь −t/4=5t/4−3t/2 сохраняет исходную поправку −3/(2q). Она не выброшена вместе с более высокими модами.
| 
| Для каждой из четырёх величин R, R_t, \mathfrak D R, \mathfrak D R_t получаем единый бюджет
| 
| \[
| \boxed{
| |\cdot|\le20 L_B\frac{s+1}{\alpha^3}.
| }
| \tag{26}
| \]
| 
| Например, без \mathfrak D коэффициент не больше 1+3/2+α^{-2}<3. После \mathfrak D вклад среднего слагаемого стоит 21/2, с учётом производной 1/α; общий коэффициент не больше
| 
| \[
| 7+\frac{21}2+\frac2\alpha+\frac3{\alpha^2}<20.
| \]
| 
| Таким образом, (25) не является недифференцированным O-членом, который затем формально дифференцируется. Контроль смешанной производной остатка доказан до следующего шага.
| 
| ### 4.6. Переход к логарифму и доказательство бюджета (14)
| 
| **[ABSTRACT][PAPER; собственная оценка]** Запишем
| 
| \[
| I=\frac t\alpha(1+q),\qquad
| q=\frac{\tfrac{s\rho(t)}2-\tfrac14}{\alpha}+e,
| \qquad e=\frac{\alpha R}t.
| \tag{27}
| \]
| 
| Определим
| 
| \[
| \boxed{
| H_B=1+\sup_{t\in B}(|\rho(t)|+|\rho'(t)|)
| +60L_B(a^{-1}+a^{-2}).
| }
| \tag{28}
| \]
| 
| Константа конечна. По (26), каждая из величин e, e_t, \mathfrak D e, \mathfrak D e_t ограничена по модулю H_B(s+1)/α². Коэффициент 60 учитывает также \mathfrak Dα=2α и производную 1/t.
| 
| Обозначая производную после подстановки α=πe^{2s} обычным индексом s, получаем
| 
| \[
| \begin{aligned}
| |q|,|q_s|,|q_t|&\le\frac{2H_B(s+1)}\alpha,\\
| q_{st}&=\frac{\tfrac12-s}{\alpha}\rho'(t)+e_{st},\qquad
| |e_{st}|\le\frac{H_B(s+1)}{\alpha^2}.
| \end{aligned}
| \tag{29}
| \]
| 
| При α≥4H_B(s+1) имеем |q|≤1/2. В силу (20), (27)
| 
| \[
| C=\frac{q_{st}}{1+q}-\frac{q_s q_t}{(1+q)^2}.
| \tag{30}
| \]
| 
| Множитель log(t/α) смешанной производной не даёт. Пусть T=(1/2−s)ρ'(t)/α. Тогда
| 
| \[
| \begin{aligned}
| |C-T|
| &\le 2|e_{st}|+2|T||q|+4|q_s q_t|\\
| &\le\frac{2H_B(s+1)+20H_B^2(s+1)^2}{\alpha^2}\\
| &\le\frac{24H_B^2(s+1)^2}{\alpha^2}.
| \end{aligned}
| \]
| 
| Это доказывает (14), сохраняя весь нелинейный смешанный член q_s q_t.
| 
| ### 4.7. Строгий положительный главный член и явное правило порога
| 
| **[ABSTRACT][PAPER; наследуемый точечный источник, не одна абстрактная strict concavity]** S4 §4 содержит точное следствие опубликованного Csordas Remark 4.3(a) в исходной нормировке:
| 
| \[
| J_f(t)=t(f'(t)^2-f(t)f''(t))+f(t)f'(t)>0
| \quad(t>0).
| \]
| 
| Поэтому
| 
| \[
| \rho'(t)=\frac{t p'(t)-p(t)}{t^2}<0.
| \tag{31}
| \]
| 
| Здесь строгость используется из явного точечного неравенства, а не ошибочно выводится из абстрактной строгой вогнутости. На B непрерывная функция −ρ' имеет положительный минимум
| 
| \[
| \eta_B=\min_{t\in B}[-\rho'(t)]>0.
| \tag{32}
| \]
| 
| **[COFINAL_FAMILY][PAPER; завершение нового ограниченного доказательства]** Выбери любое целое S_B≥2, для которого
| 
| \[
| \boxed{
| \frac{\pi e^{2S_B}}{S_B+1}
| \ge\max\left\{4H_B,\frac{192H_B^2}{\eta_B}\right\}.
| }
| \tag{33}
| \]
| 
| Такое целое существует, поскольку e^{2s}/(s+1) возрастает и неограниченно при s≥1. Уже при s≥2 выполнено πe^{2s}>100. Для s≥1 также
| 
| \[
| \frac{(s+1)^2}{s-1/2}\le4(s+1).
| \]
| 
| Следовательно, при s≥S_B ошибка (14) не больше половины положительного главного члена. Получается настоящая **нижняя огибающая**:
| 
| \[
| \boxed{
| C(s,t)\ge\frac{\eta_B(s-1/2)}{2\pi e^{2s}}>0
| \qquad(s\ge S_B,\ t\in B).
| }
| \tag{34}
| \]
| 
| Это и есть теорема (12). В её доказательстве использованы полный theta-остаток E, полный интеграл I и дифференцируемый остаток R. Численная квадратура или конечная сетка не занимают ни одного квантора. □
| 
| ## 5. Почему новая хвостовая теорема не закрывает запрос
| 
| **[ABSTRACT][PAPER; проверка кванторов и потребителя]** Доказано
| 
| \[
| \forall B\Subset(0,\infty)\ \exists S_B\ \forall s\ge S_B\ \forall t\in B:\ C(s,t)>0.
| \]
| 
| Не доказано
| 
| \[
| \forall s,t>0:\ C(s,t)\ge0.
| \]
| 
| Порог S_B зависит от B через L_B, H_B и η_B. Нет контроля этих констант при a↓0 или b↑∞, который покрывал бы всю четверть. Перестановка кванторов здесь была бы ошибкой.
| 
| Теорема не покрывает автоматически совместный уход s,t→∞, диагональный режим s≈t, оси s↓0 или t↓0 и оставшиеся конечные области. Даже положительный C в двух разнесённых хвостовых полосах не определяет знак двойного интеграла (4): ему нужен весь квадрат [x,y]².
| 
| Поэтому результат (34) является новым частным утверждением о фактической C, но **не** новым доказанным семейством двухузловых V-форм. Владелец не получает фиктивного обнуления счётчика за такой частный результат.
| 
| ## 6. Первая неоплаченная оценка — одна, без переименования
| 
| **[ABSTRACT][CONDITIONAL; неоплаченный исходный знак]** Пусть
| 
| \[
| b(v;s,t)=(s+t+2v)f(s+v)f(t+v)
| -(s-t+2v)f(s+v)f(t-v).
| \]
| 
| Тогда K=∫b, а его производные — интегралы соответствующих полных производных b. Все четыре абсолютных интеграла конечны по §3. Следовательно, по Fubini
| 
| \[
| \begin{aligned}
| N(s,t)=\frac12\int_0^\infty\!\int_0^\infty
| \big[&b(v)b_{st}(w)+b(w)b_{st}(v)\\
| &-b_s(v)b_t(w)-b_s(w)b_t(v)\big]dv\,dw.
| \end{aligned}
| \tag{35}
| \]
| 
| Аргументы s,t во всех множителях одинаковы. Формула сохраняет взаимодействия разных интегральных параметров и всю отражённую часть. **Первая неоплаченная оценка — N(s,t)≥0 на части положительной четверти, не покрытой (34).** Не получен ни её источник-специфический нижний бюджет, ни отрицательный исходный свидетель.
| 
| Считать (35), новую букву для N или условие «правая часть (35)≥0» достижением в полном знаке означало бы `NO_PROGRESS_TAUTOLOGY`: это сама IC после допустимой перезаписи.
| 
| **[ABSTRACT][PAPER; статус доступных альтернативных тождеств]** Полные масштабированные BP2-уравнения и двулинейный баланс из S2 (33) сохраняются, но в этом цикле не дали оценки (35). Не выведено и не предполагается, что из их положительных скалярных частей следует знак двухпараметрической разности.
| 
| Кандидат
| 
| \[
| C=\mathbb E_\mu[\partial_{st}\log J_u]
| +\operatorname{Cov}_\mu(\partial_s\log J_u,\partial_t\log J_u),
| \quad d\mu=J_u\,du/K,
| \]
| 
| не использован. Его отдельные score-интегралы не объявляются здесь проверенными. Прямые формулы (9)–(11), (35) обходят это дополнительное требование. В частности, ковариация не заменяется нулём и ни одному её слагаемому не присваивается знак без доказательства.
| 
| ## 7. Границы и DISCRIMINATOR
| 
| **[ABSTRACT][PAPER]** Оценки §3 доказывают законность производных и хвостовых пределов. Они не доказывают нужный знак. На диагонали Δ_-(x,x)=0 тождественно; это не «маленькое положительное число» и не отрицательный свидетель.
| 
| Для различения возле диагонали сохраняется исходный **DISCRIMINATOR**, то есть функционал, способный отличить тождественный ноль от отрицательного соседнего минора:
| 
| \[
| D_2(x)=K(x,x)K_{st}(x,x)-K_s(x,x)^2=K(x,x)^2C(x,x).
| \tag{36}
| \]
| 
| Тейлор и симметрия дают
| 
| \[
| \Delta_-(x,x+h)=h^2D_2(x)+o(h^2).
| \]
| 
| Строго отрицательная **верхняя** оценка D₂(x) опровергла бы настоящий ODD2 локально. В этом цикле такой оценки нет. Если D₂(x)=0, нужен первый последующий ненулевой коэффициент полного определителя с остатком; увеличение точности тождественного нуля не является проверкой знака.
| 
| **[COFINAL_FAMILY][PAPER]** Для нового хвостового результата нулевой предел C(s,t)→0 при фиксированном t не оставлен без различителя. Из (14)
| 
| \[
| \boxed{
| \frac{\pi e^{2s}}s C(s,t)\longrightarrow-\rho'(t)>0
| }
| \tag{37}
| \]
| 
| равномерно по t∈B. Это источник-специфический нормированный функционал, отличающий положительную исчезающую кривизну от точного нуля. Он не требует численного разрешения экспоненциально малого C.

| ## 9. STRONGEST ATTACK — что могло бы сделать этот ответ ложным
| 
| **[ABSTRACT][PAPER; адверсариальные проверки]** Главная опасность — выдать
| 
| \[
| \forall B\ \exists S_B

| ## 1. Что означает «свидетеля нет»
| 
| **[ABSTRACT][PAPER: логика утверждений]**
| 
| Для вещественнозначной квадратичной формы на фиксированной области \(\mathcal D\):
| 
| \[
| \neg\exists g\in\mathcal D:\ Q(g)<0
| \quad\Longleftrightarrow\quad
| \forall g\in\mathcal D:\ Q(g)\ge0.
| \tag{1}
| \]
| 
| Это эквивалентные утверждения, а не конкурирующие требования. Один полный положительный бюджет и один строго отрицательный свидетель для той же формы на той же области одновременно существовать не могут.

| ## 2. Что у Ходжа давало знак
| 
| **[ABSTRACT][PAPER: классическая теорема, не новая theta-лемма]**
| 
| Нужна **теорема Ходжа об индексе**, а не гипотеза Ходжа. Существенна форма пересечений и её знак на правильно выделенном подпространстве. Это не утверждение о положительной кривизне поверхности.

| На комплексной компактной кэлеровой поверхности для вещественной гармонической примитивной формы типа \((1,1)\) выполняется \(*\alpha=-\alpha\). Поэтому

| -\int\alpha\wedge\alpha
| =\int\alpha\wedge*\alpha
| =\|\alpha\|_{L^2}^2\ge0.
| \tag{3}

| ## 3. Зачем Вейлю поверхность-произведение
| 
| **[ABSTRACT][PAPER: реконструкция классического механизма по [W1]]**
| 
| Для кривой \(X/\mathbb F_q\) возникает поверхность \(X\times X\). Она содержит диагональ и графы степеней Фробениуса. Их пересечения кодируют числа точек. После удаления горизонтального и вертикального классов противоположная форма пересечений становится положительной по теореме об индексе.
| 
| Пусть \(H=X\times\{p\}\), \(V=\{p\}\times X\), а
| 
| \[
| p(D)=D-(D\cdot V)H-(D\cdot H)V.
| \]
| 
| На \(E=\operatorname{span}(H,V)^\perp\) берём \(\langle a,b\rangle_E=-a\cdot b\). Для графа \(\Gamma_n\) степени \(n\) Фробениуса, рода \(g\) и \(N_n=\#X(\mathbb F_{q^n})\) точные формулы имеют вид
| 
| \[
| \|p\Gamma_0\|^2=2g,\qquad
| \|p\Gamma_n\|^2=2gq^n,\qquad
| \langle p\Gamma_0,p\Gamma_n\rangle=q^n+1-N_n.
| \tag{4}
| \]
| 
| Следовательно, неравенство Коши–Буняковского даёт
| 
| \[
| |q^n+1-N_n|\le2gq^{n/2}.
| \tag{5}
| \]
| 
| Нужный двухузловой определитель здесь не угадывают: это уже определитель Грама двух векторов в доказанно положительном пространстве. Источник (4) — [W1], Lemma 3; случай \(n=1\) разобран там непосредственно после леммы.
| 
| **[ABSTRACT][PAPER: методологический вывод из (3)–(5)]**
| 
| Это полезный ответ на вопрос про «дополнительную поверхность». Поверхность служит пространством пар и соответствий. Но само увеличение размерности не даёт знака. Знак даёт совместимая положительная геометрия, а формулы (4) связывают её с нужной арифметикой.
| 
| Есть и спектральная версия того же урока. **Поляризация** задаёт инволюцию Розати \(\dagger\); для Фробениуса \(\pi\) имеем \(\pi^\dagger\pi=q\). Положительность Розати позволяет вывести \(|\lambda|^2=q\) для корней характеристического многочлена [W4, II, Lemmas 1.2–1.3]. Здесь нельзя молча заменить положительную поляризацию произвольной невырожденной формой.
| 
| Для понимания последнего шага достаточно отдельной линейно-алгебраической модели: если на комплексном пространстве дана положительная норма, \(F^*F=qI\) и \(Fu=\lambda u\ne0\), то
| 
| \[
| |\lambda|^2\|u\|^2=\|Fu\|^2=q\|u\|^2.
| \]
| 
| Это аналогия на точных гипотезах, не объявление пространства Тейта обычным вещественным гильбертовым пространством.

| **[ABSTRACT][PAPER: точная комплексная алгебра]**

| Для нашей пары положительных узлов положим
| 
| \[

| ## 7. Где в самом исходном ядре находится задача о положительной геометрии

| Все они принадлежат \(\mathcal H\) по полным хвостам исходной \(f\). Переменные логарифмические, без отдельной физической размерности; нормировка остаётся \(f=\Phi/A\).
| 
| Сначала из чётности \(f\) следует \(V(-x,-y)=V(x,y)\). Действительно, после \(w=v+(x+y)/2\) подынтегральное выражение равно
| 
| \[
| 2w f\left(w+\frac{x-y}{2}\right)
|     f\left(w-\frac{x-y}{2}\right).
| \]
| 
| Оно нечётно по \(w\), абсолютно интегрируемо, и его интегралы от \(-m\) и от \(m\) до бесконечности совпадают. Следовательно, также \(V(-x,y)=V(x,-y)\).
| 
| Раскрытие четырёх членов даёт
| 
| \[
| \langle U_x,W_y\rangle+\langle W_x,U_y\rangle
| =V(x,y)-V(x,-y)-V(-x,y)+V(-x,-y)=2K(x,y).
| \]
| 
| Поэтому
| 
| \[
| \boxed{K(x,y)=\langle a_x,a_y\rangle-\langle b_x,b_y\rangle.}
| \tag{16}
| \]
| 
| Для всех конечных наборов и всех комплексных коэффициентов получаем
| 
| \[
| \boxed{
| \sum_{i,j}\overline{c_i}K(x_i,x_j)c_j
| =\left\|\sum_i c_i a_{x_i}\right\|^2
| -\left\|\sum_i c_i b_{x_i}\right\|^2.
| }
| \tag{17}
| \]
| 
| Здесь сохранены весь интеграл, отражённые члены, общий источник и произвольные комплексные фазы. Положительность каждого подынтегрального блока не предполагалась.
| 
| **[ABSTRACT][PAPER: точная граница геометрического предложения]**
| 
| Независимо построенный линейный оператор \(T\), удовлетворяющий
| 
| \[
| T a_x=b_x\quad(x>0),\qquad\|T\|\le1,
| \tag{18}
| \]
| 
| сразу сделал бы всю правую часть (17) неотрицательной. Но одного введения \(T\) недостаточно. Его существование на замыкании \(\operatorname{span}\{a_x\}\) с нормой не больше единицы эквивалентно положительности всех конечных нечётных матриц.
| 
| Доказательство обратного направления: из (17) и неотрицательности следует
| \(\|\sum c_i b_{x_i}\|\le\|\sum c_i a_{x_i}\|\). Поэтому правило \(\sum c_i a_{x_i}\mapsto\sum c_i b_{x_i}\) корректно: нулевое представление слева даёт нуль справа. Оно линейно, имеет норму не больше единицы и непрерывно продолжается на замыкание.
| 
| Следовательно, (18) нельзя принять как готовую «новую лемму о геометрии». **Новым поставщиком** могло бы стать только независимое построение этого оператора из theta-источника и доказательство его нормы, не использующее требуемый знак. Сейчас такого построения здесь нет.
| 
| Для текущего ODD2 достаточно сравнения норм в (17) только на каждом двухпрофильном пространстве. Общий оператор для всех узлов сильнее этого потребителя. Положительность всех пар не разрешает молча склеить парные операторы в один общий.

| ## 9. Отрицательный свидетель не обязан жить на двух узлах

| **[ABSTRACT][PAPER: лемма о строгом знаке и плотности]**

| Для непрерывного ядра \(V\) и фиксированного \(n\) функция
