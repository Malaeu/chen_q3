### Как сертифицирована точка

[ABSTRACT][PAPER] Определим масштабированные лучи

\[
A_n(s)=\int_0^\infty\phi_n(t+i\vartheta)e^{(s+iT)t}dt.
\]

Тогда X=e^(-vartheta T+i vartheta sigma) sum A_n(sigma), Y=e^(-vartheta T+i vartheta sigma) conjugate(sum A_n(-sigma)). Общий мнимый сдвиг производной не меняет эрмитову матрицу; h_N и M_+ умножаются на один exp(-2 vartheta T).

Интегрируются A_n(+-1/2), A_n'(+-1/2) для n<=30 на [0,4]. GL32 имеет шаг 1/128. Все 32 корня P32 изолированы непересекающимися рациональными интервалами со сменой знака; веса вычислены по точной формуле 2/((1-x^2)P32'(x)^2).

На круге радиуса R=1/200 вокруг [0,4] проверено cos(2(theta+R))>1/400. Пишем q=a_n exp(2 Re t). Тогда

\[
|\phi_n(t+i\vartheta)|\le8(4q^2+6q)e^{-q/400}.
\]

Из e>2 и максимумов q^2 exp(-q/400), q exp(-q/400) следуют верхние границы 160000 и 200. Дополнительные множители наклона, фазы и t-момента ограничены 8,3,5. Их произведение с мажорантой меньше 10^9. Оценка Коши и остаток GL32 дают на каждый луч и момент

\[
\mathrm{Err}_{GL}\le
\frac{8\cdot10^9}{65\binom{64}{32}^2}(200/128)^{64}
<9.301\cdot10^{-17}.
\]

Хвост t>=4 оплачен заменой u=exp(2t)>2800 и явными интегралами u^3 exp(-a_n c u), u^2 exp(-a_n c u). Хвост n>=31, включая все пропущенные координаты вплоть до N=83, ограничен

\[
\eta=448c^{-1}31^3e^{-\pi c31^2}<2.723\cdot10^{-8}.
\]

Для норм и скалярного произведения пропущенных координат достаточно 2 eta^2. Конечный срез N=83 проверен интервально: 83^2 < (T+1)(32+20 log(T+1))/3 <84^2. Ничего не вычисляется по обрезанной положительной версии источника.

Положительная масса вычисляется из точной rank-two формулы. Для вектора масштабированных лучей u и производных без общего i theta сдвига v, положим U=u*u, V=v*v, b=Im(u*v), delta=sqrt(UV-b^2), J=sum u, D=sum v. Тогда

\[
M_+=\frac U\delta\left|D+\frac{\delta-ib}{U}J\right|^2.
\]

Здесь символ u*v в U,V,b означает эрмитово скалярное произведение. Все ненулевые знаменатели отделены от нуля интервалами.

## 4. Ремонт глобальной мишени: сохранять полный запас, не отдельные константы

[ABSTRACT][PAPER] Точно:

\[
G=(g_0-\varepsilon)/\kappa,
\qquad g_0=(1-|Y/X|^2)/\sigma.
\]

Отказ kappa<=6/5 нельзя чинить произвольным увеличением этой константы и очередной сеткой. В точке раздела 3 большая положительная поправка E_coh оплачивает большую kappa. Раздельные оценки теряют эту компенсацию.

Для вывода знака исходной H величина M_+ вообще не обязательна. Достаточно совместно доказать (A1). Это снимает отдельные требования к kappa, к ненулевости X,Y и к относительному полу M_+.

Введём точную форму без деления на кластеры:

\[
\mathcal B_N(\sigma,T)=4\int_0^1\left[
|J_N'(u\sigma+iT)|^2+
\Re\big(J_N''(u\sigma+iT)\overline{J_N(u\sigma+iT)}\big)
\right]du.
\]

Угол theta и N фиксированы при производных. Из h_N(iT)=0 и основной теоремы анализа следует

\[
\boxed{\mathcal B_N=h_N/\sigma\quad(\sigma>0).}
\]

В sigma=0 формула имеет обычное непрерывное значение

\[
4(|J_N'(iT)|^2+\Re(J_N''(iT)\overline{J_N(iT)})).
\]

Значит (A1) равносильно нижней оценке B_N-e_N>=0 для всего заданного источника. Это вычислимое выражение с уже оплаченными производными порядков 0,1,2; его знак здесь глобально НЕ доказан.

[COFINAL_FAMILY][CONDITIONAL] Более слабый достаточный интерфейс допускает исчезающий отрицательный запас: для каждого фиксированного sigma,T существуют N_j->infinity и a_j>=0 с a_j+e_(N_j)->0 и h_(N_j)/sigma>=-a_j. Тогда H/sigma>=-a_j-e_(N_j) и предельная нижняя граница равна нулю. Это не вывод из положительности одного верхнего конца интервала; нужен доказанный бесконечный квантор и сходимость оплаченных ошибок.

## 5. Финальная импликация без строгого пола и без простоты нулей

[ABSTRACT][PAPER] Предположим только (A). Пусть F(sigma_0+iT_0)=0 при 0<sigma_0<=1/2 и |T_0|>9/2. Вещественное отражение позволяет считать T_0>9/2.

Для фиксированного T_0 положим q(s)=|F(s+iT_0)|^2. Тогда

\[
q'(s)=2\Re(F'(s+iT_0)\overline{F(s+iT_0)})=\mathcal H(s+iT_0)/2\ge0.
\]

Поэтому при 0<s<sigma_0 имеем 0<=q(s)<=q(sigma_0)=0. F зануляется на целом отрезке. Теорема тождественности даёт F identically 0, что противоречит F(0)>1/4 из раздела 2.

Отрицательные sigma исключаются чётностью F(-p)=F(p). Низкие |T|<=9/2 уже исключены (2.2). Нетривиальные нули zeta находятся в 0<Re(s)<1, а нули completed xi соответствуют им. Следовательно, при посылке (A) все они имеют Re(s)=1/2.

**Итак, доказана импликация (A)=>RH. Посылка (A) остаётся открытой.** Это прямое доказательство, а не вызов теоремы монотонности, которая сама предполагала бы безнулевую полуплоскость.

### Почему нельзя без нужды требовать глобальный положительный пол

[ABSTRACT][PAPER] Если F имеет осевой нуль порядка r в i gamma, то

\[
F(i\gamma+\sigma)=a\sigma^r+O(\sigma^{r+1}),\quad a\ne0,
\]
\[
\mathcal H(i\gamma+\sigma)/\sigma
=4r|a|^2\sigma^{2r-2}+O(\sigma^{2r-1}).
\]

При r>=2 предел равен нулю. Поэтому глобальный контракт H>=c(T)sigma с c(T)>0 потребовал бы дополнительно простоты всех осевых нулей. Из RH такая дополнительная посылка здесь не выводится. Нестрогий шаг B не нуждается в ней.

Рабочая директория команд — `rh_two_steps_audit` из распакованного пакета:

```bash
python audit_endpoints.py
python low_rectangle.py
python certify_high_point.py 0
python certify_high_point.py 1
python certify_high_point.py 2
python certify_high_point.py 3
python certify_high_point.py combine
```

Аргументы 0,1,2,3 задают соответственно интегральные отрезки [0,1], [1,2], [2,3], [3,4]. `combine` добавляет строгие квадратурные остатки и бесконечные хвосты. Секретов или параметров репозитория подставлять не нужно. Зависимость — mpmath для предложения узлов; знаки узлов затем проверяются точно. Для проверки symbolic_checks используется sympy. Arb не использован: попытка установки python-flint в этом окружении не удалась, и его проверка не заявляется.

Этот документ допускает публикацию только как PAPER-вердикт с внешним ревью PENDING. Lean-исходники и production-состояние не изменяются; ядро не запускалось. Коммит публикации и хеш документа сообщаются отдельной квитанцией, поскольку файл не может содержать собственный будущий SHA.

Справочные первичные источники: NIST DLMF 25.4 (xi и отражение), 25.10 (критическая полоса), 3.5(v) (остаток гауссовой квадратуры); Sondow--Dumitrescu, arXiv:1005.1104 (родственный критерий монотонности). Доказательство раздела 5 дано непосредственно и не импортирует гипотезу безнулевости из последней работы.
