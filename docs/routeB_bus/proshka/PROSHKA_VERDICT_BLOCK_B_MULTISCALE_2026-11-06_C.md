## 2. Неизменный источник и два разных предела

[FINITE_CELL / ABSTRACT | PAPER.]

\(N\) — длина мёбиусова префикса; \(T\) — вспомогательный Fourier-cutoff. Нельзя считать конечность при фиксированном N оценкой при N→∞. Положим

\[
 L=\log N,\quad a_1=1,\quad a_n=\mu(n)\frac{\log(N/n)}L\ (2\le n\le N),
\]
\[
 R_N(k)=1+\sum_{n=2}^Na_n\frac{k\bmod n}{n},\quad
 E_N=\sum_{k\ge1}\frac{|R_N(k)|^2}{k(k+1)},
\]
\[
 s_N=\sum_{n\le N}\frac{a_n}n,\quad q_1=1-s_N,\quad q_n=a_n\ (n\ge2),
 \quad Q_N=\sum_{n\le N}|q_n|.
\]

Всегда \(\sum q_n/n=0\). Сохраняется \(b_N=1+(\sum a_n-s_N)/2\) и \(\mathcal S=\{N\ge3:b_Nb_{N+1}\le0\}\). Введём настоящий divisor-current

\[
 A_N(\ell)=\sum_{\substack{n\mid\ell\\n\le N}}q_n,
 \qquad d_{N,\ell}=\frac{\mathbf1_{\ell=1}-A_N(\ell)}\ell. \tag{1}
\]

Единица при \(\ell=1\) необходима: буквальная формула R_N(0)=1 отличается от нулевого левого значения в операторе разности. Из точного целочисленного деления

\[
 R_N(k)-R_N(k-1)=-A_N(k),\qquad
 A_N(\ell)=\mathbf1_{\ell=1}+\Lambda(\ell)/L-s_N\quad(\ell\le N). \tag{2}
\]

Все proper prime powers остаются в Λ. Ни коэффициенты, ни их история не меняются.

Пусть \(v_\ell=\mathbf1_{\{1,\ldots,\ell\}}\in\ell^2\),
\[
 y_j=\sum_{\ell\ge j}d_{N,\ell},\quad
 y^{[T]}=\sum_{\ell=1}^T d_{N,\ell}v_\ell,\quad
 E_N^{[T]}=\|y^{[T]}\|_2^2.
\]
Вход R даёт \(E_N=\|y\|_2^2\). Для контроля импорта: U имеет столбец Uδ_k с первыми k координатами 1/[k(k+1)], следующей −1/(k+1), далее нулями. Их нормированные версии ортонормированы; ортогональное дополнение состояло бы из постоянной ℓ²-последовательности, значит нулевое. Это доказывает унитарность и равенство норм без RH.

Центрирование даёт для любых v≥r≥1
\[
 \left|\sum_{\ell=r}^v A_N(\ell)\right|
 =\left|\sum_n q_n\left(\{(r-1)/n\}-\{v/n\}\right)\right|\le Q_N.
\]
Суммированием по частям \(|y_j|\le Q_N/j\) при j≥2. Поэтому
\[
 \boxed{\|y-y^{[T]}\|_2^2\le\frac{2Q_N^2}{T}.} \tag{3}
\]
Действительно, при j≤T разность равна y_(T+1), а при j>T равна y_j. E_N^[T] не обязана возрастать или лежать ниже E_N.

## 3. Универсальная локализационная теорема

[ABSTRACT / FINITE_CELL | PAPER; все входы комплексные.]

Для любых T≥1 и d∈C^T положим
\[
 G_T(\ell,k)=\min(\ell,k),\qquad
 \kappa(\ell,k)=\left(1-\frac{|\log((\ell+1)/(k+1))|}{\log2}\right)_+,
\]
\[
 K_T(\ell,k)=G_T(\ell,k)\kappa(\ell,k).
\]

**Теорема 1.** В порядке эрмитовых матриц, одновременно для всех T,
\[
 \boxed{\frac17G_T\ \preceq\ K_T\ \preceq\ 15G_T.} \tag{4}
\]
Таким образом удаление пар с отношением (ℓ+1)/(k+1) вне (1/2,2), с указанным taper внутри, не теряет энергию больше абсолютного множителя. Это не произвольное зануление элементов: именно этот положительный kernel имеет оценку (4).

### 3.1. Растущие блоки: верхняя константа 7

Для 1≤t<2 и b≥0 зададим
\[
 m_b(t)=\lfloor2^bt\rfloor,\quad I_b(t)=\{m_b,\ldots,m_{b+1}-1\},
 \quad V_b(t)=\sum_{\ell\in I_b(t)}d_\ell v_\ell,\quad
 D_t(d)=\sum_b\|V_b(t)\|_2^2, \tag{5}
\]
продолжая d нулём после T. m_0=1 и m_(b+1)≥2m_b; все положительные целые покрыты один раз.

Пространство, содержащее V_b, имеет ортонормированный базис
\[
 p_b=m_b^{-1/2}\mathbf1_{[1,m_b]},\qquad
 e_j\quad(m_b<j<m_{b+1}).
\]
Интерьерные e_j различных блоков не пересекаются. У prefix-векторов
\[
 |\langle p_b,p_c\rangle|=\sqrt{m_{\min(b,c)}/m_{\max(b,c)}}
 \le2^{-|b-c|/2}.
\]
Норма их Gram не больше суммы геометрической строки
\[
 1+2\sum_{r\ge1}2^{-r/2}=3+2\sqrt2.
\]
Последнее следует непосредственно из 2|z_bz_c|≤|z_b|²+|z_c|², то есть не требует непроверенного спектрального импорта. Если Π_b — ортопроектор на указанное пространство, то
\[
 \sum_b\|\Pi_b z\|^2\le(4+2\sqrt2)\|z\|^2<7\|z\|^2.
\]
Дуальность и Cauchy–Schwarz дают
\[
 \left\|\sum_bV_b\right\|^2
 \le7\sum_b\|V_b\|^2=7D_t(d). \tag{6}
\]
Это настоящая all-input положительная блочная мажоранта, с константой, не зависящей от числа блоков. В отличие от R, ширина здесь растёт с Fourier-индексом.

### 3.2. Зачем усреднять границы

Положим y_j=Σ_(ℓ≥j)d_ℓ, E=Σ|y_j|². Если m=m_b, M=m_(b+1), то точно
\[
 \|V_b\|^2=m|y_m-y_M|^2+
                  \sum_{j=m+1}^{M-1}|y_j-y_M|^2.
\]
Из |x−z|²≤2|x|²+2|z|² и суммирования по блокам
\[
 D_t(d)\le2E+4\sum_{b\ge1}(m_b-1)|y_{m_b}|^2. \tag{7}
\]
Для конечного d последний y_M=0, поэтому неоплаченного терминального члена нет. Усреднение теперь является точной конечной операцией:
\[
 \int_1^2(m_b-1)|y_{m_b}|^2dt
 =2^{-b}\sum_{j=2^b}^{2^{b+1}-1}(j-1)|y_j|^2
 \le2\sum_{j=2^b}^{2^{b+1}-1}|y_j|^2.
\]
Следовательно
\[
 \boxed{E/7\le\int_1^2D_t(d)dt\le10E.} \tag{8}
\]
Это именно dt-усреднение, зафиксированное во freeze.

Для ОДНОГО фиксированного разбиения обратное сравнение неверно. Пусть m=2^b≥2, y=e_m, d_(m−1)=−1, d_m=1. Тогда E=1, но D_1=2m−1. В то же время точное среднее по dt равно 3−2/m. Значит усреднение реально оплачивает произвольность dyadic boundaries; оно не косметическое.

### 3.3. Закрытая balanced-формула

Как следствие (6)–(8), после freeze получено удобное логарифмическое усреднение
\[
 Z_T(d)=\int_1^2D_t(d)\frac{dt}{t\log2}. \tag{9}
\]
Это отдельное следствие, не замена frozen dt-спецификации и не задним числом предсказанный результат.

Два индекса ℓ,k находятся в одном блоке тогда, когда случайная по log t dyadic boundary не разделяет log_2(ℓ+1) и log_2(k+1). Точный вес совпадения равен κ(ℓ,k). Действительно, ℓ∈I_b эквивалентно
\[
 b+\log_2t<\log_2(\ell+1)\le b+1+\log_2t.
\]
Интегрирование по одному периоду log_2t∈[0,1) даёт
\[
 Z_T(d)=\sum_{\ell,k\le T}\overline{d_\ell}d_k
                           \min(\ell,k)\kappa(\ell,k)=d^*K_Td. \tag{10}
\]
Положительность следует из суммы квадратов (9), а не из знака отдельных коэффициентов d. По (6), интегрируя относительно вероятностной меры dt/(t log2), E≤7Z_T. По (8), Z_T≤10E/log2<15E, поскольку log2>2/3. Это доказывает (4). □

Для импульса выше логарифмическая цена равна
\[
 Z_T=1+\frac{2(m-1)\log(1+1/m)}{\log2}<1+\frac2{\log2},
\]
а не 2m−1. Никакая другая функция Мёбиуса для этого отрицательного теста не вводится: это тест общей операторной границы, не контрпример для источника.

## 4. Вычислимый положительный объект и точный остаток

[FINITE_CELL | PAPER.]

Для любого конечного d, продолженного нулём, обозначим
\[
 B_{m,M}(d)=m\left|\sum_{\ell=m}^{M-1}d_\ell\right|^2
       +\sum_{j=m+1}^{M-1}\left|\sum_{\ell=j}^{M-1}d_\ell\right|^2\ge0.
\]
В (9) случай m_b=m разбивается на m_(b+1)=2m и 2m+1. Поэтому имеется конечная формула без интеграла:
\[
 Z_T(d)=\frac1{\log2}\sum_{m=1}^T
 \left[\log\frac{2m+1}{2m}\ B_{m,2m}(d)
       +\log\frac{2m+2}{2m+1}\ B_{m,2m+1}(d)\right]. \tag{11}
\]
Все веса строго положительны. В этой логарифмической версии матрица НЕ рациональна. Frozen dt-версия имеет те же блоки с весом 2^(-b-1) при 2^b≤m<2^(b+1), поэтому её конечный Gram рационален. Нормы двух вариантов не смешиваются.

Если p_j=Σ_(ℓ<j)d_ℓ, блок вычисляется как
\[
 B_{m,M}=m|p_M-p_m|^2+(M-m-1)|p_M|^2
 -2\Re\left(\overline{p_M}\sum_{j=m+1}^{M-1}p_j\right)
 +\sum_{j=m+1}^{M-1}|p_j|^2. \tag{12}
\]
После трёх prefix-сумм это O(1) операций на блок; вся (11) требует O(T) арифметических операций после построения d. Это не оценка битовой сложности и не обещание численной устойчивости: для сертификатов нужны рациональная/интервальная арифметика; положительное определение B первично. Divisor-sieve для источника до T требует O(T log(N+1)) сложений. Общий период lcm(1,...,N) не перебирается.

Для истинного бесконечного источника D_N(t)=Σ_b B_(m_b,m_(b+1)) определена положительной суммой. При m≥2 частичные суммы A_N ограничены Q_N, поэтому конечное суммирование по частям даёт
\[
 \left|\sum_{\ell=j}^{M-1}d_{N,\ell}\right|\le Q_N/j,
 \qquad B_{m,M}\le2Q_N^2/m.
\]
Следовательно для B≥1
\[
 0\le D_N(t)-\sum_{b<B}B_{m_b,m_{b+1}}
              \le\frac{4Q_N^2}{2^B}, \tag{13}
\]
одновременно для всех t. Та же оценка верна после обоих усреднений. Таким образом цена действительно конечна при фиксированном N: старой logarithmic divergence по частотному cutoff больше нет.

Полная энергия имеет также ТОЧНОЕ разложение
\[
 E_N=\sum_b\|V_b\|^2+2\Re\sum_{b<c}\langle V_b,V_c\rangle. \tag{14}
\]
Оно понимается как предел конечных сумм, а не как произвольная перестановка потенциально условного двойного ряда. Теперь (6) законно оплачивает всю сумму абсолютным множителем 7. Усреднённая положительная цена не может расходиться при ограниченной E_N: dt-цена ≤10E_N, логарифмическая цена ≤15E_N. Это существенно сильнее одной конечности при фиксированном N.

## 5. Полный возврат к NB и явная цена cutoff

[FINITE_CELL / COFINAL_FAMILY | PAPER.]

Применим (4) к настоящему d_(N,1),...,d_(N,T), обозначив
\[
 \mathcal Z_{N,T}=Z_T((d_{N,\ell})_{\ell\le T}).
\]
Из (3) и неравенства ||x+r||²≤2||x||²+2||r||²:
\[
 \boxed{E_N\le14\mathcal Z_{N,T}+4Q_N^2/T,\qquad
        \mathcal Z_{N,T}\le30E_N+60Q_N^2/T.} \tag{15}
\]
Квадратный остаток задан точно: y=y^[T]+r^[T], где r_j=y_(T+1) при j≤T и r_j=y_j при j>T. Поэтому E_N=E_N^[T]+2Re⟨y^[T],r^[T]⟩+||r^[T]||². Смешанный член не забывается: именно его оплачивает множитель 2 в (15).

(15) верно для любых конечных комплексных коэффициентов a_n с тем же centering, не только для μ. Например, 14Z+4NΣ|q_n|²/T — положительная квадратичная мажоранта всей NB-нормы для всех таких входов. Для dt-версии это конечный рациональный верхний Gram; для (10) в нём присутствуют логарифмы рациональных чисел.

### 5.1. Настоящий taper: T=N², ошибка 9/log²N

Оплата source-константы не использует RH. Из Σ_(n≤x)μ(n)floor(x/n)=1 следует |Σ_(n≤x)μ(n)/n|≤2. Кроме того,
\[
 \sum_{n\le N}\frac{\mu(n)}n H_{\lfloor N/n\rfloor}=1,
 \quad |H_{\lfloor x\rfloor}-\log x-\gamma_E|\le2/x.
\]
Поэтому |L s_N|≤1+2γ_E+2<5. Сравнение убывающей суммы с интегралом даёт
\[
 \sum_{n=2}^N|a_n|\le\frac{N-1-L}{L},\qquad
 Q_N\le1+5/L+\frac{N-1-L}{L}=\frac{N+4}{L}.
\]
При N≥8 это не больше 3N/(2L). Фиксируем T=N² и пишем
\[
 \boxed{\mathcal Z_N=
 \sum_{\ell,k\le N^2}\frac{(\mathbf1_{\ell=1}-A_N(\ell))
                         (\mathbf1_{k=1}-A_N(k))}{\max(\ell,k)}
 \left(1-\frac{|\log((\ell+1)/(k+1))|}{\log2}\right)_+.} \tag{16}
\]
Настоящие коэффициенты вещественны; для общего комплексного входа первый множитель сопрягается. Balanced здесь относится к индексам тока ℓ,k, а не к исходным индексам n,m Vasyunin-Gram; оценки других balanced/unbalanced сумм сюда автоматически не переносятся. По (15), для каждого N≥8,
\[
 \boxed{E_N\le14\mathcal Z_N+9/L^2,\qquad
        0\le\mathcal Z_N\le30E_N+135/L^2.} \tag{17}
\]
Все части (16) конечны и source-defined. Это не значение E_N, переименованное после его вычисления, и не корень из неизвестной A_m. Положительность для любых входов доказана до арифметической специализации.

По сравнению с R8 cutoff N^(3/2), данный cutoff N² больше. Выигрыш здесь не в скорости расчёта или новой степени RH-ошибки, а в универсальной возможности оставить только balanced-пары. Нельзя рекламировать (17) как новый NB-rate.

## 6. Попытка оценить арифметическую часть

[FINITE_CELL | PAPER для тождеств; COFINAL_FAMILY | CONDITIONAL для нужной верхней границы.]

На начальном квадрате ℓ,k≤N точная μ-свёртка даёт часть (16)
\[
 \frac1{L^2}\sum_{\ell,k\le N}
 \frac{(Ls_N-\Lambda(\ell))(Ls_N-\Lambda(k))}{\max(\ell,k)}
                                      \kappa(\ell,k). \tag{18}
\]
Это signed prime-pair expression, включая все простые степени; целая форма положительна, отдельные cross-terms не обязаны быть положительными. После ℓ>N остаётся полная усечённая divisor-свёртка A_N(ℓ), не одна Λ(ℓ).

Разделение на индексы ≤N и >N оставляет два положительных главных блока и точный подписанный cross-term. Благодаря κ связь через эту границу может идти только между индексами порядка N: k>N и ℓ≤N требуют k≤2N и ℓ>(N−1)/2. Но эти оставшиеся связи не удалены и не оплачены автоматически. Малость мёбиусовой суммы в них не следует из geometrical blocking.

**Попробованный арифметический шаг.** Внутри каждого B_(m,M) сохранялись суммы (s_N−Λ(ℓ)/L)/ℓ при M−1≤N и полная A_N далее; после раскрытия применялись точные floor/divisor identities, а не независимые знаки пакетов. Они дали (18) и перенос cutoff (17), но не постоянный верхний bound (16). Полная периодическая CRT-ковариация из R усредняет по начальному вычету; она не равна этой фиксированной начальной форме. Неоплаченная замена одного другим не производится.

На S доступный прежний bound R8 E_N≤(290N+6)/L² даёт только
\[
 \mathcal Z_N\le(8700N+315)/L^2. \tag{19}
\]
Это не новый знаковый выигрыш и не отрицательный свидетель против ограниченности.

**Минимальная остановка:**
\[
 \exists C<\infty:\quad
      \{N\in\mathcal S:\mathcal Z_N\le C\}\text{ неограниченно}. \tag{20}
\]
(20) не доказано. По (17) это эквивалентно ограниченности E_N на неограниченной части S, а через вход H — прежней ограниченности J_N. Это не более слабая доказанная арифметическая посылка. Необходимость такого конкретного Selberg-taper условия для RH не установлена.

**Что всё-таки снято:** ранее even finite E_N могла сопровождаться бесконечной ценой fixed-width all-input оценки. Теперь построен all-input positive certificate, цена которого отличается от истинной энергии лишь абсолютным множителем и оплаченным cutoff. Значит отдельная трудность разнесённых масштабов устранена; новый сертификат не вставляет скрытое более сильное требование ограниченности.

## 7. Условная стрелка к RH — полностью, без подмены кванторов

[COFINAL_FAMILY | PAPER для импликации; (20) остаётся CONDITIONAL.]

Предположим (20). Тогда E_N≤14C+9 на выбранной неограниченной последовательности. Для каждого фиксированного k и N≥k настоящая свёртка даёт
\[
 R_N(k)=k s_N-\psi(k)/\log N\longrightarrow0.
\]
В H=ℓ²(1/[k(k+1)]) ограниченность норм и поточечный нулевой предел дают слабую сходимость к нулю: сначала проверка на конечной поддержке, затем Cauchy–Schwarz для хвоста любого фиксированного теста. Выберем подпоследовательность R_(N_j) с |⟨R_(N_i),R_(N_j)⟩|≤2^(-i-j), i<j. Тогда
\[
 e_{N_J}\le\left\|J^{-1}\sum_{j=1}^J R_{N_j}\right\|_H^2
 \le\frac{14C+9}{J}+\frac1{J^2}\longrightarrow0. \tag{21}
\]
Здесь e_N — оптимальная NB-ошибка, не энергия одного taper. Среднее остаётся допустимым приближением из исходного словаря; его коэффициенты треугольные, не запрещённый фиксированный ряд.

Обычные соседние целые дают точную изометрию J на ячейки (1/(k+1),1/k] и
\[
 Jr_n(x)=\{1/(nx)\}-\{1/x\}/n,\qquad
 \int_0^1 Jr_n(x)x^{s-1}dx=\frac{\zeta(s)}s(1/n-n^{-s}). \tag{22}
\]
Равенство сначала выводится суммированием при Re s>1; pole при 1 сокращён, а продолжение законно при Re s>0. В настоящем правом нуле ρ=β+iγ, β>1/2, Mellin-образ любого residual равен 1/ρ, поэтому
\[
 e_N\ge(2\beta-1)/|\rho|^2>0. \tag{23}
\]
Это противоречит (21); функциональная симметрия исключает и левые нули. Следовательно (20)⇒RH, но **(20) не получено**.

В этой записи нет finite-implies-global шага: одной конечной проверки (17) недостаточно. При полученном capture прежний R7 receiver можно применять к буквальным A_m; в настоящей работе нового cofinal floor для A_m не доказано.

## 8. Место арифметики и собственные ложные источники

[ABSTRACT / COFINAL_FAMILY | PAPER; существование отрицательных миров импортируется только из закреплённых предыдущих source-controls.]

Геометрическая теорема (4) специально работает для любых входов. Требовать, чтобы она сама перестала сохранять положительность в ложном мире, было бы ошибкой. Различающий шаг — соединение тока с полным источником: (2), (22), затем стандартный, а не изменённый local factor.

**DMV/Бёрлинг.** Обычный floor(x/n) и сдвиг k→k+1 в (2),(22) перечисляют обычные целые. Они не перечисляют собственные generalized integers DMV. Использовать прежний r_n как его собственный Mellin-null словарь означает заменить его ζ_B на ζ. Это точное место отказа; ему не приписывается отсутствующее completion. Для любого законного L²-null-словаря данного мира его собственный правый нуль даёт (23), что исключает bounded-pointwise-zero supplier.

**DH.** Его полный источник имеет собственные Dirichlet-коэффициенты, odd-Gamma, conductor 5 и отсутствие полюса. (22) с обычным r_n не становится тождеством с D(s) вместо ζ(s). Нужная source-match стрелка отсутствует; при корректном null-словаре с собственным правым нулём остаётся (23). Ни geometry, ни CRT обычных q_n не подменяют его коэффициенты.

**Квартет a=1/3.** Для Q(z)=((z-a)²+γ²)((z+a)²+γ²), γ>0, собственный completed source ξ_Q(s)=Q(s−1/2)ξ(s)/Q(1/2) содержит добавку Q'/Q в логарифмической производной. При сохранении стандартной Γ uncompleted factor также изменён. Старое (22) его не вычисляет. В source-correct null-словаре ρ=5/6+iγ даёт положительную границу (23); целый подписанный quartet-source не отбрасывается.

**Самодуальные v_b R6 B.** Они могут оставить обычную арифметическую ζ, изменив только Mellin local factor. Доказательство обычной RH не утверждает отсутствие дополнительных нулей Q_bξ. Завершающая стрелка требует точно
\[
 \int_0^\infty e^{-\pi x^2}x^{s-1}dx=\tfrac12\pi^{-s/2}\Gamma(s/2)
 \quad(\Re s>0),\qquad
 \xi(s)=\tfrac12s(s-1)\pi^{-s/2}\Gamma(s/2)\zeta(s). \tag{24}
\]
Подмена этого множителя положительностью/самодуальностью не разрешена.

**Контрмассив R9.** Новая geometry честно работает и на нём, но не выдаёт ложного малого сертификата. При первом изменённом n0 нарушается Σ_(d|n0)c_d=0, так что истинная head-формула (2) перестаёт выполняться. Более количественно: R9 даёт H_N^bad>N/(2·10^9 L²) при N≥10^7. Его s_N и модульная taper-граница сохранены, поэтому оплата Q_N≤(N+4)/L и (17) остаётся законной. Поскольку E_N^bad≥H_N^bad,
\[
 \mathcal Z_N^{bad}>\frac{N/(2\cdot10^9)-9}{14L^2}
                         \longrightarrow\infty. \tag{25}
\]
Значит тот же S не обманывает новый balanced-core: малая скалярная мода не делает его малым.

**Кривая над F3.** Для её собственного источника h=log3, а не для искусственно навязанного ζ-словаря,
\[
 \operatorname{Per}f(x)=\sum_{j\in\mathbb Z}(-1)^j f(x+2hj),\quad
 W_E[f]=2h\int_0^{2h}|\operatorname{Per}f(x)|^2dx
       =\sum_{j\in\mathbb Z}|\widehat f((j+1/2)\pi/h)|^2\ge0. \tag{26}
\]
Это Parseval на антипериодической ячейке. Для компактного носителя число перекрытий конечно; буквальные оконные сжатия положительны с нулевым дефектом. Общие положительные карты (4) не нарушают этот контроль. Новый аналог именно ordinary-mu condition (20) для кривой не заявляется: собственный положительный source-return уже задан (26).

## Приложение. Воспроизводимый точный судья геометрии

Python 3, стандартная библиотека. T — число Fourier-индексов, здесь 8,16,32. Код проверяет конечные матрицы и границы; доказательство для всех T находится в §3.

```python
from fractions import Fraction as F


def averaged_gram(T: int):
    if T < 1:
        raise ValueError('T must be positive')
    B = T.bit_length()
    phases = 1 << B
    M = [[F(0) for _ in range(T)] for _ in range(T)]
    for q in range(phases):
        t = F(2*phases + 2*q + 1, 2*phases)
        bounds = [int((1 << b)*t) for b in range(B+1)]
        for lo, hi in zip(bounds, bounds[1:]):
            hi = min(hi, T+1)
            if lo > T:
                break
            for i in range(lo, hi):
                for j in range(lo, hi):
                    M[i-1][j-1] += F(min(i, j), phases)
    return M


def positive_ldl(A):
    n = len(A)
    L = [[F(0) for _ in range(n)] for _ in range(n)]
    D = []
    for i in range(n):
        pivot = A[i][i] - sum((L[i][k]**2*D[k]
                               for k in range(i)), F(0))
        if pivot <= 0:
            raise AssertionError((i, pivot))
        D.append(pivot)
        L[i][i] = F(1)
        for j in range(i+1, n):
            L[j][i] = (A[j][i] - sum((L[j][k]*L[i][k]*D[k]
                                      for k in range(i)), F(0)))/pivot
    return D


for T in (8, 16, 32):
    M = averaged_gram(T)
```
