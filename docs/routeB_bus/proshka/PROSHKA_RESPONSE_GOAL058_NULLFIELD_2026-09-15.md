## 3. Вариант A: какой именно положительный вклад допустим

Пусть поле зависит от c линейно, а его энергия квадратична. Тогда \(\mathcal E[0]=V[0]=0\), поэтому тождество \(V[c]=\mathcal E[c]+C\) с фиксированным \(C>0\) невозможно уже при c=0.

Если существует отрицательная строка \(V[c_0]<0\), то
\[
V[\lambda c_0]+C=|\lambda|^2V[c_0]+C<0
\]
при достаточно большом \(|\lambda|\). Следовательно, утверждение \(V[c]+C\ge0\) для всех c не является ослабленным способом исправить знак: оно уже влечёт \(V[c]\ge0\). Эта проверка **не доказывает наличие** отрицательной V-строки. `[ABSTRACT][PAPER]`

Содержательный вариант — \(C_*W[c]\), где W построена до знания знака V. В основной конструкции ниже берём конкретную
\[
W[c]=\mathcal E_k[c]=\|\mathscr L_fu_c\|_{L^2(w)}^2.
\]
Это не произвольная новая норма из неизвестного квадратного корня V. Область универсальности \(C_*\) — все конечные списки узлов в I и все комплексные c, при одном заранее выбранном k и той же нормировке \(f=\Phi/A\). В §11 доказано: W=0 ровно на строках, у которых после объединения одинаковых узлов все коэффициенты равны нулю. Но **ни одно \(C_*>0\) не удовлетворяет \(V\ge C_*W\) на всём этом классе**, по (2).

Другие W не исключены. Само неравенство \(V+C_*W\ge0\) по-прежнему не даёт \(V\ge0\). `[ABSTRACT][PAPER]`

\boxed{0<f(u)\le C_0e^{-c_0e^{2u}}\quad(u\ge0).} \tag{4}

Для каждой фиксированной производной ряд после дифференцирования содержит конечную сумму степенных множителей по n,t перед тем же экспоненциальным членом. То же отделение частей экспоненты даёт

|f^{(j)}(u)|\le C_j e^{-c_0e^{2|u|}},\quad u\in\mathbb R,
\tag{5}

с конечным исходным \(C_j\). Для наших операций достаточно j≤2; утверждение не означает единую константу для всех j.

Для q нужна относительная, а не только абсолютная оценка. Первая положительная мода даёт

Все остальные моды сохранены в S_j; нижняя оценка первой модой используется только в знаменателе положительной полной функции.

Вводим исходную **хвостовую первообразную**
\[
\boxed{\tau(u)=\int_u^\infty t f(t)\,dt.} \tag{7}
\]
Она определена на всей вещественной прямой, гладка, положительна и чётна. Действительно, \(tf(t)\) нечётна и абсолютно интегрируема, так что \(\tau(-u)=\tau(u)\); при u≥0 её положительность непосредственна. Также

### 5.2. Профили, заданные до выбора коэффициентов

\[
\boxed{

\begin{pmatrix}f(X+x)\\-\tau(X+x)\end{pmatrix},\quad x\in J.
} \tag{11}
\]
Закон k не зависит от N, c или результата измерения V. Основной KILL ниже требует, чтобы k была вещественно-аналитической на всём J; сначала сама формула имеет смысл при любом k(x)>0.

A_c(X,Y)=\sum_i c_i e^{-k_iY}f(X+x_i),\quad
T_c(X,Y)=\sum_i c_i e^{-k_iY}\tau(X+x_i),

\[
\widetilde Q_c(X,Y)=\sum_i c_i e^{-k_iY}(X+x_i)f(X+x_i),
\qquad k_i=k(x_i),\qquad v_c=(A_c,-T_c).
\tag{12}
\]
Буква T_c обозначает поле первообразных, не Brownian total energy из прежних отчётов.

Поле имеет **точные исходные граничные данные**
\[
v_{c,1}(X,0)=P_c(X),\qquad
\partial_Xv_{c,2}(X,0)=Q_c(X).
\tag{13}
\]
Второе равенство использует \(\tau'(u)=-uf(u)\), включая отрицательные u. Таким образом, исходная V заранее фиксирована как нижний граничный поток этой конструкции. Это не подбор поля под знак каждой строки.

&=-\Re\int_0^\infty v_{c,1}(0,Y)\overline{\partial_Yv_{c,2}(0,Y)}\,dY\\
&\quad+\Re\int_0^\infty v_{c,1}(X,0)\overline{\partial_Xv_{c,2}(X,0)}\,dX\\
&=\frac12\bigl(V[c]-\mathcal B_k^X[c]\bigr).
\end{aligned} \tag{17}
\]
Угловой атом не возникает: сначала используется гладкое поле на замкнутом конечном прямоугольнике, не распределительная производная его нулевого продолжения.

Идентичность \(Q_f+2J_f=|D_Xu_1+\partial_Yu_2|^2\) теперь даёт (1). В отличие от компактного внутреннего поля из Z5, **полный интеграл null-плотности здесь не обязан равняться нулю**. Именно (17) — его правильный граничный вариант. `[ABSTRACT][PAPER]`

### 6.1. Обычные производные не подменяют D_X

Буквально сохраняем поправку задания:
\[
\begin{aligned}
\mathcal T_q[c]:=\int_\Omega w\{&2q\Re(\partial_Xu_1\overline{u_1})+q^2|u_1|^2\\
&+2q\Re(\partial_Yu_1\overline{u_2})\}.
\end{aligned} \tag{18}
\]
Все её отдельные члены абсолютно интегрируемы по §5.3. В физических компонентах это
\[
\mathcal T_q=\int_\Omega
\left(2q\Re(A_X\overline A)-q^2|A|^2-2q\Re(A_Y\overline T)\right).
\tag{19}
\]
Значит \(\mathcal S_k=\int wQ_0[u_c]+\mathcal T_q[c]\), и ещё одна буквальная запись полного результата:
\[
\boxed{V[c]=\mathcal E_k[c]-\int_\Omega wQ_0[u_c]-\mathcal T_q[c]+\mathcal B_k^X[c].}
\tag{20}
\]
Смена знака у q² в (19) не ошибка: в обычной производной \(\partial_Xu_1=(A_X-qA)/f\) уже присутствует −qA.

| Слагаемое | Его точная роль | Знак |
|---|---|---|
| \(\mathcal E_k\) | Полный квадрат дивергенции (14) | ≥0 |
| \(-\int wQ_0\) | Необходимый обычный объёмный член | Не назначен |
| \(-\mathcal T_q\) | Все три поправки к обычным производным | Не назначен |
| \(\mathcal B_k^X\) | Сохраняемый след X=0 | Не назначен |
| Поток Y=0 | Ровно V/2 до умножения на 2 | Исходная цель |
| X=∞, Y=∞ | Полные предельные потоки | Ровно 0 |

Все строки таблицы имеют область `[ABSTRACT]` и verifier `[PAPER]`. Положительность первой строки не превращает сумму остальных в положительную границу.

### 6.2. Равенство на уровне каждого смешанного ядра

Пишем \(f_x(X)=f(X+x)\), \(\tau_x(X)=\tau(X+x)\) и \(d_x(X)=f'(X+x)+k_x\tau(X+x)\). Интегрирование по Y даёт
\[
E_k(x,y)=\frac1{k_x+k_y}\int_0^\infty d_x(X)d_y(X)\,dX,
\tag{21}
\]
\[
\begin{aligned}
S_k(x,y)=\frac1{k_x+k_y}\int_0^\infty\{&f'_x f'_y+k_xk_y\tau_x\tau_y\\
&-[k_x(X+y)+k_y(X+x)]f_xf_y\}\,dX,
\end{aligned} \tag{22}
\]
\[
B_k^X(x,y)=\frac{k_y f(x)\tau(y)+k_x\tau(x)f(y)}{k_x+k_y}.
\tag{23}
\]
Нужная проверка коэффициентов:
\[
\int_0^\infty f'_x\tau_y
=-f(x)\tau(y)+\int_0^\infty(X+y)f_xf_y.
\]
Применяя её к обоим смешанным членам (21), получаем **буквально**
\[
\boxed{V(x,y)=E_k(x,y)-S_k(x,y)+B_k^X(x,y),\qquad x,y\in J.} \tag{24}
\]
Каждая матрица вещественна и симметрична. Умножение на \(\overline c_i c_j\) и конечное суммирование дают (1) для всех комплексных фаз. Здесь нет ограничения на знак \(\Re(\overline c_i c_j)\), common-phase класса или число узлов. `[ABSTRACT][PAPER]`

## 7. Первый отказ и настоящий ремонт внутри той же конструкции

При первоначальном k(x)=−σx, σ>0, возьмём один узел x=−ε, ε↓0. Из (21)
\[
2\sigma\varepsilon E_k(-\varepsilon,-\varepsilon)
=\int_{-\varepsilon}^\infty[f'(u)+\sigma\varepsilon\tau(u)]^2du
\longrightarrow\int_0^\infty f'(u)^2du>0.
\tag{25}
\]
Предел оплачен доминированием через \(f'^2+\tau^2\) на [−ε₀,∞). В то же время \(V(-\varepsilon,-\varepsilon)\to V(0,0)<\infty\). Следовательно, остаток V−E уже отрицателен на достаточно малых допустимых отрицательных одиночных сдвигах. Это отказ естественной незазорной Laplace-координаты, не отрицательный знак V. `[COFINAL_FAMILY][PAPER]`

Ремонт — добавить положительное затухание \(k(x)=\delta-\sigma x\), δ>0. Тогда знаменатель в (21) имеет конечный ненулевой предел при x↑0, и прежний взрыв исчезает. Такой ремонт действительно исправляет (25); прежний аргумент против него не применяется.

Но следующий полный тест ниже исключает **и этот ремонт**, и любой положительный вещественно-аналитический k на J. Он не использует (25), не оставляет исчезающий знаменатель и не предполагает, что k ограничена или имеет какой-либо заданный предел. `[ABSTRACT][PAPER]`

## 8. Решающий полный бюджет: поле не затухает там, где V затухает

Определим до выбора k или строки две исходные константы
\[
A_1=\int_{-1}^{1}f'(u)^2du>0,\qquad
B_1=\int_{-1}^{1}\tau(u)^2du>0,\qquad
\kappa_f=\sqrt{A_1B_1}>0.
\tag{26}
\]
Положительность B₁ следует из τ>0. Если A₁=0, аналитическая f постоянна на интервале, затем на всей прямой, что несовместимо с (4) и f>0. Эти константы не используют знак V, его нули или неизвестную спектральную меру.

Для x=−R, R≥1, обозначим \(\lambda=k(-R)>0\). В (21) весь интервал u∈[−1,1] входит в интеграл. Поскольку f′ нечётна, а τ чётна,
\[
\int_{-1}^{1}f'(u)\tau(u)du=0.
\]
Поэтому
\[
\boxed{
E_k(-R,-R)\ge\frac{A_1}{2\lambda}+\frac{\lambda B_1}{2}
\ge\sqrt{A_1B_1}=\kappa_f.
} \tag{27}
\]
Последнее неравенство — точный квадрат
\((\sqrt{A_1}-\lambda\sqrt{B_1})^2/(2\lambda)\ge0\).
**Нижняя граница едина для всех λ>0**, даже если λ зависит от R или от полного источника. Смешанный член не оценён грубо: он занулился на симметричном подинтервале по точной чётности. Остальной интеграл квадрата неотрицателен.

У исходной диагонали, напротив, чётность сохраняет полное сокращение:
\[
0<V(-R,-R)=2\int_{-R}^\infty u f(u)^2du
=2\int_R^\infty u f(u)^2du.
\tag{28}
\]
Из (4), заменой s=e^{2u},
\[
\boxed{
V(-R,-R)\le D_0e^{-2c_0e^{2R}},\qquad
D_0=\frac{C_0^2}{4c_0}.
} \tag{29}
\]
Здесь снова использовано \(\log s/s\le1\). Весь хвост входит в правую часть.

Для каждого C_*>0 можно взять явный исходно определённый порог
\[
\boxed{
R_{C_*}=1+\frac12\log\left(1+\frac1{2c_0}
\log\left(1+\frac{2D_0}{C_*\kappa_f}\right)\right)>1.
} \tag{30}
\]
Для R≥R_{C_*} правая часть (29) строго меньше \(C_*\kappa_f/2\). Следовательно,
\[
\boxed{
V(-R,-R)-C_*E_k(-R,-R)<-\frac{C_*\kappa_f}{2}<0.
} \tag{31}
\]
Это **строгая отрицательная верхняя огибающая полного остатка**, а не провал его достаточной оценки. Она действует на всей указанной отрицательной полуоси и равномерно по положительным значениям k. Порог (30) не вычислялся численно; его константы заданы положительными полными source-интегралами и сходящимся рядом, независимо от искомого знака. `[COFINAL_FAMILY][PAPER]`

В частности, поле платит ненулевую цену за прохождение через симметричную центральную область, тогда как исходная V там сохраняет точное нечётное сокращение. Нельзя удалить это сокращение при сопоставлении энергий.

## 9. Почему далёкий отрицательный остаток относится к исходному интервалу I

Сам по себе узел −R из (31) не принадлежит I. Нужен отдельный all-rank перенос, который мы сейчас оплачиваем для **остатка**, не для V.

Пусть k положительна и вещественно-аналитична на J=(−∞,0). Она имеет голоморфное продолжение в некоторое открытое связное множество O, содержащее J. Сужая окрестности вещественной оси, можем потребовать
\[
O\subset\mathfrak S,\qquad \Re k(z)>0\quad(z\in O).
\]
Согласованность локальных продолжений следует из теоремы тождественности; можно использовать достаточно узкую объединённую окрестность самого интервала J.

На O×O определим аналитические ядра (21) и V, **без сопряжений в комплексных переменных**. Знаменатель \(k(z)+k(w)\) не равен нулю. Мажоранты (9) на каждом компактном произведении оплачивают локально равномерную сходимость X-интегралов. Поэтому
\[
R_{k,C_*}(z,w):=V(z,w)-C_*E_k(z,w)
\tag{32}
\]
голоморфно на O×O и вещественно-симметрично на J×J. В частности, возможные комплексные нули f не создают здесь деления: в (21) нет 1/f.

### Лемма распространения, с сохранёнными смешанными узлами

Если такое ядро K положительно полуопределено для **всех** конечных комплексных строк на непустом открытом подинтервале I⊂J, то оно положительно полуопределено на всём J.

Доказательство. Пусть положительность уже известна на открытом интервале B. Выбери a∈B и комплексный диск радиуса η внутри O. Для каждого фиксированного конечного порядка M прямые разности
\[
\ell_{n,h}=\frac1{n!h^n}\sum_{j=0}^n(-1)^{n-j}\binom nj\operatorname{ev}_{a+jh},\quad 0\le n\le M,
\]
при малом h>0 используют только узлы B. Добавь к ним произвольное конечное число старых узлов из B. Применение этих функционалов к обеим переменным — конечная конгруэнция положительной матрицы. При h→0 она даёт положительную смешанную матрицу старых значений и нормированных производных в a.

Новые значения в |y−a|<η заменяем конечными Taylor-функционалами \(\sum_{n\le M}(y-a)^n\partial^n/n!\). Их конечные матрицы положительны. При M→∞ они сходятся к истинным матрицам: новые/новые элементы — по двойному Taylor-ряду в полидиске; старые/новые — по однопеременному ряду при фиксированном старом узле. Один и тот же радиус работает для этих элементов, поскольку область имеет вид O×O. Итак, положительность распространяется на объединение B с новым интервалом, **включая все смешанные старые/новые строки**.

Каждый вещественный отрезок, соединяющий исходный I с заданной конечной группой узлов J, компактен в O. Покрывая его конечной цепью таких дисков, получаем нужную положительность. Порядок пределов: сначала h→0 для фиксированного M, затем M→∞. Ни ограниченный обратный оператор, ни равномерная оценка по rank не предполагаются. □ `[ABSTRACT][PAPER]`

Применение леммы к (32): если бы \(V[c]\ge C_*\mathcal E_k[c]\) для всех строк в I, то то же выполнялось бы на J. Это противоречит (31). Следовательно, (2) доказано.

**Что известно о локальном свидетеле:** конечный rank, узлы и коэффициенты существуют; их численные значения и верхняя граница rank не получены. Это аналитическая контрапозиция all-rank теоремы. Далёкий явный одновузловой свидетель (31) нельзя выдавать за одновузловой свидетель внутри I. `[ABSTRACT][PAPER]`

## 10. Точная область отказа после ремонта

Основное заключение имеет кванторы
\[
\boxed{
\forall k\in C^\omega(J;(0,\infty))\ \forall C_*>0\
\exists n\ge1,\ x_1,\ldots,x_n\in I,\ c\in\mathbb C^n:\
V[c]-C_*\mathcal E_k[c]<0.
} \tag{33}
\]
Таким образом, положительный offset δ исправляет только локальную дивергенцию (25), но не необходимый для всей конструкции знак полного остатка. Произвольная исходно-зависимая аналитическая скорость k на J тоже не исправляет его. Область k в (33) явно важна: функция, заданная только на I и не допускающая такого продолжения, этим доказательством не исключена.

При C_*=1 первый переход к желаемому положительному тождеству был бы
\[
\mathcal B_k^X[c]-\mathcal S_k[c]\ge0\quad\text{для всех строк в I}.
\tag{34}
\]
Теперь это не просто неоплаченный вход: **(34) ложно** для данного подъёма. Для произвольного C_* соответствующая полная поправка равна
\[
\mathcal R_{k,C_*}
=\mathcal B_k^X-\mathcal S_k+(1-C_*)\mathcal E_k;
\quad V=C_*\mathcal E_k+\mathcal R_{k,C_*}.
\tag{35}
\]
Её знак также опровергнут (33).

Нулевая поправка вида \(v\mapsto v+(\partial_Y\psi,-\partial_X\psi)\), с допустимыми производными и сохранённым исходным граничным потоком, не помогает: дивергенция и \(\mathcal E_k\) не меняются. Значит V−C_*E тоже не меняется. В частности, это верно для гладких ψ компактного носителя внутри Ω. Перераспределение S и B не может изменить знак их полной комбинации.

Добавление других **неотрицательных** энергий при сохранении положительного коэффициента перед E лишь усиливает требование \(V\ge C_*E\), уже опровергнутое. Иная конструкция, где дивергенция реально изменяется и старый положительный квадрат не сохраняется как слагаемое, не исключена. Узлонезависимые следы (13) фиксируют нормировку именно этого поля; произвольное узловое масштабирование меняет тот граничный поток и требует нового точного учёта. `[ABSTRACT][PAPER]`

## 11. W действительно положительна; контроль f0 не перепутан с theta

### 11.1. Нулевые направления построенной W

После объединения повторов узлы различны. Если E_k[c]=0, то
\[
\sum_i c_i e^{-k_iY}\bigl(f'(X+x_i)+k_i\tau(X+x_i)\bigr)=0
\]
почти всюду, затем по непрерывности всюду в Ω. Сгруппируем равные k_i. Линейная независимость конечного набора различных экспонент по Y даёт для каждой группы со скоростью λ>0
\[
\sum_{i:k_i=\lambda}c_i h_\lambda(X+x_i)=0,\qquad
h_\lambda(u)=f'(u)+\lambda\tau(u).
\]
По аналитичности это равенство продолжается на все вещественные X. Функция h_λ принадлежит L¹ и
\(\int_{\mathbb R}h_\lambda=\lambda\int\tau>0\).
Её Fourier integral непрерывен и не равен нулю на некоторой окрестности частоты 0. Интегрирование последнего равенства против \(e^{-i\omega X}\), с законной конечной перестановкой, даёт
\(\sum c_i e^{i\omega x_i}=0\) на этой окрестности. Производные при ω=0 и невырожденность конечной матрицы Вандермонда дают все c_i=0. Таким образом,
\[
\boxed{W[c]>0\quad\text{для каждой ненулевой строки после объединения повторов}.}
\tag{36}
\]
Это только положительность **построенной** формы, не V. В доказательстве даже не нужна теорема обращения Fourier: достаточно одного интеграла и его ненулевого значения в нуле. `[ABSTRACT][PAPER]`

### 11.2. Обязательный отрицательный контроль

Для \(f_0(u)=e^{-u^2}-e^{-2u^2}/4\) тот же подъём определён, с собственной явно вычисленной
\[
\tau_0(u)=\tfrac12e^{-u^2}-\tfrac1{16}e^{-2u^2}>0.
\tag{37}
\]
Не вводится никакой выдуманной условной theta-плотности для f0. Контроль C, R11–R12, уже даёт допустимые четыре отрицательных узла \((-h,-2h,-3h,-4h)\) с конечными коэффициентами функционала
\[
L_h=\frac{\operatorname{ev}_{-h}-3\operatorname{ev}_{-2h}+3\operatorname{ev}_{-3h}-\operatorname{ev}_{-4h}}{h^3}
+\frac{25}{3h}(\operatorname{ev}_{-h}-\operatorname{ev}_{-2h}),
\]
и \(V_0[L_h]\to-25/162\) при h↓0. Эта проверка заново не выполнялась. При малом h все узлы входят в I.

Для данного поля E_{0,k}≥0, а тождество (24) сохраняется. Поэтому на этой принятой строке
\[
B^X_{0,k}[L_h]-S_{0,k}[L_h]
=V_0[L_h]-E_{0,k}[L_h]<0.
\tag{38}
\]
**Точная невыполненная предпосылка — неотрицательность полного гранично-объёмного остатка (34).** Null-identity, область поля и полное равенство не ломаются.

Но эта же предпосылка не прошла проверку и для самой theta, по (33). Поэтому данный подъём **не поставляет различающее положительное свойство theta**. Полный theta-ряд реально использован в (4)–(9), (29) и в аналитической области; механизм отрицательного вывода (27) шире theta и опирается на чётность и ненулевую центральную энергию. Это не новая теорема, выводящая знак из additive TN или просто из положительной плотности. `[ABSTRACT][PAPER]`

## 12. Что сохраняется и какой необходимый тест получен для других полей

Принятые положительность всех двухузловых V-семейств, ограничения старых K_s-слоёв, точные NULLVAR-границы и невозможность прежнего common Fourier multiplier не пересматриваются. Ни один из этих старых no-go не является доказательством (33); его доказательство дано выше для нового явного поля.

Из §9 следует полезный **необходимый тест**, не новая достаточная RH-гипотеза. Пусть другой положительный field-Gram K_E допускает ту же продуктовую аналитическую область над J, и \(V-K_E\) положителен на всех конечных строках I. Тогда его знак распространяется на J, и обязательно
\[
\boxed{0\le K_E(-R,-R)\le V(-R,-R)\le D_0e^{-2c_0e^{2R}}.} \tag{39}
\]
Это проверка соответствия **энергии**, а не только её граничных значений. У нашего поля (27) нарушает её с фиксированным положительным запасом. Для другого поля (39) может выполняться; такое выполнение ещё не доказывает весь смешанный знак.

Здесь не установлены ни общая невозможность положительного поля, ни отрицательная V-строка, ни невещественный нуль xi. Полный положительный перенос за пределами проверенного класса остаётся **RESEARCH_DEBT**. **Самое сильное возражение: далёкий узел не лежит в I.** Верно, поэтому (31) сам по себе недостаточен. §9 отдельно доказывает аналитичность именно V−C_*E и распространение всех смешанных конечных матриц. Не устанавливается размер локальной отрицательной строки.

**«Отрицательная поправка означает отрицательную V?»** Нет: V=E+R, E≥0. Уже в (31) исходная одновузловая V строго положительна. Отрицательный результат касается заявленного положительного split.

**«Ты взял более широкий класс k?»** Да, для ремонта внутри одной формулы (11). Основной явный кандидат k=−x и ремонт k=1 уже принадлежат классу. No-go не требует угадывать оптимальный k.

**«Почему не обнулить поле и положить B=V?»** Тогда положительность B — исходная неоплаченная задача. Это не конструктивная положительная энергия и не новый результат.

**«Можно занулить ненужный объёмный член null-поправкой?»** Полная дивергенционная формула (17) сохраняет V и B одновременно. Если дивергенция не меняется, её энергия не меняется; если меняется, требуется новая проверка source-fit. Отрицательный R нельзя удалить без изменения тождества.

## Appendix A. Точная калибровка инструмента

Проверки ниже используют только целые числа и `fractions.Fraction`. Они проверяют один комплексный jet и ориентацию сторон на одном полиномиальном поле; theta и V не вычисляются. Универсальные доказательства находятся в основном тексте.

Для воспроизведения сохрани блок в `check_algebra.py` и выполни `python check_algebra.py`. В шаблоне `python {папка}/check_algebra.py` подставь свой каталог, например `python /tmp/nullfield/check_algebra.py`. Переменные в самом тесте — фиксированная рациональная калибровка, не узлы theta.

```python
"""One exact rational jet calibration; no theta evaluation or quadrature."""
from fractions import Fraction as F

# Complex scalars as pairs of rational numbers, without floating point.
def z(a, b=0): return (F(a), F(b))
def add(a, b): return (a[0]+b[0], a[1]+b[1])
def sub(a, b): return (a[0]-b[0], a[1]-b[1])
def sc(q, a): return (q*a[0], q*a[1])
def norm2(a): return a[0]*a[0]+a[1]*a[1]
def real_pair(a, b): return a[0]*b[0]+a[1]*b[1]

u1,u2,x1,y1,x2,y2=z(2,1),z(-1,3),z(4,-2),z(1,2),z(-3,1),z(2,-1)
q=F(3,5)
d1=add(x1,sc(q,u1)); d2=add(x2,sc(q,u2))
Q0=norm2(x1)+norm2(y2)+2*real_pair(y1,x2)
Qf=norm2(d1)+norm2(y2)+2*real_pair(y1,d2)
Jf=real_pair(d1,y2)-real_pair(y1,d2)
price=2*q*real_pair(x1,u1)+q*q*norm2(u1)+2*q*real_pair(y1,u2)
assert Qf+2*Jf==norm2(add(d1,y2))
assert Qf-Q0==price
assert price != 0
print('COMPLEX_NULL_SQUARE_IDENTITY: PASS')
print('FULL_Q_CORRECTION: PASS; omitted_price='+str(price))

# Exact boundary flux for v1=X+2Y+1, v2=3X-Y+2 on [0,1]^2.
right,left,top,bottom=-F(3),F(2),-F(21,2),F(9,2)
J=F(-7); Q=F(14)
assert right+left+top+bottom==J
assert Q+2*J==0
assert bottom != J
print('FOUR_ORIENTED_BOUNDARIES: PASS; full_J=-7; bottom_only=9/2')

# Kernel coefficient after two exact integrations by parts.
kx,ky,X,x,y=F(2),F(3),F(5,7),-F(1,4),-F(1,8)
left_coefficient=ky*(X+y)+kx*(X+x)+kx*(X+y)+ky*(X+x)
right_coefficient=(kx+ky)*(2*X+x+y)
assert left_coefficient==right_coefficient
print('KERNEL_E_MINUS_S_PLUS_BOUNDARY: PASS')

# AM-GM lower envelope uses a nonnegative square, not a fitted constant.
a,b,k=F(4),F(9),F(5,2)
assert a/(2*k)+k*b/2-F(6)==(F(2)-k*F(3))**2/(2*k)
print('SYMMETRIC_WINDOW_ENERGY_LOWER_ENVELOPE: PASS')
print('THETA_EVALUATIONS=0; QUADRATURES=0; SOURCE_GRIDS=0; LEAN_RUNS=0')
```
