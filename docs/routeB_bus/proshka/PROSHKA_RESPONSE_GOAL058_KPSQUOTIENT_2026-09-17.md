## 3. Буквальный источник и бюджеты, независимые от знакового вывода

Сохраняем

    r(t)=sum_(n>=1)(4pi^2 n^4 t-6pi n^2)exp(-pi n^2 t),
    Phi(x)=exp(5x/2)r(exp(2x)), q=Phi/Z, Z=int_R Phi>0,
    rho(s)=q(sqrt(s)), M(p)=int_0^infinity s^(p-1)rho(s)ds,
    D(u)=M(u+1/2), N(u)=int_0^infinity s^(u-1/2)(-rho'(s))ds,
    phi_*(u)=4N(u)/D(u).                                 (KQ3)

Здесь s>0 и степенные множители используют вещественный log s. q — L1-нормировка, тогда как физическая V по-прежнему использует f=Phi/||Phi||_2. Никакого нового ядра вместо V не вводится. `[ABSTRACT][PAPER]`

Для каждой фиксированной производной j полный theta-ряд на x>=0 даёт при t=exp(2x)>=1

    |q^(j)(x)| <= C_j t^(j+9/4) exp(-pi t)
                    *sum_(n>=1)n^(2j+4)exp(-pi(n^2-1))
                <= C'_j exp(-pi t/2).                  (KQ4)

Константы конечны: фиксированный многочлен от n интегрируем против гауссова ряда, а sup_(t>=1)t^(j+9/4)exp(-pi t/2)<infinity. Производные theta-слагаемых имеют именно такой максимальный порядок; меньшие степени поглощаются при n,t>=1. Чётность оплачивает другой вещественный конец. Это оценки полного ряда, не замена первым слагаемым.

Отсюда для каждого j у rho^(j)(s) при s>=1 имеется оценка C''_j exp(-c_j exp(2sqrt(s))), c_j>0. Дифференцирование по s создаёт лишь конечные степенные множители и производные q. У s=0 все эти производные ограничены, поскольку чётная голоморфная q задаёт сходящийся степенной ряд по s. Поэтому все используемые интегралы с фиксированными степенями и логарифмами сходятся на своих явно указанных полуплоскостях. В частности h rho=-rho', где h=-rho'/rho, оплачивает интегралы с одним h без предположения, что h ограничена.

Для последующего комплексного продолжения можно взять полностью исходную константу

    C_*=(1/Z) sum_(n>=1)
       (4pi^2 n^4 exp(3)+6pi n^2 exp(5/3))
       *exp[-pi n^2 exp(-4/3)cos(4/3)] < infinity.       (KQ5)

Она ограничивает |q(z)| на |z|<=2/3: Re exp(2z)>=exp(-4/3)cos(4/3)>0. Следовательно rho голоморфна на |s|<4/9, ограничена там C_* и её производная на |s|<=1/4 ограничена C_1=(36/7)C_* по Cauchy. Чётность снимает выбор корня, в том числе s=0.

Для c_k=rho^(k)(0)/k!, delta=1/8 и любого целого m>=1 имеем на 0<=s<=delta

    |rho(s)-sum_(k<m)c_k s^k| <= 2C_*(4s)^m,
    |-rho'(s)-sum_(k<m)(-(k+1)c_(k+1))s^k|
                                  <=2C_1(4s)^m.        (KQ6)

Это обычные Cauchy-оценки на радиусе 1/4 с отношением 4s<=1/2. Все константы определены до любого возможного нуля D. `[ABSTRACT][PAPER]`

## 4. Полная положительная область знаменателя

В этом разделе используется уже принятая строгая вогнутость log rho(s). Она делает h(s)=-rho'(s)/rho(s) строго возрастающей. Для p>0 положим

    A(p)=pM(p)/M(p+1),
    dP_p(s)=s^(p-1)rho(s)ds/M(p).                       (KQ7)

Интегрирование производной s^p rho(s) сохраняет оба конца: у нуля p>0, у бесконечности действует (KQ4). Поэтому

    A(p)=E_(P_(p+1)) h(S),
    A'(p)=Cov_(P_(p+1))(h(S),log S)>0.                  (KQ8)

Дифференцирование законно по (KQ4); строгий знак следует из двух независимых копий и положительности плотности. Это применение известной вогнутости, не новая theta-вогнутость.

Сравниваем A(p+1)>A(p). Оно даёт

    M(p)M(p+2)/M(p+1)^2 < (p+1)/p.

При m_p=E_(P_p)S=M(p+1)/M(p), R=S/m_p отсюда следует

    E R=1,  E(R-1)^2<1/p.                              (KQ9)

Теперь при вещественном tau

    M(p+i tau)/(M(p)m_p^(i tau))=E exp(i tau log R).

На |R-1|<=1/2 имеем |log R|<=2|R-1|, а на дополнении модуль разности двух единичных фаз не больше 2. Cauchy–Schwarz и Chebyshev дают

    |E exp(i tau log R)-1|
      <=2|tau|E|R-1|+2P(|R-1|>1/2)
      <=2|tau|/sqrt(p)+8/p.                            (KQ10)

Подстановка p=a+1/2 доказывает (KQ1). Если p>=64(1+tau^2), первое слагаемое не больше 1/4, второе не больше 1/8. Обратное треугольное неравенство даёт (KQ2). Нулевой tau также покрыт; фактически при нём нормированное отношение равно 1 точно. Граница параболической области включена. `[ABSTRACT][PAPER]`

**Предел действия:** (KQ2) доказывает знак нижней огибающей только для |D|, не для Im phi, не для производных phi и не для V. Вне этой области нули не объявляются существующими. Даже полная безнулевость D в исходной полуплоскости не была бы доказательством B_P1.

## 5. Мероморфное продолжение и правильная сдвиговая формула

Для Re u>-m-1/2 определим продолжение D формулой

    int_delta^infinity s^(u-1/2)rho(s)ds
    +int_0^delta s^(u-1/2)[rho(s)-sum_(k<m)c_k s^k]ds
    +sum_(k<m)c_k delta^(u+k+1/2)/(u+k+1/2).             (KQ11)

Вторая строка сходится с полным бюджетом (KQ6); первая цела по u благодаря нижней положительной границе и (KQ4). Те же оценки с |log s|^j дают локальную голоморфность. На пересечениях формулы согласованы, поскольку равны исходному интегралу при Re u>-1/2. Получаем мероморфную D на всей C. Возможные полюса — только u=-k-1/2, простые, с вычетом c_k; при c_k=0 соответствующего полюса нет. Аналогично N имеет там вычет -(k+1)c_(k+1). В частности обе функции голоморфны во всей открытой верхней полуплоскости. `[ABSTRACT][PAPER]`

На исходной области интегрирование по частям даёт

    N(u+1)=(u+1/2)D(u), Re u>-1/2.

По тождественности мероморфных продолжений

    N(v)=(v-1/2)D(v-1)                                (KQ12)

на всей C. Нельзя подставлять в эту формулу расходящийся исходный интеграл вместо продолжения. Например, при v=1/2 получаем N(1/2)=rho(0)>0: нуль линейного множителя устраняет полюс D(-1/2), а не зануляет N.

Следовательно в любой точке, где D(v) не ноль и нет полюсов,

    phi_*(v)=4(v-1/2)D(v-1)/D(v).                      (KQ13)

Для верхней полуплоскости возможны только нули знаменателя; отрицательные полуцелые границы интегралов туда не входят.

## 6. Нуль D: сокращение не делает тест безрезультатным

### 6.1. Конечный перенос к нулю самой phi

Предположим, что установлена хотя бы одна точка u0 с Im u0=tau>0 и D(u0)=0. Это ПОСЫЛКА данного пункта, не полученный theta-свидетель.

По (KQ2) D(u0+j) не равно нулю при всех достаточно больших целых j>=0. Например, достаточно Re u0+j+1/2>=64(1+tau^2). Множество

    J={j>=0 integer: D(u0+j)=0}

поэтому конечно и непусто. Пусть j_* — его максимальный элемент и v=u0+j_*+1. Тогда

    D(v-1)=0, D(v)!=0, Im v=tau>0.

Формула (KQ13) показывает: phi_* голоморфна около v и phi_*(v)=0. Если нуль D в v-1 имеет порядок m, то нуль phi_* в v имеет ТОЧНО тот же порядок m: v-1/2 не ноль, D(v) не ноль. Не требуются ни простота, ни отсутствие сокращения в исходной точке u0. `[ABSTRACT][PAPER; условный тест]`

Непостоянная Pick-функция не может иметь внутренний нуль в верхней полуплоскости: её неотрицательная гармоническая мнимая часть по принципу минимума либо строго положительна, либо функция постоянна и вещественна. Строгое возрастание phi_* на положительной оси исключает постоянство. Поэтому

    any nonreal zero of the continued D
       ==> phi_* is not Pick ==> phi_* not in B_P1.     (KQ14)

Нижние невещественные нули отражаются вверх, поскольку D(conj u)=conj D(u). Утверждение покрывает ВСЮ C вне вещественной оси, а не только исходную интегральную полуплоскость. Оно не выводит наличие невещественного нуля из отсутствия доказательства безнулевости.

### 6.2. Строгая отрицательная огибающая, если посылка будет оплачена

Пусть v,m получены выше, a_m=phi_*^(m)(v)/m! !=0. Выберем R>0 так, чтобы замкнутый диск |z-v|<=R лежал в верхней полуплоскости и не содержал нулей D. Пусть B_R=max_(|z-v|=R)|phi_*(z)|>0. Для 0<r<=R/2 Cauchy даёт

    |phi_*(v+r exp(i theta))-a_m r^m exp(i m theta)|
                       <=2B_R r^(m+1)/R^(m+1).

Выбираем дополнительно r<=|a_m|R^(m+1)/(4B_R) и угол с a_m exp(i m theta)=-i|a_m|. Тогда

    Im phi_*(v+r exp(i theta)) <=-|a_m|r^m/2<0.         (KQ15)

Так оплачивается необходимый строгий отрицательный знак, без выдуманных координат. Все параметры в (KQ15) зависят от ПОКА НЕ НАЙДЕННОГО u0. Эта условная формула не является действительным отрицательным сертификатом theta в текущем отчёте.

### 6.3. В исходной полуплоскости нуль D исключил бы даже BF

Обычная ненулевая Bernstein-функция имеет представление

    phi(z)=kappa+d z+int_(0,infinity)(1-exp(-z r))nu(dr),
    kappa,d>=0, int min(1,r)nu(dr)<infinity.

Оно голоморфно при Re z>0 и даёт

    Re phi(a+i tau)>=phi(a)>0, a>0.                    (KQ16)

Здесь не используется Pick. Малые r оплачиваются O(r), большие — ограниченностью экспоненты на компактных подмножествах этой полуплоскости.

Если Im u0>0 и Re u0>-1/2, то полученный в §6.1 v имеет Re v>1/2. Его нуль противоречит (KQ16) для любого гипотетического BF-интерполянта: принятый preflight заставляет его совпасть с phi_* на положительной оси, а тождественность даёт phi D=4N на правой полуплоскости, в частности около v. Следовательно

    a zero of D in Re u>-1/2
       ==> no ordinary BF interpolation of the exact b_n. (KQ17)

На вещественной части этой области D уже строго положительна. Итак, для возможной BF-интерполяции D должна быть безнулевой во ВСЕЙ исходной интегральной полуплоскости. Первоначальный тест «D=0, N!=0» был достаточным; (KQ17) не требует N!=0 в первоначальной точке. Нельзя переносить (KQ17) на Re u<=-1/2 для BF: там остаётся только Pick-вывод (KQ14).

## 7. Проверка оставшегося знака без удаления смешанной части

Фильтр нулей не доказывает нужную принадлежность. Запишем отдельно первый неоплаченный вещественный шаг. При u>0 и dP_u=s^(u-1/2)rho(s)ds/D(u), L=log S, H=h(S), дифференцирование полного отношения даёт

    phi_*''(u)=4 E_u[(H-E_u H)(L-E_u L)^2].              (KQ18)

Все интегралы с H оплачиваются rho' и (KQ4), включая логарифмы у нуля. Возрастание H и L доказывает ковариацию первого порядка, но не знак (KQ18). **Неравенство (KQ18)<=0 для каждого u>0 — первый Bernstein-знак после уже принятого phi_*'>0, который здесь не оплачен.** Ни его нарушения, ни его универсального выполнения я не доказал.

Есть также точный комплексный дискриминатор. Для a>-1/2, tau>0 и D(a+i tau)!=0 положим

    W_a(r)=exp((a+1/2)r) int_0^infinity t^(2a)
      rho(t exp(r))rho(t)[h(t exp(r))-h(t)]dt, r>0.

Тогда

    Im phi_*(a+i tau)
      =4/|D(a+i tau)|^2 *int_0^infinity W_a(r)sin(tau r)dr. (KQ19)

Доказательство: раскрыть Im(N conjugate(D)), симметризовать пару (s,t), оставить s>t и подставить s=t exp(r), ds=t exp(r)dr. Это даёт показанную степень t и множитель exp((a+1/2)r), без потери второго сигнала.

W_a(r)>0, но синус меняет знак. Абсолютная интегрируемость следует из конечности D(a)N(a): на s>t разность h(s)-h(t) ограничивается h(s)+h(t), поскольку h>0. Те же аргументы с |log s|+|log t| оплачивают первый момент по r. Поэтому (KQ19) — полная формула, не условная перестановка расходящихся интегралов. `[ABSTRACT][PAPER]`

**Ни W_a>0, ни (KQ2) не доказывают неотрицательность её синусного преобразования при всех tau.** Это ровно оставленный смешанный фазовый знак, а не новый положительный supplier. Даже установление этого знака в данной полуплоскости отдельно не оплатило бы всё глобальное Pick-продолжение и 1-разделение.

## 8. Контроли и сильнейшие возражения

**Гауссов положительный контроль.** Для rho(s)=C exp(-beta s), beta>0, D(u)=C beta^(-u-1/2)Gamma(u+1/2), N=beta D и phi_*=4beta. Относительная дисперсия (KQ9) равна 1/p, то есть оценка откалибрована на правильном масштабе. W_a=0; синусная формула даёт нуль. У theta строгая вогнутость делает ковариацию строгой, но в (KQ1) допустима общая нестрогая граница.

**Известный не-Pick BF-контроль.** Для q0 пропорциональной exp(-x^2)-exp(-2x^2)/4 сохраняются все выводы §4. Но его прежняя phi0=4(1-2a2^(-u))/(1-a2^(-u)), a=2^(-5/2), при

    u=1+3pi i/(2log 2), c=a/2,
    Im phi0(u)=-4c/(1+c^2)<0.                           (KQ20)

Это точная проверка направления (KQ19), не новый theta-контрпример. Его D-нули имеют Re u=-5/2, поэтому (KQ17) НЕ объявляет ложным его действительно существующий BF-интерполянт. Его положительное Abel-представление и взаимность после обратной замены не компенсируют отсутствие аддитивного PF. Совместный PF+reciprocity-механизм здесь не опровергается.

**Проверка сокращённого нуля.** Искусственный полином D(z)=(z-i)(z-i-1), с N(z)=(z-1/2)D(z-1), даёт после точного сокращения

    4N(z)/D(z)=4(z-1/2)(z-i-2)/(z-i).

Нуль знаменателя в z=i+1 устранён, но z=i+2 — голоморфный нуль отношения. Это только алгебраический plant для логики §6; полином не выдаётся за Mellin(theta).

**«Из положительной области можно продолжить безнулевость всюду».** Нет. Тождественность продолжает равенства, не отсутствие нулей. В §6 используется дискретное сдвиговое тождество совместно с гипотезой BF/Pick, либо последним нулём заданной цепи; без существующего u0 никакого отрицательного вывода нет.

**«Продолжение Mellin интеграла на всю C незаконно».** Именно поэтому (KQ11) содержит Taylor-вычитания и все явные простые дроби. За исходной полуплоскостью используется эта функция, не расходящийся интеграл.

**«Это новый source-sign прогресс».** Нет. Новое — количественная область знаменателя и устранение необходимости проверять локальное сокращение при условном тесте. Положительный бюджет V не улучшился. Все реальные theta-свойства, использованные для (KQ1), также есть у соответствующего контроля; новая специфическая арифметическая сила из них не извлечена.
