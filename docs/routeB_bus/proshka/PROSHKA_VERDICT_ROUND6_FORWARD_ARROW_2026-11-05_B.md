## 2. Источник из аддитивной решётки: нормировка без пропущенных полюсов

[ABSTRACT | PAPER; T1 и T3 плюс прямой вывод.]

Используем Fourier на вещественной прямой в нормировке

    F_2pi v(t)=integral_R v(x) exp(-2*pi*i*x*t) dx.

Положим g_0(x)=exp(-pi*x^2), theta(x)=sum_(n in Z) g_0(n*sqrt(x)) и Psi(x)=(theta(x)-1)/2. Формула Пуассона на **аддитивной** Z даёт

    theta(x)=x^(-1/2) theta(1/x),       x>0.                 (2.1)

В логарифмической координате u положим D=d/du и

    B(u)=exp(u/2) Psi(exp(2u)),
    Phi(u)=(D^2-1/4) B(u).

Из (2.1):

    B(-u)-B(u)=sinh(u/2).

Оператор D^2-1/4 уничтожает эту полюсную разность и коммутирует с отражением, поэтому Phi чётна. Для u>=0, y_n=pi*n^2*exp(2u),

    Phi(u)=sum_(n>=1) exp(u/2-y_n) P_0(y_n),
    P_0(y)=4y^2-6y.                                      (2.2)

Здесь y_n>=pi>3, поэтому каждая слагаемая строго положительна. Phi гладкая, положительная и вместе со всеми производными убывает быстрее любой экспоненты на обоих концах. Абсолютная сходимость theta-ряда с производными на компактах и (2.1) оплачивают эти утверждения, включая u=0.

При Re s>1 почленное Mellin-интегрирование и два интегрирования по частям дают

    xi(s)=s(s-1) integral_R Psi(exp(2u)) exp(su) du
         =integral_R Phi(u) exp((s-1/2)u) du.              (2.3)

На -infinity исходная Psi равна (exp(-u)-1)/2 плюс сверхмалый остаток; при Re s>1 краевые члены исчезают. После применения D^2+D интеграл целый, так что (2.3) продолжается на C. В частности,

    Xi(t)=xi(1/2+it)=integral_R Phi(u) exp(itu) du.

Это нормировка полного Fourier-интеграла. Она согласуется с T2 после замены переменной u/2; никакой фактор 2 или 8 не переносится на глаз.

**Сохранённая структура:** обычная Z, точное Gaussian-ядро, оба полюсных края, функциональная симметрия, все целые n. Это не следствие одной свободной мультипликативной решётки.

## 3. Прямая PSD-цепочка действительно строится

[FINITE_CELL / ABSTRACT | PAPER.]

Пусть L=log m, f=S_m z — прежний чётный cosine-синтез, с нулевым продолжением из I_L=(-L/2,L/2). В RG базис индексирован 0<=j<=m; этот carrier не сокращается и не заменяется. G_m измеряет ||f||_2^2+||f'_int||_2^2, K_m={z:z_0=0,p_m^*z=0}.

Возьмём положительное пространство

    H=direct_sum_(n>=1) L2((0,infinity),du),
    P^(0)=I_H.

При w_n(u)=exp(u/2-y_n)P_0(y_n)>0 определим

    (V_m z)_n(u)=sqrt(2 w_n(u)) f(u),  0<u<L/2,
                 0,                  u>=L/2.

Это ограниченное отображение конечномерного пространства в H: Phi непрерывна и ограничена, и

    P_m^theta=V_m^* I_H V_m,
    P_m^theta[z]=integral_(I_L) Phi(u)|f(u)|^2 du >=0.     (3.1)

Таким образом имеется конечная цепочка длины один; бесконечный theta-ряд входит в **один определённый ограниченный оператор**, а не в недоказанный бесконечный алгоритм. Эквивалентно можно брать конечные суммы по n и предел матриц; на конечном окне сходимость в норме следует из Gaussian-majorant, единого по конечному числу базисных функций.

### Универсальность положительных звеньев

Для каждого фиксированного S отображение X -> S^*XS сохраняет PSD для **всякого** X>=0, поскольку его значение на v равно <Sv,X Sv>. Сжатие — тот же случай. Неотрицательная сумма PSD-форм сохраняет знак. Для Schur product: если A_ij=<a_j,a_i>, B_ij=<b_j,b_i>, то (A o B)_ij=<a_j tensor b_j,a_i tensor b_i>. Предел конечных матриц сохраняет PSD при сходимости всех квадратичных значений. В бесконечном случае заранее нужны общий домен и конечность формы; здесь они оплачены ограниченностью V_m.

Ни одно из этих утверждений не предполагает PSD A_m. В (3.1) корень извлекается из **явного положительного theta-слагаемого**, не из неизвестного оператора Вейля.

### Автономность

V_m строится из n, Gaussian, L, исходного cosine-базиса и уже положительных весов. Он не считывает psi-x, нули ξ, собственные значения A_m или знак его минимума. Первое настоящее аддитивное звено — (2.1), Poisson на Z. При желании к (3.1) можно применять остальные указанные классы PSD-операций, если их коэффициенты так же заданы структурно.

Для сравнения, GCD/Smith-матрица

    K(a,b)=sum_(d|a,d|b) c_d,  c_d>=0,

равна E diag(c) E^*, E_(a,d)=1_(d|a), и имеет ту же положительность на любом формальном свободном коммутативном моноиде. Selberg-square — та же Gram-логика. Эти две конструкции не используют n+1 и сами не различают DMV.

**Но (3.1) ещё не есть A_m.** Ни положительность Gram-матрицы, ни её автономное построение не доказывают последнего source-return звена. Именно это звено проверяется дальше.

## 4. Один положительный самодуальный seed с внеосевым квартетом

### 4.1. Полностью явная конструкция

[ABSTRACT | PAPER.]

Зафиксируем a=1/3, b=gamma^2 и первоначально gamma=100, b=10000 — ровно параметры freeze. Положим

    Q_b(z)=((z-a)^2+b)((z+a)^2+b)
          =z^4+2(b-a^2)z^2+(b+a^2)^2,
    kappa_b=Q_b(1/2)=b^2+(13/18)b+25/1296 >0,
    G=x*d/dx+1/2,
    v_b(x)=Q_b(G) g_0(x)/kappa_b.                        (4.1)

При Fourier F_2pi имеем F_2pi G=-G F_2pi на Schwartz-функциях. Q_b чётен, F_2pi g_0=g_0, следовательно

    F_2pi v_b=v_b.                                      (4.2)

Кроме того, v_b(0)=1: в точке 0 оператор G действует на значение чётной гладкой функции как умножение на 1/2. Поэтому integral_R v_b=1. Это не приближённая нормировка.

Осталось доказать **положительность v_b**, которая не следует автоматически из применения дифференциального оператора.

### 4.2. Точный положительный сертификат seed

[ABSTRACT | PAPER; символьные тождества проверены над Q.]

При y=pi*x^2,

    v_b(x)=exp(-y) S_b(y)/kappa_b,
    S_b(y)=16y^4-112y^3+(8b+1486/9)y^2
                         -(12b+113/3)y+kappa_b.

Точное разложение:

    S_b(y)=16y^2(y-7/2)^2
           +(8b-278/9)y^2-(12b+113/3)y+kappa_b.          (4.3)

Для b>=10000 и y>=0,

    8b-278/9 >= 7b,
    12b+113/3 <= 13b,
    kappa_b >= b^2.

Значит

    S_b(y)>=7b y^2-13b y+b^2
           >=b(b-169/28)>0.                            (4.4)

Следовательно v_b — **строго положительная, чётная, самодуальная Schwartz-плотность с массой 1 и v_b(0)=1**. Никакой неизвестный нуль не участвовал в определении или проверке. Все параметры фиксированы до теста.

При b=10000 проверялся также дополнительный рациональный Bernstein-сертификат на [0,3] и положительность коэффициентов S_b(3+x), x>=0; они согласовались с (4.3). Для доказательства достаточно более короткого (4.3)–(4.4).

### 4.3. Настоящий Poisson и правильные полюса переживают подсадку

[ABSTRACT | PAPER.]

Определим собственную theta-функцию нового seed:

    theta_b(x)=sum_(n in Z) v_b(n sqrt(x)),
    Psi_b=(theta_b-1)/2,
    B_b(u)=exp(u/2) Psi_b(exp(2u)).

Из (4.2), по обычной формуле Пуассона на той же Z,

    theta_b(x)=x^(-1/2)theta_b(1/x).                     (4.5)

Это **та же форма модульной идентичности**, не только похожая симметрия. Масса seed и его значение в нуле равны 1, поэтому оба полюсных края имеют исходную нормировку. Дифференцирование под сходящейся суммой даёт

    B_b=Q_b(D)B/kappa_b,
    Phi_b=(D^2-1/4)B_b=Q_b(D)Phi/kappa_b.                (4.6)

По (4.5) Phi_b чётна. Следующий сертификат доказывает, что она тоже положительна — одной положительности v_b для этого недостаточно.

### 4.4. Положительность полного xi-kernel: сертификат на полупрямой

[ABSTRACT | PAPER.]

Если D применяется к exp(u/2-y)P(y), y=pi*n^2*exp(2u), его действие на P равно

    T P=2y P'(y)+(1/2-2y)P(y).

Для P_0=4y^2-6y вычислено точно:

    T^2 P_0=16y^4-112y^3+165y^2-(75/2)y,

Поэтому при b=10000 полином одной слагаемой Q_b(D)Phi есть

Ключевой точный сертификат — не его знаки в этой координате, а сдвиг y=3+x:

Все коэффициенты строго положительны. При u>=0 каждый y_n>=pi>3. Значит каждая слагаемая

Это точное тождество с положительными коэффициентами по x,v. Поэтому оба положительных результата верны одновременно для **всех gamma>=100**. Это не замена неудачного параметра: исходный gamma=100 прошёл первым.

### 4.5. Полная completion и её нули

[ABSTRACT | PAPER.]

Для Re s>1 Mellin-transform seed удовлетворяет

    M[v_b](s)=integral_0^infinity v_b(x)x^(s-1)dx
       =Q_b(s-1/2)/kappa_b * (1/2)pi^(-s/2)Gamma(s/2).

Знак аргумента после интегрирования по частям исчезает из-за чётности Q_b. Поэтому собственная completion нового theta-source равна

    xi_b(s)=s(s-1)zeta(s) M[v_b](s)
           =Q_b(s-1/2)xi(s)/kappa_b
           =integral_R Phi_b(u)exp((s-1/2)u)du.          (4.9)

Это целая функция порядка 1, вещественного типа, с xi_b(s)=xi_b(1-s) и xi_b(0)=xi_b(1)=1/2. Однако у неё есть квартет

    s=1/2 +/- 1/3 +/- i*gamma.                           (4.10)

Нули ξ не могут сократить эти нули: здесь умножение, не деление. Если совпадение уже существовало, кратность увеличивается.

**Существенная граница.** Euler-множитель ζ остался прежним; изменился Mellin-фактор выбранного archimedean seed. Нельзя объявлять xi_b стандартной ξ с тем же Gamma-фактором. Ровно эта подмена сделала бы отрицательный контроль бессмысленным. Ниже используется ПОЛНАЯ форма xi_b, включая дополнительную рациональную логарифмическую производную.

### 4.6. Контрпримеры могут быть сколь угодно близки к исходному seed

[ABSTRACT | PAPER.]

Из (4.1) следует точное равенство

    v_b-g_0 = (G^2-1/4)[G^2+1/4+2(b-a^2)]g_0/kappa_b.   (4.11)

Поскольку kappa_b~b^2, в каждой фиксированной Schwartz-полунорме правая часть O(1/b). Аналогично, для каждого фиксированного A>=0 и целого j>=0,

    ||exp(A|u|) d^j(Phi_b-Phi)/du^j||_L1
      +||exp(A|u|) d^j(Phi_b-Phi)/du^j||_L2=O_(A,j)(1/b).
                                                               (4.12)

Все производные исходной Phi имеют нужные сверхэкспоненциальные хвосты. Следовательно любое фиксированное конечное семейство непрерывных диагностик со строго положительными запасами сохранит свои знаки при достаточно большом b, хотя каждый источник (4.9) имеет квартет (4.10).

Это не запрет точной проверки Gaussian-коэффициентов или иной дискретной идентичности с нулевым допуском. Это запрет выводить глобальный знак из устойчивых конечных проверок, слепых к уходящему вверх квартету.

Все моментные Gram-матрицы и Bochner-матрицы нового источника действительно PSD. Например,

    sum_(i,j) conjugate(c_i)c_j xi_b(1/2+i(t_j-t_i))
      =integral_R Phi_b(u)|sum_j c_j exp(i t_j u)|^2 du>=0.

Таким образом даже положительность **всех** таких Gram-матриц — не положительность формы Вейля.

## 5. Точное изменение полного источника: rank two, а не забытый остаток

[FINITE_CELL / ABSTRACT | PAPER.]

Из (4.9)

    xi_b'/xi_b(s)=xi'/xi(s)+Q_b'(s-1/2)/Q_b(s-1/2).       (5.1)

Нормирующая kappa_b исчезает. Четыре дополнительных нуля дают собственное ядро

    r_b(u)=4 cosh(a u) cos(gamma u).

Поэтому для исходного физического f и Q_f(u)=2 Re integral conjugate(f(x))f(x+u)dx,

    W_b[f]=W[f]+integral_0^L r_b(u)Q_f(u)du,
    A_m^b=S_m^* W_b S_m.                                (5.2)

Сохранены исходные Gamma, все Lambda(p^k), оба полюса и добавлен весь quartet-source. Это не использование старого A_m под новым именем.

На чётном секторе положим

    c(x)=cosh(a x)cos(gamma x),
    d(x)=sinh(a x)sin(gamma x),
    c_m=S_m^*c, d_m=S_m^*d.

Раскрытие cosh(a(x-y))cos(gamma(x-y)) и исчезновение нечётных моментов дают

    A_m^b-A_m=4(c_m c_m^*-d_m d_m^*).                    (5.3)

Это точная разность двух ранговых квадратов. Квадрат с минусом нельзя выбросить, сославшись на положительность Phi_b. Он также не является null-gauge из e0 и p_m.

Достаточный для возврата cutoff-бюджет:

    ||A_m^b-A_m||
       <=4(||c||_(L2(I_L))^2+||d||_(L2(I_L))^2)
       <=(2/a)sinh(aL)+2/gamma
       <=3m^(1/3)+1/50,       gamma>=100.               (5.4)

Здесь проекция S_m^* не увеличивает L2-норму. Бюджет полиномиален по m и потому совместим со сверхполиномиально малыми cutoff/projection errors RG §6. Это верхняя оценка нормы, НЕ сама отрицательная верхняя огибающая полного A_m^b; последняя доказывается дальше.

## 6. Строгий отрицательный судья для полной подсаженной формы

[COFINAL_FAMILY | PAPER; RG §§2,4,6,8.3, с явной проверкой изменения gamma и kernel.]

Используем ровно зафиксированный до неизвестных нулей профиль RG:

    eta(x)=pi^(-1/2)exp(-x^2),
    g=d_x^2(d_x^2-1/4)eta,
    F(z)=integral_R g(x)exp(zx)dx
        =z^2(z^2-1/4)exp(z^2/4).                        (6.1)

F исчезает только при z=0,+/-1/2. Поэтому F(a+i*gamma) не равен нулю, в частности при gamma=100. Его чрезвычайно малая величина не является точным нулём.

Пусть h_b(t)=W_b(g,T_t g). У RG Laplace-transform исходного h имеет вид F(z)^2 zeta'/zeta(1/2+z)+A(z), где A голоморфна при Re z>-1/2. Из (5.2) добавляется конечная сумма экспонент с Laplace-полюсами z=+/-a+/-i*gamma. Следовательно у нового transform есть ненулевой вычет

    (multiplicity_in_xi + 1) F(a+i*gamma)^2              (6.2)

в z=a+i*gamma. На положительной вещественной полуоси transform мероморфно продолжается без особенностей: у ξ там нет вещественных нулей, полюс ζ в 1 снят F(1/2)^2, а Q_b(z)>0 для вещественного z. Рост h_b и h_b' не хуже O(exp(t/2)); добавленный член имеет показатель a<1/2.

Для полноты — направление Landau-аргумента. Если h_b(t)>=-M exp(c t) для всех поздних t при 0<=c<a, добавим M exp(c t) и неотрицательную компактную поправку, получив k(t)>=0. Ненулевой полюс (6.2) заставляет абсциссу сходимости его Laplace-transform быть не меньше a. У transform неотрицательной функции конечная абсцисса обязана быть вещественной особенностью: иначе Taylor-разложение справа от неё с неотрицательными моментными коэффициентами по монотонной сходимости продолжает интеграл левее абсциссы. Но положительная вещественная ось здесь регулярна. Противоречие. Поэтому

    liminf_(t->infinity) exp(-c t)h_b(t)=-infinity
                     для каждого 0<=c<a.               (6.3)

Нельзя заменить эту осцилляцию отрицательностью в каждом позднем t.

### Возврат в буквальные окна и ограничения

Для L=log m берём две копии g с центрами +/-L/4, smooth cutoff chi(2x/L), cosine projection с N=m, затем ровно две поправки RG (6.1): зануление координаты e0 и вычитание p_m-момента через e1. Получаем w_m in K_m. Пусть z_m=w_m/sqrt(w_m^*G_m w_m). Тогда

    z_m^*G_m z_m=1,
    w_m^*A_m^b w_m=2W_b[g]+2h_b(L/2)+O_N(m^(-N)),
    w_m^*G_m w_m -> 2||g||_(H1)^2>0.                   (6.4)

Это не нелегальное помещение целого Gaussian внутрь конечного окна: расстояние до cutoff равно L/8, weighted Gaussian tails имеют exp(-cL^2+O(L)), cosine-tail допускает произвольный порядок, полюсные поправки оплачены RG. Новый источник требует только дополнительной полиномиальной цены (5.4), так что те же оценки остаются сверхполиномиально малыми. Endpoint n=m имеет нулевое корреляционное перекрытие. Внутренняя H1-норма не подменяется H1-нормой нулевого продолжения.

Переход от t к целому m=nearest(exp(2t)) имеет |t-(log m)/2|=O(exp(-2t)); рост h_b' даёт исчезающую ошибку. Поэтому из (6.3)–(6.4)

    liminf_(m->infinity) [z_m^*A_m^b z_m]/m^epsilon
       =-infinity,        для каждого 0<=epsilon<1/6.    (6.5)

Этот вывод не предполагает RH для исходной ξ. Возможные собственные внеосевые нули ξ не могут сократить положительную кратность полюса (6.2).

### Нужная строгая верхняя огибающая

Пусть P_m>=0 — **любой** выход любой положительной цепочки. Для произвольных фиксированных C,r существуют сколь угодно большие целые m, на которых

    z_m^*[A_m^b-P_m+C(1+log m)^r G_m]z_m
      <= -m^(1/12)+C(1+log m)^r <0.                     (6.6)

Первое неравенство использует (6.5) и P_m>=0, второе — рост степени быстрее polylog. Именно (6.6), а не большая верхняя оценка ошибки, сертифицирует запрет. Конкретный конечный m численно не локализовался; доказан аналитический квантор существования бесконечной последовательности.

## 7. Теорема о невозможности универсального последнего звена

[ABSTRACT / COFINAL_FAMILY | PAPER.]

Рассмотрим класс S6-B, пункт 5 freeze: входы допускают строго положительные чётные self-Fourier Schwartz-seeds с v(0)=integral v=1, положительный even xi-kernel, точную собственную Poisson/Mellin completion и её полный источник. В частности, класс содержит g_0 и все v_b, b>=10000. Разрешены любые конечные композиции PSD-сохраняющих операций §3 с автономными структурными коэффициентами, а также корректные пределы этих операций.

**Теорема.** Не существует универсального source-return утверждения для всего этого класса, которое для каждого входа и всех поздних m даёт

    A_m^(input) >= P_m^(input)-C_input(1+log m)^r_input G_m
                       на K_m,                         (7.1)

где P_m^(input) — PSD-выход цепочки, а C_input,r_input конечны и независимы от m. Даже разрешение константам зависеть от всего фиксированного входа не спасает утверждение.

**Доказательство.** Выбрать один вход v_10000. Он удовлетворяет всем перечисленным предпосылкам по §4. Любая допустимая цепочка заканчивается PSD-формой по §3. Но (6.6) противоречит (7.1) для любых её C,r. □

Обструкция сильнее отсутствия удачно выбранных звеньев: даже произвольный PSD-выход не исправит отрицательную нижнюю огибающую **этого** полного источника. Поэтому дополнительная свобода Schur products, Schur complements корректных положительных блоков, congruences или нелинейного выбора текущего положительного состояния не ремонтирует универсальный возврат.

**Что теорема не говорит.** Бриф не требует, чтобы выходная оценка была верна для каждого положительного self-Fourier seed. Для исходного g_0 она может использовать его специальные коэффициенты. Именно поэтому KILL_SCOPE здесь THEOREM_SHAPE, а не ROUTE_FAMILY, и запрет не является отрицательным результатом о RH. Спецификация большей универсальности была объявлена во freeze; она не приписывается владельцу задним числом.

Реальное различие обнаружено в Mellin-звене:

    M[g_0](s)=(1/2)pi^(-s/2)Gamma(s/2),
    M[v_b](s)=Q_b(s-1/2)M[g_0](s)/kappa_b.               (7.2)

У положительного самодуального seed его Mellin-transform может иметь внеосевые нули. Уничтожение дополнительного Q_b'/Q_b при возврате к исходному ζ-source — **подписанная операция**, а не бесплатное следствие PSD. Здесь и нужно использовать точный Gaussian local factor, а не только положительность и Пуассон.

## 8. Четыре мира: собственный источник и место разрыва

[ABSTRACT / COFINAL_FAMILY | PAPER, с явно обозначенными inherited RG-результатами.]

**Подсаженный квартет.** Цепочка §3 действительно запускается с собственными положительными весами Phi_b. Поиска нулей в звеньях нет; b задан до теста. Poisson, Mellin, масса, оба полюсных нормирования и все Gram-положительности проходят. Ломается **последнее универсальное source-return звено**, строго по (6.6). Если Gaussian-специфическое правило отвергнет v_b уже по (7.2), это допустимый источник-специфический discriminator, а не опровержение нашей теоремы.

**DMV.** Делимость, GCD и Selberg Gram идут на формальном моноиде его generalized primes. Но (2.1) построена на обычных точках n in Z. Использовать её как собственный theta-source DMV означало бы заменить его обобщённые целые обычными. При замене n на реальные generalized integers обычное доказательство Gaussian Poisson не переносится. Точный разрыв — **аддитивное source-identification звено**, а не PSD incidence-матрицы. Здесь не доказано отсутствие вообще всякой альтернативной Poisson-теории для DMV, и не приписано ему функциональное уравнение ζ. Независимый конечный отрицательный судья использует ровно RG §8.1: W_B=H+P-B_B с явными zeta-Gamma/pole и реальными generalized-prime atoms; его Laplace-полюсы запрещают cofinal polylog floor. Следовательно подставить его полный A_m в (7.1) всё равно нельзя.

**DH.** Обычный theta/Euler-source не является его источником: должны сохраняться все коэффициенты b_D(n), в том числе b_D(6), его odd-Gamma, conductor 5 и отсутствие pole. Это RG §8.2, inherited PAPER, не новый численный аудит DH-нуля. При сохранении этого источника правый Laplace-полюс также исключает малый нижний порог. Ни положительная матрица обычной делимости, ни generic Gram от положительной меры не доказывают нужного DH source-return.

**Кривая E/F3: положительный полный выход, а не только контроль.** Пусть h=log 3. Собственный completed factor — 2cosh(h(s-1/2)); источник соответствует antiperiodic lattice с периодом 2h. Для компактно поддержанного f определим на [0,2h)

    (Rf)(x)=sum_(k in Z) (-1)^k f(x+2hk).               (8.1)

При каждом x сумма конечна. Это структурная периодизация, не обращение к неизвестным нулям. Начать с I на L2([0,2h)) и применить congruence S=sqrt(2h) R S_m. Тогда

    P_m^E[z]=2h ||R S_m z||_2^2
       =2h ||f||_2^2+2h sum_(k>=1,2hk<L)(-1)^k Q_f(2hk)
       =A_m^E[z] >=0.                                  (8.2)

Последнее — собственный finite-window source кривой из R4B §9, также проверяемый Fourier-разложением antiperiodic periodization. По Parseval,

    2h||Rf||^2=sum_(j in Z)|fhat((pi/2+pi*j)/h)|^2.

Endpoint 2hk=L даёт нулевое перекрытие. Для каждого фиксированного L оператор R на функциях с такой поддержкой ограничен: число перекрытий конечно. Никакого zeta-Gamma здесь нет. Это подлинная прямая цепочка с C=0, проходящая positive control; она не переносится на Q через переименование её периода.

## 9. Что получено на выходе для настоящего A_m — и что нет

[FINITE_CELL | PAPER для равенства и грубой оценки; COFINAL_FAMILY | CONDITIONAL для искомого улучшения.]

Для g_0 построен P_m^theta из (3.1). Его **точный** дефект в буквальном источнике равен

    D_m[f] = integral_0^infinity j(u)[2||f||^2-Q_f(u)]du
             -c_*||f||^2
             +integral_0^L 2cosh(u/2)Q_f(u)du
             -sum_(2<=n<m) Lambda(n)n^(-1/2)Q_f(log n)
             -integral_(I_L) Phi(x)|f(x)|^2dx,
    A_m[z]=P_m^theta[z]+D_m[S_m z],                     (9.1)

где j(u)=exp(-u/2)/(1-exp(-2u)), c_*=EulerGamma+log(8pi)+pi/2. Все члены исходника сохранены. Формула не считается доказательством знака D_m.

Пусть M_Phi=sup_R Phi<infinity. Положительность arch-jump energy и полюсного квадрата на чётном секторе, |Q_f|<=2||f||^2, Lambda(n)<=log n и sum_(n<m)n^(-1/2)<=2sqrt(m) дают честную, но слишком большую оценку

    A_m[z]>=P_m^theta[z]
          -[c_*+M_Phi+4sqrt(m)log m] z^*G_m z.           (9.2)

Можно наследовать более сильный по логарифмам bound R4B, но это не даст нового показателя и не станет результатом этого раунда. Нужная замена правой цены на C(1+log m)^r здесь **не доказана**.

Для выбранного P минимальная отсутствующая строка буквально:

    exists C<infinity, integer r>=0, M:
      D_m[S_m z]>=-C(1+log m)^r z^*G_m z
      for all integers m>=M and every z in K_m.          (9.3)

Называть (9.3) новой оценкой было бы переименованием исходной стены. Нового выигрыша для настоящей ζ здесь нет. Достижение раунда — доказанный невозможный supplier, который не надо пробовать ещё раз: (9.3) нельзя получить из одной универсальной положительности theta/Gram плюс self-duality/Poisson. Требуется дополнительное использование **точного** источника.

## 10. Сильнейшие атаки на собственный результат

[ABSTRACT / COFINAL_FAMILY | PAPER scope audit.]

**«Ты изменил источник».** Да: это собственный явно изменённый источник отрицательного мира, как требует приёмка. Для него выведено (5.1)–(5.3). Прежний prime/Gamma-source без добавки не используется. Из его отрицательности не выводится отрицательность настоящего A_m.

**«Дифференцирование не сохраняет положительность».** Верно. Q_b(D) НЕ объявлен PSD-preserving link для любого входа. Положительность нового конкретного seed и его xi-kernel независимо доказана (4.3)–(4.8). Затем обычная congruence-цепочка сохраняет PSD для всякого положительного операторного входа. Эти два уровня не смешиваются.

**«Gamma=100 даёт практически нулевой residue».** Он мал, но F(a+i gamma) точно ненулевой по (6.1). Landau-судья использует ненулевой полюс, а не десятичный порог. Никакого конечного m для обнаружения этого квартета численно не обещано.

**«Один отрицательный quartet-вклад мог быть компенсирован исходной ξ».** Поэтому используется полный h_b и его несократимый полюс, а не знак одного слагаемого. Доказательство (6.3)–(6.6) не предполагает RH или отсутствия иных внеосевых нулей.

**«Запрет универсального класса убивает весь поиск».** Нет. Универсальность последнего звена сильнее требования брифа для одного исходного Gaussian. Её снятие и использование (7.2) — честное направление ремонта. Не доказана ни достаточность этого ремонта, ни невозможность всех других автономных карт.

**«Бесконечный ряд стал конечным доказательством по числам».** Нет. PSD-chain использует явно ограниченное отображение и доказанный положительный предел. Cofinal отрицательная огибающая выведена аналитически. Численных eigenproblem/zero-grid не было.

Старые запреты не обходятся словесно: здесь нет positive envelope для -K_m, bounded current неперенормированной alpha, scalar Euler–Mobius balancing, статической endpoint-склейки, ни theta-minorant типа NULLFIELD/RESOLVENTGRAM/POINCARECOMP. Не используется неравенство старого signed-trace с недоказанной константой. Это другой объект — положительный additive Gram с отдельно проверяемым source-return, и запрет относится именно к его универсальному последнему звену.

**B. Аддитивные fractional-part/Nyman probes, а не generic theta positivity.** В H=L2((1,infinity),dx/x^2) взять

    h_n(x)=floor(x/n)-floor(x)/n,   n>=2,
    target=1.

На [k,k+1) h_n=-{k/n}; поэтому

    <h_n,h_l>=sum_(k>=1) {k/n}{k/l}/[k(k+1)].            (11.1)

Здесь n+1 и соседние целые клетки входят буквально. Это самостоятельный положительный Gram, а не матрица A_m. При Re s>1 и далее по продолжению при Re s>0,

    integral_1^infinity h_n(x)x^(-s-1)dx
          =zeta(s)(n^(-s)-1/n)/s.                      (11.2)

Полюс в 1 сокращён. Из (11.2) и Cauchy–Schwarz: если rho=beta+i gamma, beta>1/2, — нуль ζ, то для любого конечного residual r_N=1-sum c_n h_n

    ||r_N||_H^2 >= (2beta-1)/|rho|^2.                   (11.3)

Следовательно стремление target-distance к нулю было бы достаточным, но **не доказано**. Одной PSD (11.1) недостаточно; требуется target capture. В отличие от blind Gram-аргумента, (11.2) фиксирует конкретный Mellin/Euler multiplier. Для подсадки нельзя оставить те же h_n и объявить их multiplier равным xi_b. Kill-power высокий по (11.3); стоимость finite definition низкая, стоимость density/decay высокая. Мост к буквальному A_m и независимая оценка target capture здесь не построены. Это кандидат, не второй якобы завершённый путь.

## Приложение. Проверка сертификатов без внешних Python-пакетов

[ABSTRACT | PAPER identities; executable exact-arithmetic check.]

```python
from fractions import Fraction as F
from math import comb


def trim(p):
    p = list(p)
    while len(p) > 1 and p[-1] == 0:
        p.pop()
    return p


def add(*polys):
    out = [F(0)] * max(map(len, polys))
    for p in polys:
        for i, c in enumerate(p):
            out[i] += c
    return trim(out)


def scale(p, c):
    return trim([F(c) * x for x in p])


def T(p):
    # D[exp(u/2-y) P(y)] = exp(u/2-y) T(P), y'=2y.
    out = [F(0)] * (len(p) + 1)
    for j, c in enumerate(p):
        out[j] += (2*j + F(1, 2)) * c
        out[j + 1] -= 2*c
    return trim(out)


def shifted(p, h=3):
    out = [F(0)] * len(p)
    for j, c in enumerate(p):
        for k in range(j + 1):
            out[k] += c * comb(j, k) * F(h)**(j-k)
    return trim(out)


b, a2 = F(10000), F(1, 9)
p0 = [F(0), F(-6), F(4)]
p2, p4 = T(T(p0)), T(T(T(T(p0))))
r = add(p4, scale(p2, 2*(b-a2)), scale(p0, (b+a2)**2))
expected = [F(129091942969,72), F(129109525609,72),
            F(129738764833,324), F(14337920,9),
            F(2861752,9), F(96), F(64)]
assert shifted(r) == expected
assert all(c > 0 for c in expected)

# Family b=10000+v: coefficients of v and v^2 after y=3+x.
s1 = shifted(add(scale(p2, 2), scale(p0, 2*(b+a2))))
s2 = shifted(p0)
assert s1 == [F(359293), F(359317), F(720386,9), F(160), F(32)]
assert s2 == [F(18), F(18), F(4)]
assert all(c > 0 for c in s1 + s2)

# Seed polynomial, and its exact completed-square decomposition.
one = [F(1)]
seed = add(T(T(T(T(one)))), scale(T(T(one)), 2*(b-a2)),
           [(b+a2)**2])
kappa = b*b + F(13,18)*b + F(25,1296)
assert seed == [kappa, -(12*b+F(113,3)), 8*b+F(1486,9),
                F(-112), F(16)]
assert seed == add([F(0), F(0), F(196), F(-112), F(16)],
                   [kappa, -(12*b+F(113,3)), 8*b-F(278,9)])
assert 8*b-F(278,9) >= 7*b
assert 12*b+F(113,3) <= 13*b
assert kappa >= b*b
assert b*(b-F(169,28)) > 0
print('EXACT_POLYNOMIAL_CERTIFICATES_VERIFIED; RH_NOT_PROVED')
```
