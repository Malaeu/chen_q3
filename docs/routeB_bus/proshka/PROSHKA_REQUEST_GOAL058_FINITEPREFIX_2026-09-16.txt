3. Источник, форма и различие двух размеров

T=sum_{n>=1} Gamma(2,1)/(pi*n²), r=density(T), mu=E T=pi/3.
Phi(X)=exp(5X/2)r(exp(2X)), A=||Phi||_2, f=Phi/A.
r(1/t)=t^(5/2)r(t), r(t)~4pi²t exp(-pi t).
H имеет плотность lambda^(-1/2)-1 на (0,1), независимо от всех T_j.
W_0=1, W_j=H_1...H_j, S_m=sum_{j=1}^m W_(j-1)T_j.
Терминальный закон S_infinity — size-biased T, плотность t r(t)/mu.
Это точный закон исходного источника, не произвольная деформация.

Для a=exp(2x), b=exp(2y), x,y в I=(-log(2)/2,0), из SIZEBIASCOMP (44):
psi_xy(t)=mu/(2A²)*(ab)^(5/4)*sqrt(t)*r(at)r(bt)/r(t)
          *(log(t)+x+y).
K_m(x,y)=E[1_(S_m>=1)*psi_xy(S_m)].
V(x,y)=lim_{m->infinity} K_m(x,y), с уже доказанными бюджетами полного
signed telescope, включая границу. K_m точно равно сумме первых m средних
приращений; никакая частичная плотность не объявляется терминальным законом.

m — глубина renewal, N — число физических сдвигов. Они независимы.
Кандидатный положительный метод требовал бы некоторой конечной глубины m,
при которой K_m[c]>=0 для каждого конечного N и всех комплексных c.
Мы не утверждаем, что это необходимо для фактического V>=0.

4. Новый оплаченный K_2 и конкретная непроверенная гипотеза об общем m

У K_2, q_2=density(S_2), установлено q_2(t)/r(t)~2log(t), и есть глобальная
оценка C(1+log t) при t>=1. Точный перенос диагонали даёт

 K_2(x,x)/(a log(1/a)) -> (mu/A²) J <0,
 J=integral_0^infinity sqrt(u)r(u)^2 log(u)du
  =integral_1^infinity (u^(1/2)-u^(5/2))r(u)^2 log(u)du <0.

Общий голоморфный домен вместе с A1 возвращает конечную отрицательную строку
K_2 в исходный I. Это не двухузловой свидетель внутри I и не отрицательная V.

Предлагаемая для твоей проверки общая формула, пока UNVERIFIED для m>=3:

 q_m(t)/r(t) ~ [2^(m-1)/(m-1)!]*(log t)^(m-1),  t->infinity,

при КАЖДОМ ФИКСИРОВАННОМ m>=1. Гипотеза о единой ошибке, равномерной по m,
НЕ вводится. Источник рекурсии: q_1=r, q_(m+1)=r*v_m, где

 v_m(t)=density(H S_m)(t)
       =integral_t^infinity [(tu)^(-1/2)-u^(-1)]q_m(u)du.

Если точный коэффициент неверен, исправь его. Существенны положительный
ведущий коэффициент, степень log и доказанный полный majorant.
