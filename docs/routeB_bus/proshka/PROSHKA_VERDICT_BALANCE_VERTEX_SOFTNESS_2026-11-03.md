## 3. Условия (V) несовместимы

**Теорема 1 [ABSTRACT | PAPER; LA].** Пусть d>=2, одна ручка M_j>=0 и L(1)=0. Тогда

    t_j=e_j-(1/d)1 !=0,
    t_j in U,
    L(t_j)=M_j>=0.                                      (3.1)

Следовательно, {t in U:L(t)>=0} не равен {0}.

**Доказательство.** Сумма координат t_j равна 1-d/d=0. Вектор e_j не пропорционален 1. По линейности L(t_j)=M_j-L(1)/d=M_j. Даже при M_j=0 вектор остаётся в указанном конусе: его определение включает нулевые образы. Конец доказательства.

Для полюсной ручки первая часть (V), ker L_m=span(1), влечёт L_m(1)=0, а (3.1) противоречит второй части. Это не зависит от RH, обусловленности, счёта нулей или скорости (2.2).

Если дополнительно требуется ненулевой эффективный образ, следующая теорема даёт M_pole!=0 при J!=0. Если требуется факторизовать нулевые ручки, это ДРУГАЯ формулировка, не неявный ремонт (V).

Опровергнута форма утверждения, не знак действительного A_m. Неуспех достаточной оценки нигде не используется как опровержение ζ-положительности.

## 4. Полюсное сжатие действительно ненулевое

**Теорема 2 [FINITE_CELL | PAPER; LA/A, интерполяция R2].** На исходном чётном cosine-carrier, для исходного J из фактических комплексных нулевых value-условий,

    dim J>0  ==>  M_pole=v v^*, v=Q^*p_m!=0.             (4.1)

Следовательно, это ненулевой PSD-оператор ранга один.

**Доказательство.** В базисе R2

    phi_j(x)=d_j(-1)^j cos(omega_j x)/sqrt(L),
    d_0=1, d_j=sqrt(2) при j>0, omega_j=2pi j/L

положим lambda_j=omega_j^2, D_m(X)=prod_(j=0)^m(X-lambda_j). Унаследованная точная формула:

    F_f(z)=hat f(z)=(2z sin(zL/2)/sqrt(L)) P_f(z^2)/D_m(z^2),
    P_f(X)=sum_(j=0)^m d_j a_j prod_(k!=j)(X-lambda_k).    (4.2)

Она задаёт изоморфизм коэффициентов a_j с вещественными полиномами степени <=m; модальные особенности устранимы. Каждое активное нулевое условие зануляет P_f в соответствующем квадрате спектрального узла. Сопряжённые узлы группируются вместе. Автоматические внешние sinc-строки удаляются; кратность нуля сохраняет вес в форме, но не создаёт повторного независимого value-условия.

Обозначим различные активные квадратные узлы zeta_1,...,zeta_q. При J!=0 теорема ранга R2 даёт q<=m. Выберем

    P(X)=prod_(l=1)^q(X-zeta_l).                        (4.3)

Этот полином веществен благодаря сопряжённой симметрии. Узла -1/4 среди zeta_l нет: z=+/-i/2 отвечал бы s=0 или 1, а не нетривиальному нулю. Также D_m(-1/4)!=0 и sin(iL/4)=i sinh(L/4)!=0. Поэтому соответствующий f принадлежит J и

    F_f(i/2)!=0,
    <p,f>=sqrt(2)F_f(i/2)!=0.                           (4.4)

Его коэффициенты выписаны явно:

    a_j=P(lambda_j)/(d_j D_m'(lambda_j)).               (4.5)

Полюсный функционал не равен нулю на J, откуда (4.1). Положительность нулевых вкладов не использовалась. Конец доказательства.

## 5. Явное (S) на неограниченной исходной семье

**Теорема 3 [COFINAL_FAMILY | PAPER; I/E-поддержка, F-полюс, LA].** Для каждого простого m=p с ненулевым J вектор

    t_Gamma=0, t_pole=+1, t_p=-1 при p=m,
    t_q=0 для всех остальных простых q                  (5.1)

удовлетворяет

    t perpendicular to 1, ||t||_2=sqrt(2),
    sum_i t_i C_i=C_pole>=0,
    L_m(t)=v_m v_m^*>=0, v_m!=0.                        (5.2)

**Доказательство.** Две нулём продолженные L2-функции с поддержкой в интервале длины L при сдвиге L пересекаются только в одной точке. Их корреляция точно нулевая. Утверждение билинейно, значит оператор endpoint-атома n=m равен нулю. При m=p простом p^2>m, и в B_p нет других атомов:

    B_p=0 на ВСЁМ V_m, не только на J_m.                 (5.3)

Теперь (5.2) следует из (5.1) и теоремы 2. Конец доказательства.

Унаследованный ранг R3 растёт для всех достаточно больших m на его fixed-c shrinking-kappa расписании. Простые неограниченны: если бы p_1,...,p_N были всеми простыми, простой делитель p_1...p_N+1 был бы новым. Значит, теорема 3 даёт (S) на каждом достаточно большом простом окне, без перехода от конечных измерений к бесконечности.

Для 0<=epsilon<1 сохраняется даже покоординатная положительность исходных параметров:

    s(epsilon)=1+epsilon t,
    A(s(epsilon))=A+epsilon C_pole>=A.                  (5.4)

Если A>=0, это настоящий допустимый прямой луч. Без такого предположения (5.4) остаётся точной монотонностью, но не доказывает A>=0. Само (5.2) не требует положительного baseline.

**Границы:**

- Образ направления ненулевой; это не только параметрическая зависимость.
- В доказательстве baseline-источника не удалено ни одного активного простого. Отрицательная координата действует на точно нулевую ручку, весь исходный A сохранён.
- Γ не меняется. Полюсная вариация — одна из разрешённых пользователем ручек, не скрытая добавка к доказательству знака исходной формы.
- Направление зависит от m; единого второго L-ряда на всех окнах эта конструкция не задаёт.
- При m=p^k, k>1, прежние степени в B_p активны. Условие Lambda(m)>0 не заменяет простоту m.
- Для всех достаточно больших составных m и для задачи после удаления нулевых ручек вывод не заявлен.

Сертификат знака для любого x:

    x^*L_m(t)x=|v_m^*x|^2>=0.                           (5.5)

Это точный нижний envelope, не floating-SVD.

## 6. Точный двойственный закон баланса

**Теорема 4 [ABSTRACT | PAPER; LA].** Для любых фиксированных вещественных симметричных M_i и U=1-perp условие

    {t in U:L(t)>=0}={0}                               (6.1)

равносильно СОВМЕСТНО двум условиям:

    (i) ker(L|_U)={0};
    (ii) существуют Y>0 и lambda in R такие, что
         tr(Y M_i)=lambda для каждой ручки i.           (6.2)

Это конечномерная альтернатива, не доказанный арифметический знак ζ.

**Доказательство.** Необходимость (i) очевидна. Пусть W=L(U). При (6.1) подпространство W не содержит ненулевой PSD-матрицы. Проекция компактного выпуклого множества {X>=0:tr X=1} на W-perp не содержит нуля. Строгое конечномерное разделение даёт Y in W-perp с tr(YX)>0 на всём этом множестве. Подстановка rank-one X даёт Y>0. Ортогональность L(e_i-e_j) даёт равные следы (6.2).

Обратно, при L(t)>=0 и t in U имеем tr(YL(t))=lambda sum_i t_i=0. Из Y>0 следует L(t)=0, а из (i) t=0. Конец доказательства.

Нормируем tr Y=1. В настоящем источнике (2.1) даёт ТОЧНЫЙ trace-баланс

    d lambda=tr(YD),
    lambda=tr(Y M_pole)=v^*Yv>0,                       (6.3)

если J!=0. Невязка поставляет лишь

    0<lambda<=delta_m/d,
    lambda_min(Y)||v||^2<=delta_m/d.                    (6.4)

Поэтому допустимый строго положительный двойственный баланс может становиться плохо обусловленным. Без нижней оценки ||v|| утверждение о фактической скорости этого вырождения не делается.

На простом окне M_p=0 заставляет lambda=0, что несовместимо с v^*Yv>0. Двойственный и прямой исходниковый аргументы согласованы точно.

Удаление нулевых ручек или фиксация полюса изменяют параметрическое подпространство и вид (6.2). Это не было сделано молча. Для такой изменённой кофинальной задачи наличие primal-направления или положительного dual-Y не доказано. Двойственная эквивалентность — THEOREM; нужный кофинальный supplier для изменённой задачи — отсутствует.

## 7. Где действительно нужен второй порядок

**[ABSTRACT / FINITE_CELL | PAPER; LA].** Касательный конус в точке 1 допустимого множества можно обсуждать как касательный в допустимой точке лишь после A(1)>=0. Здесь это не предполагается.

Если в данной конечной ячейке A(1)>0, любое параметрическое направление локально допустимо: epsilon||H||<lambda_min(A) обеспечивает A+epsilon H>0. Сколь угодно узкий, но ненулевой интервал не является вершиной.

Если A>=0 имеет ТОЧНОЕ ядро K0, условие первого порядка для окружающего PSD-конуса использует K0, а не почти тихое J. Оно также не гарантирует допустимость прямого луча. При переходе от окружающего матричного конуса к ограниченному параметрическому семейству могут потребоваться дополнительные условия; равенство этих касательных здесь не предположено.

Пусть сначала

    A=[[0,0],[0,G]], G>0,
    H=[[M,N*],[N,R]].

При G+epsilon R>0 точное условие:

    A+epsilon H>=0
      iff M-epsilon N*(G+epsilon R)^-1 N>=0.           (7.1)

Если M>0, достаточно малый положительный epsilon подходит. Если M>=0 вырождено, условие ker M subset ker N необходимо и достаточно для достаточно короткого прямого луча: после его выполнения остаётся оценить положительный минимум M на ran M. В частности, M=0 требует N=0.

Точный контрпример автоматическому переносу первого порядка:

    A=diag(0,1), H=[[0,1],[1,0]],
    det(A+epsilon H)=-epsilon^2<0.                     (7.2)

Для настоящего почти тихого разложения

    A=[[D,B*],[B,G]], ||D||,||B||<=delta_m,
    H=[[M,N*],[N,R]]

при G+epsilon R>0 необходимо и достаточно

    D+epsilon M
      -(B+epsilon N)*(G+epsilon R)^-1(B+epsilon N)>=0.  (7.3)

Если отдельно поставлен gap G>=gI и |epsilon|||R||<g, норма вычитаемого члена не превосходит

    (delta_m+|epsilon|||N||)^2/(g-|epsilon|||R||).       (7.4)

Положительный gap дополнения здесь не импортирован. Теорема 3 обходит эту проблему законно: для её направления ВЕСЬ H=C_pole положителен, а не только его сжатие.

## 8. Ручка x^2: аналитическое спаривание и условный порог

**[ABSTRACT / FINITE_CELL | PAPER; A/F/E/I; условный exit-budget отмечен отдельно].** Боковой сдвиг не является автоматически направлением исходного pencil.

Пусть F(z)=hat f(z), F^#(z)=conjugate(F(conjugate z)). Аналитическое произведение нулевой стороны:

    H_f(z)=F^#(z)F(z),                                  (8.1)

не |F(z)|^2 в комплексной точке. Для вещественного чётного f оно равно F(z)^2. Умножение корреляционного теста на x^2 даёт -H_f''.

У X_a(s)=xi(s+a)xi(s-a) нули сдвинуты. Нормируем соответствующую форму множителем 1/2, чтобы при a=0 получить исходную:

    W_a[f]=(1/2)sum_rho[H_f(z_rho+ia)+H_f(z_rho-ia)].    (8.2)

Γ и полюсы здесь принадлежат именно произведению X_a, не остаются прежними. Для фиксированного m и |a|<=a0:

    W_a[f]=W_0[f]-(a^2/2)D_f+E_4(a),
    D_f=sum_rho H_f''(z_rho),
    |E_4(a)|<=a^4 R_f/24,                              (8.3)

где, суммируя РАЗЛИЧНЫЕ нули с весами кратности nu,

    R_f=sum_rho nu_rho sup_(|u|<=a0, signs +/-)
                         |H_f''''(z_rho +/- iu)|.       (8.4)

В (8.2)-(8.3) можно либо суммировать повторённые нули, либо различные с весом nu; кратности нельзя учитывать дважды. R_f конечен без RH. Пусть b=L/2 и V_j=TV(x^j f_extended), j=0,...,4. Интегрирование по частям для нулём продолженных BV-функций даёт

    R_f<=exp((1+2a0)b)
          [sum_rho nu_rho/|Im rho|^2]
          sum_(j=0)^4 binom(4,j)V_j V_(4-j).            (8.5)

Обратноквадратичная сумма конечна по безусловному счёту нулей; у конечного низкого набора ординаты ненулевые. Для единичных cosine-тестов V_j явно ограничиваются через ||f'||<=Omega||f||, ||f||_1<=sqrt(L)||f|| и |f(b)|<=sqrt((2m+1)/L)||f||.

На J в каждом низком нуле F=F^#=0, поэтому вклад в D_f равен

    2F^#'(z_rho)F'(z_rho).                              (8.6)

Он неотрицателен в вещественной спектральной точке, но не знакоопределён в комплексной. Кроме того, D_f сохраняет ВСЕ высокие нули. Само i^2 не доказывает D_f>0.

Точный алгебраический контроль: для w=gamma+i eta, gamma>eta>0, и F(z)=(z^2-w^2)(z^2-conj(w)^2) сумма H_f'' по четверке равна -512 gamma^2 eta^2(gamma^2-eta^2)<0. Этот полином — только контроль аналитического знака, не объявлен физическим Fourier-образом или настоящим нулевым набором ζ.

Условный строгий выход можно записать. Если для выбранного единичного f in J независимо доказаны D_f>=d_m>0 и R_f<=r_m, то

    W_a[f]<=delta_m-(d_m/2)a^2+(r_m/24)a^4.             (8.7)

Следовательно,

    4delta_m/d_m<a^2<=min(a0^2,6d_m/r_m)                (8.8)

даёт W_a[f]<0; при r_m=0 соответствующая верхняя граница не нужна. Непустота интервала обязательна. Это достаточный порог отрицательного теста, НЕ точное a*(m) и не доказанная непустота для настоящего источника. Недостающий sign-supplier — нижняя оценка полного D_f. При a=it знак квадратичного члена меняется, но pairing и остаток остаются обязательными.

Наконец, Euler-коэффициенты произведения имеют вид

    Lambda(p^k)[p^(ka)+p^(-ka)]
       =2Lambda(p^k)cosh(ka log p).                    (8.9)

После нормировки 1/2 множитель равен cosh(ka log p) и зависит от k. Ручка B_p умножает ВСЕ степени p одним t_p. При вещественном a!=0 и m>=p^2 это в общем случае не та же ручка. Γ-факторы и полюсы completion тоже сдвигаются. Наличие Euler product и функционального уравнения у X_a не делает его прямой в исходном pencil. При a>0 коэффициенты p^a+p^-a также нарушают рамку Рамануджана с оценкой для каждого epsilon>0. Это прямые следствия Euler product и отражения xi, не импорт положительности.

Имеем Q*H Q=1>0, но A_bad+epsilon H=diag(epsilon,-1) неопределена при любом epsilon>=0. Это не подмена исходной матрицы в теореме 3; это проверка логической силы её заключения.

"""Exact algebra controls; no CCM eigensolver, no numerical zero assumptions."""
from pathlib import Path
from fractions import Fraction

import sympy as s

results = []
def check(name: str, condition: bool) -> None:
    if not condition:
        raise AssertionError(name)
    results.append({'name': name, 'status': 'PASS'})
    print('PASS ' + name)

# P1: a map with exact radial kernel still has a PSD zero-sum direction.
M = [s.diag(1,0), s.diag(0,1), -s.eye(2)]
ones = s.ones(3,1)
t = s.Matrix([s.Rational(2,3), -s.Rational(1,3), -s.Rational(1,3)])
flat = s.Matrix.hstack(*(s.Matrix([X[0,0], X[1,1], X[0,1]]) for X in M))
check('radial_kernel_exact', flat.nullspace() == [ones])
Lt = sum((t[i]*M[i] for i in range(3)), s.zeros(2))
check('radial_kernel_nonzero_PSD_direction', (ones.T*t)[0]==0 and t!=s.zeros(3,1) and Lt==M[0])

for p in list(s.primerange(2, 102)):
    k=1; exponents=[]

        exponents.append(k); k+=1
    check('prime_endpoint_'+str(p), exponents==[1] and max(s.log(p)-s.log(p),0)==0)
check('prime_power_not_dormant', s.simplify(s.log(4)-s.log(2))>0)

y=s.symbols('y')
m=6
nodes=[s.Integer(n*n) for n in range(m+1)]

for j,r in enumerate(nodes):
    dj=s.Integer(1) if j==0 else s.sqrt(2)
    aj=s.cancel(P.subs(y,r)/(dj*s.diff(D,y).subs(y,r)))
    reconstruction += dj*aj*s.div(D,y-r,y)[0]
