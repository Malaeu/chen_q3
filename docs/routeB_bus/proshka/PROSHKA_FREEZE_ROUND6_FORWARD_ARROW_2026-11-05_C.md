## S6-C: автономная остаточная Gram-цепочка

[ABSTRACT / COFINAL_FAMILY | CONDITIONAL: полный сертификат пока не построен.]

1. Для каждого m>=3 источник A_m, L=log m, G_m=I+diag((2*pi*j/L)^2), N=m и Kcal_m={z:z0=0,p_m*z=0} остаются буквальными. Положительный старт Q_m=A_m(1/2) берётся из полного корреляционного демпфирования Round4B, dd22692d, §§1,4: Gamma, оба полюса и все степени сохранены. Это только один фиксированный доказанный старт; никакой delta-поток в цепочку не включается.

2. Независимое от m арифметическое пространство:

   H=ell^2({1,2,...}, w_k=1/[k(k+1)]),
   v(k)=1,
   r_n(k)=(k mod n)/n,  n>=2.

   Остаток k mod n определяется обычным целочисленным делением k=n*floor(k/n)+(k mod n). Начальная положительная метрика в H — тождественная. Граммы строятся только из v,r_2,...,r_N и этих положительных весов.

3. Текущее состояние при N: конечный Gram, ортопроекция Pi_N на span(r_2,...,r_N), остаток v-Pi_N v и число e_N=||v-Pi_N v||_H^2. Начальное e_1=1. Добавление r_(N+1) производится ортогональным исключением; его скалярное уравнение должно иметь вид e_(N+1)=e_N-|b_N|^2/a_N, a_N>0, с отдельно доказанными независимостью словаря и неотрицательностью всех e_N. Случай нулевого нового направления, если встречается в другом источнике, пропускается.

4. Положительный матричный выход конечного префикса:

   P_m^(N)=e_N Q_m.

   Звено при e_N>0: X -> (e_(N+1)/e_N) X. Это конгруэнция скалярным оператором; коэффициент вычисляется из текущего Gram-состояния, не из A_m(0). При e_N=0 выход остаётся нулевым. Разрешённый класс карт: конгруэнции, положительные суммы, ортогональные сжатия и Schur-дополнения положительных Gram-матриц с доказанно положительной опорной частью. Каждое сохранение PSD доказывается для любого допустимого PSD-входа.

5. Остановка, которую необходимо ДОКАЗАТЬ, а не предположить: для каждого достаточно большого m алгоритм достигает конечного N_m с e_(N_m)<=m^(-6). N_m выбирается по остаточному состоянию, без чтения нулей, psi-x, спектра или знака A_m. Никакой заранее обещанной скорости N_m нет.

6. Источниковый выход: доказать независимо, что достижение указанного порога влечёт

   A_m[z] >= P_m^(N_m)[z] - C (1+log m)^2 m^(-3/2) G_m[z]

   с одной конечной C, для всех поздних m и всех допустимых z. Более подробный конечный бюджет через e_N и независимый параметр высоты T должен быть выведен до предельного утверждения. Отсутствие такого бюджета или отсутствие остановки — незакрытая стрелка, не результат RH.

7. Аддитивный/source-мост, который проверяется: при x in (0,1), k=floor(1/x), r_n(k)={1/(n*x)}-n^(-1){1/x}. Поэтому Mellin-образ словаря должен быть (n^(-1)-n^(-s))*zeta(s)/s. Этот мост использует интервалы между СОСЕДНИМИ обычными целыми и их вычеты, а не только свободный моноид делимости. Он не переносится автоматически на generalized-integer counting, DH или completion с квартетом. Полная source identity каждого контрольного мира проверяется отдельно. Если исходный остаточный Gram остаётся тем же после изменения completion, это не разрешает использовать старый Mellin-мост для нового источника.

8. Достаточность: если пункты 5 и 6 доказаны, PSD выход даёт нижний пол, стремящийся к нулю на G-нормированных векторах. Применение закреплённого moving-Gaussian receiver 62f78231 §6 исключает положительный показатель Theta/2, следовательно RH. Обратная импликация и известная классическая сила условия e_N->0 должны быть раскрыты, не спрятаны. Положительность всех Gram-префиксов отдельно не доказывает пункт 5.

9. Граница результата: P_m^(N) может становиться малым. Этот выход НЕ объявляется точной положительной реализацией A_m или новым спектральным оператором. Содержательная обязанность — количественный источник-перенос и доказательство захвата фиксированной цели, а не факт, что положительную матрицу можно умножить на положительное число. Не разрешается назвать e_N->0 следствием одной монотонности.
