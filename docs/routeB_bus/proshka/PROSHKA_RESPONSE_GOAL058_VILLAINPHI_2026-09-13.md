Он ограничен и непрерывен. Вращательная симметрия моделей и принятый Abel-перенос [B] дают E Psi(|Y_N|)=E psi(X_N) и integral Psi d rho=integral psi p. Поэтому (17) исключает также law(|Y_N|)=>rho. Никаких новых предпосылок о плотности предельного радиуса не нужно.

## 6. Что на самом деле порождает вся последовательность

**[COFINAL_FAMILY][PAPER]** На одном вероятностном пространстве возьмём независимые phi_n с плотностями (3) и независимый равномерный Theta. Тогда

\[
S_N(c)=c\sum_{n=1}^N\frac{e^{i\phi_n}}n
=c\sum_{n=1}^N\frac{e^{i\phi_n}-q_n}{n}
+c\sum_{n=1}^N\frac{q_n}{n}.
\tag{19}
\]

Первый ряд сходится в L2: для M>N его квадрат нормы не превосходит c^2*sum_{n>N}n^(-2). Второй сходится абсолютно, поскольку q_n=e^(-pi*n^2). Значит S_N->S_c в L2, Y_N=e^(iTheta)S_N->Y_c=e^(iTheta)S_c в L2; X_N->X_c и |Y_N|->|Y_c| также в L2.

Это **полная последовательность**, не подобранная после результатов подпоследовательность. Ее радиальный закон rho_c^star=law(|S_c|) и проекционный закон p_c^star:=law(X_c) существуют. Для p_c^star не требуется объявлять существование плотности. Он нетривиален:

\[
\boxed{
\mathbb E X_c^2
=\frac{c^2}{2}\left(\frac{\pi^2}{6}
+2\sum_{n<m}\frac{q_nq_m}{nm}\right)
\ge\frac{c^2\pi^2}{12}>0.}
\tag{20}
\]

Сравнение (13) обеспечивает uniform exponential moments для любого фиксированного c,R. Поэтому transforms сходятся к E exp(hX_c) локально равномерно: на |h|<=R сначала отсекаем |X|>T, используя uniform bound при 2R+1; на остатке используем слабую сходимость и конечную сетку по h с равномерной оценкой производной. Предел целый. Theorems 3,7 [NW] дают Lee--Yang для **p_c^star**. Это не вывод о p.

Итак, устройство действительно производит допустимый положительный физический предел. Именно поэтому его несоответствие Phi нельзя скрыть словом «аппроксимация».

## 7. Самая сильная попытка ремонта: изменить только масштаб

**[ABSTRACT][PAPER]** Несовпадение (17) при c=1/2 можно попытаться исправить меньшим c, подогнав дисперсию. Одна дисперсия сама по себе не исключает эту починку. Проверим второе независимое свойство **того же полного закона**: рост по действительному полю.

Из (6) имеем точную факторизацию

\[
\Phi(x)=4\pi^2e^{9x/2-a}H(a),\quad a=\pi e^{2x},
\quad H(a)=1-\frac3{2a}+\sum_{n\ge2}(n^4-3n^2/(2a))e^{-(n^2-1)a}.
\tag{21}
\]

При a>=pi все слагаемые хвоста положительны, поэтому H(a)>1/2. Для верхней границы

\[
H(a)\le1+\sum_{n\ge2}n^4e^{-3(n^2-1)}
\le1+16(3/8)^9\frac{1000}{999}<2.
\tag{22}
\]

Отношение соседних мажорант здесь ещё меньше уже проверенного в (8). Следовательно, для x>=0:

\[
2\pi^2e^{9x/2-\pi e^{2x}}<\Phi(x)<8\pi^2e^{9x/2-\pi e^{2x}}.
\tag{23}
\]

Положим r_h=h/2+9/4 и I(h)=integral_0^infinity exp(hx)Phi(x)dx. При h>=0, заменяя a=pi*exp(2x), получаем

\[
\pi^{2-r_h}\Gamma(r_h,\pi)<I(h)<4\pi^{2-r_h}\Gamma(r_h,\pi),
\quad I(h)/Z\le M(h)\le2I(h)/Z.
\tag{24}
\]

Здесь Gamma(r,pi)=integral_pi^infinity a^(r-1)e^(-a)da. Чтобы не прятать внешнюю асимптотику, достаточно при r>=pi прямых границ

\[
r^{r-1}e^{-(r+1)}\le\Gamma(r,\pi)
\le2[2(r-1)/e]^{r-1}.
\]

Нижняя получается интегрированием на [r,r+1]; верхняя — максимумом a^(r-1)e^(-a/2) и интегралом exp(-a/2). Поэтому log Gamma(r,pi)=r log r+O(r), с достаточными явными односторонними выражениями выше. В результате

\[
\boxed{\lim_{h\to+\infty}\frac{\log M(h)}{h\log h}=\frac12.}
\tag{25}
\]

Это вывод из положительного полного тэта-источника на действительной оси. Он не использует нули xi или RH.

## 8. Ровно та же проверка для звезды; скалярный ремонт невозможен

**[COFINAL_FAMILY][PAPER]** Предел (13) при действительном h даёт

\[
\frac78\prod_{n\ge1}I_0(ch/n)\le M_c^\star(h)\le
\frac87\prod_{n\ge1}I_0(ch/n).
\tag{26}
\]

Бесконечное произведение сходится: log I_0(t)<=t^2/4 около нуля. Оценим его рост без предположений о его нулях. При t>=1 интегрирование только по |a|<=t^(-1/2), где cos a>=1-a^2/2, даёт

\[
\frac{e^{t-1/2}}{\pi\sqrt t}\le I_0(t)\le e^t.
\tag{27}
\]

Пусть H=ch>=2, k=floor(H). Для n<=k применяем (27), для n>k — log I_0(H/n)<=H^2/(4n^2). Тогда

\[
H\sum_{n\le k}\frac1n
-\frac12\sum_{n\le k}\log(H/n)-k(1/2+\log\pi)
\le\log\prod_{n\ge1}I_0(H/n)
\le H\sum_{n\le k}\frac1n+\frac{H^2}{4k}.
\]

Здесь log k<=sum_{n<=k}1/n<=1+log k; кроме того,
0<=sum log(H/n)=k log H-log(k!)<=k(1+log 2), используя integral_1^k log t dt<=log(k!). Поэтому обе границы равны H log H+O(H). Из (26):

\[
\boxed{\lim_{h\to+\infty}\frac{\log M_c^\star(h)}{h\log h}=c.}
\tag{28}
\]

Если p_c^star=p, (25),(28) вынуждают c=1/2. Но (10),(20) тогда дают

\[
\mathbb E X_{1/2}^2-\mu_2>
\frac{\pi^2}{48}-\frac18>
\frac{3}{16}-\frac18=\frac1{16}>0.
\tag{29}
\]

Противоречие. Следовательно, **ни один фиксированный c>0 не исправляет эту звезду с весовым профилем 1/n**. Совпадение только второго момента при другом c не оплачивает полный источник: оно разрушает необходимый коэффициент h log h.

Это исключает также произвольный общий масштаб c_N>0 на N-м графе. Действительно, X_N(c_N)=c_N X_N(1), а X_N(1)=>X_1 с ненулевой дисперсией. Подпоследовательность c_N->infinity не может быть tight: существует r>0 с P(|X_1|>r)>0, и эта масса уходит за любой фиксированный порог. Для всякой ограниченной последовательности масштабов есть подпоследовательность c_N->c>=0. При c=0 предел — delta_0; при c>0 — p_c^star по сходимости (19), а ни один из них не равен p. Поэтому law(X_N(c_N))=>p невозможно.

Граница вывода: не исключены изменения отдельных весов, например низких мод, добавление других связей или другая связь между спектром и графом. Такие изменения меняют названный механизм и требуют новой исходной конструкции. Скалярный запрет не превращается в запрет всего класса Виллена.

## Appendix A. Точный исполнявшийся код

Команда: `python3 verify_villainphi.py`. Код не принимает параметры и не требует подстановки имён или путей. Его проверяемые рациональные сравнения дополняют выведение выше, но не подменяют его. Проверка нескольких коэффициентов I0 в конце — только калибровка: общее неравенство 1/(j!)^2<=1/j! для всех j доказано непосредственно, а не конечным циклом.

SHA-256 кода: `6a22a9cf0b35aca4d8e0c842631c9de7b618e80b306e254f0b5d51c2414ee1a7`.

```python
#!/usr/bin/env python3
"""Exact rational checks for the named Villain-star obstruction.
No theta sampling, quadrature, floating-point arithmetic, or Hankel scan.
Run: python3 verify_villainphi.py
"""
from fractions import Fraction as F
from math import factorial


def add(a, b):
    c = [F(0)] * max(len(a), len(b))
    for i, x in enumerate(a):
        c[i] += x
    for i, x in enumerate(b):
        c[i] += x
    return c


def mul(a, b):
    c = [F(0)] * (len(a) + len(b) - 1)
    for i, x in enumerate(a):
        for j, y in enumerate(b):
            c[i+j] += x*y
    return c


def deriv(a):
    return [i*a[i] for i in range(1, len(a))]


def ev(a, x):
    out = F(0)
    for v in reversed(a):
        out = out*x + v
    return out


def source_step(a):
    return add(mul([F(1,2), F(-2)], a), mul([F(0), F(2)], deriv(a)))


def check(label, condition, value=None):
    if not condition:
        raise AssertionError(label)
    print(label + ': PASS' + ('' if value is None else ' | ' + str(value)))


def main():
    p0 = [F(0), F(-6), F(4)]
    p1 = source_step(p0)
    p2 = source_step(p1)
    check('P1_EXACT', p1 == [0, -15, 30, -8])
    check('P2_EXACT', p2 == [0, F(-75,2), 165, -112, 16])
    q = add(p2, [8*a for a in p0])
    check('Q_EXACT', q == [0, F(-171,2), 197, -112, 16])
    check('Q_AT_3', ev(q, F(3)) == F(-423,2), ev(q, F(3)))
    check('Q2_LOWER', 192*9-672*F(22,7)+394 == 10)
    check('Q1_UPPER_NEGATIVE', ev(deriv(q), F(22,7)) < 0,
          ev(deriv(q), F(22,7)))
    check('PI4_UPPER', F(22,7)**4 < 100)
    check('TAIL_POLYNOMIAL', 197 < 2*144)
    ratio = F(3,2)**8 * F(3,8)**15
    check('FULL_N_TAIL_RATIO', ratio < F(1,1000), ratio)
    tail = 1800*256*F(3,8)**12*F(1000,999)
    check('FULL_N_TAIL_BOUND', tail < F(15,4), tail)
    check('SOURCE_GAMMA_MARGIN', -F(423,108)+F(15,4) == -F(1,6))
    qmax = F(3,8)**3
    eps = 2*qmax/(1-qmax**3)**2
    check('ALL_EDGE_MODES_TOTAL', eps < F(1,8), eps)
    check('RN_LOWER', 1-F(1,8) == F(7,8))
    check('RN_UPPER', 1/(1-F(1,8)) == F(8,7))
    check('C_HALF_GAUSSIAN_EXPONENT', F(10,96) == F(5,48))
    exp1 = F(16,7)/(1-F(5,48))
    check('UNIFORM_ABS_EXP_LT_3', exp1 < 3, exp1)
    psi_tail = 3*12**2*F(3,8)**12
    check('BOUNDED_TEST_TAIL', psi_tail < F(1,64), psi_tail)
    var4 = F(1,8)*sum((F(1,n*n) for n in range(1,5)), F(0))
    check('N_GE_4_VARIANCE', var4 == F(205,1152), var4)
    gap = var4-F(1,64)-F(1,8)
    check('WEAK_TEST_GAP', gap == F(43,1152) and gap > F(1,32), gap)
    check('SIGNED_UPPER_ENVELOPE', -gap < -F(1,32), -gap)
    # These are two admissible edge first-Fourier means, not source data.
    weights = [F(1,2), F(1,4)]
    means = [F(1,3), F(1,5)]
    diag = sum((w*w for w in weights), F(0))/2
    cross = weights[0]*weights[1]*means[0]*means[1]
    check('UNIFORM_CIRCLE_PLANT', diag == F(5,32), diag)
    check('POSITIVE_HEAT_CORRELATION_PLANT', diag+cross == F(79,480), diag+cross)
    check('PLANTED_WRONG_CROSS_SIGN_REJECTED', diag-cross == F(71,480)
          and diag-cross != diag+cross, diag-cross)
    ht = 16*F(3,8)**9*F(1000,999)
    check('FULL_H_TAIL_LT_1', ht < 1, ht)
    # I_0(z)=sum (z^2/4)^j/(j!)^2; its variance coefficient is 1/2.
    check('I0_SECOND_DERIVATIVE_PLANT', 2*F(1,4) == F(1,2))
    for j in range(9):
        if F(1, factorial(j)**2) > F(1, factorial(j)):
            raise AssertionError('I0 majorant plant')
    check('I0_EXP_MAJORANT_FINITE_PLANT', True)
    print('SOURCE_EVALUATIONS=0; QUADRATURES=0; HANKEL_SCANS=0; LEAN_RUNS=0')
    print('SCOPE=NAMED_HARMONIC_VILLAIN_STAR_ONLY; RH_CLAIM=NOT_MADE')
```
