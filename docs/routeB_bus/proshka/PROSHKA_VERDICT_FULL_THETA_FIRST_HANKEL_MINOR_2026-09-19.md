## 1. Первые моменты прямо из полного источника

[ABSTRACT][PAPER] Положим

\[
c(t)=-(\log\Phi(t))'',\quad S(t)=4c(t)^2-c''(t),\quad
Z_\sigma=\int w_\sigma\Phi^2>0,\quad
\langle f\rangle_\sigma=Z_\sigma^{-1}\int w_\sigma\Phi^2 f.
\tag{1.1}
\]

Усреднение здесь идёт по явно положительной плотности источника. Оно НЕ предполагает положительность неизвестного Fourier-спектра.

Определим mu_(2j)=(-1)^j mathscr K_sigma^(2j)(0), mu_(2j+1)=0. Получаем

\[
\boxed{\mu_0=4Z_\sigma,\qquad
\mu_2=2Z_\sigma\langle c\rangle_\sigma,\qquad
\mu_4=Z_\sigma\langle3c^2-c''/2\rangle_\sigma.}
\tag{1.2}
\]

Доказательство: для l=log Phi

\[
l(t+v/2)+l(t-v/2)
=2l(t)+l''(t)v^2/4+l^{(4)}(t)v^4/192+O(v^6).
\]

После экспоненцирования и дифференцирования (0.1) коэффициенты равны соответственно 4, -2l'', 3(l'')^2+l^(4)/2. Подстановка l''=-c, l^(4)=-c'' даёт (1.2). Дифференцирование под интегралом разрешено: на ограниченных v производные Phi(t+v/2)Phi(t-v/2), умноженные на w_sigma(t), имеют интегрируемые мажоранты. Экспоненциальное убывание сохраняется и при sigma=0.

Отсюда точный определитель

\[
\boxed{
\frac{\mu_0\mu_4-\mu_2^2}{\mu_0^2}
=\frac14\operatorname{Var}_\sigma(c)+\frac18\langle S\rangle_\sigma.

\tag{1.3}

Дисперсия равна integral (c-<c>)^2 по плотности (1.1), поэтому её знак уже известен. Неоплаченный до этой попытки член — S; его оценка доказана в §§2–3.

## 4. Положительный моментный блок на всей полосе

[ABSTRACT][PAPER] Для каждого 0<=sigma<=1/2 определим

\[

\[

Это знак на квадратах полиномов степени <=2. Он не равносилен поточечному знаку спектра. Числа 8 и 32 являются моментными запасами, не глобальным нижним полом H или H/sigma.

## 6. Законный переход всех порядков к полному знаку

[ABSTRACT][PAPER, HAMBURGER IMPORT] Для фиксированного sigma полный kernel (0.1) продолжается голоморфно по v в |Im v|<pi/2: оба аргумента Phi остаются в |Im t|<pi/4. На компактах доминирование даёт законность интеграла и дифференцирования. Поэтому для каждого 0<R<pi/2 существует C_R<infinity такое, что

\[
|\mu_{2j}|\le C_R(2j)!R^{-2j}.
\tag{6.1}
\]

Допустим, ВСЕ M_r=(mu_(a+b))_(0<=a,b<=r) положительно полуопределены. По Theorem 3.1 Schmüdgen существует положительная мера nu с этими моментами. Для 0<b<R по Тонелли и (6.1)

\[
\int\cosh(b\tau)d\nu(\tau)=\sum_{j\ge0}\frac{b^{2j}\mu_{2j}}{(2j)!}
\le\frac{C_R}{1-(b/R)^2}<\infty.
\]

Значит характеристическая функция integral exp(i tau v)dnu голоморфна в |Im v|<b. Её Taylor-коэффициенты совпадают с (0.1). Теорема тождественности даёт совпадение на всей вещественной оси. Fourier-единственность и Schwartz-регулярность нашего kernel дают hat mathscr K_sigma>=0.

Обратное направление следует интегрированием |P(tau)|^2 против неотрицательной спектральной плотности. Таким образом, для этого полного источника

\[
\boxed{[M_r(\sigma)\succeq0\ \forall r]\iff
\widehat{\mathscr K_\sigma}(\tau)\ge0\ \forall\tau.}
\]

Доказан переход, но НЕ его предпосылка для всех r. Он требует PSD всех матриц, а не только неотрицательных полных определителей. Для конечного набора моментов это заключение запрещено §5. При выполнении предпосылки для каждого 0<sigma<=1/2 прежний аргумент монотонности |F|^2 исключает внеосевые нули. РХ здесь не заявлена.

K8A:
- DOWNSTREAM_CONSUMER: горизонтальная монотонность |F|^2 для исходного xi.
- ACTUAL_CONSUMER_REQUIREMENT: H>=0, все высоты и 0<sigma<=1/2.
- ORIGINAL_REQUESTED_OBJECT: первый моментный блок полного ядра как ограниченный тест выбранной репрезентации.
- ORIGINAL_OBJECT_IS: PROVED_NECESSARY для полного Fourier-знака, но NOT_SUFFICIENT.
- KNOWN_WEAKER_INTERFACES: прямой полный знак; нижние оболочки с исчезающей ошибкой; положительная факторизация самого kernel. Не требуется фиксированный спектральный пол.
- FAILURE_TYPE: NO_DERIVATION для универсальной положительности всех порядков; COUNTEREXAMPLE только для общего вывода M2=>полный знак.
- EPISTEMIC_STATUS: RESEARCH_DEBT для r>=3; MATHEMATICALLY_DEAD только для общей стрелки, опровергнутой Q в §5.
- KILL_SCOPE этого контрольного вывода: THEOREM_SHAPE; KILL_EVIDENCE_KIND: EXACT_NEGATIVE_FOURIER_VALUE; KILL_EVIDENCE_REF: §5, tau=4.
- REOPEN_TRIGGER для глобального входа: доказанная рекурсия Schur-остатков произвольного порядка или иная факторизация полного kernel.
- NOVELTY_AXIS: источник-специфическая C4-оценка и первый моментный квадрат; математический приоритет не заявляется.
