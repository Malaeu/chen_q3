## 1. Буквальный объект, чётность и неизменный consumer

[FINITE_CELL / COFINAL_FAMILY | PAPER; определения и THEOREM-импорт R1–R3.]

Пусть `m≥3`, `L=log m`, `I_L=(-L/2,L/2)`, `N=m`,
\[
\phi_j(x)=d_j(-1)^jL^{-1/2}\cos(\omega_jx),\qquad
\omega_j=2\pi j/L,\quad d_0=1,\ d_j=\sqrt2\ (j>0),\quad0\le j\le m.
\tag{1.1}
\]
Синтез обозначается `𝒮_m`, чтобы не спутать его со сдвигом. Нулевое продолжение за окно сохраняется. Ровно исходные матрицы:
\[
A_m=H_m+p_mp_m^*-B_m,\quad G_m=I+X_m,\quad
X_m=\operatorname{diag}(\omega_j^2),\quad p(x)=\sqrt2\cosh(x/2).
\tag{1.2}
\]
На полном вспомогательном L² окна, **до** чётного сжатия,
\[
e_n=n^{-1/2}S_{\log n},\quad
Z_L=\sum_{n<m}e_n=\prod_{p<m}(I-e_p)^{-1},\quad
C_L=Z_L^{-1}YZ_L-Y=\sum_{2\le n<m}\Lambda(n)e_n,
\tag{1.3}
\]
\[
Yf=(x+L/2)f,\qquad B_m=\mathcal S_m^*(C_L+C_L^*)\mathcal S_m.
\tag{1.4}
\]
Все простые степени сохранены; `n=m` имеет нулевое перекрытие. Γ-часть полная:
\[
H[f]=\int_0^\infty\frac{e^{-u/2}}{1-e^{-2u}}\|f-T_uf\|_2^2du-c_*\|f\|_2^2,
\quad c_*=\gamma_E+\log(8\pi)+\pi/2.
\tag{1.5}
\]
На чётных тестах `W=H+|<p,f>|²−B`. Для рассмотрения производной и сдвигов используется **полное** эрмитово продолжение: полюсное ядро `2cosh((x−y)/2)`, то есть `p⊗p−r⊗r`, `r=√2 sinh(x/2)`. Его чётное сжатие ровно (1.2), не другой источник.

Важно: `i d/dx` переводит чётную функцию в нечётную. Нельзя объявить его самосопряжённым оператором непосредственно на скалярном косинусном секторе. Вспомогательная динамика строится на полном пространстве; знак по-прежнему проверяется на исходных чётных `V_m`. В `G_m` производная внутренняя, не производная нулевого продолжения.

Наследуемый точный интерфейс:
\[
\mathrm{RH}\iff
\exists C<\infty,\ m_k\to\infty:\quad
z^*B_{m_k}z\le C z^*G_{m_k}z\quad(p_{m_k}^*z=0).
\tag{1.6}
\]
Имеется также эквивалентный полный фиксированный Sobolev-пол. **Предпосылка (1.6) здесь не доказана.** По R4 собственные степени дают `(L/2)e_0e_0*+O_form(G_m)`; эквивалентный prime-only интерфейс на `z_0=0,p_m*z=0` остаётся открытым. R5 запрещает оплачивать соседние сырые prime-shells независимо. Ни тот, ни другой факт не исчезает при смене представления.

## 2. Теорема A: обычная склейка навязывает неправильную спектральную периодичность

[ABSTRACT / COFINAL_FAMILY | PAPER; THEOREM, KILL_SCOPE=THEOREM_SHAPE.]

### 2.1. Точный класс

Рассматривается физическое `𝓗_L=L²((0,L);K_L)` и минимальный оператор
\[
D_{\min}=i\partial_x,\qquad\mathfrak D(D_{\min})=H_0^1((0,L);K_L).
\]
Конечномерный случай: `dim K_L=d_L≥1`. Склейка
\[
\mathfrak D(D_{B,L})=\{f\in H^1:f(L)=B_Lf(0)\},\qquad D_{B,L}f=if',
\tag{2.1}
\]
где `B_L` может зависеть от `m`, всех простых, Γ, полного `Z_L` и любого вычисления, но **не от спектрального параметра**. Скалярные положительные веса нормы, не зависящие от `x`, и фиксированная положительная матрица метрики допускаются после изометрии.

Для самосопряжённых расширений это весь класс: Green identity даёт
\[
\operatorname{Im}\langle f,Df\rangle
=\tfrac12(\|f(L)\|^2-\|f(0)\|^2).
\tag{2.2}
\]
Максимальные нейтральные подпространства граничной формы являются графиками унитарных `B_L`. При `||B_L||≤1` получается максимальное диссипативное расширение в конвенции `Im<f,Df>≤0`.

### 2.2. Спектр и универсальная репликация

Решение `if'=zf` есть `f(x)=e^{-izx}v`. Поэтому
\[
z\in\sigma_p(D_{B,L})\iff e^{-izL}\in\sigma(B_L)\setminus\{0\}.
\tag{2.3}
\]
Для `μ=|μ|e^{iθ}≠0` соответствующие уровни:
\[
z_k=\frac{-\theta+2\pi k}{L}+i\frac{\log|\mu|}{L},\qquad k\in\mathbb Z.
\tag{2.4}
\]
Отсутствие ненулевых собственных значений `B_L` не спасает модель: тогда нет уровней, воспроизводящих нули.

Есть более инвариантное доказательство. Умножение
\[
(V_kf)(x)=e^{-2\pi ikx/L}f(x)
\]
равно единице на обоих концах. Оно сохраняет **любое однородное линейное условие только на endpoint traces**, и
\[
D V_k=V_k(D+2\pi k/L).
\tag{2.5}
\]
Следовательно, репликация охватывает и граничные линейные отношения, не записанные графиком (2.1).

При унитарном `B_L` положительный counting function, с операторными кратностями,
\[
N_{B,L}(T)=\frac{d_LL}{2\pi}T+O(d_L).
\tag{2.6}
\]
При фиксированных `L,d_L` это несовместимо с полным ζ-divisor, у которого `N_ζ(T)~T log T/(2π)`. Это безусловный запрет для полного weighted spectrum, не предположение RH. Сам по себе этот counting-аргумент не подставляется для спектра без кратностей; следующий аргумент этого ограничения не имеет.

### 2.3. Более сильный запрет: не работает и кофинальная спектральная сходимость

Пусть `L_k→∞`, размеры и склейки произвольны. Требуются одновременно:

* хотя бы один настоящий нуль `w` приближается уровнями `z_k∈σ_p(D_{B_k,L_k})`;
* нет спектрального загрязнения: всякая конечная предельная точка уровней принадлежит дискретному нулевому множеству исходной completion.

Из (2.5) при любом вещественном `t` выбираем целые `n_k`, для которых
\[
z_k+\frac{2\pi n_k}{L_k}\longrightarrow t+i\operatorname{Im}w.
\tag{2.7}
\]
Так целая горизонтальная прямая должна состоять из нулей ненулевой entire-функции. Противоречие. **Никакой рост числа каналов не устраняет (2.7).**

Для самосопряжённых склеек имеется ещё более дешёвый свидетель: в любом канале есть уровень `|λ_L|≤π/L`. При `L=log m` он стремится к нулю. Но `Xi(0)=xi(1/2)≠0`: для `0<s<1` знак eta-ряда положителен, `ζ(s)=η(s)/(1−2^(1−s))<0`, а `s(s−1)<0`. Поэтому `xi(1/2)>0`. Самосопряжённая склейка физического растущего окна неизбежно производит ложные уровни около нуля.

Не запрещены выбор отдельных уровней, относительное вычитание спектров или проектирование на source-defined подпространство. Но тогда нужны точные веса/проекция и возврат формы. **Спектр выбранного подпространства — уже не полный спектр расширения (2.1).** Сильная резольвентная сходимость сама по себе также не обещает отсутствия исчезающих в пределе ложных уровней; здесь запрещена именно заявленная полноценная спектральная идентификация.

### 2.4. Бесконечный голый слой каналов не исправляет компактность

Если `dim K=∞`, возьмём ортонормированные `v_n` и фиксированную ненулевую `χ∈C_c∞(0,L)`. Все `f_n=χ v_n` принадлежат минимальной области, значит любой её операторной реализации. Их graph-нормы `||f_n||²+||if_n'||²` одинаковы, а в L² нет сходящейся подпоследовательности. Вложение graph-domain в L² некомпактно. Следовательно, никакое замкнутое расширение с непустой резольвентой не имеет компактной резольвенты.

Внутренний неограниченный оператор по каналам, дополнительная динамика, переменная спектральная метрика или не-L² source quotient выходят из этого класса. Они не убиты данной теоремой.

## 3. Теорема B: буквальный краевой след Z не является граничным условием расширения

[FINITE_CELL | PAPER; THEOREM, KILL_SCOPE=THEOREM_SHAPE.]

В координатах `a=−L/2,b=L/2` правый след конечной суммы сдвигов равен
\[
(Z_Lf)(b-)=f(b)+\sum_{2\le n<m}n^{-1/2}f(b-\log n),
\qquad (Z_Lf)(a+)=f(a).
\tag{3.1}
\]
След понимается почленно; утверждение `Z_L:H¹→H¹` не требуется и вообще может ломаться на внутренних скачках.

Попытка
\[
(Z_Lf)(b-)=U_L(Z_Lf)(a+)
\tag{3.2}
\]
не содержит минимальную область `C_c∞(I_L)` и потому **не задаёт расширение исходного `i∂`**. Доказательство: выбираем bump, равный единице в одной из внутренних точек `b−log n` и нулю во всех остальных; оба endpoint traces равны нулю, левая часть (3.2) ненулевая.

Свидетель существует даже в нужном чётном pole-null классе для каждого целого `m≥3`. Возьмём простой `ℓ|(m−1)` и `x_ℓ=b−log ℓ`. Зеркальная точка `−x_ℓ` совпала бы с другой sampling-точкой только при целом `n=m/ℓ`, чего нет. Кроме того, `x_ℓ≠0`. Две малые симметричные bump-функции дают чётный `f_0` со значением 1 в `±x_ℓ` и нулём на остальных sampling-точках. Вычитаем чётную компактную функцию `g`, поддержанную вне всех этих точек, с ненулевым `<p,g>`, с коэффициентом `<p,f_0>/<p,g>`. Получаем
\[
f\in C_{c,\mathrm{even}}^\infty(I_L),\quad\langle p,f\rangle=0,
\quad (Z_Lf)(b-)=\ell^{-1/2}\ne0,\quad (Z_Lf)(a+)=0.
\tag{3.3}
\]
Здесь `p` — полюсная функция из (1.2), `ℓ` — выбранное простое. Для краевого следа `C_L` тот же свидетель даёт `log(ℓ)/sqrt(ℓ)`.

Это не запрет любых nonlocal boundary operators. Это запрет назвать (3.2) расширением **того же минимального** дифференциального оператора. Изменить минимальную область, скалярное произведение или внутреннее действие можно, но тогда требуется новая точная source identity. Физическая Γ/prime-форма от такого переименования автоматически не возвращается.

## 4. Два ложных детектора унитарности

[ABSTRACT / FINITE_CELL | PAPER; THEOREM, KILL_SCOPE=THEOREM_SHAPE.]

Для любой эрмитовой матрицы `K`, в том числе с отрицательным спектром,
\[
U=(K-iI)(K+iI)^{-1},\qquad U^*U=I.
\tag{4.1}
\]
Можно взять буквальный `K=G_m^{-1/2}A_mG_m^{-1/2}` любого fake-мира. Унитарность остаётся точной. Контрпример в одной размерности: `K=−1`, отрицательный upper envelope `−1<0`, но `U=i` унитарен. Фазы содержат знак; равенство `U*U=I` его не проверяет.

Аналогично для real-type entire-функции `J`, без предположения о её нулях,
\[
M_J(z)=-\frac{J'(z)}{J(z)},\qquad
\mathcal S_J(z)=\frac{M_J(z)-i}{M_J(z)+i}
=\frac{J'(z)+iJ(z)}{J'(z)-iJ(z)}.
\tag{4.2}
\]
На вещественной оси `M_J` вещественна вне полюсов, поэтому `|𝒮_J(t)|=1`. В общих нулях `J,J'` сокращается общий множитель; предельное значение при нуле J равно 1. Это верно для DH и planted quartet. **Нужна аналитическая контрактность в полуплоскости, не унитарность граничных значений.**

Наконец, просто вещественный спектр также не равен унитарности произвольной склейки: `B=[[1,1],[0,1]]` даёт вещественные уровни `2πk/L`, но не самосопряжённый оператор. В геометрическом контроле положительность Розати обеспечивает именно унитарность, а не только расположение собственных значений.

## 5. Точный выживший объект: арифметическая группа на алгебраическом факторе

[ABSTRACT | PAPER; безусловная алгебраическая конструкция, положительная Hilbert-realization — CONDITIONAL.]

Пусть `𝒟_full` — полный комплексный класс гладких тестов с быстрым убыванием вместе с производными быстрее любой фиксированной экспоненты, на котором закреплена смешанная явная формула. Определяем **из арифметической формы**, не из списка нулей,
\[
\mathcal R_W=\{f\in\mathscr D_{\rm full}:W(f,g)=0\ \forall g\in\mathscr D_{\rm full}\},
\qquad \mathcal Q_W=\mathscr D_{\rm full}/\mathcal R_W.
\tag{5.1}
\]
Это алгебраический фактор с невырожденной эрмитовой формой. Он не объявляется гильбертовым пространством или пространством Крейна: соответствующие положительность/топологическая реализация ещё не даны. **Фактор L² по замыканию плотного радикала был бы нулём; он здесь не используется.**

Все члены полного источника зависят от разностей координат. Поэтому для `T_hf(x)=f(x−h)`
\[
W(T_hf,T_hg)=W(f,g),\qquad
\mathsf F_h[f]:=[T_hf],\quad
\mathsf F_{h+k}=\mathsf F_h\mathsf F_k,\quad
\mathsf F_h^{-1}=\mathsf F_{-h}.
\tag{5.2}
\]
Радикал сохраняется. В смысле эрмитовой формы `𝔉_h` является изометрией. Это **не** положительная унитарность. Инфинитезимальное действие на тестах — `[f]↦[if']`; оно симметрично относительно W по дифференцированию (5.2). При этом чётность не сохраняется отдельным сдвигом: исходные чётные тесты остаются подпространством проверки формы, а не самостоятельным пространством этой группы.

### 5.1. Где входит ℚ

В (5.1) подставляется полный источник (1.3)–(1.5), включая Γ и полюс. Точная арифметика находится в
\[
\sum_{d\mid n}\mu(d)=\mathbf1_{n=1},\qquad
\sum_{d\mid n}\mu(d)\log(n/d)=\Lambda(n).
\tag{5.3}
\]
Эти равенства создают именно `Z_L^{-1}YZ_L−Y`, но не дают положительную метрику на (5.1). Это не попытка сделать сам `Z_L=I+nilpotent` унитарным. Использован другой объект — действие сдвига на **source quotient**.

### 5.2. Один внелинейный нуль даёт точный неопределённый блок

Используем Fourier-конвенцию `hat f(z)=∫f(x)e^{izx}dx`; тогда `hat(T_hf)=e^{ihz}hat f`, `hat(if')=z hat f`. Для real-type completion `J` полная смешанная явная формула имеет вид
\[
W_J(f,g)=\sum_{w:J(w)=0}\nu_w\,
\overline{\widehat f(\bar w)}\widehat g(w),
\tag{5.4}
\]
где сумма по различным нулям с кратностями `ν_w`. При вещественных нулях это обычная Gram-форма, при невещественных — не сумма модулей.

Пусть `w∉R` — нуль кратности `ν`. В данном классе источник допускает entire Gaussian-интерполянты. Например, с `J_w(z)=J(z)/(z−w)^ν`,
\[
\widehat g_w(z)=\frac{J_w(z)e^{-z^2}}{J_w(w)e^{-w^2}}.
\tag{5.5}
\]
Он равен 1 в w и 0 во всех остальных нулях. Для ζ и DH произведение Gaussian с entire-функцией порядка один и конечными делителями принадлежит нужному тестовому классу: на каждой горизонтальной полосе Gaussian доминирует рост, а сдвиг Fourier-контура даёт любое фиксированное экспоненциальное убывание. Это построение используется как **отрицательный свидетель**, не как положительная конструкция по нулям.

В подпространстве классов `[g_w],[g_bar(w)]` имеем точно
\[
[W_J]=\nu\begin{pmatrix}0&1\\1&0\end{pmatrix},\qquad
[\mathsf F_h]=\begin{pmatrix}e^{ihw}&0\\0&e^{ih\bar w}\end{pmatrix}.
\tag{5.6}
\]
Действительно, разность `T_hg_w−e^{ihw}g_w` зануляется во всех нулях и по (5.4) лежит в радикале. Оба класса ненулевые: их взаимное спаривание равно ν. Если `w=γ+ia`, `a>0`, модули собственных значений равны `e^(−ah)` и `e^(ah)` для `h>0`.

Следовательно, этот блок **не допускает никакой верной ему положительной гильбертовой реализации**, в которой `𝔉_h` изометричен при `h≠0`: собственный ненулевой вектор должен удовлетворять `||Uv||=|μ| ||v||=||v||`, что требует `|μ|=1`. При этом равенство сохранения неопределённой формы из (5.2) выполняется совершенно точно. Так DH проходит формальное «сохранение формы», но не положительную унитарность.

Для чётных тестов берём также `−w,−bar(w)`. Значения `i` в `±w` и `−i` в `±bar(w)` дают по (5.4) **строгий отрицательный upper envelope** `W_J[f]=−4ν`. Он может быть реализован real-type чётным Gaussian-интерполянтом, как в R1 §9.1. Поэтому препятствие не спрятано в нечётном секторе.

### 5.3. Точная сила конструкции для ζ

[ABSTRACT / COFINAL_FAMILY | PAPER; доказаны импликации, не RH.]

При любом фиксированном `h≠0` следующие утверждения эквивалентны:

1. RH.
2. `𝔉_h` на `𝒬_W` имеет инъективную положительную Hilbert-realization `J:𝒬_W→𝓗` с плотным образом, `J𝔉_h=UJ`, где U унитарен.
3. Существует (1.6), то есть прежний исходниковый кофинальный graph-budget.

`2⇒1`: при внелинейном нуле (5.6) противоречит положительной изометрии. Инъективность существенна: уничтожить плохой блок и сохранить source form невозможно, потому что он невырожден.

`1⇒2`: при RH W неотрицательна; берём completion `𝒬_W` в W-норме. Сдвиги сохраняют её, а непрерывность формы на тестах даёт сильную непрерывность группы. Либо используем условную sampling-realization с весами `ν_w`: интервальные/конечные таблицы нулей для этого универсального утверждения не подставляются. Эквивалентность с 3 — R1–R3.

Это **не новая независимая положительность**. Здесь определён правильный algebraic object и точный положительный контракт. Объявить completion гильбертовым до доказательства знака W означало бы предположить требуемый вывод. Плотный радикал также исключает ненулевое замыкаемое в физическом глобальном H¹ отображение, которое точно реализует W как положительную норму, но не исключает сам новый целевой Hilbert space.

## 6. Обязательный положительный контроль: та же конструкция даёт Фробениус

[ABSTRACT | PAPER; THEOREM-импорт Rosati positivity и trace identity, дальнейшие тождества проверены непосредственно.]

Для кривой `C/F_q` положим `h=log q`, `F=q^(−1/2)π`,
\[
\mathcal E=\operatorname{span}_{\mathbb C}\{F^k:k\in\mathbb Z\},\quad
\langle X,Y\rangle_{\mathcal E}=\tau(X^\star Y),\quad F^\star=F^{-1}.
\tag{6.1}
\]
Rosati pairing положительно определён на этом конечномерном пространстве. Полная source identity S1:
\[
X_f(t)=\sum_{k\in\mathbb Z}f(t+kh)F^k,\qquad
Q_C(f,g)=h\int_0^h\tau(X_f(t)^\star X_g(t))\,dt.
\tag{6.2}
\]
Сумма локально конечна для компактных тестов. `𝒰[f]=√h X_f` проходит через радикал и по completion является изометрическим изоморфизмом на `L²((0,h);𝓔)`.

Прямой сдвиг индекса даёт
\[
X_{T_hf}(t)=F X_f(t),\quad X_f(t+h)=F^{-1}X_f(t),\quad
X_{if'}(t)=i\frac d{dt}X_f(t).
\tag{6.3}
\]
Следовательно, (5.2) **именно** превращается в нормированный Фробениус, а генератор — в
\[
D_F=i\partial_t,\qquad
\mathfrak D(D_F)=\{u\in H^1((0,h);\mathcal E):u(h)=F^{-1}u(0)\}.
\tag{6.4}
\]
Интегрирование по частям и унитарность F дают самосопряжённость; проверка adjoint-domain возвращает то же условие на концы. Это совпадает с Thm.9.3 S1, включая область.

Если `F b_j=e^{ihβ_j}b_j`, собственные функции равны `e^{-i(β_j+2πk/h)t}b_j`, и спектр есть `β_j+2πk/h`. Различные Frobenius phases учитываются один раз; `||b_j||²=m_j` хранит кратность нуля. `𝓔` — не автоматически `2g`-мерный Tate module. Так воспроизводится контроль Сузуки без ложного утверждения о кратностях операторных уровней.

Теорема A не противоречит кривой: здесь имеется **фиксированный фундаментальный период h**, и её нули действительно периодичны. Перенос на длинный интервал `kh` с одним условием `u(kh)=F^(−k)u(0)` создаёт лишние уровни. Для эквивалентности надо дополнительно наложить `u(t+h)=F^(−1)u(t)` внутри всего интервала. Это source-defined подпространство, а не свободная физическая область (2.1).

Явный контроль: `E/F_3: y²=x³−x`. У неё 4 точки над F₃, полином Фробениуса `t²+3`, `F²=−I`, и нормированная completion
\[
J_E(z)=2\cos(hz),\qquad h=\log3,\qquad
M_E(z)=h\tan(hz).
\tag{6.5}
\]
При `Im z>0` мнимая часть `tan(hz)` положительна. Поэтому соответствующий Cayley-функционал из (4.2) контрактен во всей верхней полуплоскости. Это положительный контроль, а не численная гипотеза.

## 7. Адресный дискриминатор: не модуль на оси, а комплексная пассивность

[ABSTRACT | PAPER; THEOREM.]

### 7.1. Определение непосредственно из арифметики ℚ

Пусть `Xi(z)=xi(1/2−iz)` и `s=1/2−iz`. Для `Im z>1/2`:
\[
M_\Xi(z)=i\left[\frac1s+\frac1{s-1}-\frac12\log\pi
+\frac12\psi(s/2)-\sum_{n\ge2}\frac{\Lambda(n)}{n^s}\right].
\tag{7.1}
\]
Затем берётся **его** мероморфное продолжение. Ни список нулей, ни подогнанные фазы не нужны для определения. Это то же полное сочетание полюса, Γ и всех prime powers; брать только конечный Euler product вместо продолжения (7.1) нельзя.

Для настоящей Xi:
\[
\boxed{\mathrm{RH}\iff M_\Xi\text{ — функция Герглотца в }\mathbb C_+
\iff\mathcal S_\Xi\text{ голоморфна и }|\mathcal S_\Xi|\le1\text{ в }\mathbb C_+.}
\tag{7.2}
\]
Функция Герглотца здесь означает голоморфную функцию с неотрицательной мнимой частью. Последнее свойство — **аналитическая пассивность**, а не только модуль 1 на R.

Доказательство: при RH paired canonical product вещественной чётной entire-функции порядка один даёт
\[
M_\Xi(z)=\sum_{\gamma>0}\nu_\gamma
\left(\frac1{\gamma-z}+\frac1{-\gamma-z}\right),\qquad
\operatorname{Im}M_\Xi(z)
=(\operatorname{Im}z)\sum_{\gamma\in\mathbb R}\frac{\nu_\gamma}{|z-\gamma|^2}>0.
\tag{7.3}
\]
Сходимость следует из `Σν_γ/γ²<∞`; evenness исключает лишний линейный экспоненциальный множитель. Обратно, внелинейный нуль дал бы полюс `−ν/(z−w)` в верхней полуплоскости, несовместимый с голоморфностью M. Real-type symmetry исключает затем и нижнюю полуплоскость. Переход к 𝒮 — обычное преобразование Кэли; обратное `M=i(1+𝒮)/(1−𝒮)`. Непостоянная Schur-функция не достигает 1 внутри области. 𝒮 здесь не может быть тождественно 1, поскольку J не нулевая entire-функция.

Вместе с (1.6) это даёт точную цепочку `source graph-floor ⇔ RH ⇔ complex passivity`. **Количественной оценки дефекта 𝒮 через одну конечную матрицу A_m здесь нет.** Эквивалентность глобальных утверждений не является такой оценкой.

### 7.2. Почему это не готовая склейка окна

`𝒮_J(z)` зависит от спектрального параметра. Условие `f(L)=𝒮_J(z)f(0)` — нелинейная spectral pencil, не область одного расширения `i∂` в том же физическом L². Его уравнение `e^(−izL)=𝒮_J(z)` вообще не утверждает `J(z)=0`.

Для реализации такого impedance как границы нужна дополнительная внутренняя динамика и её точный coupling к источнику. Пассивная Hilbert-realization потребует (7.2); выводить его из самого слова «рассеяние» нельзя. Этот кандидат предлагается как **вычислимый адресный судья**, а не уже построенный положительный оператор для ℚ.

### 7.3. Полюс даёт локальный дефект, который остальные нули не могут погасить

Пусть `w=γ+ia∈C_+` — нуль J полной кратности `ν`. В малом диске:
\[
M_J(z)=-\frac\nu{z-w}+r(z),\qquad r\text{ голоморфна}.
\tag{7.4}
\]
После сокращения общего нуля числителя и знаменателя 𝒮 аналитична возле w и
\[
\mathcal S_J(w)=1,\qquad
\mathcal S_J(z)=1+\frac{2i}{\nu}(z-w)+O(|z-w|^2).
\tag{7.5}
\]
Отсюда для достаточно малого `0<ε<a`:
\[
\boxed{|\mathcal S_J(w-i\varepsilon)|^2-1
=\frac{4\varepsilon}{\nu}+O(\varepsilon^2)>0.}
\tag{7.6}
\]
Это положительный дефект `|𝒮|²−1`, то есть отрицательный upper witness для требуемого `1−|𝒮|²≥0`.

Неасимптотическая проверка: если `|r|≤R` в диске радиуса δ, выбираем `ε<min(a,δ,ν/[2(R+1)])`. Тогда `Im M(w−iε)≤−ν/ε+R<−1`, знаменатель не нулевой, а точная формула
\[
|\mathcal S_J(z)|^2-1=-\frac{4\operatorname{Im}M_J(z)}{|M_J(z)+i|^2}
\tag{7.7}
\]
даёт строгий знак. Остальная арифметика входит в ограниченную r и не отменяет полюс. **Адрес — Re w=γ.** Формула не утверждает, что на вещественной сетке всякая отрицательная диагональ A_m находится в одной ячейке от γ.

Если попытаться записать тот же верхний комплексный уровень как eigenvalue статической склейки (2.1), потребуется `|μ|=e^(aL)=m^a`, так что `||B_L||≥m^a`. Это дополнительное препятствие контрактной склейке. Оно само по себе не является оценкой source graph-budget: отображение граничных данных и его нормы могут зависеть от окна. Нельзя молча отождествлять `||B_L*B_L−I||` с дефектом формы A_m.

## 8. Фейки и точный шаг «пол ⇒ положительность»

[ABSTRACT / COFINAL_FAMILY | PAPER; перенос Beurling/DMV — отдельно CONDITIONAL.]

Для собственного корректного источника J используются **его** mixed radical и его return. Если `W_J[f]=−c<0` и `h_n` — собственные радикальные тесты с `h_n→f` в H¹, то
\[
W_J[f-h_n]=W_J[f]=-c.
\tag{8.1}
\]
Любой фиксированный пол `W_J[g]≥−C||g||²_H¹` дал бы `−c≥0` при `n→∞`. При source-correct finite-return это отвергает и любой соответствующий кофинальный матричный пол. Сначала фиксируется n, затем возвращается тест в окно; диагональный обмен пределов не делается.

Плотность собственного радикала здесь не переносится из ζ по имени. Для ζ, DH и указанных entire-деформаций она проверяется заново одним аргументом: функции с Fourier-образом `J(z)e^(−z²)cos(az)` радикальны по (5.4). Если чётный g ортогонален им в H¹ при всех вещественных a, то cosine-transform L¹-функции `(1+t²)overline(hat g(t))J(t)e^(−t²)` тождественно нулевой. Единственность Fourier-преобразования и `J(t)≠0` почти всюду дают g=0. Собственный finite-return для конкретного fake-источника остаётся обязательным; для DH он наследуется из source-correct постановки R1, а для Beurling/DMV не предполагается.

### 10.1. Три проверенные связи между представлениями

**Теория расширений → периодичность.** Green identity и модуляция (2.5) закрывают весь класс endpoint-only физических склеек, требующих полного незагрязнённого спектрального соответствия. Обструкция не зависит от доступной вычислительной мощности или точности Z.

**Impedance → адресное нарушение пассивности.** Логарифмическая производная источника даёт (7.4), а точное Cayley-тождество (7.7) превращает полюс в отрицательный upper witness для `1−|𝒮|²`. Код ниже — выполненный тест; `seeds` содержит лишь начальные приближения, а `eps` — вертикальный шаг вниз от уточнённого верхнего нуля. `dps` — десятичная точность. Вывод сохраняется рядом со скриптом в `diag_results.json`; в длительном цикле есть ASCII-индикатор и ETA. `mpmath==1.3.0` — реально использованная версия, не утверждение о самой новой версии библиотеки.

```python
from __future__ import annotations
import json, time
from pathlib import Path
import mpmath as mp
ROOT = Path(__file__).parent
seeds = [("0.808517", "85.69935"), ("0.650830", "114.16334"),
         ("0.869531", "240.40467"), ("0.574356", "166.47931")]
def dh(s):
    c = (mp.sqrt(10 - 2 * mp.sqrt(5)) - 2) / (mp.sqrt(5) - 1)
    coeff = (mp.mpf(1), c, -c, mp.mpf(-1))
    return mp.power(5, -s) * sum(a * mp.zeta(s, mp.mpf(k)/5)
                               for k, a in enumerate(coeff, 1))
def completion(s):
    return mp.power(5/mp.pi, s/2) * mp.gamma((s+1)/2) * dh(s)
def M_dh(z):
    s = mp.mpf("0.5") - 1j*z
    return 1j * (mp.log(5/mp.pi)/2 + mp.digamma((s+1)/2)/2 + mp.diff(dh, s)/dh(s))
def M_zeta(z):
    s = mp.mpf("0.5") - 1j*z
    return 1j*(1/s + 1/(s-1) - mp.log(mp.pi)/2 + mp.digamma(s/2)/2
                + mp.zeta(s, derivative=1)/mp.zeta(s))
def defect(M, z):
    v = M(z)
    S = (v-1j)/(v+1j)
    direct = abs(S)**2-1
    identity = -4*mp.im(v)/abs(v+1j)**2
    return direct, abs(direct-identity)
def nstr(x): return mp.nstr(x, 32)
records = []
start = time.monotonic()
for dps in (45, 70):
    mp.mp.dps = dps
    for index, (beta, gamma) in enumerate(seeds, 1):
        rho = mp.findroot(dh, mp.mpc(beta, gamma), tol=mp.mpf(10)**(-dps+8), maxsteps=40)
        w = mp.mpc(mp.im(rho), mp.re(rho)-mp.mpf("0.5"))
        row = {"dps":dps, "kind":"DH", "beta":nstr(mp.re(rho)), "gamma":nstr(mp.im(rho)),
               "root_residual":nstr(abs(dh(rho))), "samples":[]}
        s = rho + mp.mpf("0.03")
        fa, fb = completion(s), completion(1-s)
        row["functional_equation_relative_error"] = nstr(abs(fa-fb)/max(abs(fa),abs(fb)))
        row["real_axis_DH_defect"] = nstr(defect(M_dh, mp.re(w))[0])
        row["real_axis_zeta_defect"] = nstr(defect(M_zeta, mp.re(w))[0])
        for eps_s in ("0.001", "0.0001"):
            eps = mp.mpf(eps_s)
            z = w-1j*eps
            dd, err = defect(M_dh, z)
            dz, _ = defect(M_zeta, z)
            dc, _ = defect(lambda z: mp.log(3)*mp.tan(mp.log(3)*z), z)
            row["samples"].append({"epsilon":eps_s, "DH_defect":nstr(dd),
                                   "ratio_to_4eps":nstr(dd/(4*eps)),
                                   "zeta_control_defect":nstr(dz),
                                   "curve_control_defect":nstr(dc),
                                   "defect_identity_error":nstr(err)})
        records.append(row)
        done = (0 if dps == 45 else 5) + index
        eta = (time.monotonic()-start)*(10-done)/done
        print(f"[{'#'*done}{'.'*(10-done)}] {done}/10 ETA {eta:.1f}s", flush=True)
    w = mp.mpc(7, mp.mpf(1)/3)
    poles = (w, -w, w.conjugate(), -w.conjugate())
    def M_plant(z): return M_zeta(z) - sum(1/(z-v) for v in poles)
    row = {"dps":dps,"kind":"PLANTED","w":"7+i/3", "samples":[],
           "real_axis_defect":nstr(defect(M_plant, mp.mpf(7))[0])}
    for eps_s in ("0.001", "0.0001"):
        eps = mp.mpf(eps_s)
        dd, err = defect(M_plant, w-1j*eps)
        row["samples"].append({"epsilon":eps_s, "defect":nstr(dd),
                               "ratio_to_4eps":nstr(dd/(4*eps)),
                               "defect_identity_error":nstr(err)})
    records.append(row)
    print(f"[{'#'*(5 if dps==45 else 10)}{'.'*(5 if dps==45 else 0)}] {(5 if dps==45 else 10)}/10", flush=True)
(ROOT/'diag_results.json').write_text(json.dumps({"status":"DIAG_NOT_INTERVAL", "elapsed_seconds":time.monotonic()-start,
                                               "records":records}, indent=2)+'\n')
print(ROOT/'diag_results.json')
```

Результат этого кода — лишь проверка указанных точек. Он намеренно не создаёт фиктивного `D_B`, не использует ζ-таблицу положительных нулей как доказательство и не выводит никакого универсального знака из конечных контрольных чисел.
