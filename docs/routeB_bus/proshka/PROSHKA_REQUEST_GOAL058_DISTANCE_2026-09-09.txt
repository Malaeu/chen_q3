1. THE OBJECT (observer's reformulation; prove or correct it)
 Write Φ = v_in + v_out, v_in = Φ·1_(−a,a), v_out = Φ·1_{|x|>a}. Let W_a = C_c^∞(−a,a) (or its closure in ℰ = {𝒲 + 𝒟 < ∞} of KERNEL (K6)–(K7)). Since F_Φ(z) = ξ(½+z) vanishes at every zero, the signed explicit formula (K16) gives Q(Φ, w) = 0 for every admissible w — with or without RH. Then for f ∈ W_a and w := v_in − f ∈ W_a:
     Q[f] = Q[v_in − w] = Q[Φ − v_out − w] = Q[v_out + w],
 hence
     λ_a := inf_{f∈W_a} Q[f]/‖f‖² = inf_{w∈W_a} Q[v_out + w] / ‖v_in − w‖².                          (D1)
 Reading: the window floor is the Q-distance² of the theta TAIL to the window space, normalised by the cut mass. Under RH, Q ⪰ 0 on ℋ and (D1) is a genuine (semi)distance; the numerics say W_a approximates the tail in Q-metric to relative error ~√T: Q[v_out] ≈ T‖Φ‖² and inf_w Q[v_out + w] ≈ c·T²‖Φ‖². Under ¬RH the infimum is −∞ for a beyond some a₀ (SCREW dichotomy, SIGNATURE n₋(a)).

2. QUESTION 2 — THE T² LAW (upper bound unconditional, lower bound under RH)
 (a) UPPER (unconditional): prove inf_{w∈W_a} Q[v_out + w] ≤ C(a)·T(a)²·‖Φ‖² with C polynomial in e^{a} (not exponential in e^{2a}). Candidate mechanism: w* = −(the part of v_out that W_a can reach in Q-metric); since Q(u,u′) = Σ_λ m_λ conj(F_u(jλ))F_{u′}(λ) sees only values at zeros, and F_{v_out} is entire of exponential type > a with tiny mass, a window function matching F_{v_out} at the zeros to first order exists (Paley–Wiener / Beurling–Malliavin density of the zero set against type a — cite exactly). Write the proof or the first inequality that fails. Note: an unconditional upper bound of this form is the THEOREM behind «Zhu's certificate is sharp» and behind the wall e^{−2πe^{2a}}: it bounds every future certificate from above.
 (b) LOWER (under RH): is inf_{w∈W_a} Q[v_out + w] ≥ c(a)·T(a)²·‖Φ‖² with c polynomial? This is a lower bound on the distance from a fixed vector to a subspace in a Hilbert space whose norm is a sum over the zeros — a statement about how well type-a entire functions can interpolate a fixed function on the zero set. If it is a known extremal problem (Beurling–Malliavin, de Branges spaces of type a, Suzuki's H_W restricted to (−a,a)), name it with locator. If the honest answer is «λ_a ≥ 0 only, no rate», say so and name what a rate would require.
 (c) THE MECHANISM: identify w* (the minimiser) analytically. Numerically w* is small (‖w*‖² ≈ 1–3 % of ‖v_in‖²) but removes all first-order energy. Guess to test: w* is the Q-orthogonal projection of −v_out onto W_a; give F_{w*} at the zeros, or the integral equation for w* (Suzuki's screw-function kernel g of (1.3) restricted to (−a,a) is the natural candidate: (D1) is a minimisation of ⟨G_a(·),·⟩ with a fixed inhomogeneity).
