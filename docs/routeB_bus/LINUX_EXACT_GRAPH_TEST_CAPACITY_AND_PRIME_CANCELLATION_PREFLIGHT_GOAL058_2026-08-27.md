## 1. PHASE 0 — CAPACITY AUDIT: семейство ДЕЙСТВИТЕЛЬНО УЖЕ

**Полнота есть, но цена сверхполиномиальная.** Оба факта нужны честно.

(а) Полнота. Матрица `[1/(n_j − ζ_i)]` — матрица Коши; при попарно
различных узлах и точках её определитель не равен нулю. Значит `2m+1`
graph-тестов формально порождают всё пространство. Ссылка на «малую
размерность» была бы самообманом, и я её не делаю.

(б) Цена. При `|n| ≥ 2·sup|ζ| = O(L)` разложение

    1/(n − ζ) = (1/n)·Σ_{p≥0} (ζ/n)^p

даёт: с точностью `O((CL/n)^{P+1})` весь high-mode блок семейства лежит в
линейной оболочке **P+1 фиксированных векторов** `(n^{-(p+1)})_j`.
Следовательно, чтобы разрешить `P` независимых направлений на высоких
модах, нужны коэффициенты размера не меньше `(n/CL)^P ≈ (m/log m)^P`.
Разрешение всех `~m` мод требует `P ~ m`, то есть interpolation-константа
растёт как `(m/log m)^{Θ(m)}` — **сверхполиномиально**.

Эффективная размерность семейства при полиномиальной точности `m^{-A}`:

    P_eff ≈ A·log m / log(m/log m) → A  — то есть ОГРАНИЧЕНА

при фиксированной полиномиальной точности; логарифмическая при
экспоненциальной. Полное пространство имеет размерность `2m+1`.

**Вывод Phase 0.** `KILL_IF` (полиномиально ограниченная frame/interpolation
константа) НЕ выполняется. `SURVIVE_IF` выполняется: восстановление
произвольного единичного вектора стоит сверхполиномиально, что превышает
любой компактный consumer-бюджет. Старое проваленное all-unit-v требование
через graph-тесты **не восстанавливается**. Семейство genuinely narrower —
количественно (через обусловленность), не структурно (полнота есть).

## 2. PHASE 1 — точная редукция консюмера (две забанкованные теоремы)

Консюмер: `E_k(z) = centerFactor_k · ⟨C_k⁻¹κ_k(z), r_k⟩`.

`C` эрмитов (Lean: `trialGraphOperator_posDef`), значит

    ⟨C⁻¹κ(z), r⟩ = ⟨κ(z), C⁻¹r⟩.

По **A3** (Lean: `trialGraphOperator_inv_mulVec_residual`)
`C⁻¹r = q − d⁻¹ξ =: w` — вектор ошибки «пробник минус нормированный грунт».
По **B1** (Lean: `proposition59PoleKernel_diagonal_resolvent`)

    E_k(z) = centerFactor_k · c(z) · Σ_j  w_j / (n_j − ζ(z)).

То есть консюмер — **Коши-трансформа дискретной меры ошибки**, а не её
норма. Обе подстановки опираются на kernel-green теоремы; сурогатов нет.

## 3. Что это меняет: стена в прежней форме НЕ воспроизводится

Расщепление по геометрии §0 (граница `|n| ≤ CL` против `|n| > CL`):

**Высокие моды.** Разложение по `ζ` даёт

    Σ_{|n|>CL} w_n/(n − ζ) = Σ_{p≥0} ζ^p · M_{p+1},   M_q := Σ_{|n|>CL} w_n/n^q.

Требуется малость **обратных моментов** `M_q`, а не нормы `‖w‖`. Это строго
слабее: моменты суммируют координаты с весами `n^{-q}` и допускают
знаковое сокращение, которого норма не видит. Именно здесь прежнее
требование теряет силу.

**Низкие моды.** Их всего `O(L) = O(log m)` штук. Устранимость полюса
работает точно: `c(z) = (√L/π)·sin(zL/2)`, и при `ζ → n` числитель
обнуляется линейно вместе со знаменателем, поэтому

    |c(z)/(n − ζ)| ≤ √L · λ^σ  равномерно на подполосе `|Im z| ≤ σ`.

Значит вклад низкого блока `≤ L·λ^σ·(Σ_{|n|≤CL}|w_n|²)^{1/2}`.

## 4. Точный остаточный долг (честно, без сглаживания)

Полного rate у меня НЕТ. Осталось ровно два скалярных требования, и они
теперь названы точно:

1. **LOW**: `(Σ_{|n| ≤ C·log m} |w_n|²)^{1/2} = o( m^{−σ} / log m )`
   — степенная малость ошибки, но лишь на `O(log m)` центральных модах,
   не на всех `m`.
2. **HIGH**: обратные моменты `M_q(w)` малы равномерно по `q` с
   суммируемостью ряда по `ζ^p` на компакте.

Ни одно из двух не эквивалентно прежнему all-unit-v требованию, и ни
одно не сводится обратно к `‖r‖`, `‖Γ‖` или self-energy: перевод обратно
к норме стоил бы ровно той обусловленности, которую Phase 0 показал
сверхполиномиальной.
