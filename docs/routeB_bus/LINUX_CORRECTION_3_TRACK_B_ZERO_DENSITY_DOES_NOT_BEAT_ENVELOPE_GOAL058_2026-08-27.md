## 1. Что не так

Тождество из `74a741a5 §2` верно:

    |f(x+iy)|² / |f(x)|²  =  ∏_n [ 1 + y²/(a_n − x)² ] .

Ошибка — в следующем шаге. Я оценил произведение через
`exp(y²·S(x))`, `S(x) = Σ_n 1/(a_n−x)²`, и объявил ограниченность `S`
достаточным условием. Оценка `1+t ≤ e^t` здесь катастрофически груба:
слагаемых бесконечно много, каждое мало, и сумма показателей сильно
переоценивает произведение.

## 2. Точный счёт на нашей же геометрии нулей

Структура нулей известна точно. Наша функция имеет вид

    G(z) = c · sin(zL/2) · R(z),   R(z) = Σ_j ξ_j/(z − p_j),  p_j = 2πn_j/L,

поэтому её нули — это нули `R` (перемежающиеся с узлами, шаг `≍ 2π/L`)
плюс вся решётка нулей синуса `2πn/L` вне сектора узлов. **Все нули лежат
на решётке с шагом `h = 2π/L`.**

Для такой решётки произведение считается в замкнутом виде:

    ∏_{n∈ℤ} [ 1 + y²/(nh − x)² ]  =  1 + sinh²(πy/h) / sin²(πx/h) .

При `h = 2π/L` имеем `πy/h = yL/2`, значит

    |f(x+iy)| / |f(x)|  ≍  e^{|y|L/2} / (2|sin(πx/h)|)  =  λ^{|y|}/(2|sin|) .

Это **ровно тот же множитель `λ^σ`**, что даёт грубый P59-конверт. Никакого
выигрыша нет. Мой шаг через `S(x)` не только не улучшает оценку — он даёт
`exp(y²L²/8)`, что **хуже** конверта.

## 3. Причина, по существу

Рост в полосе у нашего семейства не является артефактом грубой оценки.
Он структурен: множитель `sin(zL/2)` имеет тип `L/2`, а решётка нулей с
шагом `2π/L` — это ровно та плотность, которая такой тип и порождает.
Вещественность нулей не даёт выигрыша, потому что нули у нас
регулярно-решёточные, а не редкие.

Формулировка из `74a741a5 §3` («грубый конверт переоценивает рост, потому
что игнорирует вещественность нулей») — **неверна**. Отзываю.

## 4. Что выживает

**Выживает целиком** дополнение `7bc66aeb`: на вещественной оси
`Im z = 0`, множитель `λ^{|y|} = 1` тождественно, и требование к невязке
там логарифмическое, а не степенное. Этот вывод не использует ни `S(x)`,
ни переход в полосу.

**Выживает** форма Витали–Портера (`74a741a5 §1`): локальная
ограниченность плюс сходимость на множестве с точкой накопления. Она
по-прежнему правильный каркас.

**Не выживает** заявленный механизм получения локальной ограниченности из
вещественности нулей.

## 5. Честный статус Track B

Track B распадается на две части с разной ценой:

| Часть | Статус |
|---|---|
| сходимость на вещественной оси, требование `‖r‖ = o(1/√log m)` | ДЕРЖИТСЯ, требование логарифмическое |
| локальная ограниченность в полосе | ОТКРЫТА, дешёвого пути нет |

Вторая часть — настоящая щель Track B, и она НЕ решается вещественностью
нулей. Любой будущий кандидат обязан объяснить, откуда берётся отмена
множителя `λ^{|Im z|}`, при том что он структурно присутствует в `sin(zL/2)`.

Замечание для следующего кандидата: предел `Ξ` в полосе не растёт, значит
отмена обязана происходить между `sin(zL/2)` и `R(z)` — то есть внутри
самой конструкции трансформы, а не за счёт свойств нулей.
