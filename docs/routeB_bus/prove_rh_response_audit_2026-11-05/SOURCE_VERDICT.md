## 1. Неизменный источник и обозначения

[ABSTRACT / FINITE_CELL | PAPER; источник R1–R3.]

Для T_t f(x)=f(x-t), j(s)=e^(-s/2)/(1-e^(-2s)) и c_*=gamma_E+log(8pi)+pi/2 полная эрмитова форма:

    W(f,k) = integral_0^infinity j(s)<f-T_s f,k-T_s k> ds
             -c_*<f,k>
             -sum_(n>=2) Lambda(n)/sqrt(n)
                    [<f,T_log(n) k>+<f,T_-log(n) k>]
             +conj(M_+(f))M_-(k)+conj(M_-(f))M_+(k),
    M_±(f)=integral f(x) exp(±x/2) dx.                    (1.1)

Все степени простых, оба полюсных момента и весь Gamma-хвост сохранены. На чётном секторе полюс есть |<p,f>|², p=sqrt(2)cosh(x/2). Форма трансляционно инвариантна в обоих аргументах вместе.

При m>=3, L=log m, I_L=(-L/2,L/2) исходный синтез S_m использует

    phi_j(x)=d_j(-1)^j cos(2pi j x/L)/sqrt(L),
    d_0=1, d_j=sqrt(2) for j>0, 0<=j<=m.

Нулевое продолжение — прежнее. A_m=S_m* W S_m и G_m=I+diag((2pi j/L)^2). G_m измеряет физическую L2-норму и ВНУТРЕННЮЮ производную; конечные косинусы не объявляются глобально H1 после нулевого продолжения.

Положим

    Theta = sup_(xi(rho)=0) |Re rho-1/2|,  0<=Theta<=1/2. (1.2)

Функциональная симметрия даёт также Theta=sup(Re rho-1/2). Это обозначение неизвестного числа, не новый вход в конструкцию. Ни профиль, ни векторы ниже не используют Theta или нули.

## 2. Один фиксированный профиль без слепых внелинейных точек

[ABSTRACT | PAPER; прямое вычисление, без численных тестов.]

Определим раз и навсегда

    eta(x)=pi^(-1/2) exp(-x²),
    g=partial_x²(partial_x²-1/4)eta
     =pi^(-1/2)(16x^4-49x²+25/2)exp(-x²).                (2.1)

Это НЕ радикальный Xi-фильтр. Профиль не зависит от zeta вообще. Он некомпактный; возврат в конечные окна будет отдельно доказан в §6.

Его двусторонний Laplace-transform и Fourier-transform:

    F(u)=integral g(x)e^(ux)dx
        =u²(u²-1/4)exp(u²/4),
    ghat(z)=z²(z²+1/4)exp(-z²/4).                        (2.2)

Следовательно integral g=M_+(g)=M_-(g)=0, и

    F(u) != 0 whenever Im u != 0.                        (2.3)

В частности, F(rho-1/2) не исчезает ни в одном нетривиальном нуле zeta — реальном или внелинейном в спектральной координате. Реальных rho в критической полосе нет: eta-series даёт ненулевость zeta(s) при вещественном 0<s<1.

Обозначим автокорреляцию

    C(t)=integral g(x)g(x+t)dx
        = (partial_t^8 - (1/2)partial_t^6
                         + (1/16)partial_t^4)
                         [exp(-t²/2)/sqrt(2pi)].          (2.4)

C реально-чётна. Все её производные — полиномы, умноженные на Gaussian. Точно integral C(v)e^(uv)dv=F(u)^2. Последнее равенство использует чётность F; никакого модуля в комплексной точке нет.

## 3. Полная арифметическая функция, которую надо ограничить

[ABSTRACT | PAPER identity.]

Положим h(t)=W(g,T_tg), t>=0. Полюсный член нулевой. Прямое раскрытие (1.1) даёт

    h(t)=H_g(t)-S_g(t),
    H_g(t)=integral_0^infinity j(s)
              [2C(t)-C(t-s)-C(t+s)]ds-c_*C(t),
    S_g(t)=sum_(n>=2) Lambda(n)/sqrt(n)
              [C(t-log n)+C(t+log n)].                  (3.1)

Все суммы абсолютно сходятся при каждом t и локально равномерно с производными. Например, сумма атомных масс на log n в [k,k+1] не превосходит O(e^(k/2)) по Chebyshev psi(x)=O(x); Gaussian в C(t±k) делает итог сходящимся.

Из того же разбиения следует

    |h(t)|+|h'(t)| <= C_g exp(t/2),  t>=0.               (3.2)

Архимедов вклад гораздо меньше:

    H_g(t)=O_g(exp(-t/2)).                              (3.3)

Для (3.3) при 0<s<1 использовать симметричную вторую разность C и |C''(t+v)|; это оплачивает j(s)=O(1/s). При s>=1 использовать j(s)=O(e^(-s/2)) и integrability e^(|v|/2)|C(v)|. Члены C(t), C(t+s) имеют Gaussian decay. Это также доказывает ограниченность H_g на всей полуоси.

Поэтому нужная для выбранного пути оценка имеет вид

    sup_(t>=0) S_g(t) < infinity,
    equivalently inf_(t>=0) h(t) > -infinity.             (G)

(G) ниже будет доказана ЭКВИВАЛЕНТНОЙ RH. В этой работе сама (G) не доказана. Введение h не считается доказательством её нижней границы.

## 4. Laplace-идентичность и универсальное обнаружение полюса

### Лемма 1. Точный полный transform

[ABSTRACT | PAPER.]

При Re u>1/2

    integral_0^infinity h(t)e^(-ut)dt
        = F(u)^2 (zeta'/zeta)(1/2+u) + A(u),             (4.1)

где A голоморфна при Re u>-1/2.

**Доказательство.** Для lambda=log n подстановка v=-t в отрицательную половину полного интеграла даёт

    integral_0^infinity [C(t-lambda)+C(t+lambda)]e^(-ut)dt
      =e^(-u lambda)F(u)^2 + R_lambda(u),
    R_lambda(u)=integral_0^infinity
                   C(lambda+v)[e^(-uv)-e^(uv)]dv.         (4.2)

R_lambda цела. На каждом компакте u её модуль вместе с любым числом u-производных ограничен Gaussian по lambda, умноженной на полином и exp(O(lambda)). Поэтому sum Lambda(n)n^(-1/2)R_log(n)(u) — целая функция: сравнить с интегралом O(e^(lambda/2)) Gaussian(lambda). Перестановка исходной Dirichlet-суммы при Re u>1/2 абсолютно законна. Поскольку sum Lambda(n)n^(-1/2-u)=-zeta'/zeta(1/2+u), минус в (3.1) даёт ПЛЮС в (4.1). Laplace-transform H_g голоморфен в Re u>-1/2 по (3.3). Это доказывает утверждение. □

Каждый нуль rho с delta=Re rho-1/2>0 даёт в u_rho=rho-1/2 полюс правой части (4.1) с вычетом

    multiplicity(rho) * F(u_rho)^2 != 0.                 (4.3)

Это один профиль для всех rho, а не выбор профиля после знания rho. Полюс zeta в s=1 снят нулём F(1/2)^2. Правая часть (4.1) голоморфна возле каждой положительной вещественной u: zeta не имеет вещественных нулей s>1/2, а singularity при s=1 устранима после умножения.

### Лемма 2. Односторонняя осцилляция с любым меньшим показателем

[ABSTRACT / COFINAL_FAMILY | PAPER; conditional only on existence of the named off-line zero.]

Если имеется нуль с delta>0, то для каждого 0<=a<delta

    liminf_(t->infinity) e^(-at)h(t) = -infinity,
    limsup_(t->infinity) e^(-at)h(t) = +infinity.          (4.4)

**Доказательство.** Предположим сначала h(t)>=-M e^(at) для всех поздних t. На конечном начальном отрезке добавим неотрицательную компактную поправку, чтобы k(t)=h(t)+M e^(at)+b(t)>=0 на всей полуоси. b имеет компактную поддержку, её Laplace-transform целый.

Абсцисса сходимости sigma_c transform k конечна по (3.2). Полюс (4.3) заставляет sigma_c>=delta>a: иначе transform k был бы голоморфен в u_rho, тогда как его мероморфное продолжение имеет там ненулевой полюс. На вещественной sigma_c правая часть (4.1), M/(u-a) и transform b аналитичны.

Для неотрицательного k это невозможно. Вот нужная лемма Ландау без скрытой Tauberian-посылки. Если transform аналитичен через конечную sigma_c, выбрать sigma_1>sigma_c достаточно близко и Taylor-диск, достигающий sigma_1-v<sigma_c. Taylor-коэффициенты по v равны integral t^n e^(-sigma_1 t)k(t)dt/n! и неотрицательны. Сходимость ряда и монотонная сходимость дают конечность integral e^(-(sigma_1-v)t)k(t)dt — противоречие определению sigma_c.

Следовательно eventual lower bound не существует ни при каком M. Непрерывность h на компактах даёт первый предел (4.4). Для второго повторить аргумент с -h; знак ненулевого вычета не имеет значения. □

Замечание: это liminf/limsup, НЕ монотонная дивергенция h и НЕ отрицательность в каждом позднем окне.

## 5. Ближайшая доказанная теорема: точный показатель одного отклика

[COFINAL_FAMILY | PAPER; T1 для полной явной формулы.]

Для r_+=max(r,0) имеем безусловно

    limsup_(t->infinity) log(1+(h(t))_+)/t = Theta,
    limsup_(t->infinity) log(1+(-h(t))_+)/t = Theta.        (5.1)

**Доказательство верхней границы.** Полная mixed explicit formula даёт

    h(t)=sum_(rho) F(rho-1/2)^2 exp((rho-1/2)t),          (5.2)

с кратностями. Это НЕ sum of absolute squares, пока RH не доказана. Продолжение с компактных тестов к g законно: Gaussian cutoff errors стремятся к нулю в экспоненциально взвешенных source-нормах; на нулевой стороне

    |F(beta-1/2+i gamma)|^2
       <= C(1+|gamma|)^8 exp(-gamma²/2).                 (5.3)

В силу порядка один Xi сумма этих мажорант конечна. Она сходится локально равномерно по t. Поэтому |h(t)|<=M_g e^(Theta t).

**Нижняя граница.** При Theta>0 для любого a<Theta можно выбрать нуль с delta>a и применить (4.4). Получаются оба неравенства limsup>=a; затем a->Theta. При Theta=0 верхняя граница и неотрицательность log(1+r_+) дают оба нулевых предела. □

При RH формула (5.2) становится абсолютно сходящейся cosine-суммой с неотрицательными коэффициентами |ghat(gamma)|². Тогда

    |h(t)|<=h(0)=W[g].                                  (5.4)

Обратно, одной постоянной нижней границы h достаточно по Лемме 2. Итак,

    RH <=> inf_(t>=0) h(t)>-infinity <=> (G).             (5.5)

(5.1) содержит количественное утверждение, которого не было в прежнем judge: один заранее выбранный профиль восстанавливает весь supremum отклонений нулей. Однако (5.5) не делает неизвестный знак известным и не устанавливает меньшую сложность доказательства.

## 6. Один явный вектор в каждом буквальном A_m

[COFINAL_FAMILY | PAPER; новая moving-family оценка, не незаконное применение fixed-test леммы.]

Зафиксируем один C-infinity чётный cutoff chi, равный нулю при |y|>=1 и единице на [-3/4,3/4]. Можно взять chi(y)=1-s(4|y|-3), где s(v)=b(v)/(b(v)+b(1-v)), b(v)=exp(-1/v) при v>0 и b(v)=0 иначе. Возле y=0 chi постоянна, поэтому модуль не нарушает гладкость.

Для L=log m задаём

    t_m=L/2,
    f_m(x)=g(x-L/4)+g(x+L/4),
    v_m=S_m* [chi(2x/L) f_m(x)],
    vtilde_m=v_m-v_(m,0)e0,
    w_m=vtilde_m-(p_m* vtilde_m)/p_(m,1) e1.             (6.1)

Здесь p_m=S_m* p и p_(m,1)>0 — известный полюсный коэффициент. Все операции определены из g, L и исходного базиса. Ни zeta-zero, ни eigenvector A_m не используются. Точно w_(m,0)=0 и p_m*w_m=0.

### 6.1. Ошибки и края

Все внутренние нормы f_m^(j) ограничены по m, поскольку это сумма двух сдвигов одного Gaussian. Между центрами ±L/4 и областью, где chi перестаёт равняться 1, расстояние не меньше L/8. Поэтому для любых фиксированных A,j,N

    ||exp(A|x|) partial^j[(1-chi(2x/L))f_m]||_2
       =O_(A,j,N)(m^(-N)).                              (6.2)

Это следует из exp(-cL²+O_A(L)) и не требует неизвестной арифметической оценки. Производные cutoff имеют только степени 1/L.

У срезанной функции все краевые следы равны нулю. Для любого q>r Fourier-series tail в исходной частоте Omega_m=2pi m/L удовлетворяет

    ||(I-P_m^cos)(chi f_m)||_(H^r_int)
       <= C_q Omega_m^(r-q).                            (6.3)

Выбирая q после фиксированных r,N, получаем любой m^(-N) с допустимыми log-факторами. Моментные ошибки в (6.1) также сверхполиномиальны: цена exp(|x|/2) на окне и ||p||_2 имеет полиномиальный масштаб; p_(m,1) асимптотически положительная константа times m^(1/4)/sqrt(L).

Для prime-формы norm <=2 sum_(n<m) Lambda(n)/sqrt(n)=O(sqrt(m)); для полюса norm O(sqrt(m)+L). Gamma-форма ограничена внутренним H1-бюджетом на поддержке окна, как в R3. Эти полиномиальные цены умножаются на (6.2)–(6.3). Нулевое продолжение конечных косинусов может иметь скачки: их цена входит в Gamma-bound, а не игнорируется.

Для перехода от всего f_m к cutoff f_m можно использовать directly экспоненциальную source-bound: взвешенная норма самого f_m растёт не быстрее степени m, норма Gaussian-tail убывает быстрее любой степени. Абсолютная prime-сумма и смешанный Gamma-integral потому дают тот же исчезающий бюджет. Не требуется заранее объявлять f_m компактной.

В итоге для каждого N

    w_m* A_m w_m = 2W[g]+2h(t_m)+O_N(m^(-N)),
    w_m* G_m w_m -> 2||g||_(H1)^2 >0.                   (6.4)

Первое равенство использует точную трансляционную инвариантность полного W. Второе — Gaussian decay перекрытия двух пакетов и (6.2)–(6.3).

Пусть z_m=w_m/sqrt(w_m*G_mw_m) для всех достаточно больших m и

    q_m=z_m*A_m z_m.                                    (6.5)

Тогда z_m*G_mz_m=1 и z_m принадлежит прежнему Kcal_m.

### Теорема 2. Точный отрицательный показатель одного матричного направления

Безусловно

    limsup_(m->infinity) log(1+(-q_m)_+)/log m = Theta/2. (6.6)

При Theta>0 для каждого 0<=b<Theta/2 также

    liminf q_m/m^b = -infinity,
    limsup q_m/m^b = +infinity.                          (6.7)

**Переход от непрерывного t к целым m.** Для любого большого t выбираем ближайшее целое к e^(2t). Тогда |t-t_m|=O(e^(-2t)); по (3.2) |h(t)-h(t_m)|=O(e^(-3t/2)). Поэтому все экспоненциальные осцилляции (4.4) видны на этой решётке. Нормировка в (6.5) стремится к положительной константе; добавка 2W[g] не меняет положительный показатель. Верхняя оценка следует из |h(t)|<=M_g e^(Theta t). При Theta=0 она даёт нулевой показатель, а под RH q_m>=0 для самих конечных A_m. Это доказывает (6.6)–(6.7). □

В частности,

    RH <=> exists C,M: q_m>=-C for EVERY integer m>=M.    (6.8)

Квантор здесь другой: ОДИН заданный вектор, но ВСЕ поздние окна. Произвольную хорошую подпоследовательность для q_m подставлять нельзя. Прежний полный graph-floor мог использовать подпоследовательность, поскольку контролировал ВСЕ направления. Конечные прогоны (6.8) не доказывают.

**Более слабый достаточный бюджет.** Из (6.6), без новой положительной посылки, следует также

    RH <=> for every epsilon>0 there exist C_epsilon,M_epsilon:
             q_m >= -C_epsilon m^epsilon
             for every integer m>=M_epsilon.             (6.9)

Не нужны одна константа для всех epsilon или конкретная скорость epsilon->0. Любой настоящий нуль с delta>0 противоречит (6.9) уже при одном epsilon<delta/2. Это меняет достаточную обязанность: можно доказывать односторонний субполиномиальный рост ОДНОГО направления, вместо постоянного пола всей матрицы. Само (6.9) не доказано; более слабая внешняя форма не означает установленной меньшей арифметической трудности.

## 7. Попытка доказать требуемую границу — и её точная остановка

### 7.1. Безусловная оценка реально получена, но она растёт

[COFINAL_FAMILY | PAPER; T2 plus (5.2).]

Классический zero-free region и отсутствие нулей на Re s=1 позволяют уменьшить c0 так, чтобы

    beta <= 1-c0/log(|gamma|+3)

выполнялось для всех нетривиальных нулей. Начальная компактная область содержит конечное число нулей, отделённых от Re s=1; их вычисление не требуется для существования c0.

Для t достаточно большого делим АБСОЛЮТНО сходящуюся сумму (5.2) при |gamma|=sqrt(t). Низкая часть по (5.3) не больше

    C exp[t/2-c0 t/log(sqrt(t)+3)].

Высокая часть не больше C exp(t/2-t/4)=C exp(t/4): оставить половину Gaussian для суммируемой мажоранты, другую оплатить условием gamma²>t. Следовательно существуют c,C>0 с

    |h(t)| <= C exp[t/2-c t/log(t+3)],
    |q_m| <= C exp[(log m)/4-c (log m)/log(log m+3)].     (7.1)

Это вывод для ДАННОГО Gaussian-сглаживания. Он не переносится автоматически на несглаженную ошибку PNT или все векторы A_m. Не заявляется новая zero-free region.

Правая часть (7.1) всё ещё стремится к бесконечности. Она совместима с любым фиксированным off-line смещением меньше 1/2. Поэтому (7.1) НЕ даёт (G), (6.8), dagger или SD.

### 7.2. Где осталась именно арифметика

[ABSTRACT | PAPER identity; односторонняя оценка OPEN.]

Пусть E(x)=psi(x)-x,

    w_t(x)=x^(-1/2)[C(t-log x)+C(t+log x)].

Интегрирование по частям, с E(1)=-1 и Gaussian boundary at infinity, даёт ТОЧНО

    S_g(t)=I(t)+2C(t)+J(t),
    I(t)=integral_0^infinity (e^(v/2)-e^(-v/2))C(t+v)dv,
    J(t)=integral_1^infinity E(x)x^(-3/2)
          { [C(t-log x)+C(t+log x)]/2
             +C'(t-log x)-C'(t+log x) } dx.             (7.2)

Для I использовано integral_R e^(v/2)C(t-v)dv=e^(t/2)F(1/2)^2=0. Поэтому I(t) и C(t) ограничены и Gaussian-малы при t->infinity. Начальный член +2C(t) не удалён. Все Lambda(p^k) остаются внутри psi.

Незавершённая строка теперь имеет совершенно конкретный вид

    sup_(t>=0) J(t) < infinity.                         (7.3)

Она эквивалентна (G); это не следствие знака E(x), поскольку такого знака нет, и ядро в (7.2) также знакопеременно. Форма автокорреляции обеспечивает точное зануление главной массы, но не знак дискретного остатка.

Я не получил (7.3) из обычной целой решётки, Möbius-инверсии или геометрии двух проекций. Раскрытие (7.2) не считается новой one-sided prime estimate. Нельзя повысить (7.1) до постоянной или вызвать Landau в обратном направлении без посылки нижней ограниченности.

Для более слабого consumer (6.9) не обязательно получать постоянную в (7.3). Достаточно, и также RH-эквивалентно,

    for every epsilon>0 there exists C_epsilon:
       J(t)<=C_epsilon exp(epsilon*t) for every t>=0.    (7.4)

Оценка (7.1) имеет экспоненциальный показатель 1/2, а (7.4) требует нулевой показатель только для положительной части J. **Не получены ни (7.3), ни более слабая (7.4). Это точное место остановки доказательства RH**, не техническая оговорка об audit.

## 8. Приёмка: один и тот же профиль, названное место отказа

[ABSTRACT / COFINAL_FAMILY | PAPER, с указанными source imports.]

### 8.1. DMV

Используем W_B=H+P-B_B ровно в смысле R1, не приписывая ей completed zero identity. Gaussian-суммы и (4.1) переносятся по psi_B(x)=O(x); весь отрицательный-tail correction (4.2) остаётся целым. Вместо zeta'/zeta стоит zeta_B'/zeta_B.

Как в R1, выбирается b0 между 3/4 и 1 без вещественных нулей в [b0,1), затем один нуль beta>b0. НОВОЕ: профиль g выбирать после этого не нужно — F(rho-1/2) автоматически ненулевой. Landau-абсцисса >=beta-1/2>b0-1/2 попадает в вещественную область без полюсов. Значит h_B не ограничена снизу; для каждого a<beta-1/2 действует (4.4). DMV проваливается непосредственно на (G), а не только при дальнейшем source-return. Gaussian matrix return использует O_B(sqrt(m)) и остаётся законным.

### 8.2. DH

Берутся ВСЕ b_D(n), включая b_D(6), собственная odd-Gamma j_D=e^(-3s/2)/(1-e^(-2s)), conductor 5 и отсутствие полюсной формы — R4, (3.3)–(3.6). Не подставляется обычный prime product.

Сумма логарифмической производной абсолютно сходится в некоторой правой полуплоскости, например Re s>2. Это обеспечивает экспоненциальную мажоранту h_D; Gaussian делает коррекцию (4.2) целой и здесь. Laplace-transform содержит F(u)^2 D'/D(1/2+u). Реальных нулей D(s) при s>0 нет по положительной группировке коэффициентов R4 §4.2. Его известный внелинейный нуль даёт ненулевой остаток при том же F. Поэтому тот же Landau-аргумент опровергает (G)_D. Ни данные об ординатах, ни простой корень не нужны.

### 8.3. Подсадка a=1/3, gamma=7

Для completion xi(s) times [((s-1/2-a)^2+gamma²)((s-1/2+a)^2+gamma²)] сохраняем ДОПОЛНИТЕЛЬНУЮ полную quartet-форму. Её вклад в Laplace-response имеет полюсы при u=±a±i gamma. F(a+i gamma) не равен нулю; если исходная xi уже имела такой нуль, полная кратность только увеличивается. Симметричный множитель строго положителен на вещественной оси, так что нового вещественного полюса логарифмической производной нет.

Тот же argument даёт unbounded negative response. После t_m=(log m)/2 для каждого 0<=b<1/6 имеем liminf q_m^plant/m^b=-infinity. Это утверждение об истинной полной подсаженной форме; старые Lambda и Gamma без quartet-добавки не выдаются за весь источник. Отказ снова на (G), с явным ненулевым вычетом.

### 8.4. Кривая E/F3

Для СОБСТВЕННОЙ формы кривой, h=log3 и gamma_n=(pi/2+pi n)/h:

    h_E(t)=sum_n |ghat(gamma_n)|² exp(i gamma_n t),
    |h_E(t)|<=sum_n |ghat(gamma_n)|²<infinity.             (8.1)

Это непосредственно проходит ту же нижнюю границу отклика. Gaussian coefficients дают абсолютную сходимость; нули gamma_n вещественны явно, не предполагаются по аналогии с zeta. Положительность W_E и буквальных сжатий следует из той же суммы квадратов. Не подставляется zeta-Gamma в curve-source.

### 8.5. Что приёмка не даёт

(G) проваливается на всех трёх отрицательных мирах и проходит кривую. Это доказывает, что критерий не слеп к требуемым фейкам. Это НЕ доказывает его для настоящей zeta. Свойство ordinary integer lattice ещё не использовано для оплаты (7.3). Конечная унитарность u_m, quasi-inner compactness, source equality и injectivity F по отдельности не поставляют эту границу.
