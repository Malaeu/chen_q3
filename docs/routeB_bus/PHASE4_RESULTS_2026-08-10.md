## Зачем

Вердикт требует Вход 1 — `D_c ⪰ dI` с явным `d > 0` на хвосте `T_R` — и объявляет
`YoshidaTailCoercivity13Explicit` минимальным named gap всего маршрута. Мифос оценил
цену этого шага вилкой

```
R(μ=1) ∈ [2·10², 10⁵]
```

и написал прямо: «вся стоимость проекта сидит в этой вилке». Разброс в 500 раз — это
разница между конечной задачей на полсотни мод и неподъёмной.

Вилка получена двумя прокси-оценками символа. Мы её **измерили** вместо оценивания.

## R1 · Что померили

Для каждого среза `n ≥ n₀` проверяется интервальным `LDL^T` без пивотирования:

```
K_odd[n₀:, n₀:]  ⪰  μ·I,   μ = 1
```

Матрица строится **не заново**, а импортом `CCMArbBuilder` из
`phase1_scripts/ccm_control_cell_penalty.py` — теми же source-side формулами
(`w02 − wr − prime`), которыми получен сертификат Phase 1. Расхождение формул исключено
по построению, а не проверкой.

Результат при `N = 120`, `dps = 40`, шаг сетки 1:

```
n₀ = 69   fail   NONPOSITIVE_PIVOT @ pivot 4
n₀ = 70   PASS   минимальный пивот [0.7603670240015970605172441220555054432411 ± 1.95e-41]
n₀ = 71   PASS   [0.7606964614605413829259870202748264604968 ± 4.14e-41]
```

Переход резкий и монотонный: всё, что ниже 70, проваливается; всё, что от 70 и выше,
держит пол.

```
R(μ = 1) = 70
```

## R2 · Это не артефакт обрезания — проверено тем, что различает

Срез конечен, поэтому первое подозрение: не меряем ли мы просто край нашей матрицы. Исход,
который различает прочтения, очевиден — **настоящий порог не должен двигаться при росте
`N`**, артефакт обрезания обязан ползти вместе с ним.

| `N` | порог `n₀` |
|---|---|
| 60 | 48 |
| 90 | 72 (сетка шага 4) |
| 120 | **70** |
| 180 | 72 (сетка шага 4) |
| 240 | **70** |

Точное значение считалось шагом 1 при `N = 120` и `N = 240` — **оба дают ровно 70**,
совпадает и точка перехода (`69` fail → `70` PASS). Значения при `N = 90, 180` получены
сеткой шага 4 и с ним согласованы.

Выпадает только `N = 60`: там от порога до края остаётся 12 мод, то есть обрезание само
меньше измеряемой величины. Это ожидаемое поведение края, а не контрпример.

## R3 · Настораживающее наблюдение, записанное до объяснения — и снятое в тот же час

Минимальный пивот при переходе **просел** на удвоении:

```
N = 120   0.7603670240015970605172441220555054432411
N = 240   0.7342389581660078168603269624116358064253
```

−3.4% на удвоении `N`. Это ровно та форма, которая в этом проекте уже однажды означала
беду: `β*_N` падал на 18.9% за удвоение, и именно это дало `DELTA_RATE_UNRESOLVED`.

Два прочтения записаны до счёта:

- **(a)** пол сходится к положительному пределу, падение затухает;
- **(b)** пол ползёт к нулю геометрически, и тогда при больших `N` порог вырастет, а вилка
  Мифоса окажется права.

Различающий исход: посчитать третью точку. Если падение повторится тем же темпом — (b);
если остановится — (a).

**Посчитано, `N = 480`, тот же срез `n₀ = 70`:**

```
0.7342389581660078168603269624116358064253
```

Совпадает с `N = 240` **до последней из сорока значащих цифр**. Падения нет вовсе:
минимальный пивот достигается на модах, уже включённых при `N = 240`, и добавление мод
`241…480` его не меняет. Прочтение (b) снято, (a) подтверждено.

Наблюдение закрыто в тот же час, когда записано.

## Что это значит для маршрута

**Вилка сужена в 500 раз и оказалась ниже своего нижнего конца.** Мифос давал
`[2·10², 10⁵]`, измерено `70` — втрое меньше нижней границы вилки и в 1400 раз меньше
верхней.

Практический вес: `corrected-head` матрица `B_c − d⁻¹R_c*R_c` из Входа 2 имеет размер
порядка `R`. При `R = 70` это конечная задача, которую мы считаем здесь за секунды. При
`R = 10⁵` маршрут был бы неподъёмным. Прогноз вердикта
`tail_supplier: PASS_AFTER_EXPLICIT_CONSTANT_EXTRACTION` этим замером поддержан.

## Чего это НЕ доказывает

**Это не сертификат хвоста и не Вход 1.** Измерена компрессия `T_R` на конечный срез:
моды выше `N` в проверку не входят ни при каком `N`. Устойчивость по `N` — сильное
свидетельство, но не доказательство утверждения о бесконечномерном хвосте.

Для настоящего `D_c ⪰ dI` нужна теорема, и здесь открыт вопрос Q8 очереди: для формы
Вейля целевое утверждение — Yoshida [33, Lemma 3] (пол в честной `L²`-норме), а не
Suzuki Theorem 4.3 (пол в норме антипроизводной), куда отправляет `TASK_B`. Этот замер
не решает, какая из двух теорем инстанцируется, — он говорит только, что искомая
константа мала.

Не проверялось: другие `μ`; чётный сектор; ячейки `m ≠ 13`; поведение при `c₀ = 1e-58`
вместо `μ = 1` (у вердикта `d = 1 − c₀`, отличается от единицы на `1e-58`, то есть за
пределами этой точности неразличимо).
