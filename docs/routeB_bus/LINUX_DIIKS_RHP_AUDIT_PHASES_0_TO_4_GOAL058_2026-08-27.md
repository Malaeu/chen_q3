## PHASE 1 — диагональный адаптер (поправка судьи принята)

Стандартное dIIKS-ядро имеет НУЛЕВУЮ диагональ; наша `M` — нет. Точная
факторизация:

    M − aI = H_a · ( I + H_a⁻¹ K0 ),   H_a := A_diag − aI .

`H_a⁻¹K0` снова zero-diagonal dIIKS с левым вектором
`f_i ↦ (H_a)_ii⁻¹·f_i`, то есть `f_i = ((β_i, 1)/(τ_ii − a))`, `g_j = (1, −β_j)`;
условие `f_iᵀg_i = 0` сохраняется (скалярный множитель на строке).

**Исключительный случай выписан, не спрятан:** если `τ_ii = a` хотя бы для
одного `i`, `H_a` вырождена, и факторизация недоступна; тогда требуется
блочное расщепление по множеству `{i : τ_ii = a}`. Моя прежняя фраза
«(K−aI)⁻¹ прямо есть IIKS-резольвента, потому что K/a интегрируемо» —
слишком сильна для полной матрицы; отзываю, принимаю формулировку через
адаптер.

## PHASE 2 — генератор смещения для графа C (точный, минимальный)

    [D,P] = (Dq)q* − q(Dq)*                                    (ранг 2)
    [D,M] = β𝟙ᵀ − 𝟙βᵀ                                          (ранг 2, kernel-green)

Раскрытие `C = (M−ε) − P(M−ε) − (M−ε)P + P(M−ε)P + P` даёт коммутатор,
чьи все члены лежат в оболочке шести векторов

    { q,  Dq,  r,  Γ = D r,  β,  𝟙 } ,

где замыкание обеспечивается тождеством
`(M−ε)Dq = D(M−ε)q − [D,M]q = D r + (a−ε)Dq − (𝟙·q)β + (β·q)𝟙`.
Следовательно

    [D,C] = U Vᵀ,   rank ≤ 6 ,

и `[D,C⁻¹] = −C⁻¹UVᵀC⁻¹`, то есть `C⁻¹` — Коши-подобная.

**Циркулярность признаю явно (твой P4/атака):** генераторы `C⁻¹U` и
`C⁻ᵀV` содержат нерешённые системы. Называть их «явными» до решения dRHP
или эквивалентной структурированной системы нельзя. Здесь это НЕ делается.

## PHASE 4 — арифметическое замыкание: точный вид β

Это главный результат аудита. Считаю с диска, без приближений.

Ядро (`ccmQKernel`) при `m = 0`, `n ≠ 0`:

    Q(L, n, 0, x) = ( sin(0) − sin(2πnx/L) ) / (π(n − 0)) = − sin(2πnx/L)/(πn) .

Прайм-вклад: `Prime(n,0) = Σ_{k≤m} Λ(k)·k^{−1/2}·Q(L,n,0,log k)`, поэтому

    β_n^{prime} = n·Prime(n,0) = −(1/π)·Σ_{k≤m} Λ(k)·k^{−1/2}·sin(2πn·log k / L) .

**Множитель `n` сокращается тождественно.** Остаётся чистая
тригонометрическая сумма с частотами `θ_k = 2π·log k / L`. Собирая её в
комплексную форму, `k^{2πin/L} = e^{2πin log k/L}`:

    β_n^{prime} = (1/π)·Im [ (ζ'/ζ)_{≤m} ( 1/2 − 2πin/L ) ] .

**То есть вектор `β` — это сэмплирование логарифмической производной
дзеты ВДОЛЬ КРИТИЧЕСКОЙ ПРЯМОЙ**, в точках высоты

    t_n = −2πn/L ,   n = −N … N ,

то есть с шагом `2π/log m` вплоть до высоты `2πm/log m`.

Два остальных вклада:

- `β_n^{W02} = 32L·sinh²(L/4)·n/(L² + 16π²n²)` — **рациональная функция `n`**
  (получено подстановкой `m = 0` в `ccmW02Entry`); голономна порядка 1.
- `β_n^{WR}`: тот же множитель `n` сокращается, остаётся Фурье-коэффициент
  гладкого веса на `[0,L]`; конечной рекуррентности нет, но есть быстрое
  убывание по `n`.

### Ответ на вопрос Phase 4 судьи

**Конечная рекуррентность существует ровно для прайм-части**: сумма `J`
синусов удовлетворяет линейной рекуррентности порядка `2J` с
характеристическим полиномом

    ∏_{k = p^j ≤ m} ( x − k^{2πi/L} )( x − k^{−2πi/L} ) ,

то есть **её корни суть степени простых, поднятые в мнимую степень**.
Порядок `2·π(m) ≍ 2m/log m` — меньше размерности `2m+1` лишь
логарифмически. Полная `β` не голономна из-за `WR`-интеграла.

## Что это означает для dRHP (и для всего маршрута)

Данные вычетов нашей дискретной задачи Римана–Гильберта **суть значения
`ζ'/ζ` на критической прямой**. Отсюда сразу:

1. **Объяснение всех прежних стен.** Мы девять раз упирались в «оценку про
   простые» не потому, что плохо искали, а потому что входные данные
   задачи буквально ЕСТЬ дзета на критической прямой. Любой маршрут,
   требующий контроля `β`, требует контроля `ζ'/ζ` там же.
2. **Точная цена IIKS.** Структура настоящая, но твоя атака попадает:
   dRHP с такими данными не проще исходной задачи, пока нет независимого
   контроля сэмплов `ζ'/ζ`.
3. **Но появляется различающий вопрос**, которого раньше не было:
   консюмер `E(z)` есть спаривание с `κ(z)`, а не норма `β`. Сэмплы
   `ζ'/ζ` входят в него **со знаками и осцилляцией**, и вопрос —
   сокращаются ли они в этом конкретном спаривании.
