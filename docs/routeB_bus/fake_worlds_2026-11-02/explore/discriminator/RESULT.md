# Non-prime-power loading as a finite source discriminator

DIAGNOSTIC_NEVER_A_PROOF. The three-case exploratory calibration separates the selected matched cases. This is a source-mechanism probe on saved complement-minimum vectors, not a theorem or a universal sign detector.

## Hypothesis and fixed test

Define

    R_NPP(f) = [Σ_{n≤m, n not a prime power} b(n) Q_f(log n)/sqrt(n)] / H_original(f).

The numerator keeps the actual signed coefficients and correlations. It is harmful when positive because arithmetic is subtracted in the original source form. The denominator is the entire positive original arch jump energy including its tail, with the correct kernel for each world. All quantities use the same selected unit physical vector within each case.

Before evaluating these ratios, PREREGISTRATION.md fixed the predictions R_NPP<0.75 for DH80 q41 and R_NPP>0.75 for both DH120 q63/q65. It prohibited threshold adjustment if any prediction failed. The broader task context already supplied the DH80/DH120 arithmetic and arch scales before choosing0.75. This is retrospective exploratory calibration, **not independent predictive validation**. Registration before recomputing ratios provides an audit trail, not a held-out test.

## Falsifier and limits

The fixed three-case retrospective separation passed. A stronger proposed interpretation—“negative DH complement iff R_NPP>0.75”—is already falsified by the pre-specified native controls:

|DH80 q73|-1.24068701|0.74432098|

The threshold is therefore a finite separator for the requested matched cases, not a necessary condition for negativity. Different complements select different minimizing vectors. No independence, unseen-sample generalization, causal effect of deleting atoms, operator bound, zero-location conclusion, or cofinal rate follows. The saved zero censuses and numerical minimizers retain their parent dataset's qualifications.

## New intervention: delete NPP atoms on the unchanged complement

A separate addendum fixed a genuinely new sign-removal prediction before calculating any altered spectrum: delete all non-prime-power arithmetic, hold the original physical carrier and complement synthesis U fixed, and predict that all three altered complement minima become positive. No threshold was selected from these new spectra.

The altered matrix is A_delete=A_D+P_NPP, so it preserves the correct DH arch term, scalar constant and every prime-power coefficient. It changes the arithmetic source. It is **not asserted to satisfy the DH functional equation**, retain its zero set or have the original quiet residual. This is a finite intervention on source components, not an analytic DH/Euler interpolation.

The pre-specified sign-removal prediction passed in all3 cases. This recomputes the entire minimum on the fixed complement; positivity of the old minimizing vector alone would not have established that result. The NPP matrix need not be positive semidefinite, and no monotonicity argument is used. New minima were computed with mpmath eigsy at80dps; eigen residuals are below8.4e-80. The independent modal NPP contraction on each old minimizer reproduces its saved atom total. These are numerical diagnostics, without outward-rounded interval positivity certificates.

The intervention strengthens the local mechanism evidence: the negative matched120 complements disappear when this arithmetic sector is removed, while all other source pieces and the space are held fixed. It does not imply that every NPP coefficient is necessary, identify a canonical analytic replacement function, or prove any cofinal proposition.
