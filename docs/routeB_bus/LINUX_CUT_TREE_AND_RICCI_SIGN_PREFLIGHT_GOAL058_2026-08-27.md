# CUT TREE + RICCI SIGN — preflight

## 6. RICCI–DOOB SIGN GATE: **FATAL**, и доказывается в три строки

Гейт требует диагональной калибровки знаков `S = diag(s_i)`, после которой
все внедиагональные элементы `S K S` имеют допустимый марковский знак; для
троек это условие `sign(K_ij K_jk K_ki) = −1`.

Для `i < j < k` (то есть `n_i < n_j < n_k`) знаменатели дают

    sign K_ij = sign(β_j − β_i),
    sign K_jk = sign(β_k − β_j),
    sign K_ki = sign(β_k − β_i),

поэтому произведение равно `sign[(β_j−β_i)(β_k−β_j)(β_k−β_i)]`, и оно равно
`+1` ровно тогда, когда тройка значений **возрастает** (или два других
порядка из шести). Значит гейт требует: **у `β` нет возрастающей тройки**.

**Такая тройка есть всегда, по чётности.** С диска: все три компоненты `β`
нечётны по `n` (синус в прайм- и архимедовой частях, множитель `n` в
рациональной `W02`-части), поэтому

    β_{−n} = −β_n ,     β_0 = 0 .

Возьмём любое `n > 0` с `β_n > 0` (существует: `β` не тождественно нулевая).
Тогда индексы `−n < 0 < n` дают

    β_{−n} = −β_n < 0 = β_0 < β_n ,

то есть возрастающую тройку. Произведение знаков `+1`, калибровки не
существует.

    RICCI_DOOB_SIGN_FRUSTRATION_FATAL .

Классический марковский/Риччи-маршрут закрыт **структурно, а не численно**:
фрустрация следует из нечётности `β`, то есть из того же свойства, которое
даёт нулевую массу веса. Твоя ставка `P_RICCI_2` (0.76) подтверждена, и
причина оказалась сильнее ожидаемой — не «один неудачный треугольник», а
тождественная невозможность.

## 1–3. Точные тождества (ток, дивергенция, разрез, Хаар)

    J_{jl}(v) = Re(conj(v_j)·v_l)/(n_j − n_l),   J_{lj} = −J_{jl}
    w_j = Σ_{l≠j} J_{jl} = div J
    W_i = Σ_{j≤i} w_j = Σ_{j≤i} Σ_{l>i} J_{jl} = Flux через разрез (i,i+1)
    Σ_j β_j w_j = −Σ_i (Δβ)_i · W_i
    sup_i |W_i| ≤ 2π‖v‖²                    (неравенство Гильберта, точная константа)

Ступенчатое разложение и его операторная форма:

    β_j = β_{−N} + Σ_i (Δβ)_i · 1_{>i}(j) ,
    [M_β, H] = Σ_i (Δβ)_i · [M_{1_{>i}}, H]     (константа коммутирует)

Замена базиса на Хаар (каждый `h_I` = «разрезать кусок `I` пополам»):

    [M_β, H] = Σ_{I ∈ D} ⟨β, h_I⟩ · [M_{h_I}, H] .

## 4. Универсальная цель (равномерно по N)

    ‖ v · (H_N v) ‖_{H¹_d}  ≤  C · ‖v‖₂²      (константа не зависит от N)

эквивалентно карлесоновской оценке квадратичной функции на коэффициентах
потока разрезов. Это гармонический слой, арифметики в нём нет.

## 5. Требуемая скорость для завершённой β

Downstream требует `o(1/√log m)` на вещественной оси и
`o(m^{−σ/2}/√log m)` на компакте. По Coifman–Rochberg–Weiss достаточно
было бы `‖β‖_{BMO_d} = o((log m)^{−1/2})`, но это сильное требование.
Реалистичный вариант — consumer-weighted:

    Σ_{I ∈ D} |⟨β, h_I⟩|² · ω_I(v) = o(1/log m) ,

где `ω_I(v)` измеряет поток разрезов выбранного consumer-вектора.

## Интеграция спектральной стороны (запрос владельца)

Наблюдение, которое здесь становится рабочим: наша матрица есть
**конечная явная формула** — три её слагаемых суть в точности полюсной,
гамма- и прайм-члены. У явной формулы два берега; всё, что мы делали,
считалось на левом (простые). Правый берег выражает тот же элемент через
**нули дзеты**.

Для диадической программы это конкретно означает вот что.
`⟨β, h_I⟩` — средняя осцилляция `β` на масштабе `|I|`. На левом берегу это
осцилляция прайм-полинома. На правом — вклад нулей, чья высота отвечает
масштабу `|I|` по нашему словарю `t_n = 2πn/L`. То есть **диадический
масштаб `I` ↔ окно высот нулей**, и карлесоновская сумма по дереву есть
энергия нулей, разложенная по масштабам.

Практическое следствие: требуемая оценка не обязана знать нули поимённо —
ей достаточно их **распределения по масштабам**, а плотность нулей
(Риман–фон Мангольдт) известна безусловно. Это первый пункт за сессию, где
правый берег может дать вход, не требуя RH.

**Оговорка, чтобы не повторить свою же ошибку:** переход между берегами
законен только на завершённой формуле с явными остаточными членами, и
никакого поэлементного равенства `β` с `ζ'/ζ` здесь не утверждается —
только соответствие масштабов.

## 7. Два кандидата, если диадическая цель не закроется

**K1 — оконная спектральная сторона.** Оценивать `⟨β, h_I⟩` через
правый берег: вклад нулей в полосе высот, отвечающей `|I|`, с
безусловной плотностью вместо поимённого знания. Kill 8/10, cost 7/10.

**K2 — connection-Laplacian кривизна.** Твой резерв: знаковая геометрия
сохраняется, фрустрация входит как индекс, а не как убийца. Дорого, но
после FATAL знакового гейта это единственная выжившая кривизна.
Kill 7/10, cost 9/10.
