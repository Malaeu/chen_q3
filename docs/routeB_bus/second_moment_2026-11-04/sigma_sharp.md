# Uniform scalar sampling envelope

DIAGNOSTIC_NEVER_A_PROOF. `sigma_sharp.csv` contains m=16,…,300 and column `sigma_sharp`. Its input γ* is read as the full decimal first-ordinate string from the pinned arithmetic ζ census. Treating that point as a lower bound for every relevant ζ ordinate is the requested diagnostic assumption; this computation supplies no independent zero-free theorem. This cap is not valid for DH/plant merely because their heights are tabulated, and is not substituted into their control scores.

Put x0=Lγ*. On x≥x0, the maximum of sinc(x) is attained either at x0 or at the next positive stationary maximum. Such maxima solve x cos x−sin x=0 in (2kπ,2kπ+π/2), k≥1, and have value 1/√(1+x²), strictly decreasing with k. Negative lobes cannot beat the later positive maximum. Hence only those two candidates are required; this is a uniform scalar envelope, not a sampled-zero supremum. The script bisects the scalar root at 90 decimal digits and returns σ=L[1+max(sinc(x0),1/√(1+xpeak²))]. Numerical values are point approximations, not interval enclosures. Improvement over L+1/γ* ranges from roughly 6.34e−6 to .00854 over the 285 cells. No F2, zero-tail sign, finite trace correction or source-count conclusion is proved by this small sharpening.
