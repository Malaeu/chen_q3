## 1. Наблюдение, которое меняет цену условия (i)

Грубый P59-конверт растёт как `λ^σ = m^{σ/2}`, где `σ` — полуширина
подполосы. Источник роста — множитель `|sin(zL/2)| ≤ e^{|Im z|·L/2}`.

**На вещественной оси `Im z = 0`, значит `λ^σ = 1`.** Рост исчезает
тождественно, не «почти», а точно: `|sin(xL/2)| ≤ 1`.

Поэтому условие (i) отчёта `74a741a5` — равномерная ограниченность
`|G_k(x)|` на вещественном отрезке — стоит

    |E_k(x)| ≤ C·√(log m) · ‖r_k‖ ,     x ∈ ℝ ,

то есть требует лишь

    ‖r_k‖ = o( 1/√(log m) )   —   ЛОГАРИФМИЧЕСКОЕ требование.

## 2. Сравнение цен

| Маршрут | требование на `‖r_k‖` |
|---|---|
| прямой (Γ = D·r, убит) | `o(m^{−1−σ/2}/log m)` |
| прямой (graph-test, компакт в полосе) | `o(m^{−σ/2}/√log m)` |
| **Витали (вещественная ось + плотность нулей)** | **`o(1/√log m)`** |

Степень исчезает целиком. Остаётся логарифм — и он один и тот же для всех
компактов, потому что вход берётся только на вещественной оси, а переход
в полосу делает формула плотности нулей из `74a741a5 §2`.

## 3. Полная схема Track B в трёх строках

1. `‖r_k‖ = o(1/√log m)` ⟹ `E_k → 0` **на вещественной оси**
   (никакого степенного множителя, `σ = 0`).
2. `sup_k S_k(x) < ∞` на вещественном компакте, `S_k(x) = Σ_n 1/(a_n^{(k)}−x)²`
   ⟹ семейство локально ограничено **в полосе** (формула `74a741a5 §2`,
   работает только благодаря вещественности нулей).
3. (1) + (2) + Витали–Портер ⟹ `G_k → Ξ` локально равномерно на каждом
   компакте ⟹ Гурвиц ⟹ нули `Ξ` вещественны.

## 4. Что осталось, честно

Ни (1), ни (2) не доказаны.

Про (1): логарифмическое требование НЕ следует автоматически из
имеющегося. Тривиальная оценка `‖r‖ ≲ ‖K‖` растёт как `√m`, то есть даже
логарифмический порог сегодня не покрыт. Но категория требования сменилась
со степенной на логарифмическую, а это ровно тот масштаб, где безусловные
оценки вообще живут.

Про (2): это утверждение о геометрии нулей приближений, не об арифметике.
Для эталона `Ξ` соответствующая величина конечна.

## 5. Почему это не скрытый реимпорт прайм-рейта

Проверка по твоему guard: единственное место, где могла бы спрятаться
недостающая оценка, — шаг (1). Там стоит `‖r_k‖`, тот же самый объект, что
и в прямом маршруте, но **с показателем ноль вместо `σ/2`**. Это ослабление
требования, а не переименование. Шаг (2) вообще не содержит `r` и не может
нести прайм-вход: в него входят только нули уже построенных функций.
