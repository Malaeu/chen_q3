## 1. Находка

`q3.lean.aristotle/Q3/Proofs/RouteB/H2aPenaltyCoercivity.lean:395`

```lean
theorem H2a_SimpleEvenGround_FromPenaltyCoercivity
    (G K J : Matrix n n ℂ) (q : n → ℂ) (a β τ : ℝ)
    (hG : G.PosDef) (hK : K.IsHermitian)
    (hJ : J * J = 1) (hJG : Jᴴ * G * J = G) (hJK : Jᴴ * K * J = K)
    (hJq : J *ᵥ q = q)
    (hq : star q ⬝ᵥ (G *ᵥ q) = 1)
    (ha : star q ⬝ᵥ (K *ᵥ q) = (a : ℂ))
    (hab : a < β)
    (hcert : (K - (β : ℂ) • G + (τ : ℂ) • Matrix.vecMulVec (G *ᵥ q) (star (G *ᵥ q))).PosSemidef) :
    ∃ lam : ℝ,
      (∃ x, GEig K G lam x) ∧
      lam ≤ a ∧
      (∀ μ y, GEig K G μ y → lam ≤ μ) ∧
      (∀ μ y, GEig K G μ y → μ ≠ lam → β - a ≤ μ - lam) ∧
      (∀ x y, GEig K G lam x → GEig K G lam y → ∃ c : ℂ, y = c • x) ∧
      (∀ x, GEig K G lam x → J *ᵥ x = x)
```

Доказана, sorry-free, конечномерная, базис-инвариантная. Из **одного конечного
PSD-сертификата** получаются сразу четыре вещи: существование нижнего собственного
значения, **простота**, **чётность** и **явная щель `λ₂ − λ₁ ≥ β − a`**.

Пробник `q` даёт `a` как своё рэлеевское значение; `β − a` — запас коэрцитивности над
пробником. Сертификат — не аналитика, а конечная матричная проверка `⪰ 0`: та же
технология, что отлажена на 054 (Arb-энклоужеры → Lean).

**Инструмент не упомянут в `MAP.md` ни разу.** Мы его забыли, нашли случайно —

## 2. Почему это может быть важно за пределами нашего маршрута

Программа Конна–Консани–Московичи (CCM 2511.22755) сводит RH к трём входам:

| Вход | Утверждение | Состояние |
|---|---|---|
| A | нижнее состояние формы Вейля `QW_λ` просто и чётно при **всех** λ | открыт; Судзуки Thm 1.4 — только малые окна |
| B | пролатная догадка приближает арифметический вектор с темпом `o(λ^{−η})`, ∀η<½ | открыт; упирается в щель `Δ_λ` |
| C | галёркинский пролёт `N→∞` при фикс. λ | открыт |

Мосты после гейта `A∧B∧C` доказаны, 4 из 4. Входов доказано 0 из 3.

**Щель `Δ_λ` не ограничена ни в одной из шести центральных работ этого кластера.** Судзуки
доказывает простоту и чётность через positivity-improving полугруппу, но только для малых
окон, и щель **не оценивает вообще**.

Форма Вейля на галёркинском усечении — эрмитова матрица на `2N+1` модах. Это ровно тот
объект, который наша теорема ест. Инволюция `J` стоит там же, где у Конна чётность
`u ↦ u⁻¹`.

**Статус: гипотеза о связи, не результат.** Матрицы Конна (§4 CCM 2511.22755) в оригинале
никто из нас не читал — только через пересказ. Поэтому и пакет.

Она меряет секционную щель `λ₂^(N) − λ₁^(N)`. Но перенос пола на оператор идёт **не через

**M4 — читается тем же заходом, что M1, но это отдельный вопрос.**
**Замкнута ли форма Вейля `QW_λ` на своей области, и является ли `⋃_N E_N` её форм-керном?**
Сказано ли это у Конна явно, или подразумевается.

Почему это критично — добавлено 2026-08-07 после зума
(`maps/ZOOM_2026-08-07_GAP_TRANSFER_THROUGH_GALERKIN.md`):

Сертифицированный пол щели **не переносится** с секции на оператор как щель — Галёркин по
Куранту–Фишеру даёт `λ_k^(N) ≥ λ_k`, то есть **только оценки сверху**, а для щели нужна
нижняя оценка на `λ₂`, которой он не даёт вовсе.

Переносится **сертификат**, потому что он есть неравенство между формами:
`∀v ∈ E_N : Q(v) − β‖v‖²_G + τ|⟨Gq,v⟩|² ≥ 0`. Неравенства между формами переносятся по
плотности; собственные значения — нет. Если сертификат держится на каждом `E_N` с одними и
теми же `β, τ, q`, неравенство верно на `⋃E_N`, **а на всей области — только если это
форм-керн**. Тогда min-max на коразмерности один даёт `λ₂ ≥ β`, и с `λ₁ ≤ a` получается
`λ₂ − λ₁ ≥ β − a` уже для оператора.

**Без ответа на M4 весь перенос условен.** У Конна `E_N` — линейная оболочка нижних
собственных функций оператора масштабирования; правдоподобно, что керн, но это надо
предъявить, а не предположить.
