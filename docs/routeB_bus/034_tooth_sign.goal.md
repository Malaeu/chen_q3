# ГОЛ 034 — EXACT FULL-WINDOW TOOTH SIGN CERTIFICATE

От: диспетчер. Формулировка собрана Codex по входам 031 и 033, судьёй не
утверждена — при расхождении с решением Mythos приоритет за судьёй.
Статус: `CHALLENGER / NOT_RH`. `BUS_010_VOID`. SCOPE: `FINITE_CELL m=257`.

## Почему этот гол

033 закрыл интегральный бюджет по всему окну
(`FULL_WINDOW_POSITIVE_PART_BUDGET_PROVED`), но оставил вторичный флаг
`TOOTH_SIGN_INCONCLUSIVE`. Зубья не входят в лебеговский бюджет **по
построению**: множество меры нуль под интегралом не видно. Их знак — это
отдельная задача, а не хвост предыдущей.

## Предмет

Для каждого `r = 17..257` рассмотреть точный зуб

```text
S*_r = Σ_{n=1}^{r-1} Ψ(n/r) + Ψ(1)/2
```

Доказать `S*_r ≥ 0` для всех 241 зубьев и дать точное разбиение на `S*_r > 0`
и `S*_r = 0`.

Разбиение по ledger 033: **179 зубьев уже положительны** — идут как regression
controls; **62 zero-compatible зуба** — основной объект работы.

## Входы, доказанные в 031

- `S*_r = r·T_r(Ψ) − Ψ(0)/2` — `EXACT_TOOTH_ALIAS_IDENTITY_PROVED`
- `L_Theta4(δ) = ((Theta4 − Theta0)/2)·b0`, `δ_0 = 0` —
  `JACOBI_DIVIDED_DIFFERENCE_IDENTITY_PROVED`

## Метод

1. Переписать каждый зуб через alias-тождество 031.
2. Применить конечный дискретный Green ledger к divided difference.
3. Для каждого ещё не закрытого зуба построить знаковый dual-множитель,
   делающий forcing pairing неотрицательным.
4. Нижний boundary term занулять **только** через `a_-1 = 0` и точное `δ_0 = 0`.
5. Терминальный boundary term оставить живым и сертифицировать его знак —
   подмена terminal ratio нулём запрещена.
