Independent normalization and F-tail review

core.py normalization: CONFIRMED.
For Omega=2*pi*n/L,
(1/2) Im psi(1/4+i*Omega/2)
  = sum_{r>=0} Omega / ((2r+1/2)^2+Omega^2).
Subtracting the exponential terms in core.beta gives exactly source(3.2).
All prime powers are retained; an endpoint atom has sin(Omega*L)=0.
The row formula is source(3.1), including d0=1 and dj=sqrt2.
xiH=2*s*(s-1)*pi^(-s/2)*Gamma(s/2)*zeta(s)=4*xi(s).
H is real even, so using s=1/2+it agrees with the -it convention.
The high coefficient sqrt(2/L)*(-1)^n*H(2*pi*n/L) is source(3.5).
Raw F has no Z normalization; Z belongs in the subsequent inverse-weighted mass.

The coarse fully explicit source(3.6)-(3.7), optimized over p=1..300,
gives respectively for m12/16/20/24:
p98:6.70893e-39; p87:2.10322e-34; p81:1.81744e-31; p76:2.15588e-29.
It does not provide the desired <1e-90 tail at R192.

Sharper elementary analytic envelope:
For s=1/2+it, t>=1, Euler summation gives
zeta(s)=s/(s-1)-s*int_1^infinity {x}*x^(-s-1) dx,
hence |zeta(s)|<=1+2*sqrt(t^2+1/4).
Rotate the Gamma integral by theta=pi/2-1/t, obtaining
|Gamma(1/4+it/2)| <= Gamma(1/4)*(sin(1/t))^(-1/4)
                           *exp(-pi*t/4+1/2).
Using sin(1/t)>=2/(pi*t) and t>=1 yields
|H(t)| <= C*t^(13/4)*exp(-pi*t/4),
C=(5/2)*Gamma(1/4)*exp(1/2)*2^(-1/4)*(1+sqrt5)
 =40.6657195911519587636...
No zero-location assumption is used.

Set n0=R+1, a=pi^2/(2L), rho_q=exp(-a)*(1+1/n0)^q,
S_q=n0^q*exp(-a*n0)/(1-rho_q).
For n>=n0 the ratio of successive n^q exp(-a*n) is <=rho_q<1.
Source row(3.4) and R>=2m give the explicit F-vector tail bound
sqrt(2/L)*C*(2*pi/L)^(13/4) * [ A_row*S_(5/4)+2*B_row*S_(9/4) ].
It also bounds every normalized eigenvector coordinate F_i.

m12:1.14023143000284e-157 (round up to1e-156)
m16:1.93176563745697e-140 (round up to1e-139)
m20:2.57168297787001e-129 (round up to1e-128)

These are evaluations of an analytic envelope, not an interval certificate for
all matrix/eigenvector/quadrature errors. They address the infinite F-mode tail
only. They supply no lower bound on a cancellation-prone F_i or lambda_i.

Principal-angle implementation: CONFIRMED.
Columns are scaled before high-precision SVD; no Gram inverse is formed.
Angles use canonical-vector orthogonal residuals for sine and atan2(sin,cos),
which avoids loss from acos(1-epsilon). Raw cosines and orthogonality errors
are retained. For rank6 ladder, k3 has4 canonical angles plus2 unmatched
ladder dimensions; k5 has6 angles; k7 has6 angles plus2 unmatched cluster
dimensions. Thus the eight-dimensional cluster is not silently reduced to6.

Forced intersections are explicitly reported as
max(0, ladder_rank + cluster_dimension - ambient_dimension).
In particular m12,k7 gives6+8-13=1 exactly shared dimension, hence one
structurally zero principal angle. A tiny computed first angle there is
roundoff, not an additional scientific alignment result. Raw angles remain.
