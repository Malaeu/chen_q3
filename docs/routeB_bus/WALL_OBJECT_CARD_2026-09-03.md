## Объект
Форма Вейля в лог-переменной `x = log u` на тестах `g = f₀·s`, где `f₀ = Φ/‖Φ‖`, `Φ(x) = 4E(h)(e^x)`, `h(u) = (π²u⁴ − (3/2)πu²)e^{−πu²}`,
`FΦ = Ξ` (масштаб 4 к CCM (7.1), проверен), `f₀ > 0`, чётна, спадает как `exp(−(π/2)e^{2|x|})`. Точное представление (GS, вердикт XIDEV, аудит):
```
Q(f₀·s) = ½ ∬ f₀(x) f₀(x′) ν(|x − x′|) |s(x) − s(x′)|² dx dx′,      dν(t) = b(t) dt + Σ_n (Λ(n)/√n) δ_{log n},
b(t) = k(t) − e^{t/2},  k(t) = e^{−5t/2}/(1 − e^{−2t});   b > 0 ⇔ e^t < ρ = 1.324718 (пластическое число), t₀ = log ρ = 0.28120.
```
Ядро формы бесконечномерно: `Q(f₀ * h) = 0` для всех `h` (Ξ-кратные тесты; проверено численно). `f₀` — радикальный вектор: `B(f₀, v) = 0 ∀v`.

## Стена (одна)
```
(DOM)   Σ_n (Λ(n)/√n) E_s(log n) + ∫ b₊ E_s dt  ≥  ∫ b₋ E_s dt   для всех компактных гладких s,   E_s(t) = ∫ f₀(x) f₀(x+t) |s(x+t) − s(x)|² dx.
```
(DOM) ⟺ W (положительность Вейля на всём комплексном классе) ⟺ RH. Эквивалентные конечные формы: (ZG) на буквальной `K_{m,N} = Γ − c_L I − 2ββ*`
(нижняя оценка с исчезающими ошибками на восстанавливающем семействе), (FM) конечная маржа по простым с явным cutoff `P(v, ε)` и хвостом.
Ничего слабее RH внутри нет: `λ₁ ≥ −o(λ₂)` ⇒ RH (второй уровень ограничен сверху); `ε_∞ ≤ C` ⇒ RH (монотонность (3.27) CCM).
