# Стена как объект — карточка для семантического поиска (2026-09-03)

Принцип владельца: стена это объект. Описать входы и выходы, переписать в других формах,
и искать, кто уже держал этот объект в руках под другим именем. Карточка написана так,
чтобы её можно было отдать поиску (`./ask.sh`, литразведке, Mythos) как запрос.

## Объект

Конечная последовательность чисел `κ_k`, `k → ∞`, и вопрос: ограничена ли она.

| вход | что это |
|---|---|
| `K_k` | вещественная симметричная матрица `(2N+1)×(2N+1)`, форма Вейля на окне `[0, L]`, `L = log m`, `N = m`; внедиагональ `(β_i − β_j)/(i − j)` (матрица Лёвнера, displacement rank 2), диагональ из архимедова члена и суммы по простым `≤ m` |
| `ξ_k` | единичный собственный вектор наименьшего собственного значения `λ₁ ~ 10^{−1.9m}`, чётный |
| `F_k` | целая функция экспоненциального типа `L/2`, кардинальный интерполянт значений `√L(−1)^n ξ_n` в узлах `x_n = 2πn/L`; все нули вещественны (теорема) |

| выход | что это |
|---|---|
| `κ_k` | `−F_k''(0)/(2F_k(0)) = Σ_{ρ>0} 1/ρ² + (L²/4π²)Σ_{n>N}1/n²` |

## Одиннадцать записей одного и того же числа

1. Логарифмическая вторая производная в нуле: `−F''(0)/(2F(0))`.
2. Сумма обратных квадратов нулей: `Σ 1/ρ²` (класс Лагерра–Пойи; Пойя–Шур).
3. Половина квадрата HS-нормы обратного оператора Дирака CCM: `½‖(D_log)⁻¹‖²_HS` (спектр симметричен).
4. Линейный функционал от ряда: `(L²/2)[1/12 + (1/2π²ξ₀)Σ_{n≠0}ξ_n/n²]` (норма функционала `1/√80`).
5. Смешанное резольвентное спаривание: `(L²/2)[1/12 − ⟨c,(D−λ₁)⁻¹b⟩]`, `c_n = 1/(2π²n²)`.
6. Наклон окаймлённого определителя: `(L²/4)·∂_t[det(K+t(e₀wᵀ+we₀ᵀ)−λ₁)/det(D−λ₁)]|₀`.
7. Нечётный Gram-дефект: `(L²/4π²)[½‖r‖² − ⟨r,A(Rb)⟩ + (a₀−λ₁)⟨r,Ar⟩ + хвост]`, `r_n = 1/n`.
8. Замкнутая форма: `(L²/4π²)[Σ_{n≤N}(1 + 2ξ_n/ξ₀)/n² + Σ_{n>N}1/n²]`.
9. Знакопеременная решёточная сумма: `2Σ_{n≤N}(−1)^n(F_k(x_n)/F_k(0) − 1)/x_n² + хвост`.
10. То же с вычтенной `Ξ`: `S_Ξ,k + 2Σ(−1)^n Δ_n/x_n² + хвост`, `Δ_n = F_k(x_n)/F_k(0) − Ξ(x_n)/Ξ(0)`.
11. Численно: `0.0259, 0.0263, 0.0258, 0.0252, 0.0245` при `m = 13…163`; предел-кандидат `Σ_γ 1/γ² = 0.02310499`.

Записи 5, 6, 7 платят `1/λ₂ ~ 10^{300}` при любом разбиении (зонды 5–8): в них
сокращение живёт между расходящимися частями. Записи 9, 10 показывают, что объект есть
**вход A с весами**: близость `F_k` к `Ξ` в узлах.

## Что доказано и что нет

- Доказано (Lean): `κ_k ≥ 0`, тождества 1 = 2 = 4, и `|F_k(z)| ≤ |F_k(0)|e^{κ_k|z|²}`.
- Доказано (бумага, судья): 3 с множителем ½, 5–8 как тождества.
- Доказано (бумага, судья `f788d2fa`): запись 9 точна, хвост `|T| ≤ L²/(2π²(N+1)²)`,
  `κ ≤ S_Ξ + (L²/2π²)W + |T|`, `S_Ξ,k → κ_Ξ`.
- Не доказано: `sup_k κ_k < ∞`. Достаточно: `W_k = Σ_{n≤N}|Δ_n|/n² ≤ C/L²`. Численно `C ≈ 0.3`.
  Это НЕ слабейшее условие (точное знаковое разложение слабее) и НЕ закрывает
  идентификацию предела: та требует `sup_{n≤XL/2π}|Δ_n| → 0` при каждом `X`.

## Текущий кандидат в атом (после `f788d2fa`)

Центрально-нормированное собственное уравнение для `y = ξ/ξ_0`:
`R(y)_n = (K̃y)_n − y_n·(K̃y)_0 = 0`, записанное на низких модах как рекуррентность,
до любого обращения матрицы. Вопрос: замыкается ли она на низких модах без плотного хвоста
и без щели (`P59_XI_LATTICE_LOW_MODE_STABILITY_IDENTITY`, судья 0.40). Провал:
`P59_XI_LATTICE_EQUATION_REIMPORTS_DENSE_TAIL_OR_GAP`, откат к проективному двухджетовому
маршруту `|A|L^{5/2}√p = O(1)`.

## Под какими именами этот объект живёт у других

- **Класс Лагерра–Пойи / порядок нулей**: `Σ 1/ρ²` как коэффициент Тейлора лог-производной; теория Пойя–Шура, Йенсеновские многочлены (`Σ 1/ρ²` = второй «момент нулей»).
- **Константа `Σ_γ 1/γ² = 0.0231`**: Тейлор `ξ(s)` в `s = 1/2`; коэффициенты Ли / Кайпера, Bombieri–Lagarias 1999.
- **Знакопеременная сумма Римана**: формула Эйлера–Буля / Эйлера–Маклорена для `Σ(−1)^n g(nh) → −g(0)/2`; ошибки таких сумм для гладких `g`.
- **Лёвнеровские матрицы и displacement rank 2**: Лёвнер 1934, Bhatia–Friedland–Jain 2015, Kailath–Sayed 1995.
- **Локализация формы Вейля**: Yoshida 1992, Bombieri 2000, Connes–Consani 2020, Suzuki 2026; CCM 2025 §7–8 — «главное препятствие».
- **Trace/HS обратного оператора Дирака на интервале с нелокальным краем**: Krein strings, Weyl–Titchmarsh m-функции (Suzuki 2606.09096 §7).
- **Взаимное расположение узлов и нулей**: интерполяция Уиттекера–Шеннона на критической плотности, Duffin–Schaeffer 1952; Cartwright 1936 (что НЕ работает).

## Чего объекту не хватает, одним предложением

Арифметического механизма (из явной формулы, не из спектра), по которому вектор
наименьшего собственного значения конечной формы Вейля повторяет `Ξ` в узлах с ошибкой
`O(1/log² m)`. Это та же дверь, что §8 у CCM, но с точно измеренной шириной.
