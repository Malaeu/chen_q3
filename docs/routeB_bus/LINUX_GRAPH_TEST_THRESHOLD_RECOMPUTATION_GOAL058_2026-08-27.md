## 1. Точная оценка ядрового множителя (через sinc, без потерь)

`c(z) = (√L/π)·sin(zL/2)`, `ζ(z) = −zL/(2π)`, значит `zL/2 = −πζ` и
`sin(zL/2) = −sin(πζ)`. Для каждого целого узла `n`:

    | c(z)/(n − ζ) | = (√L/π)·|sin(π(ζ−n))/(ζ−n)| = √L·|sinc(ζ−n)|

Отсюда две вещи сразу:

- **устранимость полюса точная**: при `ζ → n` предел конечен, `≤ √L·e^{π|Im ζ|}`;
- **квадратичная сумма сходится**: `Σ_n |sinc(ζ−n)|² ≤ C·e^{2π|Im ζ|}`,
  потому что `|sinc(x)| ≤ min(1, 1/(π|x|))·e^{π|Im x|}` и ряд `Σ 1/(n−t)²`
  сходится равномерно по `t`.

На подполосе `|Im z| ≤ σ`: `|Im ζ| ≤ σL/(2π)`, значит
`e^{π|Im ζ|} ≤ e^{σL/2} = m^{σ/2} = λ^σ`. Итого **точный ядровый конверт**:

    ( Σ_j |c(z)/(n_j − ζ(z))|² )^{1/2}  ≤  C·√L·λ^σ

(это и есть отложенный узел D2 — здесь он выписан как оценка на бумаге.)

## 2. Новый порог consumer

    |E_k(z)| ≤ |centerFactor_k| · ‖w_k‖ · C·√L·λ^σ,   w_k = C_k⁻¹ r_k

С готовым центрирующим бондом `|centerFactor| ≤ ‖Ξ(0)‖/√c*` и
`‖w‖ ≤ ‖r‖/min(1, β)` получаем требование

    ‖r_k‖ = o( m^{−σ/2} / √(log m) )     для каждого фиксированного σ < 1/2.

## 3. Сравнение со старым порогом: выигрыш РОВНО ОДНА СТЕПЕНЬ m

Старая (убитая) форма шла через `Γ = D·r` и требовала
`λ^{2σ}·L²·‖Γ‖² → 0`. Мода-диагональ `D` умножает координаты на `n`, и на
нашем расписании `N = m`, поэтому `‖Γ‖` допускает лишь `‖Γ‖ ≤ m·‖r‖`.
Подстановка даёт старое требование

    ‖r_k‖ = o( m^{−1−σ/2} / log m ).

Новое требование `o(m^{−σ/2}/√L)` слабее ровно в `m` раз.

**Причина структурная, не техническая.** `D` растит координаты (множитель
до `m`); `C⁻¹` их не растит (норма `≤ 1/min(1,β)`). Прежняя цепь платила
одну степень `m` только за то, что несла мода-взвешенный объект, хотя
consumer его не требует. Graph-test форма эту плату снимает.

## 4. Что теперь стоит между нами и целью — точно

Тождество дисперсии (уже теорема в корпусе,
`...ResidualVariance.lean:392`): `‖r‖² = ⟨K²⟩_q − ⟨K⟩_q²`. То есть
требуемое — это степенная малость **дисперсии энергии в пробном
состоянии**: пробник обязан быть почти-собственным с точностью `m^{−σ/2}`.

Тривиальная (операторная) оценка даёт `‖r‖ ≤ 2‖K‖ ≲ C√m`, так как
прайм-часть имеет операторную норму порядка `Σ_{n≤m} 2Λ(n)/√n ~ 4√m`.
Разрыв между тривиальным и требуемым:

    m^{1/2 + σ/2}     (то есть от m^{1/2} при σ→0 до m^{3/4} при σ→1/2)

Против прежней цепи, где разрыв достигал `m^{3/2+σ/2}`, это понижение на
целую степень: **вопрос из класса «сверхтривиального» перешёл в класс
«корневого сокращения»**.

## 5. Следующая цель — названа точно

Оценивать надо НЕ операторную норму прайм-части, а её действие на
конкретный гладкий пробник:

    ‖ Prime_k · q_k ‖   при q_k = нормированная prolate-строка.

Операторная норма берёт супремум по всем векторам (тот самый убитый
квантор). Для одного гладкого локализованного `q` сумма по простым
несёт осцилляционную структуру, и именно здесь explicit-formula-класс
оценок работает на конкретной тест-функции, а не на всём пространстве.

Это первый пункт цепи, где прайм входит в форме, для которой
классический аппарат вообще предназначен: сумма по простым против
гладкого веса, а не против произвольного вектора.
