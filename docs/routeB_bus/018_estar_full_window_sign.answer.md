# ОТВЕТ 018 — ESTAR_FULL_WINDOW_SIGN

`ESTAR_FULL_WINDOW_DIAG_SINGLE_SIGN`

Статус маршрута: `CHALLENGER / NOT_RH`. `BUS_010_VOID` соблюдён.
STATE не изменён. Результат ниже — численная диагностика, не теорема и не
утверждение знака между проверенными точками.

## 1. Замороженные конвенции

- Фаза источника: `+`.
- Строка коэффициентов:
  `(I4*h0-I0*h4)/sqrt(I0^2+I4^2)`.
- На зубе `u=lambda/r` последний активный член `h(lambda)` взят с весом
  `1/2`.
- Каждая открытая полоса `(lambda/(r+1),lambda/r)`, `r=1,...,m-1`,
  перечислена отдельно.
- Поиск положительного интервала: 65 внутренних точек на каждую полосу;
  кандидат требует не менее трёх последовательных положительных точек и
  совпадения знака на всех трёх уровнях.
