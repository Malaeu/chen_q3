# ОТВЕТ 021 — FULL-WINDOW SIGN НА КАНОНИЧЕСКОМ ПАКЕТЕ

`INSTRUMENT_FLOOR_UNRESOLVED`

Статус: `CHALLENGER / NOT_RH`. Это численная диагностика сетки, не теорема
и не утверждение знака между измеренными точками. `STATE` не изменён;
`BUS_010_VOID` соблюдён.

## 1. Объект и fingerprint

На каждом уровне P1/P2/P3 пакет пересобран из тех же endpoint-сырьевых мод,
из которых заново вычислены `J0,J4,N0,N4`:

```text
htrial(lambda*t)
  = (J4*phi0(t) - J0*phi4(t))
    / (sqrt(lambda)*sqrt(J0^2*N4^2 + J4^2*N0^2)).
```

Фаза каждой моды выбрана единственным правилом `J_j>0`. Старые коэффициенты
018 не использовались.

SHA-256 исполняемого скрипта:

```text

```

## 7. Граница результата

- Все 320 полос и 323 зуба на каждом уровне перечислены.
- Fingerprint канонического объекта закреплён.
- Сетка обнаруживает положительные candidate runs, но прибор не отделяет их
  от cancellation floor на трёх уровнях.
- Никакой sign-теоремы и следствия для RH не утверждается.
- Fejer, Poisson residual и внешний G3 не запускались.
