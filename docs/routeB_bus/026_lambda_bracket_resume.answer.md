## 1. Метод и source-lock

Выбран разрешённый путь `interval Sturm + Schur tail-resolvent`
(`026...goal.md:16-18`).

В ортонормированном чётном базисе Лежандра проектный оператор

```text
Theta = -D((1-t^2)D) + G t^2
```

задаёт симметричную трёхдиагональную матрицу. Для конечного блока `A_D` и
хвоста, начинающегося с `D+2`,

```text
D_tail - E >= ((D+2)(D+3)-E) I.
```

Поэтому точный бесконечный Schur complement заключён между

```text
A_D-E-c(E)ee* <= S(E) <= A_D-E,
c(E)=b_D^2/((D+2)(D+3)-E).
```

На каждом endpoint интервальный LDL/Sturm-count обеих крайних матриц
совпал. Это сертифицирует count бесконечного оператора; значение собственной
пары усечённой матрицы использовано только как центр поисковой вилки, но не как
точечный вход.

Crosswalk к DLMF-рекурсии:

```text
Lambda = Theta-G,
d_N = B_N-Lambda = B_N+G-Theta.
```

Формулы `p_N,r_N,B_N`, конус, сжатие и хвосты взяты дословно из
`PROSHKA_PEN_GO_2026-07-27.md:26-60`.

## 4. Krawczyk и нормировка

После исключения core-переменных первая строка рекурсии однозначно строит
ядро при фиксированном `Theta`, а последняя строка становится скалярным
уравнением

```text
forward_ratio(Theta) = continued_fraction_tail(Theta).
```

Это Schur-reduction совместной системы `(core,Theta)`. Во всех шести случаях
получено строгое `K(X) ⊂ interior(X)`. После contraction финальная строка
содержит нуль, forward-ratio и живой tail-ratio пересекаются.

Нормировка использует

```text
finite_L2^2 + [0, 2|a_N0|^2/(3(2N0+5))],
```

то есть полный finite-plus-tail интервал, а не конечную сумму.
