# Анализ Паппа: обратное проектирование доказательства

Когда применять: результат Прошки, Кодекса или собственный упёрся в стену («открыто», INCONCLUSIVE, «нужна оценка X»). Или владелец говорит: «разбери», «декомпозируй», «как бы мы это доказали», «вернёмся назад».

Принцип. Вопрос не «что ещё можно вывести из имеющегося», а три других:
- какое утверждение завершит доказательство;
- какие более конкретные утверждения его обеспечат;
- что из них уже доказано, и где остался **единственный неоплаченный переход**.

Сначала проектируем достаточную цепочку назад, потом доказываем её вперёд. Каждый шаг записываем как `a + b − c = x`, у каждой буквы есть цена.

## Шаг 1. Цепочка сверху вниз

Выписать цепочку от RH вниз до арифметики. Пометить каждую стрелку: доказано / проверено условно / нет.

```
RH
 ↑ приёмник (A1…A10 или классический: |ψ(x)−x| = O_ε(x^{½+ε}))
 ↑ повторяемый шаг (если выбран итерационный путь)
 ↑ неравенство нужной формы
 ↑ точное арифметическое разложение + оценка его ПОДПИСАННОГО остатка
```

Работать **только над нижней неоплаченной стрелкой**. Верхние, уже проверенные стрелки заново не доказывать.

## Шаг 2. Цены кусков

| цена | смысл |
|---|---|
| 0 | тождество |
| O(1) | оплачено |
| log N | допустимо, потому что log^k N ≪ N^ε |
| N^δ | запрещено — это стена |

Вычеркнуть оплаченное. Остаток — это стена: какой кусок, какой приёмник, какой объект.

## Шаг 3. Форма нужного неравенства — рассчитать от цели

Итерация — только один из путей. Если удаётся прямо доказать достаточный знак, итерация не нужна.

Если путь итерационный, общий баланс такой (Прошка G/H):

```
B^p ≲_η X^{(p−r)/2 + η} · B(2X)^r + X^{p/2 + η},   p > r ≥ 0
⇒  θ_new = ½ + (r/p)·(θ − ½)
```

Пример: p = 2, r = 1 даёт θ → θ/2 + 1/4. В энергетической форме: z_N ≤ C·N^η(√z_{2N} + 1), где энергия ⇔ показатель нулей по Меллину–Планшерелю.

Не жениться на одном шаблоне: подходит любое доказанное правило, которое запускается из доступной оценки и сходится к ½.

Условия, иначе шаг пустой:
1. Двигает показатель (f(θ) < θ), а не только фиксирует ½.
2. Есть старт: работает при θ = 1 (тривиально B ≤ X·log X), иначе первый вход оплачивается отдельно.
3. Сохранён **количественный возврат** к исходной задаче: норма, область, кванторы, допустимая потеря. Менять объект можно — энергия, матрица, Фурье, — если известно, сколько стоит каждый переход.

   Без отдельной теоремы это дыры:
   - малое среднее → мало в нужной точке;
   - ограниченность на подпоследовательности → все большие масштабы. Нужен возврат «на всех больших N», например телескопирование по N, N/2, N/4, …

## Шаг 4. Три вопроса к каждой новой конструкции

1. **Что именно она должна доказать?** Конкретное неравенство с областью и константами, а не «даёт сокращение».
2. **Почему этого достаточно?** Полная цепочка до конечной цели проверена заранее.
3. **Что реально становится доступнее?** Какой остаток можно оценить, какое сокращение сохраняется, какая потеря уходит.

Нет ответа на третий вопрос — значит, получено ещё одно представление, а не механизм.

## Шаг 5. Проверки на вырождение и тавтологию (K2, арифметикой, до счёта)

- **Тавтология.** Не равен ли остаток алгебраически цели минус известное? Пример: R_N = W_N² − V_N. Тогда нужна **независимая** оценка через структуру коэффициентов, а не возврат к желаемой оценке.
- **Совместная подписанная оценка.** Остаток из нескольких кусков оценивать вместе, со знаком. Оценка модулей по отдельности обычно возвращает потерянную степень: g_N = O(N) даёт N².
- **Скорость изменения объекта на окне.** Если объект меняется меньше, чем шаблон допускает, среднее = значение в точке, и кусок пуст. Пример: R меняется на √X·log X на окне √X.
- **Направление неравенства.** Λ ≥ 0 даёт оценки простых снизу; если нужна оценка сверху — KILL.
- **Плотность против флуктуации.** На K_m полюс (главный член теоремы о простых числах) убит, поэтому плотностные инструменты (решёта, Чебышёв, Мертенс) не проходят.
- **Ложные миры.** Шаг обязан ломаться у DH и DMV/Бёрлинга. Если кусок верен и там, знак он не несёт.
- **Честность силы.** Если весь шаблон эквивалентен RH, ценность только в том, что он **раскладывается** на отдельно доказуемые части. Логически слабее задача не стала. Не считать трудность снятой, пока части не закрыты.

Эквивалентности (например, энергия ⇔ показатель нулей) отмечать как ФАКТ.

## Шаг 6. Сборка из наработок — не пазл

Для каждого куска найти слот в уже доказанном. Примеры:
- E: `Z_N = H + T + 2I/(L² log 2) + Rlat`;
- F: `|X_N| ≤ 2A#B#/N`, периодическая дисперсия V_N ≤ 7N/2;
- H: `W_N = g_N − S_N(h)`, `W_N² = V_N + 𝔑_N`;
- индекс S_m(C), J_m, K_m.

Таблица: кусок → слот → что ещё нужно. Брать только то, что подходит к **этой** сборке. Не пытаться вставить каждую деталь. Оценки одной ветки (например, NB/Green) не приписывать автоматически другой (B(X)). Билинейные члены (Коши–Шварц) — естественный источник «корня из энергии».

Итог шага — одна строка: **минимальное недостающее утверждение**, с кванторами, областью и допустимой потерей.
