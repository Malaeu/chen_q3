# Анализ Паппа: разбор стены назад

Когда применять: любой результат Прошки, Кодекса или собственный упёрся в стену («открыто», INCONCLUSIVE, «нужна оценка X»). Или владелец говорит: «разбери», «декомпозируй», «как бы мы это доказали», «вернёмся назад».

Принцип: искомое берём за данное и идём назад к известному. Каждый шаг записываем как `a + b − c = x`, у каждой буквы есть цена.

## Шаг 0. Сначала проверить, не делали ли уже

Обязательно, до любого предложения.
1. Конструктор: память `topics/konstruktor-bewiesen.md` и репо `docs/routeB_bus/mythos/ROUTE_B_CONSTRUCTOR_PROVEN_2026-11-06.md` — приёмники, оплаченное, убитое.
2. Планы и журналы: `ROUTE_B_CLOSING_PLAN_2026-11-02`, `ROUTE_B_LOGBOOK_2026-11-05` (проектные доки).
3. Репо: `gh search code "<ключ>" --repo Malaeu/chen_q3`, свежие коммиты обеих веток (`rh_clean`, `proshka_inbox_2026-10-31`). Проверить, не заморожена ли у Прошки та же задача: файлы FREEZE без VERDICT.
4. Определения объектов (J_m, K_m, Z_N, …) читать в исходном вердикте, не по памяти.

Если уже делали — назвать файл и коммит, сказать итог, дубль не предлагать.

## Шаг 1. Цель — одно неравенство с приёмником

Записать цель как неравенство и указать доказанный приёмник ⇒ RH (A1…A10 из конструктора). Пример: `RH ⇐ Z_N ≤ C i.o. на S`.

## Шаг 2. Разложить на куски с ценой

| цена | смысл |
|---|---|
| 0 | тождество |
| O(1) | оплачено |
| log N | допустимо, потому что log^k N ≪ N^ε |
| N^δ | запрещено — это стена |

Вычеркнуть оплаченное. Остаток — это стена. Локализовать её: какой кусок, какой приёмник, на каком объекте.

## Шаг 3. Шаблон самоулучшения вместо одного прыжка

Искать не прямую оценку, а повторяемый шаг в показателе с неподвижной точкой ½. Общий вид (Прошка G/H): `B^p ≤ X^{(p−r)/2}·B^r + X^{p/2}` (с потерями X^η) сжимает θ − ½ в r/p раз. Пример: `B² ≤ X^{½+η}·B(2X) + X^{1+η}` даёт θ → θ/2 + 1/4.

Три условия, иначе шаг пустой:
1. Шаг реально двигает показатель (f(θ) < θ), а не только фиксирует ½.
2. Есть старт: работает уже при θ = 1 (тривиально B ≤ X·log X).
3. Тот же объект на обеих сторонах. Нельзя подменять фиксированное окно средним по фазам, а одну часть — всей формой.

## Шаг 4. Проверка на вырождение (K2, арифметикой, до счёта)

Для каждого куска, который «слабее цели» (среднее вместо sup, короткое окно, другая норма):
- скорость изменения объекта на окне. Если объект меняется меньше, чем шаблон допускает, среднее = значение в точке, и кусок пуст. Пример: R меняется на √X·log X на окне √X, поэтому короткое окно ничего не даёт;
- направление неравенства. Положительность Λ ≥ 0 даёт оценки простых снизу; если нужна оценка сверху — это KILL;
- плотность против флуктуации. На K_m полюс (главный член теоремы о простых) убит, поэтому любой «плотностный» инструмент (решёта, Чебышёв, Мертенс) не проходит;
- фильтр ложных миров: шаг обязан ломаться у DH и DMV (Бёрлинг). Если кусок верен и там — он не может нести знак.

Эквивалентности (например, энергия ⇔ показатель нулей по Меллину–Планшерелю) отмечать как ФАКТ.

## Шаг 5. Разложить по слотам наработок

Для каждого куска шаблона найти слот в уже доказанном разложении (E: `Z_N = H + T + 2I/(L² log 2) + Rlat`; F: `|X_N| ≤ 2A#B#/N`; индекс S_m(C); J_m; K_m). Таблица: кусок → слот → что ещё нужно. Билинейные члены (Коши–Шварц) — естественный источник «корня из энергии».

## Шаг 6. Ставки K6 и дешёвый судья

Если нужен счёт: сначала ставки в память `areas/k6-einsaetze.md` (S#, вероятность), потом прогон, потом оценка HIT/MISS там же. Судья должен иметь дискриминатор (например, сторона простых против суммы по нулям). Инструменты: `docs/routeB_bus/mythos/tools/weil_window_judge_2026-11-06.py`.

## Шаг 7. Записать и передать

- Док в репо `docs/routeB_bus/mythos/<ИМЯ>_<дата>.md`, коммит в `rh_clean` git-плюмбингом (`mktree --missing`, автор Mythos). Никаких строк Co-Authored-By и Claude-Session.
- Бриф Прошке — только если у него нет замороженной той же задачи. Формат: «Докажи RH.» + репо → ветка → коммит → путь → blob. Идеи владельца помечать как идеи, строка свободы, без выходной оговорки. Показать владельцу, отправляет он.

## Формат ответа владельцу

«Ы», по-русски. Шаги до RH: «ЕСЛИ X → цепочка → RH», сколько звеньев, какого нет. Что закрылось, что открылось. Теорема или карта. Мало слов, простые формулы. Факт / гипотеза / спекуляция — раздельно. Собственные ошибки — молча в fehlerlog, в ответе только исправленный вывод.
