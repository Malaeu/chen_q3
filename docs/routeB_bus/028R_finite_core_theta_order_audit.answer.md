# ОТВЕТ 028R — АУДИТ НОРМИРОВКИ И K-КВАНТОРА

Статус: `CHALLENGER / NOT_RH`.

## 1. Исправленная семантика 028

028 доказал только отказ выбранного fixed-`K` достаточного контракта

```text
P_(r,K)(z) >= r * epsilon_(Psi,K).
```

Он не доказал `S_lambda<0` и не опроверг `DualThetaDominance`. Из

```text
|S_lambda - P_(r,K)| <= r * epsilon_(Psi,K)
```

и отрицательного finite core нельзя восстановить знак полного `S_lambda`,
поскольку хвост имеет неизвестный знак. В исходной клетке величина
finite-core провала порядка `1e-97`, а разрешённый суммарный хвост порядка
`1e-93`.

Lemma A из 027 не зависит от этой поправки и остаётся замороженной.

## 2. Источник J₀ и J₄

В сыром gauge `a₀=1` полный режим имеет вид `phi_j=s_j F_j`. Все полиномы
Лежандра положительной степени имеют нулевой интеграл на `[-1,1]`, поэтому

```text
J_j = integral(phi_j) = 2*s_j > 0.
```

Масштаб `s_j` выводится из coefficient boxes и recessive-tail оценки:

```text
finite_L2_lower <= sum 2*a_n^2/(2n+1) <= finite_L2_upper
0 <= tail_L2^2 <= 2*|a_N|^2/(3*(2N+5))
s_j = 1/sqrt(full_L2^2).
```

Checker v2 заново строит эти рациональные интервалы и проверяет границы
`J_j=2*s_j` точными квадратными неравенствами. Получено:

| mode | рациональная outward-вилка `J_j` | ширина |
|---:|:---|---:|
| 0 | `0.296994899101821634…` | `1e-140` |
| 4 | `0.181786851602547197…` | `1e-140` |

Для самого theta-бюджета числа `J_j` больше не являются доверенными входами:

```text
phi_(j,K)/J_j       = F_(j,K)/2
epsilon_(j,K)/J_j   = |a_(j,K)|/2.
```

Это точное сокращение положительного `s_j`, проверяемое отдельно для каждой
моды.

## 3. Решение судьи

Вердикт `PROSHKA_028_KILL_ADJUDICATION_2026-07-27.md` запретил широкую
экспериментальную лестницу и разрешил ровно две decisive-отсечки:
`extra K=20`, затем при необходимости `extra K=40`. На каждой требуется
проверять настоящие оболочки

```text
L = P_center - E_core - r*epsilon_Psi,
U = P_center + E_core + r*epsilon_Psi.
```

Отрицательность adjusted-target с **минусом** хвоста больше не считается
kill-сертификатом. Исполнение перенесено в гол 029.
