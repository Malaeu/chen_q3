## 0. Шаблон из G

    B(X)² ≤ C_η·[ X^{1/2+η}·B(2X) + X^{1+η} ],   B(X) = 1 + sup_{x≤X} |ψ(x) − x|
    B ≪ X^{θ+ε}  ⇒  B ≪ X^{θ/2+1/4+ε}

## 1. Разбор через Соболева — и его вырождение (KILL арифметикой)

Неравенство Соболева на отрезке I длины H:

    R(x)² ≤ (1/H)∫_I R² + 2∫_I |R||dR|,   |dR| ≤ (log X + 1)dx

Отсюда

    B(X)² ≤ (1/H)∫_I R² + 2·B(2X)·H·log X

При H = √X второй член **точно** совпадает с первым членом шаблона. Это P1, элементарная часть.

**Но первый член (P2) при H = √X пуст.** На отрезке длины √X функция R меняется не больше чем на √X·log X — это то же P1. Поэтому

    (1/H)∫_I R² = R(X)² ± O(B·√X·log X),

то есть P2 ⇔ сама цель. Короткое окно длины √N само по себе **ничего не даёт**: среднее по нему — это просто значение в точке.

При длинном окне (H ~ X) настоящее усреднение есть, но член B·H ~ B·X уничтожает выигрыш.

**Вывод: KILL** для пути «короткая версия машины ради Соболева».

## 2. Правильная форма: рекурсия энергии на длинном окне

**ФАКТ (Меллин–Планшерель, классика).** Для

    E(X) = (1/X)·∫_X^{2X} R²

показатель энергии ⇔ показатель нулей:

    E(X) ≪ X^{2θ+ε}  ⇔  нет нулей с β > θ

Sup не нужен, достаточно энергии — именно на нашем длинном окне [N/2, 2N].

Шаблон в нормированной энергии z_N ≍ E(N)/N (по смыслу это наш Z_N, A8: z_N ≳ N^{2β−1}):

    z_N ≤ C_η·N^η·( √z_{2N} + 1 )        ⇒        z ≪ N^{2θ−1}  →  z ≪ N^{θ−1/2}

Это частный случай общего правила Прошки (H, P2): обратная связь вида p против r при p = 2, r = 1. Она сжимает θ − ½ вдвое.

## 3. Куда это ложится в разложении E (66020529)

    Z_N = H_N + T_N + 2I_N/(L² log 2) + Rlat_N,   |Rlat| ≤ 288/L²
    I_N = ∫ P_N·Q_N du/u   (билинейно)
    |X_N| ≤ 2A#·B#/N   (F, ed480327)

| кусок шаблона | слот в E/F | что нужно |
|---|---|---|
| √z_{2N} | перекрёстный член I_N / X_N: билинейный, Коши–Шварц даёт ровно корень из энергии одного множителя | один множитель ≤ √(N·z), второй ≤ √N·N^η |
| 1 | диагональ H_N + T_N | ≤ N^η |
| Rlat | решёточный дефект | оплачен |

Гипотеза: шаблон не требует «A#, B# ≤ √N сразу» (F). Достаточно, чтобы **один** множитель перекрёстного члена был оценён через энергию самой формы, а диагональ — с потерей N^η. Открытые места:
- диагональ H_N + T_N;
- второй множитель (Мёбиус-часть) — уровень Мертенса, это тоже RH-сила, если брать его отдельно.
