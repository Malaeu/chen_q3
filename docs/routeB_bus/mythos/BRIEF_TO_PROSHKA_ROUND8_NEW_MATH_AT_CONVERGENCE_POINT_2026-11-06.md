## 3. ЧТО УБИТО — НЕ ПОВТОРЯТЬ

- δ-поток с внешней силой и любая калибровка на нём (R4 B, R5).
- Свободные внутренние пути (R5.4).
- Квадрат кривизны по δ как вся цепочка (R4, кривизна).
- Тепловая полугруппа де Брейна–Ньюмана (Rodgers–Tao).
- Универсальный возврат из положительности + Пуассона + самодуальности (R6 B).
- Полная головная последовательность NB как поставщик (Limit 9).
- Перенос роста конкретного V_N на оптимальное e_N (R7 B §8).
- Лобовые оценки через PNT, решето или средние: дают √m/(log m)^A без знака.

## 4. ПЛАНКА И ПРИЁМКА

1. **Новизна.** Переформулировка, классически эквивалентная RH без нового объекта, — NO_PROGRESS. Ответ обязан предъявить новый математический объект или структуру из трёх частей: явно вычислимая часть, положительная по построению, плюс точный остаток. Затем — доказательство нужной оценки этого остатка.
2. **Место арифметики ℚ.** Назови точный шаг, где работает арифметика ℚ.
3. **Фейки.** Каждый ломается в названном месте, на своём собственном полном источнике:
   - DMV / Берлинг;
   - DH;
   - подсаженный квартет a = 1/3 (как в R3, R6 B);
   - самодуальные подсадки v_b из R6 B.

   Кривая над 𝔽₃ обязана пройти.
4. **Импорты.** Каждый классифицировать: THEOREM / CONDITIONAL / CONJECTURE / HEURISTIC. Источник в руках, с проверкой исправлений. Численное — только DIAG, квантор оно не занимает.
5. **Freeze первым**, отдельным коммитом. Freeze не редактируется.
