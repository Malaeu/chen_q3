## Вопрос

Может ли верхнее решето (Сельберг Λ², Брун–Титчмарш) дать нужное неравенство на K_m:

    Prime(f) ≤ W_∞(f) + Pole(f) − C‖f‖²

## Вывод

1. **Без флуктуации знак не держится.** Если заменить простые их плотностью, получим W_model = W_∞ − M < 0 при всех m ≥ 4 (при m = 13: −0.632). Настоящая форма W = W_∞ − Prime > 0 при m = 13 даёт +0.018. Весь знак рождается **флуктуацией ψ − x**, а запас составляет ~3% от неё.

2. **Решето структурно мертво на K_m.** Решето знает только плотность простых, с потерями:
   - сверху — множитель 2, это и есть барьер чётности;
   - снизу — ноль: нижнее решето простых не видит.

   Нужное неравенство требует:
   - на узлах с f > 0 — простых не больше модели;
   - на узлах с f < 0 — простых **не меньше** определённого количества.

   Даже в лучшем случае решето даёт Prime ≤ 2M⁺ ≥ 0 > W_∞. Вывод: **KILL** для решёт как поставщика знака на K_m.

3. **Почему так.** K_m гасит полюс, Pole ≈ 1e-29. Главный член теоремы о простых числах — это и есть полюс. На K_m от простых остаётся только Σ по нулям (флуктуация), то есть нужное утверждение снова о нулях. Плотностными инструментами туда не войти.
