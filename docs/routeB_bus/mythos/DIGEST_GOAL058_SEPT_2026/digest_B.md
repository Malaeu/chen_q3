## Сводка батча

- **Главный структурный факт для Route B (B21, B22):** в Re s>1 точно 1+xi'/xi = a_γ(s) + 1/s + 1/(s−1) − ΣΛ(n)n^{−s}, т.е. ровно «Gamma + полюс − простые». Положительная мера η_8 строится только из Gamma; знаковая M_8 = простые − (e^{−8u}+e^{−7u}) (полюсные члены). Абсолютная (positive) termwise-мажоранта резольвента имеет бесконечную критическую e^{15u/2}-массу — KILL; знак держится только на знаковом сокращении. Реальный полюс 1/a_γ сокращается в полной дроби. Это сентябрьский предшественник «стены positive insurance» и «эха полюса».
- **Positive minorants/majorants убиты систематически:** V>=C·E_k ложно для всех C>0 (B10, механизм: центральная энергия >0, а V(−R,−R)→0; фильтр I5); fixed finite-S Sonin-квадрат не нижняя граница Вейля — через pole-null тесты g_{0,R} (B17); абсолютная мажоранта Q_8 (B21). Повторяющийся паттерн: любая фиксированная положительная часть переоценивает место, где исходная форма имеет точное сокращение.
- **Squares / SOS:** послойный SOS для тета убит (B06, L13: отрицательные слои при s→0, ≥3 узлов); работает только для квартики exp(−au⁴−bu²) (Fock-когерентные векторы, B12). Положительные суммы источников ломают V (J11<0, B12) — перекрёстные члены решают. Hankel/Ляпунов-сглаживание даёт Gram, но обратно не переносится (B14).
- **Доказанные положительные результаты/контроли:** V>=0 для 1–2 узлов и для фаз в дуге π/2 (B05); Hardy-изометрия W (B03); безусловная взвешенная контракция T_v (v>1/2) из Lagarias Re xi'/xi>0 в Re s>1 (B20); центральный безнулевой слой |M_N|>=1/256 при |Re z|<=5 для всех N (B28, Prékopa) — но использует лишь минимальную скорость π (B34); N=1 Бессель вещественен (B23); TN∞ для r (B22).
- **Точные эквивалентные критерии (не прогресс по знаку):** V>=0 ⇔ SUPPORT (P+UP−=0) ⇔ W2 ⇔ p∈L²(0,∞) (B18, B20, B21); C6 ⇔ RH (B27); тождество ||Φ||²V=−E_c'(0)/2 (B16).
