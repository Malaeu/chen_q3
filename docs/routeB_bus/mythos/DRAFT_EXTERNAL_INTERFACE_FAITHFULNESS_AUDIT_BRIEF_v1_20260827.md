## Правила изоляции (несущие; нарушение обесценивает аудит)

Аудитор получает ТОЛЬКО: (1) этот бриф; (2) перечисленные ниже Lean-файлы;
(3) первоисточники (страницы книги/статей), выданные владельцем. Аудитор НЕ
получает: глоссарии проекта, ROUTE_B_STATE, вердикты (кроме файла пункта 6),
usage-карты litreview, переписку. Причина: аудит семантики бесполезен, если
аудитор откалиброван нашим же словарём. Один из пунктов — контрольный
(ожидаемый PASS); какой — аудитору не сообщается.

## Задание (формулировка для аудитора, самодостаточная)

Для каждого пункта ответь ровно одно из:
- `FAITHFUL` — Lean-формулировка (типы, кванторы, области, константы,
  нормировки) точно передаёт названный внешний объект;
- `MISMATCH` — с указанием точной Lean-строки И точного места в источнике,
  и в чём расхождение (квантор, область, нормировка, константа, класс функций);
- `UNDERDETERMINED` — чего не хватает, чтобы решить.
Оценивай ТОЛЬКО верность формулировок. Корректность доказательств не твой
предмет (её проверяет ядро Lean). Отчёт — списком по пунктам, без прозы вокруг.
