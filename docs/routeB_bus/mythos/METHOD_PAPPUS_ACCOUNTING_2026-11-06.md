# Метод: анализ Паппа — бухгалтерия оценок и локализация стены (+ судья окна Вейля)

Дата: 2026-11-06 · Автор: Mythos · Ветка: `rh_clean`
Класс: карта метода + численный результат (двойная точность, не интервальный сертификат). RH не утверждается.

## 1. Принцип

Анализ Паппа: искомое берём за данное и идём назад к известному. Каждый шаг записывается как баланс `a + b − c = x`, у каждой буквы есть цена.

Правило сравнения ошибок:

    log^k N  ≪  N^ε        для всех k и всех ε > 0

Экономия логарифма или константы не меняет показатель степени. Степень пробивается только двумя способами:

1. **Точное тождество** (цена 0). Примеры: сокращение полюса (a4ab9e92), проекция на подпространство связей K_m, формула Пуассона в S_Λ ⊃ E(B_Λ) у Конна.
2. **Самоулучшение** (индукция по масштабам): θ_{k+1} = f(θ_k) < θ_k с неподвижной точкой ½. Это схема; такого шага у нас нет.

Цены кусков:

| цена | что значит |
|---|---|
| 0 | тождество |
| O(1) | оплачено |
| log N | допустимо |
| N^δ | запрещено — это стена |

## 2. Два приёмника — не смешивать

**A1 (цепь Z_N):** RH ⇐ Z_N ≤ C i.o. на S (доказано Прошкой).

**A4 (форма Вейля на K_m):** RH ⇔ z*B⁽¹⁾z ≤ C·z*Gz на K_m (115714b7, Thm 2).

    W(f) = Pole(f) − Prime(f) − (log 4π + γ)·f(0) − ArchInt(f)

Пояснения к столбцам:
- «Доля простых» = max по v ∈ K_m отношения Prime(v)/W_∞(v). Это та часть архимедова запаса, которую съедают простые.
- Дискриминатор (K1): прямая сторона формулы (простые) против суммы по 1500 нулям Σ_γ|v̂(γ)|² на случайном v ∈ K_m.
- Базис: (1 − t²)²·P_k(t), K = 20 функций.
- λ_min — это значения Рэлея–Ритца, то есть **верхние** оценки инфимума. Они убывают с ростом K: при m = 4 и K = 8, 12, 16, 20 получается 1.5e-4, 9.0e-6, 1.1e-6, 2.5e-7.

## 4. Находка: m* ≈ 3.3–3.4 — граница, где доминирование умирает

1. **0 < m ≤ 2** (простых нет). W_∞ > 0 на K_m. Конн–Консани доказали это для носителя (1/2, 2).
2. **2 < m < m\*** (в окне 2, затем 3). W_∞ ещё положительна, но простые съедают её почти целиком: 79% при m = 2.5, 99.2% при m = 3, 99.9% при m = 3.3.
   - Схема «архимедов запас глотает простые» здесь в принципе возможна, но с запасом меньше 1%.
3. **m > m\*.** W_∞ сама **отрицательна** на K_m. Это численный свидетель: вектор Ритца со значением −1.4e-2 при m = 3.4, на 10 порядков выше шума. При этом W = W_∞ − Prime > 0.
   - Значит, в этих направлениях простые дают **плюс**. Знак сидит в простых — согласуется со 115714b7.
   - Схема доминирования мертва. Остаются только тождество или сокращение (п. 1.1).

Оценка m\* ≤ 3.4 подкреплена свидетелем. Утверждение «W_∞ ≥ 0 при m ≤ 3.3» не сертифицировано: больший базис может сдвинуть m\* вниз.

Следствие для плана «добавлять простые по одному»: доминированием можно пройти не дальше пары простых 2, 3 при m ≲ 3.3. Окно CCM m = 13 этим путём недостижимо.

## 5. Поправки к черновику плана (attachment 2026-11-06)

- Окно m = 4 содержит 2 **и 3**, потому что log 3 < log 4. Окно с одним простым — это 2 < m ≤ 3.
- Куски цепи Z_N (A1) и формы Вейля (A4) — разные приёмники. Полюсные связи K_m относятся к A4, в разложение Z_N их не вписывать.
- Константа c ∈ (13, 17) из CC Thm 6.11 — это поправка ранга один по ĝ(0) в их нормировке. «Дрейф c» не наш судья: наш судья — λ_min W_∞ на K_m.

## 6. Чек-лист для нового свойства или статьи

1. Какой кусок и какого приёмника (A1 или A4) он забирает?
2. Сколько простых в носителе? Если носитель ⊂ (1/2, 2), инструмент работает в пустой зоне.
3. Цена списания: 0, log или N^δ?
4. Работает ли он за m\* ≈ 3.4, где W_∞ < 0? Если инструмент — доминирование, то нет.
