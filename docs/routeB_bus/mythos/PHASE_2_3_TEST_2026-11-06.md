## Находка

1. **Механизм — одна частота, а не пары.**
   ```
   знак вклада p  =  sign cos(γ*·log p)        26 из 26
   ```
   Простой p спасает ⇔ γ\*·log p ∈ (π/2, 3π/2) mod 2π.

2. **Все плохие направления W_∞ низкочастотные.** γ\* ∈ [2.9, 6.1], это меньше t₀ = 6.2898 — нуля архимедова символа:
   ```
   q_∞(t) = Re ψ(1/4 + it/2) − log π,   q_∞(0) = −c_A = −5.372,   q_∞(t₀) = 0,   t₀ ≈ 2π
   ```
   Тождество Arch = (1/2π)∫ q_∞·|f̂|² взято из `THREE_LOBE_PREFLIGHT_REPORT_2026-09-07.md` §1.
   - W_∞ < 0 ровно там, где символ отрицателен: в полосе |t| < t₀ ≈ 2π.
   - Простые закрывают эту «дыру» своими косинусами.
   - Первый ноль γ₁ = 14.13 лежит далеко над t₀. В этой полосе нулей нет, поэтому сумма по простым обязана заполнить дыру — это требует формула явных выражений.

3. **Пары 2 ↔ 3 (S2) не держатся.** При малой γ\* (m ≥ 6, где разрешение окна 2π/L становится мельче) спасают и 2, и 3. Тройка атакует только там, где γ\*·log 3 близко к 0 mod 2π.

## Следствие для шагов к RH (карта, не теорема)

```
полоса |t| < t₀ ≈ 2π:   W_∞ < 0,  простые спасают по закону cos(t·log p) < 0
полоса |t| > t₀:        W_∞ > 0 (растёт как log t),  здесь живут нули (γ ≥ 14.13)
```
Знак сидит в простых и разложен по частотам. «Пары» из идеи 5 заменяются **полосой**. Открытый вопрос: можно ли доказать спасение в полосе |t| < t₀ без нулей — там их нет, и тогда задача может быть безусловной. Если да, то стена целиком уходит в верхнюю полосу.
