## Ключевые инсайты

1. **Connes–Consani–Moscovici «Zeta Spectral Triples»** (arXiv 2511.22755,
   23.06.2026) — параллельная программа RH, структурно 1:1 с Route B: их `E_N` = наш
   `modeSet`, финал — Гурвиц. Их два missing steps (простота+чётность ground state;
   близость educated guess к настоящему вейлевскому ground state) закрываются одной
   коэрцитивной PSD-оценкой (условие C).

2. **Prolate-to-Weil bridge через коэрцитивность**: из residual
   `r_{λ,N} = (W_{λ,N} − μ_{λ,N} I) v_{λ,N}` и `P_⊥(W−μI)P_⊥ ⪰ G_{λ,N} P_⊥` следуют
   простота ground state, чётность (J-симметрия) и близость `sin∠(v,ξ) ≤ ‖r‖/G`.

3. **Rodgers–Tao no-go**: любое доказательство знака с РАВНОМЕРНЫМ ПОЛОЖИТЕЛЬНЫМ
   запасом невозможно; знак с запасом НОЛЬ доказывается ТОЖДЕСТВОМ, а не оценкой.

4. **Нелокальная факторизация**: локальный квадрат `|ĝ|² = K̂` невозможен
   (P_M4_3), но канонический внешний (outer/кепстр) фактор
   `ĝ_N = exp(½·H[log K̂_N])` существует и даёт `|ĝ_N|² = K̂_N` точно на `τ < τ_cut`.
   Знак держится на нелокальном (глобальном по спектру) факторе, а не на локальных
   «горбах».

5. **Kill-switch P_M4_3**: `K̂_N = 4[j′² − jj″]` несёт дигамма-члены + фолд-сдвиг
   носителя `x ∈ [1,∞)` (верхняя неполная гамма против полной) — локальный квадрат
   структурно невозможен.

6. **Главный открытый пролёт Route B**:
   `FiniteGroundTransformToCCMTrialLocallyUniform` (PLACEHOLDER) + «иголка Зингера»
   `c_j·G_j − T_j → 0`.

7. **Гурвиц переносит только сходимость**, не вещественность. Вещественность обязана
   жить на конечной стороне; через предел идёт только сходимость.
