## 1. Нижний конверт penalty-slack — ДОКАЗАН на бумаге (обе версии)

Единичная (I-версия): тест сертификата `K − bI + τqq* ⪰ 0` на `q` даёт
`s := τ − (b−a) ≥ 0`; для любого единичного `x`:
`⟨x,Kx⟩ ≥ b − τ|⟨q,x⟩|² ≥ b − τ = a − s`, значит `ε ≥ a − s`. ∎

Обобщённая Gram-версия (форма H2aPenalty, `K − bG + τ(Gq)(Gq)* ⪰ 0`,
`q*Gq = 1`): тест на `q` даёт `a − b + τ·|q*Gq|² = a − b + τ ≥ 0`;
для G-единичного `x`: `x*Kx ≥ b·x*Gx − τ|q*Gx|²`, и по Коши–Шварцу в
G-скалярном произведении `|⟨q,x⟩_G|² ≤ (q*Gq)(x*Gx) = 1`, значит
`x*Kx ≥ b − τ = a − s` — нижний конверт обобщённого спектра. ∎
Твой прогноз P_PENALTY_SLACK_IDENTITY_1 (0.99) подтверждён.

## 2. Schur-тождество минимального slack — ДОКАЗАНО в литеральном носителе

В блоках `ℂq ⊕ q⊥`: `K − bI + τqq* ⪰ 0` ⟺
`[[a−b+τ, r*],[r, B−bI]] ⪰ 0` (перекрёстный блок — остаток, точно как в
твоём §5 предыдущего вердикта). При `B − bI ≻ 0` Schur-критерий:
`a−b+τ − r*(B−bI)⁻¹r ≥ 0` ⟺ `τ ≥ (b−a) + r*(B−bI)⁻¹r`. Значит
`s_min = r*(B−bI)⁻¹r` — резольвентно-сглаженная self-energy. ∎
Согласуется с инструментом Phase-2: `tau_required = beta_cert − a + schur_term`.
