
### Чего она НЕ даёт — в его собственных терминах

1. **Кофинального утверждения не будет.** Thm 1.4 (p.6): любой сертификат типа Thm 1.1
   требует `T ♯ > T₁(L) = 2πe^{A_L}` с `A_L = (4+o(1))e^L`, значит размер матрицы `N ≍ LT₁`

   pointwise the threshold `T₁` cannot be lowered». Remark 1.6 (p.6): «Certifying positivity

   §16 (p.32): «The gap between `e^{2L}` and `e^{4e^L}` is the gap between knowing where the
   zeros are and proving that the primes cannot conspire. Closing it is an arithmetic problem
   […] and not a computational one.»
2. **Table 3 — ВЕРХНИЕ оценки**, того же логического типа, что наши `λ₁(m,N)` по CCM Prop. 3.4.

   inequality». Нижней оценки на наших окнах отсюда не следует ни одной.
3. **Константа подогнана.** Remark 12.2 (p.26): «the constant `2π²` is read off the plateau and

4. **Thm 1.3 предполагает RH** — как поставщик бесполезно; и экспонента там `e^L`, не `e^{2L}`
   («half saturation», §13 p.26).
5. **`simple-even` — один фиксированный масштаб** `λ = e^{0.8}`, ниже всех наших ячеек.
   Второй недостающий шаг CCM — сходимость нулей приближённого основного состояния к нулям `ζ`,
   то есть **наш собственный атом** (полный нулевой дивизор / winding lock) — «untouched by the
   present certificate» (§6 конец, p.16).
