## 4. Прайм-часть как точное Stieltjes/Abel-ядро (п. 4)

С диска: прайм-компонента формы — конечная сумма
`−2·Σ_{n=2}^{m} (Λ(n)/√n)·C_n(·,·)` (PrimeAmbient:150), кут ровно n ≤ m,
косинусные множители на Fourier-стороне окна, star-first, матричные
элементы — явные `ccmPrimeEntryN1`-нормformы. Точный экспорт частичным
суммированием против ψ(x) = Σ_{n≤x}Λ(n):

    Σ_{n≤m} Λ(n)·f_z(n) = f_z(m)ψ(m) − ∫_2^m ψ(x)·f_z′(x)dx,
    f_z(x) := K_pair(log x)/√x

где K_pair — гладкое ядро модовых перекрытий пары (S(Dv), S(q)) (явные
sinc-структуры). Разложение ψ = x + (ψ(x)−x): главный член ∫f_z(x)dx
входит в комбинированную структуру (это и есть та часть, которую
знаковый закон уже поглотил в §3); **остаток**:

    R_k(z) = f_z(m)(ψ(m)−m) − ∫_2^m (ψ(x)−x)·f_z′(x)dx + краевые члены

— единственный непокрытый аналитический объект. Прайм-стена = R_k.

## 6. Сильнейшие безусловные теоремы и прогон экспонент (п. 6)

Сильнейший безусловный вход для ψ−x: Коробов–Виноградов
`|ψ(x)−x| ≤ x·exp(−c·(log x)^{3/5}(log log x)^{−1/5})`. Прогон через ядро
пары и компактный консюмер: остаток R_k выигрывает у чебышёвского
конверта РОВНО множитель `exp(−c·L^{3/5})`, L = log m. Требуемый выигрыш
до порога spendability: `m^{1/4} = exp(L/4)` (окноая часть; после ремонта
m²-кут снят, глобальная строка изъята из решающего леджера). Сравнение:

    exp(−c·L^{3/5})  ≪  exp(−L/4)  требуемого — НЕ ДОСТИГАЕТСЯ:
    безусловный выигрыш суб-степенной, порог — степенной.

Zero-density (Ingham/Huxley) для одиночного гладкого теста возвращает тот
же exp(−c·L^{степень<1})-класс. Безусловной степенной экономии для
индивидуальных ψ-сумм в литературе НЕТ; её наличие на этом масштабе окна
эквивалентно исключению нулей с β ≥ 1/2 + δ — quasi-RH.
