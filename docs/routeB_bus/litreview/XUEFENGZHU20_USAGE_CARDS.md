## Карточка 1 — Theorem 1.1: одноходовая редукция (наша рамка `FINITE_CERTIFICATE_PRINCIPLE`)

**Что ДОСЛОВНО сказано** (Theorem 1.1 «One-stroke reduction», p.3):

> Let `L > 0` and set `T₁ := 2πe^{A_L}`. Fix any `T ♯` for which
> `β* := log(T ♯/2π) − 1/T ♯ − A_L > 0`. […] Then for every real even `f` with `supp f ⊆ [−L, L]`,
> `Q(f) ≥ R(f) := 2F(i/2)² + (1/π)∫₀^{T ♯}(Ψ_L(t) − β*)|F(t)|² dt + β*‖f‖₂².`
> Moreover, in the Legendre basis of `L²[−L, L]` the quadratic form `R` is represented by
> `β*I + 2pp^T + C` where `C` has entries supported, up to explicitly bounded super-exponentially
> small tails, on orders `n ≲ eLT ♯/2`. Consequently, if the basis is cut after `N` even modes
> `0, 2, …, 2N−2`, with the first discarded order `2N ≳ eLT ♯/2`: if the leading `N × N` block has
> `λ_min ≥ λ₀ > 0`, then
> `Q(f) ≥ (min(λ₀, β* − ε_D) − ε_B)‖f‖₂²` for all `f` with `supp f ⊆ [−L, L]`,
> where `ε_D` (tail-block deviation) and `ε_B` (leading–tail coupling norm) are explicit,
> super-exponentially small constants bounded in the proof; in the certified run of Section 5
> both are below `10⁻¹⁰⁰`.

Геометрическая сторона, из которой всё растёт (формулы (2)–(3), p.2):

```
Q(f) = 2F(i/2)² + (1/2π)∫_ℝ |F(t)|² Ψ_L(t) dt          F = f̂
Ψ_L(t) = Re ψ(1/4 + it/2) − log π − Σ_{log n < 2L} (2Λ(n)/√n) cos(t log n)
A_L = Σ_{log n < 2L} 2Λ(n)/√n                          («mass of the prime comb»)
```

**Механизм доказательства** (§4, p.12–13), четыре элементарных куска:

1. Расщепление `∫₀^∞ = ∫₀^{T ♯} + ∫_{T ♯}^∞`; на хвосте Lemma 3.1 даёт `Ψ_L ≥ β*` **поточечно**,
   и хвост выбрасывается со знаком (Parseval `∫₀^∞|F|² = π‖f‖²`).
2. Локализация: `|j_n(x)| ≤ x^n/(2n+1)!!` (12) ⟹ строки `C` сверх-экспоненциально малы за
   `n > eLT ♯/2` (Стирлинг). Полюсный вектор — тоже (`cosh` целая).
3. Двублочная оценка `λ_min(M_R) ≥ min(λ_min(A), λ_min(D)) − ‖B‖` (13) — элементарная,
   `2|x||y| ≤ |x|²+|y|²`; `λ_min(D) ≥ β* − ε_D` по Гершгорину, `‖B‖ ≤ (‖B‖₁‖B‖_∞)^{1/2}` по Шуру.
4. Все три выброшенные величины имеют **определённый знак или явную границу** (Remark 4.1, p.13):
   «finer quadrature or larger `N` can only improve the certified constant, never invalidate it».

Огибающая (Lemma 3.1, p.11) — Бине-2 для дигаммы: `Re ψ(1/4+it/2) − log π ≥ log(t/2π) − 1/t`
при `t ≥ 15/4`, плюс тривиальное `Σ c_{p,k} cos(tk log p) ≤ A_L`.

Оптимальность константы (**Lemma 3.2**, p.11, verbatim):

> Write `P_L(t) = Σ_{log n<2L} (2Λ(n)/√n) cos(t log n)`. Then `sup_{t∈ℝ} P_L(t) = A_L`.
> Consequently the crude constant `C = A_L` of Lemma 3.1 is already optimal among all pointwise
> bounds `P_L(t) ≤ C` valid for every `t`, which is the only information about the comb that
> the reduction of Theorem 1.1 uses.

Доказательство — Вейлевская равнораспределённость: `{log p}` линейно независимы над `ℚ` по
единственности разложения, фазы заполняют тор, значит все косинусы одновременно подходят к `+1`.

**Что это даёт НАМ.** Это **работающий, полностью явный экземпляр нашей рамки
`docs/FINITE_CERTIFICATE_PRINCIPLE.md` (coercive tail + finite exact certificate) на нашем же
объекте**. Все четыре ингредиента Lean-подъёмны в принципе: Бине/дигамма-огибающая (Lemma 3.1),
Бернштейн-эллипс для квадратуры (Lemma 5.1, p.13), forbidden-region хвост (§5.3, p.13),
верифицированный Холецкий (Lemma 5.2, p.14: `L̃L̃ᵀ ⪰ 0` + Вейль ⟹ `λ_min ≥ −(r+s)`).
Ни одной анонимной константы.

**Чего НЕ даёт.** Это утверждение при ФИКСИРОВАННОМ `L`. Кофинальности нет и быть не может —
см. карточку 5 (барьер), и цена на наших окнах — карточка 6.

## Карточка 5 — Theorem 1.4: барьер. Почему кофинального утверждения тут не будет

**Что ДОСЛОВНО сказано** (Theorem 1.4, p.6):

> **(Barrier for pointwise-envelope certificates.)** Any application of Theorem 1.1 requires
> `T ♯ > T₁(L) = 2πe^{A_L}`, and `A_L = (4 + o(1))e^L` as `L → ∞` by the prime number theorem;
> hence the matrix size `N ≍ LT₁` and the number of quadrature nodes grow doubly exponentially
> in `L`. Moreover `sup_t` of the prime comb equals `A_L` exactly (Lemma 3.2), so within the
> class of certificates that bound the comb pointwise the threshold `T₁` cannot be lowered.

и §16 (p.32), формулировка, которую надо цитировать целиком:

> "Defeating positivity, that is, finding small Rayleigh quotients, is governed by the resolution
> height `T ∗ = 2πe^{2L}`, singly exponential […]. Certifying positivity through the geometric side
> is governed by the alignment threshold `T₁ = 2πe^{(4+o(1))e^L}`, doubly exponential […].
> The gap between `e^{2L}` and `e^{4e^L}` is the gap between knowing where the zeros are and
> proving that the primes cannot conspire. Closing it is an arithmetic problem, concerning
> simultaneous Diophantine properties of `{log p}`, and not a computational one."

и (Remark 1.6, p.6):

> "Certifying positivity past support ≈ 3.2 (`T₁ ≈ 10⁷`) by any pointwise-envelope method is
> therefore computationally void. To improve on pointwise envelopes one must prove that the phases
> `(t log p)_p` cannot align, an arithmetic statement about simultaneous Diophantine approximation
> of `{log p}`, of the same nature as the information carried by the zeros themselves."

Носитель 3.2 ⟺ `L = 1.6` ⟺ **`m = e^{3.2} = 24.5`**. То есть: поточечно-огибающие сертификаты
кончаются сразу за нашей ячейкой `m = 23`.

**Что это даёт НАМ.** Файрвол судьи (`SIGNFREE`, `LEAKAGE`, R3-префлайт) подтверждён с другой
стороны и в другой валюте. Наш собственный вывод был логический: «`µ_λ > 0` кофинально ⟹ RH
через CCM (3.27), значит фиксированное окно кофинальности не даёт». Zhu добавляет
**количественный барьер внутри самого класса сертификатов**: даже вычислительно эта дорога
закрывается дважды экспоненциально, и `sup` гребёнки ровно `A_L` (Lemma 3.2) — улучшить нельзя
в принципе, а не «пока не придумали».

**Чего НЕ даёт (его собственная оговорка, §14.2 p.31):** «Converting it into a proved lower bound
on the cost of an arbitrary positivity certificate would require the sampling theory of low zeta
zeros, the window floor being twice the squared smallest singular value of a low-zero sampling
operator, and that remains open.» Барьер доказан **только для поточечно-огибающих**
сертификатов; наш маршрут (Ритц-верх + посылка `ε_∞ ≤ C`) в этот класс не входит.
