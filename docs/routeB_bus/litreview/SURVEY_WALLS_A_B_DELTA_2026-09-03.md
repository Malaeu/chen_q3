## 0. Три стены как три неравенства

Объект: `F_m(z) = L^{-1/2} Σ_{|k|≤N} ξ_{-k}·2 sin(zL/2)/(z − 2πk/L)`, `L = log m`,
целая, экспоненциального типа `L/2`, нули вещественны (CCM Thm 5.10). Крыша
`rh_of_real_zero_family_tendsto_centeredXi`: сходимость к `Ξ` локально равномерно
на `|Im z| < 1/2` даёт RH.

| стена | неравенство | что нужно |
|---|---|---|
| **A** (идентификация) | `√L·(−1)^k ξ_{-k(m)} → Ξ(x)` при `2πk(m)/L → x` | согласие предела с `Ξ` на множестве с точкой сгущения |
| **B** (нормальность) | `∫_{−L/2}^{L/2} |q_m(t)| e^{σ|t|} dt ≤ C_σ·|F_m(0)|`, `∀σ<1/2`, `C_σ` не зависит от `m` | масса `q_m` у края окна убывает как `e^{−σ|t|}` |
| **Δ** (щель) | `inf_m (λ₂(m) − λ₁(m)) > 0` | простота дна равномерно по пути |

## 1. Стена B — нормальность

### 1.1 Что закрывает классика (отрицательно)

- **Cartwright 1936, Duffin–Schaeffer 1945/1952, Beurling** (через Blank–Ulanovskii
  arXiv:1603.09585 и Olevskii–Ulanovskii arXiv:1106.0576, оба открыты). Ограниченность
  на решётке даёт ограниченность на прямой и на полосах **только при типе строго ниже
  найквистова**: решётка `Λ` — sampling set для `B_σ` ⟺ `D⁻(Λ) > σ/π` строго.
  Наша решётка `2πℤ/L` для типа `L/2` стоит **ровно** на критической плотности.
  Свидетель: `z·sin(πz)` (у нас `sin(zL/2)`) — нуль на всей решётке, неограничена.
- **Что выживает на критической плотности:** только Парсеваль (Duffin–Schaeffer 1952:
  `γ = π`, `λ_n = n`, `A = B = 1`). У нас: `‖F_m‖²_{L²(ℝ)} = (2π/L)·Σ|F_m(x_k)|² = 2π`
  при единичном `ξ` — **равномерно по `m`, бесплатно**.
- **Plancherel–Pólya 1937** (через Carneiro et al. arXiv:1311.4862 Lemma 2.6):
  `∫|f(x+iy)|^p dx ≤ e^{pτ|y|}∫|f|^p`. Это даёт на полосе только
  `|F_m| = O(√L·m^{|y|/2})`. Множитель `m^{σ/2}` и есть стена.

**Вывод:** стена B — не задача теории выборок. Никакая норма выборок (sup или `ℓ²`)
её не закрывает. Это утверждение о **краевой массе** коэффициентного ряда. Это
математическая причина, почему Codex убил «скалярную огибающую» 03.09.

### 1.2 Старейший инструмент про краевую массу: Fuchs 1964

- **Fuchs 1964** (JMAA 9, 317–330; формула открыта через Bonami–Karoui arXiv:1509.02646
  eq. (39)): для sinc-ядра `∂_c ln λ_n(c) = 2|ψ_{n,c}(1)|²/c`. Производная крайнего
  собственного значения по размеру окна равна квадрату **краевого значения**
  собственной функции. Это формула Адамара для вариации области у нелокальной формы.
- **Osipov arXiv:1206.4056** (открыт): при `χ_n > c²` максимум `|ψ_n|` на `(−1,1)`
  достигается **на краю**. **Bonami–Karoui 2014/2016**: `|ψ_{n,τ}(1)| ≤ 2χ_n(τ)^{1/4}`,
  равномерно по `(n,c)`. Только вещественный интервал, полосы нет.
- **Connes–Consani arXiv:2106.01715**: ground-вектор формы Вейля на окне численно
  есть конечная сумма PSWF. Не доказано для всех `N`.

**Кандидат-пересадка (главная находка разведки):** если для формы Вейля на окне
`Q_W^a` (Bombieri 2000, Yoshida 1992, Suzuki 2026 — все дают `λ_a` как минимум на
единичном шаре с носителем в `[−a,a]`, Suzuki Thm 1.3: `λ_a` непрерывна по `a`)
верна формула `dλ_a/da = −c(a)·|v_a(a)|²` с `c(a) > 0`, то монотонность плюс
ограниченность `λ_a` дают `∫ c(a)|v_a(a)|² da < ∞`: краевая масса мала **в среднем по
окну**. Для крыши нормальность нужна только вдоль кофинальной подпоследовательности
(Монтель), а интегрируемость даёт `liminf = 0`, то есть подпоследовательность с
исчезающим краевым значением. **Но:** одно краевое значение не контролирует
`∫|q_m|e^{σ|t|}dt`; нужен профиль спада у края. Это разрыв между инструментом и
стеной, его надо назвать судье.

### 1.3 Новейшее (2020–2026): пусто

Ни одной теоремы о равномерной ограниченности на полосе для трансформов
собственных векторов усечённых свёрточных/тёплицевых/вейлевых операторов вдоль
растущего окна. CCM §7: «main remaining obstacle». Connes–van Suijlekom
arXiv:2511.23257: «No explicit bounds on |ξ̂(z)| in the complex plane»; их Гурвиц —
при **фиксированном** `L`. Connes, CIRM 2026: `|φ(z)| ≤ c·λ^{|z|/2}`, `c` не
равномерна по `λ`.

## 2. Стена A — идентификация

- **Критическая плотность ⇒ изометрия** (Duffin–Schaeffer 1952): `ℓ²`-сходимость
  решёточных значений ⟺ `L²(ℝ)`-сходимость `F_m`. Вход A в `ℓ²`-форме есть
  `L²(ℝ)`-сходимость `F_m → Ξ` на прямой. Это чище, чем поточечная формулировка в
  описании 03.09.
- **Landau–Pollak 1962 Thm 3**: сосредоточенную функцию приближают `[2WT]+1` prolate,
  и sinc-базис проигрывает eigen-базису на критической плотности. Классический ответ,
  почему узлы и prolate-разложение — разные языки одной вещи.
- **Jensen-путь (Griffin–Ono–Rolen–Zagier; Holland arXiv:2608.08682)**: гиперболичность
  доказана в клине `n³log²n ≥ K d⁵`, никогда для всех `(d,n)`. Недостающая
  равномерность по `d` — точный аналог нашей равномерности по `m`. Тот же разрыв,
  другое имя.
- **de Bruijn–Newman**: семья `H_t` с вещественными нулями при `t ≥ Λ` сходится к `Ξ`
  при `t → 0`; Гурвиц применим; всё содержание RH — выживает ли вещественность **в**
  пределе. Движение 2020–2026 только по верхней оценке `Λ` и по препятствиям
  (Michalowski arXiv:2602.20313: ядро не `PF₅`). Поучительный шаблон: семья с
  вещественными нулями, сходящаяся к `Ξ`, **существует**, и RH от этого не следует.

## 3. Стена Δ — щель

### 3.1 Классика говорит: щель схлопывается

- **Kac–Murdock–Szegő 1953 / Widom 1958** (Trans. AMS 88, открыт): для тёплицева
  усечения с гладким символом `λ_{ν,n} = M − σ²ν²π²/(2n²) + o(n⁻²)`. Два крайних
  собственных значения расходятся на `O(n⁻²) → 0`. Непрерывный аналог (Widom
  Thm 3.1): `O(A⁻²)`.
- **Landau–Widom 1980**: плато `#{ε<λ<1−ε} ≍ (2/π²) log c · log((1−ε)/ε)` — число
  собственных значений в переходной зоне **растёт**. Это про схлопывание щелей.
- **Connes–Consani arXiv:2106.01715**: у формы Вейля на окне **несколько** очень
  малых собственных значений (множественное число), по одному на низкий нуль.
  **Groskin arXiv:2605.20224**: дно `≈ 10⁻³³⁴` при `c=100, N=250`. Наша фаза 1:
  `β − a ≈ 10⁻⁵⁶` уже при `m = 13`.

**Вывод:** абсолютная щель `inf Δ > 0` вдоль растущего окна противоречит всей
классике и численности. Равномерная щель возможна только от **атомарности**
символа (`Σδ_γ` под RH), не от регулярности, и то, скорее всего, в
**относительной** форме (`λ₂/λ₁`, или щель после нормировки), а не абсолютной.
Шаг 3 плана 02.09 в абсолютной форме, вероятно, поставлен неверно.
**Не проверено численно нами** — это первый зонд.

### 3.2 Как доказывали «самую большую похожую задачу» — fundamental gap

- **Ashbaugh–Benguria 1989** (Proc. AMS 105, открыт): `λ₂ − λ₁ ≥ 3π²/d²` для
  симметричной одноямной `V` на отрезке. Механизм: пробная функция `u = (v₁/v₂)u₂`,
  знак кросс-члена из монотонности `u₂/u₁`.
- **Lavine 1994** (Proc. AMS 121, открыт): для выпуклой `V`. Механизм:
  (i) Hellmann–Feynman `Γ′(τ) = ∫ ∂_τV·(u₂² − u₁²)`; (ii) деформация к линейной `V`
  с `Γ′ < 0`; (iii) вириальное тождество.
- **Andrews–Clutterbuck 2011** (J. AMS 24, открыт): полное доказательство в `ℝⁿ`.
  Механизм: двухточечный принцип максимума для `Z(y,x,t) = v(y,t) − v(x,t) − 2φ(...)`,
  `v = u₁/u₀`; **модуль вогнутости** `log φ₀` (не просто лог-вогнутость
  Brascamp–Lieb 1976, её хватает только на `π²/D²` Yu–Zhong); сравнение с `cos(πx/D)`.
- **Дискретно:** Jarret–Jordan arXiv:1403.1473 (Lavine на графе-пути,
  `Γ ≥ 2(1−cos(π/N))`); Hofmann–Kerner–Pechmann arXiv:2508.16353: на растущих путях
  щель `→ 0`, компактный потенциал ускоряет схлопывание.

**Урок:** ни одно доказательство щели не оценивает собственные значения напрямую.
Все оценивают **форму ground-вектора**: монотонность `u₂/u₁`, первую вариацию щели,
вогнутость `log φ₀`. У тёплицевых сжатий нет ни локальности, ни принципа максимума;
единственное, что переносится, — **первая вариация** (Hellmann–Feynman плюс
интерлейсинг), и Jarret–Jordan уже гоняли её на матрице.

### 3.3 Что даёт старый Q3 и инерция

- **Bombieri 2000** (EUDML abstract): при конечном числе нулей вне прямой число
  отрицательных собственных значений большого усечения ровно половина числа таких
  нулей. **Alpöge–Furman Prop. 4.1** — то же через Сильвестра. Считают знаки, не щель.
- **Yoshida 1992 Lemma 3** (через Suzuki arXiv:2206.03682 §4.2): для `a ≤ a₀` и `μ>0`
  есть `N` с `⟨φ,φ⟩_W ≥ μ‖φ‖²` на `K_N(a)` — равномерный низ после удаления `N`
  низких мод. Ближайшее классическое к «щель над дном на окне», но только для
  **малых** окон. Уже на полке (`SUZUKI_ASPECTS_2206_USAGE_CARDS.md`).
- **Groskin arXiv:2607.02828**: усечение архимедова хвоста **понижает** каждое
  собственное значение (строгая тотальная положительность приращения). Численно
  положительная щель при конечном `T` — строгая нижняя оценка. Полезно для зондов Δ,
  не для равномерности по `m`.

## 4. Потолок второго момента (для вопроса «интегрировать Lamzouri в старый Q3»)

- **Alpöge–Furman §7.2(a)**: с одними `tr`, `‖·‖_HS` и блочной структурой конфигурация
  «2/3 простых на прямой + 1/6 двойных» даёт ровно 2/3 — точно; выше нужна парная
  корреляция за пределами носителя Фурье 1.
- **Lamzouri Rem. 3.4**: `C_MT` оптимальна для метода.
- **Goldston–Lee–Schettler–Suriajaya arXiv:2503.15449, 2507.06823**: PCC (в любой
  форме) ⇒ 100%.
- Ничего в 2024–2026 не расширяет безусловный носитель Фурье за 1.

**Ответ на вопрос владельца:** возвращаться к PSD-линии старого Q3 ради Lamzouri
не стоит. PSD-сертификат для окна = индекс инерции ноль = RH-сила для окна.
Lamzouri и AF оценивают индекс **сверху** через след и норму и получают долю,
потолок 2/3 доказан ими же. В старый Q3 из этого переносится только счёт
отрицательных направлений нашей матрицы (Bombieri/AF), и он уже был на полке.
Что стоит взять из **старого Q3 плюс классики** — непрерывную форму на окне
`Q_W^a` (Bombieri/Yoshida/Suzuki): у неё чистое исчисление вариации окна, в
отличие от расписания CCM `m = N = k+2`, где окно и арифметика движутся вместе.

## 5. Единая картина и что из неё следует

Все три стены сводятся к **одному объекту**: краевым значениям двух низших
собственных функций формы Вейля вдоль растущего окна.

```
dλ₁/da = −c₁(a)|v₁(a)|²          (Fuchs/Адамар, КАНДИДАТ для формы Вейля)
dλ₂/da = −c₂(a)|v₂(a)|²
dΔ/da  = −(c₂|v₂(a)|² − c₁|v₁(a)|²)   Δ не растёт (интерлейсинг, доказано)
           ⇒ край второй функции тяжелее края первой
стена B: профиль спада v₁ у края;  стена Δ: разность краёв;  стена A: ℓ² узлов = L²(ℝ)
```

Это **представление**, не ход. Оно закрывает больше, чем открывает: три
разноимённые стены становятся одним леджером краёв, для которого уже есть имя на
шине — гол 034 «edge sliver» — и классический инструмент (Fuchs 1964).

### Дешёвые зонды (наш канал, часы)

1. **Δ схлопывается?** Два низших собственных значения CCM-матрицы вдоль `m`
   (скрипты фаз 1–3, arb). K6: `P_ABS_GAP_COLLAPSES` p=0.80.
2. **Формула Fuchs для CCM?** Численно `dλ₁/dL` против `|ξ_{±N}|²` вдоль `m`.
   K6: `P_FUCHS_IDENTITY_NUMERICALLY_HOLDS` p=0.55.
3. **Ratio-тест B** из описания 03.09 (`R_m(σ)`), K6 p=0.60 уже зарегистрирован.

### Батч судье (кандидат Q9)

1. Верна ли формула Адамара `dλ_a/da = −c(a)|v_a(a)|²` для `Q_W^a` (Suzuki/Yoshida)
   и для `λ_min(L)` CCM с явной `c > 0`? Первоисточник: Fuchs 1964 для sinc.
2. Абсолютная щель `inf Δ > 0` — не противоречит ли она CC 2106.01715 (несколько
   малых собственных значений)? Переставить шаг 3 в относительную форму?
3. Достаточно ли усреднённого контроля края (`∫c|v(a)|²da < ∞` ⇒ подпоследовательность)
   для нормальности вдоль кофинального пути, или моментная оценка требует профиля?
