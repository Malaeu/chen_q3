## Карточка 1 — Theorem 4.3: существует, дословно

**Что ДОСЛОВНО сказано** (стр. 15–16, строки 1052–1056 текстового слоя):

> **Theorem 4.3.** Let `a₀ > 0` and `µ > 0` be given numbers. Then there exists `N ≥ 0`
> such that `⟨φ, φ⟩_{G_g,a} ≥ µ ∫_{−∞}^{∞} |Φ₁(φ, z)|² dz` (4.12) for every
> `φ ∈ K_{N,0}(a)` and `0 < a ≤ a₀`, where `Φ₁(φ, z)` is the transform of φ in (4.2).

Определения оттуда же:

```
(4.2)  Φ₁(φ, z) := (φ̂(z) − φ̂(0)) / z = ∫_{−a}^{a} φ(t)·(e^{izt} − 1)/z dt
(4.1)  K_N(a)   := { ψ ∈ K(a) : ∫_{−a}^{a} ψ(x)·exp(πinx/a) dx = 0 ∀ n∈ℤ, |n| ≤ N }
       K_{N,0}(a) := { φ ∈ L²(−a,a) : φ̂(0) = 0, I₀^{(a)}(φ) ∈ K_N(a) }
```

**Что это даёт НАМ.** Подтверждена посылка вердикта: механизм high-mode coercivity
существует и не является пересказом. Утверждение Мифоса «Theorem 4.3 существует дословно
в нужной форме» — **проверено по первоисточнику, снимаю с него метку relay**.

**Чего НЕ даёт.** Константы. В формулировке стоит «there exists `N ≥ 0`» — чистое
существование. Извлечение `N = N(a₀, µ)` остаётся работой, ровно как и записано в
`TASK_B`.

## Карточка 2 — сторона нормы: риск Мифоса подтверждён и уточнён

**Что ДОСЛОВНО сказано** (доказательство Theorem 4.3, строки 1069–1072):

> Let `φ ∈ K_{N,0}(a)` and put `ψ = I₀^{(a)}(φ)` (`∈ K_N(a)`). Then `ψ(−a) = 0`,
> `ψ(a) = φ̂(0) = 0`, `Φ₁(φ, z) = −i ψ̂(z)`, and …

И в §5 (строка 1148) то же самое записано явно:

> `⟨v, v⟩_{G_g,a} ≥ µ ‖I₀^{(a)}(v)‖_{L²(−a,a)}` (5.1)

**Что это даёт НАМ.** Правая часть (4.12) — это, по Парсевалю, норма **антипроизводной**
`ψ = I₀(φ)`, а не норма самой `φ`. Предупреждение Мифоса про «сторону нормы»
подтверждено первоисточником: пол даётся в `ψ`-координатах.

Практический вывод для `Lock B` (`YoshidaTailCoercivity13Explicit`): целиться надо в
`ψ`-сторону, где базис CCM ортонормален (`G = I`). Доказательство, ведённое в
`φ`-координатах, попадает в стоп-код `YOSHIDA_TAIL_WRONG_OBJECT`, записанный вердиктом
как STRONGEST ATTACK.

**Чего НЕ даёт.** Готового перевода нашей матрицы в `ψ`-координаты. Это наша работа.

## Карточка 3 — ГЛАВНОЕ: для формы Вейля нужен Yoshida, а не Theorem 4.3

**Что ДОСЛОВНО сказано** (§4.2 «Yoshida's results», строки 746–766):

> Yoshida [33] studied a hermitian form on `C_c^∞(ℝ)` defined by `⟨φ, ψ⟩_W := W(φ ∗ ψ̃)`.
> […] Yoshida also proved that, for given `a₀ > 0` and `µ > 0`, there exists `N ≥ 0` such
> that **`⟨φ, φ⟩_W ≥ µ‖φ‖_{L²}`** for every `φ ∈ K_N(a)` and `0 < a ≤ a₀` ([33, Lemma 3]).

**Что это даёт НАМ — и это важнее всего остального в статье.** Две теоремы различаются
и формой, и нормой:

| источник | форма | правая часть | пространство |
|---|---|---|---|
| Yoshida [33, Lemma 3] | `⟨·,·⟩_W` — **форма Вейля** | `µ‖φ‖_{L²}` — честная норма | `K_N(a)` |
| Suzuki Theorem 4.3 | `⟨·,·⟩_{G_g,a}` — screw-функция | `µ∫|Φ₁|²` — норма антипроизводной | `K_{N,0}(a)` |

Наш объект — форма Вейля (`W_{0,2} + W_arch − W_prime`). Значит **целевое утверждение —
Lemma 3 Yoshida**, и она даёт ровно то, что нужно: пол в честной `L²`-норме, без потери
`1/n²`. Theorem 4.3 — аналог для другой формы, и `TASK_B` вердикта, отправляющий за
константами именно в неё, метит в соседний объект.

Сам Suzuki это и подтверждает: доказательство (4.13) идёт «in the same way as
[33, Lemma 3]» — техника общая, утверждения разные.

**Хорошая новость по STRONGEST ATTACK.** Вердикт требовал доказать crosswalk
`V_n ↔ e^{πinx/a}`, иначе маршрут стоит. Определение (4.1) построено **дословно на этих
же экспонентах**: `K_N(a)` — функции с нулевыми коэффициентами при `exp(πinx/a)` для
`|n| ≤ N`. То есть «высокие моды» Yoshida и наши моды — это один и тот же объект на
уровне определения. Crosswalk компилируется здесь, а не требует отдельной конструкции.

**Чего НЕ даёт.** Самой статьи Yoshida у нас нет: `[33]` = H. Yoshida, «On Hermitian
forms attached to zeta functions», *Zeta functions in geometry* (Tokyo), Adv. Stud. Pure
Math. — сборник 1992 года, не на arXiv. Ни констант, ни доказательства Lemma 3 мы
отсюда не получим — Suzuki её только цитирует.

## Карточка 4 — цепочка констант: что в тексте есть на самом деле

**Что ДОСЛОВНО сказано** (доказательство Theorem 4.2, строки 934–937 и 955–957):

```
C₁ = max_{ℜ(s)=1+c} { |1/(s−1) + 1/s| , |(ζ′/ζ)(s)| }
C₂ = C₂(a₁) > 0  такое, что  K(t,u;±c) ≤ C₂·K(t,u)  для |t|,|u| ≤ a, 0 < a ≤ a₁
```

Итоговое условие Theorem 4.2 (строки 1034–1045):

```
⟨φ,φ⟩_{G_g,a} ≥ ((C − 2C₁C₂) − a(C + C₀)C₃) · (1/2π)∫|Φ₁|² dz  + (то же для −z)
коэффициент положителен при достаточно малом a
```

Theorem 4.3 берёт `C > 3C₁C₂ + µ`, и вся её работа сводится к оценке

```
(4.13)  ∫_{|z| ≤ t₀} |Φ₁(φ;z)|² dz  ≪  N^{−1/2} ∫_{−∞}^{∞} |Φ₁(φ;z)|² dz
        implied constant зависит только от a₀
```

**Что это даёт НАМ.** Скелет цепочки известен: `C₁` считается явно, `C₂` сравнивает два
ядра, `C₃` и `C₀` появляются в оценке низкочастотной утечки, и всё упирается в
`N^{−1/2}`. Это и есть материал для `TASK_B`.

**Числовая поправка к разбору Мифоса.** Он написал, что «контурный сдвиг на `ℜs = 2+`
давит простые до `|ζ′/ζ| ≈ 1.5` (C₁)». Значение `C₁ = 1.5` верное, но приходит **не от**
`ζ′/ζ`. Посчитано нами на `ℜ(s) = 2` (то есть `c = 1`), `mp.dps = 20`:

```
max |1/(s−1) + 1/s|   = 1.5          ← достигается при s = 2, это и есть C₁
max |(ζ′/ζ)(s)|       = 0.56996099
```

Разница практическая: если оптимизировать `C₁`, работать надо с полюсным слагаемым, а не
с логарифмической производной — та втрое меньше и не является узким местом.

**Чего НЕ даёт.** `C₂`, `C₃`, `C₀` в тексте существуют, но не вычислены — только
«there exists». Число `R` (или `N`) в замкнутом виде из статьи не выводится, и вилка
Мифоса `R(µ=1) ∈ [2·10², 10⁵]` остаётся его оценкой, а не результатом чтения.
