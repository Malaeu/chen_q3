## Карточка 1 — Lemma 3: то самое утверждение, и оно про НАШУ форму

**Что ДОСЛОВНО сказано** (стр. 288, текстовый слой строка 485):

> **Lemma 3.** Suppose that `a₀ > 0` and `µ > 0` are given. Then there exists a
> non-negative integer `N` such that ⟨неравенство⟩ for every `φ ∈ K_N(a)`, `0 < a ≤ a₀`.

Само неравенство в текстовом слое потерялось (формула-картинка), но оно восстанавливается
из доказательства дословно — последняя строка: «Choosing `N` sufficiently large, we get
`(φ,φ) ≥ µ‖φ‖²_{L²}`». Suzuki цитирует его в той же форме:
`⟨φ,φ⟩_W ≥ µ‖φ‖_{L²}`.

Пространство (стр. 288):

```
K_N(a) = { φ ∈ K(a) : ∫_{−a}^{a} φ(x)·exp(πinx/a) dx = 0  для всех n ∈ ℤ, |n| ≤ N }
C_N(a) = C(a) ∩ K_N(a)
```

**Что это даёт НАМ.** Подтверждено по первоисточнику, а не по цитате: пол даётся в
**честной `L²`-норме** — `‖φ‖²_{L²}`, без антипроизводной. Именно этого требует `Lock B`,
потому что базис CCM ортонормален в этой норме (`G = I`).

Тем самым закрыт риск, который Прошка записала как «вероятный первый баг: normalization»,
а Мифос — как главный K3: в теореме Suzuki (Theorem 4.3) правая часть есть
`µ∫|Φ₁|² = 2π‖I₀φ‖²`, норма антипроизводной, где пол падает как `1/n²`. У Yoshida этой
потери нет.

**Чего НЕ даёт.** `N` не выписан замкнутой формулой — сказано «choosing `N` sufficiently
large». Но, в отличие от Suzuki, все входящие константы определены явно (карточка 2), так
что `N` вычислим.

## Карточка 2 — цепочка констант выписана полностью

**Что ДОСЛОВНО сказано** (стр. 287–288, строки 364–369, 386–396, 419–420, 544–556):

```
C₁(a) = (1/2a)·∫_{−2a}^{2a} (e^{x/2} + e^{−x/2}) dx
C₂(a) = |{ (p, m) : m·log N(p) ≤ 2a }|          ← счётчик простых степеней в окне

(2.2)  выбрать t₀ > 0 так, что  Re ψ(1/4 + it/2) ≥ C  и  Re ψ(1/2 + it) ≥ C  при |t| ≥ t₀
(2.3)  C₀  = max_{|t| ≤ t₀} |Re ψ(1/4 + it/2)|
       C₀' = max_{|t| ≤ t₀} |Re ψ(1/2 + it)|

(2.4)  (φ,φ) ≥ {(r₁ + 2r₂)C + log A_k − C₁(a) − 2C₂(a)}·‖φ‖²_{L²}
               − {r₁(C₀ + C) + 2r₂(C₀' + C)}·(1/2π)·∫_{|t| ≤ t₀} |φ̂(t)|² dt
```

Доказательство Lemma 3 выбирает `C` из условия

```
(r₁ + 2r₂)C + log A_k − C₁(a₀) − 2C₂(a₀) > µ
```

и приходит к

```
(φ,φ) ≥ { (r₁ + 2r₂)C + log A_k − C₁(a₀) − 2C₂(a₀) − C₃·Σ_{|n| > N} (a/πn)² }·‖φ‖²_{L²}

C₃ = {r₁(C₀ + C) + 2r₂(C₀' + C)}·(1/2π)·∫_{|t| ≤ t₀} (1 + a₀|t|)² dt
```

**Что это даёт НАМ — это и есть материал `Lock B`.** `N` определяется единственным
условием: хвост `Σ_{|n| > N} (a/πn)²` должен съесть меньше, чем запас над `µ`. Поскольку
`Σ_{|n| > N} n⁻² ≍ 2/N`, зависимость `N ≍ C₃a²/(π²·запас)` — то есть **линейная по `C₃`**,
а не что-то неуправляемое.

Для нашего случая поле рациональное, значит `r₁ = 1`, `r₂ = 0`, `A_k = 1` и `log A_k = 0`.
Цепочка сокращается до

```
C > µ + C₁(a₀) + 2C₂(a₀)
C₃ = (C₀ + C)·(1/2π)·∫_{|t| ≤ t₀} (1 + a₀|t|)² dt
```

`C₂(a₀)` при `a₀ = log√13` — это просто счётчик пар `(p, m)` с `m·log p ≤ log 13`, то есть
конечный список простых степеней до 13; он у нас уже зафиксирован в
`PRIME_POWERS = ((2,2),(3,3),(4,2),(5,5),(7,7),(8,2),(9,3),(11,11),(13,13))`.

**Чего НЕ даёт.** Численных значений `C₀`, `C₀'`, `t₀` в тексте нет — они определены
условиями на `Re ψ`, и их надо посчитать самим. Это конечная работа с дигамма-функцией,
не исследование.

## Карточка 3 — соответствие переменных с нашими объектами

| Yoshida | наш объект | статус соответствия |
|---|---|---|
| `⟨·,·⟩` — эрмитова форма из явной формулы | форма Вейля `W_{0,2} + W_arch − W_prime` | требует crosswalk, см. ниже |
| `K_N(a)`, зануление при `exp(πinx/a)`, `|n| ≤ N` | «высокие моды» odd-сектора | **совпадает дословно** — это те же экспоненты, что в паре `V_n ↔ e^{πinx/a}` |
| `a₀` | `log√13` (полудлина centered-окна) | прямая подстановка |
| `µ` | `μ = 1` в нашем замере хвоста | прямая подстановка |
| `N` | `R` из GLOWER (`R(μ=1) = 70` измерено) | **сравнимо: аналитическое `N` против измеренного 70** |
| `r₁, r₂, A_k` | поле `ℚ`: `1, 0, 1` | тривиально |
| `C₂(a₀)` | наш `PRIME_POWERS` для `m = 13` | тот же список |

**Проверка, которую это открывает.** У нас `R` измерен численно (`70`, устойчиво при
`N = 90…480`). Yoshida даёт путь посчитать `N` аналитически. Совпадение порядков было бы
сильной перекрёстной проверкой обоих; расхождение — сигналом, что crosswalk неточен.

## Карточка 4 — чего эта статья НЕ закрывает

**Она не про CCM-матрицу.** Форма у Yoshida строится из явной формулы для дзета-функции
числового поля; наша `ccmWeilMatFinite` — конечная матрица в конкретном базисе. Что
первая ограничивает вторую снизу, **из статьи не следует** — нужен тот самый crosswalk,
который вердикт назвал STRONGEST ATTACK.

**Она не даёт `Lock A` и `Lock C`.** Компрессия odd-сектора и абстрактная теорема
Feshbach — наша работа.

**Lemma 3 безусловна** (не зависит от RH) — это её ценность; но она о существовании `N`,
а не о конкретном значении, и конкретизация ложится на нас.
