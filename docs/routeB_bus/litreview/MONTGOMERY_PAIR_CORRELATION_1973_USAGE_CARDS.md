## Карточка 1 — что доказано и при каком условии

**Что ДОСЛОВНО сказано** (§1, первая строка):

> **We assume the Riemann Hypothesis (RH) throughout this paper**; `ρ = ½ + iγ` denotes a
> nontrivial zero of the Riemann zeta function.

Основной объект — преобразование Фурье распределения разностей `γ − γ'`:

```
F(α) = F(α, T) = (T/2π · log T)⁻¹ · Σ_{0<γ,γ'≤T} T^{iα(γ−γ')} · w(γ−γ'),   w(u) = 4/(4+u²)
```

**THEOREM (Assume RH).** `F(α)` вещественна, `F(α) = F(−α)`, и при `T > T₀(ε)` выполняется
`F(α) ≥ −ε` для всех `α`. Для фиксированного `α ∈ [0,1)`:

```
F(α) = (1 + o(1))·T^{−2α}·log T + α + o(1)
```

равномерно при `0 ≤ α ≤ 1 − ε`.

**Что даёт НАМ.** Это «prime side» в терминологии работы Claude: вычисление второго момента
парной корреляции через сумму по простым степеням. Именно эта часть у Montgomery
**безусловна** — RH нужна была только чтобы читать «zero side» как положительную сумму по
вещественным ординатам.

## Карточка 2 — константа 2/3 и её происхождение

**Что ДОСЛОВНО сказано** (§1, после формулы (7)):

> The number of zeros of `ζ(s)` with `0 < γ ≤ T` is `~(T/2π)log T`, so the above asserts
> that **at least ⅔ of the zeros are simple**.

Там же: известно, что первые 3 500 000 нулей просты и лежат на критической прямой;
безусловный результат в этом направлении — только у Сельберга (положительная плотность
нулей нечётного порядка на прямой).

**Что даёт НАМ.** Точное происхождение константы. В работе Claude она получена без
предположения RH: RH-зависимый шаг заменён линейной алгеброй на конечной компрессии формы
Вейля — закон инерции Сильвестра плюс rank–trace неравенство через неравенство следов фон
Неймана.

**Чего НЕ даёт.** Ничего непосредственно применимого к нашей ячейке: наш объект — щель
конечной матрицы CCM, а не статистика разностей ординат. Связь идёт только через общий
предмет — форму Вейля.
