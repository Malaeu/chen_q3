                                                                On Cartwright’s theorem
arXiv:1603.09585v1 [math.CA] 31 Mar 2016




                                                            Natalia Blank and Alexander Ulanovskii


                                                                                 Abstract
                                                     We present a characterization of sets for which Cartwright’s theorem
                                                 holds true. The connection is discussed between these sets and sampling
                                                 sets for entire functions of exponential type.

Definition 1 We say that Λ ⊂ R is a Cartwright set (CS) for a
class M of entire functions, if there is no function f ∈ M which is
bounded on Λ and unbounded on the real axis.
  Theorem 1 states that the set of integers is a CS for the class
E<π .
  We prove

Theorem 2 A set Λ ⊂ R is a CS for E<σ if and only if it contains
a u.d. subset Λ∗ satisfying D − (Λ∗ ) ≥ σ/π.
   Since the subject is classical nowadays, this result may be known
to the experts. However, to the best of our knowledge, it has not
been recorded in the literature.
   Cartwright’s theorem has inspired a number of different results.
In particular, it is shown in [B40] and [DF45] (see also literature
therein), that certain “perturbations” of the integers are CSs for
E<π .
   Papers [A51], [B55], [L57] and [M57] adopt a more general ap-
proach: The condition of boundedness of f on Λ is dropped, and
results are obtained concerning the growth of the function from its
growth on Λ.
   See [Bn48], [LM61], [OU15] (and the literature therein) for some
estimates of kf k∞ for functions f ∈ Eσ satisfying kf |Λ k∞ ≤ 1. Here

   See also [LF93], [L74] and [LN04] for some multi-dimensional

   There have been a number of other results related to Theorem 1,
which we do not mention here.
   It seems plausible that Theorem 2 can be deduced from the re-
sults of [A51] or [M57]. In our proof we use A. Beurling’s results
from [Br89].

1.2   Beurling’s Sampling Theorem
Let Bσ denote the subclass of Eσ of functions f bounded on the
real axis. It is well–known that every function f ∈ Bσ satisfies the
inequality (see, for example [L96], Lec. 6, Theorem 3)
             |f (x + iy)| ≤ kf k∞ eσ|y| ,     for all x, y ∈ R.    (3)

The spaces Bσ are usually called Bernstein spaces.
  A set Λ is called a sampling set (SS) for Bσ , if there is a constant
K such that
                kf k∞ ≤ Kkf |Λ k∞ ,         for all f ∈ Bσ .       (4)

Denote by K(Λ, Bσ ) the infimal K in (4), and set K(Λ, Bσ ) = ∞ if
Λ is not an SS for Bσ . The constant K(Λ, Bσ ) is called the sampling
bound for Bσ .
   A classical result of Beurling describes the SSs for Bσ :
Theorem 3 ([Br89]) A set Λ ⊂ R is an SS for Bσ if and only if
it contains a u.d. subset Λ∗ satisfying D − (Λ∗ ) > σ/π.


2     Sampling Sets and Cartwright Sets for Eσ
Let us extend the notion of sampling set.
Definition 2 We say that a set Λ ⊂ R is an SS for a class M of
entire functions, if there is a constant K such that for every f ∈ M
the inequality
                     max |f (x)| ≤ K max |f (λ)|                  (5)
                    |x|≤r                λ∈Λ,|λ|≤r

holds on an unbounded set of r ∈ (0, ∞) (this set depends on f ).
   This definition means that, up to a multiplicative constant, no
function f ∈ M can grow faster along the real axis than it grows
along Λ. When M = Bσ , this definition coincides with the classical
one.
   In what follows, we denote by K(Λ, M) the infimal K in (5), and
we set K(Λ, M) = ∞ if Λ is not an SS for M.
   Since Bσ ⊂ Eσ , we have K(Λ, Bσ ) ≤ K(Λ, Eσ ). In fact, these two
constants are equal:


                                     3
Theorem 4 A set Λ ⊂ R is an SS for Eσ if and only if it is an SS
for Bσ . Moreover, K(Λ, Eσ ) = K(Λ, Bσ ).
    It is clear from the definitions above that every SS for a class M
is also a CS for M. We show that for the classes Eσ the opposite is
also true:
Theorem 5 A set Λ ⊂ R is a CS for Eσ if and only if it is an SS
for Eσ .
   Theorems 3,4 and 5 yield
Corollary 1 A set Λ ⊂ R is a CS for Eσ if and only if it contains
a u.d. subset Λ∗ satisfying D − (Λ∗ ) > σ/π.
   Theorem 2 above is an immediate consequence of this corollary.
Remark 1. It might be interesting to compare Theorem 2 with the
result in [PM10] which gives a characterization of the Pólya sets. A
set Λ ⊂ R is called a Pólya set if the constants are the only entire
functions of exponential type zero which are bounded on Λ. Since
there is no non-constant function of zero type bounded on R, the
Pólya sets are therefore the Cartwright sets for the class of entire
functions of exponential type zero. However, the characterization
of CSs for functions of finite exponential type involves the lower
uniform density, while the characterization of Pólya sets involves
the so-called inner Beurling-Malliavin density, see [PM10].
Remark 2. One may wish to describe CSs for other classes of entire
functions. Here we present a result in this direction.
   Given a natural number n and a positive number σ, we denote
by E<σ,n the space of all entire functions f satisfying the inequality
                                      n
                      |f (z)| ≤ Cec|z| , z ∈ C,
with some 0 < c < σ and C > 0. Clearly, E<σ,1 = E<σ .
   The following result extends Theorem 2 to the classes E<σ,n :
Theorem 6 A set Γ ⊂ R is a CS for E<σ,n if and only if Γn is a
CS for E<σ , where
        Γn := {γ n : γ ∈ Γ, γ ≥ 0} ∪ {−|γ|n : γ ∈ Γ, γ < 0}.
   By Theorem 2, it follows that Γ is a CS for E<σ,n if and only if
the set Γn contains a u.d. subset Λ satisfying D − (Λ) ≥ σ/π.

   Given two sets Λ, Λ∗ such that Λ∗ ⊂ Λ, it is clear that K(Λ∗ , Bσ ) ≥

two closed sets Λ and Γ is the smallest number t so that
                         Λ ⊂ Γ(t), Γ ⊂ Λ(t).

4.1   Proof of Theorem 4
It suffices to check that K(Λ, Eσ ) ≤ K(Λ, Bσ ). In other words, it
suffices to check that inequality (5) holds on an unbounded set of
r > 0 for every function f ∈ Eσ and every constant K > K(Λ, Bσ ).
