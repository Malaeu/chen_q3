## Карточка 1 — что именно неасимптотично

**Что ДОСЛОВНО сказано** (абстракт):

> There are many asymptotic characterizations of the number of eigenvalues not near `0` or
> `1`. In contrast, there are **very few non-asymptotic results**, and these don't fully
> characterize the clustering behavior of the DPSS eigenvalues. In this work, we establish
> two novel non-asymptotic bounds on the number of DPSS eigenvalues between `ε` and `1 − ε`.
> Furthermore, we obtain bounds detailing **how close the first ≈ 2NW eigenvalues are to 1**,
> how close the last ≈ N − 2NW eigenvalues are to 0, as well as how small certain
> **summations** of these eigenvalues are.

Непрерывный случай (PSWF, а не дискретный DPSS) — Следствие 3, стр. 12:

```
1 − λ̃_k  ≤  10 · exp[ −( 2c/π − k − 7 ) / ( (2/π²)·log(100c/π + 25) ) ]     при 0 ≤ k ≤ ⌈2c/π⌉ − 1
```

и Следствие 4 — та же оценка для **сумм** `Σ_{k<K} (1 − λ̃_k)`.

**Что это даёт НАМ.** Величина `1 − λ̃_k` при `k = 2` — это и есть наш `1 − χ₂`. Здесь она
ограничена **сверху явно, без асимптотики, без неизвестных констант, при любом `c > 0`**.
Все константы выписаны числами.

## Карточка 2 — ГЛАВНОЕ: этот темп СЛАБЕЕ фуксовского, и это меняет цену строгости

Показатель экспоненты в Следствии 3 по порядку:

```
( 2c/π ) / ( (2/π²)·log(100c/π + 25) )  ≍  π·c / log c
```

то есть

```
Karnik (строго, неасимптотично):   1 − λ̃_k  ≲  exp( −π·c / log c )
Fuchs  (асимптотика):              1 − χ₂    ~  C·λ⁹·exp( −4π·λ² )
```

**Это принципиально разные скорости.** У Фукса показатель **квадратичен** по параметру, у
Karnik — линеен с логарифмическим делителем. Взяв Karnik ради строгости, мы теряем
`e^{−4πλ²}` и получаем радикально более слабое убывание.

**Что это значит для `Q2`.** Классификация темпов из вердикта 2026-08-07 (`σ_Δ` против
`σ_num`) сравнивает **показатели**. Подставить сюда строгую оценку Karnik вместо
эвристической фуксовской — значит сравнивать с другим показателем и, возможно, получить
`DELTA_SUPERCRITICAL_FASTER_THAN_NUMERATOR`, то есть провал ветки, там где эвристика давала
запас. **Строгость здесь не бесплатна, она меняет исход сравнения.**

Это наблюдение сделано при чтении и до сих пор нигде не обсуждалось.

## Карточка 3 — сами авторы о пределах своей оценки

**Что ДОСЛОВНО сказано** (стр. 11, после Следствия 1):

> The second bound in Corollary 1 **does not capture the faster than exponential decay rate**
> of `λ_k` for `k ≥ (eπ/2)NW` that is demonstrated by (5). However, we note that for
> `NW ≥ 15`, the second bound in Corollary 1 will yield an upper bound for `λ_{⌈eπNW/2⌉}`
> that is less than the single precision machine epsilon… So these bounds are still useful.

**Что это даёт НАМ.** Авторы сами признают: их оценка **не ловит** сверхэкспоненциальный
режим. Их защита — «всё равно ниже машинного эпсилон», то есть аргумент численной
достаточности, а не остроты.

**Чего НЕ даёт.** Для нас аргумент «ниже машинного эпсилон» не работает: мы сравниваем
показатели двух экспонент, а не проверяем, малы ли они по отдельности. Мы в интервальной
арифметике на сотнях знаков, а не в двойной точности.

## Соответствие переменных

| у них | у нас | статус сопоставления |
|---|---|---|
| `c` — параметр полосы (непрерывный случай) | `λ` в `e^{−4πλ²}` | **НЕ ПРОВЕРЕНО.** Связь `c ↔ λ` из первоисточника не выведена; без неё сравнение показателей некорректно |
| `λ̃_k` — собственные значения PSWF | `χ_k` в `1 − χ₂` | согласуется по смыслу (концентрация), проверено по абстракту |
| `N`, `W` (дискретный случай) | — | нам нужен непрерывный: Теорема 3, Следствия 3–4 |
| `1 − λ̃_k` | дефицит концентрации | это тот же объект |

**Строка `c ↔ λ` — блокирующая.** Пока она не выведена, «темп Karnik слабее фуксовского»
остаётся утверждением о **форме** показателей, а не численным сравнением. Записано как
наблюдение, не как посылка.
