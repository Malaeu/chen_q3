## 1. Первый результат — конечный словарь Гинана–Вейля (Theorem 2.5)

Вещественный чётный коэффициентный вектор `v ∈ ℝ^{N+1}` канонически определяет цепь

```
v ⟼ T_v ⟼ K_v ⟼ ĝ_v ⟼ g_v
```

и для наведённой тест-функции катофф-свободная усечённая форма **точно** вычисляет нулевую
сторону явной формулы:

```
⟨v, Q_∞ v⟩ = Σ*_{ζ(½+iz)=0} g_v(z)          (нули с кратностью)
```

**Каждое значение усечённой формы есть точная сумма по нетривиальным нулям `ζ`.**

Конструкция проходит через точный факторный источник размерности `2N+1` (Corollary 2.4);
полюсный член выключается на несхлопывающемся подсемействе размерности `N − s − 1`
(Corollary 2.7) — конечный аналог работы ортогонально полюсу в критерии Вейля.

Явные объекты (§2.1):

```
L = log c,   Δ = L/2π,   ρ = 2π/L
u₀ = v₀,  u_k = u_{−k} = v_k/√2   (1 ≤ k ≤ N)      — изометрическое чётносекторное вложение
T_v(t) = Σ_{m=−N}^{N} u_m e^{2πimt}
K_v(ω) = 2 ∫₀^ω T_v(t)·T_v(ω−t) dt                  — ядро Вольтерра «синус-хорда»
ĝ_v(ξ) = πK_v(1 − |ξ|/Δ) при |ξ| ≤ Δ, иначе 0
g_v(z) = ∫_{−Δ}^{Δ} ĝ_v(ξ) e^{2πizξ} dξ
```

Три источниковые функции усечённой формы Вейля — (1) простые, (2) полюс, (3) архимедова:

```
ψ_p^{(c)}(x) = −(1/π) Σ_{q = p^a ≤ c} (Λ(q)/√q)·sin(2πx(1 − log q/L))
ψ₀(x)        = (1/π) ∫₀^L 2cosh(y/2)·sin(2πx(1 − y/L)) dy
ψ_ℝ,T(x)     = (1/2π²) ∫_{−T}^{T} h₊(r)·S(r,x,L) dr
```

Дивидендно-разностная структура матрицы (`Q_ψ`), `(Q_ψ)_{mn} = (ψ(m)−ψ(n))/(m−n)` при
`m ≠ n`, `ψ′(m)` при `m = n` — **ровно структура Конна–ван Сёйлекома Prop 4.1**.

**Lemma 2.1 (Entry identification):** предел `Q_arch,∞` существует поэлементно, и

```
Q_∞ := Q_prime^{(c)} + Q_pole + Q_arch,∞
```

**есть галёркинская матрица Конна–Консани–Московичи формы Вейля**, в нотации [10] Eqs.
(3.10)–(3.11), (3.16): `⟨v, Q_∞ v⟩ = W_{0,2}(F_v) − W_ℝ(F_v) − W_p(F_v)`.

> **Полезно нам:** это независимая проверка того, что три источника CCM (`W_{0,2}`, `W_p`,
> `W_ℝ`) собираются именно так, как донесла разведка — с явными формулами и с
> идентификацией полюсного блока «verbatim» из CCM Lemma 4.1.

## 2. Второй результат — порядок архимедова хвоста (Theorem 3.2, Corollary 3.3)

**Theorem 3.2:** за галёркинской полосой опущенный хвост есть **ранг-два плотностной
Коши–Стилтьесовский Грам-инкремент**: для `T₂ > T₁ > max(ρN, 7)` матричный инкремент

```
Q_arch,T₂ − Q_arch,T₁   положительно определён и строго тотально положителен
```

**Corollary 3.3 — двустороннее правило решения с явным бюджетом:**

```
λ_j(Q_T^tot) < λ_j(Q_∞) ≤ λ_j(Q_T^tot) + B_T

B_T = ((2N+1)ρ)/(π²T) · (log(T/2π) + 1)·(1 + o(1))
```

Правило сертификации:

| Что видим на конечном `T` | Что сертифицировано |
|---|---|
| положительность | **катофф-свободная положительность** |
| собственное значение ниже `−B_T` | катофф-свободный негатив |
| собственное значение в `[−B_T, 0)` | **ничего** |

`B_T` убывает лишь как `log T / T`: каждое удвоение `T` покупает около одного двоичного
разряда. Глубокие спектральные масштабы брутфорсом недостижимы — правильный конечный
инструмент на глубине есть **катофф-свободная сборка**.

Числовая иллюстрация автора: масштаб `10^{−59}` при `c = 100` потребовал бы `T ≈ 8·10^{62}`;
катофф-свободная интервальная `LDL^T`-факторизация той же матрицы сертифицирует `n₋ = 0`
напрямую.

## 3. Что это даёт нам конкретно

**Кирпич, который нам нужен, но не тот, за которым шли.**

Первое неравенство `λ_j(Q_T^tot) < λ_j(Q_∞)` означает: **положительность на конечном `T`
переносится на бесконечный `T` бесплатно**, потому что опущенный хвост тотально положителен
и может только поднять спектр.

Практическое следствие для хода 1 (сертификат на матрицах формы Вейля): при реальном счёте
интеграл в архимедовом члене придётся обрезать. Без этой теоремы наш сертификат `M ⪰ 0` был
бы утверждением о матрице с обрезанным интегралом и **не переносился бы даже на `Q_∞` при
том же `N`**. Теперь переносится, с явным бюджетом.

**Из двух бесконечностей одна закрыта.** Осталась наша: равномерность по `N`.

**Плюс машинерия совпадает:** интервальная `LDL^T`-факторизация — ровно тот класс проверок,
что у нас в `PSD_PenaltyCertificate.lean` (23×23 rational SOS/LDL receiver) и
`PSD_CenteredCoeffPenaltyLDLImport.lean` (точные рациональные LDL-сертификаты). Его пакет —
Arb-интервалы; наш музейный слой — точные рациональные тождества, что строже.

### 6.1 Lemma 2.3 (finite source calculus) — это ровно наше «одна мера»

Не отмечена в разделах 1–5. А она несущая. Для `psi_{alpha,omega}(x) = (alpha/pi) sin(2 pi omega x)`
дивайдед-дифференс матрица даёт `<v, Q_{alpha,omega} v> = alpha K_v(omega)`. Следовательно
для КОНЕЧНОЙ ЗНАКОПЕРЕМЕННОЙ борелевской меры `mu` на `[0,1]` и источника
`psi_mu(x) = (1/pi) integral sin(2 pi omega x) d mu(omega)`:

    <v, Q_mu v> = integral_{[0,1]} K_v(omega) d mu(omega).

И три его источника (уравнения 1–3 статьи) все имеют ровно эту форму, на ОДНОЙ
переменной `omega = 1 - y/L`: прайм даёт атомы `-Lambda(q)/sqrt q` в точках
`omega_q = 1 - log q / L`, полюс даёт плотность `2 cosh(y/2)`, архимед даёт
`h_+`-взвешенную плотность. То есть три леджера явной формулы суть ОДНА мера,
и это опубликовано в июле 2026.

### 6.3 Независимое подтверждение нашего знака и коэффициента

Его полюсный источник: `psi_0(n) = C_c n/(n^2 + beta^2)`, `beta = L/(4 pi)`,
`C_c = L(sqrt c + 1/sqrt c - 2)/(2 pi^2)`. Так как `sqrt c + 1/sqrt c - 2 = 4 sinh^2(L/4)`,
это `C_c = 2 L sinh^2(L/4)/pi^2` — ТОЖДЕСТВЕННО наш коэффициент из `2aaff3e7`.

Его прайм-источник в целом узле `x = n`: `sin(2 pi n (1 - log q/L)) = -sin(2 pi n log q/L)`,
поэтому `psi_p^{(c)}(n) = +(1/pi) sum Lambda(q)/sqrt q sin(2 pi n log q / L)` — ПЛЮС,
тот самый знак, который мы прочитали из исходника и выставили против вердикта
`ab96a4ba`. Два независимых маршрута согласны.

### 6.4 Свежий чужой инструмент под нашу открытую щель

Наша щель: модуль непрерывности `t -> <x_k(z), [S_t, H] q_k>` на `(0, 2 pi]`. В
КВАДРАТИЧНОМ случае эта функция есть в точности его ядро Вольтерра
`K_v(omega) = 2 (T_v * T_v)(omega)` — свёртка тригонометрических многочленов, целая по
`omega`, с регулярностью, наследуемой прямо от вектора коэффициентов. Это ровно тот
класс утверждения, которого просит наша щель, и он доказан месяц назад.

Две непроверенные ступени между ним и нами:
- **поляризация.** У нас смешанная пара, у него квадратичная вещественно-чётная форма.
  Кандидат `K_{x,q}(omega) = 2 integral_0^omega T_x(t) T_q(omega - t) dt`; он поляризует
  в доказательстве Cor. 2.4, но вещественно-чётная симметрия `u_{-k} = u_k` используется
  для сокращения мнимых частей, а наш `x_k(z) = C_k^{-1} kappa_k(z)` комплексный.
- **класс коэффициентов.** `T_x` есть тригонометрический многочлен только если `x`
  принадлежит его классу векторов. `x` — выход линейного решения; поставщика нет.
  Это та же дыра, что раздел 7 отчёта `5a02a6fd`: банк держит `x` только по норме.

### 6.5 Возможная атака на нашу проблему масс sqrt(m)

`5a02a6fd` показал: полюсный и прайм леджеры несут массы одного порядка `sqrt m`,
поэтому абсолютная мажоранта промахивается на степень `m`. Corollary 2.7 даёт явное
линейное подпространство размерности `N - s - 1`, на котором полюсный член
ТОЖДЕСТВЕННО НОЛЬ (численно `9e-41` против прайм и архимеда порядка единицы). Если
выбранную строку Ферреса можно посадить на эту гиперплоскость, одна из двух больших
масс исчезает и препятствие меняет форму. Условие — ОДНО линейное уравнение на
коэффициенты. Дёшево и проверяемо.

### 6.6 Что НЕ применимо

Полная положительность Theorem 3.2 касается архимедова хвоста ЗА ЧИСЛЕННЫМ КАТОФФОМ —
артефакта конечной квадратуры. У нас такого катоффа нет: архимедов леджер есть точный
интеграл по `Ioc 0 L`. Значит ни теорема о порядке хвоста, ни бюджет `B_T` к нам не
применяются. Записано, чтобы язык strict total positivity не был импортирован по аналогии.
