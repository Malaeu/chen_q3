(`mp.quad` на осциллирующем архимедовом хвосте `∫ h_+(τ) Re(S_hat) dτ`). Этот

## 2. Соответствие обозначений

- `m` = `lambda_sq` = `λ²` — оконный параметр (L = log m). Прошкино «c» = m.
- `N` — число мод; чётный блок имеет размерность `dim = N+1`.
- метрика/нормировка: чётный базис, l2-норма `c₀² + 2·Σ_{i=1..N} cᵢ²` (изометрия, см. edge_ledger_build.py docstring).
- пробник q — **чётный** (J-even проекция `(c_n + c_{−n})/2`, мнимая часть отброшена), unit-l2 в этой же норме.
- пробник q **не** берётся из собственного вектора решателя — это независимо построенный пролатный источник (k1/g04).

## 4. Направление невязки (чётность)

q — чётный, K — чётный блок, значит r = (K−aI)q целиком лежит в чётном
секторе. Нечётный сектор в невязке не участвует (низший нечётный уровень с
чётным запасом не конкурирует на этом пробнике). Принадлежность пробника
чётному сектору — по построению (J-even проекция), не предположение.

## 6. Вывод

1. **Пробник не плохой** — пролатный источник q сходится к нижнему состоянию
   ξ₀, но резко: при N=m (cofinal) e/Δ астрономичен, а как только N переваливает
   порог, e/Δ обваливается на 15–25 порядков (m=13: порог между 26 и 90;
   m=23: между 110 и 160) до ~10⁻⁹.
2. Для ячеек с достаточным N (m=13 N≥90, m=23 N≥160) выполнено
   **e/Δ ≪ 1/2**, значит **β(q) ≥ Δ − 2e > 0** — коэрцитивность от пролатного
   источника подтверждена численно, с интервальными границами.
3. Прошкин контрпример (m=2, произвольный симметричный вектор) этот путь не
   бьёт: он закрывает вывод из слишком широкого типа данных, а настоящий
   пролатный пробник сходится туда, куда нужно.
