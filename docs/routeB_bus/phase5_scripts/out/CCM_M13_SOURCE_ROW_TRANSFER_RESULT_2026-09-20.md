## Сделано

Перенёс существующий полный penalty-сертификат (13,120) с его вещественной
чётной строки `qhat` на **неизменённый исходный комплексный кэш** `q_cache`
по теореме (T):

    y*(K-aI)y >= (gamma - a - tau*D)||y||^2,   для всех y ⟂ q.

где a = q*Kq, D = 1 − |<qhat, q>|², gamma = 10⁻⁵⁶, tau = 1.

**Итог: L_transfer = gamma − U_a − U_D = 9.9433e-57 > 0** — перенос положителен,
исходная строка `q_cache` сертифицирует положительный запас на дополнении.

L_transfer = 9.9433e-57 > 0 (строго, с интервальным радиусом 3.3e-297).

Следовательно, для **неизменённого исходного комплексного кэша** `q_cache`
выполнено:

    ∀ y ⟂ q_cache :  y*(K − a I) y >= 9.9433e-57 · ||y||².

Источниковая строка `q_cache` даёт положительный запас на дополнении — без
нового спектрального прогона, чистым переносом готового сертификата.
