## 2. Точный объект и бюджеты

Для `m=257` использованы outward Arb-вилки коэффициентов мод 0 и 4 из 026.
Каждая вилка рационализована на 140 десятичных знаках. После этого вся
арифметика — точная `fmpq`: восстановление полиномов Лежандра, образование
`Psi`, суммы степеней и преобразование в базис Бернштейна.

```text
degree(Psi)      = 880
E_core           ≈ 4.9123136684362244e-142
epsilon_Psi      ≈ 6.670150442998024e-96
```

Центры коэффициентов нигде не считались точными: в верхнюю оценку добавлен
`E_core`. В целевой оценке отдельно вычтен полный бесконечный хвост
`r * epsilon_Psi`.

## 3. Зарегистрированный порядок

| `m` | `r` | точная полоса | `r*epsilon_Psi` | максимум верхних Bernstein-коэффициентов |
|---:|---:|:---|---:|---:|
| 257 | 256 | `[1/257,1/256]` | `1.7075585134074942e-93` | `−1.7061156407616692e-93` |
| 257 | 255 | `[1/256,1/255]` | `1.7008883629644962e-93` | `−1.6996780077417488e-93` |

На обеих полных полосах все коэффициенты Бернштейна верхней оценки
`P_center + E_core − r*epsilon_Psi` строго отрицательны. Fallback Штурма не
потребовался: основной exact-Bernstein backend дал решающий знак.

Более того, уже конечный core без вычитания хвоста строго отрицателен на
точном внутреннем интервале

```text
[65281/16711680, 32641/8355840] ⊂ (1/256,1/255).
```

Для `P_center + E_core` максимум всех 881 Bernstein-коэффициентов на этом
интервале не превосходит точной рациональной границы

```text
−1 / 10^97.
```

Следовательно, для этого `K` ложна достаточная оценка
`P_(r,K) >= r*epsilon_(Psi,K)`. Это не определяет знак
`S_lambda`: отброшенный хвост имеет неизвестный знак и его разрешённый бюджет
больше найденного finite-core провала. Зарегистрированное fixed-`K`
положительное предсказание опровергнуто.

## 4. Покрытие и нотариат

После точного fixed-`K` stop-свидетеля на втором приоритетном адресе исполнение
остальных полос и зубьев остановлено по контракту fail-fast. Полнота
положительного покрытия не заявляется.

`FINITE_CORE_THETA_CERT.json` хранит source hashes, рациональные coefficient
balls, полином степени 880, оба бюджета, точные Bernstein-экстремумы,
канонический инвентарь и fixed-`K` интервал. Независимый checker не импортирует
генератор и Arb: он заново собирает весь рациональный объект и проверяет
source hashes, cover, transform, экстремумы, оба бюджета и гварды.

```text
python finite_core_theta_certificate.py
python check_finite_core_theta_certificate.py
FINITE_CORE_THETA_CERT_CHECK_OK
```

Сетки знака не использованы; `mu := 1` не делалось. `STATE` не изменён,
Bus 010 не создан.
