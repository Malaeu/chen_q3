# Spectral-control hypothesis cards

DIAGNOSTIC_NEVER_A_PROOF.

HYPOTHESIS S1: Poisson < zeta approximately GUE < picket in the registered
median clearance. Mythos prior.5.
EVIDENCE: Poisson<GUE holds in75%,80%,85%,90% of the20paired models; GUE<picket
holds in60%,0%,0%,60%, below the registered75% requirement everywhere. The
registered full order is rejected. The real-zero zeta surrogate is inside the
GUE empirical95% band, but this does not identify the actual arithmetic source.
WHAT KILLS IT: these ordering failures already do. No favorable window,
ensemble normalization or selected replicate is substituted.
HANDOFF: spectral repulsion can affect finite clearance, but it does not
supply the claimed universal hierarchy. Tail/old-history limits must remain explicit.

HYPOTHESIS S2: the common-tail zeta surrogate calibrates the actual arithmetic
source to absolute.02 in primary median margin. Prior.5.
EVIDENCE: errors .002053,.003518,.020378,.033221; fine meshes fail. Numerical
FFT refinement errors are below5.2e-11 in that statistic, so the calibration
failure is not rescued by increasing FFT length. Synthetic cutoff400/800/1600
changes remain material for Poisson/GUE.
WHAT KILLS IT: the registered gate fails. Do not export the surviving model
trend to actual zeta or tune the cutoff to make this gate pass.
HANDOFF: a controlled discrete high-zero tail is needed. Mean zero density
and an accurate continuous-tail quadrature are insufficient calibration.

HYPOTHESIS S3: Poisson<GUE is not just a point-count fluctuation effect.
Equal-count robustness prior.8, first4registered replicates only.
EVIDENCE: after matching202points and gamma1, Poisson<GUE holds in3/4,4/4,
4/4,4/4 pairs. This supports a bounded model trend. It does not restore the
GUE<picket part, and the rescaling control is not an exact GUE conditioning.
WHAT KILLS IT: an adequately powered independent equal-count ensemble
reversing the comparison, or validated source/tail numerical error comparable
to the gap. Four controls do not establish universal statistical ordering.
HANDOFF: retain finite-future eigenstructure, spectral spacing and tail
information jointly; avoid reducing clearance to local mean density alone.

HYPOTHESIS S4: a finite zero-table cutoff can fake predictability/rank loss.
Prior.99 for a fine-grid unresolved positive prefix before t6.
EVIDENCE:202positive pairs have rank<=404; no-tail float controls resolve only
354,275,24prefixes on meshes64,128,256. Adding the common positive tail removes
these numerical failures. This is a normalization/conditioning discriminator.
WHAT KILLS IT: treating those failures as genuine negative PSD worlds; the
code instead labels them unresolved and never clips a pivot or eigenvalue.
HANDOFF: finite zero truncation cannot stand in for the full positive source
when old/fresh resolution is increased. No claim about actual zeta zero
location or an arithmetic positive-kernel extension follows.
