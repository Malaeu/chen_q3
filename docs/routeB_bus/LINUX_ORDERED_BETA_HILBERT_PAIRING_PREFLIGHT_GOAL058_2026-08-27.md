# ORDERED-β HILBERT PAIRING — preflight

## 1. Полное разложение, включая диагональ (пункт 1 директивы)

С диска, `n = m` ветвь ядра даёт `Q(L,n,n,x) = 2(L−x)/L·cos(2πnx/L)`, откуда

    a_n := τ(n,n)
         = 32L·sinh²(L/4)·(L² − 16π²n²)/(L² + 16π²n²)²        [W02]
           − [ (γ + log(4π·(e^L−1)/(e^L+1)))
               + ∫_0^L WRIntegrand(L,n,n,x) dx ]               [arch]
           − Σ_{2≤k≤M} (Λ(k)/√k)·2(L−log k)/L·cos(2πn·log k/L)  [prime]

**Наблюдение о чётности, подтверждающее твою атаку.** Диагональ есть
КОСИНУС-поле по `n` (чётное), а `β` есть СИНУС-поле по `n` (нечётное).
Значит `β` действительно reflection-odd по построению, и нулевая сумма
веса против чётного основного направления получается структурно. Твоё
возражение принимается как верное: нулевая масса сама по себе — калибровка.
Ниже — что остаётся ПОСЛЕ этого признания.

## 2. Абелево тождество для веса нулевой массы (пункт 2)

Упорядочим моды по возрастанию `n_i`. Префиксы `W_i := Σ_{j ≤ i} w_j`,
`w_j = v_j (H v)_j`, и `W_last = 0` по доказанной нулевой массе. Тогда

    Σ_i β_i w_i = − Σ_i (β_{i+1} − β_i) · W_i .

То есть в потребитель входит не `β`, а её **разности первого порядка**.

## 3. ПЕРВЫЙ ТВЁРДЫЙ ФАКТ: префикс есть поток через разрез (пункт 3)

    W_i = Σ_{j ≤ i} Σ_{l ≠ j} v_j v_l/(n_j − n_l) .

Пары, у которых ОБА индекса ≤ i, сокращаются попарно по антисимметрии
`H`. Остаются только пары через разрез:

    W_i = Σ_{j ≤ i} Σ_{l > i} v_j v_l / (n_j − n_l) ,

и все знаменатели одного знака. Префикс — не абстрактная частичная сумма,
а **поток Гильберта через разрез между `i` и `i+1`**.

## 4. ВТОРОЙ ТВЁРДЫЙ ФАКТ: префиксы ограничены РАВНОМЕРНО

На нашей решётке `n_j = j − N`, поэтому `n_l − n_j = l − j`. Замена
`j′ = i − j ≥ 0`, `l′ = l − i − 1 ≥ 0` даёт знаменатель `j′ + l′ + 1`.
С `p = j′+1`, `q = l′+1` имеем `j′+l′+1 = p+q−1` и, поскольку `p+q ≥ 2`,

    1/(p+q−1) ≤ 2/(p+q) .

Классическое неравенство Гильберта `Σ_{p,q≥1} a_p b_q/(p+q) ≤ π‖a‖₂‖b‖₂`
(константа точная) даёт тогда

    |W_i| ≤ 2π·‖v‖₂²   для КАЖДОГО разреза `i`, равномерно по `N`.

Для единичного `v`: `|W_i| ≤ 2π`. **Размер задачи в оценку не входит.**
Значит вес не просто имеет нулевую сумму — он равномерно сбалансирован по
всем разрезам, и это уже не калибровочная тривиальность.

## 5. Точная downstream-цель (пункты 4–5)

Потребитель — то же спаривание, что в консюмере трекинга; требуемая
асимптотика по прежнему леджеру: вклад должен быть `o(m^{−σ/2}/√log m)`
на компакте, `o(1/√log m)` на вещественной оси.

Из §2 и §4 немедленно:

    |Σ_i β_i w_i| ≤ 2π·‖v‖₂²·Σ_i |β_{i+1} − β_i| .

## 6. Source-faithful разностная формула для β (пункт 6)

    β_{n+1} − β_n = Σ_{2≤k≤M} (Λ(k)/√k)·2·sin(θ_k/2)·cos((n + 1/2)·θ_k) ,
    θ_k = 2π·log k / L ,

плюс гладкие разности `W02`- и архимедовой частей (рациональная и
Фурье-коэффициентная, обе с быстрым убыванием).

**Дополнительный множитель `sin(θ_k/2) = sin(π·log k/L)` гасит оба края:**
малые `k` (там `log k/L → 0`) и `k` вблизи `M` (там `log k/L → 1`).
Максимум при `k ≈ √M`. Абелево суммирование по `k` даёт

    Σ_k (Λ(k)/√k)·|sin(π log k/L)| ≍ 4π·√M / log M ,

то есть **выигрыш ровно логарифмический** против `Σ_k Λ(k)/√k ≍ 2√M`.

## 7. Где встаёт (пункт 7, честно)

Полная вариация: каждая разность `β_{n+1} − β_n` есть осциллирующая сумма
со среднеквадратичным масштабом `≍ log M` (Мертенс с весом `sin²`), а
разностей `2N ≍ 2M` штук. Тривиально `Σ_i |Δβ_i| ≍ M·log M`, и оценка §5
даёт `≍ M log M` — на много порядков выше цели.

Выигрыш возможен только если использовать **знаки** `W_i` против знаков
`Δβ_i`, а не модули. Но `W_i` зависит от `v`, а `Δβ_i` — от арифметики,
и никакой согласованности между ними у нас пока не выведено.

**Дискриминатор:** `HOLD` —
`ZERO_MASS_AND_ABEL_REPRESENTATION_WITHOUT_CONSUMER_RATE`.
Твой прогноз `P_HILBERT_PAIRING_1` (0.70) подтверждён.

Не `FAIL`: представление не оказалось калибровочным переписыванием —
§4 даёт равномерную по размеру оценку потоков, которой раньше не было, и
она не выводится из нулевой массы (нулевая сумма не запрещает префиксам
расти).

## 8. Что теперь точная щель

    Σ_i (Δβ)_i · W_i   при   |W_i| ≤ 2π равномерно.

То есть: **полная вариация упорядоченной завершённой `β` против
равномерно ограниченного потока.** Это уже не «оцените β» и не «оцените
норму»: это одномерная задача о знакопеременной сумме разностей против
ограниченной последовательности. Ближайший классический аппарат —
оценки типа BMO/Карлесона для дискретного оператора Гильберта, то есть
твой R2, который ты и держал как runner-up.
