## 1. Что проверено вручную и держит

### 1.1. Мост `curvature → normality`

Пусть `G` — чётная целая функция порядка не выше `1`, вещественная на вещественной оси, все её нули вещественны и `G(0) = 1`.

По факторизации Адамара нули идут парами `±ρ`, и функция имеет произведение

```text
G(z) = ∏_ρ (1 - z² / ρ²).
```

Тогда

```text
κ := -G''(0) / 2 = Σ_ρ 1 / ρ²,
```

а для любого `z ∈ ℂ`

```text
|G(z)|
  ≤ ∏_ρ (1 + |z|² / ρ²)
  ≤ exp(κ |z|²).
```

Следовательно, равномерная оценка `κ_m ≤ C` для нормированных конечных трансформов `G_m = F_m / F_m(0)` даёт локальную равномерную ограниченность семейства на всей плоскости, в частности в критической полосе.

**Verdict:** мост настоящий; множитель `1/2` в

```text
κ_m = -G_m''(0) / 2
```

верный. Это стандартный механизм класса **Laguerre–Pólya**.

### 1.2. Формула второй производной ядра

Для

```text
K_n(z) = 2 sin(zL/2) / (z - x_n),
x_n = 2πn/L,
```

символьная проверка даёт

```text
K_n''(0) = -2L / x_n²        для n ≠ 0,
K_0''(0) = -L³ / 12.
```

Для нормированного функционала коэффициентная квадрат-норма складывается как

```text
1/144 + 1/180 = 1/80.
```

**Verdict:** формула `secondDerivative_zero` и константа `1/80` согласованы.

### 1.3. Принудительные нули вне усечения

Принудительные нули за пределами `|n| ≤ N` дают вклад порядка

```text
κ_m^forced ≍ L² / (4π²N).
```

На уже используемом пути

```text
m = N = k + 2,
L = log m,
```

имеем

```text
L² / N = (log m)² / m → 0.
```

**Verdict:** ради подавления принудительной части новый кофинальный путь не нужен. Ранее предложенное дополнительное условие `N / L² → ∞` уже автоматически выполняется на действующем пути.

### 1.4. Верхняя аналитическая цепь

Связка

```text

        +
сходимость на множестве с точкой сгущения
        ↓
Vitali
        ↓
локально-равномерная сходимость к centeredXi
        ↓
```

**Verdict:** верхняя `Vitali → real-zero limit → RH consumer`-крыша не является текущей стеной. Стена находится в количественных suppliers снизу.

## 2. Где свежие числа ломают план через абсолютную щель

Количественный Ritz-путь Прошки использует

```text
r_k = ‖Residual_k‖² / β_k²,
```

где `β_k` — абсолютный spectral floor на ортогональном дополнении, фактически масштаба

```text
β_k ≈ λ₂,k - λ₁,k.
```

Согласно текущему ledger, масштаб `λ₂` падает примерно так:

| `m` | масштаб `λ₂` |
|---:|---:|
| 13 | `1e-25` |
| 23 | `1e-45` |
| 43 | `1e-84` |
| 83 | `1e-154` |

При таком абсолютном поле условие

```text
r_k → 0
```

требует, чтобы prolate-trial попадал в ground-вектор с точностью порядка десятков и затем сотен десятичных знаков.

Отсюда:

1. запасной критерий Прошки

   ```text
   B_k = |A_k| L_k^(5/2) √r_k = O(1)
   ```

   при абсолютном `β_k` практически мёртв;

2. вход A через

   ```text
   A_k √L_k √r_k → 0
   ```

   страдает от той же абсолютной сверхточности;

3. ранее оценённый exponent `p = 0.38` необходимо пересчитать; по текущим числам он должен быть существенно ближе к нулю.

**Verdict:** нельзя продолжать quantitative proof через абсолютную оценку `Residual / (λ₂ - λ₁)` как основной supplier.

## 3. Что открывает относительная щель

При этом относительное отношение растёт:

| шаг | `λ₂ / λ₁` |
|---:|---:|
| 1 | `3.6e5` |
| 2 | `1.7e6` |
| 3 | `7.5e6` |
| 4 | `3.9e7` |

Для нормированного trial-вектора относительная Ritz-оценка имеет форму

```text
1 - |d_k|²
  ≤ ε_k / (λ₂,k / λ₁,k - 1),
```

где

```text
ε_k = Rayleigh(trial_k) / λ₁,k - 1
```

— **относительный избыток Рэлея**, а `d_k` — overlap trial-вектора с ground-вектором.

Это меняет характер стены:

- абсолютная схема требует сверхмалого residual относительно исчезающей абсолютной щели;
- относительная схема требует мультипликативно точной оценки коэффициента Рэлея;
- растущее `λ₂/λ₁` работает в нашу пользу, если `ε_k` остаётся контролируемым.

**Новый exact consumer:** доказать достаточно сильную оценку для `ε_k`, а не абсолютную оценку residual через `λ₂ - λ₁`.

## 4. Независимый скалярный путь к нормальности

Прямой curvature supplier

```text
κ_m = -G_m''(0) / 2
```

не зависит от spectral gap вообще.

Поэтому две количественные ветки следует разделить:

```text
Ветка A — sample / ground alignment
    relative Rayleigh excess ε_k
    + growing relative gap λ₂/λ₁
    → overlap / coordinate control

Ветка B — normality
    direct scalar formula for κ_m
    → bounded curvature
    → local boundedness
```

Нельзя снова искусственно связывать обе ветки одним абсолютным `r_k`, если прямой скалярный consumer для `κ_m` обходится без него.

## 6. Decision tree после появления данных

### Case 1 — `κ_m` ограничена

Тогда основной путь:

```text
exact secondDerivative_zero
        ↓
direct bound for κ_m
        ↓
curvature → normality
        ↓
Vitali
        ↓
rh_of_real_zero_family_tendsto_centeredXi
```

Приоритет получает **прямой скалярный proof**, а не глобальный `HumpMassBound` и не absolute-gap fallback.

### Case 2 — растёт только `κ_m^forced`

Проверить индексацию и фактическое отношение `L²/N`. На действующем пути эта часть должна уходить в ноль.

### Case 3 — растёт intrinsic part `κ_m - κ_m^forced`

Тогда curvature-normality route получает отрицательный сигнал. Нужно локализовать вклад внутренних нулей / ground-коэффициентов до формализации тяжёлых новых лемм.

### Case 4 — `κ_m` хороша, но relative Ritz плох

Normality-ветка остаётся живой, а Input A требует другого supplier или прямой асимптотики координат.

### Case 5 — relative Rayleigh excess контролируется

Формализовать относительную Ritz-оценку и использовать растущее `λ₂/λ₁` для sample convergence / ground alignment.
