## 1. Явные `K`, `G`, `J` — связка стоит на входе, три риска сняты

### 1.1 `G = I`

Их базис: `V_n(u) = U_n(log(λu))`, где `U_n(x) = L^{−1/2}·exp(2πinx/L)`, `L = 2 log λ` —
ортонормированный базис `L²([0,L])`. Из ортонормированности **матрица Грама единичная**.

Пенсил вырождается в обычную задачу `Kx = λx`; гипотеза `hG : G.PosDef` нашего инструмента
выполняется тривиально.

> **ПРОВЕРЕНО ДИСКОМ.** У нас то же самое: `V_n_m_orthonormal`
> (`D0LogWindowMeasureTransport.lean:213`) доказывает `Orthonormal ℂ (V_n_m i)`. Значит
> `G = I` и в нашей системе координат — инструмент применяется в упрощённой форме.

### 1.2 Транспорт — их `κ` есть наш транспорт

Их изометрия `κ`: `x = log(λu)`.

> **ПРОВЕРЕНО ДИСКОМ.** Наш `integral_comp_logWindow_dStar`
> (`D0LogWindowMeasureTransport.lean:94`) — `Real.log (lambda_m i * u)`. Символ в символ.
>
> И длины сходятся: их `L = 2 log λ`, наш `L_m i = log m`; при `λ = √m` это одно и то же.
> Подтверждает соответствие переменных **их `λ²` = наш `m`**, выведенное 2026-08-06 из
> определения окна `I_m = [m^{−1/2}, m^{1/2}]`.

### 1.3 `K = τ` — вещественная симметричная, три явные компоненты

Вид: `τ_{i,i} = a_i`, `τ_{i,j} = (b_i − b_j)/(i − j)`, с `a_{−j} = a_j`, `b_{−j} = −b_j`.

| Компонента | Что это |
|---|---|
| `W_{0,2}` | **ранг-2**, замкнутая формула (их 4.2) |
| `W_p` | конечная сумма `Λ(k)·k^{−1/2}·q(U_n,U_m)(log k)` по `k ≤ λ²` |
| `W_ℝ` | таблица через три интеграла `α_L, β_L, γ_L` — ₂F₁, дигамма, Гурвиц–Лерх; параметр `e^{−2L}` даёт быструю численную сходимость |

### 1.4 `J = γ` — инволюция, коммутирующая с `K`, ДОКАЗАНО у них

`γ(V_j) = V_{−j}`, `γ² = id`, `Tγ = γT` — их **Lemma 5.2**.

**Это снимает конкретный риск, названный в пакете R3.** Чётность `u ↦ u⁻¹` реализована
именно как матричная инволюция, коммутирующая с `K`; при `G = I` условие `JᴴGJ = G`
тривиально. Пробник чётен: `h_λ` — комбинация `h_{0,λ}` и `h_{4,λ}`, обе чётные, значит
`hJq` выполняется.

Бонус: их **Definition 5.3 «even-simple»** — дословно вывод нашего инструмента. Коммутатор
`[D,T] = |β⟩⟨η| − |η⟩⟨β|` имеет **ранг 2** — та самая CF/Toeplitz-структура из
Конна–ван Сёйлекома, гарантирующая нужную самосопряжённость.

**Итог: ход 1 ставится.** Три фальсификатора из пакета R3 — `(K,G)`-форма, чётность,
эрмитовость усечения — сняты по оригиналу.

## 2. Узел 1 (перенос) — подтверждён, и половинка настоящая

В статье есть всё нужное: `E` — кор для формы, спектр `A_λ` дискретен и ограничен снизу,
нижняя грань `QW_λ` есть предел при `N→∞` наименьшего собственного значения сужения на `E_N`.

**Это отвечает на M4 положительно** — форм-керн есть, перенос по плотности запускается.

Но следствие мин-макса на вложенных `E_N` жёсткое и совпадает с нашим зумом: **все**
`λ_k^{(N)}` убывают к `λ_k`, поэтому секционный сертификат даёт неравенство **в другую
сторону**. Бесплатного переноса щели вниз не существует.

Механизм переноса один, и он тот же, что в зуме
(`ZOOM_2026-08-07_GAP_TRANSFER_THROUGH_GALERKIN.md`): сертификат **на уровне оператора** =
конечный блок `E_N` (наша матричная проверка с запасом) + доминирование связок блок↔хвост +
хвостовая коэрцитивность. Хвост живёт на архимедовой диагонали `~log|n|`, арифметика
ограничена, `W_{0,2}` ранг-2 — это прямо из их доказательства дискретности.

**Половинка = равномерное по `N` хвост/связка-доминирование.** Наши `056s` (weighted tails)
и `056t` (complement-Parseval) — заготовка ровно под это.

Опубликованные мосты нижних оценок из конечных данных: Temple–Kato, Lehmann–Goerisch,
Zimmermann–Mertins.

**Свежий подарок:** Groskin, июль 2026 — «archimedean tail order for the truncated Weil
quadratic form», два точных конечных результата о том же усечении. Возможно, кусок нашей
половинки уже опубликован. В очереди на чтение.

## 3. Порог `½` — найден дословно, их Lemma 7.3

Фурье-образ `k_λ` сходится к `Ξ` равномерно на замкнутых подполосах **открытой** полосы
`|ℑz| < ½`; в доказательстве ошибка `O(λ^{−½−α})` при `α = ℜs ∈ (−½, ½)`.

`½` — полуширина критической полосы в нормировке `Δ^{1/2}`; у края скорость умирает как
`(1−2α)^{−1}`. Отсюда контрактное `∀η < ½`: не мистика, а требование накрыть **всю** полосу.

## 4. Переворот по `P-Δ` — главная новость разведки

Статья сама даёт **масштаб числителя**: крошечные `ε_λ` формы Вейля совпадают по поведению
с невязкой `1 − χ(λ)`, а по Фуксу

```
1 − χ(λ) ~ (2¹⁴/(3√2))·π⁵·e^{−4πλ² + 9 log λ}
```

то есть класс **`e^{−4πλ²}`** — гауссово-экспоненциальный.

Независимо перепроверено: **Groskin, май–июнь 2026** — первая независимая публичная
реализация галёркинской матрицы на 16 катоффах, `dps=500`. Наименьшее чёт-секторное
собственное значение экстраполируется Эйткеном к `log₁₀ ≈ −534…−537`, монотонно приближаясь
к эвристике Конна 2026 §6.4 (`≈ −530.4`); первые десять `γ_k` восстановлены до 307–329
знаков.

### Следствие для развилки — ставку надо расщепить натрое

**«Щель суперполиномиально мала» само по себе НЕ убивает вход B.** Дробь умирает только
если `Δ_λ` падает **сопоставимо** с `e^{−cλ²}`.

| Сценарий | Судьба B |
|---|---|
| `Δ_λ` полиномиальна | **жив**, открывается конвейер сертификатов |
| суперполиномиальна, но медленнее гауссианы | **всё ещё жив** |
| гауссова, порядка числителя | решает константа, мир жёсткий |

**Это меняет спецификацию пробы:** мерить не «мала ли щель», а **наклон `log Δ` по `λ²`**.
После сегодняшнего это единственное число, разрешающее развилку целиком.

мост опубликован, 1970) < резольвентно-контурный Като < новый мост.

## 7. Живые фальсификаторы связки — что осталось после разведки

Три сняты (см. §1.4). Живыми остаются три, названные самим каналом:

**(α) Индексный кросс-волк.** Их `V_n` — **одиночный** индекс, наш `V_n_m` — **двойной**
(`i : PairIndex` = пара `(m, N)`). Семейства не байт-идентичны; привязку надо предъявить.

> **Комментарий с нашей стороны.** Соответствие правдоподобно и проверяемо:
> их `λ = √m`, их `L = 2 log λ = log m = L_m i`, их `N` = наш `i.N` (число мод,
> `modeSet i = Icc (−N) N`). То есть их одиночный параметр `λ` есть наш `m`, а второй наш
> индекс `N` у них тоже присутствует как размер усечения. Расхождение может оказаться
> чисто нотационным — но **предъявить обязаны мы**, это наша сторона моста.

**(β) Нормировка.** Их `ξ` нормирован условием `δ_N(ξ) = 1`, **не** `G`-нормой.
Конструкция `q` для сертификата обязана выбрать одну и не смешивать.

> **Комментарий.** При `G = I` `G`-норма есть обычная `L²`-норма, так что смешение здесь
> особенно легко не заметить. Гипотеза `hq : star q ⬝ᵥ (G *ᵥ q) = 1` нашего инструмента
> требует именно `G`-нормировки.

**(γ) Половинка узла 1** — секционный сертификат без равномерного хвоста не является входом
ни A, ни B. **Это главный содержательный риск связки после разведки.**
