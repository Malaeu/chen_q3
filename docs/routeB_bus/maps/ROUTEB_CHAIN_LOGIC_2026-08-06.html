ВХОД A · открыто
просто + чётно при ВСЕХ λ
dim E_min(QW_λ)=1, ξ_λ чётен
есть: Судзуки Thm 1.4 — только малые окна (до λ²=2), через positivity improving. Дальше — каждый простой бьёт по знаку ядра. Удар 2.
ВХОД B · открыто
пролатная догадка ≈ арифм. вектор
‖k_λ − c_λ·ξ_λ‖ = o(λ^(−η)) ∀η<½
quasimode ‖r‖/Δ; зазор Δ_λ — целина. Риск: кластерное дно (P-Δ, p≈0.6) → цель переформулируется, не умирает. Удар 1 = зонд.
ВХОД C · открыто · НАШ

(ε_N, ξ_N) → (ε_λ, ξ_λ)

A ∧ B ∧ C
мост 1 · доказано
конечная вещественность — даром
самосопряжённость ⇒ спектр вещественный: CCM Thm 1.1 (нужно A на усечении) ЛИБО Судзуки Thm 1.5 — безусловно, при всех a. Нули ξ̂_{N,λ} лежат на прямой.
узел-следствие · включается входами
ξ̂_{N,λ} → Ξ локально равномерно, |Im z| < ½
B даёт k̂_λ→Ξ уже ДОКАЗАННО (hermfact1, O(λ^(−½−α))); A+B пересаживают это на ξ̂_λ; C поднимает с усечения на окно. Ровно здесь тратятся все три входа.
мост 2 · доказано
Гурвиц + свободные от нулей края
нули равномерного предела ⊂ замыкание нулей приближений (Гурвиц); границы полосы Re s = 0, 1 без нулей (Адамар–де ла Валле Пуссен) ⇒ подполос |Im z|<½ достаточно.
мост 3 · доказано (классика)
Ξ с вещественными нулями ⟺ RH
Ξ(z) = ξ(½ + iz); вещественность нулей Ξ = все нетривиальные нули ζ на критической прямой.

ловушки R1 · где входы обязаны быть сформулированы точно
  • порядок пределов N→∞ и λ→∞ — нужна ли равномерность по N;
  • чётность u↦u⁻¹ против нашей центрированной координаты (транспорт 056l);
  • цена веса λ^η — темп o(λ^(−η)) обязателен, «просто →0» не включает Гурвица;
  • кластерное дно (~2λ² почти вырожденных) — цель B переопределяется;
  • пороги простых в A — бесконечная лестница, двойка лишь первая ступень.
