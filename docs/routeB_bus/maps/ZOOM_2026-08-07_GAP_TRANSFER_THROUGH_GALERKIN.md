# ЗУМ — перенос щели через Галёркин: переносится не щель, а сертификат

**Пин:** `cfcda463` · Route B = **CHALLENGER / NOT_RH** · RH не заявляется.
**Родительский узел:** вход C цепи `A ∧ B ∧ C ⇒ RH`
(`maps/ROUTEB_CHAIN_LOGIC_2026-08-06.html`, Мифос).
**Инструмент:** `q3.lean.aristotle/Q3/Proofs/RouteB/H2aPenaltyCoercivity.lean:395`.
**Развилка:** `maps/ROUTEB_FORK_2026-08-07_THE_GAP.md`.

Зум запрошен владельцем 2026-08-07 после того, как формулировка «пол доносится до
оператора через вход C» дважды прошла по каналу как следствие. Она не следствие.

---

## 1. Постановка

Инструмент даёт на каждом усечении сертифицированный пол щели:

```
сертификат на E_N  ⟹  λ₂^(N) − λ₁^(N) ≥ β_N − a_N
```

Нужен пол для **оператора** `QW_λ`, иначе знаменатель входа B не накормлен.

## 2. Почему прямой перенос невозможен

Галёркин работает по Куранту–Фишеру. Ограничение на подпространство `E_N` убирает
кандидатов из минимума, поэтому

```
λ_k^(N) ≥ λ_k   ∀k, N          λ_k^(N) ↓ λ_k  при E_N ↗ H
```

**Все галёркинские собственные значения — оценки сверху.** Для щели нужны
разнонаправленные: верхняя на `λ₁` и **нижняя** на `λ₂`. Первую Галёркин даёт даром,
вторую **не даёт вообще**.

Отсюда прямо:

> `λ₂^(N) − λ₁^(N) ≥ c` **не влечёт** `λ₂ − λ₁ ≥ c`.

Истинное `λ₂` может лежать сколь угодно ниже секционного. Хуже: оператор может иметь
собственное значение между `λ₁` и `λ₂`, которое усечение при данном `N` не разрешает —
секционная щель широкая, операторная схлопнута.

Нижние оценки собственных значений — отдельная классическая трудность (Леманн–Мэйли–Гёриш),
и они требуют априорной информации о следующем собственном значении, которой у нас нет.
Это тот самый bootstrap, из-за которого нижние оценки всегда дороже верхних.

**Вывод: формулировка «пол доносится через вход C» в буквальном прочтении неверна.**

## 3. Что переносится на самом деле

Сертификат — **не** утверждение о числах. Это неравенство для формы:

```
K − βG + τ(Gq)(Gq)* ⪰ 0
   ⟺   ∀v ∈ E_N :  Q(v) − β‖v‖²_G + τ|⟨Gq, v⟩|² ≥ 0
```

**Неравенства для форм переносятся по плотности. Собственные значения — нет.**
Вся разница здесь.

Пусть сертификат выполняется на каждом `E_N` с **одними и теми же** `β, τ, q` (пробник
фиксирован в некотором `E_{N₀}` и дальше живёт во всех). Тогда неравенство верно на
`⋃ E_N`; если это форм-керн замкнутой формы — то на всей её области определения.
То есть **для оператора**.

## 4. И тогда щель получается в одну строку

На подпространстве `⟨Gq, v⟩ = 0` — коразмерности один — имеем `Q(v) ≥ β‖v‖²`.

Min-max для `λ₂`: минимум по **двумерным** подпространствам от максимума отношения Рэлея.
Любое двумерное подпространство пересекает подпространство коразмерности один нетривиально,
значит на нём максимум `≥ β`. Следовательно

```
λ₂ ≥ β
```

Пробник даёт `λ₁ ≤ a < β`. Итого **для оператора**:

```
λ₂ − λ₁ ≥ β − a
```

## 5. Что это меняет практически

### 5.1 Требование формулируется иначе

Не «щель секции не должна схлопываться», а **`β` не должно зависеть от `N`**.

Это другое условие и проверяется по-другому: гнать сетку по `N` при **фиксированной** `λ`
и смотреть на максимальное допустимое `β_N`. Стабилизируется — перенос состоялся.
`β_N ↓ a` — не состоялся, и это видно сразу.

### 5.2 Это дешевле, чем казалось

Не нужна теория нижних оценок собственных значений. Не нужен Леманн–Гёриш. Не нужна
равномерность сходимости спектра. Нужна одна вещь: **константа в неравенстве, не
зависящая от размерности**.

### 5.3 Это меняет вопрос к Δ-пробе

Проба 057.2 меряет `λ₂^(N) − λ₁^(N)` — **секционную** щель. Она полезна как индикатор,
но развилку решает **не она**. Решает поведение `β_N` при росте `N` на фиксированной `λ`.
Это отдельный прогон, и его стоит поставить рядом с 057.2, а не вместо.

Заметим и обратное: если `β_N` стабилизируется, а секционная щель при этом схлопывается —
противоречия нет, потому что `β` — нижняя оценка, а не сама щель. Пол может держаться,
пока измеряемая величина проседает по другим причинам.

## 6. Честные границы этого зума

**Проверено:** алгебра Куранта–Фишера и переплетения. Элементарна и верна.

**Не проверено:** замкнута ли форма Вейля на нужной области и является ли `⋃ E_N` её
форм-керном. Без этого перенос по плотности не запускается. У Конна `E_N` — линейная
оболочка нижних собственных функций оператора масштабирования; правдоподобно, что керн,
но это надо **предъявить, а не предположить**. Пока не предъявлено — весь раздел 3
условен.

**Поточечность не отменяется.** Сертификат по-прежнему даёт `Δ_λ ≥ β(λ) − a(λ)` для
**одной** `λ`. «Для всех `λ`» из входа A — по-прежнему через интервальность по `λ` или
возврат в аналитику.

**Наша теорема конечномерна.** Выкладка §4 показывает, что вывод переносится, но
бесконечномерную версию — `Q(v) ≥ β‖v‖²` на коразмерности один ⟹ `λ₂ ≥ β` — в Lean надо
писать отдельно. Это лемма уровня Mathlib о min-max, не исследование.

## 7. Что из этого следует поставить

1. **Прогон `β_N` при фиксированной `λ`** — новый, рядом с 057.2. Дискриминатор переноса.
2. **Предъявить, что `⋃ E_N` — форм-керн.** Без этого §3 висит. Вопрос к Мифосу: сказано
   ли это у Конна явно.
3. **Lean-лемма min-max** для бесконечномерного шага, если прогон 1 даст зелёный.
