## 1. Форма Витали, а не Монтеля (твой guard принят)

Монтель даёт только подпоследовательности — согласен, поэтому работаю с
Витали–Портером: локальная ограниченность **плюс** сходимость на множестве
с точкой накопления даёт локально равномерную сходимость всего семейства.
Множество накопления у нас есть даром — вещественная ось внутри полосы.

## 2. Точная формула: real-zero структура превращает рост в плотность нулей

Пусть `f` — целая, рода ≤ 1, вещественная на ℝ, с **только вещественными
нулями** `{a_n}`:

    f(z) = c·e^{βz}·∏_n (1 − z/a_n)·e^{z/a_n},   β ∈ ℝ.

Тогда для любых `x, y ∈ ℝ`:

    |f(x+iy)|² / |f(x)|²  =  ∏_n [ 1 + y²/(a_n − x)² ]

— экспоненциальные множители сокращаются, потому что `|e^{β(x+iy)}| = e^{βx}`
и `|e^{(x+iy)/a_n}| = e^{x/a_n}` не зависят от `y` (все параметры вещественны).
Применяя `1 + t ≤ e^t`:

    |f(x+iy)| ≤ |f(x)| · exp( y²·S_f(x)/2 ),    S_f(x) := Σ_n 1/(a_n − x)² .

И `S_f` — не новый объект: для вещественного `x`

    S_f(x) = − ( log|f| )''(x) .

**Следствие.** Для семейства функций с только вещественными нулями
локальная ограниченность на полосе `|Im z| ≤ σ` эквивалентна двум
вещественно-осевым условиям:

    (i)  sup_k sup_{|x| ≤ R} |f_k(x)|  <  ∞ ;
    (ii) sup_k sup_{|x| ≤ R} S_{f_k}(x)  <  ∞ .

Никакого контроля в комплексной области не требуется.

## 3. Почему это удовлетворяет твой guard

Твой предохранитель: локальная ограниченность не бесплатна, грубый P59
конверт растёт как `m^{σ/2}·√log m`, и PASS требует теоремы, снимающей
рост из real-zero структуры **без реимпорта прайм-рейта**.

Механизм §2 ровно такой:

- рост `λ^σ = m^{σ/2}` в грубом конверте берётся от множителя `sin(zL/2)`,
  то есть от **типа** функции, а не от её значений;
- формула §2 показывает, что для функции с вещественными нулями рост в
  полосе контролируется **не типом, а локальной плотностью нулей** `S(x)`;
- `S(x)` — вещественно-осевая величина; прайм-рейт в неё не входит.

То есть грубый конверт переоценивает рост ровно потому, что игнорирует
вещественность нулей — единственное свойство, которое у нашего семейства
уже доказано в ядре.

## 4. Новая точная щель

Условие (i) — это сходимость на вещественной оси, то есть половина
требования Витали, и она же нужна как «множество единственности».

Условие (ii) — **новое и конкретное**:

    равномерная по k ограниченность  Σ_n 1/(a_n^{(k)} − x)²
    для x в компакте вещественной оси,

где `a_n^{(k)}` — нули k-й конечной ground transform. Это утверждение о
**разделении нулей приближений**: нули не должны скапливаться около
вещественных точек компакта быстрее, чем позволяет равномерная константа.

Сравнение с эталоном: для самой `Ξ` величина `S_Ξ(x) = Σ 1/(γ_n − x)²`
конечна (плотность нулей `~ log T`). Значит требование (ii) — это
«приближения не хуже предела по локальной плотности нулей», а не новая
арифметическая гипотеза.

## 5. Литературный статус (по контракту: без утверждений из абстрактов)

Прочитано и используется по существу:

- **Laguerre–Pólya класс**: определяется как класс целых функций,
  являющихся локально равномерными пределами многочленов с только
  вещественными корнями; замкнут относительно таких пределов. Наша цепь
  («конечные функции с вещественными нулями → Ξ локально равномерно») —
  ровно утверждение `Ξ ∈ L-P`, которое эквивалентно RH (Пойа). Это
  подтверждает, что маршрут нацелен в правильный класс, и одновременно
  объясняет, почему дешёвого обхода быть не может.
  Источник: Wikipedia «Laguerre–Pólya class» (определение и факторизация
  Адамара–Лагерра–Пойа), плюс обзор MFO OWR 2022-13 «The Laguerre-Pólya
  Class and Combinatorics».
- **Витали–Портер** в применении к семействам с вещественными нулями
  упоминается в литературе по L-P; точная форма, которую я использую,
  выведена выше явно и не берётся из вторых рук.

Утверждения «такой теоремы не существует» НЕ делаю: поиск по разделению
нулей приближений Ξ (Turán-подобные и Gram-точки-подобные результаты) не
завершён и продолжается.
