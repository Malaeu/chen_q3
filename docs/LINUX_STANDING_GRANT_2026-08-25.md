# LINUX_STANDING_GRANT — постоянный грант Linux-телу

**Выдан владельцем 2026-08-25 в чате Linux-сессии.** Причина: Mac отвалился,
Codex-сессия мертва, судья реактивен. Тело простаивало, ожидая события, которое
некому породить. Грант убирает владельца из такта, оставляя его только там, где
решение действительно его.

Действует, пока владелец не отзовёт словом «грант отозван» либо не заменит его
новым. Расширяет `NIGHT_GRANT_2026-08-20`, не отменяя его HARD-список.

## Не снимается этим грантом (HARD)

```
PX_RH_CLAIM                      единственный owner-гейт проекта
ROUTE_PROMOTION, мёрж в main, force-push
правки глобальных правил (~/.claude/**, CODEX_CONTROL.md, протокол судьи,
  SUPPLIER_CONTRACT, session_start) — читать можно, менять нельзя
платные вызовы (Мифос и прочее), глубокие прогоны Aristotle
изменение statement и гипотез в чужих Lean-узлах без вердикта
отправка наружу чего-либо, кроме канала судьи (почта, публикация, upload)
```

`PX_RH_CLAIM` остаётся за владельцем не по осторожности, а потому что это
единственная вещь в проекте, которую нельзя проверить изнутри проекта.

## Стоп-условия — тело останавливается и докладывает

```
красный гейт, не чинящийся тактикой за две попытки
конфликт при rebase · расхождение квитанций
session_start вернул новое РАСХОЖДЕНИЕ, не чинящееся зарегистрированным входом
вердикт судьи противоречит вердикту, уже лежащему на ветке
работа упирается в решение, которое меняет маршрут, а не закрывает узел
```

Стоп-условие — это доклад, не пауза до утра: тело докладывает и берётся за
следующий узел, если он есть.

## Что тело обязано делать всегда

```
гнать ядро самому, брать ${PIPESTATUS[0]}, не пересказывать чужую расписку
писать пины из git rev-parse, никогда по памяти
регистрировать свой инструмент в TOOLS.yaml до первого боевого запуска
называть CLOSES/OPENS своего решения (W9)
записывать странное в момент, когда заметил, а не когда объяснил
чинить найденный дефект первым
перед дорогим шагом называть дешёвый различающий зонд и ветки ЕСЛИ_A/ЕСЛИ_B (VOI-гейт, docs/VOI_GATE_RULE.md)
```
