## Правила Клея (проверены на claymath.org, редакция 26.09.2018)

1. Решение публикуется в **Qualifying Outlet** — рецензируемом математическом
   журнале мировой репутации. Машинная формализация сама по себе часы
   НЕ запускает.
2. От публикации — минимум **два года**.
3. За эти два года — **general acceptance** мирового сообщества.
4. Напрямую в CMI подать **нельзя**: рассмотрение инициирует их Scientific
   Advisory Board сам.
5. Прецедент Перельмана обоюдоострый: SAB умеет гнуть форму (arXiv засчитали),
   и SAB же решает **раздел кредита** (рассматривали вклад Гамильтона).

## Механика — статья как второй дашборд базы

- Формат: **leanblueprint** (стандарт сообщества) — каждая лемма несёт
  `\lean{имя}`, сборка красит доказанное зелёным, висящее красным.
- Скелет **генерируется из базы**: цепь `assembly` → параграф, канат →
  лемма, statement — дословно из `aristotle_proofs.db`. Красные узлы =
  те же 17 канатов счётчика.
- Закрыл канат → узел позеленел → статья дописалась. Ни одна строка не
  пишется вперёд математики; выбрасывать нечего.
- LaTeX-каркас по образцу Q3: `full/RH_Q3.tex` (39 секций) как шаблон,
  `docs/routeB_bus/litreview/references.bib` как база референсов.
- Финальный проход — человеческий: вычитка на читаемость, стандартная
  нотация, повествование. Один проход по готовому, не написание с нуля.

## Атрибуция — защита кейса на приз

Родословная аудируема построчно: `supplied_by` каждого каната, даты
коммитов, профили аксиом, счётчик происхождения. Стены закрываем сами
(N0, N2, моментный бюджет, value-crosswalk) — чем больше стен наших,
тем чище кейс при разделе кредита SAB. Порты честно помечаются портами.
