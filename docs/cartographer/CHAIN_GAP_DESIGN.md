# CHAIN_GAP_DESIGN — микроскоп разрывов, полный цикл

*Дизайн зафиксирован 2026-08-19 по решению владельца. Статус: фазы 0–1 построены
(`cheap.py`: k-отчёт, слабые рёбра), стадии 1–7 ниже — целевая архитектура.
Развилка записана в момент выбора, по `RECORDING_RULES.md`.*

## Задача

Слева — доказанное. Справа — доказанное или требуемое. Посередине — разрыв.
Система обязана: строить цепи объектов через разрыв; когда цепь не замыкается —
**мерить** разрыв (сколько объектов не хватает и какими они обязаны быть, точными
типами); искать недостающее в литературе; и только когда мир пуст — ставить
задание на изобретение. Провалы копятся как иммунитет.

## Пространство объектов

Объект = Lean-декларация. Входы = гипотезы, выход = заключение. Это уже
формально и уже на диске:

```
aristotle_proofs.db   3757 лемм, все со statement
capability            1157 записей requires/provides (прозаичная тень типов)
Mathlib               через atom-таблицу и rg по исходникам
```

Прозаический слой (`capability`) — для быстрого кандидатского поиска.
Истина стыковки — только типы, и судит их только ядро.

## Семь стадий цикла

```
1. МИКРОСКОП    обратный ход от цели. Движок стыковки — сам Lean
                (exact?/apply?, fit.py-harness): цель → объекты, чей выход
                её закрывает → их непогашенные входы = под-цели. Python
                только водит дерево, ядро судит рёбра.

2. ПОЛКА        каждая под-цель сперва через ./ask.sh (СТЫКОВКИ + Lean +
                литобзор). Найден поставщик → ребро, цепь растёт.

3. ИЗМЕРЕНИЕ    под-цели, которые ничей выход не закрывает, = разрыв.
                Мера: k (сколько), и ТОЧНЫЙ ТИП каждой дыры —
                доступный контекст + требуемое заключение.

3b. ИМЯ И ЛИТЕРАТУРА
    a) типу дыры даётся семантическое имя (работа LLM): «перенос
       положительности через сдвиг» → eigenvalue perturbation / Weyl.
    b) три круга, от дешёвого к дорогому:
       prior LLM (мгновенно; ВСЕГДА relay-не-верифицировано, посылкой
       не идёт) → наша полка litreview → внешний мир (Consensus /
       Scholar / scite; найденное тянет ./paper.sh, карточку пишет
       человек).
    c) найдено → дыра закрывается ПОРТОМ известной теоремы: цитата +
       задание на формализацию. Дешевле изобретения и ниже риск.
    d) симметрично ищется НЕвозможность: чужой контрпример = готовое
       антитело, ветка отсекается до всякой работы.

4. ИЗОБРЕТЕНИЕ  только когда литература пуста. Дыра уходит судье
                typed-заданием:
                  HOLE:
                    CONTEXT:   входы, достижимые из левой стены (типами)
                    REQUIRED:  требуемое заключение (типом)
                    FORBIDDEN: антитела — формы, убитые контрпримерами
                  TASK: минимальный объект/свойство, соединяющий
                        CONTEXT с REQUIRED
                  LEDGER: CLOSES=[эта дыра], OPENS=[] или явно меньше
                  QUARANTINE: WHY_STRICTLY_WEAKER_THAN_TARGET обязателен
                Изобретение легально ровно потому, что закрывает
                измеренную дыру (W9), и ровно пока оно не переименование
                цели (C10, карантин кондуктора).

5. ГЕЙТ         def + theorem → lake env lean + scripts/q3_check.sh,
                чистый профиль на КАЖДУЮ печатаемую теорему; квитанции;
                SOURCE RECORD ≠ вердикт (SUPPLIER_CONTRACT).

6. КАТАЛОГ      мигратор кладёт W9-леджер в capability (уже вшит в петлю
                кондуктора). Цепь перемеряется: k уменьшился — цикл
                сработал.

7. ИММУНИТЕТ    провал изобретения = kill с контрпримером = антитело в
                counterexample. В эту форму больше не ходит ни поиск,
                ни судья. Прецедент: kill Рэлея 2026-08-19
                (per-cell eigenpair ⇏ fixed shift, плант K_k = k·I).
```

## Метрики цепи

- **k** — число неподтверждённых рёбер; сортировка фронтов по k восходяще
  (см. `cheap.py: chain_gap_report`). k=1 — золото.
- **Арность** — остаточные входы цепи. Франкенштейны (7–8 входов — в корпусе
  таких 4) допустимы, только если входы гасятся стеной. Свёртка
  «много входов → один» — composition-узел, легален при `CLOSES ≥ OPENS`.
- **Ребро слабое/сильное** — текстовое совпадение порождает кандидата;
  сильным ребро делает только ядро (fit.py / exact?). В k считаются только
  сильные. Scope-теги (ABSTRACT / FINITE_CELL / COFINAL_FAMILY) обязаны
  сходиться вдоль цепи.

## Потолки и честность

- Глубина обратного хода ограничена (стартово d=3): каждое ребро — вызов
  ядра, секунды–минуты.
- Микроскоп находит, где стена ТОНЬШЕ ВСЕГО. Он не обещает, что её можно
  пробить: измеренный тип дыры может быть невыполним — это и есть настоящая
  стена, и такой исход записывается как результат (K6).
- Ложное ребро хуже отсутствующего: непроверенная стыковка не входит в k
  никогда.

## К чему крепятся канаты — якоря конструкции (записано 2026-08-19 по вопросу владельца)

У каждого каната два конца, и оба записаны в базе (`assembly`):

```
нижний якорь   supplied_by / supplier_file — конкретная теорема, доказанная
               ядром (пример: канат G2:15 → simplicity_clause,
               H2aPenaltyCoercivity.lean)
верхний якорь  required_by — кто этот канат ест; цепочка required_by
               прослеживается до крыши по базе, ни одно звено не в прозе
```

**Самый верхний якорь всей конструкции — Mathlib-дзета, не наша:**

```lean
-- Q3/Basic/Defs.lean:177
def RH : Prop :=
  ∀ s : ℂ, riemannZeta s = 0 → 0 < s.re → s.re < 1 → s.re = 1/2
```

`riemannZeta` — классическая, из Mathlib, определена независимо от нас.
Крыша прибита к ней доказанным iff: `rh_iff_centeredXi_zeros_real`
(`ClassicalXiInterface.lean:108`). Подмена цели исключена ядром.

**Грунт под всеми нижними якорями один:** ядро Lean + Mathlib + три аксиомы
`[propext, Classical.choice, Quot.sound]` — стандартная классическая
математика, грунт всего Mathlib.

**Роли источников — на Q3 конструкция НЕ основана:**

```
Q3-статья (Zenodo)    ЧЕРТЁЖ. Подсказала, что доказывать. Авторитетом не
                      является: ни один канат не цитирует её посылкой.
                      Найдись в ней ещё ошибка — ни один закреплённый канат
                      не дрогнет.
статьи Connes/CvS     ЧЕРТЕЖИ отдельных креплений. Бумажный порт становится
                      канатом только после прохода через ядро.
Mathlib + 3 аксиомы   ГРУНТ — единственное, чему верим.
наши ~230 Lean-файлов САМИ КАНАТЫ, каждый доказан от грунта.
```

Финальная теорема при счётчике ноль читается так: «из трёх стандартных аксиом
следует: все нетривиальные нули Mathlib-дзеты лежат на прямой 1/2» — и между
этими точками нет ни одного места, где надо кому-то верить.
