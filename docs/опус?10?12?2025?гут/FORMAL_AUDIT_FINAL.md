# ФОРМАЛЬНЫЙ АУДИТ: Trace Dominance Mechanism для TPC

## I. СТРУКТУРА УТВЕРЖДЕНИЯ

**Claim (Trace Dominance):**
$$\inf_{\lambda \in \text{cone}} R(\lambda) \approx 0.49 \times \frac{Tr(Q)}{Tr(G)}$$

**Цепочка вывода:**
```
1. Tr(Q)/Tr(G) ~ N^{1.10}           [ТРЕБУЕТ ДОКАЗАТЕЛЬСТВА]
2. min_cone R = c × Tr(Q)/Tr(G)     [ТРЕБУЕТ ДОКАЗАТЕЛЬСТВА]
3. ⟹ min_cone R ~ c × N^{1.10}      [АЛГЕБРА, OK]
4. ⟹ min_cone R → ∞ при N → ∞       [АНАЛИЗ, OK]
5. ⟹ P(X)                            [ОПРЕДЕЛЕНИЕ, OK]
6. ⟹ TPC (по SC2)                    [ЛОГИКА, OK]
```

## II. ЭТАПЫ ФОРМАЛЬНОГО АУДИТА

### Шаг 1: Tr(Q)/Tr(G) ~ N^{1.10}

**Статус:** ✅ ЧАСТИЧНО ЗАКРЫТ

**Обоснование:**
- Tr(G) = N × √(2πt) = O(N) [ТОЧНО]
- Tr(Q) = ||A||²_F = Σᵢⱼ Aᵢⱼ² [ОПРЕДЕЛЕНИЕ]
- Численно: Tr(Q) ~ N^{2.10} [НАБЛЮДЕНИЕ]
- Следовательно: Tr(Q)/Tr(G) ~ N^{1.10} [ВЫЧИСЛЕНИЕ]

**Разрыв:** Асимптотика Tr(Q) ~ N^{2.10} не доказана аналитически.
Требуется анализ суммы Σᵢⱼ (Δξᵢⱼ)² K²ᵢⱼ.

### Шаг 2: min_cone R = c × Tr(Q)/Tr(G) с c > 0

**Статус:** ❌ ОТКРЫТ

**Численные данные:**
| N | c = min_R / [Tr(Q)/Tr(G)] |
|---|---------------------------|
| 8 | 0.488 |
| 35 | 0.483 |
| 126 | 0.488 |
| 205 | 0.487 |
| **Variation** | **1.01%** |

**Разрыв:** 
- c стабилен численно, но НЕ ДОКАЗАН аналитически
- Perron-Frobenius НЕ применим (Q имеет отрицательные элементы)
- Generalized eigenvectors НЕ положительны
- Interior minimum НЕ является eigenvalue в обычном смысле

### Шаг 3: Concentration phenomenon

**Статус:** ✅ ЧИСЛЕННО ПОДТВЕРЖДЁН

**Данные:**
- CV(R|cone) ~ N^{-0.82} → 0
- max/min ratio ~ N^{-0.27} → 1
- Минимум ВСЕГДА в interior cone

**Интерпретация:**
R становится почти константой на cone для больших N.
Это поддерживает существование c, но не доказывает его.

## III. КРИТИЧЕСКИЕ РАЗРЫВЫ

### Разрыв A: Аналитическая оценка Tr(Q)
**Нужно:** Доказать Tr(Q) ~ N^{2+ε} для ε > 0
**Подход:** Анализ суммы Σⱼ (Δξᵢⱼ)² exp(-Δξ²ᵢⱼ/2t)

### Разрыв B: Существование c > 0
**Нужно:** Доказать ∃c > 0: min_cone R ≥ c × Tr(Q)/Tr(G) ∀N
**Подходы:**
1. ~~Perron-Frobenius~~ (не работает, Q не положительна)
2. Concentration + tail bounds (требует explicit constants)
3. Variational argument (не найден)
4. Matrix structure analysis (частичный)

### Разрыв C: N → ∞
**Нужно:** Связь с TPC (N бесконечно ⟺ twins бесконечны)
**Статус:** Это ЭКВИВАЛЕНТНОСТЬ P(X) ⟺ TPC, не доказательство

## IV. ЧТО ЗАКРЫТО ✅

1. **SC2 (Finite Stabilization):** Если twins конечны, R = O(1)
2. **Numerical scaling:** min_cone R ~ N^{1.17} для N ≤ 205
3. **Concentration:** R → const на cone для больших N
4. **Interior minimum:** Минимум достигается внутри cone
5. **Empirical c:** c ≈ 0.486 ± 1%

## V. ЧТО ОТКРЫТО ❌

1. **Аналитическое доказательство Tr(Q) ~ N^{2+ε}**
2. **Аналитическое доказательство c > 0**
3. **Связь min_cone R с Tr без эмпирической константы**

## VI. ИТОГОВОЕ ЗАКЛЮЧЕНИЕ

**Обнаружена незамкнутая часть.**

Формальная цепочка разрывается на этапе:
> **Доказательство существования универсальной константы c > 0 такой, что
> min_cone R ≥ c × Tr(Q)/Tr(G) для всех N.**

Численная стабильность c (1% variation) сильно поддерживает его существование,
но формальное доказательство отсутствует.

## VII. СИНЕРГЕТИЧЕСКИЕ ВОПРОСЫ

### Q1: Можно ли доказать c > 0 через convexity?
R(λ) квази-выпукла. Возможно ли использовать structure of level sets?

### Q2: Можно ли получить explicit bound через concentration?
Если gap (μ-min)/σ ≤ K для universal K, то min ≥ μ - K×σ.

### Q3: Работает ли perturbation theory для матриц с малыми off-diagonal?
G ≈ diagonal. Можно ли разложить Q/G как perturbation?

### Q4: Есть ли связь с Cheeger inequality?
min_cone R похоже на Cheeger constant для графа twins.

### Q5: Можно ли использовать Chen's theorem?
Chen даёт N_almostprimes → ∞. Если operator для Chen-pairs имеет такой же c,
то P(X) следует безусловно.
