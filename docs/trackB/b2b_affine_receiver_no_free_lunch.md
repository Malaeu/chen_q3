# Track B B2b: Affine Receiver No-Free-Lunch

Status: B2 route-kill for one receiver family.  This is not a proof of E5p,
not a proof of RH, and not a Lean proof file.

This note follows `docs/trackB/b2b_receiver_primary_correction_gap.md`.
There we isolated the exact correction identity for the Selberg receiver:

```text
D_I = D_R - B_R^+.
```

Here we test the simplest possible RP4 repair:

```text
R_theta = 1_I + theta * (M^+ - 1_I),    0 <= theta <= 1.
```

If this worked, it would interpolate between the hard edge and the smoothed
CLV receiver, perhaps giving a better tradeoff than either endpoint.

It does not work when the proof pays the receiver residual and the correction
as separate bounds.

## Exact Affine Decomposition

Define:

```text
D_I     = P(1_I) - P0(1_I),
D_M     = P(M^+) - P0(M^+),
B_M     = D_M - D_I.
```

For the affine receiver

```text
R_theta = 1_I + theta * (M^+ - 1_I),
```

we get:

```text
D_theta = P(R_theta) - P0(R_theta)
        = D_I + theta * B_M,

B_theta = D_theta - D_I
        = theta * B_M,

D_I = D_theta - B_theta.
```

Therefore any proof that separately bounds `D_theta` and `B_theta` pays

```text
||D_theta||_G + ||B_theta||_G >= ||D_I||_G
```

by the triangle inequality.  This is not a numerical accident; it is an
algebraic lower bound for this proof shape.

## Interpretation

This kills one tempting but false proof shape:

```text
partially smooth the hard edge by affine Selberg interpolation,
bound the smoothed residual,
pay the remaining correction separately.
```

The obstruction is structural.  If the proof keeps the exact identity

```text
D_I = D_theta - B_theta
```

and pays both terms by operator norms, it cannot improve on direct hard-edge
control.  The correction is not an error term; it is the part of the hard edge
that the receiver moved out of `D_theta`.

## Verdict

`FATAL(affine Selberg receiver with separate correction bound)`.

This is not fatal for Track B.  It refines the remaining options:

1. RP1 route-equivalence: prove the E5p ledger genuinely accepts the smoothed
   receiver object `D_R` instead of the original hard edge `D_I`.
2. Nonlinear/cone-adapted RP4: build a receiver whose correction cancels by a
   structural identity, not one whose correction is merely bounded separately.
3. Return to the finite-op / structured ordinary-prime mean route, where the
   hard edge itself is controlled without receiver replacement.

Another scalar interpolation or bandwidth sweep inside
`R_theta = 1_I + theta(M^+ - 1_I)` should not be pursued.

## Proshka Audit Block

Claim:
For the affine Selberg receiver family

```text
R_theta = 1_I + theta(M^+ - 1_I),
```

the exact identity is `D_I = D_theta - B_theta`; any proof that bounds
`D_theta` and `B_theta` separately pays at least `||D_I||_G`.

Point of blockage:
The best finite separate-bound total over sampled `theta in [0,1]` is attained
at `theta=0`, i.e. no receiver smoothing.  At `theta=1`, `D_theta` is tiny but
`B_theta` is essentially the hard-edge defect.

What was tried:
- Added `clvblend` mode.
- Scanned `theta in [0,1]` on K=2,2.5,3,3.5 with the stable packet schedule.
- Checked the exact identity numerically for every sampled theta.
- Compared best separate-bound total with the hard-edge opnorm.

Minimal example:
At K=3.5, `ell=1.375`, `delta=1`:

```text
theta=0:
  total ~= ||D_I||_G ~= 0.238014

theta=1:
  ||D_theta||_G ~= 0.001014
  ||B_theta||_G ~= 0.238160
  total ~= 0.239175
```

Question for Proshka:
Is there a route-equivalence theorem that allows E5p to use the smoothed
receiver residual `D_R` directly?  If not, what nonlinear/cone-adapted
receiver condition could cancel `B_R` structurally rather than paying it as a
separate norm?

## Follow-Up

`docs/trackB/b2b_route_equivalence_audit.md` audits the first branch of that
question.  It finds no local route-equivalence theorem that lets the original
E5p hard-edge ledger use `D_R` in place of `D_I`.  The plain RP1 move

```text
prove ||D_R||_G small and call that E5p
```

is therefore a route-kill.  A legitimate smoothed route would need an explicit
downstream rewrite of every `P_edge-P0_edge` interface; otherwise Track B must
move to nonlinear cone-adapted receiver cancellation or direct ordinary-prime
mean control of `D_I`.
