Status: RP4/B2 diagnostic.  This is not a proof of E5', not a proof of RH,
and not a Lean proof file.

This note follows:

The earlier audit killed the plain replacement route:

```text
prove the smoothed Selberg receiver residual D_R
and call that the original hard-edge E5' defect.
```

The exact identity is still:

```text
D_I = D_R - B_R,
B_R = (P(M^+) - P(1_I)) - (P0(M^+) - P0(1_I)).
```

This note asks what the correction `B_R` is made of.

## Probe Mode

Implementation:

```bash
.venv/bin/python scripts/trackb_edge_operator_probe.py clvbreakdown \
  --K 3.5 --ell 1.375 --schedule fixed \
  --receiver-delta 1 --p0-na 401 --top 8
```

The new mode decomposes the Rayleigh direction of the correction operator:

```text
B_R = (P(M^+) - P(1_I)) - (P0(M^+) - P0(1_I)).
```

It reports:

- prime-side contribution by endpoint/bulk region;
- prime-side contribution by prime-power exponent `r`;
- continuum contribution by endpoint/bulk region;
- top prime shifts by absolute Rayleigh contribution;
- a Rayleigh identity check against the generalized eigenvalue.

Important implementation detail:

```text
P0(M^+) uses a full [0, max_a] quadrature grid.
P0(1_I) uses the dedicated interval grid [2K,4K].
```

`clvbreakdown` mirrors this exact convention.  The first draft used a single
full-grid weighted continuum decomposition and produced a false Rayleigh
mismatch.  The corrected helper decomposes `P0(M^+) - P0(1_I)` using the same
two-grid convention as the matrix construction.

## Interpretation

The correction is not a featureless hard-edge defect.

Prime side:

- strongly endpoint-halo localized;
- overwhelmingly ordinary-prime (`r=1`) dominated;
- concentrated just below the left endpoint `a=2K`.

Continuum side:

- dominates the absolute Rayleigh budget in the tested directions;
- is often not endpoint-local;
- at K=3.5 it is mostly interior bulk by absolute contribution.

Therefore the correction is best described as:

```text
endpoint-prime / continuum-bulk mismatch
```

This kills two naive moves:

1. **Endpoint-only prime correction**: false, because the continuum side is
   usually the larger absolute budget.
2. **Distributed ordinary-prime-only mean estimate**: incomplete, because the
   prime side is highly endpoint-local and the continuum side carries the
   matching mass.

The surviving RP4 shape is more specific:

```text
prove a matched endpoint-continuum cancellation theorem for B_R
on the Q3 cross-correlation cone.
```

Equivalently, the next theorem target should not be:

```text
||prime endpoint correction|| <= small.
```

It should be a signed/matched identity or inequality comparing the endpoint
prime layer to the continuum layer after projecting to the structured cone.

## Verdict

`PARTIAL(endpoint-halo ordinary-prime structure found)`.

`GAP(matched endpoint-continuum cancellation theorem missing)`.

This is not fatal for Track B.  It is useful because it narrows the next
mathematical question.  The correction is structured enough to attack, but the
attack cannot be a scalar norm bound on the prime side alone.

Follow-up:

- `docs/trackB/b2b_correction_structure_probe.md` checks the operator-level
  rank and cancellation structure.  The key positive signal is that
  `P(M^+)-P(1_I)` and `P0(M^+)-P0(1_I)` nearly cancel as operators.  The key
  negative signal is that the remainder is not fixed low rank in the current
  projected basis.  This points to a smooth structured quadrature theorem for
  the full receiver error, not a few-row endpoint shortcut.

## Proshka Audit Block

Claim:
The Selberg receiver correction `B_R` is not random bulk.  In the tested
opnorm Rayleigh directions, its prime side is endpoint-halo and ordinary-prime
dominated, but its continuum side dominates the absolute budget and often has
substantial interior-bulk mass.  Thus `B_R` is an endpoint-prime /
continuum-bulk mismatch, not an endpoint-only prime error.

Point of blockage:
We need an unconditional theorem that cancels or absorbs the matched
endpoint-continuum correction on the Q3 cross-correlation cone.  Existing local
boundary/cap notes are analogues, not a Track B theorem for this receiver.

What was tried:
Added `scripts/trackb_edge_operator_probe.py clvbreakdown`; fixed the
continuum decomposition so it mirrors the actual two-grid `P0(M^+) -
P0(1_I)` convention; ran K=3.5 detailed and K=2,2.5,3,3.5 compact schedule.
