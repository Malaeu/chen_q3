# Insight: Research Swarm with Symlink-Based Lake Caching

**Date:** 2026-01-17
**Category:** Infrastructure / Workflow
**Confidence:** High
**Priority:** 8/10

## One-Line Summary

Parallel research worker spawning system using symlinks to shared Lake cache, reducing storage from ~80GB to ~8GB for 10 workers.

## Context

When running multiple Claude agents in parallel on Lean 4 projects, each sandbox traditionally requires its own copy of `.lake/` directory containing Mathlib (~7.6GB) and build artifacts (~82MB). With 10 workers, this becomes prohibitive (~80GB).

## Key Insight

**Peter Steinberger's multi-checkout approach** (separate clones instead of git worktrees) combined with **symlink-based package sharing** (like pnpm store) creates an efficient parallel research system:

1. **Clone without `.lake/`** using rsync `--exclude='.lake'`
2. **Symlink packages and build** from main repo to each sandbox
3. **Same Lean/Mathlib version** across all sandboxes (enforced via lean-toolchain)

```
Main Repo                          Sandbox N
.lake/                             .lake/
├── packages/ (7.6GB) ◄────────────├── packages -> /main/.lake/packages
└── build/ (82MB)     ◄────────────└── build -> /main/.lake/build
```

## Storage Comparison

| Approach | Per Sandbox | 10 Workers | Total |
|----------|-------------|------------|-------|
| Full copy | 7.7 GB | 77 GB | 77 GB |
| Symlink | 26 MB | 260 MB | 8.3 GB |

**90% reduction in storage.**

## Implementation

Created `/scripts/swarm_spawner.sh` with:
```bash
# Clone without .lake
rsync -a --exclude='.lake' "${PROJECT_ROOT}/" "${SANDBOX_DIR}/repo/"

# Symlink packages and build
ln -sf "${MAIN}/.lake/packages" "${SANDBOX}/.lake/packages"
ln -sf "${MAIN}/.lake/build" "${SANDBOX}/.lake/build"
```

## Architecture

```
Research Agent → insights/new/*.insight.md → fswatch Watcher → Spawn Workers
      ↓                                                              ↓
  WebSearch                                                   Isolated Sandboxes
  Perplexity                                                  with symlinked cache
```

## Verification

```bash
# Check symlink savings
du -sh /main/.lake/packages  # 7.6 GB
du -sh /sandbox/.lake/       # 0 bytes (symlinks)

# Test rsync exclude
rsync -a --exclude='.lake' --dry-run --stats src/ dst/
# Shows ~26MB instead of 7.7GB
```

## Limitations

- All sandboxes must use **same Lean/Mathlib version**
- Workers should treat packages as **read-only**
- Requires `fswatch` (installable via brew)
