# Insight: Explore Agent for Mathlib Search

**Date:** 2026-01-17
**Category:** Agent Patterns / Best Practices
**Confidence:** High
**Priority:** 9/10

## One-Line Summary

Agents should EXPLICITLY use `Task(subagent_type="Explore")` for Mathlib lemma discovery instead of guessing or asking user.

## Problem

Out of 3 agents tested on Lean proof tasks:
- Only **1 out of 3** discovered and used Explore sub-agent
- Others either guessed lemma names or asked user for help
- This is a **massive productivity loss**

## Key Insight

Claude agents have access to `Task` tool with `subagent_type="Explore"` that spawns a sub-agent specifically for codebase exploration. This sub-agent can:

1. **Search Mathlib** via grep/find in `.elan/toolchains/*/lib/lean4/library/`
2. **Search .lake/packages** for downloaded dependencies
3. **Read and understand** found lemmas in context
4. **Return exact lemma names** with signatures

But agents don't automatically know to use this!

## The Pattern

```
WRONG (what most agents do):
─────────────────────────────
Agent: "I think the lemma might be called `intervalIntegral_add_adjacent`..."
Agent: "Let me try `exact?`..." (timeout)
Agent: "Can you tell me the exact lemma name?"

RIGHT (what agents SHOULD do):
──────────────────────────────
Agent: Task(
  subagent_type="Explore",
  prompt="Search Mathlib for lemmas about summing adjacent interval integrals.
          Look in MeasureTheory.Integral.IntervalIntegral.
          Find EXACT lemma names and signatures."
)
→ Returns: "Found `intervalIntegral_add_adjacent_intervals` with signature..."
```

## Must Add to Agent Instructions

```markdown
## Mathlib/Codebase Search

When you need to find lemmas or definitions:

1. **DO NOT guess** lemma names
2. **DO NOT use `exact?`** (often timeouts on complex goals)
3. **USE Explore sub-agent:**

   Task(
     subagent_type="Explore",
     prompt="Search Mathlib for [description].
             Look in [relevant modules].
             Find EXACT lemma names with signatures."
   )

4. The sub-agent will grep/find through:
   - ~/.elan/toolchains/*/lib/lean4/library/
   - .lake/packages/mathlib/
   - Project source files

5. Wait for EXACT names before writing proof code.
```
