## NUMBERING RULES — замороженная адресация

1. Каждый узел дерева имеет номер-адрес: верхний уровень 1..5,
   дети — N.1, N.2, ..., внуки — N.M.K и т.д.
2. Номера НЕ переименовываются и НЕ переиспользуются. Смена смысла =
   новый под-узел или алиас; сам номер вечен (совместимо с frozen-глоссарием
   ROUTE_B_STATE.md).
3. Новые узлы получают следующий свободный номер у своего родителя.
4. Статусы: green = доказано/закрыто · amber = почти/в работе ·
   red = открыто · gray = заморожено/нейтрально.
