## 3. Центральная лемма

Требовалось: доказать 0 ≤ α(λ) ≤ κ_λ·|a₁(λ)| с явным κ_λ — либо доложить, что импликация не следует.

**REPORT: импликация НЕ следует ни с каким κ_λ.**

(O1) Определительное препятствие: строки «α :=» не существует; любой вывод требует запрещённой реконструкции.

(O2) Структурное (внутренняя согласованность карты): пусть импликация следует из одних определений с субэкспоненциальным κ_λ. Лемма G3a из (S1) даёт |a₁| ≤ poly·E, E → 0; тогда κ_λ|a₁| → 0, обе половины liminf α = 0 бесплатны, и по (S1) при G3a — RH: узел 4 схлопывается в G3a. Противоречие с (S4) (сейф — отдельный замок) и (S1) (RH-направление — отдельная лемма AlphaDetectorPointwise). Следовательно: либо моста нет (знаковая половина — содержание леммы, не определения), либо κ_λ ≳ 1/E экспоненциален (форма ALPHA_NORMALIZED_NO_GAIN). В обоих случаях лемма не следует. ∎

Использованы только дословные строки (S1),(S3),(S4).
