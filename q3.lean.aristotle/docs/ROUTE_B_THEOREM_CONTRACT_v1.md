```text
H0 (ExactDetectorDictionary)
∧ H1 (ProjectedDefectBound / Gate 6)
```

## 3. Гипотезы контракта: тип, квантор, источник, статус

**H0 — ExactDetectorDictionary.** Слоты A1–A8: точная формула α(λ) и её знак-класс; тело теоремы 2.1; точная формула a₁; s_λ; b_λ с ДВУСТОРОННЕЙ границей 0 < c₀ ≤ |b_λ|√λ ≤ C_b·λ^(q_b) на Λ; оператор M_λ (матрица, базис, Gram) с μ₁ ≤ μ₂ ≤ μ₃ и кратностями; доказанная причина выбора μ₃−μ₁ (чётность не предполагать — доказывать); квантор детектора. Тип: определения + одна лемма невырожденности. Статус: OPEN (блок оформлен, слоты пусты). Владелец: перо Mythos → контрподпись-гейт Codex.

**H1 — ProjectedDefectBound (Gate 6).** Из неоднородного уравнения ProjectedProlateDefectEquation (bulk + коммутаторный источник + граничный источник + явные полюсно-серединные члены; подмена однородным ODE запрещена) вывести ‖B_λ‖_op ≤ C·λ^A, A ≤ 16, в ОДНОМ фиксированном пространстве X_λ (единый X-леджер; цена сдвига — отдельная строка в d; подзамки 6A–6D, 6D закрыт). Квантор: все λ ∈ Λ, λ ≥ λ₀. Статус: OPEN. Владельцы: перо Mythos (уравнение), гейты Codex (оценки), Sol (адверсарный раунд).

**H2 — G3a.** |a₁(λ)| ≤ C·λ^(B*)·E(λ), B* ≤ 25, на Λ; сборка ЕДИНЫМ точным defect-леджером в одной нормировке (шаблон — гол 007: каждый канал PRESENT_EXACT / ZERO_EXACT / ABSENT с выводом до численной оценки; накопление «мелких поправок» запрещено). Входит: узел 3.3 через мост G04DefectGramBridge (точный Rayleigh/Gram-мост, не корреляция чисел), HUMP+FAR, левый край после 007, гладкий остаток, полюсно-серединная бухгалтерия. Статус: OPEN (3.1.3 закрыт; 6D закрыт; остальное открыто).

**H3 — DetectorBridge.** Теорема E_spec ≤ C·sqrt(E_comb + E_left + E_rem) на Λ: перенос аналитической ошибки в спектральный дефект α — доказательство, а не совпадение наклонов. Статус: OPEN (перо Mythos, долг перед Sol).

**H4 — SafeWitness (RH-ядро).** ∃ подпоследовательность λ_j ∈ Λ, λ_j → ∞: α(λ_j) → 0 в знак-классе, заданном H0 (для знакового α — вместе с недопущением устойчивой отрицательности; это содержание AlphaDetectorPointwise). Статус: OPEN; НЕциркулярность — §5.

**Связующие теоремы (проверка пера — не новые доказательства):** узел 2.1 «RH ⟺ liminf α = 0 при H2» и узел 2.2 «W′(λ_j) → 0 ⟹ все нули Ξ вещественны; невещественный нуль ⟹ liminf W′ > 0 (при невырожденности b из H0)». Статус: PEN_CLAIMED_VERIFY — тела теорем предъявить и заверить (PO-11).

## 4. Цепь вывода (форма финальной сборки)

```text
H0 ∧ H2      ⟹ узел 2.1 становится безусловной эквивалентностью
H0 ∧ H1 ∧ H3 ⟹ детектор W′ корректен и невырожден на Λ
H4           ⟹ W′(λ_j) → 0 (через словарь H0)
2.2          ⟹ все нули Ξ вещественны  ⟹ RH.
```

Каждая стрелка обязана существовать как отдельная теорема с точными кванторами; ни одна не считается «очевидной».

## 5. Вердикт сейф-аудита нециркулярности (обязательный, до тяжёлых перьев)

**Вердикт: `SAFE_MECHANISM_CANDIDATE_NAMED`** (между IDENTIFIED и UNKNOWN; честное место).

- Готовой безусловной теоремы, производящей λ_j с α(λ_j) → 0, НЕ существует — иначе RH была бы доказана.
- ДОКАЗАНО (OBJECT_LOCK §3, аргумент O2): определительного моста 0 ≤ α ≤ κ_λ|a₁| с субэкспоненциальным κ_λ не существует — H4 не сводится к H2. Конъюнкция контракта нерезервируема: сейф — отдельный замок. Это же исключает вердикт «сейф = тривиальное следствие G3a».
- Именованный кандидат-механизм: **двусторонняя полиномиально-точная спектральная пара** — (H4a) острый потолок μ₁ ≤ C₁·λ^(2m₁+1)·e^(−4πλ²) (усиленный, небюджетный Gate 6) и (H4b) пол щели μ₃−μ₁ ≥ c·λ^(2m₃+1)·e^(−4πλ²) теоремой-тождеством; при m₃ − m₁ ≥ 1 + q_b это даёт W′(λ) ≤ C·λ^((1+2q_b−2(m₃−m₁))/2) → 0 на Λ (закон единой скорости Fuchs — THEOREM-класс; перенос на μ-лестницу — открытая цель). Входы механизма безусловны: явные конечные матрицы, интервальные сертификаты Гроскина, никакой статистики нулей.
- Что переворачивает вердикт в `SAFE_IS_RH_REPACKAGING`: доказательство, что ЛЮБОЙ механизм пола щели обязан использовать RH-условные входы. Что переворачивает в `SAFE_NONCIRCULAR_MECHANISM_IDENTIFIED`: закрытие H4a+H4b.
- Судья контракта (после чистки чётности): зонд r₁₃ = μ₁/(μ₃−μ₁) на λ²=13; полосы сценариев разнесены ~50 порядков (регистрация в ALPHA_DEMAND_AUDIT).

## 6. Анти-циркулярные статьи (безусловные)

- Эпистемический файрвол: RH-условные импорты (в т.ч. BFM |D|²-момент) никогда не входят в цепь H0–H4 и в связующие теоремы; безусловные замены — Гонек, twisted-моменты (`docs/RESEARCH_DIGEST_LITERATURE_2026-07.md`, sha 8dbcef9f…e335).
- K7: вычисление может фальсифицировать, калибровать и локализовать — и никогда не занимает квантор; конечные базовые случаи требуют явной мостовой леммы.
- Запрет tau0-подмены: ограниченный `Weil_criterion_tau0` не равен классическому критерию; в финальном экспорте не участвует (см. §1).
- Все литературные импорты классифицированы THEOREM / CONDITIONAL(на чём) / CONJECTURE / HEURISTIC с sha-сверкой.
