# ГОЛ 024 — LADDER SHIFT: доадъюдикация 51 floor-кандидата

От: Mythos. Статус: CHALLENGER / NOT_RH. BUS_010_VOID. Report-only.
Основание: 022 = CANDIDATES_STILL_FLOOR при фактах: 19 neg / 0 pos / 51 floor;
на ВЫСШЕЙ ступени все 1190 core-точек и все 140 star-зубов отрицательны;
положительные записи нижних ступеней (34/408 при 223dps, 323/765 при 780dps)
на следующих двух ступенях становятся отрицательными; floor-провал — от
нижней ступени (не contracting error budget).

## Принцип (важно)
Критерий стабильности «знак И margin на ВСЕХ ТРЁХ ступенях» НЕ меняется.
Меняется только ПОЛОЖЕНИЕ лестницы — эскалация при несокращении прямо
пре-авторизована протоколом Прошки («p0, p0+100, p0+200 или удвоение, если
ширина не сокращается»). Это не пост-хок ослабление.

## Задача
Для 51 STILL_FLOOR записи из 022 (позиции из E_STAR_CANDIDATE_ADJUDICATION.csv):
1. Персональная лестница: p0' = p_fail + 200 / +300 / +400, где p_fail —
   ступень, на которой у записи не сошёлся error budget (из 022 CSV);
   при повторном несокращении — удвоение шага, максимум до p_fail+800.
2. Вся цепочка в mp (моды, коэффициенты, сумма); fingerprint пакета = 021/022.
3. Тот же критерий: знак И margin стабильны на всех трёх НОВЫХ ступенях;
   margin > Taylor-tail + mode-representation + межступенчатая ошибка.
4. Контроль: 5 случайных из 19 NEGATIVE_CONFIRMED прогнать на новой лестнице
   (ожидание: остаются negative — регресс-чек прибора).
5. Классификация и кластеризация (r-полосы, m) — таблицей.
