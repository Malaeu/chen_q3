# Literal coupling source split

DIAGNOSTIC_NEVER_A_PROOF. Every integer m16–300 and worlds ζ,DH,double2. This package supplies the fixed source split A(u)=C+uB; interval solving is separate.

C is indefinite already atm16: λmin(Cζ)=−0.9354432794684964, λmin(CDH)=−0.2627694607530309. Atm300 these are −2.0169955374856694 and−0.49127167238181857. Thus a small regularizer must not be assumed to make C SPD.

The integer2-only control has λmin(A1)=−0.7930174612342252 atm16 and−0.9319214739550706 atm300. Its C is identical to Cζ and its B differs by exactly the single storedζ n=2 atom, up to float readback roundoff. Higher powers of2 retain their original coefficients.
