## 2. Положительные интегралы и нормировка

В сыром gauge `a₀=1`. Все остальные члены — полиномы Лежандра положительной
степени, поэтому их интегралы по `[-1,1]` равны нулю. Для положительного
интервального нормировочного множителя `s_j`:

```text
phi_j,K = s_j F_j,K,
J_j = integral(phi_j) = 2 s_j > 0,
phi_j,K / J_j = F_j,K / 2.
```

Слева множитель сокращён алгебраически. Справа сокращения интервальной
неопределённости нет: вычислено именно outward-rounded
`eps_j_upper / J_j_lower`. Поэтому хвостовой интервал реально уменьшает
сертифицированный запас.

## 4. Инстанцирование переноса

Для каждого из трёх `m` два сертифицированных скаляра дают условие
`r(1)>c_lambda` из замороженного Sturm–Wronskian переноса. Поэтому

```text
h_lambda(x) < 0  для 1 <= x < lambda.
```

Точка `x=lambda` обработана отдельно: зафиксированная midpoint
zero-extension берёт половину внутреннего предельного значения и сохраняет
неположительный знак. Итоговая инстанция:

```text
h_lambda(x) <= 0  для всех x в [1,lambda].
```
