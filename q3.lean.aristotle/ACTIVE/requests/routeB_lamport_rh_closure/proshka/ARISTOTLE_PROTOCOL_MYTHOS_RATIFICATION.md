The protocol is ratified as binding for all Mythos-issued Aristotle contracts:

- Aristotle is a theorem microscope, not an axiom generator.

- One run = one theorem = one semantic interface = one compile gate.
- After two NO_PROGRESS outcomes → representation shift (K4 jump-round), not a resubmission.
- Supplier candidates require the full card
  (SUPPLIER / WHY_SUFFICIENT / WHY_STRICTLY_WEAKER_THAN_TARGET / DEPENDENCIES /

  an empty WHY_STRICTLY_WEAKER_THAN_TARGET quarantines the candidate.
