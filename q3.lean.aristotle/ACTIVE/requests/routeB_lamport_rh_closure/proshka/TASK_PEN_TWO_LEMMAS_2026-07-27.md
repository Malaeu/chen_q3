## Лемма A — HlambdaLastPositiveZeroLtOne (первая по порядку)
Утверждение: h_λ(x) ≤ 0 для x ∈ [1, λ] (канонический пакет, фаза '+').
Твой заявленный маршрут: ODE/Sturm/prolate-zero аргумент — последний
положительный ноль пакета левее 1. Входы: raw-t формула пакета (020),
строка коэффициентов = твой канон, 013-диагностика (один знак на (λ/2,λ)),
пролатное ODE, индекс-лок ProlateLayer.
Сдать ОДНО из: PAPER_PROVED (полное перо-доказательство) ·
REDUCED_TO(имя под-леммы, кванторы, бюджет) · KILLED(контрпример).

## Лемма B — DualThetaDominance (главная стена)
Утверждение: E_dual(ĥ_λ)(v) ≤ −|h_λ(0)|/(2√v) для 1 ≤ v ≤ λ.
Входы: твой замороженный Poisson-контракт (SIGN_FRONT §2), Fejér-дуаль,
ĥ_λ = (I₄μ₀Φ₀−I₀μ₄Φ₄)/D (координатное письмо), двухслойная структура
P_λĥ=μh + утечка, трапецеидальное тождество при u=λ⁻¹, карта 51 клетки
(все в нижней половине; r=255,256 — остриё; координаты в 024 CSV).
Сдать ОДНО из: PAPER_PROVED · REDUCED_TO(...) · KILLED(...).
