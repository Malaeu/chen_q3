# ГОЛ 021 — 018R: FULL-WINDOW SIGN НА КАНОНИЧЕСКОМ ПАКЕТЕ

От: Mythos. Статус: CHALLENGER / NOT_RH. BUS_010_VOID.
Основание: 020 = CANONICAL_PACKET_MISMATCH — пакет, который считали 013/018,
не совпал с каноническим (старый ≈ s·canonical + поперечная примесь;
s ≈ 0.0338 / 0.0131 / 0.0056). Знак 018 на канон НЕ переносится.
Пре-регистрированное правило Прошки (кроссволк, стр. «Поправка к статусу
018»): в этом случае — 320 полос заново на исправленном пакете.

## Задача (протокол 018 дословно, объект — канонический)

ОБЪЕКТ: канонический пакет из 020, Route B (raw-t):
  htrial(λt) = (J₄φ₀(t) − J₀φ₄(t)) / (√λ·√(J₀²N₄² + J₄²N₀²)),
эквивалентно Route A — использовать реализацию, прошедшую 020
(совпадение A/B до ~1e−16 уже подтверждено).

FINGERPRINT пакета (в отчёт, чтобы идентичность была запинена):
  значения htrial в контрольных точках t ∈ {0, 0.25, 0.5, 0.75, 1⁻}
  для каждого m + SHA-256 скрипта.

Для m = 13, 53, 257:
1. E_star(htrial)(u) = √u·SumStar_{n≥1} htrial(n·u) на КАЖДОЙ tooth-band
   (λ/(r+1), λ/r), r = 1..m−1; внутри полосы — плотная сетка, не только
   равномерная глобальная;
2. значения на всех зубьях со star half-weight (primal-конвенция);
3. htrial(0) (знак и величина);
4. нижне-концевая трапецеидальная декомпозиция при u = λ⁻¹;
5. ТРИ уровня точности; вердикт знака валиден только если margin
   переживает все три; signed-log там, где амплитуды ~1e−700.

## Запреты
Никаких теорем; сетка ≠ доказательство; коэффициенты/фазу не менять;
Fejér/residual НЕ запускать (заморожены до K1-green по внешним точкам);
внешний G3-пол (float64) — отдельная задача, этот гол не блокирует.
