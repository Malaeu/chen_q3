# ГОЛ 013 — EStarUpperEdgeSignOrKill · этап A (диагностика + маршрут)

От: Mythos, по директиве Прошки (proshka/PROSHKA_AUDIT011_REMOTE_2026-07-27.md,
§7.1 и CODEX DIRECTIVE). Статус: CHALLENGER / NOT_RH. BUS_010_VOID соблюдать.

Точный факт (из компактного носителя, доказательств не требует):
для u ∈ (λ/2, λ) в сумме E_star активен только n = 1, то есть
  E_star(h_λ)(u) = √u · h_λ(u)   ТОЧНО на верхнем краю окна.
Значит вопрос «постоянна ли фаза E_star(h_λ) на окне» на верхнем краю
сводится к знаку САМОГО h_λ — самый дешёвый убийца всего sign-маршрута.

## Этап A (этот гол — report-only, без теорем)

1. Извлечь из 011 точную строку коэффициентов комбинации
   h_λ = c₀·h_{0,λ} + c₄·h_{4,λ} (нормировка + знак) и сверить с канонической
   формой Прошки: ±(I₄·h₀ − I₀·h₄)/√(I₀² + I₄²), где I_j = ∫_ℝ h_{j,λ}.
   Ответ: СОВПАДАЕТ / COEFF_LINE_MISMATCH (+ обе строки рядом).

2. ДИАГНОСТИКА (float64; в отчёте крупно пометить: NOT A PROOF):
   значения h_λ(x) на сетке x ∈ (λ/2, λ), 2001 точка,
   для λ² = m ∈ {13, 53, 257}:
   — число смен знака на интервале;
   — позиции нулей (если есть), с отступом от края;
   — min |h_λ| на интервале (насколько далеко от нуля, если знак один).

3. Маршрут-мемо (≤ 12 строк): чем это доказывать ТОЧНО —
   есть ли в Mathlib Sturm/осцилляционная теория для ODE второго порядка;
   применим ли interval-certificate подход к пролатному уравнению
   на одном явном отрезке; какие альтернативы.
