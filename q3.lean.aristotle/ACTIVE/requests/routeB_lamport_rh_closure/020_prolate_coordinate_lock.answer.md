`CANONICAL_PACKET_MISMATCH`

теорема. `STATE` не изменён; `BUS_010_VOID` соблюдён.

## 0. Конвенция и гварды

```text
t ∈ [-1,1]
x = lambda*t
y = lambda*s
Fourier_x[h](y) = integral_R h(x) exp(2*pi*i*x*y) dx
C = 2*pi*lambda^2
sqrt(2*pi)-prefactor = отсутствует
operator_prefactor = 1
kappa = J/c
mu = lambda*kappa
```

Старые `mu_old` не делились ни на `lambda`, ни на какую-либо другую
степень. `N,J,c` пересчитаны из одной endpoint-нормированной сырой ODE-моды
`phi_j(1)=1`; все амплитудные множители затем выведены отдельно.
