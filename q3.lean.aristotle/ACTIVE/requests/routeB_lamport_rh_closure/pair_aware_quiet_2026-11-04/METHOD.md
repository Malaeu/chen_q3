# Source, domain and numerical conventions

DIAGNOSTIC_NEVER_A_PROOF; same literal even N=m,L=logm source as the pinned
packets. Three source-regions are kept distinct: original16..120 tables,
extension121..300 own600-height DH census, high310..600 own900-height DH
census. Zeta/plant likewise use each packet's point table; the plant has its
pinned rank2 event gamma2pi/log2,beta1/4. Regional prefix equality is checked
where applicable, not used as permission to substitute point tables silently.

For each adjacent distinct-height event pair, use midpoint gamma for local
spacing2pi/log(gamma/(2pi)). Strict gap/spacing<theta and midpoint distance
<=2spacings from Omega or the frozen ORIGINAL winning representative define
T1. A representative belowkappa1 in an intersecting sector is clipped to1,
which leaves its strict-inclusion rank unchanged. For a quartet, q advances
by2 atomically. Original q/r and both sector endpoints are verified against
the supplied event sequence in every cell.

No T1 pair may be split. Thus the one internal sector between each marked
adjacent event pair is excluded. Connected marked edges enforce whole-cluster
inclusion automatically; edges outside the frozen T1 neighborhood are not
silently added. The same pair set is used for all optimizations at that
world,m,theta; never recenter after filtering.

For retained evaluated sectors use gap=lambda_r−||AQ||. For retained bounded
sectors keep the original absolute upper, never a stale incumbent decision.
The new lower is the maximum retained measured gap minus its guard; the new
upper is the maximum retained upper bound. Original already-padded bounds
retain their conservative inherited padding. Every new residual point is also
added to the unrestricted problem; a new information bound is not a benefit
of pair restriction. Baseline point maxima and all original enclosing bounds
remain explicitly separate.

YES_NUMERIC requires a measured non-spectrally-excluded gap>originalguard.
NO_NUMERIC requires every remaining candidate to be measured-negative beyond
that guard or excluded by the inherited singular-minmax necessary test.
Otherwise return UNRESOLVED. EMPTY_ADMISSIBLE is separate, not a separator
failure or source-sign conclusion. For theoretical max(empty), the extended
real convention is−infinity; CSV empty point/bound fields remain blank rather
than a fabricated numeric measurement. The current high-grid blocks have all
five measured points. Point medians are omitted if any member is unmeasured;
median lower/upper order statistics enclose the median under the inherited
error model. An unknown lower is−infinity, never silently dropped.

T2 refines old bounds using unchanged pinned primitives only: source400bits,
midGL192/eightpanels, highGL256/eightpanels, frames768bits. Existing cached
GL256 sources at plant248/300 are explicitly identified; the region-derived
metadata label was repaired without changing any numeric value. They are
within the pinned recipes; no source precision was raised. Remaining floor
widths are left unresolved rather than chased.

T3 transforms actual physical Fourier rows, not scalar-cancelled rows, before
float conversion. A line pair becomes average and divided difference; both
rows remain. For equal-multiplicity complex events the same invertible block
acts on corresponding real/imaginary parts. It need not be a pure analytic
gamma derivative when imaginary shifts differ. Mixed ranks are not converted
into artificial derivative/rank conditions. The numerical pilots transform a
representative active pair per prefix; their coverage is explicitly bounded.
At fixed q, exact row span, J, residual norm and lambda_r are unchanged.
Numerical relative changes at the residual floor are not scored.

T4 uses ORIGINAL delta_max, exactly delta at the first sector intersecting
kappa>=1 by nestedness. It does not use the residual at the gap optimizer.
All945 original-kappa1 residuals are available after300 control fills. The
local spike rule is fixed before overlay; m248 is separately preselected.
Optimal-cutoff association is descriptive and post-selected. No hypothesis
p-value or asymptotic confidence statement is inferred from the deterministic
grids, and the low-height spacing formula is not a density theorem for DH.

Hash-checked raw source receipts, fresh baseline replay, constraint checks,
row/null dual checks and coordinate pilots validate fixed numerical inputs.
None supplies interval source quadrature, exact ranks, complete zeros,
cofinal separators or RH.
