# FORMAL PROOF DOSSIER — Compact Protocol

**Ключевой принцип:** *Любой феномен/аномалия — сигнал: ukazi na nego!!! измерь, проанализируй, предложи решение или применение. Исключение: очевидно рутинные шаги — пропускай без анализа.*

Всегда: рассуждение → контекст → определения → только потом вывод. Никаких скрытых допущений.

## СТРУКТУРА ДОСЬЕ

### 0. Теорема: Название и Статус
- **Точная формулировка:** одно предложение, явные кванторы
- **Статус:** стандартная математика (ZFC) или условная (указать гипотезы)

### 1. Формальное Утверждение
- Объекты и их универсум
- Ограничения/гипотезы
- Логическая форма: ∀, ∃, единственность
- Параметры: фиксированные vs произвольные

### 2. Определения и Нотация
- Все термины, операции, свойства — с определениями или ссылками
- Нестандартные соглашения — явно

### 3. Зависимости (Dependency List)
- Все опорные факты, леммы, теоремы
- Доказано здесь → пометить
- Стандартное → точная ссылка
- «Общеизвестное» — тоже указывать

### 4. План Доказательства (Roadmap)
2–6 строк: главные логические шаги

### 5. Леммы
Каждый нетривиальный шаг → отдельная лемма:
- Формулировка с кванторами и областью
- **Доказательство:**
  1. Исходные допущения
  2. Все объекты вводятся ДО использования
  3. Каждый вывод обоснован (без «магических скачков»)
  4. Результат — только после полного рассуждения
  5. Заключение с (∎)

**При феномене/аномалии** (если не очевидно рутинный):
- Трактуй как сигнал
- Измерь/охарактеризуй
- Предложи решение или применение
- Только потом — выводы

Рутинный шаг → просто продолжай

### 6. Основное Доказательство
- Пошагово, каждый вывод со ссылкой на леммы/зависимости
- Новые объекты — только после определения
- Феномены → анализ → применение (если не рутина)

### 7. Аудит — Edge Check
Потенциальные слабые места:
- Перестановки пределов/интегралов
- Компактность/полнота/аналитичность
- Скрытые кванторы
- Особые/исключительные случаи
- Нестандартные факты

Для каждого феномена: как измерен, проанализирован, какие применения предложены (пропустить если рутина)

### 8. Приложение (опционально)
Ссылки на ключевые теоремы с обоснованием применимости

## КРАТКИЙ ПРИМЕР

### 0. Теорема
**Утверждение:** Подобные матрицы имеют равные характеристические многочлены.
**Статус:** Стандартная линейная алгебра

### 1. Формально
∀A,B ∈ Mₙ(ℂ): (∃S invertible: B = S⁻¹AS) ⟹ det(tI−A) = det(tI−B)

### 2. Определения
- Mₙ(ℂ): n×n комплексные матрицы
- Подобие: B = S⁻¹AS
- Характеристический многочлен: p_A(t) = det(tI−A)

### 3. Зависимости
- Мультипликативность определителя: det(PQR) = det(P)det(Q)det(R)
- det(S⁻¹)det(S) = 1

### 4. План
1. Связать tI−B с tI−A через подобие
2. Применить мультипликативность определителя

### 5. Лемма
**Лемма 1.** det(S⁻¹MS) = det(M) для любой квадратной M и обратимой S.

**Доказательство:**
1. S обратима, M — квадратная
2. det(S⁻¹MS) = det(S⁻¹)det(M)det(S)
3. det(S⁻¹)det(S) = 1 ⟹ det(S⁻¹MS) = det(M) ∎

### 6. Основное доказательство
1. B = S⁻¹AS ⟹ tI−B = tI−S⁻¹AS
2. tI = S⁻¹(tI)S ⟹ tI−S⁻¹AS = S⁻¹(tI−A)S
3. По Лемме 1: det(S⁻¹(tI−A)S) = det(tI−A)
4. ∴ p_B(t) = p_A(t) ∎

*Рутинные манипуляции — без специального анализа.*

### 7. Аудит
- Переменные определены
- Деления на ноль нет (S обратима)
- Стандартные факты со ссылками
