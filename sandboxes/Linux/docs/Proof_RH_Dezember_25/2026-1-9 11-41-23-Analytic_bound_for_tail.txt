## 5. Леммы (Lean-скелет)

### Лемма 1: из remainder-оценки в “real part bound”
**Формулировка.** Пусть \(\Re z>0\) и
\[
\Bigl|\psi(z)-\log z+\frac{1}{2z}\Bigr|\le \frac{1}{12|z|^2}.
\]
Тогда
\[
\Re\psi(z)\le \log|z|-\Re\Bigl(\frac{1}{2z}\Bigr)+\frac{1}{12|z|^2}
\le \log|z|.
\]

**Доказательство (шаги для Lean).**
1. Обозначь \(\varepsilon := \psi(z)-\log z+\frac{1}{2z}\).
2. Из \(|\varepsilon|\le \frac{1}{12|z|^2}\) следует \(\Re\varepsilon\le \frac{1}{12|z|^2}\) (лемма вида `re_le_abs` + `abs_le`).
3. \(\Re\log z = \log|z|\) при \(\Re z>0\) (в Lean: через `Complex.log_re`/ветку `Complex.log` при `re z > 0`).
4. Сложить реальныe части.

*(Эта техника ровно та же, что используется в тексте, когда “берут real parts” от remainder-оценки.)* 【66:0†RH_Q3.pdf†L32-L48】

---

### Лемма 2: явное разложение \(\log|\,\tfrac14+i\pi\xi\,|\)
**Формулировка.** Для \(\xi>0\),
\[
\log\bigl|\tfrac14+i\pi\xi\bigr|
=\log(\pi\xi)+\frac12\log\Bigl(1+\frac{1}{16\pi^2\xi^2}\Bigr).
\]

**Доказательство.**  
\(|\tfrac14+i\pi\xi|=\sqrt{\tfrac{1}{16}+\pi^2\xi^2}=\pi\xi\sqrt{1+\tfrac{1}{16\pi^2\xi^2}}\); затем \(\log(ab)=\log a+\log b\), \(\log\sqrt{u}=\tfrac12\log u\).

Lean-заметки: нужно \(\xi>0\) чтобы \(\log(\pi\xi)\) был про `Real.log` на положительном.

---

### Лемма 3: маленькая добавка к \(\log(\pi\xi)\)
**Формулировка.** Для \(\xi\ge \tfrac52\),
\[
\frac12\log\Bigl(1+\frac{1}{16\pi^2\xi^2}\Bigr)\le \frac{1}{1800}.
\]

**Доказательство (чисто рационально).**
1. Используй \(\log(1+u)\le u\) при \(u\ge 0\):
\[
\frac12\log(1+u)\le \frac{u}{2},\quad u=\frac{1}{16\pi^2\xi^2}.
\]
2. Далее оцени \(u/2 = \frac{1}{32\pi^2\xi^2}\).
3. При \(\pi>3\Rightarrow \pi^2>9\) и \(\xi\ge 5/2\Rightarrow \xi^2\ge 25/4\):
\[
\frac{1}{32\pi^2\xi^2} < \frac{1}{32\cdot 9\cdot 25/4}=\frac{1}{1800}.
\]

---

### Лемма 4: сравнение \(\log(\pi\xi)\) и \(\log(1+\xi^2)\)
**Формулировка.** Для \(\xi\ge \tfrac52\),
\[
\log(\pi\xi)\le \log(1+\xi^2)+\frac{17}{203}.
\]

**Доказательство (без производных, “алгебраическая монотонность”).**
1. Рассмотри \(r(x)=\frac{x}{1+x^2}\). Покажи: если \(1\le y\le x\), то \(r(x)\le r(y)\).  
   Это *очень Lean-friendly*:  
   \[
   \frac{x}{1+x^2}\le \frac{y}{1+y^2}
   \iff x(1+y^2)\le y(1+x^2)
   \iff (x-y)\le xy(x-y)
   \iff 1\le xy
   \]
   (последний шаг — так как \(x-y\ge 0\), делишь/переносишь; и \(xy\ge 1\)).  
2. Отсюда при \(\xi\ge 5/2\ge 1\):  
   \[
   \frac{\xi}{1+\xi^2}\le \frac{5/2}{1+(5/2)^2}=\frac{10}{29}.
   \]
3. Значит
   \[
   \frac{\pi\xi}{1+\xi^2}\le \frac{10\pi}{29}<\frac{10}{29}\cdot\frac{22}{7}=\frac{220}{203}=1+\frac{17}{203}.
   \]
4. Тогда
   \[
   \log(\pi\xi)=\log(1+\xi^2)+\log\Bigl(\frac{\pi\xi}{1+\xi^2}\Bigr)
   \le \log(1+\xi^2)+\log\Bigl(1+\frac{17}{203}\Bigr)
   \le \log(1+\xi^2)+\frac{17}{203}.
   \]
   (последний шаг снова \(\log(1+u)\le u\)).

---

### Лемма 5: итоговая оценка \(\Re\psi\) и модуль
**Формулировка.** Для \(\xi\ge 5/2\) и \(z=\tfrac14+i\pi\xi\),
\[
0\le \Re\psi(z)\le \log(1+\xi^2)+\frac{1}{10}.
\]
Следовательно \(|\Re\psi(z)|\le \log(1+\xi^2)+\frac{1}{10}\).

**Доказательство.**
- Верхняя оценка:
  \[
  \Re\psi(z)\le \log|z|
  =\log(\pi\xi)+\frac12\log\Bigl(1+\frac{1}{16\pi^2\xi^2}\Bigr)
  \le \log(1+\xi^2)+\frac{17}{203}+\frac{1}{1800}
  < \log(1+\xi^2)+\frac{1}{10}.
  \]
- Низ (чтобы убрать модуль): можно взять грубое
  \(\Re\psi(z)\ge \log|z|-\frac{1}{2|z|}-\frac{1}{12|z|^2}\) из той же remainder-оценки и заметить, что при \(\xi\ge 5/2\) \(|z|\ge |\tau|=\pi\xi > 7\), так что RHS \(>0\).  
  (Если хочешь совсем без “\(>7\)” — можно зафиксировать рациональный нижний bound через \(\pi>3\).)

## 6. Почему исходное утверждение с \(\log(1+\xi^2)\) (без +константы) не пройдёт при \(\xi=\tfrac52\)

Если тебе нужно **официально** объяснить “почему не доказывается” (и поймать баг в постановке), это делается *тем же* remainder-неравенством DLMF:

Из remainder-оценки получаешь также нижнюю границу
\[
\Re\psi(z)\ge \log|z|-\frac{5}{24|z|^2}\quad(\sigma=\tfrac14),
\]
потому что \(\Re(1/(2z))=\sigma/(2|z|^2)=1/(8|z|^2)\) и \(|\Re\varepsilon|\le 1/(12|z|^2)\). Это ровно тот “taking real parts” шаг, который у вас используется для \(a(\xi)\). 【66:0†RH_Q3.pdf†L32-L48】

На \(\xi=5/2\): \(|z|^2=\tfrac{1}{16}+(\tfrac{5\pi}{2})^2>\tfrac{901}{16}\) (из \(\pi>3\)), поэтому
\[
\Re\psi(z)>\log\Bigl(\frac{\sqrt{901}}{4}\Bigr)-\frac{5}{24}\cdot\frac{16}{901}
>\log\Bigl(\frac{15}{2}\Bigr)-\frac{10}{2703}.
\]
А \(\log(1+\xi^2)=\log(29/4)\). Разность логов — \(\log\bigl(\frac{15/2}{29/4}\bigr)=\log(30/29)\), и можно оценить снизу
\[
\log\Bigl(\frac{30}{29}\Bigr)\ge \frac{(30/29)-1}{30/29}=\frac{1/29}{30/29}=\frac{1}{30}.
\]
Но \(\frac{1}{30}>\frac{10}{2703}\), значит \(\Re\psi(z)>\log(29/4)\), т.е. требуемое \(\Re\psi\le \log(1+\xi^2)\) **ложно** при \(\xi=5/2\).

Это полезно как “диагностика”: в Lean ты не будешь биться в стену.

## 5. Lemmas (Lean-friendly “chunks”)

### Lemma 5.1 (Remainder bound with \(\sec^2\))
Let \(z\in\mathbb C\) with \(|\arg z|<\pi\). Define
\[
R(z):=\psi(z)-\log z+\frac{1}{2z}.
\]
Then
\[
|R(z)| \le \frac{1}{12|z|^2}\sec^2\!\left(\frac{\arg z}{2}\right).
\]
**Source:** DLMF §5.11(ii), “complex remainder bounded by \(\sec^2(\tfrac12\arg z)\) times first neglected term” applied to the digamma expansion (5.11.2). citeturn1view0

*(If you prefer to stay entirely inside Q3, you can take the Appendix F.4 variant directly, but you explicitly asked to include the \(\sec^2\) version.)*

---

### Lemma 5.2 (\(\sec^2\) is uniformly bounded in the right half-plane)
If \(\Re z>0\), then \(|\arg z|<\pi/2\), hence
\[
\sec^2\!\left(\frac{\arg z}{2}\right)\le 2.
\]
**Lean hint:** show \(|\arg z| \le \pi/2\) from \(\Re z>0\); then \(|\arg z|/2\le \pi/4\); use monotonicity of \(\cos\) on \([0,\pi/2]\) to get \(\cos(|\arg z|/2)\ge \cos(\pi/4)=\sqrt2/2\), hence \(\sec^2\le 2\).

**Consequence:** for \(\Re z>0\),
\[
|R(z)|\le \frac{1}{6|z|^2}.
\]

---

### Lemma 5.3 (Real-part decomposition)
For any \(z=\sigma+i\tau\) with \(\sigma>0\),
\[
\Re\psi(z) = \log|z| - \frac{\sigma}{2|z|^2} + \Re R(z)
\]
(where \(R\) is as above).
**Lean hint:** use `Complex.re_log` to rewrite \(\Re(\log z)=\log|z|\), and compute \(\Re(1/z)=\sigma/|z|^2\).

Then using triangle inequality on reals:
\[
|\Re\psi(z)| \le \log|z| + \frac{\sigma}{2|z|^2} + |R(z)|.
\]

In our application \(\sigma=\tfrac14\), so
\[
|\Re\psi(z)| \le \log|z| + \frac{1}{8|z|^2} + |R(z)|.
\]

---

### Lemma 5.4 (Turn the remainder into a rational \(1/|z|^2\))
With \(\Re z>0\), combine Lemmas 5.2 and 5.3:
\[
|\Re\psi(z)| \le \log|z| + \frac{1}{8|z|^2} + \frac{1}{6|z|^2}
= \log|z| + \frac{7}{24|z|^2}.
\]

---

### Lemma 5.5 (A clean bound for \(\log|z|\))
For \(z=\tfrac14+i\pi\xi\) with \(\xi>0\),
\[
|z|^2 = \pi^2\xi^2 + \frac1{16}
= \pi^2\xi^2\left(1+\frac{1}{16\pi^2\xi^2}\right).
\]
Thus
\[
\log|z|
= \log(\pi\xi) + \frac12\log\!\left(1+\frac{1}{16\pi^2\xi^2}\right)
\le \log(\pi\xi) + \frac{1}{32\pi^2\xi^2},
\]
using \(\log(1+u)\le u\).

For \(\xi\ge \tfrac52\) and \(\pi>3\),
\[
\frac{1}{32\pi^2\xi^2} \le \frac{1}{32\cdot 9\cdot (25/4)}=\frac{1}{1800}.
\]
So:
\[
\boxed{\;\log|z|\le \log(\pi\xi)+\frac{1}{1800}\;}.
\]

---

### Lemma 5.6 (Compare \(\log(\pi\xi)\) with \(\log(1+\xi^2)\) at \(\xi\ge 5/2\))
Write
\[
\log(\pi\xi)=\log(1+\xi^2) + \log\!\left(\frac{\pi\xi}{1+\xi^2}\right).
\]

Now bound the ratio by a rational:
1) For \(\xi\ge \tfrac52\),
\[
\frac{\xi}{1+\xi^2}\le \frac{5/2}{1+(5/2)^2}=\frac{10}{29}.
\]
**Lean-friendly proof:** cross-multiply and factor:
\[
\frac{\xi}{1+\xi^2}\le\frac{a}{1+a^2}
\iff a(1+\xi^2)-\xi(1+a^2)\ge0
\iff (\xi-a)(a\xi-1)\ge0,
\]
so it holds if \(\xi\ge a\) and \(a\xi\ge1\). Take \(a=\tfrac52\), then \(a\xi\ge a^2=25/4>1\).

2) Use \(\pi<\frac{22}{7}\) to get
\[
\frac{\pi\xi}{1+\xi^2}\le \frac{22}{7}\cdot\frac{10}{29}=\frac{220}{203}
=1+\frac{17}{203}.
\]

3) Then
\[
\log\!\left(\frac{\pi\xi}{1+\xi^2}\right)
\le \log\!\left(1+\frac{17}{203}\right)
\le \frac{17}{203}.
\]
(using \(\log(1+u)\le u\)).

So
\[
\boxed{\;\log(\pi\xi)\le \log(1+\xi^2)+\frac{17}{203}\;}.
\]

---

### Lemma 5.7 (Bound \(\tfrac{7}{24|z|^2}\) for \(\xi\ge 5/2\))
Since \(|z|^2=\pi^2\xi^2+\tfrac1{16}\ge \pi^2\xi^2\),
\[
\frac{7}{24|z|^2}\le \frac{7}{24\pi^2\xi^2}.
\]
With \(\pi>3\) and \(\xi\ge\tfrac52\),
\[
\frac{7}{24\pi^2\xi^2}\le \frac{7}{24\cdot 9\cdot (25/4)}=\frac{7}{1350}.
\]

## 6. Main proof (assemble the inequalities)
Let \(\xi\ge \tfrac52\) and \(z=\tfrac14+i\pi\xi\). Then \(\Re z=\tfrac14>0\), so Lemmas 5.1–5.4 apply and give
\[
|\Re\psi(z)| \le \log|z| + \frac{7}{24|z|^2}.
\]

Apply Lemma 5.5 and Lemma 5.6:
\[
\log|z| \le \log(\pi\xi)+\frac{1}{1800}
\le \log(1+\xi^2)+\frac{17}{203}+\frac{1}{1800}.
\]

Apply Lemma 5.7:
\[
\frac{7}{24|z|^2}\le \frac{7}{1350}.
\]

Therefore
\[
|\Re\psi(z)|
\le \log(1+\xi^2) + \left(\frac{17}{203}+\frac{1}{1800}+\frac{7}{1350}\right).
\]

Now the constant is purely rational:
\[
\frac{17}{203}+\frac{1}{1800}+\frac{7}{1350}
=\frac{98093}{1096200}
<\frac{1}{10}.
\]
Hence
\[
|\Re\psi(\tfrac14+i\pi\xi)| \le \log(1+\xi^2)+\frac{1}{10},
\]
as required.

Then
\[
|a(\xi)| \le |\log\pi| + |\Re\psi(\tfrac14+i\pi\xi)|

## 1) Ключевая лемма: из (R) получаем \(a(\xi)\ge -\log\xi\) для \(\xi\ge \tfrac12\)

Пусть \(\xi>0\) и
\[
z=\tfrac14+i\pi\xi,\qquad \sigma:=\Re z=\tfrac14,\qquad |z|^2=\sigma^2+\pi^2\xi^2.
\]

### Шаг 1. Разложение с остатком
Положим
\[
\varepsilon:=\psi(z)-\log z+\frac{1}{2z}.
\]
Тогда из (R) имеем \(|\varepsilon|\le \frac{1}{12|z|^2}\).

Следовательно
\[
\psi(z)=\log z-\frac{1}{2z}+\varepsilon.
\]

### Шаг 2. Берём действительные части и даём верхнюю оценку \(\Re\psi\)
Так как \(\Re z>0\), то \(\Re(\log z)=\log|z|\). Кроме того,
\[
\Re\Bigl(\frac{1}{2z}\Bigr)=\frac{\sigma}{2|z|^2}=\frac{1}{8|z|^2}.
\]
И \(\Re(\varepsilon)\le |\varepsilon|\).

Отсюда
\[
\Re\psi(z)
\le
\log|z|-\frac{1}{8|z|^2}+\frac{1}{12|z|^2}
=
\log|z|-\frac{1}{24|z|^2}.
\]

### Шаг 3. Переводим в нижнюю оценку \(a(\xi)\)
По определению \(a(\xi)=\log\pi-\Re\psi(z)\)【63:7†RH_Q3.pdf†L8-L24】, значит
\[
a(\xi)\ge \log\pi-\log|z|+\frac{1}{24|z|^2}.
\]

Теперь выражаем \(|z|\) через маленький параметр \(u\):
\[
|z|^2=\pi^2\xi^2+\frac{1}{16}
=\pi^2\xi^2\Bigl(1+u\Bigr),
\qquad
u:=\frac{1}{16\pi^2\xi^2}.
\]
Тогда
\[
\log|z|=\log(\pi\xi)+\frac12\log(1+u),
\]
и
\[
\log\pi-\log|z|=-\log\xi-\frac12\log(1+u),
\qquad
\frac{1}{24|z|^2}=\frac{1}{24\pi^2\xi^2(1+u)}=\frac{2u}{3(1+u)}.
\]
Итого:
\[
a(\xi)\ge -\log\xi\;+\;\underbrace{\Bigl(\frac{2u}{3(1+u)}-\frac12\log(1+u)\Bigr)}_{=:g(u)}.
\]

### Шаг 4. Показываем \(g(u)\ge 0\) при \(u\le \tfrac13\) без производных
Используем стандартное \(\log(1+u)\le u\) при \(u\ge 0\). Тогда
\[
g(u)\ge \frac{2u}{3(1+u)}-\frac{u}{2}
=
\frac{u(1-3u)}{6(1+u)}.
\]
Значит при \(0\le u\le \tfrac13\) имеем \(g(u)\ge 0\), и потому
\[
a(\xi)\ge -\log\xi.
\]

### Шаг 5. Проверяем \(u\le \tfrac13\) для \(\xi\ge \tfrac12\)
Если \(\xi\ge \tfrac12\) и \(\pi>3\) (фиксировано в Q3)【63:0†RH_Q3.pdf†L23-L27】, то \(\pi^2>9\), и
\[
u=\frac{1}{16\pi^2\xi^2}\le \frac{1}{16\cdot 9\cdot (1/4)}=\frac{1}{36}<\frac13.
\]
Следовательно:
\[
\boxed{\;\forall \xi\ge\tfrac12:\quad a(\xi)\ge -\log\xi.\;}
\]
Это — основной “универсальный” сертификат для трёх точек.

## Чётность и переиндексация: как убрать \([-1/2,1/2]\to[0,1/2]\)

Т.к. \(a(\xi)\) чётна и \(\Phi_{B,t}(\xi)\) чётна, то \(g\) чётна. Тогда периодизация \(P_A\) тоже чётна:

\[
P_A(-\theta)=2\pi\sum_{m\in\mathbb Z} g(-\theta+m)
=2\pi\sum_{m\in\mathbb Z} g(\theta-m)
=2\pi\sum_{m\in\mathbb Z} g(\theta+m)=P_A(\theta),
\]
где во втором равенстве использован факт \(g\) чётна, а в третьем — переиндексация \(m\mapsto -m\).

**Lean‑friendly трюк:** избегай `tsum` и сразу работай с конечной суммой (см. следующий пункт), тогда переиндексация делается через `Finset.sum_bij` с биекцией \(m\mapsto -m\).

## «Чистая» обрезка суммы (truncation lemma), без интегралов

## 1) Что именно брать как “DLMF 5.11 остаток” (версия Stieltjes / Euler–Maclaurin)

В Johansson (Maple Trans. 2023) это выписано в виде интегрального остатка Стилтьеса для производных \(\log\Gamma\), а затем специализация к дигамме:

- Формула остатка (27) для \(m\ge 0\):
\[
R^{(m)}_N(z)=(-1)^m(2N)^m\int_0^\infty \frac{B_{2N}-B_{2N}(\{x\})}{2N\,(x+z)^{2N+m}}\,dx.
\]
citeturn14view4

- А для \(m=1\) (дигамма) записано разложение (28):
\[
\psi(z)=\log z-\frac1{2z}-\sum_{n=1}^{N-1}\frac{B_{2n}}{2n\,z^{2n}}+R'_N(z),
\]
где \(R'_N\) — тот самый остаток, соответствующий \(m=1\). citeturn14view4

Для **\(N=1\)** сумма пуста, и получается:
\[
\psi(z)-\log z+\frac1{2z}=R'_1(z).
\]

А \(R'_1(z)\) из (27) при \(N=1,m=1\) упрощается очень приятно:
- \(B_2=1/6\),
- множитель \((2N)^m/(2N)=2/2=1\),
- знак \((-1)^1=-1\).

Итого:
\[
R'_1(z)=-\int_0^\infty \frac{B_2-B_2(\{x\})}{(x+z)^3}\,dx.
\]

**Это и есть “точный остаток” для \(N=1\)**, который можно формализовать (как итог Euler–Maclaurin / Stieltjes).

## 2) Простая (и очень безопасная) оценка остатка без сектора

Определи (в Lean) функцию
\[
E(z):=\psi(z)-\log z+\frac1{2z}.
\]
Тогда \(E(z)=R'_1(z)\) и
\[
|E(z)| \le \int_0^\infty \frac{|B_2-B_2(\{x\})|}{|x+z|^3}\,dx.
\]

### 2.1. Грубая константа на бернуллиевском “пилообразном” факторе

Бернуллиев полином
\[
B_2(t)=t^2-t+\frac16,\qquad t\in[0,1]
\]
имеет минимум \(-\frac1{12}\) (в \(t=\frac12\)) и максимум \(\frac16\) (в \(t=0,1\)). Поэтому для любой \(x\):
\[
0\le B_2 - B_2(\{x\}) \le \frac16 -\Big(-\frac1{12}\Big)=\frac14.
\]

Значит
\[
|B_2-B_2(\{x\})|\le \frac14.
\]

### 2.2. Чистая оценка интеграла \(\int_0^\infty |x+z|^{-3}dx\)

Пусть \(z=\sigma+i\tau\) с \(\sigma>0\). Тогда
\[
|x+z|^2=(x+\sigma)^2+\tau^2,
\qquad
|x+z|^3=\big((x+\sigma)^2+\tau^2\big)^{3/2}.
\]
И интеграл вычисляется в закрытом виде (обычный интеграл рациональной подстановкой):
\[
\int_0^\infty \frac{dx}{\big((x+\sigma)^2+\tau^2\big)^{3/2}}
=
\frac{1}{|z|\,(|z|+\sigma)} \le \frac{1}{|z|^2}.
\]
(Последнее, потому что \(|z|+\sigma\ge |z|\).)

### 2.3. Итоговая универсальная оценка остатка

Комбинируя:
\[
|E(z)|
\le \frac14\int_0^\infty \frac{dx}{|x+z|^3}
\le \frac{1}{4|z|^2}
\qquad(\Re z=\sigma>0).
\]

А значит автоматически:
\[
\big|\Re E(z)\big|\le |E(z)| \le \frac{1}{4|z|^2}.
\]

И это даёт **Lean‑замену вашему аксиому**, например:

> **Lemma (замена аксиома, безопасная):**  
> если \(0<\Re z\), то  
> \[
> \Big|\Re\psi(z)-\log|z|+\frac{\Re z}{2|z|^2}\Big|
> \le \frac{1}{4|z|^2}.
> \]
> (Потому что \(\Re(\log z)=\log|z|\) и \(\Re(\frac1{2z})=\frac{\Re z}{2|z|^2}\).)

Это пункт (2) из твоих вариантов с явной константой \(C=1/4\) и доменом \(0<\Re z\).

## Ask 1 — Stieltjes / Euler–Maclaurin remainder identity for \(N=1, m=1\) (digamma)

### 0. Theorem and status
**Claim.** For every \(z\in\mathbb C\) with \(\Re z>0\),
\[
\psi(z)-\log z+\frac{1}{2z}
\;=\;
-\int_{0}^{\infty}\frac{B_2 - B_2(\{x\})}{(x+z)^3}\,dx,
\]
where \(B_2(t)=t^2-t+\tfrac16\) and \(\{x\}=x-\lfloor x\rfloor\in[0,1)\) is the fractional part.

**Status.** Standard complex analysis / Euler–Maclaurin for \(\log\Gamma\). The exact integral remainder form appears explicitly in Johansson (Maple Transactions, 2023) for the remainder term of Stirling’s series for \(\log\Gamma\), and your identity is the \(N=1\) derivative of that formula.

### 1. Reference (exact formula numbers)

In Johansson, the “logarithmic Stirling series” is written as
\[
\log\Gamma(z)
=
\Bigl(z-\frac12\Bigr)\log z - z + \frac{\log(2\pi)}{2}
+
\sum_{n=1}^{N-1} T_n(z) + R_N(z)
\tag{21}
\]
with
\[
T_n(z)=\frac{B_{2n}}{2n(2n-1) z^{2n-1}}
\tag{22}
\]
and the **remainder term** satisfies the integral identity
\[
R_N(z)=\int_0^\infty \frac{B_{2N}-B_{2N}(\{x\})}{2N\,(x+z)^{2N}}\,dx,
\qquad z\notin(-\infty,0],\;N\ge1.
\tag{23}
\]
Johansson also defines Bernoulli polynomials via the standard generating function and explicitly states \(\{x\}=x-\lfloor x\rfloor\) is the fractional part. citeturn7view2

Johansson remarks that (23) can be proved using Euler–Maclaurin and points to Olver for a proof. citeturn7view2

That’s exactly the “Stieltjes remainder identity” you want, at the level of \(\log\Gamma\).

### 2. Derivation of your \(N=1, m=1\) identity from (21)+(23)

Fix \(z\) with \(\Re z>0\). Then \(z\notin(-\infty,0]\), so (21)–(23) apply.

**Step 1 (specialize \(N=1\)).**  
When \(N=1\), the sum \(\sum_{n=1}^{N-1}\) is empty, so (21) becomes
\[
\log\Gamma(z)
=
\Bigl(z-\frac12\Bigr)\log z - z + \frac{\log(2\pi)}{2}
+ R_1(z),
\]
and (23) gives
\[
R_1(z)=\int_0^\infty \frac{B_2 - B_2(\{x\})}{2\,(x+z)^2}\,dx.
\]

**Step 2 (differentiate both sides).**  
By definition \(\psi(z)=\frac{d}{dz}\log\Gamma(z)\). Differentiating the explicit part:
\[
\frac{d}{dz}\Bigl(\Bigl(z-\frac12\Bigr)\log z - z\Bigr)
= \log z - \frac{1}{2z}.
\]

So we just need \(\frac{d}{dz}R_1(z)\).

**Step 3 (differentiate under the integral sign).**  
Let
\[
F(x,z)=\frac{B_2 - B_2(\{x\})}{2\,(x+z)^2}.
\]
Then for fixed \(x\ge0\), \(F(\cdot,z)\) is holomorphic in \(z\) on \(\Re z>0\), and
\[
\partial_z F(x,z)=\frac{B_2 - B_2(\{x\})}{2}\cdot\frac{d}{dz}(x+z)^{-2}
=
\frac{B_2 - B_2(\{x\})}{2}\cdot(-2)(x+z)^{-3}
=
-\frac{B_2 - B_2(\{x\})}{(x+z)^3}.
\]

To justify exchanging derivative and integral in a Lean‑friendly way, you can use dominated convergence / “differentiate under the integral” with a global integrable majorant:

- Since \(\Re z>0\), for all \(x\ge0\), \(|x+z|\ge x+\Re z\).
- Also \(B_2 - B_2(\{x\})\) is bounded on \([0,\infty)\); in fact
  \[
  B_2 - B_2(t) = t - t^2 = t(1-t)\in[0,1/4]\quad (t\in[0,1]).
  \]
  (This identity is just algebra from \(B_2(t)=t^2-t+1/6\).)

Hence for \(x\ge0\),
\[
|\partial_z F(x,z)|
\le \frac{1/4}{|x+z|^3}
\le \frac{1/4}{(x+\Re z)^3},
\]
and \(\int_0^\infty (x+\Re z)^{-3}\,dx <\infty\).  
So `integrable` majorant exists, and you can swap derivative and integral.

Therefore
\[
R_1'(z)
=\int_0^\infty \partial_z F(x,z)\,dx
=
-\int_0^\infty \frac{B_2 - B_2(\{x\})}{(x+z)^3}\,dx.
\]

**Step 4 (conclude).**  
Differentiating the \(N=1\) Stirling identity:
\[
\psi(z)
=
\log z - \frac{1}{2z} + R_1'(z)
=
\log z - \frac{1}{2z}
-
\int_0^\infty \frac{B_2 - B_2(\{x\})}{(x+z)^3}\,dx,
\]
which rearranges to the claimed formula.

That’s exactly your Ask 1 identity, with the reference anchored at Johansson (21) and (23). citeturn7view2

## Ask 2 — Kernel integral (exact evaluation + inequality)

Let \(z=\sigma+i\tau\) with \(\sigma>0\), \(|z|=\sqrt{\sigma^2+\tau^2}\).

Define
\[
I(\sigma,\tau)=\int_0^\infty \big((x+\sigma)^2+\tau^2\big)^{-3/2}\,dx.
\]

### Step 1: shift
Let \(y=x+\sigma\). Then
\[
I(\sigma,\tau)=\int_\sigma^\infty (y^2+\tau^2)^{-3/2}\,dy.
\]

### Step 2: antiderivative
- If \(\tau=0\):  
  \(\int_\sigma^\infty y^{-3}\,dy = \big[-\tfrac12 y^{-2}\big]_\sigma^\infty = \frac{1}{2\sigma^2}\).  
  And \(\frac{1}{|z|(|z|+\sigma)}=\frac{1}{\sigma(2\sigma)}=\frac{1}{2\sigma^2}\), so the formula matches.
- If \(\tau\ne 0\): the standard primitive is
  \[
  \frac{y}{\tau^2\sqrt{y^2+\tau^2}}
  \quad\text{since}\quad
  \frac{d}{dy}\Big(\frac{y}{\sqrt{y^2+\tau^2}}\Big)=\frac{\tau^2}{(y^2+\tau^2)^{3/2}}.
  \]
  Hence
  \[
  I(\sigma,\tau)
  =
  \Big[\frac{y}{\tau^2\sqrt{y^2+\tau^2}}\Big]_{y=\sigma}^{\infty}
  =
  \frac{1}{\tau^2}-\frac{\sigma}{\tau^2\sqrt{\sigma^2+\tau^2}}
  =
  \frac{\sqrt{\sigma^2+\tau^2}-\sigma}{\tau^2\sqrt{\sigma^2+\tau^2}}.
  \]
  Multiply numerator and denominator by \(\sqrt{\sigma^2+\tau^2}+\sigma\):
  \[
  I(\sigma,\tau)=
  \frac{\tau^2}{\tau^2\,\sqrt{\sigma^2+\tau^2}\,(\sqrt{\sigma^2+\tau^2}+\sigma)}
  =
  \frac{1}{|z|(|z|+\sigma)}.
  \]

So in all cases:
\[
\boxed{
\int_0^\infty \big((x+\sigma)^2+\tau^2\big)^{-3/2}\,dx
=
\frac{1}{|z|(|z|+\sigma)}.
}
\]

### Step 3: inequality
Since \(|z|+\sigma \ge |z|\) for \(\sigma\ge0\),
\[
\frac{1}{|z|(|z|+\sigma)}\le \frac{1}{|z|^2}.
\]

That proves Ask 2.

## Ask 3 — Point bounds for \(a(\xi)=\log\pi-\Re\psi(\tfrac14+i\pi\xi)\) without any DLMF remainder axiom

You can do this **purely** from Ask 1 + Ask 2 + the digamma shift \(\psi(z+1)=\psi(z)+1/z\).

### 3.1. A single reusable lemma (error bound from the identity)

Define the “error term”
\[
E(z):=\psi(z)-\log z+\frac{1}{2z}.
\]
Ask 1 gives
\[
E(z)= -\int_0^\infty \frac{B_2 - B_2(\{x\})}{(x+z)^3}\,dx.
\]
Since \(0\le B_2 - B_2(\{x\}) = \{x\}(1-\{x\}) \le 1/4\),
\[
|E(z)|\le \frac14\int_0^\infty \frac{dx}{|x+z|^3}.
\]
For \(\Re z=\sigma>0\), \(|x+z|^2=(x+\sigma)^2+\tau^2\), so by Ask 2,
\[
\int_0^\infty \frac{dx}{|x+z|^3}
=\int_0^\infty \big((x+\sigma)^2+\tau^2\big)^{-3/2}dx
=\frac{1}{|z|(|z|+\sigma)}
\le \frac{1}{|z|^2}.
\]
Therefore:
\[
\boxed{
|E(z)|\le \frac{1}{4|z|(|z|+\Re z)}\le \frac{1}{4|z|^2}
\qquad(\Re z>0).
}
\]

This is the “replacement remainder inequality” you can use everywhere.

Also, since \(\Re(\log z)=\log|z|\) on the principal branch (safe for \(\Re z>0\)), you get the real‑part version:
\[
\Re\psi(z)
=
\log|z|-\Re\!\Big(\frac{1}{2z}\Big)+\Re E(z),
\qquad
|\Re E(z)|\le |E(z)|.
\]

### 3.2. Use the shift identity to make the error tiny at small \(\xi\)

Use
\[
\psi(z+r)=\psi(z)+\sum_{k=0}^{r-1}\frac{1}{z+k},
\quad\text{so}\quad
\psi(z)=\psi(z+r)-\sum_{k=0}^{r-1}\frac{1}{z+k}.
\]
Taking real parts:
\[
\Re\psi(z)
=
\Re\psi(z+r) - \sum_{k=0}^{r-1}\Re\!\Big(\frac{1}{z+k}\Big),
\]
and for \(z=\sigma+i\tau\) with \(\sigma>0\),
\[
\Re\!\Big(\frac{1}{z+k}\Big)=\frac{\sigma+k}{(\sigma+k)^2+\tau^2}>0.
\]

So to get an **upper** bound for \(\Re\psi(z)\) (hence a **lower** bound for \(a(\xi)\)), you:
1) upper‑bound \(\Re\psi(z+r)\) via the \(E(z)\) bound at the shifted point (large \(|z+r|\) ⇒ small error),
2) subtract a **lower** bound for the positive sum \(\sum \Re(1/(z+k))\).

This is exactly the “no numerics” route that still gives tight point bounds.

### 3.3. Recommended practical constants / shifts

- For \(\xi=\tfrac32,\tfrac52\), you can usually take **\(r=0\)**: \(|z|\) is already large, so \(|E(z)|\le 1/(4|z|^2)\) is tiny, and

- For \(\xi=\tfrac12\), **do a shift**, because \(|z|\) is small and the raw \(1/(4|z|^2)\) error is too weak.
  A safe choice is **\(r=5\)** (even \(r=6\) if you want more slack):
  \[
  z = \frac14 + i\frac{\pi}{2},\qquad w=z+5=\frac{21}{4}+i\frac{\pi}{2}.
  \]
  Then
  \[
  \Re\psi(z)=\Re\psi(w)-\sum_{k=0}^4\frac{k+1/4}{(k+1/4)^2+(\pi/2)^2}.
  \]
  Bound \(\Re\psi(w)\) using

This gives a clean analytic proof route for \(a(1/2)\ge 17/25\) with enough margin if you take \(r=5\) or \(6\). (The remaining work is just bounding a couple of logs of rationals and a few rational functions of \(\pi\); all elementary.)

### 1.2. Ветка `τ ≠ 0`: первообразная и `integral_Ioi_of_hasDerivAt_of_tendsto'`

#### (A) Определи первообразную

Возьми именно такую:

\[
F(x) := \frac{x+\sigma}{\tau^2\sqrt{(x+\sigma)^2+\tau^2}}.
\]

Lean:

```lean
let F : ℝ → ℝ := fun x =>
  (x + σ) / (τ^2 * Real.sqrt ((x + σ)^2 + τ^2))
```

#### (B) Производная: `F' = integrand` на `Ioi 0`

Ключевая «ручная» математика:

Пусть \(u(x)=(x+σ)^2+τ^2\). Тогда
\[
\frac{d}{dx}\Big(\frac{x+σ}{\sqrt{u(x)}}\Big)
= \frac{u(x)-(x+σ)^2}{u(x)^{3/2}}
= \frac{τ^2}{u(x)^{3/2}}.
\]
Значит
\[
F'(x)=\frac{1}{τ^2}\cdot \frac{τ^2}{u(x)^{3/2}}
=\frac{1}{u(x)^{3/2}}.
\]

Lean‑friendly приём: **не пытайся сразу дифференцировать “деление”**. Лучше сделай:
- `G x := (x+σ) / Real.sqrt u`
- потом `F = (1/τ^2) * G / 1` (или `F = G / τ^2`) и используй `HasDerivAt.const_mul` / `HasDerivAt.div_const`.

Технически тебе нужны леммы:
- `HasDerivAt` для `x ↦ x+σ`,
- `HasDerivAt` для `x ↦ (x+σ)^2`,
- `HasDerivAt` для `x ↦ (x+σ)^2 + τ^2`,
- `HasDerivAt` для `Real.sqrt` композиции (требует `u(x) ≠ 0`, а у нас `u(x) > 0`),
- `HasDerivAt` для `x ↦ 1/(Real.sqrt u)` (через `HasDerivAt.inv`),
- правила произведения/суммы.

**Важно:** `u(x)>0` для всех `x>0`, потому что `σ>0` и `τ^2≥0`:
\[
u(x)=(x+σ)^2+τ^2 \ge (x+σ)^2 > 0.
\]
Так что `sqrt` и `inv` легальны без “edge cases”.

#### (C) Предел на бесконечности: `Tendsto F atTop (𝓝 (1/τ^2))`

Самый Lean‑дружелюбный путь — не мудрить с `1 / sqrt(1 + ...)`, а показать, что дробь стремится к 1 через оценку разности:

Пусть \(y=x+σ>0\). Тогда
\[
\left|1-\frac{y}{\sqrt{y^2+τ^2}}\right|
=\frac{\sqrt{y^2+τ^2}-y}{\sqrt{y^2+τ^2}}
=\frac{τ^2}{\sqrt{y^2+τ^2}\,(\sqrt{y^2+τ^2}+y)}.
\]
И так как \(\sqrt{y^2+τ^2}\ge y\), то знаменатель \(\ge y(2y)=2y^2\), откуда
\[
0 \le 1-\frac{y}{\sqrt{y^2+τ^2}} \le \frac{τ^2}{2y^2}.
\]
А \(\frac{τ^2}{2(x+σ)^2}\to 0\) при \(x\to\infty\). Значит \(\frac{x+σ}{\sqrt{(x+σ)^2+τ^2}}\to 1\). Тогда \(F(x)\to 1/τ^2\).

В Lean это делается через squeeze:
- показать `0 ≤ 1 - ratio`,
- показать `1 - ratio ≤ τ^2 / (2*(x+σ)^2)`,
- `tendsto` правой части к `0`,
- вывести `tendsto (1-ratio) atTop (𝓝 0)` и значит `tendsto ratio atTop (𝓝 1)`,
- потом `tendsto` для `F` как `((1/τ^2) * ratio)`.

#### (D) Применение `integral_Ioi_of_hasDerivAt_of_tendsto'`

Ты сам указал эту лемму как целевую. Обычно она выдаёт:
\[
\int_{(0,\infty)} F'(x)\,dx = \lim_{x\to\infty}F(x)-F(0).
\]

То есть в конце ты получишь:
\[
\int_0^\infty \frac{dx}{((x+σ)^2+τ^2)^{3/2}}
=
\frac{1}{τ^2} - \frac{σ}{τ^2\sqrt{σ^2+τ^2}}.
\]

#### (E) Алгебра: привести к требуемому RHS

Положи \(a:=\sqrt{σ^2+τ^2}\). Надо показать:
\[
\frac{1}{τ^2} - \frac{σ}{τ^2 a}
=
\frac{1}{a(a+σ)}.
\]

Самый надёжный Lean‑приём: умножить обе стороны на \(τ^2 a (a+σ)\) (через `field_simp [hτ]`) и свести к тождеству:

Левая часть * \(τ^2 a (a+σ)\) = \((1-\frac{σ}{a})a(a+σ)=(a-σ)(a+σ)=a^2-σ^2=τ^2\).  
Правая часть * \(τ^2 a (a+σ)\) = \(τ^2\).

Для этого ещё нужен факт:

a^2 = σ^2+τ^2
\]
в Lean: `Real.sq_sqrt` (с предварительным `0 ≤ σ^2+τ^2`).

## 2.1 Lemma: `sqrt((x+σ)^2+τ^2) ≥ x+σ` on `x>0`

```lean
have hxσ : 0 < x + σ := add_pos hx hσ
```

## 2.2 Inequality: `1/(s*(s+(x+σ))) ≤ 1/(x+σ)^2`

Let `s = sqrt((x+σ)^2+τ^2)` and assume `hx : 0 < x` so `hxσ : 0 < x+σ`.

**Idea:** show \((x+\sigma)^2 \le s(s+(x+\sigma))\), then invert with `inv_le_inv_of_le`.

Lean snippet:

```lean
set s : ℝ := Real.sqrt ((x + σ)^2 + τ^2)
have hs0 : 0 ≤ s := Real.sqrt_nonneg _
have hxσ : 0 < x + σ := add_pos hx hσ
have hxσ0 : 0 ≤ x + σ := le_of_lt hxσ

have hs : x + σ ≤ s := by
  -- reuse the `hsqrt` proof above, then `simp [s]`:
  -- exact ...
  simpa [s] using hsqrt

have h2 : x + σ ≤ s + (x + σ) := by
  -- b ≤ a+b if 0 ≤ a
  simpa [add_assoc, add_comm, add_left_comm] using (le_add_of_nonneg_left hs0)

have hmul : (x + σ)^2 ≤ s * (s + (x + σ)) := by
  -- mul_le_mul : a≤b → c≤d → 0≤c → 0≤b → a*c ≤ b*d
  have := mul_le_mul hs h2 hxσ0 hs0
  -- left is (x+σ)*(x+σ) = (x+σ)^2
  simpa [pow_two, mul_assoc, mul_left_comm, mul_comm] using this

have hxσ2 : 0 < (x + σ)^2 := sq_pos_of_pos hxσ

have hinv : (s * (s + (x + σ)))⁻¹ ≤ ((x + σ)^2)⁻¹ :=
  inv_le_inv_of_le hxσ2 hmul

have term_le : 1 / (s * (s + (x + σ))) ≤ 1 / (x + σ)^2 := by
  simpa [one_div] using hinv
```

## 1) (1) Stieltjes N=1 identity: как получить и как обосновать дифференцирование под интегралом

### 1.1. Стартовая формула (Johansson Eq 21+23)

\[

+ \sum_{n=1}^{N-1}T_n(z)+R_N(z),
\]
и интегральный остаток
\[

\]
для \(z\notin(-\infty,0]\). На вашей области \(\Re z>0\) это выполнено автоматически. fileciteturn0file1

### 1.2. Дифференцирование по \(z\)
Дифференцируем:
- \((d/dz)\log\Gamma(z)=\psi(z)\) (это стандартное).
- \((d/dz)((z-\tfrac12)\log z - z)=\log z-\frac{1}{2z}\).

Осталось: \(R_1'(z)\). Введи
\[
f(x,z):=\frac{B_2-B_2(\{x\})}{2(x+z)^2}.
\]
Тогда
\[
\partial_z f(x,z)=\frac{B_2-B_2(\{x\})}{2}\cdot(-2)(x+z)^{-3}
=-(B_2-B_2(\{x\}))(x+z)^{-3}.
\]
Формально это даёт
\[
R_1'(z)=\int_0^\infty \partial_z f(x,z)\,dx
=-\int_0^\infty \frac{B_2-B_2(\{x\})}{(x+z)^3}\,dx,
\]
и значит
\[
\psi(z)=\log z-\frac{1}{2z}+R_1'(z),
\]
то есть ровно целевое тождество.

### 1.3. Доминирование для “d/dz под интегралом” (ключевой сертификат)

- **Bernoulli‑gap**:  
  \[

\le \frac{1/4}{(x+\sigma_0/2)^3}.

## 1) Sanity‑check тождества и “tight” дифференцирование под интегралом

\[
R_1'(z)=\int_0^\infty \frac{d}{dz}\Big(\frac{B_2-B_2(\{x\})}{2(x+z)^2}\Big)\,dx

## 2) Реал‑part remainder bound без `arg/sec`: как собрать в Lean

### 2.1 Введи \(E(z)\)
\[
E(z):=\psi(z)-\log z+\frac{1}{2z}.
\]
По Теореме A:
\[
E(z)= -\int_0^\infty \frac{B_2-B_2(\{x\})}{(x+z)^3}\,dx.

### 2.2 Оценка нормы интеграла → интеграл нормы
Используй стандартную лемму:
- **для \(\mathbb C\)-интеграла**: `norm_integral_le_integral_norm`
- или для \(\mathbb R\): `abs_integral_le_integral_abs`.

Тогда
\[
|E(z)| \le \int_0^\infty \frac{|B_2-B_2(\{x\})|}{|x+z|^3}\,dx
\le \frac14\int_0^\infty |x+z|^{-3}\,dx,

где второй шаг — `bernoulli2Diff_bounds` + монотонность интеграла по `≤` для неотрицательных функций.

Это ровно пункт (2) из файла. fileciteturn0file0

### 2.3 Привязка \(\int |x+z|^{-3}\) к вашему kernel‑интегралу
Пусть \(z=\sigma+i\tau\). Тогда
\[
|x+z|^2=(x+\sigma)^2+\tau^2
\quad\Rightarrow\quad
|x+z|^{-3}=\big((x+\sigma)^2+\tau^2\big)^{-3/2}.
\]
Значит
\[
\int_0^\infty |x+z|^{-3}\,dx
=
\int_0^\infty \big((x+\sigma)^2+\tau^2\big)^{-3/2}dx
\le \frac{1}{\sigma^2+\tau^2}.
\]
Последнее — ваш `integral_kernel_bound` (полученный из `integral_kernel_eq`). fileciteturn0file2

Итак:
\[
|E(z)|\le \frac14\cdot \frac{1}{\sigma^2+\tau^2}
= \frac{1}{4|z|^2}
= \frac{1}{4\|z\|^2}.
\]

### 2.4 Переход к нужной форме `re_digamma_remainder_bound_stieltjes`
Дальше чистая алгебра на `re`:

1) \(|\Re E(z)|\le |E(z)|\). В Lean обычно это `abs_re_le_abs` (иногда `abs_re_le_norm`).

2) Разложи \(\Re E(z)\):

\]

3) **Леммы‑переписывания, которые тебе нужны (кандидаты имён):**
- \(\Re(\log z)=\log\|z\|\): в Mathlib обычно `Complex.log_re` или `Complex.re_log`  
  (часто формулировка: `(Complex.log z).re = Real.log ‖z‖`).
- \(\Re(z^{-1}) = z.re/\|z\|^2\): обычно `Complex.inv_re` или `Complex.re_inv`.  
  Фоллбек без имени: через `Complex.inv_def : z⁻¹ = conj z / (Complex.normSq z)` и `Complex.normSq = ‖z‖^2`, тогда `re (conj z)=re z`.

После этого у тебя ровно:
\[
\big|\Re\psi(z)-\log\|z\|+\frac{z.re}{2\|z\|^2}\big|
=|\Re E(z)|
\le \frac{1}{4\|z\|^2},
\]
т.е. можно заменить ваш аксиом `re_digamma_remainder_bound_stieltjes` доказательством.

## 3) Tail на линии \(z=\tfrac14+i\pi\xi\) (\(\xi\ge 5/2\)) с вашими константами

Тут вообще не нужен `arg/sec`: только остаток \(1/(4\|z\|^2)\), \(\pi\ge3\), \(\pi\le 22/7\), \(\log(1+t)\le t\). fileciteturn0file0

### 3.1 Сначала оцениваем \(|\Re\psi(z)|\) через \(\log\|z\|\)
Из
\[
\Re\psi(z)=\log\|z\|-\frac{z.re}{2\|z\|^2}+\Re E(z)
\]
получаем
\[
|\Re\psi(z)|
\le \log\|z\|+\frac{z.re}{2\|z\|^2}+|\Re E(z)|
\le \log\|z\|+\frac{1}{8\|z\|^2}+\frac{1}{4\|z\|^2}
=\log\|z\|+\frac{3}{8\|z\|^2}.
\]

Для \(z=\tfrac14+i\pi\xi\):
\(\|z\|^2=\tfrac1{16}+\pi^2\xi^2 \ge \pi^2\xi^2\).
Если \(\xi\ge 5/2\) и \(\pi\ge 3\),
\[
\frac{3}{8\|z\|^2}
\le \frac{3}{8\pi^2\xi^2}
\le \frac{3}{8\cdot 9\cdot 25/4}
=\frac{1}{150}.
\]

Итого:
\[
|\Re\psi(z)|\le \log\|z\|+\frac{1}{150}.
\]

### 3.2 Лёгкий log‑bound без тяжёлого полинома (даёт даже сильнее, чем +1/11)
Разложение:
\[
\|z\|^2=\pi^2\xi^2+\frac1{16}
=\pi^2\xi^2\Big(1+\frac{1}{16\pi^2\xi^2}\Big),
\]
\[
\log\|z\|=\log(\pi\xi)+\frac12\log\Big(1+\frac{1}{16\pi^2\xi^2}\Big)
\le \log(\pi\xi)+\frac{1}{32\pi^2\xi^2}.
\]
При \(\xi\ge 5/2\), \(\pi\ge 3\):
\[
\frac{1}{32\pi^2\xi^2}\le \frac{1}{32\cdot 9 \cdot 25/4}=\frac{1}{1800}.
\]

Дальше сравниваем \(\log(\pi\xi)\) с \(\log(1+\xi^2)\):
\[
\log(\pi\xi)=\log(1+\xi^2)+\log\Big(\frac{\pi\xi}{1+\xi^2}\Big).
\]
Для \(\xi\ge 5/2\) докажи (алгеброй) \(\xi/(1+\xi^2)\le 10/29\). Тогда при \(\pi\le 22/7\):
\[
\frac{\pi\xi}{1+\xi^2}\le \frac{22}{7}\cdot\frac{10}{29}=\frac{220}{203}=1+\frac{17}{203},
\]
и
\[
\log\Big(\frac{\pi\xi}{1+\xi^2}\Big)\le \log\Big(1+\frac{17}{203}\Big)\le \frac{17}{203}.
\]

Итак:
\[
\log\|z\|\le \log(1+\xi^2)+\frac{17}{203}+\frac{1}{1800}.
\]

Теперь можно либо:
- (а) показать \(\frac{17}{203}+\frac{1}{1800}\le \frac{1}{11}\) (это чистая рациональная проверка), и получить ровно ваш промежуточный `+1/11`;  
либо
- (б) **вообще не вводить `1/11`**, а сразу сложить константы в финале (в Lean это проще: один `nlinarith` на рационалах).

### 3.3 Финал
\[
|\Re\psi(z)|\le \log\|z\|+\frac{1}{150}
\le \log(1+\xi^2)+\Big(\frac{17}{203}+\frac{1}{1800}+\frac{1}{150}\Big)
< \log(1+\xi^2)+\frac{1}{10}.
\]
(Последнее — снова рациональная проверка.)

## 0. Теорема: Stieltjes N=1 identity for digamma — Статус

**Точная формулировка:**  
\[
\forall z\in\mathbb C,\ \Re z>0:\quad 
\psi(z)-\log z+\frac1{2z}
= -\int_0^\infty \frac{B_2-\;B_2(\{x\})}{(x+z)^3}\,dx,
\]
где \(B_2(t)=t^2-t+\tfrac16\), \(\{x\}\in[0,1)\) — дробная часть, интеграл — по \(x\in(0,\infty)\).

**Статус:** стандартная аналитика (Euler–Maclaurin/Stieltjes remainder). В Lean‑проекте ты хочешь получить это как следствие от формулы для \(\log\Gamma\) при \(N=1\) (Johansson eq (21)+(23) / Stieltjes remainder) + дифференцирование под интегралом.

---

## 1. Формально (Lean target)

То, что у тебя сейчас как аксиома:

```lean
axiom digamma_stieltjes_identity (z : ℂ) (hz : 0 < z.re) :
  Q3.digamma z - Complex.log z + (1 / (2 : ℂ)) * z⁻¹ =
    -∫ x in Set.Ioi (0 : ℝ), (bernoulli2Diff x : ℂ) / (x + z) ^ 3
```

Здесь `bernoulli2Diff x = 1/6 - B2(fract x)` (или эквивалентно `fract x*(1-fract x)`).

---

## 2. Определения и нотация

- `bernoulli2Diff : ℝ → ℝ` уже у тебя (и `0 ≤ ... ≤ 1/4` доказано).
- Интеграл: `∫ x in Set.Ioi (0:ℝ), ...` = `MeasureTheory.integral` по `volume` restricted.
- `Q3.digamma` — твоя `ψ`.
- `Complex.log` — главная ветвь (в mathlib есть стандартная).

## 3. Зависимости

### (A) Внешняя формула на logGamma (Stieltjes remainder, N=1)

\[
\log\Gamma(z) \;=\; \Big(z-\tfrac12\Big)\log z \;-\;z\;+\;\tfrac12\log(2\pi)\;+\;
\int_0^\infty \frac{B_2-\;B_2(\{x\})}{2(x+z)^2}\,dx,\qquad \Re z>0.
\]

Назови её в Lean, например:


Это ровно тот «Johansson eq (21)+(23), N=1». Если это у тебя уже есть (как лемма/аксиома) — отлично. Если нет, то *именно это* становится новым “single axiom”, но ты хотя бы убираешь digamma‑аксиому и переносишь доверие на logGamma‑уровень (обычно проще согласиться).

## 5. Ключевая лемма: swapping derivative and integral

### 5.1. Формулировка (то, что реально надо)

Пусть `z0` с `0 < z0.re`. Определи
\[
F(z,x) = \frac{b(x)}{2(x+z)^2},\quad b(x)=bernoulli2Diff(x)\in[0,1/4].
\]
Тогда:
\[
\frac{d}{dz}\int_0^\infty F(z,x)\,dx
= \int_0^\infty \frac{\partial}{\partial z}F(z,x)\,dx
= -\int_0^\infty \frac{b(x)}{(x+z)^3}\,dx.
\]

### 5.2. Почему это Lean-friendly: выбор `bound(x)`

Самый важный ход: для swapping *не нужен* твой точный kernel‑интеграл. Достаточно дать грубую, но интегрируемую доминацию.

Возьми `ε := z0.re / 2` (положительное). Рассмотри окрестность
\[
s := \{z : \mathbb C \mid \Re z \ge ε\}.
\]
Это множество — neighbourhood `z0` (через непрерывность `re`).

Тогда для любого `z ∈ s` и любого `x>0`:
\[
|x+z| \ge \Re(x+z) = x+\Re z \ge x+ε.
\]
Следовательно
\[
\left|\frac{\partial}{\partial z}F(z,x)\right|
= \left|\frac{b(x)}{(x+z)^3}\right|
\le \frac{1/4}{|x+z|^3}
\le \frac{1/4}{(x+ε)^3}.
\]
И функция \((1/4)/(x+ε)^3\) интегрируема на \(x\in(0,\infty)\) (интеграл равен \(1/(8ε^2)\), но величина неважна — важна интегрируемость).

Эта доминация **не зависит от Im(z)** и не требует `τ`‑разбивки.

## 7. Аудит — где реально тонко

### 7.1. Интегрируемость `F z0`
Для `F(z0,x) = b(x)/(2(x+z0)^2)` достаточно:
\[
|F(z0,x)| \le \frac{1/4}{2(x+ε)^2},
\]
а \(\int_0^\infty (x+ε)^{-2} dx < \infty\).  
Это тоже очень Lean‑friendly (простые степенные интегралы).

### 7.2. Условие `z ≠ 0` для `log`
Если где-то используешь `HasDerivAt.log`, оно требует `z ≠ 0`.  
На домене `Re z > 0` это автоматически: `z ≠ 0` из `z.re > 0`. В Lean обычно `by
  intro hz0; ...` и `simp [hz0]` не проходит, надо явно:
`have : z ≠ 0 := by
  intro hz; have : z.re = 0 := by simpa [hz] ; linarith`
(или `simp [hz]` + `linarith`).

### 7.3. Условие `x+z ≠ 0`
В производных `(x+z)⁻²`/`⁻³` нужно `x+z ≠ 0`.  
Для `x>0` и `Re z ≥ ε>0`: `Re(x+z)=x+Re z>0`, значит `x+z≠0`.  
Это ровно то, зачем мы берём `s := {Re z ≥ ε}`.

## 1) Какая лемма для swap deriv/integral и как она выглядит

Тебе нужна ровно

`hasDerivAt_integral_of_dominated_loc_of_deriv_le`

из `Mathlib/Analysis/Calculus/ParametricIntegral`.

Её сигнатура (важно: **возвращает пару** `Integrable … ∧ HasDerivAt …`) такая: citeturn17view0

```lean
theorem hasDerivAt_integral_of_dominated_loc_of_deriv_le
  {bound : α → ℝ} {F : 𝕜 → α → E} {x₀ : 𝕜} {s : Set 𝕜} (hs : s ∈ 𝓝 x₀)
  (hF_meas : ∀ᶠ x in 𝓝 x₀, AEStronglyMeasurable (F x) μ)
  (hF_int : Integrable (F x₀) μ)
  {F' : 𝕜 → α → E} (hF'_meas : AEStronglyMeasurable (F' x₀) μ)
  (h_bound : ∀ᵐ a ∂μ, ∀ x ∈ s, ‖F' x a‖ ≤ bound a)
  (bound_integrable : Integrable bound μ)
  (h_diff : ∀ᵐ a ∂μ, ∀ x ∈ s, HasDerivAt (fun x : 𝕜 => F x a) (F' x a) x) :
  Integrable (F' x₀) μ ∧
    HasDerivAt (fun n : 𝕜 => ∫ a, F n a ∂μ) (∫ a, F' x₀ a ∂μ) x₀
```

**Как использовать:**

```lean
have h :=
  hasDerivAt_integral_of_dominated_loc_of_deriv_le
    (μ := volume.restrict (Set.Ioi (0:ℝ))) hs hF_meas hF_int hF'_meas
    h_bound bound_integrable h_diff

have hF'Int : Integrable (F' z) (volume.restrict (Set.Ioi (0:ℝ))) := h.1
have hDeriv : HasDerivAt (fun w => ∫ x, F w x ∂(volume.restrict (Set.Ioi (0:ℝ))))
```

## 2) Самый короткий proof: `{w | ε ≤ w.re} ∈ 𝓝 z` (без `Metric.ball`)

Трюк: берёшь **открытую** половинуплоскость `{w | ε < w.re}`, она ∈ `𝓝 z`, потом расширяешь до `≤`.

```lean
lemma nhds_re_ge (z : ℂ) (ε : ℝ) (hε : ε < z.re) :
    {w : ℂ | ε ≤ w.re} ∈ 𝓝 z := by
  -- open half-plane
  have hopen : IsOpen {w : ℂ | ε < w.re} := by
    -- preimage of Ioi under continuous re
    simpa [Set.preimage, Set.setOf_app_iff] using
      (isOpen_Ioi.preimage (RCLike.continuous_re : Continuous fun w : ℂ => w.re))
  have hzmem : z ∈ {w : ℂ | ε < w.re} := by
    simpa [Set.mem_setOf_eq] using hε
  have hnhds : {w : ℂ | ε < w.re} ∈ 𝓝 z :=
    hopen.mem_nhds hzmem
  -- widen < to ≤
  exact Filter.mem_of_superset hnhds (by
    intro w hw; exact le_of_lt hw)
```

Замечание: `RCLike.continuous_re` точно есть (см. в `Mathlib.Analysis.RCLike.Basic`). citeturn18view0

Если ты хочешь именно `ε = z.re/2`, то `hε` делается чисто `nlinarith [hz]`.

## 1) Самый сильный фикс: **приведи цель к форме `∫ x, … ∂μ` и зафиксируй μ как локальную константу**

Почти всегда `whnf`‑взрыв происходит, когда Lean пытается сопоставить:

- твою цель вида `∫ x in Set.Ioi (0:ℝ), …`
- с формой в теореме `∫ a, F n a ∂μ`

и он начинает раскручивать “интеграл по множеству” как “интеграл по restricted measure”, а затем ещё `volume`, и так далее.

### Рекомендую переписать **внутри** леммы `stieltjes_integral_deriv`:

```lean
classical
let μ : Measure ℝ := volume.restrict (Set.Ioi (0:ℝ))
-- дальше везде использовать ∂μ

-- вместо: ∫ x in Set.Ioi (0:ℝ), ...
-- пиши: ∫ x, ... ∂μ
```

И в самом месте применения `hasDerivAt_integral...` сделай `change` до **точно** совпадающей формы:

```lean
-- было: HasDerivAt (fun w => ∫ x in Set.Ioi 0, F w x) ...
-- сделай:
change HasDerivAt (fun w => ∫ x, F w x ∂μ) (∫ x, F' z x ∂μ) z
```

Очень часто **одного этого** хватает: унификация становится тривиальной и `whnf` не взрывается.

## 2) Второй фикс: **не передавай F/F'/bound как огромные λ**, а вынеси в `def`/`abbrev`

Если ты пишешь прямо в вызове:

```lean

(F' := fun z x => -(bernoulli2Diff x : ℂ) / (x+z)^3)
(bound := fun x => (1/4:ℝ) / (x+ε)^3)
```

то Lean может пытаться `whnf`‑нормализовать эти лямбды при унификации (и это бывает дорого).

Лучше:

```lean
abbrev F  (z : ℂ) (x : ℝ) : ℂ := (bernoulli2Diff x : ℂ) / (2 * (x + z)^2)
abbrev F' (z : ℂ) (x : ℝ) : ℂ := -(bernoulli2Diff x : ℂ) / (x + z)^3
abbrev bound (ε : ℝ) (x : ℝ) : ℝ := (1/4 : ℝ) / (x + ε)^3
```

И потом в вызове:

```lean
have h := hasDerivAt_integral_of_dominated_loc_of_deriv_le
  (μ := μ) (F := F) (F' := F') (bound := bound ε) (x₀ := z) (s := s) hs

exact h.2
```

**Почему быстрее:** унификация видит константы `F`, `F'`, `bound` вместо больших термов.

Если хочешь ещё сильнее, можно сделать `opaque F …` и отдельно иметь лемму `F_def : F z x = …` для ручного раскрытия в местах, где надо; но чаще хватает `abbrev`.

## 3) Третий фикс: **вынеси `h_bound` и `h_diff` наружу (как отдельные леммы), не держи их внутри одного гигантского `by`**

Да, это реально помогает компилятору: вместо одного огромного term‑graph, ты даёшь ссылку на уже типчекнутую лемму.

То есть:

```lean

  ∀ᵐ x ∂μ, ∀ w ∈ s, ‖F' w x‖ ≤ bound ε x := ...

lemma h_diff_lemma (z : ℂ) (hz : 0 < z.re) :
  ∀ᵐ x ∂μ, ∀ w ∈ s, HasDerivAt (fun w => F w x) (F' w x) w := ...
```

А в `stieltjes_integral_deriv` просто:

```lean
have h :=
  hasDerivAt_integral_of_dominated_loc_of_deriv_le
    (μ := μ) (F := F) (F' := F') (bound := bound ε) (x₀ := z) (s := s) hs

    (h_bound_lemma z hz) (bound_integrable_lemma z hz) (h_diff_lemma z hz)
exact h.2
```

Это часто снимает `whnf`‑таймаут именно потому, что Lean перестаёт пытаться нормализовать гигантский “всё‑в‑одном” proof term вокруг вызова.

## 4) Четвёртый фикс: **используй открытый half‑plane, а не `Metric.ball`**

Ты уже перешёл на half‑plane, но подчеркну: это важно и для скорости, и для `linarith`.

## 5) Пятый фикс: **не `simp`‑и `F/F'` в самом вызове леммы**

Если у тебя есть `simp [F, F']` **внутри** аргументов к `hasDerivAt_integral...`, это часто и вызывает `whnf` blow‑up.

Правило:

- до вызова: никакого `simp` на больших выражениях;
- вызываем лемму “как есть”;
- **после** получения `HasDerivAt` делаем маленькие `simp` только на цели/результате (и лучше `simp_rw` точечно).

### 0. Теорема: производная `log ∘ Gamma` при попадании в `slitPlane`
**Формулировка:**  
\[
\forall z,\ (0<\Re z)\land (\Gamma(z)\in\text{slitPlane})
\;\Rightarrow\;
\frac{d}{dz}\log(\Gamma z)=\frac{\Gamma'(z)}{\Gamma(z)}.
\]

### 1. Lean‑формулировка (почти 1:1)
```lean
import Mathlib.Analysis.SpecialFunctions.Gamma.Deriv
import Mathlib.Analysis.SpecialFunctions.Complex.LogDeriv

namespace Q3

theorem logGamma_hasDerivAt_of_gamma_mem_slitPlane
    (z : ℂ) (hz : 0 < z.re) (hslit : Complex.Gamma z ∈ Complex.slitPlane) :
    HasDerivAt (fun w => Complex.log (Complex.Gamma w))
      (deriv Complex.Gamma z / Complex.Gamma z) z := by
  -- 1) Gamma differentiable
  have hdiff : DifferentiableAt ℂ Complex.Gamma z := by
    -- Gamma is differentiable away from negative integers; `hz` implies `z ≠ -m`.
    -- In mathlib: `Complex.differentiableAt_Gamma` takes a proof `∀ m : ℕ, z ≠ -m`.
    refine Complex.differentiableAt_Gamma z ?_
    intro m
    -- show contradiction from real parts: Re(-m) = -m ≤ 0 < Re(z)
    have : (z.re) = (- (m : ℂ)).re := by
      -- from `z = -m` (contradiction assumption) take real parts
      -- exact congrArg Complex.re ?h
      -- (fill with `simp` once you have `h : z = - (m:ℂ)`)
      sorry
    -- then `hz` contradicts `(- (m:ℂ)).re ≤ 0`
    -- (finish with `linarith` after `simp` gives `(- (m:ℂ)).re = -m`)
    sorry

  have hderiv : HasDerivAt Complex.Gamma (deriv Complex.Gamma z) z :=
    hdiff.hasDerivAt

  -- 2) chain rule for clog (log on slitPlane)
  -- lemma exists: `HasDerivAt.clog` in `Complex.LogDeriv` citeturn1view0
```

- `Complex.differentiableAt_Gamma` (из `Gamma.Deriv`) citeturn4view0  
- `HasDerivAt.clog` / логарифмическая производная для `log` (из `Complex.LogDeriv`) citeturn1view0  

### 2. Что делать дальше (чтобы получить нужную `digamma_stieltjes_identity`)
Если ты сейчас выводишь `digamma_stieltjes_identity` из `logGamma_stieltjes_N1` через дифференцирование, то **вместо** глобального `logGamma_hasDerivAt hz` просто применяешь новую лемму с `hslit` *локально на множестве*
\[
U := \{z : \Re z>0 \land \Gamma(z)\in\text{slitPlane}\}.
\]
Это `U` — открытое множество (по непрерывности `Gamma` и открытости `slitPlane`). На `U` дифференцирование корректно, и получается равенство для `digamma` на `U`.  
Далее можно добить “все `Re z>0`” так:
- левая и правая части `digamma_stieltjes_identity` — голоморфны на `{Re z>0}` (интеграл даёт голоморфность через вашу `stieltjes_integral_deriv`),
- равны на непустом открытом `U`,
- значит равны на всей связной области `{Re z>0}` (identity theorem).

**Это строго корректный ремонт** без изменения определения `logGamma`.  
Минус: тебе понадобится один “уникальность голоморфного продолжения”‑лемма (в mathlib это стандартный инструмент про совпадение на множестве с предельной точкой).

## Путь B (математически правильный и ещё чище): перестать звать `log ∘ Gamma` “logGamma”

Это концептуально то же, что в любой CAS: **логарифм гаммы — это не `log(Gamma z)` как principal log**, а отдельная голоморфная ветвь, выбранная так, что `exp(logGamma z)=Gamma z` и `logGamma` голоморфна на нужной области. Именно поэтому в численных библиотеках и говорится про расхождение на `2π i`. citeturn13view0  

Если в файле `Q3/DigammaRemainder.lean` у тебя `logGamma_stieltjes_N1` — это Johansson/Stieltjes формула для *аналитического* `logGamma` на `Re z>0`, то самый “Lean‑дружелюбный” ход:

1) **переопредели `Complex.logGamma`** не как `log ∘ Gamma`, а прямо как RHS Stieltjes‑формулы (она голоморфна на `Re z>0` из‑за голоморфности `log z` и твоего лемматического блока про дифференцирование интеграла). Тогда `logGamma_stieltjes_N1` станет `rfl`/`by simp`.

2) дальше доказывай `HasDerivAt logGamma (digamma z) z` не через `Complex.log` вообще, а через равенство:
\[
(\logGamma)'(z)=\frac{\Gamma'(z)}{\Gamma(z)}
\]
которое следует из факта `exp(logGamma z)=Gamma z`. Но это уже потребует показать `exp(RHS)=Gamma`, то есть связать RHS с Γ. Это нетривиально.

Поэтому, если цель только хвост/оценка ψ, **путь B обычно хуже по трудозатратам**, чем путь A + identity theorem.

## 2) Оценка `sqrt((x+σ)^2+τ^2) ≥ x+σ` и следствие  
`1/(sqrt…*(sqrt…+x+σ)) ≤ 1/(x+σ)^2` на `Ioi 0`

### 2.1 Лемма `sqrt ≥ x+σ`

Для `hx : 0 < x` и `hσ : 0 < σ` положим `u := x + σ`. Тогда `0 ≤ u`, и:

\[
\sqrt{u^2} \le \sqrt{u^2+\tau^2}\quad\Rightarrow\quad |u|\le \sqrt{u^2+\tau^2}\quad\Rightarrow\quad u\le \sqrt{u^2+\tau^2}.
\]

Lean‑скелет:

```lean
have hu_pos : 0 < x + σ := add_pos hx hσ
have hu_nonneg : 0 ≤ x + σ := le_of_lt hu_pos

have hsqrt_ge :
    x + σ ≤ Real.sqrt ((x + σ)^2 + τ^2) := by
  -- монотонность sqrt:
  have hle : (x + σ)^2 ≤ (x + σ)^2 + τ^2 := by
    nlinarith [sq_nonneg τ]
  -- sqrt_le_sqrt : a ≤ b -> sqrt a ≤ sqrt b
  have := Real.sqrt_le_sqrt hle
  -- переписываем sqrt((x+σ)^2)=|x+σ|=x+σ (так как u≥0)
  simpa [Real.sqrt_sq_eq_abs, abs_of_nonneg hu_nonneg] using this
```

### 2.2 Неравенство для “ядра” (то, что тебе нужно для squeeze)

Обозначим
```lean
term x :=
  1 / (Real.sqrt ((x+σ)^2 + τ^2) * (Real.sqrt ((x+σ)^2 + τ^2) + (x+σ)))
```

Хочешь:
\[
term(x)\le \frac{1}{(x+\sigma)^2}.
\]

Делаем так: сначала докажем
\[
(x+\sigma)^2 \le \sqrt(u^2+\tau^2)\,(\sqrt(u^2+\tau^2)+u),
\]
а затем применим `one_div_le_one_div_of_le` (или `inv_le_inv_of_le`). Это чисто алгебра + монотонность умножения.

Lean‑скелет (на одной строке “без магии”):

```lean
have hu_pos : 0 < x + σ := add_pos hx hσ
have hu_nonneg : 0 ≤ x + σ := le_of_lt hu_pos
have hsqrt_nonneg : 0 ≤ Real.sqrt ((x + σ)^2 + τ^2) := Real.sqrt_nonneg _

have h_u_le_sqrt : x + σ ≤ Real.sqrt ((x + σ)^2 + τ^2) := hsqrt_ge (x:=x) (σ:=σ) (τ:=τ) hx hσ

-- (x+σ) ≤ sqrt + (x+σ)
have h_u_le_sum : x + σ ≤ Real.sqrt ((x + σ)^2 + τ^2) + (x + σ) :=
  le_add_of_nonneg_left hsqrt_nonneg

-- шаг 1: (x+σ)^2 ≤ sqrt * (x+σ)
have h1 : (x + σ) * (x + σ) ≤ Real.sqrt ((x + σ)^2 + τ^2) * (x + σ) := by
  exact mul_le_mul_of_nonneg_right h_u_le_sqrt hu_nonneg

-- шаг 2: sqrt*(x+σ) ≤ sqrt*(sqrt + x+σ)
have h2 :
    Real.sqrt ((x + σ)^2 + τ^2) * (x + σ)
      ≤ Real.sqrt ((x + σ)^2 + τ^2) * (Real.sqrt ((x + σ)^2 + τ^2) + (x + σ)) := by
  exact mul_le_mul_of_nonneg_left h_u_le_sum hsqrt_nonneg

have hden :
    (x + σ)^2
      ≤ Real.sqrt ((x + σ)^2 + τ^2) *
          (Real.sqrt ((x + σ)^2 + τ^2) + (x + σ)) := by
  -- (x+σ)^2 = (x+σ)*(x+σ)
  simpa [pow_two] using le_trans h1 h2

-- теперь инвертируем:
have hterm_le :
    1 / (Real.sqrt ((x + σ)^2 + τ^2) *
          (Real.sqrt ((x + σ)^2 + τ^2) + (x + σ)))
      ≤ 1 / (x + σ)^2 := by
  -- one_div_le_one_div_of_le : 0 < a -> a ≤ b -> 1/b ≤ 1/a
  exact one_div_le_one_div_of_le (by nlinarith [hu_pos]) hden
```

Это как раз твоё “clean proof of `1/(sqrt...*(sqrt...+x+σ)) ≤ 1/(x+σ)^2`”.

```lean
have hterm_le' : ∀ᶠ x in atTop, term x ≤ 1/(x+σ)^2 := by
  -- filter_upwards, берёшь hx : 0 < x, потом применяешь hterm_le
  -- (внутри всё из 2.2)
  ...

have hmain : Tendsto (fun x : ℝ => 1 / (x + σ)^2) atTop (𝓝 (0:ℝ)) := h
```

### 4.1 Как получить `s ∈ 𝓝 z` для `s := {w | ε ≤ w.re}` (не шар)

Трюк: берёшь **открытое** множество `s' := {w | ε < w.re}`, оно в `𝓝 z` (если `ε < z.re`), и `s' ⊆ s`.

```lean
have hzε : ε < z.re := by linarith

have hs' : {w : ℂ | ε < w.re} ∈ 𝓝 z := by
  have hopen : IsOpen {w : ℂ | ε < w.re} :=
    isOpen_lt continuous_const continuous_re
  exact hopen.mem_nhds hzε

have hs : {w : ℂ | ε ≤ w.re} ∈ 𝓝 z :=
  Filter.mem_of_superset hs' (by intro w hw; exact le_of_lt hw)
```

Это обычно самый чистый способ.

## 5) Branch‑cut: правильная замена твоего (ложного) глобального `logGamma_hasDerivAt`

Если где-то ещё у тебя всплывает “лог‑гамма дифференцируема на `Re z>0`” для `log ∘ Gamma`, то **это в общем неверно** из-за ветвления `Complex.log`. Правильный Lean‑friendly statement — *с условием* `Gamma z ∈ slitPlane`, и тогда берёшь `HasDerivAt.clog`. citeturn14view0turn21view0

Скелет:

```lean
open Complex

theorem logGamma_hasDerivAt_of_gamma_mem_slitPlane
    (z : ℂ) (hz : 0 < z.re) (hslit : Gamma z ∈ slitPlane) :
    HasDerivAt (fun w => log (Gamma w)) (deriv Gamma z / Gamma z) z := by
  have hdiffG : DifferentiableAt ℂ Gamma z := by
    refine Complex.differentiableAt_Gamma z ?_
    intro m hm
    -- если z = -m, то re z ≤ 0, contradiction with hz
    have : z.re = (-(m : ℂ)).re := by simpa [hm]
    -- (-(m:ℂ)).re = -(m:ℝ)
    have : z.re = -(m : ℝ) := by simpa using this
    have : z.re ≤ 0 := by nlinarith
    exact (not_lt_of_ge this hz)

  have hderivG : HasDerivAt Gamma (deriv Gamma z) z :=
    hdiffG.hasDerivAt

  -- главный шаг:
  simpa using (HasDerivAt.clog hderivG hslit)
```

Если хочешь именно твой `digamma z`, то просто `simp [digamma]` в конце.

### 1.2. Мини‑ядро: какие леммы нужны (Lean‑friendly список)

#### (A) Stieltjes summation (N=1) для произвольной C¹‑функции
Сформулируй как отдельную лемму (самую общую не надо; достаточно под вашу `f`):

**Лемма `stieltjes_sum_eq` (идеальная форма):**

Для `N : ℕ`, `z : ℂ` с `0 < z.re`:

\[
\sum_{n=0}^{N-1} \frac{1}{z+n}
=
\log(z+N)-\log z + \frac{1}{2z}-\frac{1}{2(z+N)}
-\int_{0}^{N} \frac{B_1(\{x\})}{(x+z)^2}\,dx
\]

где \(B_1(t)=t-\tfrac12\), \(\{x\}=\text{fract}(x)\).

Lean‑скелет:

- определяешь `B1fract x : ℝ := Int.fract x - (1/2:ℝ)`.
- доказываешь на каждом интервале `[k,k+1]` интегрирование по частям/телескоп:
  \[
  \int_k^{k+1} f(x)\,dx = f(k+\theta) \text{ и } \int_k^{k+1}(x-k-\tfrac12)f'(x)dx
  \]
  стандартный Stieltjes trick.
- суммируешь по `k=0..N-1` (`intervalIntegral.sum_integral_adjacent_intervals`‑подобная лемма или `MeasureTheory.integral_Icc_eq_sum_integral_Icc`).

**Важно:** на линии `0<Re z`, у тебя `x+z` лежит в правой полуплоскости, значит `Complex.log` можно использовать *без* branch‑условий, потому что правая полуплоскость ⊂ slitPlane автоматически. То есть в этой части branch‑cut не всплывает.

#### (B) Переход `N→∞` к digamma через limit
Ключевая “смычка”:

\[
\psi(z)=\lim_{N\to\infty}\left(\log N - \sum_{n=0}^{N-1}\frac{1}{z+n}\right)
\]

Это следует из стандартной серии digamma (которая у вас уже есть в Stage 1/2 через `digammaSeq → digamma`). В `PROWKA_RESPONSE_3` ровно эта стратегия описана “без чисел”. fileciteturn0file9

Lean‑friendly доказательство:

1) Берёшь уже имеющуюся лемму вида  
`digamma z = -γ + ∑ (1/(n+1) - 1/(n+z))`.
2) Пишешь для частичных сумм:
`log N - ∑ 1/(n+z) = (∑ (1/(n+1)-1/(n+z)) - γ_N) + (log N - H_N)`  
и используешь:
- `tendsto` частичных сумм к `∑`,
- `tendsto (H_N - log N) = γ` (это обычно **определение** `Real.eulerMascheroni` в mathlib, так что часто это легко).

Фишка: γ сократится, и предел будет именно `digamma z`.

#### (C) Превращаем B1‑интеграл в ваш B2Diff‑интеграл
Вы хотите финальную форму с `bernoulli2Diff/(x+z)^3`. Для этого делается **интегрирование по частям по x на каждом (k,k+1)**, где `bernoulli2Diff` гладкая:

- у вас уже есть формула:
  `bernoulli2Diff x = fract x * (1 - fract x)` и границы. fileciteturn0file8
- на `(k,k+1)` имеем `fract x = x-k`, значит  
  `d/dx (bernoulli2Diff x) = 1 - 2*fract x = -2*(fract x - 1/2) = -2*B1(fract x)`.
- и также `d/dx (x+z)^{-2} = -2 (x+z)^{-3}`.

Отсюда на каждом интервале:
\[
\int_k^{k+1} \frac{B_1(\{x\})}{(x+z)^2}dx
=
-\int_k^{k+1}\frac{\text{bernoulli2Diff}(x)}{(x+z)^3}dx
\]
потому что граничные члены обнуляются: `bernoulli2Diff k = bernoulli2Diff (k+1)=0`.

Суммируешь по k, получаешь равенство на `[0,N]`, затем `N→∞`.

#### (D) Готовая цель: `digamma_stieltjes_identity`
Получается ровно ваш target:

\[
\psi(z)-\log z+\frac{1}{2z}
=
-\int_{0}^{\infty}\frac{\text{bernoulli2Diff}(x)}{(x+z)^3}dx,
\quad \Re z>0.
\]

Это и есть то, что в ваших файлах фигурирует как “digamma_stieltjes_identity”. fileciteturn0file4

## 1) Быстрый маршрут: Finite‑N Stieltjes (Euler–Maclaurin N=1) → предел N→∞

### 1.1. Локальная (unit interval) лемма: “трапеция + остаток через B1”

**Цель леммы на одном отрезке `[n, n+1]`** (реальная переменная `x`, значения в `ℂ`):

Пусть `f : ℝ → ℂ` дифференцируема на `[n,n+1]`. Тогда:
\[
\int_n^{n+1} f(x)\,dx
= \frac{f(n)+f(n+1)}{2} - \int_n^{n+1} (x-(n+\tfrac12))\, f'(x)\,dx.
\]

**Lean‑скелет** (без магии, только ФТОК на производной произведения):

- Введи `g(x) := (x - (n + 1/2)) * f x`.
- Тогда `g'(x) = f x + (x - (n+1/2)) * f' x`.
- Интегрируй `g'` на `n..n+1` и распиши `g(n+1)-g(n)`.

Это в Lean обычно делается через `intervalIntegral.integral_deriv_eq_sub`/`integral_eq_sub_of_hasDerivAt` на `g`, плюс `HasDerivAt.mul` и `HasDerivAt.sub_const`.

**Почему это быстро:** это *маленькая* лемма, без measure‑theory на `Ioi` и без глобальных доминируемых сходимостей.

---

### 1.2. Суммирование по n=0..N−1: “finite‑N Stieltjes sum identity”

Берёшь `f(x) = 1/(x+z)` при `0 < z.re`. Тогда `f'(x) = -(x+z)^{-2}`.

После суммирования unit‑interval леммы ты получаешь стандартную формулу из `PROSHKA_REQUEST_7` (п.1): 【343:0†PROSHKA_REQUEST_7.md†L41-L48】

\[
\sum_{n=0}^{N-1} \frac{1}{z+n}
= \log(z+N) - \log z + \frac1{2z} - \frac1{2(z+N)}
- \int_0^N \frac{B_1(\{x\})}{(x+z)^2}\,dx,
\]
где \(B_1(t)=t-\frac12\).

**Lean‑заметки, чтобы не словить branch cut:**

- Используй `Complex.hasDerivAt_log` и условие `x+z ∈ Complex.slitPlane`. Это есть в mathlib: `Complex.hasDerivAt_log` требует `z ∈ slitPlane`. 【turn15view0†L82-L90】
- Для `0 < z.re` и `x≥0` имеем `(x+z).re > 0`, значит `x+z ∈ slitPlane` (поскольку slitPlane содержит правую полуплоскость). Это прямо упоминается в `PROSHKA_REQUEST_7`. 【343:0†PROSHKA_REQUEST_7.md†L49-L52】

### 1.3. Конверсия “B1(fract) → bernoulli2Diff” через интегрирование по частям на каждом `[k,k+1]`

Это шаг (2) из `PROSHKA_REQUEST_7`: 【343:0†PROSHKA_REQUEST_7.md†L53-L64】

Используй вашу функцию `bernoulli2Diff x = Int.fract x * (1 - Int.fract x)` (уже есть как `bernoulli2Diff_eq_mul`). 【343:0†PROSHKA_REQUEST_7.md†L28-L30】

На интервале `(k,k+1)`:
- `u(x) := bernoulli2Diff x = t(1-t)` где `t = fract x`.
- Производная: `u'(x) = 1 - 2t = -2(t - 1/2) = -2 * B1(fract x)`.

Дальше на `[k,k+1]`:
\[
\int_{k}^{k+1} \frac{B_1(\{x\})}{(x+z)^2}\,dx
= -\int_{k}^{k+1} \frac{u(x)}{(x+z)^3}\,dx
\]
потому что:
- `B1 = -u'/2`,
- интегрирование по частям переносит производную на `(x+z)^{-2}`,
- и **границы исчезают**, т.к. `u(k)=u(k+1)=0` (fract=0 ⇒ u=0).

Именно это и написано как целевое равенство (2) в `PROSHKA_REQUEST_7`. 【343:0†PROSHKA_REQUEST_7.md†L60-L64】

### 1.4. Переход N→∞: два предела

Здесь ровно шаг (3) `PROSHKA_REQUEST_7`: 【343:0†PROSHKA_REQUEST_7.md†L35-L41】

Нужны:

**(A) предел суммы:**
\[
\lim_{N\to\infty}\left(\log N - \sum_{n=0}^{N-1} \frac{1}{z+n}\right) = \psi(z)
\]
(в вашем коде это “existing digamma series machinery”). 【343:0†PROSHKA_REQUEST_7.md†L35-L41】

Если вдруг этого exact‑леммы не хватает, самый короткий путь — разложить:
\[
\log N - \sum_{n=0}^{N-1}\frac{1}{z+n}
= (\log N - H_N) + \sum_{n=0}^{N-1}\left(\frac1{n+1}-\frac1{z+n}\right),
\]
и использовать mathlib‑лемму о пределе гармоник:
`Real.tendsto_harmonic_sub_log` (в файле про Euler–Mascheroni). 【turn16search1†L1-L4】

**(B) предел интеграла:**
\[
\int_0^N \frac{bernoulli2Diff(x)}{(x+z)^3}\,dx \to
\int_0^\infty \frac{bernoulli2Diff(x)}{(x+z)^3}\,dx
\]
Это делается стандартно через “integrable tail” (раз integrand абсолютно интегрируемый на `Ioi 0`, то `integral_Icc 0 N → integral_Ioi 0`).

Итог после (A)+(B) даёт:
\[
\psi(z) - \log z + \frac{1}{2z}
= -\int_0^\infty \frac{bernoulli2Diff(x)}{(x+z)^3}\,dx,
\]
то есть ровно целевую `digamma_stieltjes_identity`. 【343:0†PROSHKA_REQUEST_7.md†L7-L14】

### 0. Теорема: Stieltjes N=1 для digamma на `Re z > 0`
**Формулировка (как у тебя):**
\[
\forall z\in\mathbb C,\ (\Re z>0)\Rightarrow
\psi(z)-\log z+\frac1{2z}
= -\int_{0}^{\infty}\frac{B_2 - B_2(\{x\})}{(x+z)^3}\,dx,
\]
где \(B_2(t)=t^2-t+\frac16\), \(\{x\}=\mathrm{fract}(x)\in[0,1)\), а у тебя
`bernoulli2Diff x = (1/6) - bernoulli2 (Int.fract x)`.

**Статус:** стандартная математика (Euler–Maclaurin / Stieltjes remainder), без дополнительных гипотез, кроме `Re z > 0` (для корректности комплексного `log` на пути интегрирования).

## 1. Что реально надо сделать в Lean (минимальный набор лемм)

### Шаг A. Финитная формула Эйлера–Маклорена для `f(x)=1/(x+z)` на `[0,N]`
Для `N : ℕ`, `N>0`, доказать:
\[
\sum_{n=0}^{N-1}\frac1{z+n}
=
\int_0^N \frac{dx}{x+z}
+\frac12\Big(\frac1z-\frac1{z+N}\Big)
-\int_0^N \frac{B_1(\{x\})}{(x+z)^2}\,dx,
\]
где \(B_1(t)=t-\frac12\) и на каждом интервале \((n,n+1)\) имеем \(B_1(\{x\})=x-n-\frac12\).

**Как сделать в Lean “по‑камешкам”:**
- разрезать интегралы на сумму по интервалам `[n,n+1]`;
- на каждом `[n,n+1]` применить integration by parts к
  \(u(x)=x-n-\frac12\), \(v(x)=\frac1{x+z}\).

Это даёт локально:
\[
\int_n^{n+1}\frac{dx}{x+z}
=
\frac12\Big(\frac1{z+n}+\frac1{z+n+1}\Big)
-\int_n^{n+1}(x-n-\tfrac12)\cdot\Big(-\frac1{(x+z)^2}\Big)dx.
\]
Суммирование по `n=0..N-1` и телескоп даёт формулу выше.

**Ключевой момент:** тут **не нужно** дифференцировать `Int.fract`. На каждом интервале просто используешь, что `Int.fract x = x - n` на `x ∈ Ioo (n) (n+1)` (через `Int.floor_eq_iff` / `Int.fract_def`), и всё становится линейным.

---

### Шаг B. Перепаковка “B1‑интеграла” в “B2Diff‑интеграл” без ветвления
Определим (как у тебя):
\[
\mathrm{B2Diff}(x)=\frac16-B_2(\{x\}) = \{x\}-\{x\}^2.
\]

На каждом `(n,n+1)` имеем:
\[
\mathrm{B2Diff}(x) = (x-n)-(x-n)^2,\quad
\frac{d}{dx}\mathrm{B2Diff}(x) = 1-2(x-n)= -2\big((x-n)-\tfrac12\big).
\]
То есть:
\[
\mathrm{B1Fract}(x):=\{x\}-\tfrac12 = -\frac12(\mathrm{B2Diff})'(x)
\quad\text{на }(n,n+1).
\]

Теперь на **каждом** `[n,n+1]` делаем integration by parts:
- `u = bernoulli2Diff` (квадратичная по `x` на интервале),
- `v = - (1/2) * (x+z)⁻²` (так что `v' = (x+z)⁻³`).

Получаешь локально:
\[
\int_n^{n+1}\frac{B_1(\{x\})}{(x+z)^2}\,dx
= -\int_n^{n+1}\frac{\mathrm{B2Diff}(x)}{(x+z)^3}\,dx
\]
**без граничных членов**, потому что `bernoulli2Diff n = bernoulli2Diff (n+1) = 0` (у тебя это легко: `Int.fract_int = 0`).

Суммируя `n=0..N-1`:
\[
\int_0^N \frac{B_1(\{x\})}{(x+z)^2}\,dx
= -\int_0^N \frac{\mathrm{B2Diff}(x)}{(x+z)^3}\,dx.
\]

### Шаг C. Предел `N → ∞` и связь с `digamma`
Нужно использовать известную формулу:
\[
\psi(z)=\lim_{N\to\infty}\Big(\log N - \sum_{n=0}^{N-1}\frac1{z+n}\Big)
\quad(\Re z>0),
\]
которая выводится из уже имеющейся у тебя **series‑версии** digamma + факта `harmonic N - log N → γ`.

Это, судя по твоим Stage 1/2, у тебя уже есть как часть `digammaSeq`‑машины (или его легко добить одной леммой через `Real.tendsto_harmonic_sub_log`).

Потом подставляешь финитную формулу из Шага A+B:
\[
\log N - \sum_{n=0}^{N-1}\frac1{z+n}

(\log N - \log(z+N))
+ \log z
-\frac1{2z}
+\frac1{2(z+N)}
-\int_0^N\frac{\mathrm{B2Diff}(x)}{(x+z)^3}dx.
\]

Дальше:
- `log N - log(z+N) → 0`,
- `1/(z+N) → 0`,

\[
\psi(z)=\log z-\frac1{2z}-\int_0^\infty\frac{\mathrm{B2Diff}(x)}{(x+z)^3}\,dx
\]
=> требуемая формула.

## 0. Теорема и статус

**Утверждение (Stieltjes N=1 remainder для digamma, logGamma‑free):**  
Для любого `z : ℂ` с `0 < Re(z)` верно
\[
\psi(z)-\log z+\frac1{2z} \;=\; -\int_{0}^{\infty}\frac{B_2 - B_2(\{x\})}{(x+z)^3}\,dx,
\]
где \(B_2(t)=t^2-t+\tfrac16\) и \(\{x\}=\mathrm{fract}(x)\in[0,1)\).  
В ваших обозначениях:
```lean
Q3.digamma z - Complex.log z + (1/2:ℂ) * z⁻¹
  = - ∫ x in Set.Ioi (0:ℝ), (bernoulli2Diff x : ℂ) / (x+z)^3
```

**Статус:** стандартный анализ/комплексный анализ; в Lean реализуемо через FTC на каждом `[n,n+1]` + предел.

1) На каждом `[n,n+1]` вывести “трапецоидное” тождество:
   \[
   \int_n^{n+1}\frac{dx}{x+z}

### 5.1 Tendsto `1/(x+σ)^2 → 0` (чистая цепочка)

```lean
open scoped Topology
open Filter

lemma tendsto_one_div_add_sq_atTop (σ : ℝ) :
    Tendsto (fun x : ℝ => 1 / (x + σ)^2) atTop (𝓝 (0 : ℝ)) := by
  -- use: (x+σ)^2 → ∞, then inv → 0
  have h1 : Tendsto (fun x : ℝ => (x + σ)^2) atTop atTop := by
    -- (x+σ) → ∞, then square → ∞
    have : Tendsto (fun x : ℝ => x + σ) atTop atTop := by
      simpa [add_comm, add_left_comm, add_assoc] using (tendsto_add_const_atTop_iff (a := σ))
      -- If this lemma name doesn't match in your Mathlib: use `tendsto_atTop_add_const_right`.
    exact (tendsto_pow_atTop_atTop_of_one_lt (by norm_num : (1:ℕ) < 2) this)
  -- now invert
  simpa [one_div] using (tendsto_inv_atTop_zero.comp h1)
```

```lean
lemma inv_prod_sqrt_le_inv_sq (x σ τ : ℝ) (hx : 0 ≤ x) (hσ : 0 < σ) :
    1 / (Real.sqrt ((x+σ)^2 + τ^2) * (Real.sqrt ((x+σ)^2 + τ^2) + (x+σ)))
      ≤ 1 / (x+σ)^2 := by
  have hA : x+σ ≤ Real.sqrt ((x+σ)^2 + τ^2) := sqrt_sq_add_le x σ τ hx hσ
  have hxσ : 0 < x+σ := by nlinarith [hx, hσ]
  have hpos1 : 0 < Real.sqrt ((x+σ)^2 + τ^2) := lt_of_lt_of_le hxσ hA
  have hpos2 : 0 < Real.sqrt ((x+σ)^2 + τ^2) + (x+σ) := by nlinarith [hpos1, hxσ]
  -- lower bound for denominator:
  have hden : (x+σ)^2 ≤ Real.sqrt ((x+σ)^2 + τ^2) * (Real.sqrt ((x+σ)^2 + τ^2) + (x+σ)) := by
    -- use monotonicity: sqrt ≥ x+σ and (sqrt+(x+σ)) ≥ (x+σ)
    have hB : x+σ ≤ Real.sqrt ((x+σ)^2 + τ^2) + (x+σ) := by nlinarith [hA]
    nlinarith [hA, hB]
  -- invert inequality
  have hposDen : 0 < Real.sqrt ((x+σ)^2 + τ^2) * (Real.sqrt ((x+σ)^2 + τ^2) + (x+σ)) := by
    nlinarith [hpos1, hpos2]
  have hposSq : 0 < (x+σ)^2 := by nlinarith [hxσ]
  exact one_div_le_one_div_of_le hposSq (by simpa using hden)
```

## 6. Основная лемма `digamma_stieltjes_identity`: как резать в Lean

### Ключевой “сертификат” (финитный шаг)

Вот точная финитная формула, которую надо сделать основной промежуточной леммой (в ℂ‑значных интегралах по ℝ):

\[
\sum_{k=0}^{N-1}\frac{1}{z+k}
=
\log(z+N)-\log z + \frac{1}{2z}-\frac{1}{2(z+N)}
+ \int_{0}^{N}\frac{\texttt{bernoulli2Diff}(x)}{(x+z)^3}\,dx.
\]

В Lean я бы делал так:

- Лемма A (`trap_unit_interval`): для каждого `n : ℕ` на `[n,n+1]`.
- Лемма B (`b1_to_b2_unit_interval`): на `[n,n+1]`.
- Лемма C (`sum_trap`): суммирование по `n=0..N-1` с телескопированием `log(z+n+1)-log(z+n)` и граничными членами.
- Лемма D (`digammaSeq_finite`): переписать в форме `digammaSeq z N = ...`.
- Лемма E (`tendsto_integral_trunc`): `∫_{(0,N]}` → `∫_{(0,∞)}`.
- Финал: `tendsto_digammaSeq` + `tendsto_inv` + `tendsto_integral_trunc`.
