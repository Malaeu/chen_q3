# X Insider

## Обзор

Собирать практические инсайты из недавнего диалога и фиксировать их в единой личной базе знаний.

## Процедура

1. Определить окно анализа.
По умолчанию брать последние `5-10` сообщений чата. Если пользователь явно задал другое окно, использовать его.

2. Извлечь только полезные сигналы.
Фиксировать решения, причины решений, риски, ограничения, блокеры, рабочие команды и ближайшие шаги.

3. Сжать материал.
Сформировать `4-10` коротких пунктов без шума логов и без повторов.

4. Записать инсайты в файл.
Запускать скрипт:

```bash
python3 skills/x-insider/scripts/append_chat_insights.py \
  --output docs/insides_knowledge_base_personal.md \
  --window "последние 5-10 сообщений" \
  --title "<краткая тема>" <<'EOF_INSIGHTS'
- <инсайт 1>
- <инсайт 2>
- <инсайт 3>
EOF_INSIGHTS
```

5. Подтвердить запись.
Проверить хвост файла:

```bash
tail -n 40 docs/insides_knowledge_base_personal.md
```

## Экспорт чата и режим `--from-chat-file`

Если нужен полуавтоматический режим, сначала сохранить чат в текстовый/markdown файл, затем запустить:

```bash
python3 skills/x-insider/scripts/append_chat_insights.py \
  --from-chat-file session_exports/chat_latest.md \
  --messages-window 10 \
  --max-insights 8 \
  --title "<краткая тема>" \
  --tag chat-export
```

Этот режим:
- Берет последние `N` сообщений из экспортированного файла.
- Автоматически собирает короткие пункты-инсайты.
- Записывает результат в `docs/insides_knowledge_base_personal.md`.

## Быстрый экспорт из локальной сессии (`x-export`)

Вместо ручного копирования можно экспортировать текущую сессию напрямую из `~/.codex/sessions`:

```bash
./scripts/x-export
```

По умолчанию экспортирует всю последнюю сессию в `session_exports/chat_latest.md`.

Экспорт только последних `N` сообщений:

```bash
./scripts/x-export 10
./scripts/x-export 5
```

После этого сразу запускать выжимку:

```bash
python3 skills/x-insider/scripts/append_chat_insights.py \
  --from-chat-file session_exports/chat_latest.md \
  --messages-window 10 \
  --max-insights 8 \
  --title "Выжимка по локальной сессии"
```

## One-shot режим (`x-insider`)

Для автоматической цепочки `экспорт -> выжимка -> запись`:

```bash
./scripts/x-insider
./scripts/x-insider 10
./scripts/x-insider 5
```

- `./scripts/x-insider` -> экспортирует всю последнюю сессию и пишет выжимку.
- `./scripts/x-insider N` -> экспортирует последние `N` сообщений и пишет выжимку.

## Критерии качества

- Писать конкретно и проверяемо.
- Сохранять команды и пути как есть, если они важны.
- Не переносить длинные логи целиком.
- Не добавлять предположения без явной пометки, что это гипотеза.
