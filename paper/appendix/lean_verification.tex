\section{Lean Verification Notes}
\label{app:lean}

This appendix records the verification methodology and scope.
The \emph{current} machine-checked status is maintained in
\texttt{appendix/lean\_status\_snapshot.tex}, which is generated from the live
Lean chain and must be treated as the single status source in this manuscript.

\subsection{Scope}

The Lean development verifies formal statements in the Q3 chain and tracks
axiom dependencies for the current theorem route. Status claims in prose are
considered valid only if they match the generated snapshot.

\subsection{Reproducible Status Pipeline}

The snapshot is generated from:
\begin{itemize}
  \item \texttt{q3.lean.aristotle/Q3/CheckAxioms.lean}
  \item \texttt{\#print axioms Q3.Main.RH\_of\_Weil\_and\_Q3}
  \item \texttt{q3.lean.aristotle/ACTIVE/orchestrator.md}
\end{itemize}

Operational commands:
\begin{verbatim}
cd q3.lean.aristotle
python3 scripts/export_paper_status.py --out ../paper/appendix/lean_status_snapshot.tex
python3 scripts/export_paper_status.py --out ../paper/appendix/lean_status_snapshot.tex --check
./scripts/check_paper_status.sh
\end{verbatim}

\subsection{Interpretation Rule}

If any statement in this manuscript conflicts with the generated Lean snapshot,
the generated snapshot takes precedence.
